# 合规使用边界

本包只提供通用能力：包内零站点名称、零域名、零站点专属接口、零选择器、零账号与零凭据。站点差异由使用方在本机实例目录按各技能规范自建，随包分发的只有方法。使用方对本包的使用方式独立承担合规责任；本文列出必须守住的边界与逐项判据。

## 一、允许的使用范围

| 项 | 判据 |
|---|---|
| 素材来源 | 自己享有著作权，或已取得权利人覆盖本次使用方式与范围的授权 |
| 采集对象 | 自己有权访问的内容，且访问方式符合目标站点 robots 协议、用户协议与访问频次约定 |
| 发布账号 | 本人实名注册、本人持有并有权使用的账号 |
| 发布内容 | 自己生成或已获授权的作品，内容合法，标识齐全 |
| 使用规模 | 与正常人工操作相当的量级，按平台审核节奏分批 |

## 二、素材采集边界

1. 采集前确认目标站点的 robots 协议与用户协议；两者任一限制自动化访问时，以限制为准。
2. 不得绕过登录校验、验证码、身份认证、访问控制与频率限制；不得注入非本人账号的登录态；不得使用代理池或换出口规避风控。
3. 不得删除、改变或绕开水印、权利管理电子信息与平台设置的展示标记；不得为取得无水印版本而改写地址参数。
4. 不得采集含他人肖像、声音、姓名、联系方式等个人信息或人格要素的素材用于生成与发布，取得权利人明确授权的情形除外。
5. 采集所得属素材，不是成片；不得将他人作品原样或经轻微改动后作为自有作品发布。
6. 采集链路的站点参数、站点分册、动作台账与登录态只留在本机用户级目录，不得随任何二次分发的包外流。

## 三、账号与发布边界

1. 每个账号限于注册人本人使用；不得共享、出租、买卖账号，不得代收验证码，不得伪造或复用他人登录态。
2. 自动化操作、多账号矩阵与批量投稿是否获准，以目标平台现行用户协议为准；平台条款限制时，按条款执行。
3. 真实发布属外发动作：先出发布单、人工确认、再执行；未确认状态一律停在闸门前。
4. 逐站差异化文案与错峰安排用于配合平台审核节奏，不得用于规避平台风控判定。
5. 回执状态按实际填写；「发布未验证」不得写成「已发布」。

## 四、内容与标识边界

1. AI 生成合成内容须同时具备显式标识与隐式标识；平台声明入口只是显式标识的一环，勾选不得视为合规完成。
2. 原创声明按实际沿用比例判断；成片沿用原片构图、分镜、镜头运动或音轨时，按二创或演绎口径处理，并保留来源与授权凭证。
3. 字体按通用规范白名单选取；字体名与授权协议、素材来源与授权协议一并记入《字体与素材授权台账》。
4. 内容不得含违法信息、侵害他人名誉与知识产权的表述，不得冒用他人名义。

## 五、包体与二次分发边界

1. 本包保持零站点；针对具体站点的解析链路、投稿字段、选择器、按钮文案与字数上限由使用方在本机自建。
2. 面向第三方的二次分发物同样适用零站点要求：不得附带已跑通的站点记录、绕控手法、账号配置与凭据。
3. 打包器的站点记录排除与凭据门禁不得关闭或改写；出包日志须为「未检出凭据与站点记录」。

## 六、使用方自行核验清单

| 项 | 核验动作 | 通过判据 |
|---|---|---|
| 目标站点条款 | 逐站阅读 robots 协议、用户协议、自动化与多账号条款 | 条款允许本次访问与发布方式 |
| 素材权利 | 逐项查授权凭证、授权范围与期限 | 覆盖本次使用方式、地域与期限 |
| 人格要素 | 涉及真人形象或声音时查授权 | 有可追溯的书面授权 |
| AI 标识 | 查成片显式标识与文件元数据隐式标识 | 两者齐备 |
| 平台声明 | 首次发布前在真实表单页确认声明入口 | 控件与文案取自真实页面 |
| 现行法规与条款 | 按分发时点复核 | 以现行有效文本为准 |

## 七、依据与责任

涉及的主要规范：《人工智能生成合成内容标识办法》（2025-09-01 施行）、《中华人民共和国反不正当竞争法》（2025 年修订，数据专款）、《中华人民共和国刑法》第二百八十五条、《中华人民共和国网络安全法》第二十七条、《中华人民共和国著作权法》与《中华人民共和国民法典》人格权编，以及各目标平台现行用户协议。

本文为使用边界说明，不构成法律意见；法规与平台条款随时可能调整，对外商业分发或规模化使用前，由使用方自行取得专业法律意见。本包按现状提供，使用方对素材授权、账号权限、内容合法性与目标平台合规独立负责。
