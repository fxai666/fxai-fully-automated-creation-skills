# 字体与素材授权台账

每个交付物一份，落在项目目录，随交付清单留存。台账是交付物的一部分，不进技能目录、不进分发包。

规范出处：`fxai-standard/references/06-字体与素材授权.md`。本册只给台账格式与判据，白名单以该册为准。

## 一、记录口径

| 项 | 判据 |
|---|---|
| 字体 | 只从通用规范 06 册白名单选取；记录字体名 + 授权协议，厂商免费商用声明另记声明来源与日期 |
| 图片 / 音频 / 视频片段 | 记录来源、权利人、协议、凭证位置与使用范围 |
| AI 生成内容 | 记录生成方式、提示词出处与 AI 标识落地方式 |
| 交付物 | 一个交付物对应一份台账，文件名带交付物名或项目名 |

## 二、来源判据

| 来源状态 | 处理 |
|---|---|
| 自己原创，权利完整 | 记录创作人、完成日期、首次发布位置 |
| 已获权利人授权 | 记录授权方、协议或授权书、覆盖范围与期限、凭证位置 |
| 开源或免费商用 | 记录协议全称、声明来源与查证日期 |
| 来源或授权范围不明 | 禁用；补齐凭证后再进入交付 |

## 四、与发布环节的关系

1. 原创声明与 AI 声明按实际填写，两者均不替代台账。
2. 勾选平台 AI 声明入口不替代隐式标识，隐式标识状态另见《已知合规缺口清单》。
3. 发布单引用台账路径，不复制台账正文。
4. 台账缺失的交付物停在发布闸门前。
