# 02 · 更新与合并规程

> **何时读**：执行更新、做三方合并、处理冲突与回滚时。

## 更新流程

1. `update.py check` —— 取索引，比对本机版本。
2. `update.py update` —— 下整包 → 校验 → 解压到 `stage/full/` → 逐文件按下面三类判定处理。
3. `update.py tasks` —— 看待合并任务（每条给出基线 / 本地 / 上游三份文件的绝对路径）。
4. 智能体逐条合并 → `apply_merge.py apply` 落盘。
5. `update.py status` —— 复核版本与剩余待合并。

## 三类判定（脚本自动做）

| 判定 | 条件 | 处理 |
|---|---|---|
| 已一致 | 本地与包内 sha256 相同 | 只登记，不动文件 |
| 直接替换 | 本地与基线一致（本地没改过），或本地无此文件 | 备份本地 → 落包内版本 → 刷新基线 |
| 待合并 | 本地 sha256 与基线不符 | 包内版本留在 `stage/full/`，写进 `pending_merge.json` |

仅本机有、包里没有的文件：列在 `[LOCAL-ONLY]` 里，**保留不删**（可能是用户自建内容）。
版本不高于本机时 `update` 直接退出，要重拉加 `--force`。

包内含 `专家包/` 时，落盘结束前会做一次「专家就绪检查」：按 01 册四种判定，未安装、版本落后、
市场清单未登记才执行包内 `install_expert.py`；已就绪不动。专家安装失败只告警，不阻断技能落盘、
不阻断版本号写入，随后可单独跑 `update.py expert --install` 补齐。

## 三方合并（智能体做）

三份材料的语义：

- `base` —— 基线副本：上次落盘时的版本，共同祖先。
- `ours` —— 本地当前文件：装着本机改动。
- `theirs` —— 包内新版：装着官方这次的改动。

合并判据（按序执行）：

1. **以 `theirs` 为骨架**，把 `ours` 相对 `base` 的改动逐处并入；不得反向用 `ours` 当骨架
   去挑上游改动 —— 上游新增的函数、字段、章节、判据会漏。
2. **两边改动不重叠的部分全部保留**：上游的新规则与本地的个性化内容都要在结果里。
3. **改动重叠时的取舍**：结构、接口、字段名、判据、命令入口以 `theirs` 为准；
   本地独有的路径、账号、自定义条目按语义并入新结构。无法两全时，保留 `theirs` 结构
   并把 `ours` 的独有内容就近安置，在报告里写明安置位置。
4. **结果自检**：`.py` 走内存 `compile()`，`.json` 走 `json.loads`，`.md` 查章节与表格行数
   不低于 `theirs`；任一不过就重做，不得带错落盘。

## 落盘与放弃

- `apply_merge.py apply --file <相对路径> --merged <合并后文件>`：备份本地 → 落盘 →
  刷新基线副本与状态文件的 sha256；队列清空时写入上游版本号。
- `apply_merge.py keep --file <相对路径>`：保留本地不动，把本地当前内容记为新基线
  （此后该文件按本地内容比对）。

## 回滚

`update.py rollback`：把最近一份备份（`<备份目录>/<时间戳>/`）的文件拷回技能目录，
并还原状态文件的 sha256。指定 `--to <时间戳>` 回滚到更早那份。
备份只增不删，回滚本身不删备份；`stage/` 与 `pending_merge.json` 不参与还原。

## 专家安装与回滚边界

- 判定与落点见 01 册；`update.py expert --check` 只报不动，`--install` 才写专家市场。
- 安装脚本来自已通过 sha256 校验的整包，仅做本地文件复制与市场清单注册；不得启动服务。
- 配有多个宿主配置根时，用 `--config-root` 指定；缺省取环境变量或技能根反推的那一个。
- 备份目录只收技能文件，`rollback` 不还原专家目录；专家异常单独跑 `expert --install`。
- 旧版更新器把 `专家包/` 平铺进技能根留下的目录，只是残留文件、不是安装位置，专家中心看不到；
  正确位置在 `<配置根>/plugins/marketplaces/my-experts/plugins/`。按「仅本机有保留不删」处理，不清理。

## 安全红线

- 只走 HTTPS，host 必须等于配置的官网域名；跨主机重定向一律拒绝。
- 整包打不开或 `testzip()` 不过即中止；索引给了 `sha256` 就比对，不符不落盘。
- 相对路径含 `..` / 盘符 / 绝对路径一律拒绝；`__pycache__` / `.pyc` 不落盘。
- 整包内 `专家包/` 一律不落进技能根；专家只由包内 `install_expert.py` 写进专家市场目录。
- 除本技能外，任何技能目录只写「落盘 + 备份 + 刷新基线」这三个动作产生的文件，
  其余一律不写。
