# 01 · 接口与目录约定

> **何时读**：配官网域名 / 路径前缀、改服务端 `skill.json`、确认本机落点时。

## 配置（读 `~/.workbuddy/fxai_global.json`）

| 键 | 作用 | 缺省 |
|---|---|---|
| `update.site` | 官网域名（只写域名，不带 `https://`） | 取 `brand.official_site` |
| `update.prefix` | 服务端升级目录名 | `upgrade` |
| `update.skills_dir` | 本机技能根目录（各 `fxai-*` 的父目录） | `~/.workbuddy/skills` |
| `update.state_dir` | 状态 / 基线 / 备份的父目录（隔离测试改它） | `~/.workbuddy` |

`brand.official_site` 也缺省时，域名用 `www.fxai.site`（与 `fxai-common/env_guard.py` 的品牌兜底同源）。

## 服务端接口

- 索引：`https://<site>/<prefix>/skill.json`
- 压缩包：`https://<site>/<prefix>/<path>` —— `<path>` 由索引返回，中文按百分号编码后拼在
  前缀后面。**层级与文件名由服务端决定**，客户端不写死；服务端把包挪到 `packages/xxx.zip`，
  只要 `path` 返回同样的相对串即可，客户端不用改。

## skill.json 字段

| 字段 | 必填 | 含义 |
|---|---|---|
| `version` | 是 | 版本号，按数字段比较（`1.2` 与 `V1.2` 同值） |
| `path` | 是 | 压缩包相对 `upgrade/` 的路径 |
| `sha256` | 否 | 整包校验值；给了就比，不符即中止 |
| `size` | 否 | 整包字节数，仅作提示 |

服务端返回的编码可能是 UTF-8 带 BOM、纯 UTF-8 或 GB18030，客户端按这个顺序试解码，
第一个解通的即用（带 BOM 时标准 UTF-8 解码会让 `json.loads` 报错，必须走 `utf-8-sig`）。

## 本机三个落点（都在 `update.state_dir` 下，不进技能目录）

| 落点 | 路径 | 内容 |
|---|---|---|
| 版本状态 | `<state_dir>/fxai_update_state.json` | 当前 `version` + 每个文件的 `sha256` / `size` |
| 基线副本 | `<state_dir>/fxai_update_baseline/<相对路径>` | 落盘时的文件内容副本，三方合并的共同祖先 |
| 备份与暂存 | `<state_dir>/fxai_update_backup/<时间戳>/` | 旧文件备份、`stage/`（整包 + 解压目录）、待合并任务 `pending_merge.json` |

状态文件缺失时，首轮 `update` 以本机现有文件建立基线（`version` 记 unknown），
此后按基线判「本地是否被改过」。

## 随包专家的落点（不进技能根）

包内 `专家包/` 不参与逐文件落盘。更新器读 `专家包/.codebuddy-plugin/plugin.json` 的
`name` / `version`，把专家装到专家市场：

```
<配置根>/plugins/marketplaces/my-experts/plugins/<专家ID>/
```

配置根认定顺序：`WORKBUDDY_CONFIG_DIR` → `dirname(update.skills_dir)`；技能装在哪，专家就装在同一配置根。
不得写死产品目录名。专家目录不得使用目录连接：宿主加载器 `resolve()` 后校验专家必须位于该市场目录下，
每个配置根各存一份实体文件。

| 判定 | 条件 | 动作 |
|---|---|---|
| 未安装 | 专家目录不存在 | 执行包内 `install_expert.py --config-root <根>` |
| 版本落后 | 本机 `plugin.json` 版本低于包内 | 同上加 `--upgrade` |
| 未登记 | 市场清单无该条目 | 同上，只补清单与缺件，不覆盖同名文件 |
| 已就绪 | 版本不低于包内且已登记 | 不动 |

专家状态写在 `fxai_update_state.json` 的 `expert` 字段（ID / 版本 / 判定 / 配置根）。
`check` 与 `status` 会报本机专家状态；`rollback` 只还原技能文件，不还原专家。

## 发布一版（作者侧）

`scripts/make_index.py --zip <整包zip> --version 1.2 --out <发布目录>`：
把 zip 放进发布目录、按 `--path` 指定的相对路径写出 `skill.json`；整个发布目录上传到官网
`<prefix>/` 下即完成发布。
