`fxai_common.py` 是 fxai 全系列技能共用的底层模块。**它不是一个技能**——没有触发条件，智能体不会主动"调用"它；
它是被别的技能 `import` 的库。装包时它必须和各技能目录**同级**（所有依赖方都用 `../fxai-common` 相对路径找它）。

### 影调与接缝对齐（`video_tone.py`）

分段生成后拼成一条之前过两道工序：① 影调对齐（乘法增益，拉回参考色阶）
② 接缝对齐（加法平移，贴上一段末帧）。**顺序不得颠倒**，原理与口径见 05 册。

```python
import video_tone
fixed = video_tone.align(段列表, outdir="tmp/tone")   # 返回等长同序的路径，直接拼
```

不依赖 ComfyUI、不占显存，可以单独重跑；校正量可忽略的段原样返回、不重编码。

## 公共约定：等任务纪律（跨技能唯一真相源）

**任何技能跑长任务都适用**——MV 渲染、短剧批量渲染、生图、云端部署、配图批量生成。
本条是全技能唯一真相源，各技能 SKILL.md 内联「等任务」时只指向这里，完整规则以本条为准。

### 三类等待，三条不同的规矩

三类等待对象的等法对照表见 references/04-等任务速查.md。

### 🔴 后台 Bash 任务：不得阻塞等待

**规则**：派后台任务后，若收到「仍在运行 / 你会被自动通知 / do NOT poll」这类提示，
**立刻停止查询**，任务完成通知是唯一正确的结果获取路径。

- **`block=true` 只在预计剩余 ≤60 秒时用**（否则长时间零产出并吞掉完成通知）。
- **同一后台任务最多连查 1 次**。要看实时进度走 `progress.html` 面板（浏览器直连 WS，零token），
  别让 Agent 反复轮询。
- **长任务用「派子代理 + 后台跑 + 等通知」，主线程同时写文案 / 查资料**，
  主线程的活同时干（写文案 / 查资料）；`block` 等同一个任务会把主线程和后台都堵死。

## 公共约定：参考图 ref 路径语义（代码层事实 + 指针）

所有用到人物 / 场景参考图的 fxai 技能（`fxai-short-drama` / `fxai-fourview-gen` / `fxai-scene-gen` /
`fxai-mv-pipeline` / `fxai-audio-video` 等）共用这一条 `ref` 规则。**路径格式、取值出口、
提交被拒的定位判据归 `fxai-standard/references/10-资源引用路径规范.md`**，本条只写代码层事实。

### 最小约束（打包不带 fxai-standard 时同样成立）

- `ref`（以及由角色 / 场景 `server_index` 推导出的参考图路径）一律填【服务端相对路径】
  `<子目录>/<文件名>`（如 `avatar/000.png`、`shortdrama_xjz/000.png`），直接喂给图像选择器节点
  （四视图节点147「图片列表」、Ref2VA 参考图列表），由服务端按 rel 读取。
  音频、视频同一形态，基准分别为 `fxai/audio/`、`fxai/video/`。
- 本机路径只作上传源与 ffmpeg 入参，不进节点输入；本机磁盘 ≠ 服务端磁盘，`ref` 不依赖本机有这张图。

### 解析（实现见 `fxai-workflow/comfy_client._role_ref`）

取值解析表见 references/03-ref路径速查.md。

### 自有形象

- 女主 / 男主等自有角色一律用全局头像库路径 `avatar/000.png` / `avatar/001.png`
  （即 `comfy_client.REF_WOMAN` / `REF_MAN`）。只传路径：服务端本来就有这份头像，
  上传 / 另存 / 重传到项目目录会变成「项目内的另一张脸」，锚脸即错位。
- 需要确认它存在时才查（`comfy_client._list_files('avatar')`），本机目录不作依据。
