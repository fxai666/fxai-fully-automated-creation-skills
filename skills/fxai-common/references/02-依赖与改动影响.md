# fxai-common 依赖方与改动影响面

**何时读**：查谁在依赖它、或评估改公共函数会波及哪些技能时

| 技能 | 用它做什么 |
|---|---|
| `fxai-workflow` | `comfy_client.py` 靠它做代理绕过和 HTTP 出口（**ComfyUI 全部调用的入口**） |
| `fxai-comfyui-watcher` | `comfy_watch.py` 靠它轮询任务进度 |
| `fxai-voiceover` | `tts_client.py` / `voice_gen.py` 靠它发请求 |
| `fxai-voiceover-script` | `script_gen.py` 靠它校验口播文案 |
| `fxai-audio-video` | `audio_video.py` 靠它提交 ComfyUI 任务 |
| `fxai-digital-human-video` | `dh_pipeline.py` / `dh_video.py` 靠它提交任务 + 拼视频 |
| `fxai-audio-video` / `fxai-digital-human-video` | **`video_tone.py`** 拼段前做影调/接缝对齐（`concat_videos(..., tone=...)`） |

⚠️ **漏了这个目录，上面所有技能一调就 `ImportError: No module named 'fxai_common'`。**
解压后请确认 `fxai-common/fxai_common.py` 和 `fxai-workflow/` 是同一层。

全系列共用同一份实现。
所以改它要连带跑一遍上表里所有技能的调用；反过来，如果某个技能报了地址格式 / 代理 / 超时的怪问题，
先来这里看。
