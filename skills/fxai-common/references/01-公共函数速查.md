# fxai-common 公共函数与环境守卫速查

**何时读**：查它提供哪些函数（地址与代理 / HTTP / 环境守卫 / 口播文案）时

### 地址与代理

- `norm_url(s)` —— 地址规范化：反斜杠换正斜杠、压掉重复斜杠、去尾斜杠。
  Windows 路径和手抄地址混进反斜杠（`http://host:8188\`）会拼错 URL，统一走这里。
- `allow_local(trusted=("127.0.0.1", "localhost"))` —— **本机地址绕过代理**。
  127.0.0.1 一律绕过系统代理；走代理时 ComfyUI 提交任务直接 502 / 超时。
- `opener()` —— 全系列统一的 HTTP opener，已带本机绕过。HTTP 请求一律走这个。

### HTTP

- `http_get(url, timeout=8, op=None)` / `http_post(url, payload, timeout=60, op=None)` —— 统一出口，
  错误信息统一成可读格式。

### 环境守卫（换机器 / 给客户装时用）

`env_guard.py` 解决「技能搬到一台新机器上能否直接跑」，职责分两条，按下表各走各的：

| 类别 | 处理 | 理由 |
|---|---|---|
| 大件：ffmpeg、whisper 环境+模型、ComfyUI 及工作流模型 | **只探测，不自动下载**；缺了打下载指引（官网 + 夸克/迅雷/百度网盘 + 安装视频） | 体积大、安装繁琐，统一由「凤希AI伴侣」一次装好 |
| pip 小包：Pillow / numpy / opencc 等 | **自动补**：探测到缺就 pip 装（官方源 → 清华 → 阿里依次试） | 体积小，装得上就别烦用户 |

- `first_run_check(pip_pkgs=[...], need_companion=True)` —— 开工前调一次，查伴侣 + 补 pip。
- `require_companion()` —— 缺伴侣就打指引并抛 `RuntimeError`；返回软件安装目录。
- `has_companion()` / `companion_install_dir()` / `companion_data_dir()` ——
  按固定目录名 `<盘>:\fxai`（含 ffmpeg.exe）与 `<盘>:\fxaitool` 自动命中，**不猜具体盘符**。
- `ensure_pip(pkgs)` —— 返回 `(已装上的, 装不上的)`，装不上只警告不阻断。
- `guide_text(reason)` —— 指引文案本体。改下载链接 / 品牌联系方式改 `PAN_LINKS` 与模块顶部常量；
  品牌信息优先取 `~/.workbuddy/fxai_global.json` 的 `brand` 段（可加 `video_url` 指向安装视频页）。

⚠️ 文案写在源码里，**随源码一起被 fxai-crypt 加密打包**；指引内嵌在源码中，
外置文件在加密包丢失后就查不到了。

### 口播文案

- `MARK = "<|endofprompt|>"` —— 语气指令和正文之间的固定分界符。
- `parse_line(line)` —— 拆一行成 `(语气标签, 正文)`；无标签时标签为空。
- `check_script(lines, limit=80, require_tag=False)` —— 校验每段正文不超过 80 字、标签是否合法。
  超限 / 缺标签的段会列出来，由 `format_bad(bad)` 格式化成能直接说给用户的提示。
  被 `fxai-voiceover-script` 和 `fxai-voiceover` 共用，两边口径一致。

### 分段视频的影调 / 接缝对齐（`video_tone.py`）

**何时用**：多段生成后要拼成一条，段与段之间亮度/色温对不上、接缝一眼看出跳。
原理与参数口径见 `05-影调与接缝对齐.md`。

- `align(paths, outdir=None, mode="增益", region="八方位", seam=True, ref=None,
  strength=1.0, max_adjust=20.0, max_offset=12.0, max_jump=30.0, exe=None)` ——
  **一站式**：分析 → 影调规划 → 接缝规划 → 逐段校正。返回与入参等长、同序的路径列表，
  **校正量可忽略的段会原样返回原路径**（不重编码），直接拿返回值去拼即可。
- `analyze(path, region="八方位")` —— 抽首/中/末三帧，返回宽高帧率 + 背景块均值 + 逐通道均值。
- `plan_tone(segs, ref=None, mode="增益", strength=1.0, max_adjust=20.0)` —— 只算不写，
  返回每段 `{"gain", "offset", "note"}`；`ref=None` 以第一段为锚。
- `plan_seam(segs, tone=None, max_offset=12.0, base_rgb=None, max_jump=30.0)` ——
  **必须传 tone**（按影调校正后的值算），否则同一份差异校正两遍，段头会明显偏亮。
- `apply_correction(src, dst, gain=1.0, offset=(0,0,0))` —— 单段施加（`lutrgb`，crf16 重编码）。
- 命令行：`python video_tone.py --in a.mp4 b.mp4 --outdir out --dry-run`（先看量再动手）。

### 最终交付视频编码（`video_encode.py`）

**何时用**：任何技能写最终交付 MP4。规格与判据见 `fxai-standard/references/12-交付视频编码规格.md`。

- `DELIVERY_TOTAL_KBPS = 2000` / `DELIVERY_AUDIO_BPS` / `BITRATE_TOLERANCE` —— 数值唯一出处。
- `delivery_video_bps(audio_bps)` —— 视频目标码率＝总码率减音轨码率。
- `delivery_venc(audio_copy=True, audio_bps=None, extra=None)` —— 返回单遍定码率参数列表，
  直接替换产线原有的 `-crf` / `-cq` 参数段；含 `-maxrate` / `-bufsize` / `+faststart`。
- `encode_delivery_2pass(src, dst, vf=None, ffmpeg=None, cwd=None, ...)` —— 两遍定码率，
  偏差最小，完成后自动跑码率验收；烧字幕时传 `vf` 与 `cwd`。
- `decoded_bitrate(path)` / `assert_delivery_bitrate(path)` —— ffprobe 读取 `format.bit_rate`，
  落在 1800～2200 kbps 才放行。命令行：`python -B fxai-standard/scripts/video_bitrate.py <成片.mp4>`。
