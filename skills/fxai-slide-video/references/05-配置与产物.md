# 05 · 配置与产物

> **何时读**：配环境、找产物、查脚本职责时。只管出片的话读 SKILL.md 即可。

## 项目建在哪

🔴 项目文件夹建在**当前工作区**下，按项目名建文件夹。没有「全局 projects_root」这一层。

目录解析优先级、子目录结构、成片命名、交付清单均由 **`sv_layout.py` 强制执行**，查结构看该文件。

一句话规则：**单件 → 项目根；成组 → 子目录；中间产物 → `_tmp/`。**

改目录结构 / 清单字段只改 `sv_layout.py`，路径由它统一产出。查落点与归位：

```
python sv_layout.py <项目名> [--files] [--migrate] [--delivery] [--export DIR] [--dry]
```

🔴 `sv_layout.migrate()` 只用于幻灯片项目。

## 全局配置

🔴 工具路径从 `~/.workbuddy/fxai_global.json` 读。该配置只放机器级设置，**不放项目路径**：

| 键 | 用途 |
|---|---|
| `software_install_dir` | ffmpeg（必须带 libass）|
| `chrome_path` | 浏览器（headless 截图 / 录制）|
| `whisper_device` | CPU 或 GPU |
| `audio_loudness` | 响度归一化目标（默认 -16 LUFS）|
| `brand` | `{name, official_site, qq_group}`，供 `site_bar` 用 |

## 依赖

| 依赖 | 用途 | 要求 |
|---|---|---|
| Chrome | headless 截图 / CDP 录制 | `--headless=new`，走 `chrome_path` |
| ffmpeg | 拼接 / 烧录字幕 | 必须带 libass |
| Node | 录制器 `rec_anim.js` | ≥21（内置 WebSocket/fetch）|

## 脚本

| 脚本 | 职责 |
|---|---|
| `sv_pipeline.py` | 整套入口（文案→配音→配图→拼接→字幕→清单），支持 `--spec` / `--preset` / `--script` |
| `sv_media.py` | 拼接、按音频时长排字幕、校验、烧录 |
| `sv_layout.py` | **项目存储格式 + 交付清单的唯一执行点** |
| `slides.py` | 配图风格基座（CSS）+ 13 种版式 + `render()` |
| `slide_spec.py` | `segments.json` 规格：13 种版式注册表 + 配图/分段对应校验 |
| `gpu.py` | 显卡检测 + `brand` / `official_site_url` |
| `rec_anim.js` | CDP 录制器（零依赖）|
| `sv_compliance.py` | 合规预检判定表（文案 + 发布标题）|
| `sv_title.py` | 发布标题生成，落 `发布文案.md` / `titles.json` |

参数见各脚本 `--help`；`--dry-run` 只打印将执行的命令。

## 配套技能

| 环节 | 技能 |
|---|---|
| 口播文案 | `fxai-voiceover-script` |
| 配音 | `fxai-voiceover` |
| 生图（media / cover_image / showcase）| `fxai-comfyui-image-gen` |
| 字幕对齐 | `fxai-lyric-subtitle` |

## 落盘三条（SKILL.md 铁律 11 的判据）

    - 🔴 **`--spec` / `--script` 传啥都行**（绝对路径、相对 cwd、甚至落在工作区根）：流水线**启动即把它们拷进项目目录**，项目始终是单一事实源——换文件夹 / 换 cwd 都不会散。勿在项目外另存一份规格单再手工维护。
    - 🔴 **运行日志一律写进项目 `_tmp/`**，绝不落到工作区根；调用方勿把日志再 tee 到根目录。
    - 🔴 **`--export` 目标必须是「独立交付目录」**，不得是工作区根或项目目录本身（否则副本又散回根，技能会直接报错拦截）。项目根只保留 `成片_<W>x<H>.mp4`，交付副本只在真正往外交付时 `--export <交付目录>`。
