# 03 · 动画与录制

> **何时读**：做页内动效、开录制、调滚动时。只出静态配图的话不用读。

## 动画库（`segments.json` 每段 `anim` 字段）

| 取值 | 含义 |
|---|---|
| `true` / 不写 | 默认「分层弹入」|
| `false` / `"none"` | 静态（不生成帧序列，用于封面首帧）|
| `"<动画名>"` | 从下表点名 |

| 动画名 | 效果 |
|---|---|
| **分层弹入** | 元素自上而下依次上移淡入（默认）|
| **逐条错峰** | 同分层弹入，间隔拉大 1.5 倍，一条一条出 |
| **整体淡入** | 整页一起淡入，干净克制 |
| **缩放弹入** | 元素由小放大（0.8→1）|
| **上滑入** | 元素从下方大幅上滑 |
| **左滑入** / **右滑入** | 元素从左右两侧滑入 |
| **下落弹入** | 元素自上方落下 |
| **模糊聚焦** | 元素由模糊变清晰 |

动画名清单见 `slides.py` 的 `ANIMS`；作用范围为暗色动效版式。

## 两种引擎

| | **逐帧定格（`--anim`）** | **实时录制（`--anim --rec`）** |
|---|---|---|
| 适用 | 静态版式、简单弹入 | 序列揭示、交互演示、长页面滚动 |

🔴 要「一条一条出现」的效果（`steps` / `chat` 气泡 / `.seq`）必须走 `--rec`；逐帧定格下 `.seq` 无序列效果。

- 动画 CSS 一律写 **longhand**（`animation-name/-duration/-timing-function/-fill-mode` 分开写）。
- 排障时可设 `FXAI_VIDEO_ENCODER=libx264` 强制 CPU 编码；显卡平时自动检测、失败自动回落。

## 页面动效设计规范（★ 设计页面时必读）

### 0. 理念

- **页面内元素的动效才是主体**，整页淡入/淡出只是很小一部分。
- **按这段实际在讲什么**安排动效：讲流程一步步点亮、讲对比左右分别滑入、讲数字跳出+脉冲、讲结论先铺陈再高亮扫过。
- **顺序本身就是信息**；同一套模板不同段落换不同动效组合。
- 设计三问：① 谁是主角谁是配角？② 视线按什么顺序移动？③ 哪个词/数字最该被记住？

### 1. 动效优先级

| 层级 | 动什么 | 举例 |
|---|---|---|
| ① 主体内容 | 标题、要点、卡片、数字 | 逐个上浮 / 左滑入场 |
| ② 顺序关系 | 有先后逻辑的元素 | 「等上一个播完再下一个」（§2）|
| ③ 强调 | 关键词、价格、结果数字 | 高亮扫过、脉冲、下划线生长 |
| ④ 氛围 | 背景光、装饰点 | 呼吸、缓慢漂移（低频）|

一段 3~4s 放 **2~4 个动作**；超过 6 个会乱。

### 2. 「上一个播完再下一个」两种实现

**A. `--d` 步进法（两种引擎通用，首选）**：后一个 `--d` ≥ 前一个 `--d` + 单条动画时长。

```css
.mk-title{--d:0s}
.mk-sub  {--d:.5s}
.mk-chips{--d:1.0s}
```

**B. `seq` 序列揭示（仅录制引擎）**：元素加 `class="seq"` + `data-seq="1/2/3"`，
**等前一个播完再放下一个**；`data-fx` 指定出场方式。

```html
<div class="seq" data-seq="1" data-fx="left">第一步</div>
<div class="seq" data-seq="2" data-fx="pop">第二步</div>
```

- 节奏可调（写在 `<body>` 上）：`data-seq-step` / `data-seq-gap` / `data-seq-wait` / `data-seq-delay`。
- 不录制（静态/逐帧）时不注入 JS，`.seq` 保持可见。
- 🔴 **CSS 里不得写裸 `.seq{opacity:0;animation-name:…}` 兜底**：静态出图会截在动画第 0 帧，
  `steps` / `chat` 气泡 / `pricing` 卡整行透明。要兜底只能写成 `html:not(.js-seq) .seq{opacity:1;animation:none}`
  —— 录制时 `SEQ_JS` 给 `<html>` 加 `.js-seq`，这条自动失效，交给 `.seq.on` 逐条播。
  （横版 `LANDSCAPE_CSS` 曾踩过这个坑，2026-10-27 修。）

### 3. 动效库（`fx-*`，默认即最终态，仅录制时从 0 播）

| 类名 | 效果 | 用途 |
|---|---|---|
| `.fx-pulse` | 强调脉冲（放大→回弹 ×2）| 数字、价格 |
| `.fx-breath` | 呼吸（明暗循环）| 背景光、装饰 |
| `.fx-spin` | 旋转入场 | 徽章、图标 |
| `.fx-sweep` | 高亮扫过（底色从左扫到满）| 行内关键词，配 `.seq` |
| `.fx-underline` | 下划线生长 | 标题关键词 |
| `.fx-flash` | 内容刷新（淡入上移）| JS 改写文本时 |

### 4. 选型速查

| 想表达 | 用什么 |
|---|---|
| 内容一条条出来 | `--d` 步进（0.5s）或 `.seq` |
| 强调某个词/数字 | `.fx-sweep` / `.fx-pulse` |
| 标题"落笔"感 | `.fx-underline` |
| 数字跳动 / 面板刷新 | `.fx-flash` |
| 图片入场 | `.mk-media` + 默认入场（`--d` 靠后）|
| 真的"点一下" | `--js` 交互脚本 |

### 5. `marketing` 内置序列步骤条 `fields.steps`

每行自动 `class="seq"`，录制时**等上一行播完再下一行**；静态出图时多行同时可见。

```json
{ "template": "marketing", "anim": true,
  "fields": { "chapter": "三步出片", "badge": "序列步骤",
              "title": "三步<span class=\"hl\">出片</span>",
              "steps": [["01","选模板","挑版式改字就出片"],
                        ["02","写文案","写多长都行"],
                        ["03","一键合成","配图 · 配音 · 字幕 · 烧录全自动"]] } }
```

每项 `[编号, 标题, 说明]`（说明可省）；编号底色自动循环橙/绿/蓝/粉/紫。该段必须走录制（`--rec`）。

### 6. 两阶段解耦：页面设计 / 录制滚动 各自独立

🔴 **页面设计阶段只管按视频实际宽高排好：宽度锁死，高度可超出，页面侧不写滚动代码。**
滚动判断由录制阶段负责。

- 滚动时：`absolute` / 常规流内容**跟着滚**；`position:fixed` 装饰（品牌条 / 满屏底图）**不动**。
- 要滚的内容用 `absolute` / 常规流，`position:fixed` 只用于视口锚定的装饰。
- 滚动时长以该段音频时长为准（页面更长滚到哪算哪，页面更短自动放慢滚完）。

| 入口 | 默认 | 适用 |
|---|---|---|
| `record_anim(name, html, out_dir, scroll=..., audio_dur=...)` | `scroll="auto"` | 自己的页面 |
| `record_url(url, name, out_dir, ...)` | **`scroll="none"`** | 别人的网页 / 线上站，只录首屏 |
| `screenshot_url(url, out_path, ...)` | 真截图 → `.png` | 只想截图 |

录别人的网站默认只录首屏；要明确做滚动演示才显式打开 `scroll`。
