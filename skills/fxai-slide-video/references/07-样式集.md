# 07 · 样式集（配色体系）

> 什么时候读这册：**换配色 / 换风格、新增一套样式、查变量含义**时读。只做默认样式不用读。

## 结构：骨架固定，样式外置

- 骨架（类名/ID：`.mk-*` `.ot-*` `.st-*` `.ch-*` `.pr-*`）**固定在基座 CSS 里，不随样式变**。
- 基座只写 `var(--xxx)` 占位，**不写任何硬编码色**。
- **一套样式 = 一个 CSS 文件**，放 `themes/<样式名>.css`；用哪套就加载哪个文件。
- 主题文件内容 = `:root{变量表}` + 可选附加样式（附加样式优先级最高，可覆盖圆角/阴影/字号）。
- 新增样式不用改代码，往 `themes/` 加一个 `.css` 即可被 `--theme` 调用。

## 三种选样式方式（优先级从高到低）

| 方式 | 用法 |
|---|---|
| 命令行 | `python sv_pipeline.py --project X --spec segments.json --theme 樱花粉` |
| 自定义文件 | `--theme-file <任意路径>/我的样式.css`（路径可以是任意位置） |
| 规格单内 | `segments.json` 顶层写 `"theme": "樱花粉"`（与 `segments` 同级） |
| 脚本内 | `slides.set_theme("樱花粉")` 或 `slides.set_theme(path="x.css")` |

命令行 > 规格单 > 默认（`深夜蓝金`）。查可用样式名：`slides.list_themes()`。

## 铁律

1. 🔴 **RGB 三元组必须与对应 hex 同步**：`--acrgb` 由 `--ac` 转换（`#ffb020` → `255,176,32`），改 `--ac` 必须同步改 `--acrgb`。
2. 🔴 **深色样式与浅色样式的变量语义是反的**：深色样式 `--panel`/`--card` 取深色、`--ink` 取浅色；浅色样式反过来。照抄深色主题去改浅色会全糊。
3. 🔴 **浅色样式必须把 `--chiprgb` 设为深色**（如 `22,35,59`）：胶囊底是 `rgba(var(--chiprgb),.05)`，设成白色在白底上等于没有。
4. 🔴 **主题里只改变量和附加样式**：骨架类名由基座固定，动类名会破坏动画与序列揭示（`--d`/`--step` 由基座控制）。
5. 🔴 **新增样式后跑一次样张验证**：`slides.set_theme(名)` → 渲染 marketing 封面 + stats 数据页各一张，确认无元素透明或糊成一团。
