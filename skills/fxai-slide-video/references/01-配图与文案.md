# 01 · 配图与文案

> **何时读**：做配图、写/分段文案时。定版式、写 `fields`、切段文案都看这册。

## 版式（`slides.py` 内置，`segments.json` 可点名 13 种）

| 版式 | 用途 |
|---|---|
| 步骤逐步展开 `steps` | 讲「第几步」：安装、操作流程 |
| 清单逐项点亮 `list` | 讲「要准备什么」：素材、清单 |
| 并排对比 `compare` | 二选一 / 三选一 |
| 要点罗列 `points` | 规则、注意事项、卖点 |
| 命令卡 `code` | 命令、日志、路径 |
| 引述卡 `quote` | 对话摘句 |
| 生图主视觉 `showcase` | 商品 / 真人图做主视觉（见下）|
| 营销花字 `marketing` | 爆款图文口播：深色底 + 大花字 + 胶囊 + 图标流程 |
| 穿搭展示 `outfit` | 人物图满屏 + 底部暗卡列单品（穿搭 / 种草）|
| 商品展示 `product` | 商品图完整不裁切 + 底部暗卡列规格（食品 / 实物）|
| 数据战绩 `stats` | 大数字 + 涨跌柱图 + 数据行，讲「结果」|
| 聊天对话 `chat` | 仿 IM 气泡逐条弹出，讲「反馈 / 咨询」|
| 三档套餐 `pricing` | 并排价格卡高亮一档，讲「报价 / 方案」|
| **上中下分栏** `frame`（旧名栏目图文）| **竖屏 9:16 专用**：固定节目壳（上下黑带全片不动）+ 中区一条全宽 16:9 的素材带；一段内可给多张做轮播（推移/上下切换），图/视频/海报混排；中区还能跑一整页网页（文字卡/长图滚动/真网页，见 02-模板库 2.61）（栏目化连载、静态背景板式）|
| 二分栏 `thirds` | 文字占一区、媒体占一区、背景铺满；横屏是「左右二分栏」、竖屏是「上下二分栏」；文字随段变，**没有固定壳**（旁白+素材混排、岗位盘点、案例复盘）。字段与背景底见 `../fxai-mixed-layout/references/03-二分栏版式.md` |
| **左中右分栏** `trio` | 和上中下分栏同一族壳：左栏竖排标题 + **中槽** + 右栏竖排品牌落款。**槽形只看槽里素材的方向**：竖素材 = 满高贴边竖条（顶天立地、上下零边距、`fit:"height"`）；横素材 = **16:9 横带居中**（`fit:"cover"`，上下留白）。**横屏画布上放竖素材也走满高竖条**（1366×768 下槽 432×768、两翼各 466）—— 分辨率不变，只是竖素材按画布高度缩。适合竖素材 / 人像占满高度，也适合横素材做「文字左右」那版 |
| **自动** `auto` | 按第一个素材的构图方向挑布局：竖素材 → `trio`、横素材 → `frame`（读不到按 `frame` 兜底）。想指定就写死 `trio` / `frame` |

各版式 `fields` 写法 → **`02-模板库.md`**；换页与语速参数 → **`03-动画与录制.md`**。

## 文案规则

- 🔴 **叙事范式（怎么写厚、怎么开好头）→ `fxai-voiceover-script/references/03-叙事范式.md`**：文案不限时长、厚度来自段数、
  开篇三不（相邻段首不重复关键词 / 不抛抽象结论 / 首段钩子带数字不提问、不套模板句式）、13 拍叙事弧、口语细则。
- 一段 = 一张配图 = 一条音频，一一对应。
- 文案写多长都行、拆多少段都行。
- 用口语。
- 定稿即查：写完 `segments.json` 跑 `python sv_compliance.py <spec>`（管线已内置同款预检）。→ `06-投稿规则.md`
- 定稿同批定发布标题：模型直接给一条主推 + 3 条备选（打法互不相同），
  `python sv_title.py <spec> --main "<主推>" --alts "a|b|c"` 只做校验与落盘。→ `06-投稿规则.md`

### 注入真人经验（每篇 ≥2 段，其中 ≥1 段带主观感受）

第一人称亲历句式：`我们 + 具体动作 + 结果数字或故障 + 当时什么感受`。
配图 `fields` 同步出现同名数字 / 名词。

| 写成 | 不写成 |
|---|---|
| 「我们自己跑了 30 集，卡在第 3 集的参数上」 | 「这套可以批量出片」 |
| 「一集从 4 小时压到 11 分钟，跑完那一刻是真解脱」 | 「一集从 4 小时压到 11 分钟」 |
| 「四道坎里最抓狂的是修报错」 | 「四道坎：装环境、调参数、修报错」 |

- 感受词：抓狂 / 崩溃 / 踩过坑 / 没想到 / 后悔 / 真香 / 解脱 / 踏实 / 翻车 / 白折腾。
  只列事实不讲感受，读者读不出「真人用过」——外部反馈里最常缺的就是这一项。
- 位置：至少一段落在中后段，别全堆在开头。
- 能力罗列句一律改写为「卡在哪一步 + 后来怎么过的」。

### 埋互动锚（≥2 处，其中 ≥1 处面向群体）

🔴 **规则与写法全在公共层 `fxai-voiceover-script/references/05-结尾与引导.md`**，本册不另存：

- 结尾段 = `真实问句 + 关注动作`，提问在前、引导在后，别让「点个关注」把提问挤没。
- 🔴 引导取**当页就能完成的动作**：关注 / 收藏 / 点赞；教程内容留在本条作品里。
- 正片中后段一次面向群体的开放式提问（大家 / 各位 / 你们）。
- 画面与文案不出现联系方式、领取口令与私信引导话术（→ `06-投稿规则.md`）。

### 定发布标签

文案定稿时同步选定六类必选标签之一，写进 `交付清单.md` 发布栏：
含有 AI 生成内容 / 含有营销信息 / 内容为个人观点 / 含有虚构演绎内容 / 内容为转载 / 无需标注。

## 画面

- 一律复用 `slides.CSS`（浅色版式）或 `slides.MARKETING_CSS`（深色版式）。
- 步骤类配图做成**逐步展开**：已完成打勾、当前步高亮、后续置灰。
- 配图底部留够烧录字幕区。
- 渲染后抽查若干张，确认无裁切。

## 逐步推进的写法

同一模板换「当前第几步」，连续播放即成逐步推进：

```python
from slides import steps_slide, render_many

STEPS = [("下载安装 WorkBuddy", "免费的，官网就能下"),
         ("解压技能包", "一堆 fxai 开头的文件夹"),
         ("复制到技能目录", "连文件夹整个复制"),
         ("重启 / 刷新 WorkBuddy", "左边能看到技能就装好了")]

render_many({f"S{3+i:02d}_安装第{i}步": steps_slide(STEPS, i) for i in range(1, 5)},
            out_dir="配图")
```

## 生图 / 照片做主视觉（`showcase` 模板）

商品图、真人照片等**必须用真实生图或照片做主角**时，用 `showcase` 模板。

🔴 **图满屏裸露、主体通透，文字集中放进底部一张紧凑暗卡**，上 2/3 的主体完全通透，
底部留给烧录字幕。

## 页内点缀图（`media`）与封面图（`cover_image`）

用生图工具（`fxai-comfyui-image-gen`）出**横构图配图**（如 768×512），
某段 `fields.media=<图绝对路径>` 即可嵌入；封面图片型模式同理用 `cover_image`。

🔴 生图时**直接引用自有角色底图（role=woman/man/both）必须写【穿搭/服装】+【头型/发型】**，
否则 `check_outfit()` 报错。纯场景（`role=None`）与二次生成免检。

## 引导条 `site_bar`

🔴 **视频是展示/引导，链接不可点**；site_bar 只**显示**官网 + QQ群 + 下载提示，
**只提示「网盘获取安装包」，不暴露具体网盘链接**。默认不显示，仅 `fields.site_bar` 显式为真时出现。

| 场景 | 是否开 |
|---|---|
| 教程视频 | 整段都开 |
| 数字人 / 短剧成片 | 结尾段开 |
| 穿搭 / 商品展示 | 不开 |
| 营销快剪 | 不开 |

## 文案与叙事铁律（SKILL.md 铁律 6–9 的判据）

6. 🔴 **每篇文案 ≥2 段第一人称亲历**（`我们 + 动作 + 数字或故障 + 主观感受`，至少一段在中后段），
   互动锚 ≥2 处且含一次面向群体的邀请，结尾「提问 + 关注动作」。→ `01-配图与文案.md`
   🔴 结尾引导取**当页完成的关注 / 收藏 / 点赞** → `fxai-voiceover-script/references/05-结尾与引导.md`
7. 🔴 **动笔前先读 `fxai-voiceover-script` 的 03/04/05 三册，出「叙事拍子规划表」**：13 拍逐拍落位、热点词与中文数字读法定稿后再写 `segments.json`。
8. 🔴 **口播 `text` 里的数字写中文读法**（两点 / 四小时 / 百分之三十）；配图 `fields` 视觉文案照旧写阿拉伯数字。
9. 🔴 **选题锚定一个当下热门的技术词或工具名**，首帧封面上直接点名它；开篇一律共同经历式叙事（述事 → 当时都这么干 → 翻转），不提问。
