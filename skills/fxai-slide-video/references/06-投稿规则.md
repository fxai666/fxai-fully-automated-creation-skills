# 06 · 投稿规则

> **何时读**：写稿阶段就启用。`segments.json` 写完立刻跑合规预检，不等渲染、不等发布。
> 文案里的经验与互动锚写法见 `01-配图与文案.md`，配图画法同样在那册。

## 检查点：文案定稿即查

> ⚠️ **合规 0 WARN ≠ 文案写好了**：预检只卡硬指标（亲历 / 互动 / 钩子 / 违禁词）；
> 厚度、具象、叙事弧拍子覆盖由人对照 `fxai-voiceover-script/references/03-叙事范式.md` 逐拍核对。

```bash
python sv_compliance.py <segments.json> [--mode public|private]   # 单查文案
python sv_compliance.py <segments.json> --titles titles.json      # 文案 + 标题一起查
python sv_pipeline.py --project <名> --spec <segments.json>       # 管线自带：先出标题，再打印报告
```

| 档 | 内容 | 处置 |
|---|---|---|
| ERROR | 联系方式露出、私信引导话术、公网版开 `site_bar`、还没产出发布标题 | 改完或补跑 `sv_title.py` 再往下；`--strict` 直接中断 |
| WARN | 违禁词命中、亲历 <2 段、亲历段缺主观感受、亲历只在前半段、互动锚 <2 处、缺群体邀请、结尾缺提问或关注动作、引导跳转主页、开篇套路化（夜半熬夜 / 反问逼问 / 灾难夸张）、主推标题 >22 字、备选 <3 条 | 逐条人工确认，误伤项保留即可 |
| INFO | 六类必选发布标签待选定、话题标签待补 | 写进 `交付清单.md` 发布栏 |

退出码：0 = 无 ERROR，1 = 存在 ERROR，可接门禁。
`--mode public` 为默认（按抖音 / 视频号 / 小红书 / 快手尺度）；出私域版传 `--mode private`。

### WARN 怎么判

| 命中位置 | 判定 |
|---|---|
| 描述第三方产品或客观评测（如「能力顶尖」指的是 ComfyUI） | 保留，不改 |
| 描述自家产品 / 服务、承诺效果或销量 | 按 `01-配图与文案.md` 的能力罗列句改写为亲历句 |
| 章节胶囊、版式提示词等非宣传位 | 保留，不改 |

## 平台尺度（选 mode 用）

| 平台 | 画面留联系方式 | 私信引导话术 | 合规承接方式 |
|---|---|---|---|
| 抖音 / 快手 | 不允许 | 不允许 | 关注 / 收藏（当页动作）、粉丝群、企业号留资组件、小店 |
| 小红书 | 不允许 | 不允许，个人号禁用主动导流 | 关注 / 收藏（当页动作）；企业号用聚光社媒名片 / 线索表单 |
| 视频号 | 仅账号简介，且用商务合作邮箱 | 变通，需挂官方组件 | 企微客服、粉丝群、服务号、小店 |
| B站 | 允许保留 | 允许 | 勾「AI 生成」标注 |
| 自有阵地（官网 / 社群 / 公众号 / 私聊） | 允许，保留完整引导条 | 允许 | 直链不限 |

🔴 **公域平台按「把用户从站内引出去」判违规，不只查联系方式**。
`私信我获取` / `私信我拿一份` / `如有需要可私信获取` / `如您需要私信获取` / `主页有惊喜` 一律命中，
委婉前缀与谐音变体同样拦不住。判定为「引流出站内」，处罚是限流、内容下架、私信功能封禁、扣违约金，
同主体关联账号连带处置。`sv_compliance.py` 公域模式已按此判 ERROR。

### 「给人一套资料」的承接

把教程内容**留在本条作品里**，结尾写互动提问 + 关注动作：

| 取 | 替 |
|---|---|
| 关注动作（关注 / 收藏 / 点赞） | 如有需要可私信获取 / 私信我拿安装包 / 主页有惊喜，懂的都懂 |

🔴 **引导取当页就能完成的动作**：关注 / 收藏 / 点赞。
🔴 **话术与用词只认一处**：`fxai-voiceover-script/references/05-结尾与引导.md`。
本册不复写话术、不复制用词表——复写即分叉，改一处漏一处（已实测回滚过一次旧版）。
🔴 **期数按实际进度给**，不写固定期数。

同稿两版：复制一份 `segments.json`，删结尾段 `fields.site_bar`、CTA 改为纯关注动作，跑出「公域版」；保留引导条的原版作「私域版」。

## 六类必选标签

发布端必选其一：含有 AI 生成内容 / 含有营销信息 / 内容为个人观点 / 含有虚构演绎内容 / 内容为转载 / 无需标注。
AI 配音或 AI 绘制画面选「含有 AI 生成内容」。

## 标题随稿产出

`segments.json` 定稿的同一拍产出发布标题，落 `发布文案.md`（人读）+ `titles.json`（机器读），
并写进 `交付清单.md` 的「发布信息」栏。

| 环节 | 谁做 |
|---|---|
| 标题内容 | 写稿的模型直接给：一条主推 + 3 条备选，四条打法互不相同 |
| 校验与落盘 | `sv_title.py`：字数、联系方式、违禁词、写盘、进清单 |
| 兜底 | 没给 `--main` 时，脚本按画面大字 + 模板自动抽取 |

```bash
python sv_title.py <segments.json> --main "<主推>" --alts "a|b|c"   # 常规：模型给，脚本查
python sv_title.py <segments.json> --force                          # 兜底：脚本自己抽
```

备选按打法分组：数字对比 / 极短痛点 / 提问钩子 / 清单式，四条路线互不相同 ——
数据不好时换的是打法，不是换同义词。

| 约束 | 值 |
|---|---|
| 主标题 | 一条通用，全平台同用，不按平台各写一条 |
| 字数 | 去空白后 ≤22 字 |
| 必备 | 主题词 + 一个数字或痛点 |
| 备选 | ≥1 条，数据不好时可换 |
| 取词范围 | 只取正文与 `fields` 内容位；`brand` / `chapter` / `badge` / `hint` / `foot` 不参与 |

### 兜底路径（`--main` 缺席时）

素材自动抽取：主题词取首段标题里的首个术语词，旧做法动词取 `手搓/手写/手动…`，
新做法词按 `智能体/技能包/自动化…` 词频取最高，工时对比取第一句含两组「数字+单位」的口播句。

候选两路一起评分取最高：一路是**画面大字**（各段 `fields.title` 按 `<br>` 折行拼成一句，与画面说的是同一句），
一路是模板生成（主题词 + 旧做法词 + 工时对比 + 新做法词）。
评分权重：主题词 15 > 数字 15 > 两组数字对比 10 > 新做法词 8 > 旧做法词 6 > 主题词开头 5 > 提问 5。

## 封面与话题标签

- 封面 ≤3 行文字，高对比配色，与首帧强相关。
- 话题标签 2–4 个：2 个垂直赛道 + 1 个泛赛道，不堆无关大热门。

## 发布节奏

- 时段：早 7:00–9:00、午 12:00–14:00、晚 19:00–22:00，以创作者后台粉丝活跃时段为准。
- 频率：固定日更 1 条，起号期可 2 条，不断更。
- 画质：1080P 起、画面无水印、收音干净、字幕完整、重点词标色。

## 发布后 2 小时

- 逐条回复评论区留言。
- 数据不达标的处理顺序：曝光低改标题胶囊与标签 → 完播低改前 3 秒钩子 → 互动低补结尾引导再发，不删稿重发。
