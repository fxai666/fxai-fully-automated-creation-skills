# 04 · 字幕与合成

> **何时读**：字幕、拼接、响度、烧录环节出问题要排查时。

这几个环节全部由 `sv_media.py` 按代码默认值执行，参数无需人工干预。排查时按执行点定位：

| 环节 | 执行点 | 约束 |
|---|---|---|
| 字幕时间轴 | `speech_subtitles()` | 时间取 Whisper 实际语音起止，文字取正文 |
| 落盘前校验 | `check_subtitles()` | 时长 / 字数 / 时序全部通过才落盘 |
| 拼接 | `concat()` | 片段先统一规格，时长严格等于该段音频 |
| 响度归一化 | voice_gen + `make_part` | 逐段拉齐 -16 LUFS（全局 `audio_loudness` 可调）|
| **背景配乐 BGM** | `mix_bgm()`（管线 `--bgm <文件> [--bgm-volume 0.20]`） | **生成 + 混音口径见下节** |
| 烧录 | `burn()` | ffmpeg 必须带 libass |

- 方言 / 重口音匹配率不足时自动兜底：按该段音频时长按字数均分，文字仍取正文。

## BGM 环节（背景配乐）

**何时做**：成片想要氛围配乐时。缺省不混 BGM 不算错，但口播片有 BGM 垫底听感完整。

### 0. 🔴 顺序：BGM 是**最后一道工序**，排在铺封面之后

整条链路固定为：

```
文案 → 配音 → 配图 → 拼接 → 字幕烧录 → 铺首帧封面 → 混 BGM → 出片
```

**为什么必须这个顺序**：

- 铺封面时封面段自带的是**垫音**（25Hz 正弦，−73dB 级），不是配乐；封面段沿用垫音，配乐只由混 BGM 一道铺。
- 但封面段这 0.4s 若只有垫音，整条音轨的**第 0 帧就是准静音**，平台可能把开头当空白裁掉，
  音画基准就错位了。
- 把 BGM 放到最后一道、**作用于已铺封面的整片**，`mix_bgm` 本来就 `atrim` 铺满整片、
  `-c:v copy` 只重编码音频 —— 于是**配乐从封面第一帧起就响着，一直铺到片尾**。
  反过来「先混 BGM 再铺封面」，封面段会被替换成垫音，开头就缺一截配乐。

**执行点**：`sv_media.py --cover <封面PNG>` / `sv_pipeline.py --cover <封面PNG>`，
管线内部顺序已固定，不需要手动分两次跑。帧数、垫音、接缝口径全在
`fxai-poster/references/04-接入视频首帧.md`，本册不复写。

### 1. 配乐从哪来：`--bgm auto` 让音乐生成器现场出一首（默认推荐）

`--bgm auto` 不给文件，由 `sv_bgm.py` 调公共件 `fxai-workflow` 的 ComfyUI 接口现生成一首：
占位符工作流 → `/prompt` → 轮询 `/fxai/tasks/result` 拿 url 令牌 → `/fxai/down/file` 下载到
`<项目>/配乐/bgm_<时间戳>.wav`。**产物只走接口令牌取，不读 ComfyUI 本地 output 目录**
（服务端可能不在本机，与生图/生乐技能取路径方式一致）。

- 默认模型 `minimax3`（`music-minimax3-api.json`），`--bgm-model yue2` 可换（更慢）。
- 请求时长 = **成片时长 + 2s**（上限 300s）；模型可提前收尾，短了由混音端 loop 补足。
- ComfyUI 没起 / 模型没装会直接报错并给三条处置，不会静默出无声片。

#### 人声：默认纯器乐，按内容也可以带唱（两档，不做统一规定）

**带不带人声由内容定，不是硬规格**。纯器乐靠提示词保证，不需要额外检测工序。

| 档 | 用法 | 提示词怎么落 |
|---|---|---|
| **纯器乐**（默认） | `--bgm auto` 即可；`--bgm-vocal none` 是显式写法 | 内置 caption 的 **Vocal Details 明写「纯器乐、全程无人声演唱，无和声、无呼吸/念白」**，lyrics 给 `[Instrumental]`。给了 `--bgm-style` 也会自动补这句（不补 M3 会漂出唱） |
| **带唱** | `--bgm-vocal "轻柔女声轻唱，气声，人声靠后"` + 歌词 | Vocal Details 换成这句人声描述，lyrics 换成给的歌词。**必须给歌词**：`--bgm-lyrics "…"` 或 `--bgm-lyrics-file 配乐/歌词.txt`（可写 `[Verse]` / `[Chorus]` 标记） |

- **只给歌词、没写人声描述**也算带唱：自动用默认描述「轻柔人声轻唱，气声，人声靠后，不抢正面口播」，
  不静默忽略歌词。
- 写了人声描述却没给歌词 → **直接报错中断**，不静默退化成器乐（有词的唱才有意义）。
- 人声描述写清**音色 + 唱法 + 位置**三样（如「低音男声轻唱，民谣，靠后不抢」）。
- **不做「人声转写抽检」的固定工序**：纯器乐只靠提示词指定就够了（实测提示词写了就干净，
  转写只会出「字幕志愿者」这类幻觉词）。要查的只有带唱版唱对没唱对，想听再听、想查再查。
- 交付清单 `bgm` 字段带「带唱」字样，便于事后区分两档。


### 2. 也可以给现成文件

`--bgm 配乐/<名>.wav`（自有音乐须记录授权，走 `fxai-standard` 06 字体与素材授权）。
相对路径先按当前目录找，找不到再按项目根找；文件不存在直接报错中断。

### 3. 混音口径（沿用 `fxai-ad-video/references/04-声音与节拍.md`）

- BGM 音量：**纯器乐 0.20**（约低于口播 14dB），**带唱 0.15**（有词会和口播抢注意力，垫更后）。
  不给 `--bgm-volume` 时按人声档自动取值，给了就以给的为准。口播片几乎句句相连，**整片一条直线**；
  留白特别多的片（段间停 1s 以上）才整体给到 `--bgm-volume 0.25~0.28`，不做逐段起伏——
  自动 ducking 会跟口播抢中频，听感反倒更糊。
- **口播 1.0 不降**（`amix normalize=0`，BGM 只垫不抢）。
- BGM **原样铺满整片**（含封面段），片尾自然收，**不得加 `afade`**；短于成片 loop 补足后 `atrim`。
- 混音后整片 loudnorm 回 **-16 LUFS / TP -1.5**（交付响度口径与无 BGM 版一致）。

### 4. 执行

```bash
# 全程一条命令：文案→配音→配图→拼接→字幕→铺封面→配乐→出片（顺序由管线保证）
python sv_pipeline.py --project <项目名> --spec segments.json --bgm auto
python sv_pipeline.py --project <项目名> --spec segments.json --bgm auto --bgm-style "温暖钢琴，慢速"

# 带封面 + 带配乐：一条命令，配乐从封面第一帧铺满整片
python sv_pipeline.py --project <项目名> --spec segments.json --bgm auto \
    --cover 封面/封面_主推.png
python sv_pipeline.py --project <项目名> --spec segments.json --bgm 配乐/自有曲.wav --bgm-volume 0.22

# 按内容要带唱（歌词可放文件，长一点更好维护）
python sv_pipeline.py --project <项目名> --spec segments.json --bgm auto \
    --bgm-vocal "轻柔女声轻唱，气声，靠后" --bgm-lyrics-file 配乐/歌词.txt
# 只给歌词不写人声描述也行，自动用默认「气声轻唱、靠后」
python sv_pipeline.py --project <项目名> --spec segments.json --bgm auto --bgm-lyrics-file 配乐/歌词.txt

# 已经出了片、后补封面：封面和配乐一起补，顺序同样由脚本保证
python sv_media.py --project <项目名> --bgm auto --cover 封面/封面_主推.png
# 只想单独出一首配乐试听（纯器乐 / 带唱）
python sv_bgm.py --out-dir 配乐 --duration 60
python sv_bgm.py --out-dir 配乐 --duration 60 --vocal "低音男声轻唱" --lyrics "…"
```

带封面时成片名是 `成片_<W>x<H>_带封面.mp4`；不带封面仍是 `成片_<W>x<H>.mp4`。

### 5. 交付

成片带 BGM 与不带 BGM 均为合法交付物。交付清单 `bgm` 字段标
`含背景配乐（自动生成 bgm_xxx.wav，vol 0.20）` / `含背景配乐（自动生成 bgm_xxx.wav，带唱，vol 0.15）` /
`文件名（vol 0.20）` / `无配乐`（`delivery.json` 与 `交付清单.md` 同源）。

`配乐/` 是 BGM 素材目录（一片可能留多版试听），不进交付清单「目录一览」——
`sv_layout` 只登记 `配图/`、`音频/`、`_tmp/`。有没有配乐、用的哪首，一律以清单 `bgm` 字段为准。
同一项目重复跑 `--bgm auto` 会**再生成一首新文件**（不覆盖旧的），要复用就显式给 `--bgm 配乐/<旧文件>`。

产物落盘位置与项目目录结构 → **`05-配置与产物.md`**。
