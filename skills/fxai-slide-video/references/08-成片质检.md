# 08 · 成片质检（最终验收环节）

> **何时读**：成片合成后、交付前**必读**。整片、单段返修、改壳、改字号后都要重新走一遍质检，全绿才交付。

成片质检是 fxai-slide-video 的**最终验收环节**：合成出来的 `成片_<W>x<H>.mp4` 不只是「渲染成功」就完事，必须按下面的清单逐项过，发现问题记进质检报告并修复、复验、回环，才算交付合格。

## 执行入口（机械能查的交给程序）

```bash
python sv_check.py --project <项目名> --root <工作区>
```

`sv_check.py` 自动跑完清单里**能程序判定**的项（成片元数据 / 壳冻结 / 背景虚化 / slogan 单行 / 字幕位置 / 字幕条数与对齐率 / 素材登记 / 音轨与配乐），写 `质检报告.md` 到项目根，失败项自动追加问题记录。**人眼项**（画面观感、字体、发布标签）由执行人对照本册清单人工核，在报告里填结果。

## 质检清单（12 项，成片后逐项过）

| # | 检查项 | 判据（sv_check 自动 / 人工） | 失败处理 |
|---|---|---|---|
| 1 | 分辨率 / 时长 / 帧率 | 分辨率 = 画布档（`成片_<W>x<H>.mp4` 命名即档）；时长 ≈ 音频总时长 ±1s；帧率 24 | 重跑 sv_media，勿手改容器 |
| 2 | 壳全片冻结 | 首尾帧上下带区域帧差 < 阈值（壳一个字都不得动） | 检查是否误开了整帧淡入淡出（`--fade 0`） |
| 3 | 中区素材混搭 | delivery.json 配图数 = 段数；视频/图片/网页按 segments 登记垫入 | 查 segments `media` 与素材落盘 |
| 4 | 字幕位置 | 字幕底落在中区下沿内侧（1080×1920 → bottom≈637）；非默认画布必由 sv_media 重算 | 字幕掉下带 = 位置值透传了旧档，交 sv_media 重算 |
| 5 | 字幕内容 | whisper 对齐率 ≥95%、无错字、时间轴连续 | 重跑字幕对齐，勿手工改 SRT |
| 6 | 品牌区排版 | slogan 单行完整、无换行、无重叠 | 下栏 flex 挤爆 → 收 logo 字号 + slogan `white-space:nowrap` |
| 7 | 背景虚化 | 上下带亮度均值 > 阈值（纯黑≈11，透出虚化 ≥25） | 半透明带被不透明色盖住 → 上下带改 `rgba(11,11,12,.78)` |
| 8 | 花字 / 字幕不打架 | 两层位置分离（花字中区 0.44 处、字幕中区下沿 0.79 处） | 调 overlay_pos，勿往下压字幕 |
| 9 | 网页文字卡 | 内容完整、无乱码、字号可读 | 重录网页槽，勿塞超 5 条 |
| 10 | 合规预检 | sv_compliance 0 ERROR 0 WARN（pipeline 阶段已跑） | 改稿后重跑合规，再重渲 |
| 11 | 发布标签 | 交付清单标注「含有 AI 生成内容」等必选标签 | 补标注后刷新清单 |
| 12 | 音轨与配乐 | 有 aac 音轨；有配乐时清单 `bgm` 字段与成片一致；整片 mean −24~−12 dB；48kHz 为上传安全档（非 48k 只提示不判失败） | 重跑 `--bgm` 混音；缺音轨查合成主链是否误加 `-an` |

## 问题记录格式（发现的问题必须记下来）

每条问题按 P 编号追加到 `质检报告.md` 的「质检问题记录」，五个要素缺一不可：

```
### P<n> · 一句话问题（涉及层）
- **现象**：用户看到什么、抽帧看到什么
- **根因**：代码 / 参数 / 规格出处
- **修复**：改了哪个文件哪一处（技能侧修复对后续项目同样生效，须注明）
- **复验**：用什么方式确认修好了（抽帧 OCR / 像素统计 / 日志值）
```

## 返修回环（质检不过不许交付）

1. 质检发现问题 → 修复 → **重跑 `sv_check.py` 直到清单全绿**，同时复验上一条 P 记录已闭环。
2. 单段问题优先单段返修（`rework.splice_segment`），改壳 / 改字号 / 改品牌 → 重渲遮罩 + 重跑 sv_media + 重跑质检。
3. 质检报告随成片一起交付；用户要求回看质检时，读项目根 `质检报告.md`。

## 已沉淀的技能侧修复（后续项目直接受益）

- 字幕位置：非默认画布 preset 值置 None，交 sv_media 按中区槽位重算（P1）
- 背景虚化：frame 版式接通 bg_slot，上下带半透明透出虚化（P2）
- 品牌区：logo 字号 90px + slogan nowrap 保证单行；品牌 logo 文字 =「凤希AI」（P3/P5）
