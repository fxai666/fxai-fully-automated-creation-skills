# 调用参数速查

**何时读**：查怎么调 gen_char_view / gen_threeview、参数含义时

```python
import sys, os
sys.path.insert(0, os.path.join(SKILL_DIR, "..", "fxai-fourview-gen"))
from fourview_gen import gen_char_view, gen_threeview

# 四视图（有自有角色参考图 000）
p, rel = gen_char_view("黑色长直发，淡妆，穿红色描金齐胸襦裙", ref="avatar/000.png", views=4,
 tag="女主四视图", subdir="charview", num=0)

# 三视图（无参考人物，纯设定）
p, rel = gen_char_view("短发利落，深色职业装", views=3, tag="角色A", subdir="角色三视图")
# 等价别名：
p, rel = gen_threeview("短发利落，深色职业装", ref="", subdir="角色三视图")
```
- `prompt`：**只写人物自身**（发型 + 妆容 + 服装 + 配饰 + 足部）。**技术性构图由节点内置**（分栏/白底/8k/站姿）；**prompt 里只出现人物本身**，环境（地面/青石/水/雪/云雾/背景/室内外/天气/光线）一律不写——四视图只出人物本身，写环境会把地物画到人物脚下或身边。
  - 🔴 穿搭里凡是「踏在/站在某物上」之类的环境从句，整句去掉，只留人物自身（如「赤足」）——否则会把地物画到人物脚下。
- `ref`：人物参考图的【服务端相对路径】`<子目录>/<文件名>`（如 `avatar/000.png`）。格式、取值出口与提交被拒的定位判据见 `fxai-standard/references/10-资源引用路径规范.md`（全技能唯一真相源），本技能不重复。**我们自己的形象（女主/男主）一律用全局头像库路径 `avatar/000.png` / `avatar/001.png`**（即 `C.REF_WOMAN` / `C.REF_MAN`）。
 - **四视图（默认）：ref 可选**。给了 → 参考头像注入节点147「图片列表」，经节点210 `FxAiQwenFaceFeature` 人脸特征锚脸再出四视图；没给 → 节点147 传空图列表，纯按提示词出四视图。**两种都出四视图。**
 - 自有角色（000/001 这类我们自己的图）**必须传 ref**，靠参考图锁脸锁身段；不是自有角色的（客串/他人肖像/纯新角色）按提示词生成。
 - 🔴 **自有参考图直接引用 `avatar/000.png` 路径**，服务端本来就有这份；上传/另存/重传到别处会多出一份"另一张脸"，锚脸即错位。需要确认它存在时才查（`_list_files('avatar')`），本机目录扫不出结果。
 - 🔴 **参考图里的东西（眼镜/耳钉/手表/现代物）必须先在参考图里就没有，靠 prompt 挡不住**。四视图输出 = **左格「锚脸特写」+ 右三格（正/侧/背）**，左格是照参考图原样走的（黑框眼镜原样保留），右三格才按 prompt 生成。
   - 正确做法：先把参考图改干净（裁一张无镜/无现代物的版本，或用图像编辑擦掉）再重跑四视图；改完要重眼一遍**左格**有没有残留。
   - 改参考图时若它已在头像库（`avatar/xxx.png`），用 `C.upload_image(本地路径, subdir="avatar", filename="001.png", overwrite=True)` 原地覆盖，下游 ref 路径不用动。
- `views`：默认一律 `4`（四视图）；传 3 走三视图独立工作流，新项目不推荐。
- `subdir`：ComfyUI 端保存子目录（默认 `charview`，与场景图目录隔离）。
- `num`：固定文件序号（配合节点「启用文件名覆盖=True」实现同名覆盖，不堆积）。
- 返回 `(本地png路径, ComfyUI相对路径)`，相对路径供下游（MV Ref2VA / 短剧 manifest）使用。
