# 三视图空参考的运行时依赖与外部依赖

**何时读**：三视图报空图列表错、或换机器配依赖时

三视图工作流 `img-qwen21-threeview.json` 的节点 203（FxAiQwenImage21ThreeView）`图片列表` 接自节点 147（FxAiCharacterImageSelector）；三视图传空图列表（`fxai_imageinput=""`）时，依赖该自定义节点**能接受空图列表并纯文本生成**。若节点对空图列表报错，需改三视图工作流（或由 `gen_threeview` 传一张占位基底图）——属工作流层问题、非本技能代码问题。

## 外部依赖

- `fxai-workflow/comfy_client.py`（共享客户端：占位符提交 / 校验 / 广播等结果 / HTTP 下载）
- `fxai-workflow/img-qwen21-fourview.json`、`fxai-workflow/img-qwen21-threeview.json`（工作流，**去前缀 + 模型 token 命名**，内部 `fxai_` 占位符不变）
- ComfyUI 常驻在线（地址见 `~/.workbuddy/fxai_global.json` 的 `comfy_url`，默认 `http://127.0.0.1:8188`）
