# 01 · 登记规范

## 字段表

`素材登记.json` 每条素材固定这些键：

| 键 | 谁写 | 说明 |
|---|---|---|
| `id` | 脚本 | 按类型编号：`V`视频 / `G`图 / `A`音频 / `X`其他，三位序 |
| `文件` | 脚本 | 相对台账目录的路径，正斜杠 |
| `类型` | 脚本 | 视频 / 图 / 音频 / 其他 |
| `规格` | 脚本 | ffprobe 探的 `宽x高 · 时长`，探不到留空 |
| `大小` / `大小字节` | 脚本 | 人类可读 + 原始字节 |
| `日期` | 脚本 | 文件 mtime |
| `md5_1m` | 脚本 | 首 1MB 的 md5 前 10 位，只用来找重复拷贝 |
| `档` | 脚本初判 + 人改 | `精选` / `未评` / `过程` |
| `用途` | **人写** | 这是什么、什么规格、适合用在哪 |
| `标签` | **人写** | 2~4 个检索词，用 `/` 分隔 |
| `可复用` | **人写** | `true` / `false` / `null`（未判） |
| `来源` | **人写** | 自制 / 采集（附链接）/ 客户提供 / 生成 |
| `备注` | **人写** | 授权状态、画质问题、踩过的坑 |
| `missing` | 脚本 | 路径已不存在时置 true |

**脚本只写脚本那几列**。人写的四列脚本永不覆盖 —— 这是 `sync` 敢反复跑的前提。

## 三档怎么判

### 精选
「下一条片子还想用它」的才进精选。典型：

- 真实界面截图 / 录屏（网站操作、软件操作）
- 成片、样片、对比片
- 场景图、角色四视图、道具图、封面
- 通用 BGM、音效、配音样本
- 品牌横幅、片头片尾卡

### 过程
「是为这条片子临时切出来的」的进过程：

- 按段落切的分片（`p01.mp4` ~ `p15.mp4`、`片段_0-12秒.mp4`）
- 中间渲染（`burned.mp4`、`final.mp4`、`merged*.mp4`）
- 分段配音（`xxx01.wav` ~ `xxx24.wav`）
- 幻灯片成页图（`S01_封面.png`）
- 一次性推文配图（`fig1.png` ~ `fig8.png`、`cover.png`）

判错了不要紧，`sync` 不会覆盖你改回来的值，md 重渲染只是重新排版。

### 未评
扫进来还没人看过。`check` 会数出来，慢慢清。超过 100 条说明该花十分钟过一遍了。

## 用途怎么写

差：「图1」「素材A」「截图」
好：「镜像广场搜索框输入『凤希AI』· 5760 宽高清」

公式：**画面内容 + 关键识别信息 + 规格**。
如果是某条片子的固定开场，直接写「XX 片开场用」。

## 标签怎么打

2~4 个够了，取「以后会拿它去搜什么」的词。

- 平台 / 场景：`仙宫云` `ComfyUI` `镜像广场`
- 动作：`开实例` `搜索` `配置`
- 形态：`界面` `标注` `成片` `对比` `封面`

别打「重要」「好素材」这种无法检索的。

## 跨项目索引

```bash
python ~/.workbuddy/skills/fxai-asset-registry/scripts/registry.py index <项目空间根>
```

会遍历根下所有 `素材登记.json`，按更新时间倒序出表：项目 / 总数 / 视频 / 图 / 音频 / 可复用数。
找素材先跑这个，比 `ls` 快一个数量级。

## 常见问题

**Q：扫出来上千条，全是过程产物怎么办？**
先跑 `scan` 看清单，确认确实都是分片就放着不管 —— 它们在「过程产物」一节，只占 json 不占视线。

**Q：素材改了名 / 移了位置？**
`sync` 会把旧条目标 `missing`、新路径当新条目收。想保住用途标注，就在 json 里先改 `文件` 字段再 `sync`。

**Q：两个项目都要用同一批截图？**
各建各的台账，各自登记同一路径。台账是索引，同一文件可以被多条索引指向，不复制文件。

**Q：能自动填用途吗？**
不能，也不该。脚本猜出来的用途比留空更糟 —— 留空至少 `check` 会提醒你。

## 统一素材库与分册

各项目台账是「第一层」，只管这条片子用过什么。跨项目找素材用「第二层」：

```bash
python registry.py catalog <素材库根> --src <项目空间根>
```

产出：

```
<素材库根>/
├── 素材总清单.md      # 册列表 + 每册条数 + 链接
├── 素材总清单.json    # 机读，含每条的真实路径
└── 分册/
    ├── 仙宫云.md
    ├── 角色替换.md
    ├── 成片.md
    └── …
```

**分册规则**：条目「标签」的第一个词就是册名，没标签的进「未分类」。
所以标签第一个词要选「以后按什么归类找它」——`仙宫云` 而不是 `界面`。

**只汇精选**：`档` 不是 `精选`、`missing`、`可复用=false` 的一律不进素材库。
过程产物不进，这是分册能保持可读的原因。

**不搬文件**：分册每条记的是绝对路径（台账目录 + 相对路径）。同一文件被多个项目引用就会出现多条，
`重复` 字段会自动标出首 1MB 相同的兄弟条目，方便发现「同一张图存了两份」。

**编号**：`<册名>-<三位序号>`，如 `仙宫云-007`。catalog 每次重排，编号可能变，
引用时用「册名 + 用途」更稳，编号只用于口头指代。

**刷新时机**：项目里标了新的精选就跑一次，成本几秒。
