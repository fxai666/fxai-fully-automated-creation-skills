# 可复用素材登记台账

一个项目目录一份台账，两个文件同源：`素材登记.json`（机读，字段固定）+ `素材登记.md`（人读，由 json 渲染）。

**为什么要有它**：素材散在各项目目录里，找一次全靠翻盘。做完一条片子，把里面能复用的东西登记下来，
下次做同类片子直接查台账拿路径，不用再「我都不知道它存哪了」。

## 本技能文件清单（先读这里，再决定读哪册）

| 文件 | 什么时候读 |
|---|---|
| `scripts/registry.py` | 唯一的脚本；改判定规则、加字段时才读 |
| `references/01-登记规范.md` | 定字段含义、判「精选 / 过程」、写用途话术、多人协作时 |

**确定本次要做什么之后，只读对应的那一册，其余一律不读。**

## 六条命令

```bash
S=~/.workbuddy/skills/fxai-asset-registry/scripts

python $S/registry.py scan    <目录>              # ① 只扫不写，先看有什么
python $S/registry.py init    <目录> --name 项目名 # ② 建台账骨架（已存在不覆盖）
python $S/registry.py sync    <目录>              # ③ 增量登记（日常就用这条）
python $S/registry.py check   <目录>              # ④ 查路径失效 + 还剩多少没标用途
python $S/registry.py index   <根目录>            # ⑤ 汇总根下所有台账，出总索引
python $S/registry.py catalog <素材库目录> --src <根目录>  # ⑥ 把各项目精选汇成总索引（分册）
```

> 入库（把文件收进素材库）已迁到 **`fxai-asset-library`** 的 `lib.py add`。
> 本技能的 `promote` 保留兼容、写的是同一份 `库内清单.json`，但不推荐——
> 它不生成缩略图、不做重复检测、不做反向引用。

## 三层里的哪一层（本技能只管第三层）

| 层 | 位置 | 谁管 |
|---|---|---|
| 系统级（技能级） | `~/.workbuddy/skills/<技能>/assets/` | 技能自己，谁都不许动，动了技能就坏 |
| 应用级（素材库） | `<素材库根>/_库/<形态>/`（全局配置 asset_library.root） | **`fxai-asset-library`**（`lib.py`） |
| **项目台账** | 各项目目录 `素材登记.json` | **本技能** |

本技能只管「这条片子用过什么」，**不负责库内台账的检索、详情维护与看板**。要那些走另一个技能：

```bash
L=~/.workbuddy/skills/fxai-asset-library/scripts/lib.py
python $L find 仙宫云 开实例      # 按词定位
python $L ls --form 录屏          # 按形态翻
python $L info 仙宫云-001         # 详情 + 被哪些项目引用
python $L html                   # 出带缩略图的看板
```

项目引用库内素材时，条目**不复制文件**，只挂编号：
`"库内": "仙宫云-001", "仅库内": true` —— 本技能 `sync` 见到就跳过、不报失联。

## 一次完整的登记

1. `scan` 看规模。上千项的目录先别急着全标，看有没有一堆过程产物。
2. `init` 建骨架，`sync` 收录。
3. **开 `素材登记.json`，把真正能复用的条目 `档` 改成 `精选`，填 `用途` 和 `标签`**。
   - 用途写「这是什么 + 什么规格」，别写「图1」「素材A」这种等于没写的话。
   - 能一句话说清它适合用在哪种片子里最好。
4. `registry.py md <目录>` 重渲染，`check` 确认没有失效路径。
5. 以后新增素材：只要 `sync` 一次，新文件自动进「待评」，老条目的用途标注不会被覆盖。

## 铁律速查

1. 🔴 **只登记，不动素材**。不移动、不改名、不删除、不转码。要归位是另一件事，先跟用户确认。
2. 🔴 **相对路径相对台账所在目录**，整目录搬到别的盘也不失效。
3. 🔴 **`档` 三档**：`精选`（人工确认能复用）/ `未评`（还没判）/ `过程`（分段切片、中间渲染、分段配音、一次性配图）。
   `sync` 只会把 `未评` **降级**成 `过程`，**绝不覆盖**人工标的 `精选`。
4. 🔴 **用途字段要么写清要么留空**。留空显示「待标注」，比瞎写强；`check` 会列出还剩多少条没标。
5. 🔴 **md 是渲染产物，结构不手改**。要改内容改 json 再重渲染。
6. 🔴 **台账放项目目录根部**，与 `_fxai_project.json` 同级；不放进 `_tmp/`、不放进技能包。
7. 🔴 **不建备份副本**。台账是索引不是副本，原文件只有一份。
8. 🔴 敏感素材（含真人肖像、客户素材、未授权素材）在 `备注` 里写清授权状态，`可复用` 置 `false`。
9. 🔴 跨项目找素材先跑 `index`，别一个个目录 `ls`。

## 自动判定规则（想改就改 `registry.py` 顶部两个正则）

| 归「过程」的特征 | 例子 |
|---|---|
| 目录名 | `_tmp` `anim` `_frames` `配图` `music` `音频` `配乐` `fftest_out` |
| 文件名 | `p01.mp4` `clip.mp4` `burned*` `final.mp4` `merged*` `S01_封面.png` `01.wav` `seg_003*` |

命中不等于丢弃，只是进「过程产物」一节，md 里最多列 60 条，全量仍在 json 里。
