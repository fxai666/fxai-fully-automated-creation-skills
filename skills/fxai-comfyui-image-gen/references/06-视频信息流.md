# 06 · 视频信息流

> **何时读**：做视频信息流这类界面模板时（播放页 / 直播页 / 笔记详情 / 商品详情 / 聊天详情同一骨架）。

## 适用判据

需求里出现下列任一特征即按本册走：全屏播放页 / 推荐页 / 整屏 / 状态栏 / 导航栏 / 点赞与评论数 / 底部导航 / 界面复刻。

同一骨架覆盖：短视频播放页、直播页、笔记详情、商品详情、聊天详情。区别只在 UI 五区各自填什么。

排除两类：只有画面内容、无界面元素的，走 02 册常规人物图；要的是信息流列表里那张缩略卡片，属封面图，走 `fxai-poster`。

## 段序固定

六段按下列顺序排列，不得调换：界面五区整块前置于主体人物之前，主体描述收尾时不被界面文字截断。

| 段 | 写什么 | 缺了会怎样 |
|---|---|---|
| 一 画布与质感 | 画幅比例 + 摄影质感总纲（真实度 / 灰度 / 锐度 / 即时感） | 质感总纲缺失，画面出成设计稿 |
| 二 构图落位 | 主体方位、占画面比例、朝向、前中后三层各由什么填充 | 占比不写，主体撑满画面 |
| 三 UI 五区 | 状态栏、导航栏、右侧互动栏、底部导航、左下文案 | 只写「有导航栏」，文字乱码或缺失 |
| 四 主体人物 | 头型/发型、穿搭/服装、姿态朝向、手持道具 | 缺【】标记，被穿搭校验拦截 |
| 五 场景环境 | 地点、承托物细节、邻位物件、窗外远景 | 只写地点，座椅与背景一片空白 |
| 六 光影色调 | 光源方向、受光面、阴影面、色温基调、氛围 | 缺光源方向，出成平光 |

## 画布尺寸

| 比例 | 像素 | 用途 |
|---|---|---|
| 9:16 | 864×1536 | 竖屏播放页全屏 |
| 2:3 | 832×1248 | 竖屏略窄 |
| 3:4 | 1080×1440 | 竖屏详情页 |
| 1:1 | 1024×1024 | 方形卡片 |
| 4:3 | 1440×1080 | 横屏图文 |
| 16:9 | 1536×864 | 横屏全屏 |

边长取 32 的整数倍且落在 512~4096，其他比例按此换算后取整。

## UI 五区写法

区内按屏幕实际顺序排：横排区从左到右，竖排区自上而下。

| 区 | 列什么 | 判据 |
|---|---|---|
| 状态栏 | 时间、信号、WiFi、电量 | 电量写颜色 + 内嵌数值 |
| 导航栏 | 左端菜单图标与角标、中段页签文案、选中态、右端搜索 | 页签逐个列文案；选中态写「某文案下方一条白色短横线表示当前选中」 |
| 右侧互动栏 | 头像、点赞、评论、收藏、转发、功能入口 | 每项 = 图标形状 + 附注文字与数值 |
| 底部导航 | 各入口文案 + 数字角标 | 角标写位置 + 颜色 + 数值；文案与图标分开点名，末尾补一句「入口全部带白色文字标签」，否则「消息」易只剩图标、「我」易走形 |
| 左下文案 | 作者名、正文、按钮、歌曲信息 | 正文含话题标签时逐个列出 |

图标判据：位置 + 图形 + 附注文字，三者齐。只写「点赞图标」，模型自造数值。

角标判据：位置（哪个图标右上角 / 正上方）+ 颜色 + 数值，三者齐；无数字的红点写「红色小圆点」并指明相对位置。

## 段落配额

UI 五区合计占提示词四成，主体人物三成，构图与场景与光影三成。UI 段低于三成，文字缺失；高于五成，主体被挤小。

## 背景图案强化

布面印花、涂鸦、帘布、贴纸这类图案细节，在描述句里标「（重点）」并补颜色与占画面比例。只写「有图案」，模型退化成浅纹理。

## 骨架（按段填）

```text
<画幅比例>手机应用全屏截图，<摄影质感总纲>。
【构图】<主体落在画面哪个方位>，<占画面比例>，<朝向>；<前中后三层各由什么填充>。
【UI·状态栏】<时间>；<信号>、<WiFi>、<电池：颜色+内嵌数值>。
【UI·导航栏】<左端图标与角标>；<页签文案逐个>，<选中态>；<右端图标>。
【UI·右侧互动栏】<头像>；<各项图标形状+附注文字数值，自上而下逐个>。
【UI·底部导航】<各入口文案与角标>。
【UI·左下文案】<作者名>；<正文与话题标签>；<按钮>；<歌曲信息>。
【主体】<性别与年龄段>，<身形>；【头型/发型】<…>；【穿搭/服装】<上装+下装+鞋+配饰>；<姿态与朝向>；<手持道具>。
【场景】<地点>；<座椅或台面等承托物：材质+图案>；<邻位物件>；<窗外或远处>。
【光影】<光源方向>；<受光面>；<阴影面>；<色温基调>；<氛围>。
```

## 结构化拼装

`feed_screen.py` 按同一骨架拼装并提交，字段名与骨架逐段对应，字段表见脚本 `SPEC_FIELDS`。

```bash
python feed_screen.py <spec.json> --tag <项目>_<界面> --save-dir <项目目录>
```

spec 文件与产物同项目不同位：spec 放项目 `_tmp/`，产物放项目根。

## 验收

交付前逐项对图，缺一项即返修：

- 状态栏时间与电量数值
- 每个数字角标的位置、颜色、数值
- 当前选中页签的下划线
- 互动栏各项数值
- 底部导航每个入口文案逐个核对，单字入口（我 / 消息）走形率最高
- 左下作者名、正文、话题标签、按钮文案、歌曲信息
- 主体朝向与面部遮挡程度
- 服饰敞开、滑落、交叠等细节
- 承托物图案与窗帘等背景件
- 光源方向与受光面是否与设定一致

## 参数

`role` 按主体性别取；尺寸按比例表取；`tag` 用 `<项目>_<界面>`。主体段必带【头型/发型】与【穿搭/服装】，判据见 05 册第 5 条。
