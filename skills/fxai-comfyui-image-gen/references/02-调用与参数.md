# 两种调用方式、参数表与输出目录

**何时读**：查怎么调 generate_image、参数默认值、产物落哪时

### 方式 A：直接 import（对话内脚本首选）

```python
import sys
sys.path.insert(0, r"<技能目录>/fxai-comfyui-image-gen")
from image_gen import generate_image

path = generate_image(
 "深夜书房，一个女子独坐桌前，面前发光的工作站主机，电影级光影，" + QUALITY,
 role="woman", width=1280, height=720, tag="cover_xxx"
)
print(path) # -> 本地 PNG 绝对路径
```

### 方式 B：CLI（Bash 直接跑，连 ComfyUI 需放行沙箱网络）

```bash
python "<技能目录>/fxai-comfyui-image-gen/image_gen.py" \
 "中秋满月高悬中式楼阁，红灯笼桂花飘落，电影级光影" --role woman --w 1280 --h 720 --tag cover_mid
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `prompt` | 必填 | **中文提示词**（千问2.1 原生中文理解，无需翻译成英文） |
| `role` | `"woman"` | `"woman"`(女,默认) / `"man"`(男) / `"both"`(001+000同框) / `None`或`""`(纯场景无人物) |
| `width`/`height` | `1280`/`720` | 像素；公众号横幅建议 1280x720 |
| `tag` | 时间戳 | 输出文件名（不含扩展名） |
| `comfy_subdir` | `"skill_gen"` | 提交给工作流节点的「输出分类子目录」参数（仅服务端使用，客户端不读取本机目录） |
| `save_dir` | 技能`/output` | 本地成品落点 |
| `timeout` | `600` | 单图超时（秒） |
| `model` | `None` | 模型 slug（如未来 `"kling"`）；`None`=该任务默认模型（qwen21） |

返回：本地 PNG 绝对路径；失败抛 `RuntimeError`。

- ComfyUI 中间产物：留在 ComfyUI **服务端**（由工作流节点自行管理，客户端不读取本机目录）。
- 本地成品（默认，经 HTTP 下载）：`<技能目录>/fxai-comfyui-image-gen/output/<tag>.png`

> 归档位置由**调用方（实际任务）**决定，本技能只负责「接口下载 + 返回本地路径」，不自己定项目目录。
