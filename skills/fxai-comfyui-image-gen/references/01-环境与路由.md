# 开工前的环境、路由与云端开关机

**何时读**：开工前查前置条件、本机优先路由、仙宫云自动开关机时

0. 🔴 **开工第一步：读 `fxai-workflow/SKILL.md` 的「🚨 ComfyUI 服务端模式铁律」**（本册是它的补充，不是替代）。
   调用方开工前必读被依赖件的 SKILL.md，尤其标"公共层 / 内部引用"的那些——铁律只在 SKILL.md，不在 `.py`。
   核心：ComfyUI 由「凤希本地AI控制台」／启动器启停，本技能只按地址发 HTTP；本机 8188 探不通 → 走云或提示人启动；资源有无只认服务端接口。
1. **ComfyUI 在线**：由 `comfy_url` 指定（本地或远端均可，见 `fxai-workflow`）。
   本机默认 `http://127.0.0.1:8188`；指向仙宫云等远端时用 `xgy_api.py comfy-url <id>` 取地址。
2. **工作流复用公共目录**：生图走 `fxai-workflow/img-qwen21-process.json`（千问2.1 占位符版），由 `comfy_client.submit_workflow` 注入 `fxai_prompt`/`fxai_width`/`fxai_height`/`fxai_imageinput`/`fxai_outputdir`/`fxai_filename_index`/`fxai_seed` 后提交。模型维度集中在 `comfy_client` 的 `WORKFLOWS` 注册表（`scene → {qwen21: img-qwen21-process.json}`），`generate_image(..., model=)` 可切模型，未来加 kling/sdxl 只加注册表一项。
3. **角色参考图存在**（走本机时才需要关心）：`<comfy_root>/fxai/image/avatar/000.png`（女，默认）、`001.png`（男）。
   ⚠️ 这个路径是 **`<comfy_root>/fxai/image/avatar/`，不是 `input/avatar/`** ——
   `FxAiCharacterImageSelector` 源码里写死 `base_dir = "fxai/image"`，再拼 `avatar/000.png`。
   放错目录不会报错，运行时才挂在 `RuntimeError("没有图片，请选择图片文件")`。
   客户端不读取服务端目录，但**跨机器（如从本机传到仙宫云）时必须按这个落盘路径传**；
   你的 ComfyUI 装在 `<盘>:\ComfyUI` 时，源图通常在 `<盘>:\ComfyUI\input\005_*.png`。
4. **全程经 HTTP 接口、不读本机目录**：提交 `POST /prompt` → 探测 `POST /fxai/tasks/result` 拿 url 令牌 → 下载 `GET /fxai/down/file?url=<令牌>`。**配置只需 `comfy_url`（服务器地址）**，不需要任何本机 ComfyUI 目录路径配置。
   - 🔴 **连「确认参考图是否存在」也必须走接口**：本机扫 `avatar/` 等 ComfyUI 资源目录的结果不可信（服务端可能装在另一台机器），资源有无一律由服务端判定。直接提交工作流被 `queued` 即证明服务端已读到。通用铁律见 `fxai-workflow` 技能。

> `generate_image()` 开工先调 `prefer_local()`：**本机 `127.0.0.1:8188` 探得通就走本机**（不计费、不自动开机，
> 也不会弹收工关机询问）；本机没起才由 `require_comfyui()` 按配置里的云地址自动开机。
> 想强制走云：显式传 `url=`，`fxai_global.json` 的 `comfy_url` 保持原值（那是全局配置，会带歪 MV / 短剧 / 四视图）。
> 更详细的路由规则见 `fxai-workflow` SKILL.md 的「本机优先」一节。
> `generate_image()` 走云时，`require_comfyui()` 会自动探活、探不通且是仙宫云地址就自动开机；
> 整套流程跑完那一步（`comfy_client.finish()`），再向用户确认是否关机。
> 开机 / 关机 / 实例 ID 怎么取 / 问哪两档，**一律以 `fxai-workflow` 的 SKILL.md 为准**，
> 命令速查也在那儿（`list` / `use` / `ensure` / `hint` / `stop`）。本技能不另设开关机配置。
