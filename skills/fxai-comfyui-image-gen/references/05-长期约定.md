# 05 · 长期约定（生图红线判据）

> **何时读**：写提示词前、传参考图前、遇到穿搭校验或 `<imageN>` 报错时。

## 长期约定

1. **人物参考图一律用自有角色 000/001**，他人肖像有侵权风险。`role="woman"` 默认唤起 000，`"man"` 唤起 001，双人用 `"both"`；也可直接传自定义相对路径（如短剧角色图 `shortdrama_qsl/001.png`，原样透传，逗号分隔多张）。
2. **中文提示词直达图像**，无需英文翻译；想夸张/二次元风格仍保留 000/001 参考。
3. **产物带完整性校验**：经 HTTP 下载到本地后，`png_ok` 校验 PNG 含 IEND 结束块（不完整则重试），根治半张图。
4. 本技能**只管生图**；公众号发布/群发由 `fxai-weixin-gzh-publisher` 技能负责。需要"生图+发公众号"时两个技能配合：本技能出图 → 把路径交给发布技能上传。
5. 🔴 **人物出图必写【穿搭/服装】+【头型/发型】**：凡画面里有人（`role≠None`，或 `role=None` 但提示词在描述人物），按取景写明——**全身图→上装+下装+鞋+配饰+发型；半身图→上半身穿搭+发型**。提交前由 `check_outfit()` 硬校验拦截；词表与放行条件见 `references/03-穿搭校验细则.md`。
6. 🔴🔴 **多参考图必须写引用标签 `<imageN>`（缺一个都不行）**：传 N 张参考图（`role="both"`=2 张、自定义逗号路径同理），提示词里必须【逐个】包含 `<image1>`…`<imageN>`，把每张图显式绑到具体人物/元素上（如「`<image1>` 是画面右侧的男子…`<image2>` 是画面左侧的女子…」）。标签编号 = 参考图列表顺序（`both` 与自定义路径都是男主图在前 → `<image1>`=男、`<image2>`=女）。这是 Qwen-Image-2.1 edit 的图片绑定机制（`qwen_image21.py` 按图片顺序插入 `<imageN>`+视觉块）；**不写标签 = 不告诉模型哪张脸是谁，参考图会被直接忽略**（2026-10-12 双人封面事故：传了 2 张图没写标签，男主完全没锁上）。由 `check_image_refs()` 硬拦：**N>1 缺标签直接 ValueError**，N≤1 缺标签打印告警不拦（兼容既有单图链路）；`role=None` 免检。
7. 🔴 **封面/海报类角色图，参考图用「该作品自己的角色形象图」**：如短剧封面必须用渲染管线同一套角色图（`project_def` 的 `server_subdir` + `characters[].server_index` 派生，如 `shortdrama_qsl/001.png`），**勿用全局头像库 `avatar/000、001`**——那是凤希AI 品牌头像（女主/用户本人证件照），与剧中人物形象对不上，模型会忽略参考图。通用 `_series_role_refs()` 已封装此派生（fxai-short-drama/platform_publish.py）。
8. 🔴 **着装红线只一条：胸部 / 私密部位保持遮挡**；透视装 / 薄纱 / 透明演出服 / 贴身礼服允许，力度取"透而不露"。
