# 07 · 字幕（通用分册，所有模板共用）

> **何时读**：合并成片出来后要烧字幕时。本册是口播字幕的**唯一标准做法**，
> 模板册（T1/T2…）不重复抄，只指向这里。

## 🔴 铁律：字幕必调 `fxai-lyric-subtitle`，不自写样式

字幕的**对齐 / 断句 / 校验 / 样式**一律由字幕技能产出，本技能**不自己写
ASS/SRT 样式文件**。脚本只负责把「时间轴」喂给技能。

## 两条路：按音频来源选

| 音频来源 | 路 | 做法 |
|---|---|---|
| 本技能自己 TTS 逐句合成（`口播01~NN.wav`） | **时长轴**（首选，100% 对齐） | 文案行 ↔ 音频严格 1:1，用各条音频实测时长做累计时间轴 |
| 用户提供的外部音频 | **whisper** | 交给字幕技能走 ASR 识别（中英文混排漂移时按①兜底） |

## 时长轴标准做法（TTS 路，实测最优）

本片音频是逐句 TTS 拼成的，行↔音频 1:1，所以：

1. 脚本按各条音频时长（ffprobe 实测，求和 = 合并片总时长）算累计时间轴，
   按字数比例在每行窗内铺开；
2. 把时间轴写成 **whisper 同款 `_words.txt`**（每行 `[起->止] 文本`，逐 chunk，
   文本写 normalized 后的字符）；
3. 用 `--transcript` 传给字幕技能 → 技能跳过 whisper，用它内置的对齐/断句/
   校验/默认样式生成并烧录；
4. source 与 target 字符序列一致 → 对齐 100% 命中，不再漂移。

⚠️ **chunk 边界必须复制技能 `chunks_of()`（含 `max_chars=16`）**：否则数字归一
`_cn_number_to_digits` 在逐字/整句上结果分岔，对不齐。

⚠️ **whisper 路的脆弱点**：中英文混排 + 全局编辑距离会漂移；ASR 整句漏听时该
chunk 映射全 None、直接报错。外部音频优先 whisper；漂移/报错就退回时长轴思路
（能拿到逐句音频时）。

## 烧录纪律

- 烧录用**带 libass 的 ffmpeg**（`av.ffmpeg_libass()`；conda 自带的没有
  `subtitles` 滤镜）。
- **一句字幕 = 一个完整时间窗口**：whisper 把一句切成多个 phrase 时，窗口取
  首 phrase 的 start → 末 phrase 的 end，不逐 phrase 显示。
- **单条字幕按方向分档**：竖屏 4.0 秒 / 16 字，横屏 6.0 秒 / 24 字。
- **字幕不显示标点**：标点只参与断句，上屏前剥掉。
- **字幕只显示正文**：`用…的语气说<|endofprompt|>` 标签在烧录前剥掉，
  烧录后校验，发现即报错不落盘。
- **时间轴写盘前自检**：单条 ≥0.6s / ≤上限 / 递增不重叠 / 覆盖到音轨末尾，
  不合格报错不落盘。
- 字体走 `fxai-standard/references/06-字体与素材授权.md` 白名单
  （正文/字幕首选 Noto Sans SC；微软雅黑随 Windows 预装可用）。

## 禁做项

- ❌ 自己写 ASS 样式 / SRT 时间轴文件直接烧（对齐与样式不可控，返工更贵）
- ❌ 拿 `ceil(时长/10)` 估段数去铺时间轴（段数用 `av.h3_segment_count()` 算）
- ❌ 逐 phrase 显示字幕（一句一个窗口）
