# 10 · 场景创意配方库

> **核心原则：场景服务于内容，但不被现实束缚。**
> 凤希要的不是"办公室/会议室/讲台"这种传统三件套，是**有创意、不拘一格**——
> 科幻空间、超现实场景、自然奇观、艺术化表达，只要贴合这段文案的气质，都可以用。
>
> 传统场景是基础选项，不是标准答案。**先想创意，再想合不合理。**

---

## 选场景的思维方式

### 第一步：先想这段文案的"气质"是什么

不是问"这事发生在哪儿"，是问"这段话给人什么感觉"：

| 文案气质 | 场景方向 | 举例 |
|---|---|---|
| 科技感、未来感、讲AI | 科幻空间、全息投影、数据中心 | 悬浮平台上、星舰舰桥、全息界面环绕 |
| 专业感、权威感、讲行业 | 高端但不传统 | 顶层落地窗前、极简美术馆、博物馆展厅 |
| 自由感、旅行感、讲生活 | 自然奇观、户外开阔地 | 山顶悬崖、海边礁石、星空下的天台 |
| 温暖感、亲密感、讲情感 | 温馨但不普通 | 暖光书房、窗边懒人沙发、雨后的街角 |
| 力量感、宣言感、讲观点 | 有仪式感的空间 | 巨大的落地窗前、空旷的展厅、阶梯讲台 |
| 神秘感、探索感、讲未知 | 超现实空间 | 云雾缭绕的平台、悬浮的环形空间、发光的隧道 |

### 第二步：传统场景和创意场景混搭

勿全程一个风格。一条片子里：
- 开场用创意场景抓人（科幻空间、自然奇观）
- 中段切回现实感场景讲细节（办公桌、实验室）
- 收尾再回到创意场景升华（星空下、山顶）

**混搭才有节奏感，全程一个风格会腻。**

---

## 创意场景库（不限于此，打开想）

### A. 科幻/未来感场景

#### A1 · 悬浮平台
- **构图**：中景，人物站在一个圆形悬浮平台上，脚下是透明的，能看到下方云层或城市
- **光线**：人物边缘有冷蓝色轮廓光，平台边缘发出柔和的白色光晕
- **道具**：无实物，只有空气里悬浮的全息界面（淡蓝色线条，不可读）
- **气质**：未来、科技、宏大
- **适用**：讲AI、讲未来趋势、讲技术革命

#### A2 · 星舰舰桥/控制室
- **构图**：中景，人物站在巨大的弧形屏幕前，屏幕上是星空或数据流
- **光线**：屏幕发出冷蓝色主光，人物面部被屏幕光照亮
- **道具**：弧形操作台、悬浮的全息按钮
- **气质**：硬核科技、掌控感
- **适用**：讲系统架构、讲产品控制、讲技术方案

#### A3 · 全息数据空间
- **构图**：中景，人物站在一个全是悬浮数据面板的空间里，面板环绕在人物四周
- **光线**：数据面板发出各种颜色的微光（蓝、紫、绿），柔和照亮人物
- **道具**：无数悬浮的半透明数据面板，上面是图表和线条，不可读
- **气质**：数据感、信息密集
- **适用**：讲数据分析、讲增长指标、讲行业数据

---

### B. 自然奇观场景

#### B1 · 山顶悬崖
- **构图**：中景，人物站在山顶的岩石平台上，身后是云海和连绵的山脉
- **光线**：金色夕阳从侧面打来，人物轮廓被镀上金边
- **道具**：无，只有风和云
- **气质**：开阔、力量、宣言感
- **适用**：讲观点输出、讲行业判断、讲人生感悟

#### B2 · 海边礁石
- **构图**：中景，人物站在海边的礁石上，身后是大海和天空
- **光线**：自然光，阴天柔和散射光，或日落暖光
- **道具**：海浪拍打的礁石，远处有海平线
- **气质**：自由、辽阔、思考感
- **适用**：讲人生选择、讲行业趋势、讲开放式话题

#### B3 · 星空天台
- **构图**：中景，人物站在一个高空天台上，头顶是满天星空
- **光线**：城市灯光从下方反射上来，星空有微光
- **道具**：天台边缘的栏杆，远处是城市灯火
- **气质**：浪漫、思考、夜晚感
- **适用**：讲复盘、讲感悟、讲深夜思考类内容

---

### C. 艺术/设计感场景

#### C1 · 极简美术馆
- **构图**：中景，人物站在一个纯白的极简展厅里，墙面有巨大的空白
- **光线**：均匀的顶部射灯，干净明亮，没有多余阴影
- **道具**：无，只有干净的白墙和水泥地面
- **气质**：高级、极简、设计感
- **适用**：讲设计、讲美学、讲品牌理念

#### C2 · 环形阶梯空间
- **构图**：中景，人物站在一个巨大的环形阶梯中间，阶梯层层向上延伸
- **光线**：柔和的自然光从顶部洒下来，形成光柱
- **道具**：环形阶梯本身就是场景
- **气质**：仪式感、递进感、宏大
- **适用**：讲成长路径、讲方法论、讲进阶过程

#### C3 · 光影隧道
- **构图**：中景，人物站在一个发光的隧道中间，隧道壁是流动的光线
- **光线**：隧道发出各种颜色的流动光带，环绕人物
- **道具**：无，只有光
- **气质**：梦幻、穿越感、未来
- **适用**：讲技术突破、讲转折时刻、讲概念性内容

---

### D. 传统但升级的场景

#### D1 · 顶层落地窗办公室
- **构图**：中景，人物站在巨大的落地窗前，身后是城市天际线
- **光线**：自然光从窗户打来，城市在身后虚化
- **道具**：一张极简的办公桌，一把椅子
- **气质**：专业、高端、都市感
- **适用**：讲商业、讲创业、讲行业洞察

#### D2 · 实验室/操作台
- **构图**：中景，人物站在一个现代化的实验台前，台上有各种仪器
- **光线**：冷白色实验室灯光，均匀照亮台面
- **道具**：显微镜、试管、显示屏、各种实验设备
- **气质**：专业、精密、科学感
- **适用**：讲技术细节、讲研发、讲产品原理

#### D3 · 书房/暖光阅读角
- **构图**：中景，人物坐在一个暖光书房的沙发上，身后是满墙书架
- **光线**：落地灯暖黄色主光，书架上有小灯补光
- **道具**：书架、落地灯、沙发、毛毯、马克杯
- **气质**：温暖、知性、亲密
- **适用**：讲读书体会、讲个人感悟、讲经验分享

## 空镜头 / B-roll 的无限可能

空镜头（E/M/B段）**不受任何现实场景限制**——只要是好看的、有氛围感的画面，都可以用：

| 类型 | 举例 |
|---|---|
| **自然空镜** | 云海翻涌、星空延时、海浪拍岸、森林光斑、日落延时 |
| **城市空镜** | 雨后街道反光、高楼玻璃幕墙、地铁人流、车流光轨 |
| **科技空镜** | 数据中心服务器、电路板特写、代码滚动、全息界面旋转 |
| **艺术空镜** | 抽象光影流动、彩色玻璃折射、水墨晕染、粒子飘散 |
| **产品空镜** | 产品旋转展示、细节特写、包装拆封、使用场景 |

**空镜头就是用来"呼吸"的**——讲完一段密集的内容，切一个好看的空镜给观众喘口气，再切回人物继续讲。

## 场景混搭节奏（一条片子的编排）

一条几分钟的口播，场景勿一直换，但也勿一直不变。建议节奏：

| 段落 | 内容类型 | 场景选择 |
|---|---|---|
| **开场 0-10s** | 抛出话题、立人设 | 创意场景（山顶/星空/科幻空间），先抓住眼球 |
| **中段 10-60s** | 讲细节、讲步骤 | 切回现实感场景（办公桌/实验室），让内容落地 |
| **中段 60-120s** | 讲观点、讲判断 | 再切一个有气质的场景（美术馆/落地窗前），提升格调 |
| **收尾 最后一段** | 总结、CTA | 回到创意场景（星空下/山顶），呼应开场，升华感 |

**场景切换点落在内容转折处**——不是每10秒切一次，是"从讲细节转到讲观点"的时候才切。

## 场景图提示词的创意写法

写场景图的时候，勿被"办公室"这种词限制住。用画面感的描述：

❌ 太普通：
```
办公室场景，一张桌子，一把椅子，电脑
```

✅ 有画面感：
```
巨大的落地窗前，脚下是城市天际线，午后阳光从侧面打来，
人物站在窗前，玻璃反射出柔和的光影，极简空间只有一张桌子
```

✅ 更有创意：
```
悬浮在云海之上的圆形平台，边缘发出柔和的白色光晕，
远处是连绵的山脉和金色夕阳，天空有流动的云层，
整体未来感与自然感结合，人物站在平台中央
```

**关键词：光线 + 空间感 + 氛围 + 道具，勿只写"这是什么房间"。**

## 光线的创意用法

光线不只是"照亮人物"，本身就是氛围：

| 光线风格 | 写法 | 气质 |
|---|---|---|
| **金色夕阳** | 从侧面45度打来，人物轮廓镀上金边，暖色调 | 温暖、力量、黄昏感 |
| **冷蓝屏幕光** | 从前方屏幕打来，人物面部被冷光照亮，背景偏暗 | 科技、深夜、专注 |
| **白色极简光** | 均匀顶部射灯，干净明亮，没有多余阴影 | 高级、极简、设计感 |
| **暖黄灯光** | 落地灯从侧前方打来，柔和温暖，阴影很软 | 温馨、亲密、居家 |
| **流动彩光** | 隧道里流动的蓝紫光带，环绕人物 | 梦幻、未来、穿越感 |
| **自然窗光** | 从大窗户洒进来的散射光，柔和均匀 | 日常、真实、舒适 |

---

## 铁律（不管什么场景都要守）

1. 🔴 **场景图 = 空实景**：不出现主角本人，可有背景人物剪影
2. 🔴 **场景图不出现可读文字**：屏幕内容虚焦，没有清晰文字
3. 🔴 **人物落位区无前景遮挡**：镜头和人物之间不得有家具挡住
4. 🔴 **光线写具体**：什么光源、从哪侧来、什么色温，不写"柔和光线"
5. 🔴 **相邻段换景**：勿全程一个场景，至少2-3个场景轮换
6. 🔴 **创意场景也要有可指认的实物**：不得只有"氛围感"，要有具体的东西让人物和场景互动

## 选场景速查表（创意优先版）

| 这段在讲什么 | 创意首选 | 现实备选 |
|---|---|---|
| 讲AI、讲未来技术 | 全息数据空间 / 悬浮平台 | 办公桌前 |
| 讲行业判断、讲观点 | 山顶悬崖 / 星空天台 | 落地窗前办公室 |
| 讲产品功能、讲细节 | 实验室操作台 / 全息界面 | 办公桌前 |
| 讲设计、讲品牌美学 | 极简美术馆 / 光影隧道 | 书房 |
| 讲人生感悟、讲复盘 | 海边礁石 / 星空下 | 书房沙发 |
| 讲成长路径、讲方法论 | 环形阶梯空间 | 会议室 |
| 讲数据、讲增长 | 全息数据面板环绕 | 办公桌双屏 |
| 讲情感、讲亲密话题 | 暖光阅读角 | 客厅沙发 |

**先用"创意首选"，不够落地再切"现实备选"。**
一条片子里混搭着来，勿全是创意也勿全是现实。
