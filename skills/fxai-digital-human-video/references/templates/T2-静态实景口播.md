# T2 · 静态实景口播（坐姿融入式 + 无人物演示空镜）

> **何时用**：讲解 / 教程 / 复盘 / 实操演示 / 叙事——数字人**不一定在场景里走动**，
> 可以**坐在办公桌、椅子、书房、咖啡厅**里边讲边比划，可以**倚靠/静立**在
> 白板旁、马路边，也可以**干脆不出镜**，让场景本身演示内容（屏幕、操作台、
> 便签看板、道具特写）。要"走着讲、逼近镜头"的强动态 → 那拍用 **T1** 形态。
> 参数 → `01-参数与命令.md`；场景硬规则 → `02-人物动作与场景图.md`；
> 字幕 → `07-字幕.md`；封面 → `05-封面.md`；通用铁律 → `06-模板库.md`。

## 核心主张

1. **人物融入环境，而不是穿透环境**：坐姿/静立让人物"在"场景里，
   观众的注意力回到**内容与演示**上——讲步骤、讲界面时，人物大动态反而抢戏。
2. **演示比描述有力**：讲"界面长什么样""步骤怎么排""数据在哪看"的那几拍，
    **不出人，直接拍场景**（E 段空镜），是最真实的展示。
3. **怎么写根据内容定**：同一套管线，走 / 坐 / 立 / 空镜按节拍混排，
   分镜表每拍标注形态即可。

## 与 T1 的分工

| | T1 · 实景中景口播 | T2 · 静态实景口播 |
|---|---|---|
| 人物状态 | 走动 / 走近镜头，动态强 | 坐姿 / 静立 / 倚靠 / **无人物** |
| 构图 | 近景小构图 | 坐姿中景（人物占 1/3~1/2）/ 空镜全景细节 |
| 运镜 | 运镜库轮换 + 极缓单向位移 | 人物镜头固定 / 极缓推近；空镜（E/M/B）可推可移 |
| 动作库 | 走动向（移步/转身/靠近） | 坐姿向（坐姿手势/前倾/侧身）/ 静立向（倚靠/指物） |
| 空镜 | 无 | **有（E 段，场景即演示）** |
| 适合 | 观点 / 营销 / 成果展示 | 讲解 / 教程 / 复盘 / 实操演示 / 叙事 |

> 术语与档位 → `08-镜头语言.md`。**人物镜头只走固定与极缓推近**（平移会让背景逐段重算、
> 画面闪烁跳跃）；平移只用在空镜上，由 `make_material_seg.py` 出。

**混排是常态**：走动讲观点（T1 式）→ 坐下讲细节（S）→ 起身指看板（L）→
空镜演示（E）→ 坐下收尾（S）。各拍按形态取规则，管线不变。

## 三种镜头形态

### S · 坐姿融入（主力）

- **场景**：办公桌（开放办公室工位）、书房（书桌 + 书架）、咖啡厅（靠窗位）、
  会议室长桌、客厅沙发、居家书桌——**坐得下来的真实环境**都可以。
- **场景图要点**（写进 prompt）：
  - 「**留出人物座位区**」（椅子/桌前位置空出，桌面朝向镜头），
     中景构图，人物入画后占画面 1/3~1/2，环境细节可见
     （屏幕内容、桌面道具、咖啡杯、书架、窗外）。
  - 空实景、禁文字、禁主角本人；可有远景虚化背景人物。
- **提示词动作库（坐姿，全部原地）**：坐姿抬手比划 / 双手开合示意 /
  轻点桌面 / 手指向屏幕 / 侧身面向屏幕 / 微前倾强调 /
  重心后移放松 / 缓慢转身半面 / 双手比框 / 微笑认真思考。
  🔴 禁：站起、走动、大位移——会被 H3 放大成画面晃动。
  🔴 动作库里**没有任何头部动作**（无转头、低头、抬头、仰头、点头），也没有眼神描写。
- **穿搭贴合场景**：正式教程偏利落通勤、居家闲聊偏宽松舒适、
  咖啡厅偏轻便外搭（`--char-desc` 只写穿搭，面貌由四视图锁定）。

### L · 静立 / 倚靠

- **场景**：白板旁、操作台、书架旁、倚靠桌沿、马路边（户外同样成立，
  注意光线氛围统一）。
- **动作库（原地）**：静立手势、侧身、倚靠桌沿/墙、缓慢转身半面、
  **指向白板/看板/屏幕**形成讲解交互。
  🔴 禁大步走动；要"走"只写极缓单向位移且那是 T1 的拍。

### E · 无人物演示空镜

- **场景本身 = 内容演示**：屏幕界面特写、操作台过程、白板便签看板
  （选题/配图/排版/回复）、道具摆放、设备特写、手机屏。
- **不出人物**；运镜极缓推近 / 横移展示细节；标题卡照常压。
- **用途**：讲"界面长什么样""步骤怎么排""数据在哪看"——拍出来，别描述。
- **实现（标准路，稳）**：不走 H3 渲染，用**场景图 + 缓慢推拉**成段，
  再与数字人段拼接（省 GPU、无注入人物抽奖）：

  ```bash
  # 单张场景图 → 缓推片段（参数必须与成片一致：768×1280 / 24fps / yuv420p / h264）
  ffmpeg -loop 1 -i image/scene05.png \
    -vf "zoompan=z='min(zoom+0.0006,1.10)':d=<帧数=秒数*24>:s=768x1280:fps=24" \
    -t <时长> -c:v libx264 -pix_fmt yuv420p -r 24 -an _tmp/segE_05.mp4
  ```

  拼接时各段编码参数对齐（24fps / yuv420p；音频 aac 24000Hz stereo 静音），
  否则 concat demuxer 拒收。
- **备选路（待验证）**：`--seg-prompts` 对应段只写环境与运镜、明确
  「画面中不出现人物」。multiref 仍会传人物参考图，H3 是否服从未实测——
  用前先单段验证，不服从就回标准路。

## 场景图规范（在通用铁律上加两条）

- 🔴 **坐姿场景必须留座位区**：prompt 写明"留出人物座位/站位，人物入画后
  占画面约三分之一到一半"——不留座位，注入的人物会突兀地悬浮在环境里。
- 🔴 **演示空镜场景必须含可指认的视觉元素**（屏幕、看板、道具、设备），
  空镜不是风景空镜，是"内容演示位"。
- 其余同通用铁律：空实景、禁字、禁主角、按节拍语义配景、相邻段换景。

- 节拍 = 文案章节（非镜头）；长章节内部由多个 ≤9.42s 镜头循环组成。

- 标题卡 = 内容强调，字幕 = 语音正文，二者分离（见 07）。

## 跑法骨架（程序在技能 `scripts/`，项目只放数据）

```bash
# ① 场景图：dh_video.py 按 --scene-desc 逐张出图，**生成后自动取回 image/scene_NN.png**
#    （本地已有就跳过，--force 才覆盖）
#    scripts/gen_scenes.py 只产「场景↔节拍」映射 scene_rels.json，它不出图，别指望它取回

# ② 数字人段（S/L 拍）：合并模式 multiref；逐段提示词按形态写
#    （坐姿动作/静立动作；E 拍若走 multiref 备选路则该段只写环境——先单段验证）
python dh_video.py --project <项目> --audio-dir <项目> --mode multiref \
       --char-desc "年轻女子，米色针织衫配利落短发，淡妆，神态亲切自信" \
       --seg-prompts <项目>/seg_prompts.txt

# ③ E 段空镜：场景图 + zoompan 缓推成段（见上），与数字人段按分镜顺序拼接

# ④ 字幕：时长轴 → 调 fxai-lyric-subtitle → 烧录（见 07）
python scripts/make_subtitle.py --project <项目> --merged <项目>/合并_768x1280.mp4 \
       --audio-dir <项目>

# ⑤ 标题卡 + 封面 + 拼接（一条命令，别手写 ffmpeg）
#    finalize.py 内部：算 _beat_times.json → fxai-title-card 叠卡(可选) → gen_cover → stitch_cover
python scripts/finalize.py --project <项目>

# ⑥ 交付自检（缺项非零退出，全绿才算完）
python scripts/check_delivery.py --project <项目>
```

⚠️ **`dh_video.py` / `dh_pipeline.py` 只跑到第 ② 步（+字幕）**，产出 `成片_{W}x{H}.mp4`
是**中间成片**，不是交付物。没走 ⑤ 就没有标题卡和封面，等于半成品。
交付物只有一个名字：`成片_最终_{W}x{H}.mp4`。

⚠️ 重跑前先删旧 `口播音频.wav`（合并残留会被当成第 N+1 条源音频 → 成片翻倍）；
中途别 kill 渲染任务（ffmpeg 半截文件能胀到几十 GB 撑爆盘）。
E 段与数字人段拼接时统一 24fps / yuv420p，音频 aac 24000Hz stereo。
