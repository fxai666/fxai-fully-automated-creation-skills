# T1 · 实景中景口播（走动运镜式）

> **何时用**：抛观点 / 晒成果 / 营销向 / 快节奏干货——需要数字人"活着"、
> 动态强、贴近镜头讲话的片子。要坐下讲细节或空镜演示 → 换 **T2**。
> 参数 → `01-参数与命令.md`；场景硬规则 → `02-人物动作与场景图.md`；
> 字幕 → `07-字幕.md`；封面 → `05-封面.md`；通用铁律 → `06-模板库.md`。

## 形态

| 项 | 值 |
|---|---|
| 分辨率 | 竖屏 768×1280（横屏加 `--multiref-landscape`） |
| 模式 | `multiref`（人物注入空实景图，**中景小构图不占满全屏**） |
| 人物 | 头像库 `avatar/000.png`(女)/`001.png`(男) 四视图；提示词只写穿搭 |
| 场景 | N 张**实景空场景**（相邻段必换景），按节拍语义焦点配景 |
| 文字 | 场景图禁字；标题卡 PNG 后期叠加（排版规范见下「标题卡排版规范」，由 `fxai-title-card/scripts/gen_cards.py` 写死） |
| 字幕 | 调 `fxai-lyric-subtitle`（时长轴 / whisper，见 07） |
| 封面 | 写实封面（生图背景 + PIL 叠字，可含数字人本体），拼在片头 |

## 构图控制（中景小构图是本模板的签名）

每张场景图 prompt 写明「**中景构图，人物占画面左/右三分之一，腰部以上入画，
上方与对侧留白给真实环境**」——确保注入后数字人不占满全屏，真实环境始终可见。
`single` 人物画进场景会占满画面；本模板靠 multiref + 构图指令保证小构图。

🔴 **落位区无前景遮挡**：人物落位区身前禁任何家具/台面（桌面俯拍会让注入的
人沉进桌子里）；物件特写（手机屏/机箱/桌面）一律作空镜演示镜头，不注入人物。
白名单写法见 `02-人物动作与场景图.md`「人物落位区无前景遮挡」；护栏已自动
追加进场景提示词（`_SCENE_GUARD`）。

## 运镜与动作（走动式）

> 景别、机位角度、运镜、构图、光线的术语与档位 → `08-镜头语言.md`；本节只给本模板的取值。

从技能库**轮换**（第 i 段取 `i % len`，逐段不重样）：

- 运镜（生成层）：**固定中景 / 极缓推近**（仅此两类，改焦段不改机位角度，背景才稳）
- 动作（`SPEAK_ACTS` 13 条）：比划开合 / 侧身移半步 / 前倾轻点 / 转身半面 / 后移摊掌 /
  走近两步停住 / 轻点身侧物件 / 停顿一笑 / 抬手数数 / 双手比框 / 侧身示意 / 摊掌展示 /
  **场景内缓慢横移**（缓缓横向漂移，约一个身位；删掉「两步」离散短位移，会被当快步）
- 入场（`ENTRY_ACTS` 4 条，**只给第 0 段**）：外侧走入 / 后退半步打招呼 / 侧身转进 /
  **从远处走来（起幅全身 → 落幅腰以上）**
- 🔴 **动作库里没有任何头部动作**（无仰头、低头、抬头、点头），也没有眼神描写

🔴 **背景稳住（防闪烁跳跃）**：multiref 背景逐段重算，**生成层运镜只许固定机位或极缓推近**；
拉远 / 横移 / 摇 / 手持一律走后期 `scripts/camera_move.py`（`08-镜头语言.md` 4.4）。
细节与代码约束见 `02-人物动作与场景图.md`「背景稳住」节。

🔴 **入场必须有位移或朝向变化**：第 0 段不给入场动作，观众第一眼看到的就是站定念稿的人。

🔴 **"走"的边界**：位移写**极缓单向、慢、短、有明确终点**（走近两步停住 / 走到屏幕前停下），
**禁**「来回走动 / 走近又退回 / 横穿画面」——会被 H3 放大成画面晃动。横移要慢、要短、要写「全程持续移动」。

🔴 **头部与眼神一个字都不写**：不写点头节拍、不写仰头低头、不写「眼神看向镜头 / 目光与镜头交流」。
只保留「面向镜头」这一句朝向。写「动作幅度克制 / 原地不动」会把动作空间压没，
模型只剩头能动，整段退化成无规律连续点头（`08` 册 4.5）。

## 场景图规范

- 空实景、只写环境、禁文字、禁主角本人；可有远景虚化背景人物
  （办公室同事 / 咖啡馆对座，体现真实人际交互）。
- 按节拍语义配景：讲什么配什么（讲草稿箱配手机屏实景、讲成本配机箱特写）。
- 描述不够时叠加视角/光线/构图差异化修饰（`_SCENE_VARIANTS`），保证张张不同。
- 场景类型匹配题材基调（科技选题→科技场景，禁纯自然风景硬拗）。

## 分镜表（每拍一行，开跑前与文案逐句对齐）

| 节拍 | 对应口播句 | 实景场景（场景图描述） | 构图 | 标题卡文字 | 运镜/动作 |
|---|---|---|---|---|---|
| 1 | 口播01 | … | 中景坐/站（腰部以上），留白给环境 | 主标 + 副标 | 极缓推近 |
| … | … | … | … | … | … |

- 节拍 = 文案章节（非镜头）；长章节内部由多个 ≤9.42s 镜头循环组成。
- 标题卡 = 内容强调，字幕 = 语音正文，二者分离。

## 标题卡排版规范（已写死进 `fxai-title-card/scripts/gen_cards.py`，勿在项目里另写）

- 画布 768×1280 透明 RGBA，**纯文字叠加层、零渐变蒙版**（渐变只留给封面那截）。
- 🔴 **字号是固定档，不按画布比例算**：768×1280 属「小档」——主标 64（>7 字 54）、副标 36、
  引语 27、基线 y=80。1080×1920 属「中档」（主标 96、基线 120），`2560×1440` 大档、
  4K 超大档。四个档位全表见 `fxai-title-card/SKILL.md`「排版规范」或
  `fxai-title-card/references/01-排版与时间码.md` 第二节，改字号只改 `cardkit.TIERS`。
- 主标颜色：金 `(224,180,95)` + 深棕描边 `(45,33,14)`。
- 行距：查档位表的主→副 / 副→引语（小档 36 / 20），**不要目测**。
- 设计目标：三行尽量收拢、占屏越小越好，少遮挡画面显示区。
- 输入 `<项目>/image/cards.json`（`[{title,sub,foot,side?}]`，`side:"left"|"right"` 可钉死这一拍落哪侧），输出 `image/title_NN.png`。
- 🔴 **以上是竖版（9:16）的排法**。横版（16:9 / 4:3）改走**侧边竖排**（从上到下）**左右交替**：
  横版人物居中出镜，顶部一行横字正压脸上；一直贴同一侧又呆板。`finalize.py --card-position auto`
  （默认）按画幅自动选、横版逐张左右交替，不要手写 `top`。
  竖排参数见 `fxai-title-card/references/01-排版与时间码.md`「竖排」节。

## 跑法骨架（程序在技能 `scripts/`，项目只放数据）

```bash
# ① 场景映射：prompts 一行一条 → scene_rels.json
python scripts/gen_scenes.py --project <项目> --prompts scenes.txt \
       --scene-refs "dh_scene/000.png,dh_scene/001.png,..."

# ② 数字人视频：合并音频 multiref，竖屏（铁律见 06-模板库）
python dh_video.py --audio-dir <项目> --script <项目>/口播文案.md --out-dir <项目> \
       --mode multiref --role woman --no-charview \
       --char-desc "年轻女子，米色针织衫配利落短发，淡妆，神态亲切自信" \
       --scene-ref "dh_scene/000.png,..." --scene-desc "真实居家书房，...|..." \
       --name 口播

# ③ 字幕：时长轴 _words.txt → 调 fxai-lyric-subtitle 烧录
python scripts/make_subtitle.py --project <项目> --merged 合并_768x1280.mp4

# ④ 标题卡（排版规范写死在脚本里）→ 叠卡 + 拼封面 → 最终成片
python <fxai-title-card>/scripts/gen_cards.py --timeline <项目>/timeline.json --size 768x1280 --out <项目>/image
python scripts/finalize.py --project <项目>   # 叠卡(可选)+拼封面

# ⑤（可选）写实封面重出：背景 image/cover_bg.png + cover.json 文案
python scripts/gen_cover.py --project <项目>
```

⚠️ 重跑前先删旧 `口播音频.wav`（合并残留会被当成第 N+1 条源音频 → 成片翻倍）；
中途别 kill 渲染任务（ffmpeg 半截文件能胀到几十 GB 撑爆盘）；
dh_video 客户端默认 timeout=7200s 可能小于 multiref 长片渲染时长——超时退出后
服务端仍在渲（GPU 100% 为证），轮询 `/fxai/tasks/result` 取结果令牌再
`comfy_client._download` 取回 `合并_768x1280.mp4` 续跑 ③④ 即可，勿重渲。
