# ★ 口播人物动作：判据与词级禁写

人物整体可以动：走动、横移、走近走远、换重心，配手部动作与静态表情。
**动作落在位移与姿态变化上，固定小幅摆动不算动作。**
唯一锁死的是朝向 —— 口播只允许正面朝镜头。

## 四条判据

### 1. `motion` 部位白名单

`motion` 只准出现 **脚 / 腿 / 重心 / 手 / 臂 / 掌 / 指**。

⛔ 禁写部位：肩 / 胸 / 背 / 腰 / 颈 / 脖 / 上身 / 躯干 / 锁骨 / 脊椎 / 头。
这些部位在腰以上构图里一律被模型渲成头部动作：

| 禁写短语 | 渲成 |
|---|---|
| 上身前压 | 点头 |
| 上身后仰 | 仰头 |
| 肩线高低错开 | 歪头 |
| 肩头略收 | 缩脖 + 点头 |

例外白名单（`TORSO_OK`，静态且不含动作，属「手在哪儿」）：`肩背放松` / `双肩放松` /
`肩线平稳` / `胸口高度` / `胸前比` / `胸前摊` / `胸前收` / `胸前合` / `胸前划`。

对应 `preflight.py` 第 28 项 + `TORSO_PART` / `TORSO_OK`。

### 2. 头部动作与面部节拍

⛔ 词级禁写（`HEAD_ACT` / `FACE_BEAT`）：点头 / 抬头 / 低头 / 转头 / 回头 / 歪头 /
仰头 / 摇头 / 探头 / 扭头 / 侧头 / 颔首 / 表情灵动 / 随内容变化 / 自然切换 / 眼神闪烁。

✅ 允许项（`FACE_OK`，静态）：`面带微笑` / `表情认真` / `表情凝重` / `眼睛看向` /
`目光落在` / `看向镜头`。判据：**部位 + 静态状态**，不带动词性节拍。
眼珠的静态落点可以写；**头部怎么动一个字都不写**，交给模型。

### 3. 不写冻结词

⛔ `停住不动` / `定住` / `僵住` / `一动不动` —— 模型理解成整个人（含嘴）停止运动，
配上静态表情就是一张不开口的静止照片。

要表达动作收尾，只写**局部**的停：`脚步站定` / `手收回身前`。
对应 `preflight.py` 第 27 项（`FREEZE`）。

### 4. 讲话强度

每段提示词须同时含三项，缺一即被 `preflight ★9` 拦：

| 要素 | 判据 |
|---|---|
| 覆盖全段 | 明确「从第一个字到最后一个字」持续讲话 |
| 嘴部幅度 | 明确「明显开合」，而不是「同步」 |
| 逐字跟随 | 口型随 `<Audio 1>` 内容变化，语速与音频一致 |

⚠️ 只有「嘴唇与 <Audio 1> 精准同步开合」这一句强度不够 —— 它等于「对齐一下」，
配上静态表情，出片几乎不动嘴。走位镜最容易漏：`dh_video._tune_prompt` 会替换整段
`action_core`（目的是拿掉手势），讲话句必须跟着替换成强版。

## 走位三件套

**1. 走位配中全景。** 中景是头顶到腰以上，人物没有下半身，走位物理上不可见。
走位镜用中全景（头顶到大腿以上），中景留给手势镜。`preflight ★2` 拦。

**2. 不写离散量。** 离散量（两步 / 走过去 / 走近三步）被模型当成一次性快速小动作，
出来是快步。判据：位移须「连续、匀速、幅度 ≤ 一个身位、有明确终点」，
`preflight ★4` 拦「两步 / 走过去 / 来回 / 横穿」。

**3. 一镜一种主动作。** 走位与开放手势同时给，模型只给「小幅站位偏移」的中间解。
用 `kind` 区分：

| `kind` | 主任务 | 提示词拼法 |
|---|---|---|
| `"move"` | 走近 / 走远 / 左右横移（不转向） | 只给 `motion`，`action` 留空 |
| `"gesture"` | 原地解释手势 | `motion`（姿态）+ `action`（手势） |

`dh_video.build_seg_prompts` 按此拼提示词；`action` / `motion` / `expression`
三个字段都进提示词。

## 朝向锁死

口播是对着观众讲话。位移只有两种：沿纵深走近 / 走远，沿左右横移。

⛔ 词级禁写（`BODY_TURN`）：侧身 / 侧转 / 转身 / 转体 / 背对 / 背朝 / 面向屏幕 / 朝向屏幕。

三重拦截，任一处独立生效：

| 位置 | 作用 |
|---|---|
| `preflight.py` 第 25 项 | 分镜表体检，出片前必过 |
| `dh_video._strip_turn()` | 拼提示词时整句删带转向词的分句，删空则兜底成原地讲解 |
| `dh_video._AUDIT_BAD` | 渲染前对最终提示词再审一次 |

⚠️ 9~10 s 的段里长距离走位会被稀释成约 10% 画宽的横移。走位镜的价值是
「躯干有位移」，长距离走位需要 >15 s 或拆段。

## 动作与运镜库

逐段轮换，同一片里不得连续重复：

- `SPEAK_CAMERAS`（6 条）：固定中景 / 极缓推近 / 极缓推后停定 / 固定略偏侧前方 /
  极缓推到位保持 / 固定中景略偏一侧。全部只改焦段，不改机位角度。
- `SPEAK_ACTS`：单条中性规范（手随话语动、重心会换、脸朝镜头）。具体怎么演写在
  分镜 `motion` / `action`，不往代码里加动作库。
- `ENTRY_ACTS`（2 条，只给第 0 段）：从画面外侧走入 / 从画面深处走近。
第 i 段取 `i % len`；经 `av.build_ref2va_prompt(..., camera=, act_extra=, entry=)` 传入。

🔴 **入场必须有位移**：第 0 段不给入场动作，观众第一眼看到的就是站定念稿的人。
`entry` 只给第 0 段 —— 每段都写入场，每次硬切都像重新进一次门。

🔒 **整段是单个稳定镜头**：`build_ref2va_prompt` / `fl2va_body` 自动把
「镜头不摇晃、不做快速推拉」写进 `detailed_description`。这句只约束**镜头**，
人物幅度另给足 —— 人物幅度写小，模型能动的只剩头，整段退化成连续点头。

**位移要慢、短、有明确终点**；「来回走动 / 走近又退回 / 横穿画面」会被放大成画面晃动。

## 场景图数量规则（与 MV 同源的时间规则）

数量**只能由音频真实时长按时间规则算**（与 `fxai-mv-pipeline/produce_song.py` 同一套）：

| 时长 | 场景图张数（= H3 精确分段数 `seg`） |
|---|---|
| ≤ 120s | `seg`（每段一张，零重复） |
| > 120s | `seg // 2 + 1`（前面场景最多循环一次） |

再叠一条**口播专属下限**（`multiref` 强制，`single`/`multi` 不受此限）：

```
n_scenes = min(seg, max(2, 时间规则值))    # multiref
n_scenes = 时间规则值                       # single / multi
```

- 🔴 **多参考至少 2 个不同场景，上限 = 段数**。整条口播只有**同一个**场景时，段与段之间会感觉**跳帧**；换场景就自然顺畅。代码 `scene_count_for()` 已强制（`--scene-count` 给 1 也会被抬到 2，给超过段数会被截到段数）。
- 段数用 H3 精确公式算（`av.h3_segments`），`ceil(时长/10)` 估出来的段数偏少。
- 🔴 场景图**按所在段的语义焦点配景**（这一段讲什么画面方向就配什么）：如讲"整份文件提交"配文件堆叠 / 桌面工作台，讲"省 token"配数据仪表盘 / 流速光带，讲"路由分册"配目录树 / 索引卡；多段同主题可复用场景，相邻段换景。整篇定基调（如科技选题统一科技场景，见下条），逐段定焦点。
- **场景图只写环境**（场景/光线/氛围/构图），不写主体；可有背景人物（远景/虚化的听众、路人）；不出现文字或字幕。

## 🔴 人物落位区无前景遮挡（防「沉入家具」穿帮，白名单写法）

multiref 把人物**注入**场景图——如果镜头与人物落位区之间有家具/台面等前景物
（典型：桌面俯拍、前景是桌子/沙发背），注入后人物会被画成**沉进家具里**
（实测：咖啡馆桌面俯拍 → 人只剩头浮在桌面上方，身体全埋进桌子）。

**❌ 禁用写法（黑名单）**：
- 「前景遮挡形成层次」「前景是桌面/台面」「框架式构图透过门窗拍」等一切
  **在镜头与落位区之间放物体**的构图
- **「桌上有X」的桌面陈列句**（「桌上一台显示器一台笔电，旁边摊着两本厚手册」）：
  模型会先画出一整张桌子，为了拍清桌面物品必然俯拍，桌沿直接压到画面下半部。
  白名单里同时写了「家具放背景与两侧」也压不住——**具体陈列句的权重高于抽象约束**
- 「低机位仰视」（从桌面向上拍 → 人物必然在桌子后面）
- 「过肩视角」（场景图无人却写过肩 = 暗示前景有人形遮挡）
- 桌面/手机屏/机箱等**物件特写镜头给人物注入**——特写就是特写空镜（T2 式 E 镜头），
  人物镜头与物件特写**分开**，人物勿置于特写旁

**✅ 白名单写法（按此组织构图描述）**：
- 「画面中下部留出开阔的**人物落位区**，落位区身前无任何前景遮挡」
- **物品用「身后 / 两侧有什么」组织**：「身后是一排虚化的工位桌面与显示器，画面两侧有绿植与低矮隔断」；
  再补一句「**画面下半部是开阔的空地面**」——这一句比「留出落位区」更管用
- 家具一律放**背景与两侧**：「木桌在画面左侧靠后」「双屏显示器在人物身后两侧」
- 相机平视，机位用**离地高度**描述：「平视机位，镜头离地约 1.5 米水平朝前」
- 要层次感用**背景纵深**（「层次靠背景纵深，背景虚化」），不用前景遮挡

### 人体词会把「人」画出来

场景图要求**空景**，但描述里只要出现具体的人体词，模型就会补一个站在那里的人：

| ❌ 会画出人的写法 | ✅ 换成技术描述 |
|---|---|
| 「镜头高度与**站立人物**视线齐平」 | 「镜头离地约 1.5 米水平朝前」 |
| 「**人物站位**身前没有任何物体」 | 「地面与镜头之间没有任何物体」 |
| 「留出**坐姿**空间」 | 「画面下半部是开阔的空地面」 |

实测：「站立人物视线」这条一写，画面正中就多出一个背对镜头站着的男人——即使同一句里
写了「没有人物」也压不住。**机位高度用米数写，空间用「地面」写**，人物就不会被画进来。

**护栏已写死进代码**：`dh_video._SCENE_GUARD` 自动追加到每条场景提示词
（含 `--scene-desc` 的用户描述）；`_SCENE_VARIANTS` 差异化修饰词已全部换成
无遮挡安全写法。`--scene-ref` 用现成场景图时不经此护栏——**自己备图时按白名单自检**。

## 🔴 背景稳住（禁会重算背景的运镜，防「闪烁跳跃」）

multiref 把场景背景**逐段重算**生成。一旦该段运镜要求「平移 / 抬升 / 环绕」等
改变机位或视角，背景就被反复重算扭曲——表现为背景**突然闪烁、跳跃**（实测穿帮）。
H3 的 `stable_rule` 本就要求「镜头不摇晃、不来回推拉」，所以运镜只能落在两类：

- ✅ **固定机位**（首选）：镜头完全不动，只让人物做重心微移/手势，背景纹丝不动。
- ✅ **极缓推近**：幅度极小、速度极慢的缓慢推近，背景保持静止不重算。
- ❌ **禁用**：平移 / 后拉 / 低处抬升 / 环绕 / 任何改变机位角度或高低的运动——
  它们都会触发背景重算 → 闪烁跳跃。

⚠️ **场景图机位要一致**：多张场景图统一平视眼高，修饰词只变光影/景深/色调，
不改机位角度高低（代码 `_SCENE_VARIANTS` 已约束），否则相邻段切换也会"跳"。

**代码已约束**：`dh_video.SPEAK_CAMERAS` 逐段运镜库只含「固定 / 极缓推近」两类、
删除了原平移/抬升/环绕三条；`_SCENE_VARIANTS` 修饰词已禁改动机位角度。

🔴 **要真正的机位运动，走后期 `scripts/camera_move.py`**（拉远 / 横移 / 摇 / 手持），
它在成片像素上做变换，背景一次都不用重算，幅度与缓动完全可控。
**生成层锁机位 + 后期补运镜**是分工，不是二选一——细节见 `08-镜头语言.md` 4.4。

- 🔴 **数字人可与场景元素交互（非正对镜头念稿）**：场景可嵌入可指认的视觉元素（屏幕、白板、悬浮数据流、操作台），运镜与动作库含「指向场景元素 / 回望屏幕 / 轻点身侧物件」以形成讲解交互感；场景图仍只写环境、由 `char_rel` 注入人物。
- **场景图按整篇文案意境挑环境，不预设清单**：室内、室外、森林、小溪、大海、山顶、屋顶、
  街市、旷野……**任何地方都可以**，只要贴合内容、彼此不同、氛围统一。
- 🔴 **场景服务内容，实景优先**：先问「这一段讲的事发生在哪儿」，按那个地方的真实环境配景——
  办公室 / 工位 / 会议桌 / 操作台 / 车间 / 后厨 / 教室 / 诊室 / 店铺 / 直播间 / 户外，
  **任何行业、任何岗位都适用**，不预设题材清单。
  科技、AI、工具类选题同样落在**真实工作位**（桌面、屏幕、操作台、白板），
  屏幕内容虚焦不可读即可。**一个普通的真实办公室，胜过酷炫却没有真实感的特效空间。**
- 🔴 **同篇氛围统一、逐段换位置**：整篇定基调（都是现代办公 / 都是车间 / 都是居家），
  相邻段换具体位置（工位 → 白板 → 会议桌 → 操作台），各段机位眼高保持一致。
- 🔴 **场景里要有可指认、可操作的实物**（屏幕、白板、键盘、设备、道具、桌面物件）：
  人物才能指着讲、伸手操作、走近去看——**"实拍感"来自人物与环境发生关系**，
  纯空景只能让人物站着念稿。
  机制与 MV「歌词感知场景图」相同：有逐段语义线索时按**该段语义焦点**配景，无线索才用整篇意境兜底。有文案就追加
  `画面环境呼应全文意境：「…」，但只表现其中的环境意象…，保持空镜、不出现主体人物`；
  完全无线索才用中性兜底。给 `--scene-desc` 则按描述原样用。
- 描述不够时 `_scene_prompts()` 循环取用并叠加**视角/光线/构图差异化修饰**（`_SCENE_VARIANTS`），保证每张图真的不同——否则同场景跨段依旧跳帧。
- 场景图**不出现主角本人**（由 `char_rel` 注入，再出现会双人穿帮）；可有观众/路人等背景人物；不出现任何文字或字幕。

⚠️ **`single` / `multi` 画面偏静止**（H3 走 FL2VA 首尾帧 + 音频参考，动态主要靠音频驱动）。
4.2 秒 `single` 成片首/中/尾三帧几乎一致，人物只有极轻微呼吸感。
**要明显的运镜与动作，用 `multiref`**（逐段 Ref2VA 提示词，镜头语言写得进去）。
口播建议默认 `multiref`，长片一律走 `multiref`（`single` 只适合一镜到底的短片）。

## ★ multiref 生图 = 四视图人物 + 场景图（与 MV 同一规则）

| 图 | 规则 |
|---|---|
| **人物图（`<Picture 1>`）** | **四视图**（`gen_char_view(..., views=4)`）。提示词**只写穿搭**，面貌由参考图锁定（不写五官脸型）；参考图直接用全局头像库 `avatar/000.png`（`REF_WOMAN`）/`001.png`（`REF_MAN`），**不另存/重传** |
| **场景图（`<Picture 2>`…）** | **只写环境**（场景/光线/氛围/构图），不写主体——人物由 `char_rel` 注入，场景图带主体会重复/冲突（双人、错位）。可有**背景人物**（远景/虚化的听众、路人，不抢戏）；不出现文字或字幕。数量按上面的时间规则 |

- multiref **默认先生成四视图**再生成场景图；`--no-charview` 可跳过、直接用头像库作人物图。
- **穿搭（`--char-desc`）按口播内容设计**：讲什么题材、什么场合、什么季节就穿什么衣服
  （正式教程偏利落通勤、居家闲聊偏宽松舒适、户外题材偏轻便外搭）。没给则用
  `av.DEFAULT_CHAR_DESC` 兜底。
- `single` / `multi` 把人物画进场景图，**不需要四视图**。
- 四视图子目录 `dh_charview`、超时 `--charview-timeout`（默认 3600，队列拥堵时别调小）。
