# 06 · 模板库（数字人口播的形态选型）

> **何时读**：每次做口播视频**先读本册选模板**，再按模板跑管线。模板是「形态配方」——
> 同一个 `dh_video.py`，不同模板只是场景图、逐段提示词、标题卡、封面的组织方式不同。
> 参数怎么给 → `01-参数与命令.md`；场景图硬规则 → `02-人物动作与场景图.md`；
> 字幕 → `07-字幕.md`；封面 → `05-封面.md`。

## 🔴 实景拍摄总纲（所有模板共用，先读这一节）

数字人口播的底层不是「人物 + 一张背景图」，是**一段实拍**：人物在一个真实的地方，
真的在做事——坐着讲、抬手指向屏幕、伸手操作设备、起身走到白板前指着说、对着机台讲。

- 🔴 **场景是真实的地方，不是氛围素材**：先问「这一段讲的事发生在哪儿」，就配那个地方。
  办公室 / 工位 / 会议桌 / 操作台 / 车间 / 后厨 / 教室 / 诊室 / 店铺 / 直播间 / 车站 /
  体育馆 / 街边 / 车里 / 户外……**任何场所都成立，按内容设计，不限行业与岗位**。
- 🔴 **实景优先于氛围**：普通但真实的办公室，胜过酷炫却假的特效空间。
  屏幕内容虚焦不可读即可，不靠霓虹、光带、悬浮面板堆「科技感」。
- 🔴 **人物与环境发生关系**：场景里放可指认、可操作的实物（屏幕、白板、键盘、设备、道具），
  人物才有得指、有得看、有得动手。**这是「实拍」与「贴图」的分界。**
- **形态按节拍混排**：一条片子由多种镜头剪成，见下「镜头类型库」。

### 技术边界：走动幅度

H3 会把大幅位移放大成画面来回晃动，所以：

- ✅ 起身站定、极缓单向位移（走近半步）、原地换重心
- ❌ 大步走动、来回踱步、走远又走回

要「走动感」用**极缓单向位移 + 换场景**（切到另一个地方），不让人物在画面里长距离走。

## 镜头类型库（一条片子按内容选镜头，混着用）

> 景别、机位角度、运镜、构图、光线的完整术语与本技能能做到的档位 → `08-镜头语言.md`。
> 这一节只给「拍什么镜头」的选型表；**每一镜具体怎么设计（动作 / 景别 / 运镜 / 是否需要 B-roll）
> 由模型出分镜表，不由代码写死** → `09-分镜设计与验收.md`。

两类方向：**实拍镜头**（画面里有人，在真实地方做事）与**素材镜头**（画面里没有人物，
用画面本身交代内容）。两者在同一条片子里交替，才是剪辑的节奏。

| 代号 | 镜头 | 画面里有什么 | 怎么生成 | 什么时候用 |
|---|---|---|---|---|
| **S** | 坐姿实景 | 人物坐在真实工位/桌前讲，可抬手指向屏幕、轻点桌面 | multiref + 留座位区的场景图 | 讲步骤、讲细节、长段叙述 |
| **L** | 静立 / 倚靠 | 人物站在白板、设备、桌沿旁讲，可指物 | multiref + 留站位的场景图 | 讲结构、讲对比、指着东西说明 |
| **W** | 走动（T1） | 人物极缓位移、走近半步 | multiref + 走动场景图 | 抛观点、开场、段间转场 |
| **E** | 演示空镜 | 场景本身在演示：界面、操作台、看板，画面里没有人物 | 空场景图 + `make_material_seg.py --motion zoom-in` | 讲「界面长什么样」「步骤怎么排」 |
| **M** | 素材贴图 | 截图 / 图表 / 产品特写 / 对比图 | `scripts/make_material_seg.py`（数据类用 `--fit contain`） | 给证据、给数据、给对比、给参数 |
| **B** | 环境 B-roll | 真实环境一段：街景、车间运转、人流、窗外 | 实拍素材，或空场景图 + `make_material_seg.py --motion pan-left` | 过渡、呼吸、交代地点 |

E / M / B 三段共用 `make_material_seg.py`：一张静图 → 一段带运镜的静音视频，直接 concat。
运镜怎么选、`--fit` 怎么取 → `08-镜头语言.md` 第十二节。

**选镜头按内容，不按流程**：

- 说观点 → W / L
- 说步骤、说界面 → S + E
- 给数据、给对比、给证据 → M
- 换地点、换时间、给呼吸 → B
- 收尾 → S 或 L

⚠️ 一段口播可以只用一种镜头，也可以切成好几种；**切不切看内容有没有换**，
不是每句都切。切换点落在语义转折处，不落在句子中间。

## T 清单

| 模板 | 一句话 | 人物状态 | 适用 |
|---|---|---|---|
| **T1 · 实景中景口播** | 人物在实景里边走边讲、走近镜头，动态强、节奏快 | 走动/运镜 | 观点 / 营销 / 成果展示 / 快节奏干货 |
| **T2 · 静态实景口播** | 人物**静坐/静立/倚靠**融入实景讲解，或干脆不出镜、用场景本身演示内容 | 坐姿 / 静立 / 倚靠 / 无人物 | 讲解 / 教程 / 复盘 / 实操演示 / 叙事 |

**混用是常态**：一条片子里可以按节拍混用两种模板——走动讲观点（T1 式）→ 坐下讲细节
（T2 式）→ 空镜演示（T2 式）。分镜表里**每拍标注形态**（走 / 坐 / 立 / 空镜），
各拍按所属模板的规则出场景图与提示词即可，管线不变。

## 怎么选

| 内容长相 | 选 |
|---|---|
| 抛观点、晒成果、带情绪的营销向 | T1 |
| 讲步骤、讲界面、讲"怎么做" | T2（坐姿 S + 演示空镜 E） |
| 复盘 / 叙述 / 慢节奏聊天 | T2（坐姿 S / 静立 L） |
| 一边操作设备一边讲 | T2（S/L + E 空镜拍操作过程） |
| 拿不准 | 默认 T2——静态形态容错高，E 空镜还能省渲染 |

## 新增模板规范

做一个新形态 = 一份「配方」落成 `references/templates/TN-名字.md`，必须写清八件：

| # | 配方件 | 写什么 |
|---|---|---|
| 1 | 定位 | 一句话 + 与现有模板的分工 |
| 2 | 人物状态 | 走 / 坐 / 立 / 倚靠 / 无人物，及对应动作库 |
| 3 | 场景图规范 | 空实景怎么描述（坐姿要留座位区、演示要含可指认元素） |
| 4 | 构图 | 人物占画面比例、留白给谁 |
| 5 | 运镜 | 用技能库里哪几条、轮换规则 |
| 6 | 文字 | 标题卡怎么压、压什么（场景图本身禁字） |
| 7 | 封面 / 字幕 | 指向 `05-封面.md` / `07-字幕.md`，不重抄 |
| 8 | 跑法骨架 | `scripts/` 命令表（程序在技能，项目只放数据） |

写完在「T 清单」表加一行。

## 通用铁律（所有模板共用，模板册不重复）

1. 🔴 **竖屏 768×1280 默认**；横屏才加 `--multiref-landscape`（1280×768）。
2. 🔴 **模式默认 `multiref`**：人物由参考图注入空实景图，近景/中景小构图，
   **人物不占满全屏**；`single`/`multi` 画面偏静止，只适合一镜到底短片。
3. 🔴 **场景图 = 空实景**：只写环境（场景/光线/氛围/构图），**禁文字、禁主角本人**
   （人物由 `char_rel` 注入，再出现会双人穿帮）；可有远景虚化背景人物。
4. 🔴 **场景图按节拍语义焦点配景**，相邻段换景；整篇定基调、逐段定焦点。
5. 🔴 **人物图 = 四视图**，参考图用全局头像库 `avatar/000.png`(女)/`001.png`(男)，
   提示词只写穿搭，面貌由参考图锁定。
6. 🔴 **动作要换类型，不只换幅度**：位移 / 朝向 / 躯干俯仰 / 坐站轮着来（见 `02` 册动作库）；
   「来回走动 / 走近又退回」会被 H3 放大成画面晃动——位移写**慢、短、有明确终点**。
   **头部动作一律不写**（写了就变成一边说一边点头，`08` 册 4.5）。
7. 🔴 **机位运动走后期** `scripts/camera_move.py`（拉远 / 横移 / 摇 / 手持），
   生成层提示词只写固定 / 极缓推近（`08` 册 4.4）。
8. 🔴 **场景文字走后期叠加层**：标题卡 PNG 由独立技能 `fxai-title-card` 的 `gen_cards.py` 生成
   （得意黑主标 + Noto 副标，`06-字体白名单`；**字号用固定档表**，按短边分 小/中/大/超大四档，
   同档同字号、不做倍乘，见 `fxai-title-card/SKILL.md`「排版规范」——纯文字零渐变蒙版），
   按节拍时间码 composite；场景图本身不写字。
   **横版例外**：横版人物居中，顶部横排正压脸 → 走侧边**竖排**且**逐张左右交替**（`--card-position auto` 自动判），
   参数见 `fxai-title-card/references/01-排版与时间码.md`「竖排」节。
9. 🔴 **字幕必调 `fxai-lyric-subtitle`**，不自写 ASS/SRT 样式 → `07-字幕.md`。
10. 🔴 **封面走写实**（生图背景 + PIL 叠字），禁幻灯片口播那套纯色底 → `05-封面.md`。
11. 🔴 **固定程序实现放技能 `scripts/`，项目只放数据与产物**（场景 prompt 清单、
    标题卡 JSON、节拍时间码、文案、音频）；不把 `_*.py` 留在项目目录。
12. **产物落当前工作区 `<工作区>/<项目名>/`**，目录扁平，图片多才放 `image/`。
13. 已有段视频 / 场景图默认复用（`--force` 才重跑），中断重跑不重复烧 GPU。
