# 05 · 封面（设计规范 + 出图执行）

封面 = 成片片头的静态帧，平台抓首帧当首页缩略图。本册只定封面「怎么设计」，
`scripts/gen_cover.py` 是它的执行体；两者不一致时以本册为准，改脚本对齐。

🔴 **封面段占多长、音轨怎么垫，不在本册规定**，统一见
`fxai-poster/references/05-封面模板库.md`「封面段时长」。本册不重复、不覆盖。

## 一、术语：封面读不清，设计上叫什么

| 现象 | 设计术语 | 判据 |
|---|---|---|
| 浅色字压在浅色背景上读不出 | **明度对比不足**（Value Contrast Failure） | 字色与底色明度比 < 2.6 |
| 文字浮不出背景、像陷进去 | **图底分离失效**（Figure–Ground Separation Failure） | 眯眼测试时字形边界消失 |
| 缩略图上一整行糊掉 | **缩略图可辨性不足**（Thumbnail Legibility） | 300px 宽时字高 < 11px |
| 几级字互相抢、没有主次 | **视觉层次坍塌**（Visual Hierarchy Collapse） | 相邻层级字号比 < 1.25 |
| 文字被平台裁掉一半 | **安全区不足**（Safe Area Violation） | 文字距边 < 6% 画布宽 |

🔴 **决定可读性的是明度对比，不是色相对比**。金色（`#EEC470`）与白色在色相上差得远，
但在明度上很接近——缩略图转灰度后两者一起消失。靠「换个颜色」救不回可读性，
只能靠**拉开明度差**（压暗底、加描边、加晕影）。

### 四层可读性手段（专业名 → 本技能实现）

| 手段 | 专业名 | 本技能做法 |
|---|---|---|
| 局部压暗 | **Scrim**（影视减光层 / Gradient Scrim） | 圆角矩形 + 高斯羽化，峰值 alpha 中部 146 / 底部 172，羽化 46px |
| 描边 | **Keyline**（字形轮廓线） | 标题 6 / 副标 4 / 引语 3 / 品牌 5 px，色 `#1A1206` |
| 晕影 | **Halo / Drop Shadow** | 文字 mask 膨胀模糊（半径 ≈ 字号×0.22），叠黑 alpha .88~.95 |
| 字号阶梯 | **Type Scale** | 92 / 40 / 31 / 56 / 31 / 32 px |

四层缺一不可：只压暗不描边，缩小时边缘被背景吃掉；只描边不压暗，字周围一圈亮底反光。

### 验收方法：缩略图测试（Thumbnail Test）

**Squint Test（眯眼测试）**的等价做法：把成品缩到 **300px 宽**看一遍。
眯眼会丢掉高频细节，只剩明度块——缩略图上一眼是否读得出层级，就是这个测试要的答案。
放大看永远没问题，所以这一步不可省。

## 二、封面背景图：主题氛围图，不是场景图

🔴 **两张图是两种东西，不得互相顶替**：

| | 场景图 `image/scene_NN.png` | 封面背景 `image/cover_bg.png` |
|---|---|---|
| 用途 | 数字人站立的环境 | 封面的底 |
| 前景 | 必须是**空地面**，给人物落位 | 必须**摆足主题实物**（封面上没有人物，实物就是内容本身） |
| 明暗 | 均匀自然光，无硬阴影 | 中下部有质感，四周自然偏暗 |
| 数量 | 每段一张 | 一条片子一张 |

拿场景图当封面背景 = 一张空房间配一堆字，观众看不出这条片子讲什么。

### 从文案里提三样东西再写提示词

1. **场景**：这件事发生在哪（工作台 / 车间 / 直播间 / 教室 / 机房）。
2. **身份**：谁在做、用什么做（一个人、一台电脑、几本手册、一叠打印纸）。
3. **情绪落点**：什么感觉（深夜赶工 / 桌面摊开 / 刚跑完 / 一团乱线）。

三样都落进提示词，背景才和内容咬得上。只写「温馨办公室」「高级感桌面」这类形容词，
出的是通用图库照，与选题无关。

### 明暗分布：给文字留「可压的底」

- 用**光源位置**制造明暗：一盏台灯从侧后打光、窗光从远处进来，画面四周自然变暗。
- 中下部放 1~2 件有质感的实物（桌面、手册、键盘），忌满铺、忌对称陈列。
- 🔴 提示词里**不得**写「顶部明亮」「留出深色空间」这类构图指令——出图会变成一块死黑，
  压暗层救不回来，也难看。明暗要来自场景本身。

### 提示词结构

`[场景] + [主体实物及位置] + [光源与明暗] + [摄影质感]`，末尾由脚本自动补硬约束
（竖构图、无人物、无可读文字、无 logo、无二维码）。

## 三、封面文案：按标题设计师的标准写

封面文案不是标题的缩写版，是**标题的补充**。标题给结论，封面给场景、数字或反差。

### 五级文案的分工

| 层级 | 位置 | 承担什么 | 字数 | 参考 |
|---|---|---|---|---|
| 胶囊 `pill` | 顶部 | **内容属性**：观点 / 干货 / 避坑 / 拆解 / 结论 | 4~8 | 干货 · 拆解 |
| 主文案 `title` | 中部 | **钩子**：具体数字 + 具体结果 | 8~14 | 三十个技能，一个人干完 |
| 副标 `sub` | 主文案下 | 把钩子**具体化**，不复述 | 10~16 | 从写稿到成片，我只提需求 |
| 证据行 `foot` | 副标下 | 一个**可核对**的数字 | 10~18 | 113 个脚本 · 131 册手册 |
| 品牌 `brand` / `brand_sub` | 底部 | 品牌名 + 账号定位 | — | 凤希AI / 公众号自动化运营 |

### 六条判据（同时过）

1. **主文案含一个具体数字**，且数字落在前半句。
2. **主文案给结果，不给过程**：读者要的是「干完了什么」，不是「怎么干的」。
3. **副标是补充不是复述**：与主文案的重合字不得过半，重复即删。
4. **主文案 8~14 字**，一行或对折两行，不出现第三行。
5. **证据行的数字必须在正文里出现过**，不得编造或四舍五入成整数。
6. **胶囊写内容属性，不写口号**：「AI 全自动创作」是口号，「干货 · 拆解」才是属性。

### 公式（一条封面只用一个主公式）

| 公式 | 结构 | 适用 |
|---|---|---|
| 数字清单 | 「三十个技能，一个人干完」 | 报家底、拆解类 |
| 结果前置 | 「我把流水线交给机器之后」 | 亲历叙事 |
| 痛点 + 解法 | 「装环境装到崩？先看这个」 | 教程、避坑 |
| 身份代入 | 「一个人，也能天天出片」 | 目标读者明确时 |
| 场景提问 | 「每天三小时，够做什么」 | 互动类 |

## 四、版式参数（768×1280 基准）

| 项 | 值 |
|---|---|
| 胶囊 | 32px，离顶 88px，实心琥珀底 + 深色字 |
| 大标题 | 得意黑，最大 92px；单行能排到 ≥76px 就用单行，否则按「较长一行最短」对折两行 |
| 副标 | Noto Sans SC Medium 40px |
| 引语 / 证据行 | Noto Sans SC 31px |
| 品牌 | 得意黑 56px，y=1112 |
| 品牌副标 | Noto Sans SC Medium 31px，y=1196 |
| 中部文字块 | 按整体高度**居中**在 y≈486，标题行数变化时自动让位 |
| 整图压暗 | ×0.88，只压这一层 |

字体白名单见 `fxai-standard/references/06-字体与素材授权.md`。

## 五、出图、自检与验收

1. **背景**：`gen_cover.py --bg-prompt "<按第二节写的提示词>"`。已有 `cover_bg.png` 时复用，
   要重出加 `--force-bg`。背景缓存不重生图。
2. **文案**：项目根 `cover.json`（六字段），缺省走 `gen_cover.DEFAULTS`。
3. **叠字**：`gen_cover.py --project <项目>`。版式参数集中在脚本顶部
   `# ── 版式参数 ──` 一段，调封面只改那一段。
4. **机械自检**：脚本叠字前量出每行字底下的背景明度，与字色算明度比，
   低于 `CONTRAST_MIN=2.6` 打 ⚠️ 并点名是哪一级。自检挡住的是必然翻车的组合，
   不保证好看，第 5 步照做。
5. **缩略图验收**：缩到 300px 宽，六级字（胶囊 / 主文案 / 副标 / 证据行 / 品牌 / 品牌副标）
   全都要认得出。有任意一级糊掉，调那一级的字号或晕影，**不得靠整体加黑解决**。

## 七、禁做项

- ❌ 封面用幻灯片那套纯色底 + 大字（与实时视频画面割裂）
- ❌ 浅色背景上放无描边的浅色字（缩到 300px 整行消失）
- ❌ 只靠整体加黑救可读性（压成黑块，画面全废）
- ❌ 拿空场景图当封面背景（封面上没有人物，空房间等于没有信息）
- ❌ 封面文案复述标题（两级文案说同一件事，白占一层）
- ❌ 生图提示词里写文字 / 写「留出深色空间」「顶部明亮」类构图指令
- ❌ 封面塞装饰图 / 人物特写 / 太多字（稀释冲击力）
- ❌ 用 conda 自带 ffmpeg（无 libass，统一走 `av.ffmpeg_libass()` 防错）
- ❌ 封面出现网址 / 微信号 / 二维码等任何联系方式或外链。品牌块**只写品牌名**
