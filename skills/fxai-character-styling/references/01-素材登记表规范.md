# 01 · 素材登记表规范

> 何时读：定字段含义、套系划分、三级目录命名、登记规则时。

## 一句话

一张 `data/assets.csv`，一行为一条素材（姿势或服装），机读；图片本体不进技能，表里只存**相对路径**。

## 字段（表头固定，顺序不可改）

| 列 | 含义 | 取值/填写规范 |
|---|---|---|
| `id` | 稳定唯一键 | `pose_P001_front` / `cost_SPR-0001`，登记后不改 |
| `类型` | 素材大类 | `姿势` / `服装`（人物不在这里，走角色库） |
| `套系` | 内容分级/知识套系 | `SFW` / `NSFW`；也可填自定义套系名（如 `日常`、`二次元`），分级仍以是否含 NSFW 为准 |
| `一级分类` | 目录第 1 层 | 姿势：`上半身单人`/`全身单人`/`双人`；服装：`春季穿搭`/`泳装`… |
| `二级分类` | 目录第 2 层 | 姿势：`可爱系`/`性感系`/`站姿`；服装：`连衣裙`/`上衣`…（无则留空） |
| `三级分类` | 目录第 3 层 | 更细的子目录（无则留空） |
| `名称` | 姿势名或服装名 | `仰卧V字开腿` / `象牙白荷叶边针织衫…` |
| `标签` | 空格分隔关键词 | 姿势填角度别名；服装填单品/颜色（对应原 `标签`+`英文关键词`） |
| `角度` | 仅姿势用 | `正面`/`斜侧`/`侧面`/`俯视`/`仰视`；服装留空 |
| `图片` | **相对路径（接口核心）** | `../../img/xxx.webp` 或自定义库相对路径；下游按此原样取用 |
| `来源` | 出处 | `ギア/@giaaibusi` / `たきAI/CharaDB` / `自建` |
| `备注` | 授权或其他 | `仅供学习创作·禁商用` / 自定义说明 |

## 套系划分（硬口径）

- **`SFW`**：日常/标准/可爱系等，默认可见。
- **`NSFW`**：成人向素体姿势、性感/内衣穿搭、双人缠绵等。默认隐藏，必须显式 `--套系 NSFW` 才检索得到。
- 自定义套系名：允许在 `套系` 填专属名字做知识分组，但只要内容属成人向就归 NSFW 门禁，不因改名而绕过。

## 三级目录规则

- 目录层级 ↔ 分类列一一对应：`根/<一级>/<二级>/<三级>/图片文件`。
- 有几级填几级，没有的层级留空字符串；`scan` 按真实目录深度自动填。
- 选择时逐层过滤：`pick` 先选类型 → 套系 → 一级 → 二级 → 三级 → 具体条目，多一层就多问一层（接口不变，只是多一次筛选）。
- `图片` 存相对路径，基准是数据目录（`data/`）或环境变量 `FXAI_POSE_COSTUME_DATA` 指定根；跨机器可移植。

## 登记规则

1. `add`：手工登记单条；`id` 不重复，重复则报错（不覆盖）。
2. `scan`：扫目录树批量生成草稿，按目录深度填分类、`名称` 取文件名、路径自动生成；**默认先出草稿不落表**，确认后再写。
3. `check`：校验 `图片` 相对路径指向的文件是否存在、套系是否标注、必填列是否空。
4. 只登记、不搬图、不转码、不删除（与 `fxai-asset-registry` 同口径）。

## 合规边界（登记时写进来源/备注）

- 第三方图（ギア / CharaDB）只作创作参考，禁商用、禁打包分发、禁再分发；NSFW 禁未成年人。
- 本表与技能包随公共镜像发出去 = 只发文字索引，不构成图片分发。
- 自建素材（作者本人）可自由标注用途。
