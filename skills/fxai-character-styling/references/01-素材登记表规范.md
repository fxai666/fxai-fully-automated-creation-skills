# 01 · 素材登记表规范

> 何时读：定字段含义、多级子目录命名、登记规则时。

## 一句话

一张 `data/assets.csv`，一行为一条素材（姿势或服装），机读；图片本体不进技能，表里只存**相对路径**。

## 定位：本技能是纯壳

本技能只提供「选素材 → 构建提示词 → 出图」的壳与索引能力。素材内容由使用者自行决定：放什么姿势、什么服装、什么参考图，本技能一律不判定、不区分。使用者自建任意子文件夹，技能按目录层级索引，选完把路径交给出图客户端。

## 字段（表头固定，顺序不可改）

| 列 | 含义 | 取值/填写规范 |
|---|---|---|
| `id` | 稳定唯一键 | `pose_P001_front` / `cost_SPR-0001`，登记后不改 |
| `类型` | 素材大类 | `姿势` / `服装`（人物不在这里，走角色库）；使用者可自定义大类 |
| `一级分类` | 目录第 1 层 | 使用者自建子目录名，原样索引 |
| `二级分类` | 目录第 2 层 | 使用者自建子目录名，原样索引（无则留空） |
| `三级分类` | 目录第 3 层 | 更细的子目录（无则留空；更深层级折叠进此列） |
| `名称` | 姿势名或服装名 | 取文件名或自定义 |
| `标签` | 空格分隔关键词 | 自由填写，供 `find` 检索 |
| `角度` | 姿势用 | `正面`/`斜侧`/`侧面`/`俯视`/`仰视`；其它留空 |
| `图片` | **相对路径（接口核心）** | 相对路径；下游按此原样取用 |
| `来源` | 出处 | 自由填写，如作者/站点/自建 |
| `备注` | 说明 | 自定义 |

## 多级子目录规则

- 目录层级 ↔ 分类列一一对应：`根/<一级>/<二级>/<三级>/图片文件`。
- 使用者可自建任意子文件夹、任意层级；`scan` 按真实目录深度自动填列，超过三级的深层目录折叠进 `三级分类`，路径列始终指向真实文件。
- 有几级填几级，没有的层级留空字符串。
- 选择时逐层过滤：`pick` 先选类型 → 一级 → 二级 → 三级 → 具体条目，多一层就多问一层（接口不变，只是多一次筛选）。
- `图片` 存相对路径，基准是数据目录（`data/`）或环境变量 `FXAI_CHARACTER_STYLING_DATA` 指定根；跨机器可移植。

## 登记规则

1. `add`：手工登记单条；`id` 不重复，重复则报错（不覆盖）。
2. `scan`：扫目录树批量生成草稿，按目录深度填分类、`名称` 取文件名、路径自动生成；默认先出草稿不落表，确认后再写。
3. `check`：校验 `图片` 相对路径指向的文件是否存在、必填列是否空。
4. 只登记、不搬图、不转码、不删除（与 `fxai-asset-registry` 同口径）。

## 来源与交付

- 素材版权归各自权利人；登记表只记路径，本技能对素材内容不作判定。
- 本表与技能包随公共镜像发出去 = 只发文字索引，不构成图片分发。
