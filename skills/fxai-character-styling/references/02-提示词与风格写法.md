# 02 · 提示词与风格写法

> 何时读：改提示词构建逻辑、加减风格预设、核对与仓库原文一致性时。

## 唯一真相源

`repo/src/services/aiGenerator.ts` 的 `buildRecipePrompt()` 与 `STYLE_PRESETS`（只读不改）。
本技能 `scripts/prompt_builder.py` 与 `data/styles.json` 是它的 Python 逐字对应实现。

## 硬规矩（照抄，不自行发挥）

1. **不写穿搭文字**：服装靠服装参考图，名称只在括号作辅助说明。原始人物图本身可能已带穿搭，写文字会搞错。
2. **图序动态**：按实际传入顺序生成「图1/图2/图3…」，人物 / 服装 / 姿势逐一对应。
3. **肤色统一**：`人物的肤色必须与图一人物一致，所有裸露皮肤（包括服装镂空处露出的皮肤）必须与脸部肤色统一`。
4. **姿势只参考动作**：`仅参考姿势与构图，不复制...外观与服装`；最终人物是真人、皮肤真实自然（照片类风格）。
5. **风格句 + 收尾**：风格预设句后接「人物比例协调，手部与五官自然，光影统一。」，末尾固定「画面中没有任何文字、标志或水印。」

## 风格预设

`data/styles.json` 收录仓库全部 12 档：none / realistic / fashion / film / semi_real / anime / cel_anime / manga / render3d / chibi_box / cyberpunk / concept_sheet。
PHOTO_STYLES = {realistic, fashion, film} —— 这三档走「真人、皮肤真实自然」措辞，其余走「肤色与质感按风格要求呈现」。

## 本地补丁（明确标记，非仓库原文）

- `extra_scene`（`--场景`）：官方模板无场景条款；仰卧/坐卧类姿势会缺承托（悬空/倒立），补一行**仅环境、不含动作词**的场景。默认关闭，用户认可才传。
- 构图/可见性条款（如低机位仰视+部位清晰可见）若加，必须配套「镜头拉远全身入画、解剖比例正常、无广角畸变、无肢体变形」，否则低机位易透视爆炸（踩过 P080 大腿巨柱化）。

## 一致性自检

改完 `prompt_builder.py` 后，对照原文逐条核：图序索引、条件分支（upload/library）、faceless 分支、PHOTO_STYLES 措辞、风格句、收尾句。
