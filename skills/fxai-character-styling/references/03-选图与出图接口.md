# 03 · 选图与出图接口

> 何时读：选人/选服装/选姿势、调工作流、路径传参、SFW 门禁时。

## 三选一流程

1. **人物**：走 `fxai-role-management` 角色库（`scripts/role_mgr.py list / get`），取角色头像路径，作为图1。本技能不生成人物。
2. **服装**：`select.py pick/find --类型 服装` → 得到 `图片` 相对路径，作为图2。
3. **姿势**：`select.py pick/find --类型 姿势` → 得到 `图片` 相对路径，作为图3。
   `pick` 逐层过滤：一级 → 二级 → 三级 → 名称；多一层目录就多问一层（接口不变，只多一次筛选）。

## 套系门禁（硬口径）

- 默认 `--套系 SFW`，只出日常/标准/可爱系。
- NSFW（成人向素体姿势、性感/内衣穿搭、双人缠绵）必须显式 `--套系 NSFW` 才检索得到。
- 满 18 才呈现着装性感；未成年相关、全裸、幼态脸×性感 —— 一律不做。

## 路径传参（接口不变）

- 登记表 `图片` 列存相对路径（基准 = 数据目录或 `FXAI_POSE_COSTUME_DATA`）。
- `select.py path <id>` 原样输出该路径；`--resolve` 才转绝对路径。
- 三图按「**图1人物 / 图2服装 / 图3姿势**」顺序拼进 `fxai_imageinput`（逗号分隔），与提示词的图序严格对齐。

## 出图（本技能 API 客户端）

- 入口：`scripts/styling_api.py generate_styling(...)` 或 `python styling_api.py --人物 ... --服装 ... --姿势 ...`。
- 链路：三图各自 `upload_image` → 服务端相对路径 → 拼 `fxai_imageinput` → `submit_workflow` → 下载。提交/轮询/下载全委托 `fxai-workflow/comfy_client.py`。
- 工作流：`fxai-workflow` 注册表 `charstyling` → `qwen21` → `charstyling-qwen21-api.json`（UI/API 版在 ComfyUI `凤希AI/角色造型合成V1*.json`）。
- 提示词：必须由 `prompt_builder.build_recipe_prompt()` 生成，零穿搭文字（服装名称只在括号辅助）。
- 尺寸：本机默认 960 档，不自行抬档（用户硬规则）。
- 本机 8188 探不通 → 报错让人启动，不自行拉起 ComfyUI。
- `--dry-run` 只构建提示词与参数，不提交；去掉它才真提交。
- `compose.py` 仍是纯编排（只组织、不内嵌生图）；真出图走 `styling_api.py`。

## 产物落点

生成图按项目方式落 `<项目空间>/图片/<项目名>/`；中间与草稿只进 `_tmp/`。
