# fxai-title-card · 标题卡（给任何视频叠文字）

把一个视频 + 一份「什么时候显示什么字」的清单，压成一条带标题卡的视频。
**它不关心视频是谁做的**，只认两样东西：视频文件、时间码+文字。

**两种排法，按画幅自动选**（`--position auto`，默认）：

| 画幅 | 排法 | 为什么 |
|---|---|---|
| 竖版 9:16 | 画面**顶部横排**（原有） | 人物通常在画面中上部，顶部一条不挡人 |
| 横版 16:9 / 4:3 | 画面**左侧或右侧竖排**（从上到下） | 横版人物居中出镜，顶部一行横字正压脸上；竖排只占一侧窄条，中间全留给人 |

半透明形状的信息贴片（气泡/胶囊/方块，任意位置动态进出）是**另一个技能** `fxai-infocard`，
本技能只管纯文字标题卡。

## 三件事别混

| | 位置 | 跟什么走 | 谁做 |
|---|---|---|---|
| **字幕**（subtitle） | 画面底部 | 跟语音逐句，一句一个窗口 | `fxai-lyric-subtitle` |
| **标题卡**（title card） | 竖版顶部横排 / 横版左右侧边竖排 | 跟节拍/时间段，一段一张 | **本技能** |
| **信息贴片**（infocard） | 画面任意位置 | 跟讲解节奏，一条一出现 | `fxai-infocard` |
| **封面**（cover） | 片头静态帧 | 不跟时间 | `fxai-poster` |

标题卡是**内容强调**（提炼这一拍讲什么），字幕是**语音正文**（把话写出来）。
信息贴片是**另外写的辅助补充**（半透明形状，任意位置动态进出）。三者可以并存。

## 什么时候叠、什么时候不叠

- ✅ 要叠：讲解 / 教程 / 复盘 / 清单 / 观点分点 —— 观众需要"现在讲到哪了"的路标。
- ⛔ 不叠：纯情绪短片、MV、画面本身已经全是字的（界面录屏），
  以及客户明确要求干净画面的。**叠不叠是可选步骤，不是每条片子必做。**

## 数据结构（一个文件说清全部）

`timeline.json` —— 时间码和文字合一，最省事：

```json
{
  "total": 114.0,
  "beats": [
    {"i": 1, "start": 0.0,  "end": 6.2,  "title": "三十个技能", "sub": "每一个都是自己趟出来的", "foot": ""},
    {"i": 2, "start": 6.2,  "end": 12.8, "title": "两年前",     "sub": "找写稿、找配音、找剪辑", "foot": ""}
  ]
}
```

- `start` / `end` 单位秒，浮点；`end` 必须 > `start`。
- `title` 主标（金色得意黑，**≤7 字最好**）；`sub` 副标（白色 Noto，一句话）；
  `foot` 引语（可选，浅灰小字）。`foot` 留空就不画。
- 想隔一段不显示？那一拍 `title`/`sub` 都留空即可（脚本会跳过，不压空卡）。

**兼容分离式**（老项目把文字和时间码分开存的）：`--cards cards.json` + `--beats _beat_times.json`，
脚本按序合并。`cards.json` = `[{"title","sub","foot"}, …]`。

## 三个命令

```bash
# ① 只有音频 + 文字，没有时间码 → 从音频段时长算（一段音频 = 一拍）
python scripts/make_timeline.py --audio-dir <音频目录> --cards <cards.json> --out timeline.json

# ② 文字 → 透明 PNG（一卡一张，尺寸跟随目标视频）
python scripts/gen_cards.py --timeline timeline.json --size 768x1280 --out <titles目录>

# ③ 叠到视频上（不拼封面、不动音频）
python scripts/overlay_cards.py --video <任意视频.mp4> --titles-dir <titles目录> \
       --timeline timeline.json --out <输出.mp4>
```

一条龙（② + ③）：

```bash
python scripts/title_card.py --video in.mp4 --timeline timeline.json --out out.mp4
```

- `--size` 不传时由 `gen_cards.py` 从 `--timeline` 推断不了，**必须给**；
  用 `overlay_cards.py` 时它会自己 ffprobe 视频尺寸，不匹配会提示。
- `--position`：`auto`（默认）| `alternate` | `top` | `center` | `bottom` | `left` | `right`。
  - `auto`（= `alternate`）：**竖版（含方形）→ `top` 横排；横版 → 左右交替竖排**
    （第 1 张右、第 2 张左、第 3 张右……）。不用想，直接默认——一直贴同一侧看久了呆板。
  - `left` / `right`：整条片**钉死一侧**竖排（从上到下）。人物明显偏某一侧时才用：
    人物偏右→`left`，人物偏左→`right`。
  - 单拍想钉死某一侧：那一拍的 timeline 里写 `"side": "left"` 或 `"right"`（人物正好站那侧时让开）。
  - `bottom` 会避开底部字幕区（留 260px 基准）。
- 输出保持原视频的分辨率/帧率/音轨（`-c:a copy`），只重编码视频。

**横版人物出镜默认就是对的**，别手动写 `--position top`——那正是压在脸上的那个。

## 排版规范（已写死进脚本，别在项目里另调）

> 完整参数、三种时间码来源、5 个常见坑 → `references/01-排版与时间码.md`

- **字号是固定档，不按画布比例算**：按**短边**分 4 档，同一档内所有分辨率**同一个字号**
  （768×1280、720×1280、1280×720 都是小档主标 64；1080×1920、1920×1080 都是中档主标 96）。
  改字号只改 `cardkit.TIERS` 那张表。

| 档 | 短边 | 主标 | 主标长(>7字) | 副标 | 竖排副标 | 引语 | 描边 | 顶部基线 | 侧边距 |
|---|---|---|---|---|---|---|---|---|---|
| 小 | ≤800 | 64 | 54 | 36 | 44 | 27 | 4 | 80 | 96 |
| 中 | ≤1200 | 96 | 80 | 54 | 66 | 40 | 6 | 120 | 144 |
| 大 | ≤1800 | 128 | 106 | 72 | 88 | 54 | 8 | 160 | 192 |
| 超大 | >1800 | 192 | 160 | 108 | 132 | 80 | 12 | 240 | 288 |

- 主标：**得意黑 SmileySans-Oblique**，金色 `(224,180,95)` + 深棕描边 `(45,33,14)`。
- 副标：**Noto Sans SC Bold** 纯白（竖排时字号更大 + 一层极淡深色描边，浅背景才看得见）。
- 引语：**Noto Sans SC** `(235,235,235,220)`。
- **横排**（竖版片）：主标基线 = 档位的顶部基线；三行尽量收拢，**占屏越小越好**。
- **竖排**（横版片）：贴边 = 档位的侧边距、主标贴边最外侧，副标/引语依次向内并**低一截**；
  一列最多 9 字（主标）/ 8 字（副标引语），超了按**标点优先**分列，块整体在安全区垂直居中。
- **纯文字零蒙版**：标题卡只承载文字，不画渐变底（渐变蒙版只属于封面）。
- 字体白名单见 `fxai-standard/references/06-字体与素材授权.md`（得意黑 OFL / Noto Sans SC OFL）。

## 铁律

1. 🔴 **标题卡是可选步骤**：不需要顶部字就不做，别为了"流程完整"硬压。
2. 🔴 **一张卡一个时间段**：`end` 必须 > `start`，相邻卡不重叠（重叠会叠成一坨）。
3. 🔴 **不压空卡**：`title`/`sub` 全空的拍直接跳过。
4. 🔴 **不动音频、不拼封面**：本技能只改视频画面。封面与音轨拼接是产线自己的事。
5. 🔴 **任意视频都能用**：不假设项目结构、不假设有 `image/` 目录；只认 `--video` + `--timeline`。
6. 🔴 **字体只走白名单**，不塞系统里随便一款。
7. 🔴 **横版别在顶部横排**：人物出镜（口播、访谈、站播）时顶部横字正压脸，
   一律走侧边竖排（`auto` 已默认）；只有在画面顶部确实空着（纯景、纯界面）时才显式 `--position top`。
8. 🔴 **竖排主标 ≤9 字**：一列放不下会分列，分列是按格子断的（"一个人做完一 / 条片的全流程"），
   读着别扭。写的时候就压到 9 字内，最好 7 字内；副标 ≤16 字（两列以内）。
