## 五、单集分镜脚本骨架（每集 10 镜 × 6-8s ≈ 65-70s）

头部信息块 + 10 个镜头块 + 资产清单 + 本集技术注意：

```markdown
# 《剧名》第N集 · 集名（完整分镜脚本）

> **主场景**：…｜**阵容**：角色A（身份）、角色B、…
> **核心剧情**：…（一段说完这一集干什么）
> **规格**：横屏 1280×768 ｜ 10 镜 / 66 秒（规划期已过 ≥60s 校验；H3 向上取整后成片约 70s）｜ 音频=系统生成 ｜ 每镜 2 句对白（收尾镜 1-2 句）

## 镜头1 · 镜头名（场景名 · 8s）
- **角色**：xxx
- **画面**：
  - **景别运镜**：近景，固定机位，缓缓推近到下颌
  - **站位**：A 在画面右后方、三分之四侧身朝左；B 在左前一米、正侧脸；两人错开，中间留出对视的空间
  - **表演动作**：A 举碗泼下清米酒；B 抬袖挡脸、脚尖只挪半步
  - **视线与表情**：A 两眼钉在 B 脸上、目光全程锁住 B，眉拧成八字→松开、眼皮掀、睫毛颤两下、唇抿成白线；B 迎着 A 的目光不退
  - **背景**：一圈客人背对镜头，左首三人的杯子往桌下缩、右首两人缩到柱子后、楼梯口探出两个脑袋
- **台词**：
  1. 角色：*台词*
  2. 角色：*台词*
```

- **时长按内容定，不给全集统一规格**：判据是这一镜的台词说没说完、动作走没走完——长台词 8–9 秒、两句对白或群戏 7–8 秒、一个眼神或过场空镜 5–6 秒；**单镜上限 10 秒**。写进头部的是自算总和，≥60 秒。
- 600 秒以内的短剧按 10 镜 × 6–8 秒（≈65–80 秒）起手，不够就按"还差几秒 ÷ 每镜上限"补镜。
- 每镜 2 句对白；女主/主角先动手（泼/拔刀/扑），情感在动作之后才露
- 「画面」必须写到能照着生成的程度，且**六要素齐全**（见下一节）

资产清单表写法：

| 类型 | 名称 | server_index |
|------|------|--------------|
| 角色三视图 | X（花名） | 000 |
| 场景图 | 某场景（复用/新） | 009 |

技术注意写：抽帧要盯的镜、H3 易错点、本集视觉重点、封面候选镜。

## 六、每镜必写的镜头设计六要素（站位 / 动作 / 视线 / 表情 / 运镜 / 背景）

镜头写的是「一段画面」，出片就是「一段废画面」。每一镜必须写全这六件，缺一件，成片就漏一处：

| 要素 | 写什么 | 不写会怎样 |
|------|--------|-----------|
| **景别运镜** | 景别（大远景/全景/中景/中近景/近景/特写）+ 机位角度（平视/俯拍/仰拍/过肩/侧）+ 运动方式（固定机位/缓推/缓拉/横移/轻跟）+ 这一镜的镜头意图 | 十镜全是一个平视固定机位，整集像手机随手拍 |
| **站位** | 谁在画面左/右、前/后、正/侧/背，谁挡谁、两人间隔多远、光从哪一侧打来 | 两人正对正站着，视线根本对不上，只能各自看镜头 |
| **表演动作** | 这一镜这个人具体干什么；**打斗镜先向 `fxai-combat-design` 取招式术语再写**（见下一节） | 人物僵在原位，只有嘴在动；打斗镜自创招式名、动作不成因果链 |
| **视线与表情** | 谁看谁（写落点）+ 一句锁定对方、不朝镜头的措辞；表情写**变化过程**（眉/眼皮/睫毛/唇/下颌/脸色/喉结/瞳孔） | 说话的人看着镜头，对手戏毫无交流感；脸是一张不变的表情 |
| **背景角色** | 场景参考图里定了有几类人，每一类给一个**具体动作**；配角只留后脑勺/侧脸轮廓/暗色剪影，不转正面五官 | 背景是定格贴图，画面对不上参考图，还冒出一张张正面脸 |
| **台词** | 挂在时间轴上的哪一秒（先动后说 / 边走边说 / 说完停半拍） | 台词和动作错位，像在配音 |

**硬约束（写分镜时逐条自检）**
1. **视线写成「落点 + 锁定」成对句**：对手戏双方视线互相扣住，落点写死 + 加一句不朝镜头的措辞（"两眼钉在对方脸上……目光只落在对方身上"）。落点与锁定句成对出现，缺落点时人物会慌着乱瞟，缺锁定句时它照样切回看镜头。
2. **背景人物各配一个正在做的动作**（缩杯子、耸肩、探头、挪凳子、手按腰刀又松开），画面里不出现定格剪影。
3. **同一角色同集不同镜的表情与动作逐镜换新**（同一次"抬眼"，镜 2 是冷，镜 9 是"瞳孔骤缩"）。
4. **站位要错开**：正对正站不开视线，双人同框一律写成三分之四侧身或一前一后的错身位。

## 七、打斗镜先取词再写（自动化钩子）

本集只要有**打斗镜**（对招、劈砍、格挡、闪避、腾挪、摔擒、终结一击），写这些镜头的「表演动作」之前，**必须先向 `fxai-combat-design` 取词**——这是自动化链路里「分镜层 → 战斗设计层」的入口：

```bash
PY="python -X utf8"
S="<技能目录>/fxai-combat-design/scripts/combat_route.py"
$PY "$S" moves --query "<本镜动作关键词 3-6 个>"
$PY "$S" --read moves/<命中 id>          # 自动带出推荐术语
$PY "$S" --terms <类别> --tier high      # 或按类别取词
```

- 取到的术语写进分镜的「表演动作」与「视线与表情」里，**一段 2–4 个词**，当动词用、不加引号、不堆砌。
- 需要整套动作链 / 空间调度 / 一打多清场时，直接按 `fxai-combat-design` 的创作流程出**动作方案 + 分镜表**，再翻成这里的镜头六要素。
- **零命中就写「无命中」**，按常规写法走；招式名一律取检索命中的 id 里的原词。
- 详见 `fxai-combat-design/references/07-与短剧集成.md` 与 `09-被上层调用契约.md`。

## 八、写作禁令（写分镜时逐条自检）

1. **群演不露脸且必须动**：朝臣=低首剪影、禁军=蒙面黑衣人执长枪、围观=背面剪影；且每人都在动（低首、攥杯、探头、退半步）。「群演不露脸」和「群演要动起来」是两条必须一起写的——只写不露脸，背景就成了定格贴图；只写动，就补出一张张正面脸。
2. **光只有两色**：夜戏=月光冷青，室内=烛火暖黄；第三种光（火光/晨光）必须在镜头名里写明。
3. **内心独白不写进 `<d>`**（那是给 TTS 念的），内心戏用动作/神态。
4. 古装/年代剧只写古代道具（手机、电线、霓虹、西装等现代物一律换成古装器物）。
5. **全中文**，中文句用全角标点，中英文各自成句（"meal""two" 这类中英混排就是废稿）。
6. **场景描述只写一份、只放 SCENES 字典**：六段式提示词里场景那一行放占位 `@@SCENELINE@@`，由 `run_xxx.py` 的 `_fix()` 从 `SCENES` 注入。**场景描述在提示词正文里只留 `@@SCENELINE@@` 这一处**——两份会拼在一起变成两条 `<Subject N> 是 <Picture M>`，质检报「主体定义没按顺序：[1,2,3,3]」，提交直接被拦。改场景写法只改 `SCENES`，改完顺手确认提示词里没有旧版残留句。

## 九、目录结构与命名

```
<项目根>/
├── project_def.json        # 系列定义：server_subdir + 角色/场景 → server_index 映射 + 剧情文案
├── 剧集档案.md              # 全剧设定 + 五幕结构 + 逐集拆解 + 后续季线
├── 角色库.md                # 外貌三件套 / 气场 / 台词风格 / 视觉锚点 / 称呼分工
├── 场景库.md                # 场景画面要点 / 光调 / 出现集数
├── assets/角色三视图|场景图/   # 生图后本地备份（真值）
├── N、集名/                # 每集一个目录，里面有 完整分镜脚本.md
└── assets_map.json / scenes_manifest.json   # 生成期产出（见 fxai-short-drama）
```

- 集目录 = `序号、四字集名`（`1、风尘花魁`），与 project_def 的 episodes 数组保持一致
- 文件：`完整分镜脚本.md`（剧本层）/ `run_<slug><N>_ep<N>.py`（提交层，交给 fxai-short-drama 时再写）
- 每集 10 镜，时长 `7/6/6/6/7/7/6/7/7/7`（=66s，过 60 秒线）
