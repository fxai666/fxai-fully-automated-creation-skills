# 爆款公式（写逐集拆解与分镜时直接查表）

---

## 〇、爆款结构五项硬规则（逐项达标才往下写）

| 项 | 规则 |
|----|------|
| **3 秒钩子** | 每集第 1 镜必须是**特写 + 危机/爆点**，第 1 镜时长 ≥6s。钩子 6 型见本册第一节，逐集按表挑，连续两集换型使用 |
| **每集 ≥2 反转** | 反转 1 推翻观众认知，反转 2 再翻一层（身份/动机/善恶对调）。**反转必须在上一镜埋线**，写反转时先确认上一镜已铺好前因 |
| **结尾卡点** | 第 10 镜定格 + 留白给字幕，留一句能独立当封面的台词。卡点 3 型见本册第三节 |
| **信息密度** | 每集至少 1 个新情报（真相/身份/物证），每集必有 1 个新场景或新角色（否则观众记不住集数） |
| **连续钩子** | 集尾悬念必须直接构成下一集第 1 镜的钩子（第 N 集结尾 = 第 N+1 集 3 秒钩子） |

---

## 一、3 秒钩子 6 型（每集第 1 镜必用，连续两集换型）

| 型 | 开法 | 适用 | 情形 |
|----|------|------|------|
| **① 生死危机型** | 特写：刀抵喉 / 酒泼脸 / 长剑落下 / 火起 | 开局集、高潮集 | 特写烈酒泼脸，侯爷怒喝"陪酒伺候，不然沉塘喂鱼！" |
| **② 当众背刺型** | 众目睽睽下被最亲的人捅一刀 | 情感线转折集 | 姐妹端来热茶柔声安慰，茶杯底藏迷药 |
| **③ 身份揭晓型** | 一句话把身份/关系掀翻 | 反转集 | "本王的人，你也敢动？" |
| **④ 数字冲击型** | 一个具体的坏数字直接砸出来 | 商战/职场/悬疑 | "订单又掉两成，人心也跟着往下掉。" |
| **⑤ 物件指认型** | 一件信物/一份证物被指出来 | 真相集 | 一枚虎符推到灯下，指尖抚过 |
| **⑥ 认知推翻型** | 先给一个观众认定的事实，一秒推翻 | 中段反转集 | 柔弱花魁瑟瑟发抖，眼底却藏杀心 |

**钩子写法三条**：
1. 钩子前置到第 1 镜的**前 3 秒**，不铺垫、不交代前情、不写"话说当年"
2. 钩子必须是**画面**（不用解释，能拍出来），不是旁白
3. 钩子句要短、要有动词、有情绪（"陪酒伺候，不然沉塘喂鱼！"）

## 二、每集结构模板（10 镜怎么排）

```
镜1    3 秒钩子（特写 + 爆点）
镜2    钩子后的第一个反应/质问（把钩子接住）
镜3    埋线镜：为这一集的反转埋第一颗钉（一个眼神/一句软话/一个动作）
镜4    中段：对手施压，主角被动
镜5    反转 1 落地（推翻观众认知）
镜6    动作高潮：打/跑/挡/救（画面最热闹）
镜7    埋线镜 2：埋下一集的钩子（暗处的人/窗外影子/一句没说完的）
镜8    情感/代价：主角付出什么（受伤/失去/第一次动摇）
镜9    收束：信息给足（真相/身份/证据 交代完）
镜10   结尾卡点（定格 + 留白 + 一句压轴）
```

- 每集 **≥2 反转**，反转必须在**上一镜埋线**（镜 3 埋 → 镜 5 落；镜 7 埋 → 下集镜 1 落）
- 反转分层：反转 1 = 推翻认知；反转 2 = 再翻一层（善恶对调 / 谁才是布局的人）
- 集尾悬念 = 下一集第 1 镜钩子（**闭环**，否则观众不追）

---

## 三、结尾卡点 3 型

| 型 | 做法 | 适用 |
|----|------|------|
| **对峙定格型** | 两人对峙，一方说出重话，定格 | 权谋/职场 |
| **真相露头型** | 一句真相刚要出口被打断，画面切走 | 悬疑/复仇 |
| **新威胁型** | 暗处/门外/密报出现，主角不知情 | 悬疑、季终 |

卡点镜三件套：**定格 + 上方留白给字幕 + 一句能独立当封面的台词**。
例：*"清鸢……不，该叫你凤希。三年蛰伏，你终于敢露头了。"*

## 四、三条核心情报法（撑住一部剧的骨架）

一部剧先定 **3 件必须被观众知道的事**，每件绑定到一个具体集数，后面所有集都往外挂：

```
情报1（第 N 集揭）：表面真相是假的
情报2（第 M 集揭）：真正的动机
情报3（季终揭）：更大的局
```
写新一集时先问：**这一集推进一步情报没有？** 只卖钩子不推情报的集，观众记不住。

## 五、五幕 + 后续季规划

```
第一幕 入局    她/他要做什么，撞上了谁
第二幕 裂痕    证据/误会/代价开始动摇固有认知
第三幕 崩塌    关键一次牺牲或抉择（全剧最重的一次）
第四幕 反噬    对手摊牌 / 主角身份翻转
第五幕 终局    真相落地 + 新钩子（为下一季）
```

**续季规划法**（第 20 集留扣，不写完）：
1. 季终留 3 个钩子：① 反派未死（物件证据）② 主角身份的新秘密 ③ "某人"的称呼（尊主/旧部/天机）
2. 下一季每 5 集一个阶段小高潮 + 每 3 集一个新身份揭晓
3. 续季表格列：`集 | 集名方向 | 钩子 / 主线`（写到能当细纲用为止，不必写分镜）

## 六、钩子与集间连贯性铁律（用户拍板 · 逐条达标才写开场）

**1. 钩子是剧情的，不是画面的（最高铁律）**
开场钩子靠**对话 / 人物关系**立住（背叛、反转、身份错位、问句），视觉手段只做辅助（藏脸、只给手、只给局部这类拍法一律判错）。开场镜给角色正脸完全没问题——正脸拍得越真、反转越狠，反而越好。

**2. 开场三要素（本集第 1 镜必须同时满足，缺一不可）**
- **① 接住上集悬念**：用本集开场前几句对话 / 人物关系，直接接住上一集结尾甩出的钩子。**接住 ≠ 复读**——只把上一集最后一句原样复述当开场，观众一眼出戏（那是"复读"不是"发展"）。
- **② 同一句话给本集新威胁 / 新角色的来由（因果桥）**：上一集尾 → 这一集头之间，必须补一段因果——"为什么围楼 / 为什么有人来 / 局势为什么变了"。新出现的武装、危机、势力必须有出处（呼应前集已立住的 antagonism，如第 1 集侯爷），出处要在提示词里看得见。
- **③ 新登场的重要角色必须给一句身份锚点**：谁、什么来头，一句话点明，别让他以"护花英雄 / 神秘人"姿态凭空闯入。锚点一句即可（如"京里出名的温润贵人"），其真实动机留到后续反转揭。

**3. 集间钩子链 / 因果桥**
上一集结尾的悬念，下一集开场用对话接住，并顺势甩出本集钩子——集与集之间不断线。若新集要用到"回指前集"的台词 / 道具 / 数字，必须先核对前集成片确有其事（全剧审查报告的"回指前集"铁律），回指句要落在前集真实发生过的动作上。

**4. 开场写作四条硬约束（逐条自检）**
- 开场钩子要在上一集最后一句上往前走一步（发展），原样复述判错。
- 新威胁 / 新势力 / 新危机各自配因果桥 + 呼应既有 antagonism，出处写在台本里。
- 新重要角色带一句身份锚点，登场姿态写实名分（如"带刀的京中捕快"），不写"英雄 / 神秘人"这类无归属姿态。
- 地点 / 局势的转移要交代（如上一集在 A 地私密场景，下一集跳到 B 地围楼，中间写一句转移原因）。

## 七、台词写法

- **短句**：一句 ≤15 字，短剧是听的，不是读的
- **半文白 + 口语**：古风剧就"陪酒伺候，不然沉塘喂鱼"这种，别写成文言念经，也别写成现代口白
- **人物辨识度**：女主冷短句带刀、男主短而重从不辩解、反派人前温软露馅后一字一顿、配角一句个性（圆滑/粗/尖细）
- **金句率**：每集 1 句可独立当封面的台词（放第 10 镜卡点）
- 内心戏用动作（低头、攥紧、退半步），**不写进对白**
