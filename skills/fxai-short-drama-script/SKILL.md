# 短剧剧本拆解与分镜写作

## 本技能文件清单（先读这里，再决定读哪几册）

| 文件 | 什么时候读 |
|------|-----------|

| `references/storyformula.md` | 爆款五项硬规则/钩子6型/每集结构/反转三层/结尾卡点/钩子与集间连贯性铁律/续季/台词——**写钩子与反转前读** |

**确定本次要做什么之后，只读对应的那一两册，其余一律不读。**

把「一句话创意 / 一份现成剧本」变成「能直接提交渲染的 20 集分镜档案」。产出物是**纯文本真相源**，生成走 `fxai-short-drama`。

**分工界线**：本技能管**剧本层**（世界观、人物、逐集拆解、镜头分镜、验收）；`fxai-short-drama` 管**生成层**（shots → H3 提交 → 合并烧录）。写分镜时不用碰 .py 提交脚本，出单集 run 脚本时才写。

## 一、产出物与目录结构

目录树与命名见 `references/storyboard-template.md` 第九节：`project_def.json` / `剧集档案.md` / `角色库.md` / `场景库.md` / `assets/角色三视图|场景图/` / `N、集名/完整分镜脚本.md` / `assets_map.json` + `scenes_manifest.json`。

目录名 = `序号、四字集名`（4 字方便封面居中盖字）。集名取原剧本小标题，不改写。

**第一步先落 `project_def.json`**：`server_subdir` 写错，后面所有镜头引用的 rel 路径全错。

---

## 二、六步流程

1. **立项** → `project_def.json`（模板见 `references/storyboard-template.md`）
2. **世界观 + 人物** → 五幕结构、三条核心情报、人物关系图、角色库、场景库
3. **逐集拆解** → `剧集档案.md`，每集一个块
4. **写分镜** → 每集 `完整分镜脚本.md`，10 镜
5. **验收** → 跑 `scripts/check_storyboard.py`（全绿才往下走）
6. **移交** → 按 `references/h3-link.md` 转成 shots 交给 `fxai-short-drama`

---

## 三、爆款结构（硬规则，逐项达标才往下写）

五项硬规则表（3 秒钩子 / ≥2 反转 / 结尾卡点 / 信息密度 / 连续钩子）见 `references/storyformula.md` 第〇节。

### 钩子与集间连贯性铁律（用户拍板 · 逐条达标才写开场）

四条铁律见 `references/storyformula.md` 第六节：① 钩子靠对话/人物关系立住，藏脸/只给手/只给局部判错；② 开场三要素（接住上集悬念、新威胁来由的因果桥、新角色身份锚点）；③ 集间钩子链与回指前集核对；④ 开场写作四条硬约束。

---

## 四、写分镜的固定格式（每集 10 镜 × 6-8s ≈ 65-70s）

头部信息块 + 10 个镜头块 + 资产清单 + 本集技术注意，完整骨架见 `references/storyboard-template.md` 第五节。要点：

- **时长按内容定，不给全集统一规格**：长台词 8–9 秒、两句对白或群戏 7–8 秒、一个眼神或过场空镜 5–6 秒；**单镜上限 10 秒**。写进头部的是自算总和，≥60 秒。
- 600 秒以内的短剧按 10 镜 × 6–8 秒（≈65–80 秒）起手，不够就按"还差几秒 ÷ 每镜上限"补镜。
- 每镜 2 句对白；女主/主角先动手（泼/拔刀/扑），情感在动作之后才露
- 「画面」写到能照着生成的程度，**六要素齐全**（见下）

### 四之一、每镜必写的镜头设计六要素（站位 / 动作 / 视线 / 表情 / 运镜 / 背景）

六要素逐项写什么、漏写后果、四条硬约束，见 `references/storyboard-template.md` 第六节。

### 四之二、打斗镜先取词再写（自动化钩子）

含打斗镜（对招、劈砍、格挡、闪避、腾挪、摔擒、终结一击）的集，写「表演动作」前先跑 `fxai-combat-design/scripts/combat_route.py` 取词，命令见 template 第七节。

---

## 五、写作禁令（写分镜时逐条自检）

六条（群演不露脸且必须动 / 光只有两色 / 内心独白不进 `<d>` / 古装道具 / 全中文全角 / 场景描述只放 SCENES）见 template 第八节。

---

## 六、验收（写完必须跑）

```bash
python scripts/check_storyboard.py --root "<项目根>"
python scripts/check_storyboard.py --root <项目根> --min-seconds 60 --pattern "*完整分镜脚本.md"
```

六项硬查判据（镜数 / 序号 / 总时长 / 钩子在位 / 小节 / 写作禁令）、历史写法降级、常驻误报见 `references/check-rules.md`。**全绿才进渲染**。

---

## 七、设定变更（换主角 / 改名 / 改设定）

先改设定层（project_def / 角色库 / 剧集档案），再批量换台词（`苏清鸢`→`清鸢`），最后人工改需要"本名/新名"的句子（结尾定调句、关系图、后续季表格）。优先走**双名设定**（本名 X + 化名 Y，如"凤希 / 清鸢"）。改完重跑验收脚本。
