# 写凤希AI 自家工具的文章：以可复现事实为依据

写我们这套工具 / 真实案例的公众号文章时，**先真跑、再掐表、最后写数字**，数字一律来自实跑：
1. **需要什么图，就先用我们的技能真出一遍**（图源＝本次现出的成品，旧图与网图都不充数）。
2. **掐真实耗时**：从提交任务到文件落盘，逐张记秒数、记总计。
3. **把可复现的数字写进正文**：尺寸、耗时、张数这类读者能自己复现的数字；速度就写掐表档位表。
4. **没跑过的数字、百分比、「几十张 / 几分钟几张」这类模糊说法一律不进正文**。
5. 不夸大：只写跑出来的效果。

## 掐表基准（双 RTX 5060 Ti 16GB，千问2.1 工作流）
| 尺寸 | 单张耗时 |
|---|---|
| 512×512 | **18 秒** |
| 768×1024 | **36 秒** |
| 1152×1536 | **72 秒** |
| 1152×512（横版封面） | **48 秒** |
- 3 张混合串行总耗时约 **204 秒**。
- ⚠️ **并发不加速**：别写「并发出图」「一分钟出好几张」。
