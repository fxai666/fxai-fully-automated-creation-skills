# 07 平台合规与写作红线（写稿 / 发布前必看）

本册管「公众号文章哪些写法会被限流 / 不推荐」，与 SKILL.md -3 节写稿风格互为补充：-3 节管「怎么写」，本册管「哪些写法发出去会被判违规」。

命中即读：要写推文、要定价格文案、要判断联系方式怎么放、要补站点 SEO 时。

## 一、正文禁明文联系方式（互动导流红线）

- 公众号**正文、简介、评论、消息**中嵌 微信号 / 二维码 / 外部链接 / 加群方式 → 判为「互动导流」→ 不推荐 / 限流。
- 正文一律不写：个人微信、官网外链（http/https）、QQ 群号、二维码图片。
- 联系方式改放：公众号菜单、关注后自动回复、账号简介。正文只做软引导——「关注我们，在公众号私信一声」。
- 落地页 / 站内页（非公众号正文）可写明文联系方式，不触发限流。

## 二、价格与营销

- 写价格数字（如 ¥58 / ¥98 / ¥158）**不降权**，可正常写。
- 禁夸大对比词：「全网最低」「远低于官方价」等不实表述不写。
- 纯营销 / 纯广告、缺乏实际价值的内容 → 不推荐。护身做法：保留真实痛点与方案价值（装环境痛点、整套方案是什么），硬广只在结尾一次。

## 三、进推荐池的护身动作

- 发布时勾「原创」、加合集标签、开「允许推荐」。
- 推荐机制：点击率 → 完读率 → 互动 / 分享 进推荐池；被判导流 / 纯营销 / 低质 → 踢出推荐池（看一看 / 搜一搜拿不到量）。

## 四、SEO（站点落地页 / 工具页）

- 每页补：`description` / `keywords` / `author` / `robots` / `canonical` / Open Graph / Twitter Card / JSON-LD。
- 付费服务页带 `Service` 或 `Offer` 结构化数据；普通页带 `Organization`。
- 站内超链接一律 `fxaitoolkit.openUnboundedWindow` 打开（前端铁律见技能族）；改完前端 bump `?v=`。

## 五、发布纪律复述

- 默认 `draft-add` 只建草稿不发布（见 SKILL.md -1 节）。
- 要发布先确认 `publish`（不上主页、生成永久链接）还是 `mass`（占每月 4 次、不可逆）。
