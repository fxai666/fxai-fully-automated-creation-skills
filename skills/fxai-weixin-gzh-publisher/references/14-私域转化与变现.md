# 私域转化与变现

命中即读：设计加微 / 进群路径、配自动回复与菜单栏、规划变现时。正文禁明文联系方式（互动导流限流红线）以 07 册第一节为准，本册管「放哪、怎么说、怎么转」。菜单落地命令（`menu-create --file 菜单.json` 等）与结构校验规则见 05 册。

## 一、转化链路

公众号文章 → 点击引导 → 加微 / 进群 → 社群运营 → 转化成交 → 复购 / 裂变 / 口碑传播。
各环节转化率（经验参考值，因行业与粉丝质量而异，以自己漏斗数据为准）：阅读 → 点击引导 5-15%；点击 → 加微 30-50%；加微 → 进群 60-80%；群内 → 转化 5-20%。

## 二、引导位置与话术构成

| 位置 | 特点 | 场景 |
|---|---|---|
| 文末 | 最常用，读者看完决定 | 所有文章 |
| 文中插入 | 阅读中转化 | 干货提到「更多资料」处 |
| 评论区置顶 | 醒目，不伤正文 | 补充说明 / 福利 |
| 关注自动回复 | 100% 触达新关注 | 所有新关注用户 |

话术构成判据（按主题自写，现成模板不套用）：利益点（资料名 + 含什么）+ 领取方式（回复关键词）+ 入口位置。价值吸引；「转发才能领取」类强制诱导见 07 册红线。
自家账号固定导流入口（官网 / 微信号）以 06 册样本五的硬广格式为准。

## 三、自动回复配置清单

关注后自动回复六格：欢迎语 + 账号一句话介绍 + 见面礼（回复关键词领取）+ 加微入口 + 往期入口（指向菜单栏）+ 互动提问。
关键词回复表（关键词 | 回复内容）：资料 / 领取、加微信、进群、合作、转载五项各配对应内容。

## 四、菜单栏结构（3 个一级菜单）

精选文章（必读干货 / 热门文章 / 最新文章）｜免费资料（回复领资料 / 加入社群 / 工具推荐）｜联系我（加我微信 / 商务合作 / 关于我）。
设计判据：每个入口有明确价值（凑数入口浪费黄金位）；优先放「立即获得好处」的入口；精选类定期更新；移动端跳转逐项点验。

## 五、社群运营

日常 SOP（时间点按群活跃校准）：早间问候 + 今日话题 / 午间干货分享 / 下午互动（投票问答）/ 晚间精华 + 答疑 + 福利。
分层：免费群（关注即进，内容分发、筛精准用户）/ 门槛群（任务或消费门槛，深度交流）/ 付费群（专属服务）。
活跃技巧：固定栏目培养习惯；话题引导；成员展示；福利刺激；定期清理不活跃成员。
内容与推广比例 ≥4:1；高频硬广刷屏伤群。

## 六、变现路径

| 模式 | 适合阶段 | 门槛 | 说明 |
|---|---|---|---|
| 流量主广告 | 500 粉+ | 低 | 按阅读量结算，规则以官方最新公告为准 |
| 商务广告 | 3000 粉+ | 中 | 单条报价随号而异 |
| 知识付费 | 有专业内容 | 中高 | 课程 / 咨询 |
| 电商带货 | 有供应链 | 中 | 佣金 / 自营 |
| 私域服务 | 有服务能力 | 中 | 1对1咨询 / 代运营 |
| 社群付费 | 有持续价值 | 中 | 会员制 |

变现节点梯度：免费内容建信任 → 低价产品（9.9-99 元）筛付费用户 → 中价产品（199-999 元）核心服务 → 高价产品（1000 元+）深度服务。
转化原则：先给价值再谈付费；说清楚得到什么（模块数 / 服务次数 / 时长）；提供体验装降低门槛；限时限量真实；售后承诺可兑现。医疗 / 金融 / 教育类先标资质风险（07 册）。

## 七、私域误区速查

| 误区 | 后果 | 纠正 |
|---|---|---|
| 一上来就要微信 | 粉丝警惕，转化低 | 先给价值（资料 / 答疑），再提加微 |
| 群建完就凉 | 死群 | 按 SOP 固定栏目运转 |
| 菜单栏凑数入口 | 点击率低 | 每个入口有明确价值 |
| 硬广刷屏 | 取关退群 | 内容 : 推广 ≥4:1 |
| 承诺福利不兑现 | 信任崩塌 | 激励真实可交付 |

漏斗数据由用户提供后台 / 群数据后记录；私域高频问题反哺选题池（09 册来源 10）。
