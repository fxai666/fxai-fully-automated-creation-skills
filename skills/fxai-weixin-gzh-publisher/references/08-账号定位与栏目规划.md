# 账号定位与栏目规划

命中即读：做账号定位、定人设、规划栏目、搭内容日历、拆解对标账号时。

## 〇、定位澄清问题集（新账号 / 定位重做时，先问清再动笔）

四问：领域方向 / 读者画像 / 核心目标 / 人设调性。领域与读者单选；**核心目标与人设调性可多选**（用户答案常是「都要」）。选项库如下，按账号实际增删；用户给自由文本时按原话记档。

**领域方向**（单选）：全自动化创作（图文/视频/短剧/MV 的 AI 生产线）/ 全自动化运营（选题/发布/复盘/客服自动化）/ AI 替代传统团队（一人+一台电脑干完一个团队的活）/ AI 效率工具实战（工具测评/提示词/提效方法）/ 行业观点评论（趋势判断/热点解读）。

**读者画像**（单选）：中小企业主 / 个体创业者（想降本增效、找流量、做自媒体）/ 25-35岁职场白领（想提效、怕被替代）/ 18-25岁想搞副业的年轻人 / 泛人群（对AI好奇的普通人）/ 同行或想入行做AI内容的人。

**核心目标**（**多选**，选 1-3 个）：品牌人设 / 涨粉引流 / 私域转化 / 阅读互动 / 变现营收。四项全选时按「主目标轮换」设计栏目，见第四节。

**人设调性**（**多选**，选 1-3 个组合）：实战陪跑型（真跑过的案例+数据说话）/ 专业导师型（懂行、有判断、敢下结论）/ 朋友聊天型（真人真事+幽默随笔）/ 极客工程师型（工作流/代码/架构，硬核向）/ 结果晒单型（晒成果、晒前后对比）/ 反焦虑陪伴型（陪小白起步）。此处定「读者眼中你是谁」；写稿语气铁律仍是 SKILL.md -3 节。

追问纪律：一次问全四问；用户答「都要/难选」时把该题改为多选收口，由她勾选；答案记入《公众号运营档案》第 1-2 段；定位重做时旧答案整段作废重问。

## 一、定位三步法

1. 写一句话定位：身份 + 目标人群 + 解决的痛点 + 获得的价值，≤30 字。
2. 差异化四维检查（逐维过一遍，取最强一维做主差异化）：人群差异（有没有还没被满足的细分人群）/ 内容差异（有没有别人没覆盖的角度）/ 形式差异（图文化、数据化、故事化）/ 人设差异（独特身份或口吻）。
3. 验证：搜目标关键词看头部内容重叠度——重叠度高 → 收窄细分领域；重叠度低 → 定位成立。

## 二、对标账号拆解（3-5 个）

每个账号按八项填：名称、粉丝量级、内容方向、更新频率、爆款 TOP3（标题 + 阅读 + 爆因）、变现方式、可借鉴处、可差异化处。
五个分析维度：选题（写什么 / 没写什么）、标题（公式与风格）、内容（结构 / 深度 / 字数 / 配图）、互动（评论区氛围与引导话术）、变现（广告 / 带货 / 知识付费 / 私域）。
对标账号数据以实际调研为准，本册不给具体账号数据。

## 三、人设四要素

| 要素 | 定稿要求 |
|---|---|
| 身份标签 | 一句话说清「是谁、凭什么说话」 |
| 内容调性 | 固定一种语气；本账号铁律见 SKILL.md -3 节（幽默随笔） |
| 视觉识别 | 固定排版模板与封面版式；封面尺寸以 01 册为准 |
| 记忆点 | 固定开头 / 结尾 / 口头禅一类钩子 |

一致性检查：文章语气与定位匹配；配图风格统一；读者 3 秒内能认出账号。

## 四、栏目规划

设 3-5 个栏目，每个栏目定五要素：名称、定位（解决什么痛点）、字数区间、内容形态、更新频率。
栏目覆盖类型：核心干货 / 热点评论 / 故事案例 / 轻互动。
目标多选时（如品牌+涨粉+私域+互动全要）：不同栏目各背一个主目标——干货栏目背涨粉/收藏、观点栏目背品牌/转发、案例栏目背私域转化、轻互动背阅读互动；单篇只主攻一个目标，文末兼顾转化入口（14 册）。

## 六、定位纠偏（信号 → 动作）

| 信号 | 动作 |
|---|---|
| 定位太宽（「分享一切干货」） | 收窄到细分人群 + 细分问题 |
| 自嗨（只写自己想写的） | 用读者痛点验证选题 |
| 抄袭式差异（对标火就跟着做） | 对标学方法，定位做差异化 |
| 一次性定位 | 每季度结合数据复盘校准一次 |
| 人设漂移（语气忽变） | 回到人设四要素固定口吻 |

定位自检三问：一句话介绍外行能听懂；目标读者听了想「这说的就是我」；定位能支撑 100 篇以上内容。
