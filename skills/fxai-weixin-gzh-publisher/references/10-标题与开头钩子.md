# 标题与开头钩子

命中即读：写标题、起开头、给文章配封面文案时。标题与开头决定点开率，写完按本册判据自查；正文气质铁律见 SKILL.md -3 节（幽默随笔）。

## 一、标题判据（四条同时过）

1. **含关键词**：把读者会搜的那个词放进标题（搜一搜流量入口，细则见 12 册）。
2. **给具体结果或具体场景**：「省出 2 小时」优于「提升效率」。
3. **长度**：微信信息流标题约 20 字内可完整显示，超出部分在列表里被截断；关键词尽量落在前 12 字。
4. **承诺兑现**：标题许了什么，正文第一节就要给到；正文没有的，从标题里去掉。

## 二、标题结构公式（给结构，不给套话）

| 公式 | 结构 | 适用 |
|---|---|---|
| 痛点 + 解法 | 「做 X 累到崩？先看这招」 | 教程、避坑 |
| 结果前置 | 「我把 X 交给 AI 之后」 | 亲历叙事（本账号主力） |
| 反常识 | 「别再 X 了，先做 Y」 | 观点文（去掉夸大对比，07 册红线） |
| 数字清单 | 「4 个动作，第 2 个最值钱」 | 干货合集 |
| 身份代入 | 「一人公司，也能天天日更」 | 目标读者明确时 |
| 场景提问 | 「每天 3 小时碎片时间，够做什么」 | 互动文 |

一条标题可套 2 个公式，但只用一个主公式。同一账号连发 3 篇内不重复同一公式。

## 三、开头钩子公式（前 3 行定生死）

移动端首屏只显示开头两三行，钩子要在**第一行**就给出「继续读的理由」。

| 钩子 | 结构 | 落笔要点 |
|---|---|---|
| 场景切入 | 一个具体时间 + 一个具体动作 | 真实发生过的时间地点（SKILL.md -3 节：只用真事） |
| 数字反差 | 先给结果，再给过程 | 数字全部实跑得来（04 册掐表纪律） |
| 身份共鸣 | 说出读者那句心里话 | 用读者自己的措辞，避开书面腔 |
| 冲突开场 | 先说「本来以为」，再说「结果」 | 转折出现在第一段内 |
| 结论前置 | 第一句直接给判断 | 判断要有依据，别用「一定 / 必须」压人 |

**钩子纪律**：钩子必须在正文里兑现，兑现位置越靠前体验越好；一篇只用一个主钩子，辅助钩子放中段。开头忌：背景铺陈、寒暄自我介绍、目录预告、空泛感慨（「在这个焦虑的时代」）。

## 四、开头与正文衔接（三段式）

1. 钩子（首屏 3 行）：给理由。
2. 展开（1~2 段）：把这个理由具体化，给出场景或数据。
3. 承接：抛出一条正文主线（「后来我发现真正管用的其实是……」），把读者带进正文。

## 五、封面文案判据

- 封面**尺寸与出图流程以 01 册为准**；本册只管封面上那句文案。
- 封面文案 = 标题的**补充**，不是复述：标题给结论，封面补场景或数字。
- 字数控制在 8~14 字，手机端缩略图上要能一眼扫完；断句清楚，忌长句。
- 视觉层级：一句主文案 + 可选一行小字补充；小字承载细节，主文案承载钩子。
- 与正文人设一致（08 册），跨栏目保持同一视觉语言。

## 六、交付前自查

- [ ] 标题含读者会搜的关键词，且落在前 12 字
- [ ] 标题许的结果在正文第一节兑现
- [ ] 开头第一行就是钩子，没有背景铺陈
- [ ] 只用一个主标题公式 + 一个主钩子
- [ ] 封面文案与标题互补、不重复，8~14 字
- [ ] 全文没有出现夸大对比、绝对化措辞（07 册）
