# 参考案例缩影（写作口气基准）

> 本文件是「写公众号文章」时的**唯一口气基准**。动笔前读一遍，对齐 幽默随笔 / 小品文 的笔调。
> 改稿风格以 `SKILL.md` 的「写稿风格」节为铁律，本文件只管「口气像不像」。

## 一、风格指纹（动笔前默念一遍）

- 第一人称「我」+「老板」，人物一律用「我 / 老板」两个称呼。
- 真事当素材，只加工讲法、不加工事实：人物、对白、场景、数字都取自真事。
- 只写素材与判断，工作汇报体裁（"我今天干了①②③④"、能力清单、观点罗列）一律不写。
- 段落短，一两句一段；用「一、二、三」分节，每节一个小标题甩出来（带点颜色/符号更好看）。
- 口语化、轻松、带点俏皮；结尾甩一句能记住的"金句"。
- 该硬广就硬广（官网 / 微信号放结尾），硬广前面先给足真内容，开头即卖不成立。
- 敢说"我不装懂"：没把握的事明说不知道，不画大饼。

- **篇幅**：1200~1800 字是下限不是上限；砍篇幅 ≠ 砍故事，主线必须留具体那件事、那个人、那个动作。
- **人物只有"我 + 老板"**：小美 / 小片 / 老K / 钥匙 / 老张 / 监工 这类角色名与对白性格一律不用；要提能力就说岗位（"出图的那个""剪片子的那个"）或"我们这一屋子"。老板的话只转述他真说过的判断。对话一律叙述化，聊天记录引用框（灰底"员工群 · 01:10 / 老板：知道。"）不写。
- **只加工讲法、不加工事实**：人物、对白、场景、心理活动、动作细节、数字全部取自真事；允许调叙事顺序、选切入角度、换俏皮说法、结尾下判断。
- **文末署名**：`— 文章内容及图片皆由凤希AI生成 —`

## 二、口气样本（摘自参考文章，供模仿笔调）

### 样本一：开场先抛结论，不寒暄
> 这篇文章不卖东西，是我这段时间一点真实的感受。先说结论：我现在是一个人了——准确说，是一台电脑，加一个人。
> 不是团队散了，是**团队不需要了**。

### 样本二：把概念拆成"人和机器"的对比，落到自己的体感
> 我要对接的人——文案、设计、剪辑、客服、运营——现在是一个脚本的调用顺序。对接人少了，交付反而快了。
> 我不是来说"谁要失业了"这种话的。真的不是。
> 我只想说一个体感：**需求正在从"人"往"机器"那边挪**。

### 样本三：用大白话打比方，不堆术语（讲法可加工，比喻照写）
> 人类从最初的猿猴走到今天，靠的是什么？是**几千年、几万年，一代接一代地学、一代接一代地攒**。
> AI 呢？它不需要这个过程。它把所有人写下来的东西读了一遍，然后直接开始干活。
> 所以它一开始就在我们前面——它跳过了那几万年。

### 样本四：明说"我不装懂"，再给确定判断
> 说实话，我也不知道未来会变成什么样。我不会装懂，也不想给你画一张大饼。
> 但有几件事，我心里是有数的：……

### 样本五：收尾甩金句 + 自然硬广（硬广只在最后一节出现一次）
> 最后说一句掏心窝的：**未来是一片没人到过的荒野。**不知道它长什么样，也不知道走过去会怎样。但站在原地，是肯定不会赢的。

## 三、自检清单（完稿后逐条对）

- [ ] 有没有哪件事其实没发生？（有就删——事实一律取自真事）
- [ ] 是不是变成了工作汇报？（是就重写，只留素材和判断）
- [ ] 结尾有没有一句能让人记住的话？
- [ ] 前面是真内容、硬广只在最后一节出现一次？
- [ ] 人物是不是只有「我 + 老板」，没有小美 / 老K 这类角色名？
- [ ] **每个小节是不是都至少有一张对应的图**（粒度是"小节"不是"段落"：一篇通常 4~6 节，一节一张是下限，缺一节 = 稿子没写完；图落在该节最需要图示的位置、图意与本节一致、居中 + 灰色图注）？
- [ ] 有没有为凑数逐段铺图？（图是帮读者看懂这一节，不是给每段盖章——不需要的地方别塞）

## 四、一票否决

出现以下任意一种，直接重写，不看上面样本：
- 编造微信对话、"下班吧 / 嗯 / 七点半"这类虚构对白；
- 用灰色引用框模拟"员工群记录"；
- 把没跑过的效果写成已验证（自家电工具文章另走 `04-写自家工具文章.md` 的掐表纪律）。
