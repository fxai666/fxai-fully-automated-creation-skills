## 直接开跑

```bash
python scripts/wx_api.py precheck                    # 自检：配置、公众号清单、登录身份来源
python scripts/wx_api.py draft-add --title "标题" --content article/正文.html \
  --cover image/封面.jpg --digest "摘要" --author "凤希AI" --comments 1
python scripts/wx_api.py draft-add-newspic ...        # 图集，字段见 02 册
python scripts/wx_api.py publish --media-id <id>      # 默认不跑，见铁律 1
python scripts/wx_api.py publish-status --publish-id <id>
```

完整命令行、错误码与菜单命令见 05 册。

## 铁律速查（常驻；全文 14 条见 05 册）

1. **默认只建草稿**：原话没含「发布 / 群发 / 推送 / 自动发」时，`draft-add` 建完即收工，告知「草稿在箱子里，去后台点发表」。群发每月 4 次不可逆，执行前确认。
2. **发布前确认发法**：`publish` 不进主页、只生成永久链接；要让粉丝看见走「建草稿 → 后台手动发表」（03 册）。
3. **建完草稿先核对图**：图文看 `images_uploaded`、贴图看回包 `image_count`，为 0 不发布。
4. **判成败只看 `errcode` / `errmsg`**（回包 `hint` 是托底文案）；发布后 2~5 分钟跑 `publish-status`，再核 `image_count` 与正文字数（05 册）。
5. **尺寸色值只在脚本常量里出现一次**：封面、正文图、JPEG 参数见 01 册 1.3，跑 `make_cover.py` / `export_figures.py`。
6. **文本一律 `.md`**（正文 HTML 除外）；产物一律接口下载，ComfyUI 输出目录只当服务端看。
7. **首尾空白交给脚本**：所有参数过 `relay_call()`，签名与发送同源（05 册）。
8. **客户端前置**：读本机目录 / 登录身份前按 `fxai-standard` 08 册（客户端与登录检测）四步判定；缺配置或未登录就停在该步提示用户。

## 写作纪律（命中即生效）

### 风格：幽默随笔，只加工讲法不加工事实

口气基准与写法细节见 `06-参考案例缩影.md`，动笔前读一遍。

- 🚨 **人物、对白、场景、动作、数字全取自真事**；完稿自查「有没有哪件事没发生？」，有就删。
- 🚨 **人物只有「我 + 老板」**，对话一律叙述化；工作汇报体裁不写。1200~1800 字起，短段落、单句成段，硬广只在最后一节出现一次。署名 `— 文章内容及图片皆由凤希AI生成 —`
- 🚨 **每小节至少一张图**：粒度是小节（4~6 节大块），一段一图算凑数；图居中 + 灰色图注 ≤14 字，图意与本节一致；配图须真跑出（自家工具走 04 册）。标题钩子按 10 册、骨架按 11 册。
- 配图设计规范（类型 / 尺寸 / 必备要素）见 `fxai-poster/references/08`，出图后跑 `qc.py post`；头图与长图先 `qc.py fit` 裁白再质检。

### 合规与字体

- **合规**：动笔前读 `07-平台合规与写作红线.md`：正文避开明文微信 / 外链 / 群号；价格数字可写、对比不夸大；联系方式走菜单 / 自动回复。
- 🔴 **字体授权门禁**：出字前读 `fxai-standard/references/06-字体与素材授权.md`，字体只从白名单选（首选 Noto Sans SC / OFL，微软雅黑亦可用），交付记录字体名与协议。

## 两种发表形态

两者同链路（`draft/add` → `freepublish/submit`），都不占群发次数、不推送粉丝，默认用它；用户明确说「群发 / 所有人都能收到」才走 `mass`。逐字段表见 03 册。

- **图文 news**（文字主角 + 配几张图）→ `draft-add`，字段与 HTML 见 01 册。
- **贴图 newspic**（图主角 + 文字当图注，首图即封面，上限 20 张）→ `draft-add-newspic`，见 02 册。
