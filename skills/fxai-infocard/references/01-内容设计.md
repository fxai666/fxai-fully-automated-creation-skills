# 01 · 内容设计（贴片里放什么）

> **何时读**：写 infocards.json 的文字、定内容类型、定密度与位置时机时。

## 三层分工

| 层 | 位置 | 跟什么走 | 内容从哪来 | 谁做 |
|---|---|---|---|---|
| **字幕**（subtitle） | 画面底部 | 跟语音逐句 | 语音全文 | `fxai-lyric-subtitle` |
| **标题卡**（title card） | 画面顶部 | 跟节拍 | 每拍一句路标 | `fxai-title-card` |
| **信息贴片**（infocard） | 画面任意位置 | 跟讲解节奏 | 另外写的辅助补充 | 本技能 |
| **封面**（cover） | 片头静态帧 | 不跟时间 | — | `fxai-poster` |

🔴 贴片内容与口播并行：口播讲 A，贴片补 A 的背景、解释、提醒、数据、来源。
贴片文字另写，不从口播文案提炼，不复读字幕，不重复标题卡。

## 内容类型

| 类型 | 说明 | 推荐形状 |
|---|---|---|
| 名词解释 | 出现陌生概念时给出定义 | card |
| 数据 / 来源补充 | 补一个数字、出处、背景数据 | chip / card |
| 操作提示 | 命令、路径、按钮位置 | card |
| 注意事项 | 提醒易错处、前置条件 | card |
| 背景 / 延伸说明 | 补充语境、类比 | card |
| 小贴士 | 可操作的经验 | capsule / card |
| 短关键词 / 标签 | 并列要点、tag | capsule / chip |
| 引用 / 对话 | 他人原话、引语 | bubble（尾巴指向说话人） |
| 疑问 / 悬念 | 勾住观众 | bubble |

## 硬约束

- **一条一个信息点**：长句拆成多条错峰出现。
- **字数上限**：card ≤ 20 字；capsule / chip ≤ 6 字；bubble ≤ 12 字。
- **密度**：每 8~15 秒一条；同一段最多 1~2 条。
- **时机**：这句话被说到的瞬间出现；停留 2.5~4s，说明性内容可到 5s。
- **位置**：避开人脸（尤其嘴部）与底部字幕区（竖屏底部约 260px 基准）。

## 位置预设

`pos` 取 `tl tc tr ml mr bl bc br center`，或 `{"x":0.62,"y":0.4}` 画面比例。

| 预设 | 中心比例 (cx, cy) | 适用 |
|---|---|---|
| tl / tc / tr | 0.28 / 0.50 / 0.72，cy 0.14 / 0.12 / 0.14 | 顶部说明；有标题卡时下移到 ml / mr |
| ml / mr | cx 0.24 / 0.76，cy 0.46 | 侧边解释，竖屏人像最稳（肩线两侧空区） |
| bl / bc / br | 0.28 / 0.50 / 0.72，cy 0.70 / 0.72 / 0.70 | 下半区补充，停在字幕区之上 |
| center | 0.50, 0.50 | 强调、悬念；竖屏人像会压脸，慎用 |

竖屏人像的头顶与眼睛大约在 cy 0.15~0.35：顶部预设取 cy 0.12~0.14 贴在上边缘，
侧边预设取 cy 0.46 落在肩线两侧；底部预设取 cy 0.70~0.72，让贴片下沿停在字幕区之上。

🔴 **中景人物占画面 60% 宽，顶部贴片必然压头发**。实测 768x1280 的中景口播，
人物头发横跨 cx 0.30~0.72，`tr` / `tl` 的贴片宽度过半屏，左/右边缘一定切进头发，
看起来像「贴片插进脑袋」。这种画面**优先放下半区**（`bl` / `br`，cy 0.66~0.70）：
压的是毛衣或背景，深色板对比反而更清楚。非要用顶部，就把文字压到 6 字以内用 `capsule`。

**贴片下沿与字幕之间留 120px 以上**（768 宽基准）。字幕基线约 y 1140，
`bl`/`br` 的 cy 超过 0.72 就会贴到字幕上，看着像两行字挤在一起。

## 多条共存

- 两条贴片时间重叠时，位置分到不同象限。
- 同象限叠放按 `t` 顺序压栈，后出的盖住先出的。
- 同一时刻可见贴片不超过 2 条，超出时把后一条的 `t` 往后挪。
