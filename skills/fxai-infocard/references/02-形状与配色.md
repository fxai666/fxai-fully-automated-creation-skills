# 02 · 形状与配色

> **何时读**：选形状、气泡尾巴、指示箭头、主题、字体、动效时。

## 十三种形状

| shape | 样子 | 用途 |
|---|---|---|
| `card` | 方块卡片，带顶部强调条 | 默认；说明 / 解释 / 长句 |
| `bubble` | 圆角矩形气泡，可加尾巴 | 引用 / 对话 / 疑问 |
| `round` | 椭圆泡泡，可加尾巴 | 干净对话泡；低 bg_alpha 即透明泡 |
| `cloud` | 云朵泡泡（一圈小凸包） | 漫画对话 / 旁白 / 内心 os |
| `capsule` | 胶囊袋，全圆角 | 短关键词 / 标签 / 数字 |
| `chip` | 小方块，小圆角 | 并列标签 / 短补充 |
| `note` | 便签纸，右下角折起 | 提醒 / 待办 / 随手记 |
| `ribbon` | 绶带，左右燕尾缺口 | 结论 / 口号 / 强调横幅 |
| `tag` | 尖标签，右端收尖带孔 | 名词标注 / 价格 / 指向物 |
| `bookmark` | 书签，顶部色带 + 底边中间凹 V | 挂在画面边缘的短标注 |
| `label` | 纸签，内外双框，吊牌感 | 名词卡 / 价格牌 / 提示牌 |
| `underline` | 文字下方一条粗线，无面板 | 关键词强调，完全不挡画面 |
| `bracket` | 左右竖线 + 四角短横，无面板 | 引用区间 / 重点框选 |

**两类画法**：前十一种铺面板（渐变 + 投影 + 细描边），轮廓按形状遮罩生成；
`underline` / `bracket` 只画线，不铺面板，`bg_alpha` 与 `theme` 的上下渐变对它们不生效，
只用 `theme` 的 `bar` 取线色、`text` 取字色。

- `note` 的折角、`ribbon` 的燕尾、`tag` 的尖角、`bookmark` 的 V 口由高度决定大小，宽度会自动让出对应空间。
- `bookmark` 的 V 口只占底边中段，两侧留平边；`label` 的外框是主题描边，内框用 `bar` 色。
- `underline` 的线只覆盖文字宽度，不延伸到内边距。
- 这两类标注形状支持 `arrow`，可与箭头组合指向物体。
- 🔴 标注形状不铺底，字色直接压在画面上：浅背景用 `light`（深字），深背景用 `dark`/`tech`/`brand` 等（白字）。
- 🔴 铺面板的形状也要看底色：面板与背景同色系时（米白毛衣上用 `light`、白墙前用 `light`）边界糊成一片，
  换 `dark` / `tech` / `brand` 并把 `bg_alpha` 提到 210 以上。**先抽一帧看贴片落点，再定 theme。**
- 竖屏人像的下三路（`bl` / `bc` / `br`）基本都压在衣服上，`cy` 0.70 一带是胸口与手臂，
  贴片选高对比 theme，或改走 `tl` / `tr` 挂画面边缘。

## 气泡尾巴（bubble / round / cloud 通用）

| 字段 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `tail` | `triangle` / `bent` / `none` | `triangle` | 直小三角 / 弯角斜指 / 无尾巴 |
| `tail_side` | `bottom` / `top` / `left` / `right` | `bottom` | 尾巴挂在哪条边 |
| `tail_at` | 0~1 | 0.5 | 沿边位置，指向说话人时调到对应比例 |
| `tail_bend` | -1~1 | 0 | 弯角尾巴的弯向幅度，`tail:"bent"` 时生效 |
| `thought` | `true` / `false` | `false` | 仅 cloud：换成「一串变小圆」的思考尾泡 |

多个人各放一个 `cloud` / `round` 泡，用 `tail_side` + `tail_at` 指向对应说话人。

## 指示箭头（任意形状）

| 字段 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `arrow` | `"curve"` / `"straight"` / 对象 | — | 画一道指示箭头 |
| `arrow_dir` | `bl` `br` `tl` `tr` `left` `right` `up` `down` | `bl` | 从贴片边角射出的方向 |
| `arrow_color` | `bar` / `text` / `#rrggbb` | `bar` | 箭头颜色 |
| `arrow_len` | 像素（基准 768 宽） | 60 | 箭头长度 |
| `arrow_width` | 像素（基准） | 5 | 线宽 |

`arrow` 写成对象时字段名取 `kind` / `dir` / `color` / `len` / `width`。

## 八套主题

| theme | 配色 | 默认 bg_alpha | 适用 |
|---|---|---|---|
| `dark` | 深蓝黑 | 160 | 默认，通用 |
| `light` | 白浅灰 | 200 | 浅色画面 |
| `brand` | 品牌橙 | 205 | 品牌 / 警示 |
| `tech` | 科技蓝 | 165 | 数码 / AI / 工具 |
| `neon` | 霓虹紫 | 165 | 潮流 / 夜景 / 年轻化 |
| `fresh` | 清新绿 | 165 | 自然 / 健康 / 环保 |
| `sunset` | 暖阳粉 | 165 | 情感 / 生活 / 暖调 |
| `mono` | 极简灰 | 172 | 克制 / 高级感 |

`bg_alpha`（0~255）可逐条覆盖。

## 配色花样

- **深色玻璃感**：`dark` / `tech` / `neon` / `fresh` / `sunset` / `mono`，`bg_alpha` 取 ~160。
- **白色云朵感**：`theme:"light"` + `shape:"cloud"`。
- **透明泡泡感**：任意 theme 把 `bg_alpha` 降到 70~90，`round` / `cloud` 呈透明泡。

## 字体

🔴 白名单顺序：得意黑（SIL OFL）→ 微软雅黑（系统自带，屏幕渲染与输出可用）→
Noto Sans SC（SIL OFL）→ PIL 默认。

- `font:"title"` 强制作得意黑；`capsule` 默认走标题字体。
- 字号随画布对角线缩放，横竖屏观感一致；`fontsize` 与 `max_w` 同比调。
- 交付清单记录字体名与协议，口径见 `fxai-standard` 06 册。

## 五种动效

| anim | 效果 |
|---|---|
| `fade` | 仅淡入淡出（默认） |
| `slide-up` | 从下方上滑入 + 淡入 |
| `slide-left` | 从右侧滑入 |
| `slide-right` | 从左侧滑入 |
| `pop` | 缩放弹入（0.88→1）+ 淡入 |

出场统一淡出，时长 `FADE = 0.3s`。
