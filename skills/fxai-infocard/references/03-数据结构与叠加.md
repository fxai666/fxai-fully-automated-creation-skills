# 03 · 数据结构与叠加

> **何时读**：写 infocards.json 全字段、跑两个脚本、定项目归属、排 ffmpeg 错时。

## infocards.json

```json
{
  "infocards": [
    {"text": "multiref：人物图+场景图一起参考", "shape": "card",
     "pos": "bl", "anim": "slide-up", "t": 8.5, "hold": 3.5, "theme": "tech"},
    {"text": "他说：这能自动化吗？", "shape": "bubble",
     "pos": {"x":0.5,"y":0.7}, "anim": "pop", "t": 14.0, "hold": 3.0,
     "theme": "neon", "tail": "bent", "tail_side": "bottom", "tail_at": 0.5, "tail_bend": 0.5},
    {"text": "看这里", "shape": "chip", "pos": "tr",
     "arrow": "curve", "arrow_dir": "bl", "arrow_color": "#ff6b35", "t": 22.0, "hold": 2.5}
  ]
}
```

| 字段 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `text` | 是 | — | 贴片文字，空则跳过该条；写 `\n` 强制换行（按行断，不参与自动折行） |
| `shape` | 否 | `card` | 十三种形状见 02 册 |
| `pos` | 否 | `bc` | 预设或 `{"x","y"}` 画面比例 |
| `anim` | 否 | `fade` | 五种动效见 02 册 |
| `t` | 否 | 0 | 出现时刻（秒） |
| `hold` | 否 | 3.0 | 停留时长（秒） |
| `theme` | 否 | `dark` | 八套主题见 02 册 |
| `bg_alpha` | 否 | 主题值 | 0~255 |
| `fontsize` | 否 | 30 | 基准 768 宽，随画布对角线缩放 |
| `max_w` | 否 | 360 | 断行宽度，基准同上，与 `fontsize` 同比调 |
| `font` | 否 | — | `"title"` 强制作得意黑 |
| `tail` / `tail_side` / `tail_at` / `tail_bend` | 否 | 见 02 册 | 气泡尾巴 |
| `thought` | 否 | `false` | 仅 cloud |
| `arrow` / `arrow_dir` / `arrow_color` / `arrow_len` / `arrow_width` | 否 | 见 02 册 | 指示箭头 |

顶层也接受裸数组（直接 `[{...}, {...}]`），键名 `infocards` 或 `captions` 均可。

## 两个命令

```bash
# ① 内容 → 紧致半透明 PNG + render.json
python -B scripts/make_infocards.py --infocards infocards.json --size 768x1280 --out _tmp/infocards

# ② 叠到视频上
python -B scripts/overlay_infocards.py --video in.mp4 \
       --render _tmp/infocards/render.json --out out.mp4
```

- `--size` 用目标视频尺寸；`overlay` 阶段自动 ffprobe 真实尺寸。
- 输出保持原分辨率 / 帧率 / 音轨（`-c:a copy`），只重编码画面。
- 编码优先 `h264_nvenc`，失败回落 `libx264`；`--crf` 默认 20。
- 中间产物（PNG / render.json）写 `_tmp/`，不进交付目录。

### 先看效果再叠视频

`make_infocards.py` 加 `--preview`，额外输出 `preview.png`：深灰底、每条贴片一行，
标注形状 / 主题 / 尺寸 / 时间码。只跑渲染阶段就能确认字号、配色、断行与留白，
不必等 ffmpeg 合成完。

```bash
python -B scripts/make_infocards.py --infocards infocards.json --size 768x1280 \
       --out _tmp/infocards --preview
```

## 项目归属（加工类作业）

贴片属于对已有素材的二次加工，按 `fxai-standard` 01 册「加工作业的项目归属」处理：

```bash
python scripts/fxai_project.py context "<输入视频或目录>" [--workspace <工作区>]
```

- `found: true` → 贴片产物写回该项目目录，成片登记 `video` 段。
- `found: false` → 按返回的 `suggest_mode` 建档后再加工。
- 产物落点、目录整洁、交付自检见 `fxai-standard` 01 / 03 / 04 册。

## 叠加实现的三条约束

1. **fade 在 scale 之前**：`scale` 用 `eval=frame` 逐帧改尺寸，变尺寸流会让后面的
   `fade` 报 Invalid argument。链顺序固定 `format=rgba → fade → scale → overlay`。
2. **loop 输入配 `-shortest`**：`-loop 1 -i png` 是无限流，缺 `-shortest` 时编码不结束。
3. **overlay 的 x/y 不写嵌套 `if()`**：本机 ffmpeg 对该写法报 Invalid argument；
   pop 的缩放放在 `scale` 里做，overlay 用 `overlay_w` / `overlay_h` 居中。

## 排错

| 现象 | 处理 |
|---|---|
| 编码长时间不结束 | 检查输出是否带 `-shortest` |
| `Invalid argument` 出现在 fade | 检查 `fade` 是否排在 `scale` 之前 |
| `Invalid argument` 出现在 overlay | 检查 x/y 是否含嵌套 `if()` |
| 贴片文字偏上或偏下 | 文字层按实心墨迹居中；检查 `INK_T = 220` 与字体回退结果 |
| 贴片糊住画面 | 调低 `bg_alpha` 到 70~120，或换 `light` + `cloud` |
| 贴片和背景分不开 | 面板与底色同色系，换 `dark` / `tech` / `brand` 并提 `bg_alpha` 到 210 以上 |
| 文字压到字幕 | 底部预设改用 `ml` / `mr` / `tr`，或把 `hold` 提前结束 |
| `can't measure length of multiline text` | `text` 里写了 `\n`；`wrap()` 已按行切段，若报错说明脚本是旧版 |
| 叠加后烧字幕报 `Error parsing filterchain 'ass=xxx.ass'` | 滤镜参数要写全：`ass=filename=xxx.ass`；`ass=xxx.ass` 会被当成选项解析而失败 |
