# fxai-physical-publish · 物理仿真发布

本技能定义**一条用系统级鼠标键盘驱动真实浏览器的发布通道**：程序不控制浏览器内部，只像人在屏幕上移鼠标、按下松开、敲键盘。

包内不预置任何站点、地址、坐标、账号与凭据；站点差异由使用方在**实例目录**里按本规范录制，命中即复用。

## 什么时候用这条通道

要「完全像真人手动操作」、站点有强行为风控、或页面频繁改版 → **本通道**；要快、要批量、要稳定重放 → `fxai-browser-publish`。两条通道**共用实例目录**，互不覆盖：自动化通道写 `config/sites/<站点>.json`，本通道写 `sites/<站点>.json`；选型对照见 `01` 第七节。

## 铁律（不可退让）

每条一句判据；全文见 `00-铁律与执行细则.md`，28~31 见 `09`。

1. 🔴 **零注入**：不用无头、不接 CDP、不注入脚本、不改 DOM，浏览器按日常方式启动。
2. 🔴 **零凭据**：不读不写 cookie、不存登录态；登录停下等人，程序只判是否还在登录页。
3. 🔴 **坐标可固定，行为必须随机**：轨迹、节奏、间隙每次重抽样，禁用固定延时。
4. 🔴 **停顿跟着动作走**：连贯动作 `gap`（0.04~1.8s），`pause` 只给「要看 / 要找 / 要想」，禁用每步停。
5. 🔴 **拍摄前先激活**：截图 / 点击前确认目标窗口在前台，否则截到遮挡物。
6. 🔴 **区域存相对客户区**：记录客户区尺寸，偏差 >4% 拒绝执行并提示重录。
7. 🔴 **只按区域点**：区域必须工具定位（`locate.py` / 人工框选）。
8. 🔴 **让人动手不置顶，跟人说话就最小化**：人工环节 `reveal`，交回对话 `minimize`，人做完 `release`；禁用 `HWND_TOPMOST`。
9. 🔴 **随时可中止**：长按 `ESC` 立即停止。
10. 🔴 **一次只操作一个窗口**：窗口不唯一先 `windows` 确认，禁用盲点。
11. 🔴 **人工闸门不可跳过**：登录与投稿必须有明确确认节点，验证类按第 17 条走。
12. 🔴 **流程必须能一条命令重放**：不许边跑边现算坐标，卡顿混进节奏。
13. 🔴 **窗口只有一个，一直用下去**：优先复用 `config/window.json` 记的那个；不关窗、不新开、不 `Ctrl+T` 堆标签。
14. 🔴 **合集以 B 站为唯一标准，B 站必须第一个发**：后面平台照抄；界面无法建合集就让用户手工建；无合集概念记 `collection: "n/a"`。
15. 🔴 **动态项现场读**：话题、合集、分区、可见范围当场选；写死只有台账坐标。
16. 🔴 **文案分两层**：B 站技术向（链路 / 模型 / 参数），其余娱乐向（情绪 / 钩子 / 流量标签）；来源是 `平台文案.json` 的 `platforms.<站点>.tier`。
17. 🔴 **人工验证：先点「发送验证码」，叫人配合**：任何平台、任何类型；绝不代收代填代看。
18. 🔴 **动手前先自检锁屏**：`api.assert_ready()`；锁屏时 `SendInput` 报码 5、`BitBlt` 失败，先查锁屏再怀疑代码。
19. 🔴 **跨站跳转先确认真跳过去了**：导航后轮询窗口标题；「离开此网站？」只用 Tab → Enter。
20. 🔴 **AI 生成标记一票否决**：每站都要勾；找不到入口先滚到底展开「更多设置」，全页无才记 `declare_ai: "none"`。
21. 🔴 **原创声明有就必勾**：与 AI 标记不冲突，两个都要勾；漏勾等于放弃权重与维权依据。
22. 🔴 **审核中就是发出去了**：出现「审核中 / 处理中」即结束，不等结果、不开播放页、不做验收。
23. 🔴 **外发前跑合规清单**：六项必过——AI 标记、原创声明、封面、合集、可见范围、默认勾选项。
24. 🔴 **流程按三次收敛**：`v0-init` 探路 → `v1-observed` 提炼 → 连续两次无临时改动才升 `v2-stable`；`scale` 恒为 1.0。
25. 🔴 **封面只引 key**：台账只写 `{"cover": {"key": "horiz_16x9"}}`，尺寸版式归 `fxai-poster`；竖版标题竖排贴空余边，不压脸。
26. 🔴 **上传没到 100% 不提交**：进度 100% + 封面帧出现 + 能点开预览，三样齐才填表。
27. 🔴 **「点发布」是最后一个动作**：点完只看有无错误提示，无错立刻结束，不截图、不开作品；例外是第 17 条验证弹窗。
28. 🔴 **发布控件记「距视口底边」**：`anchor=bottom` + `bottom_offset`，滚到底反推 y；存量走 `reanchor`。
29. 🔴 **点前只截那一小块校验**：ROI 比模板，命中才点；未命中才全屏重扫、复验。
30. 🔴 **表单文本一律粘贴，清空只用框内拖选**（`select` / `clear`）：**禁用 Ctrl+A**——焦点不在框里时 Chrome 整页全选。
31. 🔴 **开工先诊断**：锁屏、客户区原点、独立确认窗；确认窗就是普通弹窗，点「离开/确定」继续。

## 快速开始

```bash
PY="<python>"; S="$HOME/.workbuddy/skills/fxai-physical-publish/scripts"

$PY -B $S/publish_cli.py env                     # 自检
$PY -B $S/publish_cli.py launch --fit 1500x900   # 开浏览器
$PY -B $S/publish_cli.py preflight --site <站点>      # 开工诊断
$PY -B $S/publish_cli.py mark --site <站点> --name publish_btn --anchor bottom --color ksred --text 发布
$PY -B $S/publish_cli.py probe --site <站点> --name publish_btn [--learn|--relocate]
$PY -B $S/publish_cli.py reanchor --site <站点> --names publish_btn --anchor bottom
$PY -B $S/publish_cli.py run --site <站点> --flow video   # 跑流程
$PY -B $S/publish_cli.py reveal                  # 缩窗让位（不置顶）
$PY -B $S/publish_cli.py minimize                # 最小化，让屏给对话
```

其余命令见 `08-步骤类型与回执.md`，目录归属见 `00` 第三节。
相邻技能：`fxai-browser-publish`、`fxai-poster`、`fxai-standard`。
