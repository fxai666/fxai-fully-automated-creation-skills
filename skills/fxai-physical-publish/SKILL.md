# fxai-physical-publish · 物理仿真发布

本技能定义**一条用系统级鼠标键盘驱动真实浏览器的发布通道**：程序不控制浏览器内部，只像人一样在屏幕上移动鼠标、按下松开、敲键盘。

包内不预置任何站点、地址、坐标、账号与凭据；站点差异全部由使用方在**实例目录**里按本规范录制，命中即复用。

## 什么时候用这条通道

要「完全像真人手动操作」、站点有强行为风控、或页面频繁改版改坐标更划算 → **本通道**。
要素材快、要批量、要稳定重放 → `fxai-browser-publish`。

两条通道**共用同一个实例目录**，互不覆盖：自动化通道写 `config/sites/<站点>.json`，本通道写 `sites/<站点>.json`。
选型对照表见 `references/01-通道原理与边界.md` 第七节。

## 铁律（不可退让）

每条一句判据；全文与处置见 `references/00-铁律与执行细则.md`。

1. 🔴 **零注入**：不用无头、不接 CDP、不注入脚本、不改 DOM，浏览器按用户日常方式启动。
2. 🔴 **零凭据**：不读不写 cookie、不存登录态；登录停下等人，程序只判断是否还在登录页。
3. 🔴 **坐标可固定，行为必须随机**：轨迹、节奏、间隙每次重抽样，禁止固定延时。
4. 🔴 **停顿跟着动作走**：连贯动作 `gap`（0.04~1.8s），`pause` 只给「要看 / 要找 / 要想」，禁止每步都停。
5. 🔴 **拍摄前先激活**：截图 / 点击前确认目标窗口在前台，被遮挡截到的是遮挡物。
6. 🔴 **区域存相对客户区**：记录录制时客户区尺寸，偏差 >4% 拒绝执行并提示重录。
7. 🔴 **只按区域点，不按像素猜**：区域必须工具定位（`locate.py` / 人工框选），不许手写估算。
8. 🔴 **让人动手不置顶，跟人说话就最小化**：人工环节 `reveal`，交回对话 `minimize`，人做完 `release`；永不用 `HWND_TOPMOST`。
9. 🔴 **随时可中止**：长按 `ESC` 立即停止，程序不得吞按键。
10. 🔴 **一次只操作一个窗口**：窗口不唯一先 `windows` 确认，禁止盲点。
11. 🔴 **人工闸门不可跳过**：登录与投稿提交必须有明确人工确认节点，验证类按第 17 条走。
12. 🔴 **流程必须能一条命令重放**：不许边跑边现算坐标，模型卡顿会混进节奏、下次也复现不出来。
13. 🔴 **窗口只有一个，一直用下去**：优先复用 `config/window.json` 记的那个，没有再做退让；不关窗、不新开、不 `Ctrl+T` 堆标签。
14. 🔴 **合集以 B 站为唯一标准，B 站必须第一个发**：后面平台照抄；界面不能建合集就停下来让用户手工建；站点无合集概念记 `collection: "n/a"`。
15. 🔴 **动态项一律现场读**：话题、合集、分区、可见范围当场看当场选；写死的只有台账里的坐标。
16. 🔴 **文案分两层**：B 站技术向（链路 / 模型 / 参数），其余娱乐向（情绪 / 钩子 / 流量标签）；来源是 `平台文案.json` 的 `platforms.<站点>.tier`。
17. 🔴 **遇到人工验证：先点「发送验证码」，叫人配合，接着做**：任何平台、任何验证类型；绝不代收代填代看，绝不绕过。
18. 🔴 **动手前先自检锁屏**：`api.assert_ready()`；锁屏时 `SendInput` 报错码 5、`BitBlt` 失败，先查锁屏再怀疑代码。
19. 🔴 **跨站跳转先确认真跳过去了**：导航后轮询窗口标题；「离开此网站？」只用键盘 Tab → Enter，不用坐标点。
20. 🔴 **AI 生成标记一票否决**：每个平台都要勾；找不到入口先滚到底展开「更多设置」，全页确无才记 `declare_ai: "none"` 并注明。
21. 🔴 **原创声明有就必勾**：与 AI 标记不冲突，两个都要勾；漏勾等于放弃权重与维权依据。
22. 🔴 **审核中就是发出去了**：出现「审核中 / 处理中 / 仍在检查」即结束该站，不等结果、不开播放页、不做可播放验收。
23. 🔴 **外发前跑合规清单**：六项必过——AI 标记、原创声明、封面、合集、可见范围、默认勾选项；这是提交前的门。
24. 🔴 **流程按三次收敛**：`v0-init` 探路 → `v1-observed` 提炼（同时提速）→ 连续两次无临时改动才升 `v2-stable`；`scale` 恒为 1.0。
25. 🔴 **封面只引 key**：台账只写 `{"cover": {"key": "horiz_16x9"}}`，尺寸与版式归 `fxai-poster`；竖版标题竖排贴空余边，不横排压脸。
26. 🔴 **上传没到 100% 不提交**：进度 100% + 封面帧出现 + 能点开预览，三样齐了才填表。
27. 🔴 **「点发布」是本站最后一个动作**：点完只看有无错误提示，无错立刻结束，不截图、不开作品、不复核；唯一例外是第 17 条验证弹窗。

## 快速开始

```bash
PY="<python>"; S="$HOME/.workbuddy/skills/fxai-physical-publish/scripts"

$PY -B $S/publish_cli.py env                     # 环境自检
$PY -B $S/publish_cli.py launch --fit 1500x900   # 开真实浏览器并锁画布尺寸
$PY -B $S/publish_cli.py mark --site <站点> --name <区域>  # F7 左上 / F8 右下 录制
$PY -B $S/publish_cli.py run --site <站点> --flow video   # 跑站点流程
$PY -B $S/publish_cli.py reveal                  # 缩窗让位给人（不置顶）
$PY -B $S/publish_cli.py minimize                # 最小化，把屏幕让给对话
```

其余命令见 `references/08-步骤类型与回执.md`。
