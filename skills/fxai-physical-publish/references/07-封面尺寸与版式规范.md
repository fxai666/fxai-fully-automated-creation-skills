# 封面规格（指针 · 本包不复写规范）

🔴 封面尺寸、比例、各站最小尺寸、版式 CSS、出图命令与看图判据的**唯一出处**：

- `fxai-poster/references/11-封面多尺寸与平台规格.md` —— 规范正文
- `fxai-poster/cover_sizes.json` —— 尺寸与站点规格数据真源
- `fxai-poster/cover_styles.py` / `cover_batch.py` —— 版式实现与出图入口

本包不复制尺寸表、不复写版式规则、不另立一套尺寸。

---

## 本包只做三件事

| 位置 | 只许写什么 |
|---|---|
| `sites/<站点>.json` → `cover.key` | `vert_9x16` / `horiz_16x9` 等 key |
| `sites/<站点>.json` → `cover.source_of_truth` | `fxai-poster/cover_sizes.json` |
| 项目 `封面.json` | 底图 + 文案 + 要出哪几个 key |

四条口径（细节见 `11` 册）：
1. 竖屏站一律 `vert_9x16`（1080×1920），横版站一律 `horiz_16x9`（1920×1080），**两张覆盖 13 站**；项目 `封面.json` 的 `sizes` 只列这两个 key。
2. 唯一硬例外 CSDN：`crop: false`，裁剪下限 960×540，竖版裁完被拒，只能横版。
3. 发布前合规清单里的「封面」项，只验「该站 key 对应的图存在且已过看图验收」，不验像素。
4. **平台上传框比例 ≠ 出图比例**：抖音封面向导竖 3:4 / 横 4:3（用户实测）是平台自己的裁切框，由平台裁切，不另出第三张；规格见 `cover_sizes.json` 的 `upload_frame`。竖排文字须落在 3:4 安全区内。

---

## 边界

封面尺寸是**平台公开的设计要求**，不是操作坐标、不是账号凭据，可以预置在技能包里；
站点按钮坐标仍只存在本包 `sites/*.json` 的 `regions` 中，两边互不越界。
