# 05 · 发布前合规清单（缺一不可）

> 这份清单是**外发前的最后一道闸门**。每一条都是「必须做」，不是「建议做」。
> 漏一条的代价：限流、判定违规、平台事后追责、账号权重下降。
> 2026-11-08《潮汐来信》全平台发布时，视频号漏了「内容创作声明」与「原创」勾选，
> 由用户事后手工补上——本文件即为此而写。
> 🔴 本清单**只在提交前跑**；点完发布就收工，不做发布后验收（铁律 22 / 27）。

---

## 一、两条硬性声明

### 1. AI 生成标记（每个平台都有，位置各异）

判定标准：**内容只要有一项是 AI 生成的，就必须标记**。
MV 场景下音乐是人声合成、画面是人像生成、文案可能也是模型写的，三项都算。

| 平台 | 菜单路径 | 选项文案 | 备注 |
|---|---|---|---|
| 抖音 | 发布页 → 自主声明 | 内容由 AI 生成 | **必选**（6 项单选）；弹窗另 5 项为 个人观点/转载/营销/虚构演绎/无需声明，**全页无「原创」选项**，记 `original: none`。发布可能弹账号级身份验证，见第二节 |
| 快手 | 发布页 → 内容声明 | 内容为 AI 生成 | 位置在描述框下方 |
| 视频号 | 发表页 → 内容创作声明 | 含 AI 生成内容 / 内容由 AI 生成 | **必选**；不选会限流，且事后难补 |
| 百家号 | 编辑页 → 创作声明 | 含 AI 生成内容 | **必填**，不选只在顶部弹一行红字 |
| 今日头条 | 发布页 → 作品声明 | AI 生成 | 与「视频生成图文」相邻，别顺手误勾那个 |
| B 站 | 投稿页 → 创作声明 | 含 AI 生成内容 | 在页面底部，需要滚 |
| 小红书 | 发布页 → 更多设置 | 笔记含 AI 生成内容（如提供） | 入口随版本变，找不到就记 `none` |
| YouTube | 编辑页 → 视频元素 → Altered content | 是 / 否 | 英文界面叫 *Altered content*，中文叫「改编内容」或「合成内容」 |
| TikTok | 发布页 → 设置 → 显示更多 → AI 生成的内容 | 开关打开，弹窗点「开启」 | 开关打开后还有一次说明弹窗，两层都要过 |
| 百度贴吧 | **视频贴不提供** | — | 🔴 视频贴弹层里内容声明整块 `display:none`，只有图文贴有「贴子含AI内容」。**AI 标识写进标题**（如「AI原创音乐MV」），标题是唯一显式标识 |
| 知乎 | 视频发布页 → **视频标记**（必填） | 弹窗「添加视频标记」→ 含AI生成内容 → 确认 | 点「选择标记」后弹窗有约 2 秒延迟，别当成没点上。入口地址 `zhihu.com/upload-video` |
| 微博 | 发布页 → **内容声明**（必填） | 含 AI 生成内容（可多选，勾完点「确定」） | 同页另有「类型」必填单选：原创 / 二创，选原创 |
| CSDN | **完全没有** | — | 🔴 视频发布页只有封面/标题/标签/简介四项，无任何声明入口。**AI 标识必须写进标题开头与简介正文**（如标题「AI 音乐 MV 全流程：…」，简介末句「音乐与人像画面由 AI 生成」） |

**找不到入口 ≠ 可以跳过。** 正确顺序：
1. 先看当前可视区域
2. 滚到底
3. 展开「显示更多 / 更多设置 / 高级设置」
4. 都找过确实没有，才在台账 `declare_ai: "none"` 并写明「已全页搜索未找到」

### 2. 原创声明（有就必勾）

| 平台 | 位置 | 文案 |
|---|---|---|
| 视频号 | 发表页 → 原创声明 | 声明原创（勾选即代表作品为本人原创） |
| B 站 | 投稿页 → 自制/转载 | 选「自制」 |
| 今日头条 | 发布页 → 声明原创 | 勾选「原创」 |
| 百家号 | 编辑页 → 原创 | 「原创」开关 |
| 微信公众号类 | 文末 | 原创声明 |
| 百度贴吧 | **视频贴不提供**；图文贴有「贴子原创声明」单选 | — |

**AI 标记与原创声明不冲突**：作品是我们原创的（词曲、编曲、画面设计、剪辑都是我们的），
只是生成手段用了 AI。两个都要勾，不能因为勾了 AI 就不勾原创，反之亦然。

**例外要留痕**：贴吧视频贴确实两项都没有（不是没找到，是产品形态就没有）。
这种情况在台账 `compliance` 里记 `none` + 说明「视频贴整块无此选项，已核查」，
并把 AI 标识落到标题文案里。不要因为「这站没有入口」就整条放过。

### 3. 其他常被忘的必填项

- **封面**：抖音要横竖双封面；头条默认「封面截取」必须切「本地上传」；TikTok 默认截帧要换设计稿
- **合集/播放列表**：按 `<hub>/config/collections.json` 的 canonical 名称，站上没有就建同名的
- **可见范围**：默认要选「公开 / 所有人」，不是「仅自己」「私享」
- **默认勾选的坑**：头条「视频生成图文」默认勾上，会额外发一篇低质图文，要取消

## 二、发布动作本身的策略

### YouTube：检查中直接发，不等

上传完成后平台会提示「我们仍在检查你的内容」。
**不要点「返回」保留私享**——那等于白传一次。
直接点「仍然发布 / 发布」，视频进入列表，平台在后台异步检测，
检测结果只影响是否被限制，不影响「已发布」这个事实。

判定标准：**点了发布、页面没有错误提示 = 发布完成**。
之后**不做任何复查**，不守在页面上等，不点开作品，不回列表数条数。

同理适用于：B 站「审核中」、视频号「处理中」、快手/百家号/头条「审核中」——
**状态是审核中就是发出去了**，接着做下一个平台，不要回头等。

### 发布按钮的「点一下 + 回车」

快手、视频号、抖音等多个站点的发布按钮单击不提交（前端要 keydown 事件）。
标准动作：`click` → `wait 800ms` → `key enter`。
🔴 点完**只看「有没有错误提示」：没有就立刻收工**，不截图确认跳转、不点开作品、
不比对列表条数、不做可播放验收（铁律 27）。别把流程跑长。

## 三、外发前逐项自检（打印出来照着勾）

```
[ ] 标题：没用文件名，字数在平台限制内，没有非法字符（· 在视频号短标题里非法）
[ ] 描述/简介：含 AI 生成说明、含话题标签、没被截断
[ ] 话题：数量在平台上限内（快手 ≤ 4 个），贴完确认没被整段清空
[ ] 封面：已换成设计稿，不是自动截帧
[ ] AI 生成标记：已勾 / 已开
[ ] 原创声明：已勾
[ ] 合集：已选或已建，名称与 canonical 一致
[ ] 可见范围：公开 / 所有人
[ ] 默认勾选项：该取消的已取消（头条视频生成图文等）
[ ] 点发布后：页面无错误提示 → 立刻收工，不做任何验收
```

第 5、6 两项**不建议「先发后补」**——视频号的创作声明和原创一旦漏了，
要么靠用户手工补，要么这条内容的权重就废了。


### 人工验证协作（2026-11-09 用户强制口径，适用所有平台）

🔴 **遇到要人验证的地方，不要停住、不要静默、不要存草稿走人**：

1. **直接点「发送验证码 / 获取验证码 / 发送短信」**（现场扫描定位，不许估算坐标）
2. `reveal` 让位（不置顶），**在对话里明确说一句**：「需要你输入验证码，我在这儿等你；
   填完告诉我，我点『验证』接着做」——人就在旁边，等一下即可，**不许卡住没反应**
3. 用户本人填码 / 完成人脸 / 扫码后，程序只点「验证 / 确定」提交，
   **然后立刻收工**，不跑任何后续流程
4. 🔴 **绝不代收、代填、代看验证码，绝不绕过验证**；验证码只经账号本人之手

适用：短信码、刷脸、扫码、登录密码、滑块、邮箱码……**任何平台、任何验证类型**，
不只是抖音。旧口径「先找免验证入口 → 确认硬拦 → 存草稿交用户 → 记 `blocked_verify`」
**已废止**。

**抖音实测存档（2026-11-09）**：网页端点「发布」会弹「接收短信验证码」，与草稿、
会话、是否重新上传无关（草稿恢复 / 关弹窗再点 / 全新上传三次都弹）。
「其他验证方式」只有 短信 / 刷脸 / 登录密码 / 发送短信，没有免验证入口；抖音无独立草稿箱，
草稿只在上传页「继续编辑」恢复。
本人填 6 位码 → 点「验证」→ 平台自动完成发布并跳转，**不需要再点一次发布按钮**。
`verify_btn` 坐标已录在 `sites/douyin.json`；「发送验证码」按钮坐标下次现场定位后补录。

🔴 发布完成判定：点了发布且无错误提示即成功，**不做可播放验收**（列表条数、
详情页状态、公开播放页画面这些一律不查，铁律 22 / 27）。
