# fxai-outro-card · 片尾卡

给一支视频补一张品牌收束卡：深色渐变底 + 官方 Logo + 品牌名 + 标语，按需带联系方式。
一张 PNG 就能用，也可以直接拼成成片。

## 什么时候用

- 用户明确要「加片尾 / 做个片尾 / 后面接一个我们的卡 / 把原片的平台尾卡换成我们的」。
- 🔴 **按需调用**：本技能不挂在常规交付链上，成片本身不带片尾；需要片尾时调本技能出图拼接，拼完另起文件名。
- 片头卡走 `fxai-title-card`，画面补充层走 `fxai-infocard`，封面走海报能力——这三样各有归属技能，本技能只做片尾。

## 三个变体速览

| 变体 | 画面内容 | 用在哪儿 |
|---|---|---|
| `clean` 干净版（默认） | 品牌名 + 标语，**无任何联系方式** | 公域平台（抖音 / 视频号 / 小红书 / B站），平台把片尾联系方式判为站外引流 |
| `contact` 带联系版 | + 官网 / 微信 / QQ群 | 自有渠道（私域、社群、官网、直接发客户） |
| `xianguyun` 仙宫云版 | 上面全部 + 独立一行「仙宫云 · 镜像广场搜凤希AI」 | 仙宫云渠道 |

一条命令出图：

```bash
python -B scripts/make_brand_card.py --size 960x512 --variant clean
# 三个变体一次出：--variant all
# 竖屏成片：--size 512x960（版式自动改成上 Logo 下文字并居中）
```

默认落点 `assets/brand/尾卡_<变体>_<W>x<H>.png`，可直接取用；要放到别处加 `--out`。

## 硬规矩（细则在分册）

- **品牌资源只用全局配置**：Logo 取 `~/.workbuddy/fxai_global.json` 的 `brand.avatar_512`，品牌名、标语、官网、微信、QQ群全部取 `brand` 段，**不自行生成品牌图形、不自造品牌信息**。
- **片尾段同样带 AI 角标**：`brand.ai_mark_text`（当前 `凤希AI生成`）在片尾段照常在位，不因「画面本身就是品牌卡」而省。
- **帧数与音轨**：片尾段帧数按需定（常见做法是补足到与源片等长），拼接后成片帧数、帧率、音轨必须锁死并逐一校验。
