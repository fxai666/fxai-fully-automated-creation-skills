# 02 · 生成与拼接

## 一、只出图（最常见）

```bash
cd <本技能目录>
python -B scripts/make_brand_card.py --size 960x512 --variant clean
```

| 参数 | 说明 |
|---|---|
| `--size WxH` | 必须与成片画幅一致。横屏 `960x512` / `1920x1080`，竖屏 `512x960` / `1080x1920` |
| `--variant` | `clean`（默认）/ `contact` / `xianguyun` / `all`（三个一起出） |
| `--out` | 指定输出 PNG 路径；单变体时有效，不给就落到 `assets/brand/` |

默认落点：`assets/brand/尾卡_<变体中文名>_<W>x<H>.png`。
预置尺寸 `960x512` 与 `512x960` 两个常用档，其他画幅现跑一次即可。

出图后**必须目视核对**：Logo 与文字块对齐、信息行没越界、末行高亮正确、画面没有联系方式（干净版）。

## 二、拼到成片上

片尾卡是静态图，拼接分四步，任何一步都要校验产物：

```bash
# 1) 静态图 → N 帧视频（锁帧率，帧数=需要补的帧数）
ffmpeg -y -v error -loop 1 -framerate 30 -i 尾卡.png \
  -t 3.000000 -vf "scale=960:512:flags=lanczos,setsar=1,format=yuv420p" \
  -c:v libx264 -crf 16 -preset medium -r 30 -frames:v 90 尾卡片段.mp4

# 2) 动作本体 + 片尾段 拼接
ffmpeg -y -v error -i 成片_动作本体.mp4 -i 尾卡片段.mp4 \
  -filter_complex "[0:v]fps=30,setsar=1,format=yuv420p[v0];[1:v]fps=30,setsar=1,format=yuv420p[v1];[v0][v1]concat=n=2:v=1:a=0[vc];[vc][2:v]overlay=W-w-24:H-h-24:format=auto[vo]" \
  -i AI标识角标.png -i 成片音轨.wav -map "[vo]" -map 3:a \
  -c:v libx264 -crf 18 -preset medium -pix_fmt yuv420p \
  -c:a aac -b:a 192k -ar 44100 -r 30 -frames:v 331 -movflags +faststart 最终成片.mp4
```

要点：
- **帧数锁死**：`-frames:v` 写总帧数，事后用 `ffprobe -count_frames` 的 `nb_read_frames` 复核，不用容器 `nb_frames` 当判据。
- **角标全程在位**：`overlay=W-w-24:H-h-24` 叠在拼接结果上，片尾段也带。
- **音轨重铺**：片尾段没有原声，音轨要按总时长重新 `atrim` 铺满，末尾淡出。
- **画幅一致**：片尾图与成片同宽高，`scale` + `setsar=1` 对齐，保证拼出来不变形。

## 三、踩过的坑

- 🔴 **`-af atrim=... -t <时长>` 会把音频切短**：ffmpeg 的输出时间戳偏移会让 `-t 11.033333` 只写出 10.966667（少 1/15 秒），末尾留一段没声音。`atrim` 本身已精确，**去掉 `-t`** 就对齐；脚本里加时长断言 `abs(a_dur - DUR) <= 0.002`。
- **竖屏走竖屏参数**：竖屏是上 Logo 下文字、全部居中，脚本按 `W < H` 自动切换；手改参数时按竖屏基准 `512×960` 取值。
- **干净版只留两行**：内容只有品牌名与标语，整块垂直居中，画面里没有分隔线与信息行。
- **内容加行要重排**：四行信息时压 Logo（172）、压标题（62 号）、压行距（42），画布尺寸保持不变。

## 四、验收清单

- [ ] 片尾图与成片同宽高，`setsar=1`
- [ ] 成片帧数 = 动作本体帧数 + 片尾段帧数，`ffprobe -count_frames` 实测一致
- [ ] 片尾段每一帧都带 `brand.ai_mark_text` 角标
- [ ] 干净版画面里没有任何联系方式；带联系版三行齐全；仙宫云版末行高亮
- [ ] 动作本体末帧 → 片尾首帧是硬切，没有花屏或人物残留
- [ ] 音轨时长 = 成片时长（误差 ≤ 0.002 秒），末尾有淡出
- [ ] 抽帧核对产物存在且非空（ffmpeg 抽不可解码帧会返回 0 且不落文件）
