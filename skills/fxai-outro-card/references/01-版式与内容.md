## 三、三个变体的版式参数

参数按**基准画布**给，脚本再按实际画幅等比缩放：
横屏基准 `960×512`，缩放系数 `s = H / 512`；竖屏基准 `512×960`，缩放系数 `s = W / 512`。

## 四、文案规则

- **品牌名固定 `凤希AI`**，不改写成 `凤希`、`FXAI` 等变体。
- **标语固定 `自动化创作 · 全链路视频生成`**，不改顺序、不删段。
- 干净版到此为止：**画面里不出现官网 / 微信 / QQ群 / 手机号 / 邮箱 / 二维码 / 引流口令**。需要联系方式时写进发布文案、主页简介、评论区置顶，由发布环节处理。
- 带联系版按 `官网 → 微信 → QQ群` 顺序排，缺项跳过不占位。
- 仙宫云版固定加在最后一行：label `仙宫云`、value `镜像广场搜凤希AI`，**用品牌橙高亮**与上面三行区分。

## 五、改版式时注意

- 改字号或行数后，必须重新核对**垂直居中**与**右侧不越界**：信息行 value 起点是 `文字块左边距 + 78`（随缩放），长文案（如 `镜像广场搜凤希AI`）要实测 `textlength` 是否顶到右边距。
- 内容多一行就压字号、压行距、缩 Logo，画布尺寸始终与成片一致。
- 三变体共用同一套视觉，只有信息行数量不同；配色与 Logo 三版统一。
