# 10 · 主体替换工作流

> **何时读**：用户说「主体替换」「仅替换主体」「只换主体」「把这只鸡换成这只猫」「场景不动，只换人」，
> 或任何「只换画面里的某个主体、其余一律不动」的需求；
> 要定交付范围、选提示词模板、决定分段方式、做验收时。

## 一、模式定义

**主体替换**是角色替换的一个具名工作流模式，触发词为「主体替换」「仅替换主体」「只换主体」「只换这一个主体」。模式注册表与命名口径见 SKILL.md「替换工作流模式」。

一句话口径：**只把画面里的指定主体换成参考图那个主体，其余一切按源片原样。**

| 维度 | 执行 | 判据 |
|---|---|---|
| 主体 | 全片指定主体整体换成参考图主体：外观、材质/毛色、花纹、体型、配饰一起换 | 抽帧逐格比对，任一格残留原主体的外观特征即命中 |
| 场景 | 场景、背景、地面、陈设、光源方向与色温保持源片原样 | 场景主材或陈设与源片不同即命中 |
| 表演 | 姿态、动作节奏、朝向、屏幕坐标、大小、纵深、运动轨迹逐帧保留 | 按帧号并排抽帧，构图与动作同步 |
| 镜头与光学 | 机位、景别、推拉摇移、速度渐变、运动模糊、景深、光晕、曝光闪动保留 | 被「修成清晰稳定画面」即命中 |
| 同框其他对象 | 未被指定的主体、背景个体、倒影与影子保持原样 | 主体数量与相对位置不变 |
| 音轨 | 默认沿用源片音轨 | 成片音轨与源片一致 |
| 片长 | 帧数、帧率、时长与源片一致 | `ffprobe` 三项对齐 |

**与相邻模式的分界**（选错模式等于交付口径错）：

| | 主体替换 | 全场景替换（`references/08`） | 只修脸（`references/05`） |
|---|---|---|---|
| 换什么 | 只换指定主体 | 人 + 场景 + 道具整套换 | 不动身份，只修清晰度 |
| 场景 | 原样 | 整套换 | 原样 |
| 配乐 | 沿用源片音轨 | 每次新生成纯器乐 | 沿用源片 |
| 典型话术 | 「只换主体」「场景不动」 | 「换全部场景」「场景道具都换掉」 | 「脸糊了」「精修一下」 |

**边界**：要连场景一起换 → 走 `08`；要物理删掉画面里某位 → 走 `09`（按需规则，与模式叠加）；
只换脸不换身份 → 走 `05`。主体替换**不生成新配乐**；用户同时要新配乐时，配乐段按 `08` 第五节做。

## 二、提示词

六段式骨架、主体标签格式、`retention_analysis` 必写这三条与 `references/06` 第五节完全一致，本册只写主体替换的差异。模板两份：

| 模板 | 适用 | 关键差异 |
|---|---|---|
| `assets/主体替换提示词-默认.txt` | 主体是人物 | 外观词用「脸 / 发型 / 服装 / 配饰」，负向防第二人物与人脸混合 |
| `assets/主体替换提示词-动物.txt` | 主体是动物、静物、物体 | 外观词用「毛色 / 花纹 / 耳朵 / 胡须 / 爪子 / 尾巴 / 材质」，负向防拟人化与第二主体 |

### 填写铁律

1. 🔴 **模板里的【】占位必须全部替换掉**，一个不剩。提交前 `grep -c "【" 提示词.txt` 必须为 0；带着【】提交等于把占位符喂给模型。
2. 🔴 **`<Subject 1>` 定义只写「外观全部来自 `<Picture 1>`」，不在定义句里列举长相**。具体特征（毛色、花纹、版型、图案）正向明写在 `detailed_description` 里。低步数采样下在定义句堆外观描述会触发自主生成，反而丢特征。
3. **解剖结构句按物种写**，并同时写排除项（「不要鸡冠 / 不要羽毛 / 不要翅膀 / 不要鸟爪」）。只写正向不写排除，模型会把源主体的器官带过来。
4. **负向三段固定**：不要借源主体外观 → 按原主体列一遍要排除的解剖特征 → 不要新增第二个主体 / 不要参考图背景。
5. **画面里只有一个主体时**，`detailed_description` 明写「画面里只有一个主体」，负向写「不要新增第二只 / 不要主体重复」。参考图是白底棚拍图时，负向写「不要参考图的白色背景、不要棚拍布光」，不必裁白底。

### 光学与特效保留段（源片带强运动模糊 / 速度渐变 / 形变特效时必加）

H3 会把「糊」判定成需要修复的缺陷，把整段重绘成清晰稳定的画面，观感与原片差一截。
写法是把光学特性单列成一个 `fully_preserved` 的 Subject，并在 `detailed_description` 里**反着写**：

```
<Subject 4> (S4) 是 <Video 1> 的镜头与光学特性，包括快速向前推镜、径向运动模糊、速度渐变、浅景深虚化、逆光光晕与明暗闪动。
```

`retention_analysis` 里加：`<Subject 4> (appears in [Shot 1]): fully_preserved - 保留原片的推镜、运动模糊、速度渐变、浅景深与光晕。`

`detailed_description` 里加：

> 画面必须保留原片的强烈运动模糊、径向拉伸、浅景深虚化、逆光光晕与明暗闪动，不要把它修成清晰稳定的画面。片尾若画面本身是暗的、糊的、几乎没有可辨主体，保持这种暗与糊，不要提亮、不要补出主体、不要添加清晰细节。

负向补：`不要去掉运动模糊、不要锐化、不要提亮暗部、不要新增光源`。
源片是「头身分离、长脖子、放大贴纸头」一类**形变特效**时，写法按 `references/06`「源片自带形变特效」一节，与本段叠加。

### 主体姿态要先判源片体态，再写「最高优先级」段

**2026-11-06 实测（鸡换猫，5 版才定稿）**：源片主体是贴地腾空滑翔的鸡、脚缩在身下，猫要跟着悬空。只写「不要跑动」不够——H3 有强先验，会把猫放回地面；写「站着不动」又会把镜头推进感一起压平（大特写退成全身中景）。**要什么体态就正向写死「每一帧都成立」的条件，别只写否定句。**

| 想要 | 写成最高优先级的一段（放在 `detailed_description` 姿态段开头） | 负向 |
|---|---|---|
| 悬空 / 腾空 | 从头到尾整只主体悬在空中，四爪全部离地、离地面有明显距离，身体接近水平；两条前腿向前伸展、两条后腿向后伸展，四条腿都伸开、不蜷缩、不缩在身体下面；整段视频里爪子从不接触地面 | 不要站着、不要四足着地、不要四爪踩地、不要走路、不要小跑、不要在地面奔跑、不要落地、不要蹲坐、不要把腿蜷起来 |
| 站住不动 | 从头到尾四爪着地站在同一位置，保持同一个站立姿势；原主体在奔跑、腾空、跳跃的帧里也不复制这些动作 | 不要复制原主体的奔跑/腾空/跳跃姿态、不要四爪离地、不要跳起、不要迈步 |

两条判据：

1. **先看源片体态再定口径**：抽 n=0 / 中段 / 尾段三帧不够，主体可能在中间某几帧才腾空。判「有没有离地」看**主体与地面之间有没有分离的影子**，比看腿的姿势可靠。
2. **「站住」会连带压掉镜头运动**：要求主体原地不动时，必须同时正向写明「镜头照旧快速推进，主体在画面中随镜头由小变大，屏幕位置与大小变化与原片一致」，否则模型会把推镜一起冻住，大特写退成中景。

### 参考图取用

| 参考图情况 | 处理 |
|---|---|
| 三视图 / 多角度拼在一张图里 | **原样整张挂 `<Picture 1>` 即可**：图里多个视角是同一位角色的不同角度，不会画成三个主体；提示词正向写明「多个视角属于同一位角色、不是多个个体」。旧写法「必须裁出其中一只」是某次大特写失败后的推测性处置，2026-11-07 用四视图＋四视图＋三视图原样直挂实跑证伪，已废止。真正有限的是「面部占满画面的大特写」，见 `references/06` |
| 白底棚拍图 | 直接用，负向写「不要参考图的白色背景、不要棚拍布光」 |
| 画面里要各换各的主体有多个 | 多张参考图逗号分隔，编号顺序即身份顺序，写法见 `references/06`「多主体」与「白名单式主体绑定」 |
| 只给一张图、画面里同类主体有多只 | 默认只换「最前景、动作最显著」的那一个，其余保持原样；靠提示词按花色区分个体做不到 |

## 三、端到端流程

| 步 | 做什么 | 判据 |
|---|---|---|
| 1 建档 | 建 `<工作区>/<项目名>/`，原片只读放入，参考图裁好落盘 | 目录齐、原片权限只读 |
| 2 定主体 | 说清「换哪一个、换完是什么」，写进交付清单 `需求` | 主体唯一、参考图唯一 |
| 3 测切点 | `ffmpeg -vf "select='gt(scene,0.30)',showinfo"` 数切点 | 0 切点＝单镜头，整片一次跑；多切点按 `06` 自裁独立片段再拼 |
| 4 写提示词 | 选模板、替换【】占位、按需加光学保留段 | `grep -c "【"` 为 0；六段齐全 |
| 5 试片 | 挑**最特殊**的那 4 秒（特写、暗场、特效段），不挑开头平淡段 | 单段结果主体对、场景没动 |
| 6 整片 | 全片提交，逐段落盘 | 成片帧数与源片一致 |
| 7 验收 | 按第四节逐项，出对比片（横屏上下 / 竖屏左右，见 `07`） | 全部判据通过 |
| 8 交付 | 写 `交付清单.json`，登记项目台账 | 字段齐 |

耗时口径与 `06` 一致：960 长边 4 秒段单段约 310~420 秒（RTX 5060Ti）。开工前按段数报预估。

## 四、验收

| 检查 | 做法 | 判据 |
|---|---|---|
| 主体 | 每 20 帧采样 + 原片/成片同帧并排 | 主体外观全部来自参考图，无原主体残留（毛色、花纹、冠、喙、羽毛、翅膀一类） |
| 场景 | 同帧并排看背景、地面、陈设、光源方向 | 与源片一致，无换景、无新增物体 |
| 表演 | 按帧号抽 `n=0 / 中段 / 尾段` | 姿态、朝向、屏幕坐标、大小比例与源片对齐 |
| 光学 | 看运动模糊、景深、光晕、暗场是否还在 | 未被修清晰；暗场未被提亮 |
| 帧数 | `ffprobe` 三件套 | 成片、对比片、源片帧数与帧率一致 |
| 分段边界 | 跨 4 秒处抽边界前后连帧 | 无跳色、无回到源片帧、无黑帧 |
| 特写段 | 主体头部占满画面的帧单独看 | 大特写是 H3 固有弱项（`06` 多镜头一节）；换得不准则如实标注，不反复重跑整片 |
