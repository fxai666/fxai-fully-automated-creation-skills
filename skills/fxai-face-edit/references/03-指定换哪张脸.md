# 03 · 指定换哪张脸

> **何时读**：画面里可能不止一个人，或要指定换其中某一个（如「换左边那个」）时。

## 语义（先弄清，别选错）

`--face-pos N` 传入的是 **参考脸**：拿第 N 张脸当模板，到整段视频里匹配长得像的脸再换。
它不是「只处理第 N 帧的这一张」——全片里那个人的镜头都会换，其他人一帧不动。

不给 `--face-pos` → 全部人脸都换（服务端缺省 `many`）。

## 流程

```bash
P=~/.workbuddy/skills/fxai-face-edit/scripts/face_edit.py

python "$P" faces --target 演讲.mp4 --frame 0     # 这一帧有几张脸
python "$P" submit --target 演讲.mp4 --source 头像.jpg \
                   --processors 换脸 --face-pos 1 --frame 0
```

`faces` 返回：`count`（张数）、`faces[].i`（序号，0 起）、`box`（框）、`score`（置信度）、
`crop`（裁剪图文件名，拼 `/facecrop/<crop>` 可看这张脸长什么样）。

## 判据

- `count` ≤ 1 → 不指定，直接换。
- `count` ≥ 2 且要指定其中某个人 → 按 `i` 给 `--face-pos`，并用同一 `--frame` 提交。
- `count` = 0 → 换帧号重测：画面里没人脸、或这一帧是黑场/远景。视频目标逐帧往后试，
  找到有人脸的那一帧再指定。
- 两个人的脸长得很像 → 加 `--option reference_face_distance=0.3` 收紧相似度。

## 参考帧

`--frame` 只对识别生效（决定「模板从哪一帧取」），处理范围仍是整段素材。
静态图片目标固定传 0。

## 筛选条件

只想动某一类人时，`faces` 支持按条件过滤后取序号：
`--order`（排序方式）、`--gender`（`male`/`female`）、`--age-start` / `--age-end`。
过滤后序号按过滤结果重新编号，提交时用同一个条件与序号。

同参数重复识别命中服务端缓存，返回很快；改了帧号或筛选条件则重新检测。
