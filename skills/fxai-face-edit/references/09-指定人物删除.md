# 09 · 指定人物删除

> **何时读**：需求要在角色替换 / 全场景替换里「删掉画面中某一位人物」「去掉另一个人」「只留一位」时；
> 或成片里出现多余人物、删人提示词反复未生效时。
> 本册是**按需挂接的规则**，与任一替换工作流模式叠加执行，不单独成模式。

## 一、规则定义与边界

一句话口径：**删人靠源片预处理，不靠模型提示词。**

| 维度 | 执行 | 判据 |
|---|---|---|
| 删谁 | 需求点名到具体人物（按位置、姿态、动作线区分），写进 `交付清单.json` 的 `需求.人物改写` | 清单里能读出「删 A、留 B」，禁用「删多余的人」这类无指向表述 |
| 留谁 | 保留者的动作、姿态、位置、景别逐帧不变 | 抽帧并排比对，保留者轮廓与动作同步 |
| 人数 | 生效帧集里目标人数固定（通常为一位） | 含删人镜头的逐帧扫描，任意一帧都不得多出一人 |
| 帧数 | 预处理源、生成结果、成片帧数三者与源片一致 | `ffprobe` 逐项对齐 |

**与其它规则的边界**：

| 需求 | 走哪条 |
|---|---|
| 多人画面里指定换哪一张脸（仍保留所有人） | `references/03` |
| 物理删除画面中的某一位人物，其余人换角色 | 本册 |
| 只修脸 / 放大修脸 / 超分 | 各自链路，不涉及人数 |

## 二、能力边界（先判定再动手）

本机 H3 整帧重绘 + 换人 LoRA 的固定行为是**把画面里所有出镜人体都换成参考角色**。人数属于模型结构先验，提示词无法改动这一语义项。

以下提示词路线**已判定无效，直接跳过**，换 seed 重试同样无效：

| 写法 | 结果 |
|---|---|
| 正向「全片只留一位人物」+ 负向「第二个人」 | 两位人物都被换成参考角色 |
| 增加人数主体定义、`fully_preserved`、显式禁用「把两人都换成 S1」 | 与上一行结果一致 |
| 继续叠加更强、更多次数的「第二个人 / 人形残影」负向 | 泛化成整段不画人，或只剩肢体局部 |

判据：两版不同强度的提示词试片结果一致，即判定为能力边界，停止改提示词，转入第三节。

## 三、端到端步骤

| 步 | 做什么 | 判据 |
|---|---|---|
| 1 拆镜头 | 读源片帧数/帧率；按硬切帧号裁成单镜头片段 | 各段帧数之和＝源片总帧数 |
| 2 定位 | 用**原尺寸**单帧叠 100px 坐标网格，量出待删人物包围盒；再密集逐帧扫描，确认它在哪些帧出现、消失、进入叠化 | 有坐标包围盒；有逐帧出现区间表；缩略接触表只用于定位，不作判据 |
| 3 量间隙 | 量出待删人物与保留者之间的最近间隙 | 间隙 <20px 时禁用任何矩形滤镜，改用羽化遮罩 |
| 4 定生效帧集 | 只对「待删人物可见且同框还有别人」的帧生效；叠化 / 单人帧原样保留 | 帧集外像素零改动；单人帧里唯一人物保持完整 |
| 5 抹除 | 固定渐变条 + 羽化矩形遮罩，逐帧合成（第四节） | 待删人物零残留（人头 / 手臂 / 衣角）；保留者边缘完整 |
| 6 合成预处理源 | 逐帧 PNG 按原帧率合成，音轨 `copy` | 帧数、分辨率、帧率与原片段一致 |
| 7 送 H3 | 用**干净版**提示词，人数写成「最多一位」，删人负向一律省略 | 试片逐帧扫描通过 |
| 8 拼接验收 | 各段 `concat` 锁帧，全片逐帧扫描 | 第六节全部判据通过 |

## 四、抹除做法（推荐）

环境可能缺 `numpy` / `cv2`，只用 PIL 即可完成。

1. **固定渐变条**：从**首帧**取一条不含任何人物的纯背景竖带，压成 1 列再横向拉宽成待覆盖宽度，得到「天空 → 承载面 → 地面/水面」的平滑竖直渐变；全片共用这一条。
2. **羽化遮罩**：矩形上下各超出画布约 40px，使高斯模糊只作用于左右边界；`GaussianBlur` 半径约 9，再用 `Image.composite` 合成。
3. **边界取值**：X0/X1 由包围盒定，右边界距保留者左边缘至少留 10px；间隙过窄时保守收窄 X1，以保留者边缘完整为准。
4. **逐帧生效**：只对第 4 步划定的帧集处理，其余帧原样写出。
5. **合成**：逐帧 PNG → 按原帧率编码，音轨从原片段 `copy`，输出规格与原片段一致。

### 禁用项（写成判据）

| 做法 | 判据依据 | 命中现象 |
|---|---|---|
| `ffmpeg delogo` 矩形贴满画面边缘（`y=0:h=<整高>` 一类） | 滤镜要求矩形四周留边界像素 | `Logo area is outside of the frame`，输出 0 字节 |
| 任何矩形滤镜用于间隙 <20px 的双人同框 | 矩形必然削到保留者 | 前后并排图里保留者缺手臂 / 纱袖 / 腿 |
| **逐帧**从遮罩边界取色生成渐变条 | 大幅动作时衣料扫过取色列，把填充染成异色 | 预处理帧出现与场景不符的矩形色块 |
| 全片一刀切抹除 | 叠化 / 单人帧里唯一人物会被一起擦掉 | 成品出现无主角的空帧 |
| 源片已单人后再叠一层强删人负向 | 负向泛化 | 成品整段人物消失或只剩局部 |

## 五、提示词与配乐口径

1. 源片已经单人，提示词只写目标画面的身份、场景与「最多一位人物」；针对源片状态的否定句（如「勿通过把两位人物都换成 S1」）一律省略。
2. `retention_analysis`、`<Audio 1>` 裸标签等按 `references/06` / `08` 写，删人规则不改动它们。
3. 全场景替换的纯器乐配乐仍按 `references/08` 第五节执行。
4. 淘汰掉的提示词路线写进交付清单的 `版本记录`，便于复用时直接跳过。

## 六、验收判据

| 检查 | 做法 | 返回什么算过 |
|---|---|---|
| 预处理源规格 | `ffprobe` 比对帧数 / 分辨率 / 帧率 | 三项与原片段完全一致 |
| 处理前后并排 | 抽首 / 中 / 尾 / 叠化帧，上原片下预处理 | 待删人物零残留；保留者边缘完整；无矩形接缝、无异色块 |
| H3 试片逐帧扫描 | 该镜头**全部帧**做接触表 | 每帧都是目标人数；无第二人、无人形残影、无半截肢体、无空帧、无身份跳变 |
| 全片采样 | 每 20 帧上下并排 + 含删人镜头逐帧扫描 | 任意一格都无多余人物；空镜不补人；场景稳定 |
| 拼接 | 各段帧数求和、成片与对比片锁帧 | 合计、成片、对比片三者一致 |

## 七、交付清单必填

| 字段 | 填什么 |
|---|---|
| `需求.人物改写` | 点名删谁、留谁，禁用「删多余的人」 |
| `生成链路.源片预处理` | 适用镜头、原因、做法、脚本、产物、规格、生效帧集 |
| `版本记录` | 淘汰的提示词路线及淘汰理由 |
| `验收` | 逐帧扫描结论、前后并排图路径 |

格式与命名见 `references/07`。
