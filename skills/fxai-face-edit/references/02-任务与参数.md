# 02 · 任务与参数

> **何时读**：选处理器、填素材位、调高级参数、想照抄一组常用组合时。

## 处理器表（facefusion 后端）

| 中文名 | key | 素材位 | 干什么 |
|---|---|---|---|
| 换脸 | `face_swapper` | 头像 + 目标 | 把头像那张脸贴到目标上，图片视频都行 |
| 深度换脸 | `deep_swapper` | 头像 + 目标 | 按指定人物模型整体替换，贴合度更高 |
| 人脸增强 | `face_enhancer` | 目标 | 五官更清晰，修模糊、修老照片 |
| 年龄修改 | `age_modifier` | 目标 | 调大调小（`age_modifier_direction`） |
| 表情还原 | `expression_restorer` | 目标 | 把被压平的表情修回来 |
| 人脸编辑 | `face_editor` | 目标 | 调眉毛、眼神、嘴型、头部角度 |
| 画面上色 | `frame_colorizer` | 目标 | 黑白转彩色 |
| 画面增强 | `frame_enhancer` | 目标 | 整帧画质提升 |
| 唇形同步 | `lip_syncer` | 音频 + 目标（视频） | 让画中人对上这段语音 |
| 背景移除 | `background_remover` | 目标 | 抠人像去背景 |
| 人脸调试 | `face_debugger` | 目标 | 叠加关键点/特征，排查用 |

处理器可多选，用逗号分隔；**顺序即执行顺序**（先换脸再增强，反了会把增强结果抹掉）。

## 素材位判据

- `换脸` / `深度换脸` 命中其一 → 必须给 `--source`，否则提交前拦截。
- `唇形同步` → 必须给 `--audio`，且目标必须是视频，服务端对图片目标直接拒。
- 其余处理器 → 只用目标，多给头像服务端忽略。

## 提交与一站式

```bash
P=~/.workbuddy/skills/fxai-face-edit/scripts/face_edit.py

# 素材已在库里：点名提交
python "$P" submit --target 演讲.mp4 --source 头像.jpg --processors 换脸,人脸增强

# 素材在本机：一站式
python "$P" run --target-file ./演讲.mp4 --source-file ./头像.jpg \
                --processors 换脸 --out-dir ./out --timeout 3600
```

`run` 上传时按扩展名分位：音频进 `audio`，图片视频进 `target`；头像显式走 `--source-file`。

## 高级参数（--option k=v，可重复）

| key | 取值 | 说明 |
|---|---|---|
| `face_swapper_model` | 模型名 | 换脸模型选择 |
| `face_swapper_pixel_boost` | 分辨率档 | 越大越清晰、越慢 |
| `face_swapper_weight` | 0～1 | 融合权重 |
| `face_enhancer_model` | 模型名 | 增强模型选择 |
| `face_enhancer_blend` | 0～100 | 增强强度 |
| `face_enhancer_weight` | 0～1 | 融合权重 |
| `age_modifier_direction` | 整数 | 正变老、负变年轻 |
| `expression_restorer_factor` | 0～100 | 表情还原力度 |
| `face_editor_eyebrow_direction` | 数值 | 眉毛 |
| `face_editor_eye_gaze_horizontal` / `_vertical` | 数值 | 眼神方向 |
| `face_editor_eye_open_ratio` | 0～1 | 睁眼 |
| `face_editor_mouth_smile` / `_grim` / `_pout` / `_purse` | 数值 | 嘴型 |
| `face_editor_head_pitch` / `_yaw` / `_roll` | 数值 | 头部角度 |
| `frame_colorizer_model` / `frame_colorizer_blend` | 模型名 / 0～100 | 上色 |
| `frame_enhancer_model` / `frame_enhancer_blend` | 模型名 / 0～100 | 画质 |
| `lip_syncer_model` | 模型名 | 对嘴模型 |
| `background_remover_model` | 模型名 | 抠图模型 |
| `face_mask_types` | `box` / `occlusion` / `region` | 融合遮罩 |
| `face_mask_areas` / `face_mask_regions` | 部位名 | 遮罩范围 |
| `face_detector_model` | 模型名 | 检测器 |
| `face_selector_mode` | `many` / `reference` / `one` | 换哪些脸（`03` 册） |
| `face_selector_order` | 排序方式 | 人脸排序 |
| `face_selector_gender` | `male` / `female` | 按性别筛 |
| `face_selector_age_start` / `_age_end` | 整数 | 按年龄筛 |
| `reference_face_position` | 0 起的序号 | 换哪张脸（`03` 册） |
| `reference_face_distance` | 0～1 | 相似度阈值 |
| `reference_frame_number` | 帧号 | 参考帧 |
| `execution_thread_count` | 整数 | 并行线程 |
| `video_memory_strategy` | `strict` / `tolerant` | 显存策略 |
| `output_image_quality` | 0～100 | 图片质量 |
| `output_video_encoder` / `output_video_preset` / `output_video_quality` | 编码器 / preset / 0～100 | 视频输出 |
| `output_audio_encoder` | `aac` | 缺省即 aac，换成 flac 会丢音轨 |
| `output_audio_volume` | 0～100 | 音量 |
| `trim_frame_start` / `trim_frame_end` | 帧号 | 只处理这一段 |

不传的一律走服务端默认值。

## 常用组合

| 要什么 | 处理器 | 备注 |
|---|---|---|
| 图片换脸 | `换脸` | 头像 + 目标图 |
| 视频换脸 | `换脸,人脸增强` | 先换再增强 |
| 让画中人念这段话 | `唇形同步` | 音频 + 视频目标 |
| 老照片修复 | `人脸增强,画面上色` | 顺序不可颠倒 |
| 黑白视频上色 | `画面上色,画面增强` | 先上色再提画质 |
| 抠人像 | `背景移除` | 图视频都行 |
