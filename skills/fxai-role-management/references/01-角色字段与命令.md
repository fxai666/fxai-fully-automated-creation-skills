# 01 · 角色字段与命令

> **何时读**：要执行增删改查、确认字段名、写人设内容、从备份回滚时。

## 一、可写字段（34 个）

传参形式一律 `--字段名 值`，字段名区分大小写。

| 字段 | 含义 | 字段 | 含义 |
|---|---|---|---|
| `title` | 角色名（新增必填） | `nickname` | 昵称 |
| `gender` | 性别 | `age` | 年龄 |
| `birthday` | 生日 | `category` | 分类 |
| `typeid` | 类型ID | `wakeword` | 唤醒词 |
| `callme` | 称呼我 | `systemprompt` | 系统提示词 |
| `coreidentity` | 核心定位 | `exclusivepersonality` | 性格 |
| `emotionaltendency` | 情绪倾向 | `hobby` | 爱好 |
| `taboo` | 禁忌/避讳 | `bginfo` | 背景信息 |
| `appearancefeature` | 外貌特征 | `figure` | 身材 |
| `dressstyle` | 服装风格 | `voicefeature` | 声音特征 |
| `voicelang` | 语音语言 | `voicespeed` | 语速 |
| `voice` | 音色音频路径 | `voicetext` | 音色参考文本（克隆必填） |
| `avatar` | 头像 | `portrait` | 形象照 |
| `coreskills` | 核心技能 | `behaviorboundary` | 行为边界 |
| `abilitybottomLine` | 能力底线 | `expressionstyle` | 表达风格 |
| `memoryanchor` | 记忆锚点 | `interactionrhythm` | 互动节奏 |
| `otherrequirements` | 其他要求 | `json` | 扩展JSON |

系统字段不可写：`id`、`markerid`、`addtime`、`moduleid`、`relationid`、`relationmarkerid`、`issync`。

内容型字段（人设、外貌、技能、边界）建议写成短段落或分号分隔的条目，不塞大段 Markdown；换行在页面里会被压成空格。

## 二、命令与参数

| 命令 | 位置参数 | 可用选项 |
|---|---|---|
| `dbs` | — | `--json` |
| `list` / `ls` | — | `--uid N`、`--json` |
| `get` / `show` | `<id 或 角色名>` | `--uid N`、`--json` |
| `add` / `create` | — | `--title` 必填，其余字段任意；`--uid N`、`--force`、`--json` |
| `update` / `set` | `<id 或 角色名>` | 任意字段；`--uid N`、`--json` |
| `delete` / `del` / `rm` | `<id 或 角色名>` | `--uid N`、`--yes`、`--json` |

定位角色支持四种键：`#12` / `12`（按 id）、`角色名`（按 title）、`markerid`、`昵称`。
命中多条会直接报错并列出候选，不会误改。

用户库默认取 `<客户端安装目录>\userinfo.json` 的 `myid`（安装目录按 `FXAI_APP_DIR` > `<盘>:\fxai` 定位）。`--uid` 只用于切到别的账号库，正常增删改查不用带。

## 三、输出格式

`list`：

```
当前库：user_212.db（共 2 个角色）

| ID | 角色名 | 昵称 | 性别 | 年龄 | 分类 | 音色 | 参考文本 | 头像 |
| 1 | 阿杰 | — | 男 | — | — | ✓ | — | ✓ |
| 2 | 凤希 | — | 女 | 25 | 同事 | ✓ | — | ✓ |
```

`add` 回「已新增角色：id=3「XXX」（user_212.db）」+ 备份路径。
`delete` 不带 `--yes` 只回「将要删除：…」并停住。

`--json` 结构：`list` 回 `{uid, db, roles:[…]}`；写操作回 `{ok:true, uid, id, backup}`。

## 四、回滚

每次写操作在 `data/backup/` 落一个 `<时间戳>_<动作>_user<uid>.json`，内容是被影响行写前（删除时是整行）的快照。

还原单个字段：读备份里那一行的值，用 `update <角色> --字段 <原值>` 写回。
整行还原（含被误改的多个字段）：把备份行里的可写字段逐个 `update` 回去。
行已被删除：用备份行重新 `add`，`title` 与全部可写字段照抄，markerid 会换成新的。

备份只增不删，确认无误后可手工清理旧文件。

## 五、常见报错

| 报错 | 处理 |
|---|---|
| 找不到数据目录 / 全局配置不存在 | 客户端没装或没做过配置：装好后按站点「软件配置（全面使用凤AI必看）」与「视频教程」走一遍并登录，再到「本机配置 → 技能运行环境」复制口令 |
| 找不到数据目录 | 看 `~/.workbuddy/fxai_global.json` 的 `software_data_dir` 是否指向带 `sqlite/` 的目录；缺了去「本机配置 → 技能运行环境」点复制口令 |
| 读不到当前登录用户 | 同上确认 `software_install_dir` 下有 `userinfo.json`；客户端登录一次会自动生成 |
| 多个库有角色、写操作被拒 | 加 `--uid`，先用 `dbs` 看有哪几个 |
| 当前登录用户的库不存在 | 客户端换过账号，核对 `userinfo.json` 的 myid 与 sqlite 目录里的 `user_*.db` |
| 没有 ai_digital_human 表 | 让用户在客户端打开一次「AI伙伴」页面建表 |
| database is locked | 客户端正在批量写入，等几秒重试 |
| 角色匹配到多个 | 用 `#id` 定位 |
