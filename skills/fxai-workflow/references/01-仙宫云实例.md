# 01 · 仙宫云实例（自动开机 / 收工关机）

> **何时读**：`comfy_url` 指向 `*.container.x-gpu.com`、要开关实例、或关机前确认档位时。

## 仙宫云：开工前自动开机、收工后问着关机

`comfy_url` 指向仙宫云容器（`*.container.x-gpu.com`）时实例大概率关机。`xgy_guard.py` 统一管两头，所有调用方技能自动生效；本机与非仙宫云地址不触发。

**① 开工前自动开机**（挂在 `require_comfyui()`，调用方照旧调它）：探不通就解析实例 ID → `/instance/boot` → 等 `running`（约 1~2 分钟）→ 回探端口；没令牌就停下来提示。实例 ID 依次取：配置 `xgy_instance_id` > 域名反解（`abc-8188.container.x-gpu.com` → `abc`）> 令牌下唯一那台。

**② 全部任务做完、准备交付那一步，先问是否关，再执行**（`comfy_client.finish()`；单个子任务跑完跳过）。关机前必须用提问工具问用户，两档给：释放 GPU `stop <comfy_url>`（**默认、推荐**，停计费、磁盘保留，下次要重分配 GPU + 加载镜像）／保 GPU `stop <comfy_url> --keep-gpu`（照常计费、下次秒起，用户明确说「马上还要接着用」才走）。用户没说停就别停，也别替他默认选。开机流程与文案见 `README.md`。
