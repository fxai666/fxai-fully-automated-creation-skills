# 版式登记表

「展示形式」= 一套版式（画布怎么分区、槽在哪）+ 外层怎么套。
版式可以不断加，**但素材槽只有一套**（见 `01-素材槽规格.md`），加版式不用碰合成。

| # | 版式 / 展示形式 | 画布 | 槽位 | 实现位置 | 状态 |
|---|---|---|---|---|---|
| 1 | **整页幻灯**（marketing / points / list / compare / steps / quote / showcase / code / stats / chat / pricing / outfit / product）| 768×1280 | 全屏槽（槽 = 整页，内容由 HTML 直接画）| `fxai-slide-video/slides.py` | 在用 |
| 2 | **上中下分栏**（`frame`，旧名「栏目图文」；= 静态背景模板）| **竖屏 9:16 是规范**（1080×1920）；横屏 1280×720 仅作例外 | 上带 + **中区槽恒为全宽 16:9**（9:16 下 1080×608）+ 下带。上下带全片固定，只有中区换素材；比例由 `frame_ratios(w, h)` 算，上下带另分 `--fr-bot` | `ml_frame.py`（壳 + `frame_ratios` / `frame_box`）+ `ml_slots.part`（垫槽）| 在用 |
| 2b | **左中右分栏**（`trio`）| **横竖通吃**：竖屏 768×1280 / 1080×1920、横屏 1366×768 都能用 | **槽形只看槽里素材的方向**（不看画布）：竖素材 = 满高贴边竖条（y=0、h=画布高、上下零边距）；横素材 = **16:9 横带、水平垂直居中**。槽宽由 `media_w` 调（0.30~0.92）、水平居中；竖素材按 `fit:"height"` 满高填（上下永不出边），横素材按 `fit:"cover"` 铺满（槽已是 16:9，零裁切）。默认槽宽四档：竖画布 0.62 / 横画布+横素材 0.70 / **横画布+竖素材 = 画布高×9/16÷画布宽**（1366×768 下 0.3163 → 432×768）。坐标只从 `trio_box(w, h, media_w, portrait_media)` 取 | `ml_trio.py`（壳 + `trio_box` + `portrait_media_of`）+ `ml_slots.part` | 在用 |
| 3 | **广告片 · 蒙太奇 / 静图运镜**（路线 B / C）| 1280×720 或 768×1280 | 全屏槽，无壳；时间轴来自配音时间码。段里给 `layout` 可套 `thirds`（二分栏）或 `frame`（上中下分栏）| `ml_slots`（槽）+ `fxai-ad-video/scripts/ad_assemble.py slots`（时间线 → 无声画面）| 在用 |
| 4 | **二分栏**（`thirds`）：横屏「左右二分栏」/ 竖屏「上下二分栏」| 任意（横竖自适应）| 文字区 + **媒体槽**（横屏 55.5% 宽，竖屏 88% 宽）+ 背景底 | `ml_split.py`（`split_slide` / `split_mask` / `split_box`）+ `ml_slots.part` | 在用 |
| 4b | **全屏压字**（`thirds` + `media_full`）| 任意 | 媒体铺满整幅，文字渐隐压层 | `ml_split.py` | 在用 |
| 5 | **海报 / 封面**（网页模式）| 任意 | 全屏槽 | `fxai-poster/poster.py` → `slides` | 在用 |

    `(x, y, mw, mh)`（`mh = mw×9/16`，槽宽过大使高超出画布时反过来按高收宽，比例不破）。

## 中文名对照（套模板时先认这三行）

| 中文叫法 | `template` | 结构 | 一句话认法 |
|---|---|---|---|
| **上中下分栏**（静态背景模板）| `frame` | 上带 + 中区展示 + 下带，上下带全片固定 | **三段叠起来**，上下是壳、只有中间换 |
| **左中右分栏** | `trio` | 左栏文字 + 中槽 + 右栏文字；竖素材是满高竖条、横素材是 16:9 横带 | **三段并排**，中间那格形状**跟着槽里素材的方向**变，宽度可调 |
| **左右二分栏** | `thirds`（横屏）| 文字区在左 + 媒体槽在右 | **两段并排**，文字随旁白逐段换 |
| **上下二分栏** | `thirds`（竖屏）| 文字区在上 + 媒体槽在下 | 同上一行，方向由画布比自动切 |

「上中下分栏」带「中」字，是三段壳式；「上下二分栏 / 左右二分栏」是两段并排，没有壳。
旧名「栏目图文」= 上中下分栏，`template` 里三个写法都认。
「左中右分栏」也是三段壳式，中间那格**竖素材是满高竖条、横素材是 16:9 横带** —— 记法是
「中间那格装竖素材就竖着切（顶天立地），装横素材就横着切（16:9 居中）」。
**跟画布横竖无关**：1366×768 的画布上放竖素材，中间那格仍是 432×768 的满高竖条。

🔴 **同一份素材，横屏画布下「文字上下」和「文字左右」是两种布局，都合法**：
- 文字上下 = `frame`（上带 + 16:9 中区 + 下带，上下带放标题与品牌）
- 文字左右 = `trio`（16:9 中槽居中，左右两栏竖排文字，上下留白）

竖素材就只走 `trio`（满高竖条）—— 但注意它在横屏画布上**不是 16:9 横带**，
而是「画布高 × 9/16」宽的满高竖条（1366×768 → 432×768，两翼各 466）。

## 版式 × 背景 × 槽 三个维度

套模板时按这个顺序选，勿混成一个名字：

| 维度 | 取值 | 字段 |
|---|---|---|
| 怎么分区 | 整页 / 上中下分栏 / 左中右分栏 / 二分栏 / 全屏压字 | `template` |
| 画布方向 | 带壳版式（frame / trio）横竖都支持；trio 槽形跟**素材**方向走，frame 跟画布走；二分栏横竖自适应 | 画布尺寸（都**自动切**，不是字段）|
| 底是什么 | 纯色渐变 / 虚化图 / 虚化视频 | `bg` |
| 槽里放什么 | 单图 / 轮播 / 视频 / 网页 | `media` |
| 槽里怎么放 | 铺满裁切 / **满高居中（竖素材默认）** / **铺满（横素材默认）** / 完整不裁 / 同图虚化铺底 | `media_fit` |
| 槽里怎么动 | PPT 转场（每镜边界各不同）+ 慢推近 + 关键词动效 | `trans`（list 逐边界）/ `zoom` / `ml_kw` |

「上中下分栏 · 静态背景」= `template:"frame"` + **竖屏 9:16 画布** + 上下带固定（壳写在顶层 `frame`）——
它是**有壳的三段版式**，不是「二分栏加个背景」。画布不是自由项：这个版式竖着才成立，
横屏只在素材本身是横屏片时借用一次（中区会缩成 896×504 的窗口，两侧让出 15%）。

「上下二分栏 · 静态背景」= `template:"thirds"` + 竖屏画布 + `bg:"static"`，
版式、方向、背景各取一个值，不是三个版式。

## 登记纪律

- 新版式落地**先登记再写代码**：想清楚「槽在哪、多大」，再决定放哪个技能里。
- 一个版式只允许有一个实现文件；第二个地方出现同样的 CSS / 转场表就是重复，改一处漏一处。
- 「版式名」必须能直接写进 `segments.json` 的 `template` 字段，不另起别名。
