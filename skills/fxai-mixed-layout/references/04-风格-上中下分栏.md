# 风格：上中下分栏（竖屏 9:16 深色栏目包装）

**只读这一册**：要照这套风格做片子、判断「像不像」、定字号配色与换图节奏时读它。
壳的字段表在 `fxai-slide-video/references/02-模板库.md`「上中下分栏」，槽的填法在
`01-素材槽规格.md`，都不在这里复写。

## 1. 这条风格从哪来

用户最初就是照一条竖屏口播片（584×1010 / 61.8s，账号「六虫 · 深度认知论」）定的这个版式，
后来才落成 `frame` 这套壳。所以「像不像」的判据不在我们自己的成片里，在那条参考片里。

参考片的骨架一句话：**上下两条黑带全片一个字都不改，中间一条全宽 16:9 的画面带按旁白换图。**
带子是栏目包装，画面是内容，字幕压在画面里。整片没有任何片尾关注卡 —— 品牌全靠壳说。

## 2. 三段的比例（从参考片量出来的）

| 段 | 占比 | 1080×1920 时 | 内容 |
|---|---|---|---|
| 上带 | 35.4% | 680px | 两行大标题（白 / 黄），全片冻结 |
| 中区 | 32.9% | **1080×608**，全宽 16:9 | 素材满幅铺进去，按旁白换 |
| 下带 | 31.7% | 609px | 金色品牌栏，全片冻结 |

🔴 **中区就是「全宽 16:9 一条带」**，这是版式的定义，不是可调参数：
素材按 16:9 出，进框零裁切、两边不留边。代码里 `frame_ratios(w, h)` 用画布宽度直接
算出中区高度（`w×9/16`），剩余高度按 `FRAME_SPLIT`（0.527）分给上下带 —— 换画布尺寸时
三段自己跟着对，勿另写比例。

🔴 **中区高度必须偶数**：1080 宽算出来 607.5，四舍五入成 607 —— 奇数高会被 libx264 直接拒收
（`height not divisible by 2`），整条中区片渲染失败，而报错只留最后 500 字，看起来像「编码器打不开」。
偶数化只写在 `_media_h()` 一处，`frame_ratios` 与 `frame_box` 都从它取；9:16 下取值 **1080×608**。

🔴 **上中下分栏是竖屏版式，默认画布 9:16（1080×1920）**。竖着拿在手里、上下两条带压住
画面才成立；横屏会变成「左右各让一条边、中间一个窗口」的另一种东西，不是这个版式。
横屏分支只在**素材本身就是横屏片、要整条嵌进中区**时借用（例如把一条已完成的横屏广告
整条嵌进来），借完勿把横屏当成这个版式的用法。

## 3. 视觉要素（照着这个做才像）

| 要素 | 取值 | 说明 |
|---|---|---|
| 带子底色 | `#0B0B0C` | 近黑不纯黑，纯黑在手机上会和画面边缘糊成一片 |
| 斜纹 | 45°、`rgba(255,255,255,.026)`、间距 2% 画布宽 | 极淡，远看是纹理不是条纹 |
| 左上暖金光 | 峰值约 `rgb(62,45,24)`，`radial-gradient` 圆心在 (10%,0) | **不是纯黑底** —— 少了这层光，整片会显得死板 |
| 标题第一行 | 白 `#F5F3F1`，超粗黑，字号 ≈ 画布宽 11.3% | 黑描边，行高紧 |
| 标题第二行 | 黄 `#FFD84D`，同字号 | 红棕投影向下偏 ≈ 字号 8%（`#8E1B12`），是这套风格的记忆点 |
| 品牌金 | `#D9B45A` | 底部 logo、分隔线、竖排栏目名、slogan 同色系 |
| 底部排布 | 书法 logo（左）+ 竖排栏目名（中）+ 一句 slogan（右） | 三段之间一条细金竖线分隔 |
| 字幕 | 白字 + **厚黑描边**（贴纸感），字号 ≈ 画布宽 6.6% | 落在中区画面内、离中区下沿 ≈ 画布宽 8.5% |

参考片的 logo 是毛笔书法字，用 `logo_img` 传一张图；没有书法素材时用 `logo` 文字（金字 + 字距放宽），
观感会略薄，但仍成立。

🔴 **字体只用两款，别自己找第三款**（用户 2026-10-25 明确）：**得意黑（标题 / 花字 / 关键词）+
微软雅黑（正文 / 字幕 / 品牌区）**。嫌字不够厚就调**样式**（描边、投影、同色加粗），
字体沿用同一款字：思源黑、Noto、方正那一类整族禁用 —— 用户要的是「同一款字做出参考片的味道」。

| 位置 | 取值 | 代码位置 |
|---|---|---|
| 标题 / 花字 | `ml_frame.TITLE_FONT` = `"Smiley Sans"`（得意黑，slides 已内嵌） | `ml_frame.FRAME_CSS` |
| 品牌 logo / 栏目名 / slogan | 微软雅黑（`LOGO_FONT`，可加粗字距） | 同上 |
| 中区关键词（PIL 烧字） | 得意黑（`ml_kw.FONT_CHAIN` 默认第一个就是它） | `ml_kw.py` |
| 字幕（ASS） | 微软雅黑（`sv_media.SUB_FONT` 留空即默认） | 项目侧 |

### 3.1 标题那套「厚字」样式（参考片实测，2026-10-25 学成规范）

参考片标题看着比字体本身粗一档，靠的是**两层叠加**，不是换更粗的字：

| 层 | 做法 | 取值 |
|---|---|---|
| 底层 `.kw-o` | 整行画成纯黑 + 极粗黑描边 | `-webkit-text-stroke: 0.26em #171717` |
| 上层 `.kw-i` | 字色 + **同色描边**（等于把字芯往外加粗） | `-webkit-text-stroke: 0.052em currentColor` |
| 投影 | 第一行白字只压一点点；第二行黄字压厚红棕影 | `0 0.065em 0 #8E1B12` |

- 两层必须用 **grid 叠在同一格**（`grid-area:1/1`）。用 absolute 定位会因行高/基线差出几个像素，黑边偏成「重影」。
- 描边宽度全用 `em`，字号一变（横屏 `--fr-k` 缩放）自动跟着走，别写 px。
- 参数集中在 `.fr-t1,.fr-t2` 的 `--t-bold`（同色加粗）/ `--t-edge`（黑边）两个变量上，调样式只改这两处。

### 3.2 中区关键词的「轻」样式（用户 2026-10-25 定）

老版是 8px 厚黑描边，压在画面上像糊了一块膏药。现在：

- 🔴 **完全不做黑描边**（`ml_kw.KW_STROKE_PCT = 0`，2026-10-25 用户两次强调「没必要描边」
  「描边把我们画面挡完了」）。字够不够厚靠**同色外扩** `KW_BOLD_PCT = 0.018` ——
  同色描边在视觉上就是字变粗，不会多出一圈黑。真需要黑边（亮底偶尔）就按 cue 传
  `{"stroke_pct": 0.03}`，默认不给。
- 🔴 **峰值不透明度 0.80**（`KW_PEAK_ALPHA`）：中区放的是人，字压到不透明就是一块膏药，
  0.8 才能透出后面的人和场景。别调回 0.9 以上。
- **颜色可变**：cue 的第 5 项传 `{"color": "#FF5A3C", "alpha": 0.9}`，不必一律白字。
  强调词用金 `#FFD84D`、警示词用红橙 `#FF5A3C`，同一片里挑 2~3 颗就够，全片彩色会廉价。
- **动效**：进入 1.9 → 1.0 倍、0.45s（easeOutCubic，由透明到实 —— 就是「从画外走来」）；
  停留；退场 1.0 → 1.12 倍 + 高斯模糊 5px + 淡出，0.40s。模糊是退场的关键，只放大不糊会像「被推走」。

🔴 **中区素材要明亮**（用户 2026-10-25 定）：实拍感、高调摄影、自然光，人物放在不同环境里
（会议室 / 影棚 / 录音棚 / 天台 / 咖啡厅…）。昏黄暗调、夜景、只拍一个人一张脸的图禁用 ——
参考片的中区就是「白天、明亮、有人有事在发生」。生图提示词统一带
「明亮高调摄影，自然光充足，电影感色调，画面通透」。

## 4. 节奏与动效（比配色更容易露怯的一项）

- **换图 3~5 秒一次**，最长不超过 8 秒；一条 50 秒的片子大约 12~14 镜。
- 🔴 **镜头之间不硬切，走 PPT 式转场**（用户 2026-10-25 定，取代旧规范「硬切」）：
  每次换图一个 xfade 转场，一条片子里**每个边界可以各不相同**，常用这 12 种混着来 ——
  左滑 `slideleft` / 右滑 `slideright` / 上移 `slideup` / 翻书柔滑 `smoothleft`（带加速减速，
  最像翻页）/ 圆展 `circleopen` / 圆收 `circleclose` / 左擦 `wipeleft` / 叠化 `fade` /
  推进 `distance`（带放大感）/ 像素化 `pixelize` / 对角 `diagtl` / 硬切 `cut`（偶尔用一次做重音）。
  转场时长 0.5s 左右：太短像闪、太长拖旁白。全量表在 `ml_slots.REEL_TRANS`。
- **每镜自带推近**（`zoom` 0.03~0.07，超采样实现，别按目标尺寸直接 zoompan —— 会抖）。
- **关键词动效**（参考片的「第一个坑」「能谈」）：中区画面中部压一颗超大白字，
  白字 + 厚黑描边（`stroke_width ≈ 字号/7`），字号 ≤ 中区高 26%、总宽 ≤ 74% 画布宽；
  **从外部进入放大落定**（1.9 → 1.0，0.45s，带上移与淡入），停到该镜结尾前 0.05s，
  再轻微放大消散（1.0 → 1.07，0.35s）。与字幕错开：字幕压中区下沿（0.79 处），
  关键词居中区 0.44 处。实现见 `ml_kw.py`（PIL 序列帧 + overlay，不用 drawtext —— 它无法缩字号）。
- **字幕极短**：参考片 62 秒 46 条，平均 1.35 秒一条，常见 4~8 个字。
  一句话说完就换，勿挂满两行。
- 壳不动，动的是画面与关键词。
- 🔴 合成参数写死 `--fade 0`：上带 / 下带全片冻结、一段都不重画，只有中区换素材；
  不许对整帧壳做淡入淡出（2026-10-28 与 trio 同族同规补明确）。

## 5. 两条最容易跑偏的

🔴 **壳上的字勿复述标题**。标题写「一个人顶一支团队」，底部 slogan 就换成片子在做的实事
（如「从写稿到成片，全自动」）。同一句话在上下两处各说一遍，观感立刻廉价。

🔴 **中区别塞竖版海报**。中区是 16:9 横带，竖版图哪怕 `fit: "blur"` 也是「中间一条亮、两侧一片黑」，
深色海报更是整条带子发黑，像缺图。中区素材按 16:9 出（1280×720 或 1080×608 同比例），
竖版素材留给二分栏那条版式。

## 6. 验收（出片前逐条看）

1. 上下两条带逐帧比对**完全一致**（壳是资产，一段都不该重画）。
2. 中区左右到边、上下不留缝，画面没有变形或黑边。
3. 字幕在中区画面内、离下沿约 8% 画布宽，描边够厚（糊在亮画面上也读得清）。
4. 顶带第一行白、第二行黄带红影，第二行比第一行更像「落锤」。
5. 任一静帧截出来，遮住中区内容后上下两带仍然是一个完整的栏目包装 —— 这就是「壳」的判据。

## 7. 中区转场（与 05 册共用一套）

中区素材换图这件事，**勿只调 `push_left`**。全片左右滑是用户 2026-10-25 明确否掉的观感：
「别从头到尾全部从右向左，看上去我都烦了。」

- 30 种转场、代码入口、编排规矩 → `05-CSS3转场.md`
- 上中下分栏的推荐起手式：**开场 `cube_up`（立方上翻，撑起栏目感）→ 中段 `fade` / `focus_pull`
  讲内容 → 揭晓用 `split_h` → 收尾 `zoom_out_reveal`**，中间穿插 `iris_open` / `card_drop`。
- 同一段落同一转场只用一次；`glitch` / `flash_zoom` 全片各最多一次。
- 这条同样适用于 **二分栏（`thirds`）** 的媒体槽和幻灯片的配图页 —— 转场是跨版式的，
  不属于某一个版式。
