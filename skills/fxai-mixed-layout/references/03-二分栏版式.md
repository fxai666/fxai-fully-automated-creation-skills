# 二分栏版式（`thirds`）

**只读这一册**：要写二分栏文案、调背景底、判断素材怎么放时读它。
槽的三种填法与转场表在 `01-素材槽规格.md`，不在这里复写。

## 1. 什么时候用

| 版式 | 形态 | 用在 |
|---|---|---|
| 整页幻灯 | 一屏一页，无固定壳 | 讲解型内容，一页一个观点 |
| 上中下分栏 `frame` | 上下固定带 + 中区一格 | 连载栏目，壳全片复用 |
| **二分栏 `thirds`** | 文字占一区、媒体占一区、背景铺满 | **旁白 + 素材混排**：广告片、产品演示、岗位盘点、案例复盘 |

三者共用同一条链路：造 HTML → Chrome 截图 → 素材槽垫进去 → 一条无声视频。
区别只在「怎么分区」，不在能力。

🔴 **二分栏没有壳**：文字区逐段重画，别和「上中下分栏」的三段壳混用 ——
那个的上下带全片不动、只有中区换素材（`ml_frame.py`）。
中文名认法：带「中」字的是三段壳式（上中下分栏）；「左右二分栏 / 上下二分栏」是两段并排。

## 2. 两段怎么切

```
横屏 1280×720                     竖屏 768×1280
┌──────────┬────────────┐        ┌────────────────┐
│ 文字区    │  媒体槽     │        │    文字区       │
│ 34%       │  55.5%     │        │   88% 宽        │
│           │            │        ├────────────────┤
└──────────┴────────────┘        │    媒体槽       │
   背景底铺满整幅                  │   88%×42.5%    │
                                  └────────────────┘
```

- 同一份代码按画布宽高比自动切，**横竖屏不是两个版式**。
- 媒体槽坐标由 `split_box(w, h, side, full)` 给出，CSS 里的百分比与它一一对应；
  合成端必须取这个函数，勿在别处重算一遍。
- `media_side: "left"` 镜像（媒体在左、文字在右）；竖屏忽略该字段。

## 3. 字段

| 字段 | 说明 |
|---|---|
| `kicker` | 左上栏目号（如「岗位 03 / 08」），金色小字 |
| `title` | 主标题，可用 `<em>…</em>` 标黄；`<br>` 控制断行 |
| `lead` | 主标题下一句（大号、米白） |
| `points` | 要点清单（list），3 条以内；超过 4 条会挤 |
| `note` | 角注（小字灰） |
| `steps` | 环节 / 岗位清单（list），配 `cur` 高亮当前那条；4 列自动排 |
| `cur` | 当前序号（从 1 起） |
| `media` | 媒体槽：路径 / 一叠 list（段内轮播）/ `{"page": {...}}`（网页槽） |
| `media_fit` | `cover`（默认）/ `blur`（竖屏素材：完整显示 + 同图虚化铺底）/ `contain` |
| `media_side` | `right`（默认）/ `left` |
| `bg` | 背景底：`static`（默认）/ `blur` / `blurvideo` |
| `media_full` | `true` 时媒体铺满整屏、文字渐隐压层（另一种版式：全屏压字） |
| `logo` / `slogan` / `tagline` | 品牌落款，缺省取 `SPLIT_BRAND` |

## 4. 背景底三档

| `bg` | 画法 | 适合 |
|---|---|---|
| `static` | 纯色渐变 + 斜纹 | 干净、极简、产品参数 |
| `blur` | 当段素材放大铺满 + 模糊 + 压暗 | 图片素材、封面、海报 |
| `blurvideo` | 同上，素材是视频 | 广告片默认，画面与背景同源，不跳 |

层序（`bg` 非 `static` 时）：

```
虚化背景（铺满整幅）
  └─ 槽内素材（垫在 split_box 给的坐标上）
       └─ 遮罩（文字 + 槽边框，含左侧渐隐暗底 .sp-veil）
```

遮罩里的 `.sp-veil` 是给文字垫可读性的渐隐暗底，横向到 42%、竖向到 47% 淡出 ——
它压不到媒体槽上，所以 `bg` 换档时文字始终可读。

## 5. 槽里放什么

三种填法与转场表见 `01-素材槽规格.md`，二分栏只多两条：

- **竖屏素材进横屏槽**：用 `media_fit: "blur"`，完整显示 + 同图虚化铺底（原广告的做法）；
  用 `cover` 会把 9:16 裁掉大半。素材若已是「1280×720 画布片」（竖屏居中 + 两侧黑），
  必须先裁回原始竖屏片源，否则槽里会变成黑边套黑边。
- **整张海报 / 封面**：用 `contain`，上下留深底，不裁内容。

## 6. 四条硬规矩

1. **遮罩每段一张**：文字随旁白变，`split_mask` 逐段渲染；栏目图文的壳是全片复用，两者不可混。
2. **时长以时间码为准**：广告侧走 `part(total=段长)`，无音频也要给 `total`，否则拼不齐。
3. **字号随 `--sp` 走**：`--sp = sqrt((w/1280)*(h/720))`，横屏 1.0、竖屏约 1.03。
   只按宽度算会让竖屏字号偏小，只按 `min` 会让竖屏缩到 0.6。
4. **全屏压字（`media_full`）的标题降一档**（70px）：长句在 48% 宽度里会挤成三行。

## 8. 配方：上下二分栏 · 静态背景

三个维度各取一个值，**不是新版式**，登记在这里备查：

| 维度 | 取值 |
|---|---|
| 怎么分区 | `layout: "thirds"`（竖屏自动切上中下） |
| 画布方向 | 竖屏 1080×1920 |
| 底是什么 | `bg: "static"` 纯色渐变，不铺虚化素材 |
| 槽里放什么 | 视频 / 图片 / 段内轮播 |

竖屏 1080×1920 的三段边界（`split_box()` 给的坐标，别处勿重算）：

| 段 | 纵向占比 | 内容 |
|---|---|---|
| 上 | 0 → 43.5% | kicker、标题、要点清单、环节清单、品牌落款 |
| 中 | 43.5% → 86% | 媒体槽，88% 宽 × 42.5% 高（1080 宽下 950×816）|
| 下 | 86% → 100% | 纯底色留白，不压字 |

素材按画幅挑 `media_fit`，否则槽里会空一半：

| 素材 | `media_fit` | 理由 |
|---|---|---|
| 16:9 横屏片 | `cover` | 槽比 1.16:1，左右各裁 12.5%，主体在中间时不伤 |
| 9:16 竖屏片 | `blur` | 居中清晰一条 + 两侧同图虚化，不裁人脸也不留黑边 |
| 整张海报 / 封面 | `contain` | 框内上下留深底，字不被切 |

同一份时间线两版只差画布尺寸：广告侧 `make_split_ad.py --port` 出竖屏、不带出横屏，
时间码、文案、旁白一句不用改（`--port` 同时把 `bg` 锁成 `static`，这才是「静态背景」名下该有的底色）。

槽里素材先查一遍源片：带烧录花字 / 打字机动效的那几秒进了槽会被放大到正中，
选片段时避开，别在成片里才发现。
