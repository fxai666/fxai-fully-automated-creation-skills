# 素材槽规格（`media` 字段唯一事实源）

槽是「一块矩形可变区域」。往里填什么，写在各展示形式的规格文件里，最终都归一成
**一条 `w×h` 的无声视频流**（`ml_slots` 负责）。本册只讲槽本身，不讲某个版式长什么样。

## 1. 三种填法

`segments.json` 里 `fields.media` 可以给**一张**（字符串）或**一叠**（list，段内轮播），
list 里可混排：

| 填什么 | 写法 | 归成什么 |
|---|---|---|
| 图片 | `"素材/a.png"` | `kind:"image"`，单图（可带推近 `zoom`）|
| 视频片段 | `"素材/clip.mp4"` | `kind:"video"`，直接裁进槽（可循环）|
| 图片轮播 | `["a.png","b.png","c.png"]` | 合成端做一条轮播片（`build_reel`）|
| 长图滚动 | `{"src":"长图.png","scroll":true}` | `kind:"page"`，槽内网页长图上下滚 |
| 槽内网页 | `{"page":{"type":"text",…}}` | `kind:"page"`，录制端产出视频 |
| 真网页 | `{"url":"https://…"}` | `kind:"page"`，直接录网页 |

逐条覆盖段级 `media_fit`：`{"src":"海报.png","fit":"blur"}`。

## 2. `fit` 四档

| `fit` | 行为 | 用在哪 |
|---|---|---|
| `cover`（默认）| 撑满裁切，可带推近 | 横构图素材、槽比例与素材接近时 |
| `height` | **按高度对齐**：高度恒等于槽高、水平居中，宽度溢出对称裁掉、不足补底色 | **左中右分栏·竖素材默认**（视频上下百分之百显示、上下零边距，画布横竖都一样）；任何「必须满高」的槽 |
| `blur` | 原图完整居中 + 同图虚化铺底（不留黑边、不裁内容）| **竖版海报 / 竖屏截图首选** |
| `contain` | 完整装下 + 两侧补底色 | 要给素材留白、看清整张时（9:16 进 768×440 只剩 247 宽，别用来展示竖版海报）|

🔴 `height` 与 `cover` 的差别只在**以谁为准**：`cover` 是「填满框」（框比素材窄就裁左右、
框比素材宽就裁上下），`height` 是「高度为准」（上下永远满，只动左右）。
左中右分栏的槽宽是可调参数，用 `cover` 一旦调宽就会裁掉上下，所以这个版式**竖屏下默认 `height`**
（`slide_spec` 里按版式注入，段里显式写 `media_fit` 才覆盖）。
🔴 **同一个版式横屏时反过来**：横屏槽是 16:9 横带、高度不是画布高，「满高」没有意义，
所以横屏默认切回 `cover`（槽本身已是横素材原生比例，等于零裁切）。判据在 `slide_spec`：
`seg_fit = "cover" if cw > ch else "height"`。

后三档（`height` / `blur` / `contain`）会**自动关掉推近**（推近会把补边/裁切一起放大，
`height` 下还会直接裁掉上下）。

## 3. 转场（仅多图轮播有意义）

🔴 **转场有 30 种，全表与编排规矩见 `05-CSS3转场.md`**。这里只列最常用的几条，
`trans` 传中文名、旧 ffmpeg 名（`slideleft`）都认，会自动映射。

| `trans` | 效果 | 适合 |
|---|---|---|
| `push_left` / `左右推移` | 新素材从右推进、旧的往左让 | 顺叙、讲「接着往下」 |
| `push_up` / `上下切换` | 新素材从下往上顶 | 分段递进、条目式 |
| `fade` | 叠化 | 时间跳跃、情绪转折 |
| `cube_up` / `立方上翻` | 3D 立方体上翻 | 开场、章节切换 |
| `iris_open` / `圆形展开` | 圆形从中心展开 | 聚焦重点 |
| `glitch` / `故障` | 条带错位 + 对比度抖动 | 翻车、事故、AI 味 |
| `cut` | 硬切（半帧） | 强调「就是这儿」、节奏要狠 |
| `auto` / `mix` | 按 `AUTO_ORDER` 轮换 | 新片先跑通，成片前手排 |

🔴 **一条片里的转场至少 4 种，相邻两条不许同类，不许连续左右滑**（用户 2026-10-25 提）。
细节：`05-CSS3转场.md` §6「编排规范」。

`trans_dur` 默认 0.5 秒（0.35~0.7 之间取），素材总时长太短时自动收，不会出现负时长。
轮播的每格时长自动算，不用手排时间点。

## 4. 四条踩过的坑

1. **推近必须超采样**：`zoompan` 裁剪窗口是整数像素，直接按目标尺寸出图会「有的帧不动、
   有的帧跳一整像素」→ 24fps 下就是抖。见 `FRAME_SS=4` / `FRAME_ZOUT=2`，实测逐帧差异
   从 `0.02↔2.5` 收到 `0.7~1.5`。
2. **长段推近必须封顶**：`ZOOM_MIN_STEP=2.2`，推近 3 秒内走完、之后静止；只超采样不封顶，
   长段会出现 12Hz 闪烁。
3. **静图输入一律带 `-framerate <fps>`**：否则图片解复用默认 25fps 跟 24fps 输出打架。
4. **录屏片段的时长和配音对不上**：网页录屏按「画面静止」收工，进合成前必须 `pad_to()`
   补齐（定格补尾）或裁齐，否则拼接会越拼越偏。

## 5. 槽内网页（`ml_page.page_html`）

| `type` | 字段 | 行为 |
|---|---|---|
| `text`（默认）| `kicker` / `title`（`<em>` 走强调色）/ `items` / `note` | 逐条浮入；超出槽高时录制端自动上滚 |
| `longimg` | `src` / `caption` | 宽铺满、高自然延伸，超出就上下滚 |
| `raw` | `html` | 自定义片段，兜底逃生口 |

`bg`（默认 `#0E1014`）/ `accent`（默认 `#FFD84D`）可覆盖配色。
动效约定：CSS 动画默认 `animation-play-state:paused`，录制端开录即放行。

⚠️ **槽内网页与花字天然冲突**：页面里本来就是字，外层再压一层大字必然打架。
用网页槽的段要么不写 `overlay`，要么显式 `overlay_show: true` 并自己挑位置。
