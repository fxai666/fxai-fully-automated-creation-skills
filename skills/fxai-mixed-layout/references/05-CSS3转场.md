# 转场库（CSS3 · 30 种）：图片/视频槽之间怎么换

> 代码：`fxai-mixed-layout/ml_trans.py`
> 适用：上中下分栏的中区、左右/上下二分栏的媒体区、幻灯片的配图页、广告片的分镜 —— 只要
> 是「一张图换成另一张图」，都走这里。

## 0. 一句话规矩

🔴 **一条片子里不许从头到尾都用同一种转场，更不许全片左右滑。** 30 种里挑，一片至少 4 种，
相邻两条不同类（见 §6 编排规范）。用户 2026-10-25 原话：「别从头到尾全部从右向左，看上去我都烦了。」

## 1. 为什么不用 ffmpeg 的 xfade

xfade 那 50 多种听着多，实际能用的就十来个，而且全是**二维位移 / 擦除 / 叠化 / 光圈**：
做不出 3D 翻页、立方体转面、圆形收拢、故障闪切、翻书。观感上限就是 PPT 2003。

网页这边一条 CSS 就是一台「二维 + 3D + 遮罩 + 滤镜」的合成机，PPT 里做不出的它都能做。

## 2. 引擎：定格，不是录屏（这里踩过一个大坑）

| 方案 | 结果 |
|---|---|
| ❌ 实时录制（`rec_anim.js` / CDP screencast） | 1080×608 + 30 层合成时**掉到 13fps**，还会**整页冻结**只抓到静止帧；唯一在动的是后加的标签。看着快，产物不可信 |
| ✅ 定格逐帧（本项目采用） | 所有 `animation` 一律 `paused`，用 `--T` 变量 + `calc(-1 * var(--T) + 起点)` 把整页拨到某一时刻，逐帧截图。可复现、不漏帧、时长精确 |

代价：1080×608 约 **0.9 秒/帧**。48 秒的片 ≈ 1100 帧，4~6 路并发（各自独立 Chrome 进程）
约 **5 分钟**出片。慢，但结果对。

## 3. 页面结构：四层壳（别合层）

```
.g  可见窗口闸门（opacity，窗口外硬切 0）
 └ .s  退场动画（transform / filter）
    └ .k 进场动画（transform / clip-path / filter）
       └ .z 推近（scale 1 → 1+z，整镜缓慢放大）
          └ img
```

- **为什么拆四层**：CSS 里同一个元素上两条 animation 抢同一个属性时，**后一条整个时间轴通吃**
  （不是取交集）。进场和退场都在 `transform` 上，必须拆到不同元素，靠嵌套相乘。
- 🔴 **闸门层是必须的**：第一版想省掉它、指望「进场动画的 from 状态本来就是隐藏的」，
  结果翻书 / 圆形收这两类的**进场根本没有动画**，它们从片头就挂在画面上，全片糊成一团。
  闸门就是每镜一条 `@keyframes gateN`，在 `[起点, 起点+窗口]` 之外把 opacity 打成 0。

## 4. 30 种对照表

`ml_trans.TRANS` 顺序即下表顺序。中文名、旧 ffmpeg 名（`slideleft` 之类）都能直接传，见 `ALIAS`。

### 4.1 位移推拉（像翻页，最稳）

| 代码名 | 中文 | 做法 | 适合 |
|---|---|---|---|
| `push_left` | 左推 | 新图从右进，旧图向左出 | 顺叙、时间往前走 |
| `push_right` | 右推 | 反向 | 回述、往回翻 |
| `push_up` | 上推 | 新图从下进，旧图上出 | 递进、层层加码 |
| `push_down` | 下推 | 反向 | 落地、收尾 |
| `cover_left` | 左盖 | 新图从左侧滑入盖住旧图（旧图不动） | 插入、打断 |
| `cover_up` | 上盖 | 新图从上方压下来 | 强调、盖章感 |

### 4.2 3D（最有「网页味」，别连续用）

| 代码名 | 中文 | 做法 | 适合 |
|---|---|---|---|
| `cube_up` | 立方上翻 | `translateY(-100%) rotateX(90deg)`，origin 顶边 | 开场、章节切换 |
| `cube_left` | 立方左翻 | `rotateY`，origin 左边 | 章节切换的另一种 |
| `flip_x` | 上下翻牌 | 绕**水平中轴**翻 | 对比两件事 |
| `flip_y` | 左右翻牌 | 绕**垂直中轴**翻（origin 必须居中，绕边就成门板） | 对比、换视角 |
| `page_turn` | 翻书 | 旧页绕左边翻走，露出下面的新页 | 讲「上一页怎么来的」 |
| `card_drop` | 卡片落 | 从上方带透视落下，回弹 | 抛结论、甩数据 |
| `swing_in` | 侧摆 | 斜着摆进来 | 轻松、闲聊感 |

### 4.3 形状遮罩（干净、有设计感）

| 代码名 | 中文 | 做法 | 适合 |
|---|---|---|---|
| `iris_open` | 圆形开 | `clip-path: circle(0→78%)` | 聚焦、放大重点 |
| `iris_close` | 圆形收 | 旧图收成一点露出新图 | 收束、转场收口 |
| `diag_wipe` | 对角擦 | 三角形从左上扫过 | 轻快的切换 |
| `split_h` | 中缝横开 | 从中间向左右裂开 | 揭晓、揭开 |
| `split_v` | 中缝竖开 | 从中间向上下裂开 | 揭晓的竖版 |
| `window_open` | 小窗展开 | `inset(30% 34%)` 开到全屏 | 从细节拉到全景 |

### 4.4 模糊 / 缩放（安静，讲内容时用）

| 代码名 | 中文 | 做法 | 适合 |
|---|---|---|---|
| `focus_pull` | 焦点拉 | 新图从虚到实，旧图虚掉 | 换场景、走神再回神 |
| `fade` | 叠化 | 交叉溶解 | 时间流逝、最安全 |
| `fade_white` | 白闪 | 过曝闪白再落定 | 打点、转折 |
| `fade_black` | 黑场 | 压黑再起 | 段落分隔（别多用，节奏会断） |
| `zoom_blur` | 模糊推进 | `scale 1.42 + blur 16px` 推到清晰 | 冲进来、强调 |
| `whip_blur` | 甩镜 | 横向甩 + 20px 模糊 | 快节奏、连续切换 |
| `stretch_x` | 横拉 | `scaleX(.1)` 拉开 | 标题式插入 |
| `rotate_in` | 旋转入 | 带自转放大进入 | 俏皮、短视频感 |
| `zoom_out_reveal` | 拉远 | 新图从近处退回 | 收尾、交代环境 |

### 4.5 特殊（钩子、转折用，一片最多一次）

| 代码名 | 中文 | 做法 | 适合 |
|---|---|---|---|
| `glitch` | 故障 | `clip-path` 条带位移 + 对比度，`steps(1,end)` 硬切 | 事故、翻车、AI 味 |
| `flash_zoom` | 闪推 | 过曝 + 从 1.6 倍砸下来 | 开场第一下、爆点 |

## 5. 怎么用

```python
import ml_trans, slides

ml_trans.configure(
    ffmpeg=FFMPEG, fps=25,
    shot=lambda html, name, outdir, w, h: slides.render(name, html, outdir, w=w, h=h))

items = [{"path": "a.png", "zoom": 0.05, "dur": 3.4},   # dur 不给就均分
         {"path": "b.png", "zoom": 0.04, "dur": 4.1},
         {"path": "c.png"}]

ml_trans.reel(items, "reel.mp4", total=48.92, w=1080, h=608, fps=25,
              trans=["cube_up", "fade", "split_h"],   # 或 "auto" 自动轮换
              trans_dur=0.5, workers=6)
```

- `trans`：标量（全都一种）/ list（第 k 个管「第 k→k+1 镜」）/ `"auto"`（按 `AUTO_ORDER` 轮换）。
  list 比镜数少时，剩下的自动补。
- `trans_dur`：0.35~0.7 秒。**0.5 是默认值**，约等于旁白的一个停顿。
- 只想看效果：跑 `_参考片学习/_gallery30.py`（30 镜，每镜一种，左上角带中文名）。
- 查名字：`ml_trans.names()`；中文名 / 旧 ffmpeg 名 → 代码名：`ml_trans.resolve("左滑")`。

## 6. 编排规范（写稿阶段就要定，不是渲染时随便给）

1. 🔴 **一片至少 4 种转场**；相邻两条**不许同类**（位移类 / 3D 类 / 遮罩类 / 模糊类 / 特殊类）。
2. 🔴 **不许连续两条左右滑**。全片 `push_left` + `cover_left` 合计不超过总转场数的 1/3。
3. **开场第一下给最重的**：`cube_up` / `card_drop` / `flash_zoom`（观众第一次眨眼就在这）。
4. **讲结果、讲数据**：`fade` / `focus_pull` / `zoom_blur` —— 安静，让内容说话。
5. **讲转折、讲打脸**：`glitch` / `fade_black` / `fade_white`。
6. **讲对比、讲前后**：`split_h` / `split_v` / `diag_wipe` / `flip_y`。
7. **收尾**：`zoom_out_reveal` / `iris_close`，别用推送（推送是「还没完」的意思）。
8. **同一段落里同一转场最多一次**；`glitch` / `flash_zoom` 这类特殊效果**全片最多各一次**。
9. 转场时长跟语速走：快嘴 1.1 倍速的片用 0.4 秒，慢讲解用 0.6 秒；**超过 0.8 秒会拖**。
10. `"auto"` 只是兜底（新片先跑通），成片前按上面 9 条手排一遍。

## 7. 已知的坑

| 坑 | 现象 | 解法 |
|---|---|---|
| 实时录制 | 掉帧到 13fps、整页冻结 | 用定格（`reel()` 默认就是） |
| 少了闸门层 | 翻书/圆形收那两镜从片头一直挂着，画面糊成一团 | `.g` + `gateN` keyframes |
| 进场/退场写在同一元素 | 只有一条生效，转场「不动」 | 拆成 `.s` / `.k` 两层 |
| 翻牌 origin 写边 | 变成门板开合，不是翻牌 | `flip_x` / `flip_y` 不写 origin（居中） |
| `filter` 与 `preserve-3d` 同层 | 3D 被拍平，立方体变平面缩放 | 滤镜只放在 `.k`，别放 `.s`/`.g` |
| 描边宽度写 px | 换画布尺寸就失衡 | 一律 `em` |
| 帧数按素材时长算 | 视频比音频短、字幕错位 | `reel()` 用 `total` 收口 |
