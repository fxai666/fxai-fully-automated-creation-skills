# fxai-mixed-layout（公共目录 · 混排视频）

一条视频的展示形式可以变（整页幻灯 / 上中下分栏 / 广告片），但**底层只有两层**，
两层都在这里，谁用谁 import：

| 层 | 管什么 | 文件 |
|---|---|---|
| **版式层**（layout） | 一块画布上怎么分区：整页、上下壳+中区、左右壳+中区、二分栏、全屏压字 | `ml_frame.py`（带壳：上中下固定带）<br>`ml_trio.py`（带壳：左中右，中槽满高贴边、宽度可调）<br>`ml_split.py`（二分栏：横屏左文右图 / 竖屏上文下图 + 背景底三档）<br>登记表见 `references/02-版式登记表.md` |
| **素材槽层**（slot） | 槽里填什么：单图 / 多图轮播 / 视频 / 网页，最后都是一条同尺寸无声 mp4 | `ml_slots.py`（轮播·填槽·时长对齐·填充器）<br>`ml_page.py`（槽内网页的 HTML） |

🔴 **它不是一个技能**：没有触发条件，智能体不会主动"调用"它。它是被别的技能 `import` 的库，
装包时必须和各技能目录**同级**（依赖方都用 `../fxai-mixed-layout` 找它）。

## 本目录文件清单（先读这里）

**只读对应的那一册，其余一律不读**：按当前动作挑一行，读完就动手，不通读整包。

| 文件 | 什么时候读 |
|---|---|

| `references/02-版式登记表.md` | 加展示形式、判断某个版式归谁管时查：版式 → 展示形式 → 实现位置 → 状态 |
| `references/03-二分栏版式.md` | 写二分栏文案、调背景底（静态 / 虚化图 / 虚化视频）、判断竖屏素材怎么放时读 |

## 谁在依赖它

| 技能 | 用它的哪部分 |
|---|---|
| `fxai-slide-video` | 全部（`sv_media` 绑 `ml_slots`，`slides.media_page` 转发 `ml_page`、`frame_*` 转发 `ml_frame`、`trio_*` 转发 `ml_trio`、`split_*` 转发 `ml_split`）；`frame` 是上中下带壳版式，`trio` 是左中右带壳版式，`thirds` 是二分栏版式 |
| `fxai-ad-video` | 素材槽 + 填槽（`ad_assemble.py slots`：时间线逐段填槽出无声画面，再交 `mix` 叠旁白与 BGM）；版式可选无壳全屏或二分栏 |
| `fxai-poster` | 网页模式的渲染层（`import slides` → 间接用到本公共件） |

## 边界（改之前先看这三条）

1. **不 import 任何 fxai 技能**。方向只能是「技能 → 公共件」。ffmpeg 路径、编码器、帧率
   由 `ml_slots.configure()` 注入；画布样式（字体 @font-face、主题 CSS）与字段净化由
   `ml_frame.configure(...)` / `ml_trio.configure(...)` / `ml_split.configure(...)` 注入 ——
   公共件不猜环境、不读全局配置。
2. **不碰落盘与项目结构**。产物路径由调用方给，公共件只往 `out` 参数指定的位置写文件。
3. **录制端不在这里**。槽内网页的「Chrome + rec_anim.js 录制」属于技能层，
   通过 `materialize(render_page=...)` 注入 —— 换录制方案不用改公共件。

## 怎么加一种新的展示形式（三步）

1. **定槽位**：新形式是「画布分几块、哪块是可变槽」。整页幻灯 = 一块全屏槽；
   上中下分栏 = 上带 + 中区槽 + 下带；广告片 = 全屏槽 + 角标。
2. **写版式**：HTML/CSS 画固定部分（壳、装饰、品牌），槽的位置留空或留透明；
   字段规范照现有版式的写法（字段名一律可直接写进 `segments.json`）。
   带壳的照 `ml_frame.py` 的路子：壳只画固定部分，槽留透明，素材由 `part()` 垫在下面。
   **方向与背景是参数，不进版式名**：横屏左中右、竖屏上中下由画布比例自动切；
   背景是 `bg`（static / blur / blurvideo），换背景只改字段，不新增版式。
3. **登记**：把「版式名 → 展示形式 → 实现文件 → 槽尺寸 → 状态」写进
   `references/02-版式登记表.md`，再在对应技能的 SKILL.md 里加一行指针。
   **勿在第二个地方再抄一份 CSS 或转场表** —— 那就是要回归的重复。

## 素材槽的一句话心智模型

> 一段音频 + 一块槽 + 一张素材清单 = 一段视频。

槽的尺寸是参数（整屏 `768×1280`、中区 `768×440`、广告横屏 `1280×720`），
里面的东西是什么不影响外层：所以「幻灯能用、广告也能用」是天然成立的，
变的只是槽的尺寸和外面套不套壳。
