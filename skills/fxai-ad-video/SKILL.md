# 广告片制作

把「一个产品 / 品牌 / 目的地」变成一条可投放的广告片。本技能管**广告专属规范**与全流程编排；
画面、配音、字幕、贴片各环节调对应技能，本技能只规定广告该怎么定、怎么卡、怎么验。

## 开跑

```
1 立项   读 templates/广告立项单.md 填成 <项目>/广告立项单.md   → 定片型 / 时长 / 卖点 / 渠道
2 创意   读 references/07 → 定主张档位、主线动机、主要阻力、钩子与框架；要出多方向再读 08
3 脚本   读 templates/口播稿.md + references/01 → <项目>/口播稿.txt（一句一行）
4 分镜   读 references/02 + templates/分镜表.md  → <项目>/分镜提示词.md
5 出画   按 01 册片型选路线（A/B/C/D），调下游技能出素材
6 声音   读 references/04 → 多段口播按时间码对齐，混 BGM
7 包装   读 references/05 → 标题卡 / 贴片 / 片尾卡 / 烧字幕 / 封面
8 组装   读 references/06 → ad_assemble.py 拼装体检，ad_delivery.py 出交付清单
```

四条路线一句话区分：

| 路线 | 画面来源 | 主脚本 |
|---|---|---|
| A 产品演示片 | 人物 + 产品同框，AI 出镜演动作（10–20s，2–3 镜） | 短剧管线两镜跑法（02 册） |
| B 品牌蒙太奇 | 自家既有成片切片重剪 | `ad_assemble.py concat` + `mix` |
| C 静图运镜旅拍 | 空场景图 + Ken Burns + 逐段口播（30–60s） | `ad_assemble.py kenburns` |
| D 氛围片 | 参考图 + 音乐驱动 multi 模式（无人物） | `fxai-audio-video` multi |

## 铁律速查

1. **标准只从本技能取**：时长、字数、镜长、字号、避让位一律读 `references/`；旧片只作素材来源与对比样本，不作参数依据。
2. **主张分三档**：资料明确 / 待核实 / 创意表达；只有第一档能进口播与贴片做承诺（07 册）。
3. **一条片一个购买动机**：功能 / 情绪 / 社交三选一当主线，第二个动机另做一条（07 册）。
4. **一条片解一个阻力**：不知道 / 不相信 / 不需要 / 嫌麻烦 / 嫌贵 / 替代够用，先定是哪条（07 册）。
5. **钩子就是第一句**：删掉第一句片子仍成立，说明钩子被埋了，重写第一句（07 册）。
6. **每条卖点挂一条证据**：参数、演示、对比、第三方量级四选一；挂不上的降级为情绪句，不占卖点位。
7. **专属性过测试**：品牌名换成同品类占位符后脚本仍成立，即创意没立住，回 08 册换机制。
8. **先定稿再出画面**：口播稿定字、分镜定镜长，之后才提交生成；画面出完再改稿＝重跑。
9. **时长按档位表定**：广告不套短剧 60s 下限，10s 两镜照常放行（01 册）。
10. **口播字数 = 目标时长 × 5**（中文 4.5–5.5 字/秒，含停顿），超出即压字不压语速。
11. **画面内零文字**：字幕、标题、贴片一律后期加；提示词只写画面，文字交给后期层。
12. **贴片只补参数**：信息贴片补充口播未说的参数，不复读口播原句；落在人脸与字幕区之外。
13. **一镜一个方向的动作**：同一镜只写一个方向的位移或开合，反向动作另起一镜（02 册）。
14. **相邻镜同机位**：两镜衔接靠同机位参考图，景别跳变由参考图解决，不由提示词解决。
15. **全片一套规格**：分辨率 / 帧率 / 音轨在立项单里定死，混剪素材先统一转码再拼。
16. **抽帧验收**：每段中点抽帧拼联络表，核对卖点、人物、贴片位置；日志成功不算通过。

## 产物与命名

- 产物只落 `<工作区>/<项目名>/`，交付物放项目根，中间件进 `_tmp/`（fxai-standard 01 册）。
- 成片名带分辨率后缀：`成片_<项目>_<版本>_1280x720.mp4`；烧字版加 `_sub`，带封面加 `_带封面`。
- 每条成片对应一条 `delivery.json` 与 `交付清单.md`，由 `ad_delivery.py` 生成。
