# 05 · 后期与包装

> **何时读**：加标题卡、信息贴片、片尾品牌卡、烧字幕、出封面时。画面出完、声音混完才进这一层。

## 五层包装与顺序

正片 → 标题卡 → 信息贴片 → 片尾品牌卡 → 烧字幕 → 封面（独立出图）

- **顺序不得倒**：字幕最后烧，永远压在最上层；先烧字幕再加贴片，贴片会盖住字。
- 每层单独出一版文件（`_标题卡` / `_贴片` / `_品牌信息版`），最后一版才是交付版；
  中间版留在项目根，靠后缀区分，方便单层返修不重跑。
- 各层技能：标题卡 `fxai-title-card`、贴片 `fxai-infocard`、字幕 `fxai-lyric-subtitle`、
  封面 `fxai-poster`。字体白名单见 `fxai-standard` 06 册。

## 标题卡

- 位置在画面上部，一条主标题 + 一条副标题，不带第三条。
- 按 `timeline.json` 的 `beats` 切换，`start` / `end` 与口播段落起点对齐（04 册）。
- 每条停 3–7s；短于 2.5s 来不及读，长于 8s 会腻。
- 副标题写第二层信息（天次、参数、地点），不重复主标题的字。
- 不与底部字幕同区；画面上部 1/4 是标题区，下部 1/5 是字幕区，中间留给人脸与产品。

## 信息贴片

贴片的任务是**补口播没说的参数**，让观众停在画面上也能读到硬指标。

| 项 | 判据 |
|---|---|
| 内容 | 参数 + 一句效果，不复读口播原句；一条只说一件事 |
| 条数 | 10–15s 片 3 条；30s 以上 4–6 条；一条贴片配一句口播时段 |
| 时长 | 每条 1.8–2.8s，条间留 0.3s 空档 |
| 位置 | 竖列排在画面左侧或右侧（x≈0.23 / 0.77），避开人脸中心与底部字幕区 |
| 行数 | 每条 ≤ 2 行，单行 ≤ 14 字 |
| 主题 | 深色画面用 `mono` 半透明底 + 白字；浅色画面用反色，不用彩色块 |

- **字形判据**：贴片文案只用汉字、阿拉伯数字与中文标点。`≤ ≥ × ± ° ‰ / +` 这类符号先在字体里
  查有无字形，缺字形会回退成小号斜挂；把符号改写成文字表述（`低至` / `达到`）。
- 贴片文字与字幕同屏时，两者字重拉开一档，字号贴片大于字幕。
- 客户真值未定时，贴片内容集中写在一个 `infocards.json` 里，改值只改这一处。

## 片尾品牌卡

- 时长 2.2–2.8s，单独出图（`ad_assemble.py endcard`），再与正片拼接。
- 版式左对齐六行：`brand_en` 英文小标 → `brand_cn` 品牌名 → `slogan` → 分隔线（accent 色）
  → `spec_line` 参数行 → `tail_line` 信息行（字号最小）。底色走 `bg_top` → `bg_bottom` 竖向渐变，
  右上角一层极淡暖光；右侧装饰图填 `motif_png`，留空则纯排版。
- 转场：正片 `fade out 0.32s`，片尾 `fade in 0.5s`；音轨 `afade 0.78s` 收掉后补静音段到片尾长度。
- 品牌名、电话、门店数、质保全部集中在 `brand.json`，全是占位时在交付清单里标「占位待确认」。
- 片尾不加字幕、不加贴片，只留品牌信息。

## 字幕

- 画面内零文字的规矩由后期兜住：正片不生成字幕，统一烧录。
- 断句跟口播稿一行一句，一条字幕 ≤ 18 字，单条停留 ≥ 1.2s。
- 字幕底衬与贴片底衬不同款：两层半透明叠一起会发灰，同屏时只留一层底衬。
- 参数串（`5+12A+5`）进出字幕时拆成口语断句，字幕与小字条同屏会让底部拥挤。

## 封面

- 封面与首帧分工不同：首帧是画面，封面是信息。封面必须一眼看到主体 + 一句话卖点。
- 按投放渠道各出一版比例（公众号 2.35:1 与 1:1、信息流 9:16、横版 16:9），不靠裁一张通吃。
- 封面文案与片中标题卡同一套词，不另起一句。

## 验收（包装层）

1. 抽帧看每层：标题卡不压人脸、贴片不压字幕、片尾卡文字全在安全区内；
2. 贴片文案逐条核字形，无回退小字；
3. 字幕与口播逐句对齐，无错字、无半句；
4. 片尾衔接处无黑帧、无爆音；
5. 封面与首帧不同构，卖点与片中一致。
