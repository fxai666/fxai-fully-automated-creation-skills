# 02 · 分镜与提示词

> **何时读**：写分镜表、写 H3 六段式提示词、定参考图、算镜间衔接时。
> 六段式的完整通用写法在 `fxai-h3-video-prompt`；本篇只写**广告镜**与它的差异。

## 分镜表（先出表，再出词）

落成 `<项目>/分镜提示词.md`，一镜一块，字段固定：

| 字段 | 填什么 |
|---|---|
| 镜号 / 时长 | `镜头 1（6s）`；A 类两镜合计 10s，单镜 4–7s |
| 卖点 | 本镜承担的卖点（对 01 册的卖点表） |
| 起始状态 | 画面第一帧是什么样（人物位置、手的位置、产品开合态） |
| 动作 | 动词 + 物体 + 方向，**一个方向** |
| 口播句 | 本镜说的那句话，与口播稿逐字一致 |
| 音效 | 环境底噪 + 动作声 |
| 参考图 | 服务端编号 + 本地文件 |

单镜超 7s 时动作幅度会走形；两镜之间动作接不上时加中镜，不拉长镜。

## 镜头描述五要素

一镜的描述写全五样，缺一样模型就自己补一个，补出来的通常不是想要的那个：

| 要素 | 写什么 | 判据 |
|---|---|---|
| 景别 | 特写 / 近景 / 中景 / 全景 | 卖点要看细节用近景以上；卖点要看关系（人在空间里的位置）用中景 |
| 机位 | 高度 + 朝向 + 是否固定 | 只用固定机位、极轻缓推两类；齐胸高度正面是广告默认值 |
| 在场元素 | 该镜里出现的全部主体，逐个点名 | 少点名一个，模型会自作主张加人加物 |
| 动作 | 动词 + 物体 + 方向 | 一个视觉事件，写不出动词的镜拆开 |
| 落幅 | 动作结束那一帧的确定状态 | 终点态写死（门到位、手松开、光带消失），否则镜头会飘着结束 |

- **一镜一个视觉事件**：观众在一镜里只该记住一件事。两个事件挤一镜，两个都记不住。
- **证据帧**：演示型卖点必须让动作的**中间态**可见（门缝从细线张开的整个过程、油滴接触液面的一瞬）。
  只给起点和终点，观众看不到「它真的能这样」。
- **景别对比**：同一卖点的前后对比用同一景别，换景别会让观众以为是两件事；不同卖点换景别，
  同一景别连切三镜会看成一条长镜。

## 声画对应

- 一句口播绑一个动作：句子的重音词落在动作完成的那一帧，句子与动作同起同收。
- 单句时长 ≤ 镜长 − 1s：留出动作起手与收尾的时间，句子贴满整镜会显得赶。
- 一镜一句：两句塞一镜，第二句会被动作打断。
- 台词与画面矛盾时改台词：观众信画面。口播说「单手推开」而画面是两只手，卖点当场失效。

## 广告镜四条硬约束

1. **一镜一个方向的动作**。一镜里写「先关后开」两段反向动作，产品会基本不动，只有手臂在演。
   开与合拆成两镜，各给一个起始态。
2. **相邻镜同机位**。两镜的参考图必须来自同一机位；构图不同时剪接处会从近景跳远景。
   解法是图生图：以第 1 镜参考图为源，只把产品推/开到目标态，得到第 2 镜起始图。
3. **图生图走正向**。闭合态 → 推开态成功率高；敞开态 → 拉合态常原样返回。
   需要反向起始态时，回到闭合态重推一次，不在敞开图上做反向。
4. **参数写死在正文里**。产品几何（边框宽、门缝宽、玻璃层数）、接触关系（五指扣死、
   掌心贴合、同速同向位移）逐条写进详细描述；写「自然地推开门」这种概括句，模型会给手摆在
   把手旁边而门不动。

## 六段式在广告里的取值

| 段 | 广告写法 |
|---|---|
| 主体定义 | 人物一段、产品一段，分 `<Subject 1>` / `<Subject 2>`；**只写身份词一句**（`<Subject N> 是 <Picture M> 中的<人物身份 / 产品>。`），保留类目写进延续分析，不写具体颜色款式（铁律 17） |
| 摘要 | 首句给起始态（位置 + 接触 + 产品开合态），后句给整镜唯一动作的**终点** |
| 延续分析 | 相邻两镜都要写，只列保留**类目**（人物身份、发型发色、服装、鞋履；产品形制与配色），不写具体颜色款式（`fully_preserved`） |
| 详细描述 | 机位 → 在场元素 → 动作分解 → 观众视线 → 卖点句 `At 00:00.X` 起说 |
| 整体音效 | 环境底噪 + 动作声（轨道滚动、闷顿、合上的轻响），不写配乐 |
| 非叙事音乐 | 一条情绪线铺满整镜，末镜收在单音上 |

- **卖点句起说点**在镜内 0.4–0.8s，句末与本镜动作完成同帧；说早了观众看动作不听词。
- **机位词只用固定类**：固定机位、极轻缓推、齐胸高度正面。广告镜靠产品动作抓人，
  运镜一多，观众的注意力就从产品挪到镜头上。
- **画面内零文字**：字幕、价格、参数全部后期加；提示词正文只描述画面。
  负向段由管线统一追加，只在正文两侧留空，不手抄进六段。

## 分镜提示词文档

`分镜提示词.md` 是喂给模型的**真值文档**，与给人看的画面说明分工不同：

- 每段提示词包在 ```text 代码块里——`<Subject N>` / `<Picture N>` / `<d>` 是模型指令标签，
  裸写在正文会被当 HTML 标签吞掉。
- 只收**最终提交版**，逐字从提交脚本导出，不手打、不留中途版本。
- 表格登记参考图的服务端编号与本地文件名，标出各镜起始态；中途版本另存并标「已归档」。

## 提交前自检

1. 每镜的动作句只有一个方向；
2. 相邻镜参考图同机位；
3. 人物与产品的主体定义是极简类目式，**不含具体颜色款式词**，详细描述里也没有复述外观；
4. 产品几何与接触关系写进了正文；
5. 镜内文字提及为零，卖点句时间码落在 0.4–0.8s；
6. 各镜时长加起来等于档位目标（A 类两镜 10s）。
