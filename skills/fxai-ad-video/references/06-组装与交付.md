# 06 · 组装与交付

> **何时读**：把素材拼成片、跑混音、接片尾卡、出交付清单与发布物料时。

## 项目目录

```
<项目>/
├─ 广告立项单.md          立项与卖点（01 册）
├─ 口播稿.txt             一句一行
├─ 分镜提示词.md          提交真值（02 册）
├─ timeline.json          节拍表（04 册）
├─ brand.json             品牌信息（占位集中在此）
├─ infocards.json         信息贴片文案与时间窗
├─ 成片_<项目>_1280x720.mp4
├─ 交付清单.md / delivery.json
├─ _scenes/ _clips/ _audio/   过程素材（交付前清或留着复用）
└─ _tmp/                  抽帧、联络表、试听片段
```

交付物在项目根，过程素材在 `_` 前缀目录，中间件在 `_tmp/`。交付前跑
`fxai-standard/scripts/check_project_clean.py <项目> --strict`。

## 组装入口 `ad_assemble.py`

五个子命令盖住 A/B/C/D 全部拼装动作，路径参数全相对当前目录：

```bash
# 时间线 → 无声画面片（画面侧统一入口）；每段一块槽，填图 / 轮播 / 视频 / 网页
python scripts/ad_assemble.py slots --spec timeline.json --out _tmp/timeline_visual.mp4

# 静图 → 运镜片段（C 类）；segs.json 见下
python scripts/ad_assemble.py kenburns --segs segs.json --out-dir _clips

# 无声片段 → 主体带音（B / C 类）；--voice 文件@起点秒，可重复
python scripts/ad_assemble.py mix --video visual.mp4 \
    --voice 口播01.wav@0.4 --voice 口播02.wav@6.8 --bgm 音乐.wav --bgm-volume 0.20 \
    --out 成片_主体_1280x720.mp4

# 片尾品牌卡出图（读 brand.json）
python scripts/ad_assemble.py endcard --brand brand.json --out 片尾卡.png

# 正片 + 片尾卡拼接（默认淡出 0.32s / 淡入 0.5s）
python scripts/ad_assemble.py attach --main 成片_主体_1280x720.mp4 \
    --endcard 片尾卡.png --hold 2.6 --out 成片_品牌信息版_1280x720.mp4
```

片段清单 `segs.json`（与 03 册的运镜参数对应）：

```json
{"fps": 25, "size": [1280, 720], "segments": [
  {"image": "_scenes/a.png", "duration": 6.22, "motion": "zoom-in", "out": "seg1.mp4"}
]}
```

`motion` 取 `zoom-in` / `zoom-out` / `pan-left` / `pan-right`。

时间线 `timeline.json`（画面侧的单一入口，与 04 册的节拍表同一份时间码）：

```json
{"canvas": {"w": 1280, "h": 720, "fps": 25}, "fade": 0.12,
 "segments": [
   {"start": 0.0,  "end": 6.52,  "media": ["_scenes/片头.png"], "zoom": 0.04},
   {"start": 6.52, "end": 10.08, "media": ["_clips/编剧.mp4", "_scenes/分镜.png"],
    "trans": "push_left", "trans_dur": 0.5},
   {"start": 10.08, "end": 13.60, "media": [{"page": {"type": "text", "kicker": "分镜",
    "title": "场景构图<em>自动生成</em>", "items": ["一句话大纲", "自动分场"]}}]}
 ]}
```

每段 = `start` / `end` 时间码 + `media` 清单，产出跟时长同长的无声画面段，末段自动拼成
`timeline_visual.mp4`，再交给 `mix` 叠旁白与 BGM。

- `media` 给一叠就是段内轮播（`trans` 取 `push_left` / `push_right` / `push_up` / `push_down` /
  `fade` / `cut` / `mix`），单条给一张图或一段视频就直贴。
- `{"page": {...}}` 是网页槽：文字卡 / 长图滚动 / 真网页，与幻灯片视频同一套填法。
- `fit` 取 `cover`（默认）/ `blur`（竖屏素材居中 + 虚化铺底）/ `contain`。

**要「旁白 + 左文右图」那种分栏**：段里加 `layout: "thirds"` + `fields`，媒体槽由版式给出：

```json
{"start": 6.52, "end": 10.08, "layout": "thirds", "bg": "blurvideo", "fit": "cover",
 "fields": {"kicker": "岗位 01 / 08", "title": "编剧 · <em>AI</em>", "lead": "剧本到成片",
            "points": ["一句话出三幕结构", "改台词直接重跑"],
            "steps": ["编剧","分镜","美术","歌手","演员","字幕","封面","剪辑"], "cur": 1},
 "media": ["_clips/编剧.mp4"]}
```

- `layout: "thirds"` 时画布切三分区：横屏左中右、竖屏上中下（同一份代码自动切）。
  字段、背景底 `bg`（`static` / `blur` / `blurvideo`）、全屏压字 `media_full` 见
  `../fxai-mixed-layout/references/03-二分栏版式.md`。
- `fields` 里**不写 `media`**：素材照旧走段级的 `media` 清单，这样轮播、网页槽、
  `fit` 全都不变。
- 竖屏素材进横屏槽用 `fit: "blur"`；素材若是「1280×720 画布片」（竖屏居中 + 两侧黑），
  先裁回原始竖屏片源，否则槽里会变成黑边套黑边。
- 槽内只放画面：标题卡、字幕、贴片走 05 册的后期层，不写进画面。

**要「固定壳 + 中区嵌一条现成成片」那种栏目包装**：段里加 `layout: "frame"`，
壳字段（上下两条带）写进 `fields`，媒体区就是画布中间那一条：

```json
{"start": 0, "end": 52.28, "layout": "frame", "fit": "cover",
 "fields": {"title1": "一支广告片", "title2": "全流程一个人"},
 "media": ["凤希AI广告片_成片.mp4"]}
```

- `layout` 认 `frame` / `上中下分栏` / `上中下` / `上下分栏` / `栏目图文`，五种写法同一路。
- 中区那一格的框**一律取 `ml_frame.frame_box(w, h)`**，别在段里按比例手算：
  竖屏 9:16（1080×1920）→ 中区 1080×608、全宽 16:9；竖屏 3:5（768×1280）→ 768×432；
  横屏 1280×720 → 中区 896×504、左右各让 15%。
  壳字段是 `title1`（白）/ `title2`（黄）/ `logo` / `logo_img` / `logo_en` / `tagline` / `slogan`，
  缺省取 `FRAME_BRAND`。字段全表见 `../../fxai-slide-video/references/02-模板库.md`「上中下分栏」。
- 🔴 **壳是全片一份资产，按内容寻址缓存**：同一组壳字段只截一次图，段数再多也不重复渲染；
  改动会换壳的两处是上下带文本与中区花字 `overlay`（花字画在遮罩上，不在素材上）。
- 🔴 **这个版式的规范画布是竖屏 9:16**。横屏只在「素材本身是横屏片、要整条嵌进中区」时借用
  （川西那条就是），不是第二种用法；借完勿把横屏当默认。横屏那套比例也不是竖屏等比缩出来的：
  竖屏比例套到 1280×720，中区会变成 1280×248 的扁条、16:9 片源裁掉三成高度，所以横屏改成
  中区宽高各 70% —— 一点不裁，代价是左右各留 15% 给壳底（观感就是「画框在栏目包装里」）。
- **壳的文字别与画面重复**：成片自带地名卡 / 落版金句时，上下带就写栏目包装（栏目名 + 期数），
  否则同一句会在上带和画面里各说一遍。
- **现成成片整条嵌入**：一条 0→总长的段、`media` 指那条 mp4 即可，不必拆回素材重排。
  画面由 `slots` 出、无声；音轨直接 `-map 1:a` 从原片取，**别再走一遍 `mix`** ——
  那会把已经混好的旁白当 `--voice` 又压一次，等于混了两遍。

## 组装纪律

- **画面侧只走 `slots`**：标题卡、素材切片、轮播、网页、二分栏、上中下分栏一律填进时间线，
  勿在项目里另写 PIL 画卡或手算切片的脚本 —— 那套只服务于一条片，下一片还得重写一遍。
  项目里的脚本只做两件事：备素材、写时间线。
- **先出无声片段再混音**：每段 `-an`，音轨在最后一步统一叠，各段音轨拼接处的爆点由此消掉。
- **拼前统一规格**：分辨率、帧率、像素格式（`yuv420p`）三项一致才 `concat -c copy`；
  不一致先各自转码，不走 `-c copy`。
- **中文文件名先转 ASCII**：ffmpeg 滤镜里的中文路径会解析失败，跑前复制成 `src.mp4` / `out.mp4`，
  跑完改名（fxai-standard 01 册）。
- **单层返修不重跑全链**：改贴片只重跑贴片层，改片尾只重跑 `endcard` + `attach`。

## 交付清单

跑 `scripts/ad_delivery.py <项目目录>`，扫成片与音频，写出 `交付清单.md` 并更新 `delivery.json`：

```bash
python scripts/ad_delivery.py "<项目目录>"     # 路径按实际工作区写
```

清单必须包含：

| 段 | 内容 |
|---|---|
| 规格 | 分辨率 / 帧率 / 时长（实测）/ 音轨 / 文件大小 |
| 引擎 | 视频模型与分段数、配音引擎与音色参数、字体名与授权 |
| 结构 | 镜/段表：序号、时长、卖点、对应口播句 |
| 后期层 | 标题卡、贴片、片尾卡、字幕各自版本与时间窗 |
| 待确认 | 客户未给真值的占位项（品牌名、电话、门店数、质保） |
| 复现入口 | 提交脚本、混音命令、包装脚本 |

## 验收（成片层）

1. **抽帧联络表**：每段中点一帧横排，逐帧核对人物在场、卖点画面、产品形态；日志成功不算通过。
2. **时长**：实测时长与 `sum(各段)` 差 ≤ 0.2s，与文案写的秒数一致。
3. **音画**：口播起点与段落起点差 ≤ 0.3s；无爆音、无提前截断。
4. **文字层**：标题卡、贴片、字幕三层互不遮挡；贴片无回退字形。
5. **首尾**：首帧能当封面看；末帧停在品牌卡或收口画面上，不留半帧黑场。
6. **命名**：成片名带分辨率后缀与版本词，一眼能对上是哪一版。

## 发布物料

一条广告的发布包 = 成片 + 封面（按渠道比例）+ 标题 + 一句话简介 + 话题标签。
多条广告合成一篇推文时，走 `fxai-weixin-gzh-publisher`：

- 每条广告一段：封面图 + 一句卖点 + 成片；段与段之间用小标题分隔，不复述成片口播。
- 文章标题只写一次主题，不并列三条广告的名字。
- 视频素材进公众号前核体积与比例，竖版素材不直接塞横版版位。
