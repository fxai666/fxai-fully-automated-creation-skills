# 08 · 创意机制库

> **何时读**：需要一次出多个创意方向、挑表达机制、给方向打分、或判断「这个创意是不是哪家都能用」时。
> 07 册定「买它的理由」（动机、钩子、结构），本册定「创意从哪来、用什么机制拍」。

## 创意领地（先选领地，再选机制）

| 领地 | 创意来源 | 优先场景 |
|---|---|---|
| 证据 | 产品机制、演示、实测 | 功能差异明确且看得见 |
| 人情 | 真实行为、尴尬、欲望、代价 | 人物关系有价值，痛点有画面 |
| 品类重设 | 品类默认规则、错误的评价标准 | 新品类，或同类广告高度雷同 |
| 感官 | 声音、质地、动作、设计 | 食品、美妆、香氛、材质 |
| 品牌仪式 | 固定动作、包装、人物、口音、声音资产 | 功能差异弱，需要长期占位 |
| 实用原生态 | 任务、教程、真实使用流程 | 工具、电商、低预算原生内容 |
| 文化 | 社会习惯与语言 | 去掉热点后产品关联仍成立 |

一条片只选**一个领地 + 一个主机制**，最多叠一个辅助机制。
挑战、反转、开箱、一镜到底、对比都是**机制**，不是领地：先定领地，再挑机制，顺序倒了就会拿拍法硬套产品。

## 机制库

| 机制 | 做法 | 配哪种卖点 | 风险 |
|---|---|---|---|
| 结果前置 | 先给理想结果，再倒回怎么做到 | 效率、清洁、收纳、修复 | 结果与产品脱节 |
| 视觉隐喻 | 抽象利益变成可见的物理事件 | 轻、快、静、稳、安全 | 结尾不还原真实机制就成了空镜 |
| 极限演示 | 高压或夸张场景里验证功能 | 耐用、防水、续航、吸力 | 条件不可主张，须标演示条件 |
| 痛点拟人 | 拖延、异味、噪音变成角色 | 高频日常痛点 | 配角抢戏，产品不出手 |
| 规则反转 | 建立熟悉规则再打破 | 差异化强、品类创新 | 反转不指向卖点 |
| 微型世界 | 产品内部机制或场景微缩 | 结构、流程、技术 | 解释成本过高 |
| 一镜到底 | 连续动作串起问题到结果 | 操作简单、流程顺畅 | 炫技牺牲清晰度 |
| 多场景切换 | 同一人快速换身份或生活切片 | 多用途、多场景 | 滑成功能清单 |
| 诚实对照 | 同场景同条件前后或两种做法 | 可演示的效率与体验 | 变量没控住，比较站不住 |
| 声音主导 | 用声音变化表现静音、酥脆、顺滑、速度 | 食品、家电、机械 | 静音观看时不成立 |
| 内心戏 | 犹豫、尴尬、释然变成旁白冲突 | 情绪收益、社交场景 | 旁白过长，产品不出场 |
| 假纪录 | 严肃采访拍荒诞小事 | 生活方式、年轻化 | 片尾收不回利益点 |

## 方向分叉：两个方向至少三轴不同

出方向时按六轴记录，只换形容词不算另一个方向：

| 轴 | 取值 |
|---|---|
| 戏剧机制 | 反转 / 实验 / 追逐 / 误会 / 纪录 / 仪式 / 倒计时 |
| 叙事视角 | 用户 / 旁观者 / 产品 / 痛点角色 / 未来的自己 / 群体 |
| 情绪曲线 | 紧张→释放 / 尴尬→自信 / 荒诞→合理 / 平静→惊喜 |
| 产品证明 | 同条件对照 / 连续动作 / 界面实录 / 细节微距 / 结果追踪 |
| 镜头语法 | 一镜到底 / 固定机位 / 主观视角 / 分屏 / 监控视角 / 微缩 |
| 制作路线 | 手机原生态 / 桌面演示 / 棚拍 / 外景叙事 / AI 高概念 |

标准提案出 6–8 个方向，大提案 12 个以上；任意两个方向至少三轴不同，三轴相同的并成一个。

## 评分与选型

六维打分（每维 1–5）：**原创 / 清晰 / 产品中心 / 可拍 / 平台适配 / 可信**。

- 任一维 <3 先修短板，修不动就淘汰；总分最高不自动胜出。
- 「可拍」按本技能现有能力判：现有素材、现有模型、现有后期层是否做得出。
- 「可信」对不上 07 册证据链的方向直接淘汰。

修订优先级：① 纠正无依据主张 → ② 让产品成为转折的原因 → ③ 主卖点可视化 →
④ 压开头与重复信息 → ⑤ 加风格与镜头趣味。

## 专属性测试

把品牌名与产品名替换成同品类占位符，再看脚本：

| 结果 | 专属性 | 处置 |
|---|---|---|
| 台词画面一字不改也成立 | 低 | 换机制，从产品物理动作里找记忆点 |
| 只换演示动作，创意骨架仍通用 | 中 | 加一个产品独有的动作或证据形式 |
| 依赖该产品的机制、包装动作、声音或仪式 | 高 | 可用 |

功能差异不足时，从使用仪式、包装、声音、人物、服务里建占位，不拿未证实的参数硬造功能优势。

## 陈词滥调换法

| 常见套路 | 为什么弱 | 换法 |
|---|---|---|
| 用前皱眉、用后微笑 | 换成任何产品都成立 | 找一个该产品独有的动作，让结果在同一镜发生 |
| 粒子包裹产品 | 只有高级感，没有证据 | 粒子换成真实机制、材质或数据的可视化 |
| 快节奏痛点蒙太奇 | 信息多、没有单一张力 | 挑代价最大的一个时刻展开 |
| 「科技改变生活」类 | 空泛、不可验证 | 展示步骤减少、时间缩短或体验变化 |
| 贬低同行 | 可信度低、无证据比较 | 同条件演示，或只讲自身机制 |
| 结尾突然摆产品 | 产品不是故事的原因 | 让包装、结构、动作提前成为转折线索 |

## 组合原则

1. 先选与卖点天然匹配的机制，再定风格；风格先行的方向一律打回。
2. 最强那一帧要能截成封面，且静音状态下就表达痛点或结果。
3. 一条 30s 片只留一个主冲突、一个主反转、一个动作。
4. 反转前埋线索，反转后给证据，结尾回到品牌资产。
5. 预算档位对应机制：低 = 诚实对照 / 内心戏 / 一镜到底 / 声音主导；
   中 = 痛点拟人 / 多场景 / 假纪录；高 = 微型世界 / 复杂隐喻 / 极限场景。
