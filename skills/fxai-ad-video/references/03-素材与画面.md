# 03 · 素材与画面

> **何时读**：定画幅帧率、出场景图/参考图、选路线、把异规格素材并进一条片子时。

## 规格定死（立项单里写死，全片不改）

| 项 | 取值 |
|---|---|
| 横版成片 | 1280×720（静图运镜、蒙太奇）或 1280×768（人物出镜，竖高一点给人物留头顶） |
| 帧率 | 25fps（静图运镜、混剪）；人物生成按管线默认，最后统一转 25fps |
| 音频 | 48kHz 立体声 AAC 192k；口播源 24kHz 单声道，混音时转立体声 |
| 场景图 | 1920×1080 横构图（留 1.5 倍缩放余量给运镜） |
| 封面 | 竖版按渠道（公众号 2.35:1 与 1:1 各一张），横版 16:9 |

分辨率写进文件名后缀（`_1280x720`），同一支片的不同版本靠后缀区分，不靠目录。

## 素材四种来源

| 来源 | 做法 | 注意 |
|---|---|---|
| AI 空场景图 | `fxai-scene-gen`，提示词写地点/光线/材质/画幅 | 无人物场景一次出 7–8 张，逐张配自己的描述 |
| AI 人物 + 产品同框 | `fxai-scene-gen` 传 `role=<角色四视图>`，把人和产品放进同一张图 | 人物起始姿态与手的落位比分开喂图稳得多 |
| 既有成片切片 | ffmpeg 按时间点裁 3–3.5s 片段 | 先统一转码再拼，异分辨率一律先归一 |
| 客户素材 / 实拍 | 直接转码进统一规格 | 素材只认客户给的那一批，不自配 |

- **每张场景图配一段自己的描述**：多段提交时描述用 `|` 分隔随各段下发，只给图不给描述，各段背景会雷同。
- **空场景图给 C 类用**：静图运镜全靠 Ken Burns 撑节奏，构图要留出推拉余量（主体不贴边）。
- **人物同框图给 A 类用**：两镜需要两个起始态就出两张（闭合态 / 半开态），不用一张图演两个动作。

## 异规格并轨

竖版素材进横版片子，走「模糊填充」：背景整幅裁切放大 + 高斯模糊（`boxblur=18:4`），
前景等比缩到高度贴合、居中叠加。整幅裁切会把竖版画面切掉人物头顶与脚。

横版素材进横版片子，直接 `scale=1280:720:force_original_aspect_ratio=increase,crop=1280:720`。

统一转码参数：`libx264 -crf 18 -pix_fmt yuv420p -r 25 -an`（先出无声片段，音轨最后统一混）。

## 静图运镜（C 类）

- **源图先放大 2.25 倍再裁**：1280×720 的成片，先把 1920×1080 源图 scale 到 2880×1620 再 crop，
  zoompan 在放大后的画布上做位移，边缘不会露黑边、也不糊。
- **推近**：`z='min(zoom+0.0006,1.15)'`，单段 6–8s 内推到 1.15 封顶。
- **拉远**：`z='1.15-0.15*on/(N-1)'`，用输出帧序号线性递减；用 `zoom` 递推做拉远会来回震荡闪。
- **左右横移**：`z=1.10` 固定，`x` 从 0 到 `iw-iw/zoom` 线性走完。
- **一段一种运镜**：相邻两段换运镜方向（推→移→拉），连着两段同向推看不出段落切换。
- 每段时长跟口播句走：一句一段，句长 6–8s；口播句与段落起点差控制在 0.3s 内。

## 氛围片（D 类）

- 参考图放服务端图片目录（按项目名建子目录），`mode="multi"`、`char_rel=None` 走零人物。
- 每段提示词写：景别 + 运镜 + 主体动态 + 色调 + 质感，段数与 `h3_segment_count(音频时长)` 对齐。
- 段数由音乐时长算出来，不由画面数量决定；段数多于图数时一图配多段。

## 素材边界

- 字体只用 `fxai-standard` 06 册白名单（标题 得意黑 / 正文与字幕 Noto Sans SC），商业字库禁用。
- 参考图只用用户给的那批；缺图先问用户要，不自行找图、不自行生成人物替身。
- 客户产品图、门店照这类真实素材只做转码与裁切，不做生成式改写。
