# 07 · 创意与发想

> **何时读**：01 册定完片型之后、写口播稿之前。这一册决定「这条片子说什么角度」，01 册决定「说多少」。
> 要一次出多个方向、挑表达机制、给方向打分时，读 08 册。

## 主张边界

写稿前先把手上材料分三档，档位决定这句话是否进正片：

| 档 | 判定 | 用法 |
|---|---|---|
| 资料明确 | 有出处：参数表、实测记录、客户给的文件、已授权案例 | 可进口播与贴片，可做承诺 |
| 待核实 | 客户口头说、二手转述、无单位无口径 | 只进「待确认」，不进定稿 |
| 创意表达 | 画面情境、比喻、氛围 | 可拍，但不得写成效果结论 |

- **客户提供了不等于已核实**：来源记到具体段落或文件，写不出处的按待核实处理。
- **参数与结论之间不自动成立**：有「可拆卸灯罩」推不出「单手可拆」；有「有检验工序」推不出「零故障」。
  推广出来的结论按创意表达处理，或整句删掉。
- 示意画面标示意，不冒充实测；对照演示标条件。

## 一条片子只服务一个购买动机

先定唯一动机，再定卖点。动机三选一，选中一个当主线，允许一个辅助：

| 动机 | 观众心里的问题 | 片子靠什么成立 | 适配片型 |
|---|---|---|---|
| 功能 | 它到底解决什么 | 演示 + 参数 + 对比 | A 产品演示、B 品牌蒙太奇 |
| 情绪 | 用了我会是什么感觉 | 氛围 + 质感 + 生活场景 | C 静图运镜、D 氛围片 |
| 社交 | 别人会怎么看我 | 场景里的他人反应 + 身份符号 | B 品牌蒙太奇 |

判据：把主线动机删掉，片子还剩什么？剩不下东西就说明主线没立住。
一条片里塞两种动机，观众两个都记不住——第二个动机另做一条。

### 阻力诊断（先判断他为什么不买）

广告化解的是**一个主要阻力**，不是把优点再念一遍。先选一条，全片对着它打：

| 阻力 | 观众心里的话 | 片子该给什么 |
|---|---|---|
| 不知道 | 还有这种东西 | 场景直呼 + 它有什么用 |
| 不相信 | 说得好听，真能吗 | 演示、实测、同条件对照 |
| 不需要 | 现在这样也行 | 把现有做法的代价摆出来 |
| 嫌麻烦 | 学不会、装不上、要等 | 一镜到底走完操作 |
| 嫌贵 | 凭什么这个价 | 单位成本、寿命、替代方案的账 |
| 替代够用 | 家里那个还能用 | 换掉的那一刻的具体收益 |

阻力选错，卖点再准也打动不了人：不信的人需要证据，不需要的人需要代价，两套话各自成立、互不替代。

### 价值链（把功能追到证据）

对每个功能连追四问：使用时会具体发生什么变化 → 替用户省了什么、避开了什么、得到了什么感受 →
哪个动作或参数能证明它。得到一条链：

`机制 → 使用变化 → 功能利益 → 情绪回报 → 证据`

链上每一跳都要能填满；断在「情绪回报」就说明还在讲参数，断在「证据」就说明还没找到画法。
优先选**痛点高频 + 证据强 + 可视化程度高**的那一条当主卖点，其余降为贴片内容。

## 创意形态

形态决定调性、演员与节奏，与 01 册的制作路线是两个维度：路线管画面怎么来，形态管这条片子像什么。

| 形态 | 主体是谁 | 情绪温度 | 适配动机 | 常用结构 |
|---|---|---|---|---|
| 品牌形象 | 品牌想占的那个位置 | 冷静、克制 | 社交 / 情绪 | AIDA、4P |
| 功能演示 | 产品本身 | 直接、干脆 | 功能 | FAB、钩子—主体—收口 |
| 开箱种草 | 使用者第一视角 | 亲近、随意 | 功能 + 社交 | PAS、BAB |
| 反应展示 | 旁人的反应 | 轻快、有戏 | 社交 / 情绪 | 规则反转、内心戏 |
| 剧情 | 一个冲突或误会 | 有起伏 | 情绪 | BAB、HSO |

形态写进立项单；同一支片不混两种形态，混了就变成「一半像广告一半像 vlog」。

## 钩子

钩子就是**第一句**，不是开头几句铺垫之后的第四句。前 3 秒内说完，且必须让观众判断出「这跟我有关」。

钩子五型（选一型，不叠用）：

| 型 | 成立判据 |
|---|---|
| 场景直呼 | 说出观众此刻正在经历的具体场景，场景越具体越像在说他 |
| 数字反差 | 一个真实数字 + 一个与直觉相反的事实，数字必须能兑现 |
| 反常识 | 推翻该品类里普遍被接受的一条做法，须在同一支片里给出理由 |
| 他人见证 | 引用可核实的第三方量级（评价数、复购率、门店数），不引用无出处的好评 |
| 直接指令 | 一个动词开路，紧跟一句「换来什么」，指令与所得必须对得上 |

- **埋钩子判定**：把第一句删掉，片子是否仍然成立？成立即说明第一句是铺垫，钩子被埋了，重写第一句。
- 钩子句与收口句**都要有同屏字幕**（05 册），静音刷到时靠这两句成立。
- 品牌名不进钩子：钩子讲观众的事，品牌在收口出现。

## 结构框架

框架是排布方式，不是文案。按片型与时长选一个，全片只用一个：

| 框架 | 段落 | 适配 |
|---|---|---|
| 钩子—主体—收口 | 3 段 | 默认，10–20s 标准片（本技能主结构） |
| PAS | 问题 → 加剧 → 解法 | 痛点明确的功能型，15–30s |
| AIDA | 注意 → 兴趣 → 欲望 → 行动 | 30–60s 完整片，多卖点递进 |
| BAB | 之前 → 之后 → 桥 | 转变型（改造、升级、前后对比） |
| FAB | 参数 → 优势 → 用户获得 | 单参数强、需要解释的功能型 |
| 4P | 承诺 → 画面 → 证明 → 推动 | 60s 以上，招商片、品牌片 |

- 框架选定写进立项单，分镜按框架段落切，不混用。
- 中段超过 4 个信息点时换 AIDA 或 4P，硬塞进 3 段结构会变成念参数。

## 卖点 → 证据链

每条卖点必须挂一条**可验证证据**，否则降级为情绪句，不占卖点位：

| 证据类型 | 成立条件 | 不成立 |
|---|---|---|
| 参数 | 有单位、有实测口径 | 只有形容词 |
| 演示 | 画面里演出来，观众能看见 | 只在口播里说 |
| 对比 | 同条件前后或竞品对照 | 单方面宣称 |
| 第三方 | 有出处、可核实的量级 | 无出处的「大家都说好」 |

- **FAB 三层拆解**用在参数型卖点上：参数是什么（`8mm`）→ 比同类好在哪（窄）→ 观众得到什么（可视面小、通透）。
  三层写全，口播只取后两层，参数留贴片。
- 一条卖点配一条证据；证据不足时改卖点，不硬吹。
- **三类证据不可互换**：演示证明功能存在、案例证明某情境下发生、实验证明限定条件下的结论。
  拿一个演示去撑「所有场景都适用」是越级使用，观众一戳就破。

## 创意矩阵（投放型必做）

同一支片要投多个渠道或多个钩子时，只改一个变量：

| 维度 | 一份片出几条 | 说明 |
|---|---|---|
| 钩子 | 3 条 | 同一主体同一条主体结构，只换第一句 |
| 卖点顺序 | 2 条 | 首卖点换位，看哪条先被记住 |
| 时长 | 2 条 | 标准片与钩子片各一条 |

- 一次只改一个维度，两条同时改就分不清是哪个起的作用。
- 素材命名带变量标记（`_钩子A`、`_首卖点2`），交付清单里登记改了哪一项。
- 每条素材单独出交付清单，共用同一份品牌信息与后期层。

### 短版怎么压

从完整片压到 15s / 10s 时，先删次要传播任务，保留「主张 + 证据」这一对：

| 形态 | 短版至少留什么 |
|---|---|
| 功能演示 | 一次完整的操作 |
| 品牌形象 | 一个关键选择 |
| 企业/实力 | 一条能力链 |
| 剧情 | 一个冲突与它的转折 |

压到只剩口号与收口句，等于没压，是换了一条空片。

## 平台节奏

| 版位 | 时长 | 画幅 | 声音假设 | 结构要点 |
|---|---|---|---|---|
| 信息流冷流量 | 15–25s | 9:16 | 默认静音 | 钩子与收口必须有字幕，前 3 秒出画面主体 |
| 再营销 | ≤35s | 9:16 或 1:1 | 多数有声 | 可上参数与对比，卖点密度高于冷流量 |
| 门店屏 / 大屏 | 10–15s | 16:9 | 多数静音 | 零口播依赖，画面与贴片自洽 |
| 电商详情 | 15–30s | 1:1 或 16:9 | 静音为主 | 首帧即卖点，参数贴片提前到 0.5s |
| 公众号 / 官网 | 30–60s | 16:9 | 点击后有声 | 可用完整片，允许长钩子与故事 |

- 静音版位先按「关掉声音是否看得懂」过一遍：画面 + 标题 + 贴片三者要能各自独立成立。
- 同一支片换版位时重排时长与画幅，不靠裁切通吃（03 册）。

## 三遍桌面检查

出片前按顺序过三遍，每遍只开一个通道：

1. **只看画面 + 屏幕文字**（静音）：卖点是否读得懂，钩子与收口是否都在字幕里；
2. **只听音轨**（不看画面）：口播是否独立说清一件事，有没有一句在描述画面已经说完的东西；
3. **对照资料**：每条主张回到 07 册的主张边界，逐句核档位。

文字推演代替不了这三遍；三遍都过了才进 01 册定稿闸门。

## 发想自检

1. 每条主张都能归到「资料明确 / 待核实 / 创意表达」三档之一，没有越档承诺；
2. 主线动机只有一个，删掉主线片子不成立；
3. 主要阻力说得出是哪一条，全片都在解它；
4. 第一句就是钩子，删掉它片子不成立；
5. 全片只用一个框架，段落与框架对得上；
6. 每条卖点挂着一条能兑现的证据，且证据没有越级使用；
7. 收口只有一个动作，说清下一步发生什么；
8. 静音看一遍，画面 + 标题 + 贴片能独立讲明白；
9. 品牌名换成同品类占位符后，脚本是否还成立（08 册专属性测试）；
10. 投放型的变量只改了一处，且写进文件名。
