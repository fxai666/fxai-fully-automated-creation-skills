# gen_song.py 执行方式、参数表与工作流节点硬约束

**何时读**：查怎么跑、参数默认值、占位符与节点号时

本技能自带脚本 `gen_song.py`（与 SKILL.md 同级），只依赖公共客户端 `fxai-workflow/comfy_client.py`，
**不依赖 mv-pipeline、不绑定任何项目**，换机器换目录都能直接跑。

```bash
python gen_song.py --style-file s.md --lyrics-file l.md --tag 歌名
```

参数：

| 参数 | 说明 |
|---|---|
| `--style` / `--style-file` | Style 原文或风格文件（UTF-8）。两个都不给会报错 |
| `--lyrics` / `--lyrics-file` | Lyrics 原文或歌词文件（UTF-8）。两个都不给会报错 |
| `--tag` | 结果文件名前缀，默认 `song_日期_时间` |
| `--out-dir` | 本地保存目录，默认 `fxai-workflow/output` |
| `--via` | `download`（**默认，走 HTTP 接口下载**）/ `auto`（先接口、失败才回退本地成品）/ `copy`（只按 `--copy-from` 找本地成品，找不到直接报错） |
| `--copy-from` | 仅 copy/auto 回退用：本地成品候选根目录，逗号分隔；也可用 `YUE2_COPY_FROM`。填挂载盘上的成品目录（ComfyUI 产出目录由服务端管理，客户端不读它） |
| `--seed` | 随机种子；`0`/负数=随机。**同 seed + 同 Style + 同 Lyrics 可复现同一首歌** |
| `--mode` | `full`（默认）/ `melody` / `off`，只影响生成策略与结果描述 |
| `--max-duration` | 期望最大时长（秒），仅作结果描述里的截断判断依据 |
| `--wf` | 换用自定义工作流文件名（在 fxai-workflow 内），默认 `music-yue2.json` |
| `--extra-params` | 自定义工作流里的额外占位符 JSON，如 `'{"fxai_maxduration":120}'` |
| `--timeout` | 等 ComfyUI 出结果的最长秒数，默认 3600 |

产出：一个 `.wav`（本地 `--out-dir`），stdout 打一行 `RESULT {...}` JSON，含
`wav / remote / via / seed / duration / sections`。
拿到产物还会做一次完整性校验（RIFF/WAVE 头 + 体积下限），坏文件当场报错重跑，不带病往下走。

### 工作流侧的硬约束（改代码前先看）

内置 `music-yue2.json` 只留了三个占位符：`fxai_prompt`（Style）、`fxai_lyrics`（歌词）、`fxai_seed`。
- Style / 歌词经 node53、node54 同时链接进 node42（ABC 规划）与 node45（成曲）；
- **node45 的 `max_duration` 锁死 360s**，想改时长必须换自带该占位符的工作流（`--wf` + `--extra-params`）；
- node50 的 `seconds` 保持对 node45 的输出链接；写死静态值会出声即断。
