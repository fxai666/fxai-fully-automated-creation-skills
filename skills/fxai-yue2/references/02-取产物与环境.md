# 取产物路径、前置条件、仙宫云环境与常见故障处置

**何时读**：产物取不回来、远端 ComfyUI 环境、或报错排查时

`--via download`（**默认**）：脚本拿到 ComfyUI `/fxai/tasks/result` 返回的 url 令牌，去 `GET /fxai/down/file?url=<令牌>`
把 wav 下到本地。**全程 HTTP，不碰 ComfyUI 的任何本地目录。**

> 这是硬性契约：任何「默认从本机磁盘找产物」的写法，在远端 ComfyUI 上一定取不到。
> 生图、场景图、四视图、MV 走的都是同一条路径（`image_gen.py / scene_gen.py / fourview_gen.py / mv_pipeline.py`
> 全部是 `C._download(url, dst)`），音乐这条也一样。
> 同理：**确认参考图/资源是否存在也只走接口**，本机磁盘扫不出服务端资源——任务被服务端 `queued` 即证明服务端已读到参考图。

`--via copy` / `auto` 只是**本地快路径**，必须显式给 `--copy-from`；脚本不会自动去猜
`COMFY_OUTPUT`、`output` 之类的目录。copy 命中时同样遵守三条铁律：
① 目标已存在就换名，已有文件一律保留；② **ComfyUI 侧的源文件保持原样**（随时可再取，删了只能重跑几分钟）；
③ 复制后比对字节数，不一致视为复制不完整，判失败。

`--via copy` 在候选目录里找不到本次新产物时会**直接报错退出**，不会静默改成下载——
否则你会以为走的是快路径，实际走了下载。

```bash
# 通用写法（换机器也成立）
python gen_song.py --style-file s.md --lyrics-file l.md --tag 歌名
# 已确认产物在挂载盘上，想省一次下载（--copy-from 换成你自己那台机器上的目录）
python gen_song.py --style-file s.md --lyrics-file l.md --via copy --copy-from <你的音乐产物目录>
```

## 前置条件

- ComfyUI 已启动且模型 `yue2_3b_bf16.safetensors` 就位（脚本会先探测服务，未启动会提示等待）；
- ComfyUI 装了 `fxai-toolkit` 自定义节点（提供 `YuE2GenerateABC`/`YuE2GenerateMusic`/`FxAiAudioManager`）。

#### 指向仙宫云（远端 ComfyUI）

- `comfy_url` 用官方公式 `http://<容器ID>-<端口号>.container.x-gpu.com`（**端口写在主机名里，不是 `:8188` 后缀**），
  地址由 `xgy_api.py comfy-url <实例id>` 直接取，别自己拼。
- 本机有代理时，跑之前 `export NO_PROXY=".x-gpu.com,127.0.0.1,localhost"`。
- `music-yue2.json` 的 11 类节点（`CheckpointLoaderSimple`/`YuE2GenerateABC`/`YuE2GenerateMusic`/
  `EmptyYuE2LatentAudio`/`VAEDecodeAudio`/`ConditioningZeroOut`/`KSampler`/`SeedNode`/
  `PrimitiveStringMultiline`×2/`FxAiAudioManager`/`FxAiCleanGpu`）**在仙宫云上已全部注册**，模型
  `/root/ComfyUI/models/checkpoints/yue2_3b_bf16.safetensors` 也在位，**无需额外安装**。
- ⚠️ 提前确认 fxai-toolkit 没有 `IMPORT FAILED`（典型是缺 `soundfile` 依赖），
  `YuE2*` 节点全都不会注册。用 `/object_info` 查 `YuE2GenerateMusic` 是否存在即可确认；
  补法：`/root/miniconda3/envs/comfyui/bin/python -m pip install soundfile` 后重启 ComfyUI。
- 产物名在远端是 `音乐生成/000_audio.wav`，客户端走 `/fxai/tasks/result` + `/fxai/down/file?url=<令牌>` 下载，全程 HTTP。

### 常见故障

| 现象 | 原因与处理 |
|---|---|
| 提交被拒 / 一直排队 | ComfyUI 显存被占（比如另一条 MV 还在跑），等它结束或 `/free` 释放 |
| 出声但立刻断 | node50 的 `seconds` 链接被改坏，恢复工作流默认值 |
| 时长远超预期 | node45 的 `max_duration` 被改，恢复 360 或用自定义工作流占位符 |
| 中文描述要写但拿不到时长 | 脚本自己读 wav 头算 `duration`，不会依赖外部解码器 |
