# 库结构与检索

## 一、目录长什么样

```
<库根>/                          取全局配置 asset_library.root
├── 素材库看板.html               lib.py html 生成，带缩略图 / 搜索 / 筛选 / 点击播放
├── 素材总清单.md / .json         跨项目索引（由 fxai-asset-registry 的 catalog 生成）
├── 分册/<主题>.md                按主题分的索引
└── _库/                          ← 本技能的地盘
    ├── README.md                库里自带的规矩
    ├── 库内清单.json            机读台账（唯一真相源）
    ├── 库内清单.md              渲染产物，别手改
    ├── .thumbs/<编号>.jpg       缩略图（自动生成，可随时重生成）
    ├── 录屏/  演示/  对比/  口播/
    ├── 实拍/  配乐/  版式/  图/  其它/
```

**为什么按形态分目录，不按文件类型**：做片子时脑子里想的是「我要一段别人操作软件的画面」，
不是「我要一个 mp4」。按形态分，翻目录就等于翻剪片思路。

## 二、形态归属怎么定

| 形态 | 放什么 | 例子 |
|---|---|---|
| `录屏` | 软件/网页操作过程 | 仙宫云开实例、ComfyUI 跑工作流、剪映操作 |
| `演示` | 效果本身，证明「能做出这个」 | 换人后单条镜头、成片节选、动作演示 |
| `对比` | 前后并排 | 原片 vs 换人、低清 vs 超分 |
| `口播` | 数字人说话原片 | 片头开场、讲解段 |
| `实拍` | 真实拍摄素材 | 空镜、手部特写 |
| `配乐` | BGM / 音效 | 通用紧张感铺垫、转场音 |
| `版式` | 片头卡 / 片尾卡 / 过渡卡 / 信息贴片 | 栏目片头、三步卡 |
| `图` | 静态图 | 场景图、角色四视图、封面底图 |
| `其它` | 没想清楚的先扔这 | —— |

判据仍有两条，按顺序问：
1. 它是不是「别人看到画面就明白在干什么」的过程 → `录屏`
2. 它是不是「画面本身即结果」 → `演示` / `对比`

**一段素材别拆成两条**。同一段既有操作又有结果，选主用途，另一面写进 `--desc`。

## 三、台账字段

| 字段 | 谁写 | 说明 |
|---|---|---|
| `编号` | 自动 | `<主题>-<三位>`，如 `仙宫云-001`；口头指代用 |
| `文件` | 自动 | 相对 `_库/` 的路径，如 `录屏/仙宫云_xxx_787f.mp4` |
| `原名` | 自动 | 入库前叫什么（溯源用） |
| `类型` | 自动 | 视频 / 图 / 音频 |
| `形态` | `--form` | 上面的八个分类 |
| `分类` | `--theme` | 主题 = 分册名 |
| `规格` | 自动 | `1024x960 · 24fps · 787帧 · 32.83s`，ffprobe 探 |
| `大小` / `大小字节` | 自动 | 字节数用于体检发现被替换 |
| `用途` | `--desc` | **必须有**，检索主要靠它 |
| `标签` | `--tags` | 首词=分册；后面是检索词 |
| `来源` | `--from` | 哪来的：录的 / 技能包迁出 / 客户给的 |
| `md5_1m` | 自动 | 首 1MB 哈希，用于查重复 |
| `入库` | 自动 | 时间戳 |

## 四、检索怎么打分

`find` 把关键词拆开，逐条比对，命中就加分：

| 命中位置 | 加分 |
|---|---|
| 文件名 / 原名 | +8 |
| 主题 | +6 |
| 标签（完全等于） | +6 |
| 形态 | +4 |
| 用途 | +3 |
| 标签（包含） | +2 |
| 来源 | +1 |

所有关键词都要至少命中一处才算候选（AND），按总分降序。`--limit N` 只留前 N。

**命中不了时的排查顺序**：
1. 词拆得太长 → 换短词（`仙宫云` 而不是 `仙宫云的实例部署录屏`）
2. 那一条压根没写用途 → `lib.py ls` 找出来补 `--desc`
3. 标签太抽象 → `lib.py set <编号> --add-tags "搜的时候会想起来的词"`
4. 真的没有 → 去项目台账找，找到再入库

## 五、体检项与处理

`lib.py check` 报五类：

| 现象 | 含义 | 处理 |
|---|---|---|
| 失联 | 台账有、磁盘没有 | 找回来放回原路径，或 `rm --yes` 清条目 |
| 大小变化 | 文件被替换过（重导出/重压制） | 跑 `add` 同路径重新登记规格，或确认后不管 |
| 缺用途 | 检索不到它 | 立刻 `set --desc` |
| 缺标签 | 只能靠文件名找到 | `set --add-tags` |
| 缺缩略图 | 看板没图 | `lib.py thumbs` |
| 疑似重复 | 首 1MB 相同 | 人工判断留哪个，`rm --yes` 清另一个（默认保留文件） |

## 六、多库

一个库 = 一个 `根`。什么情况会需要多个：

- 快盘放常用、慢盘放归档 → `主素材库` + `归档库`
- 不同客户素材隔离 → `客户A库` + `客户B库`
- 移动硬盘带出去 → `移动盘库`，`--use 移动盘库` 切换

**编号在库内唯一，跨库可能重号**。跨库引用时写完整：`主素材库/仙宫云-001`。

## 七、和另外两个技能/文件的边界

| 想做什么 | 用哪个 |
|---|---|
| 这条片子用了哪些素材 | `fxai-asset-registry` 的 `sync` |
| 跨项目「谁还有仙宫云素材」 | `registry.py index <项目空间根>` |
| 库里有什么、怎么找到 | **本技能** |
| 把一段好东西收进库 | **本技能** `add`（等价于旧的 `registry.py promote`） |
| 改技能渲染用的字体、框架层、片头配音 | 改技能包 `assets/`，**不归本技能** |
