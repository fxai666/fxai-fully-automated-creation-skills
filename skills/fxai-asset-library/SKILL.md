# 应用级素材库管家

一个**独立于项目、独立于技能包**的素材库。库里只放一类东西：**能被另一条片子直接拿去剪的片段**。

## 先说清三层，别串层

| 层 | 位置 | 内容 | 谁管 |
|---|---|---|---|
| 系统级（技能级） | `~/.workbuddy/skills/<技能>/assets/` | 字体、品牌图、框架层、标签、底纹、片头配音、部署清单 json、提示词模板 | 技能自己维护，**本技能不碰** |
| **应用级（素材库）** | `<库根>/_库/<形态>/` | 录屏、演示、对比、口播、实拍、配乐、版式卡、图 | **本技能** |
| 项目台账 | 各项目目录 `素材登记.json` | 这条片子用过什么 | `fxai-asset-registry` |

判据一句话：**这段东西能不能被另一条片子直接拿去剪？** 能 → 应用级入库；不能（只在某个技能里当零件）→ 留技能包。

## 本技能文件清单（先读这里，再决定读哪册）

| 文件 | 什么时候读 |
|---|---|
| `scripts/lib.py` | 台账与命令入口；要加字段、改展示逻辑时才读 |
| `scripts/idx.py` | 检索引擎（SQLite 倒排）；只有要调检索、改索引结构时才读 |
| `references/01-库结构与检索.md` | 定库地址、定形态归属、写用途话术、检索命中不了时 |
| `references/02-索引与性能.md` | 库大了（过千条）、检索变慢、要重建索引、想调权重时 |
| `<库根>/_库/README.md` | 库里自带的规矩说明（入库时顺手同步） |

**确定本次要做什么之后，只读对应的那一册。**

## 十二条命令

```bash
S=~/.workbuddy/skills/fxai-asset-library/scripts

python $S/lib.py roots                              # ① 看配了哪些库、各多少条
python $S/lib.py add <文件> --theme 主题 --form 形态 --name 内容 --desc "..." --tags "a,b"   # ② 入库
python $S/lib.py find 关键词 [关键词...]              # ③ 检索（最常用）
python $S/lib.py info <编号|片段>                     # ④ 看详情 + 被哪些项目引用
python $S/lib.py ls [--form 录屏] [--theme 仙宫云]    # ⑤ 按形态/主题列
python $S/lib.py set <编号> --desc/--tags/--theme      # ⑥ 改详情
python $S/lib.py rm <编号> [--file] --yes             # ⑦ 从台账移除（默认保留文件）
python $S/lib.py check                              # ⑧ 体检：失联/大小变/缺详情/缺缩略图/重复
python $S/lib.py thumbs                             # ⑨ 生成缩略图
python $S/lib.py html                               # ⑩ 出可预览看板（带搜索+筛选+点击播放）
python $S/lib.py reindex                            # ⑪ 重建检索索引（批量导入后跑一次）
python $S/lib.py stats                              # ⑫ 看库与索引规模
```

`find` 默认只回 30 条，`--limit 0` 给全部；`--scan` 是不走索引的内存扫描（排查用）。

## 库地址可配置

配置在 `~/.workbuddy/fxai_asset_library.json`（首次跑任何命令自动生成）：

```json
{
  "默认库": "主素材库",
  "库": [
    { "名称": "主素材库", "根": "<素材库根，取全局配置 asset_library.root>", "形态目录": ["录屏","演示","对比","口播","实拍","配乐","版式","图","其它"] }
  ],
  "缩略图宽": 480,
  "项目台账扫描根": "<项目空间根，取全局配置 projects.root>"
}
```

- **加一个库**：往 `库` 数组加一条 `{名称, 根}`，`根` 下会自动建 `_库/<形态>/`。
- **切默认库**：改 `默认库`；临时切用 `--use 库名`，直接指路径用 `--lib D:/别的库`。
- **环境变量**：`FXAI_ASSET_LIB=<路径>` 优先级高于配置文件（CI / 换机临时用）。

## 入库规矩

**命名**：`<主题>_<内容>_<规格>.<ext>`，由 `add` 自动拼，**不带版本号**（换版本直接覆盖同名）。
例：`仙宫云_镜像广场开实例四步实操_1024x960_787f.mp4`

**主题**（`--theme`）= 分册名 = 编号前缀，选「以后按什么找它」：`仙宫云` / `角色替换` / `短剧` / `成片`。

**形态**（`--form`）：`录屏 演示 对比 口播 实拍 配乐 版式 图 其它`

**用途**（`--desc`）写公式：**画面内容 + 关键识别信息 + 剪辑注意**。
> ✅ 「仙宫云镜像广场开一台实例全流程：①打开部署页 ②检索凤希AI ③选 ComfyUI 全自动全家桶 ④点使用该镜像部署再选 24G 4090。带宣传画框，剪教程需裁掉只取网站区」
> ❌ 「仙宫云素材」

没写 `--desc` 的条目**检索不到**，`add` 会直接警告。

## 检索为什么快

`find` 走的是 **SQLite 倒排索引**（`_库/.index/lib.db`），不是每次去翻台账：

- **中文切分**：CJK 段出「整串 + 全部二元组」，所以「录屏」「开实例」这种 1~2 字词也能命中，
  长句里的片段也能命中（`仙宫云镜像广场` 会被 `仙宫/宫云` 打到）。
- **字段加权**：编号 12 / 文件名 8 / 主题 6 / 标签 6 / 形态 4 / 用途 3 / 规格 2 / 来源 1，同一个词取最高那档。
- **两层检索**：先只碰高权重字段（权重 ≥4），命中够了就返回；不够再带上「用途/来源」的长文本。
  绝大多数查询第一层就结束，既快又不漏。
- **自动增量**：`add` / `set` / `rm` 立刻更新索引；台账被外部改过（手改 json、批量导入）时，
  下次 `find` 发现账本指纹变了会自动重建，不用你管。

实测（单机 NVMe，都是纯检索耗时，不含进程启动）：

| 规模 | 索引检索 | 逐个扫描 | 提速 |
|---|---|---|---|
| 5 000 条 | 1.4 – 3.0 ms | 7.4 – 11.6 ms | 4–5× |
| 20 000 条 | 2.1 – 5.3 ms | 29 – 46 ms | 9–14× |
| 引用反查（谁用过这条） | 1.1 – 1.8 ms | 115 ms | ~100× |

索引本身：5 000 条约 2.2 秒建完，20 000 条约 13 秒（一次性，之后只做增量）。
细节与调参见 `references/02-索引与性能.md`。

## 快速定位的三条路

1. **按词找** → `lib.py find 仙宫云 开实例`（对 编号/文件名/主题/形态/标签/用途/来源 加权打分）
2. **按形态翻** → `lib.py ls --form 录屏`
3. **看板里翻着选** → `lib.py html` 出 `素材库看板.html`，卡片带缩略图，点开直接播

## 项目怎么引用库内素材

项目台账条目不复制文件，只挂编号：

```json
{ "文件": "素材/录屏/01_xxx.mp4", "库内": "仙宫云-001", "仅库内": true }
```

`fxai-asset-registry` 的 `sync` 见到 `仅库内` 会跳过、不报失联；`lib.py info 仙宫云-001` 能反查出「哪些项目引用了它」。

## 技能怎么引用库内素材

脚本里不要写死路径，写成「先查 `_库`、回落 `assets/`」：

```python
import global_config as gc            # fxai-common
LIB = Path(os.environ.get("FXAI_ASSET_LIB") or (gc.asset_library_root() + "/_库"))
def seg(name):  # 库里有就用库里的，没有回落到技能自带
    hit = next(LIB.rglob(f"*{name}"), None) or (ASSETS / "segments" / name)
    return hit
```

## 铁律

- **同一段素材只存一份**，就在库里。项目里不留副本，技能包里不留副本。
- **不删源文件**：`rm` 默认只删台账条目，加 `--file` 才删文件；删之前必须跟用户确认。
- **不搬技能包 assets**：那是系统级零件，搬了技能就坏。
- **不改文件名**：库里文件改名要连台账、引用一起改；`set --move-file` 只在形态变更时用。
