# 05 · 发布物料与发布单

> **何时读**：拟标题 / 简介 / 标签、定封面、勾 AI 声明、选分类、出发布单时。

## 一、唯一输入：项目目录里的最终成片

发布只从**被发布项目的目录**读成片，路径由用户当次给出，技能包与配置里不写死。不从实例目录的媒体目录取，不重新剪辑、不转码、不改名。成片规格用 `ffprobe` 读取后写进发布单：编码、分辨率、帧率、时长、大小、横竖屏。

物料（封面 / 标题 / 简介 / 标签 / 字幕）由发布能力按规划生成，产物落在**项目目录**。项目侧用 `templates/发布材料清单.md` 做资产台账，逐站文案与物料状态都记在它里面；发布单只作审批票据，引用它而不复制正文。归属总纲见 02 册。

## 二、逐项口径

| 物料 | 做法 | 禁用 |
|---|---|---|
| 标题 | 按项目主题拟主标题与备用标题；控制站点字数上限 | 占位词当真标题 |
| 简介 | 说明内容 + AI 生成显式标识 + 话题；逐站差异化 | 虚构事实、冒用他人名义、一字不差群发 |
| 标签 | 3–6 个贴合内容的标签，按站点习惯调整；站点有数量上限时按上限裁，公共标签整组保住 | 堆无关热词；超上限硬塞 |
| 封面 | 先看站点是否自动截帧；自动截帧可能命中黑场或糊帧时，从成片挑清晰帧或做设计封面 | 随手出图；设计封面须走 `fxai-poster` 并跑 `qc.py pre\|prompt\|post` 门禁 |
| AI 声明 | 页面有声明入口就勾选；任务一律带 AI 标记；与原创声明互斥时**优先 AI 生成** | 把勾选平台选项当成合规完成 |
| 原创声明 | 按实际沿用比例判断，全场景替换可选原创；平台默认加上的原创标签保留；与 AI 声明互斥时让位给 AI | 把原创改成转载；摘掉平台默认原创标签；为保原创丢掉 AI 声明；以原创为由跳过素材授权核查 |
| 分类 / 专辑 | 先看真实下拉项里是否已有目标选项 | 新建专辑、把项目类别当成站点分区、误选近似项 |
| 定时 | 多站点错峰，拉开间隔 | 同一时刻全量群发 |

**公共文案块**：所有站点、所有作品共用的固定信息（资料下载地址、固定话题、品牌行）不写进每条任务，统一放实例目录顶层 `公共/公共文案块.json`——`descr_footer` 追加到每条简介末尾，`tags` 合并进标签列表并去重。改内容只改这一个文件，不动任务、不动代码。站点对外链限流时，对该站置 `common_block: false`，只保留标签。页脚属作品描述，不进标题、不进 AI 声明、不进发布单的合规项。

## 三、「其他」的三层歧义

1. **项目类别**：项目管理里的分类，与站点无关。
2. **站点分区**：投稿必填的内容分区，各站点术语不同。
3. **站点合集 / 专辑**：用户口语里「放到其他专辑」多半指这一层。

未登录看到真实下拉项之前，发布单里只能写「待确认：目标站点是否存在该合集 / 专辑选项」，不得替用户拍板。

## 四、AI 生成合成内容标识

《人工智能生成合成内容标识办法》自 2025-09-01 施行：

- **显式标识**：画面 / 文案里可感知，平台声明入口只是其中一环。
- **隐式标识**：文件元数据里含生成合成信息。未落地实现时列为发布单的待办风险，不得宣称合规完成。
- 任务一律带 AI 标记；声明入口找不到时日志告警，需人工确认合规口径。

## 五、发布单闸门

**任何真实发布前**，按 `templates/发布单.md` 生成一份文件，放实例目录 `发布单/` 下，文件名带日期与项目名，状态标「待确认」。内容至少包含：

1. 成片路径与规格；
2. 目标站点清单 + 每个站点使用的账号 + 登录态；
3. 逐站的标题、简介、标签、封面策略、AI 声明、**原创声明**、分类 / 专辑处理、**素材来源与授权核查结果**；
4. 未完成项与风险（字段未校准、隐式标识未做、分辨率偏低等）；
5. **授权模式行**：`- 授权模式：publish`（直接发布）或 `- 授权模式：draft`（只存草稿）。执行器读这一行决定默认动作，写 `publish` 才直接发，写 `draft` 时自动降级为存草稿，缺这一行直接拒绝执行；
6. 明确的确认方式：用户回复确认后，才允许建任务与执行。

**发布单必列素材授权核查项**：原创声明按成片实际沿用比例判断，素材来源与授权凭证一律保留，逐项记入随包《字体与素材授权台账.md》；未核清的写进风险栏，不得以「按原创声明」为由跳过（见 07 册第九节）。

发布单本身不是发布任务，不写任务队列，不上传，不改项目清单。

## 六、站点未打通时的诚实口径

站点条目存在只代表配置就位，不代表通道可用。发布单须逐站如实标注登录态、probe 结果、表单校准状态；未打通的写「通道待打通」，不得写成「可一键全站发布」。两阶段投稿页的站点，上传后表单字段须经带媒体 probe 校准后才能进入正式任务，该动作属外发，须单独授权。

## 七、确认后的执行入口

逐阶段命令、授权边界、状态对照与中断回滚见 `references/08-确认后执行SOP.md`，本册不重复。
