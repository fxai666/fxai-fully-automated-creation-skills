# 模块函数清单与外部依赖

**何时读**：查某个函数在哪个文件、或这个件依赖哪些工作流时

- `audio_video.py`：`gen_video` / `gen_videos` / `build_ref2va_prompt` / `build_fl2va_prompt` /
  `fl2va_body` / `build_multiref_lines` / `build_multiline_prompt` / `h3_segments` /
  `h3_segment_count` / `h3_actual_seconds` / `audio_duration` / `max_edge` / `concat_videos` /
  `probe_duration`。
- `concat_videos(paths, dst, tone=None)`：拼段。`tone=True` 先做影调/接缝对齐
  （调 `fxai-common/video_tone.py` 的 `align()`），`tone` 传 dict 可细调，默认不做。
- 依赖 `fxai-workflow/comfy_client.py`、`fxai-workflow/mv-minimax-{single,multi,multiref}.json`。
