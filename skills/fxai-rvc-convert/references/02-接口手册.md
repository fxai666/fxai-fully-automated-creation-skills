| 资源 | 地址 |

删整库＝连库里的文件一起删（不可恢复）。要保留其中一部分，先用
`POST /api/train/sets/<id>/move` 挪到别的库，再删这个空库。
返回 `freed_mb` 为实际释放容量；`shared_mb` / `shared_count` 是仍被
`train/<job_id>/raw/` 硬链接引用的部分，要等中间文件清理才真正释放。

`POST /api/prefs` 只传要改的字段，服务端按白名单**增量合并**（`convert` 下有
`voice` / `pitch` / `index_rate` / `protect` / `volume_envelope` / `inst_gain` /
`f0_method` / `vocal_only` / `save`）。类型不对的值直接忽略、超范围夹取，
文件坏了回落到默认值（`index_rate=1`）。**偏好存在服务端**，换浏览器、换机器
连同一个服务都生效 —— 这是它不写 localStorage 的原因。

## 提交字段

`POST /api/convert` 的 multipart 字段。越界值由服务端夹取，不报错：

| 字段 | 默认 | 范围 / 取值 |
|---|---|---|
| `file` | — | 音频或视频，单文件 ≤200MB。与 `asset_id` **二选一**，服务端收下后顺手入库 |
| `asset_id` | — | 素材库条目 id（`uYYYYMMDD-HHMMxxxx`），与 `file` **二选一**；重复翻唱同一首用它，不重复上传。两个都给时以本字段为准 |
| `voice` | — | 音色 id 或中文显示名 |
| `pitch` | `0` | `-24..24` 半音 |
| `index_rate` | `1` | `0..1`；默认 `1`＝音色最像，嫌发闷再降；无 `.index` 时引擎按 0 处理 |
| `protect` | `0.33` | `0..0.5` |
| `volume_envelope` | `0.25` | `0..1` |
| `f0_method` | `rmvpe` | `rmvpe` / `fcpe` |
| `sep_backend` | 配置值 | `melband` / `skill`；不认识的值回落默认 |
| `inst_gain` | `0` | `-24..24` dB |
| `vocal_only` | `0` | `1` = 跳过分离 |
| `save` | `1` | `0` = 不进作品库，留 12 小时 |

布尔字段认 `1 / true / yes / on`。`POST /api/train`：`name` 必填，`epochs` 250（**可填 20~600，越界由服务端夹取**）、`batch` 8、`sr` 40000，素材项可多个、字段名不限。

**素材必须先归库**，两种提交方式二选一，都不给就 400：

| 方式 | 字段 | 行为 |
|---|---|---|
| 用已有库 | `set_id=<素材库id>` | 素材从 `train_sets/<id>/` 硬链接进 `train/<job_id>/raw/`，反复训练不重复占盘 |
| 传新文件 | 文件 + `set_name`（+ `set_owner`） | 服务端先建库再开训；`set_name` 不传则用音色名，重名返回 409 |

`set_id` 与素材文件同时给时以 `set_id` 为准。训练建好后服务端往该库的 `trainings`
里记一条（`job_id` / `voice` / `epochs` / `at`），下次查 `set-detail` 就知道这套素材用什么参数练过。

建库 / 移动 / 删素材的 JSON 体：

```json
POST /api/train/sets/new      {"name": "小北-普通话", "owner": "小北", "note": ""}
POST /api/train/sets/<id>/move   {"to": "s20261026-1236wwho", "items": [0, 2, 3]}
POST /api/train/sets/<id>/remove {"items": [1]}
```

`items` 是 `set-detail` 里 `files[].i` 的序号（0 起算）；页面上显示 1 起算，
命令行 `set-move --items 1,3` 收的也是 1 起算，客户端会自己减 1。
`move` 返回 `{moved, skipped, from, to}`：目标库已有同内容（sha1 相同）的文件会被跳过、
留在原库，计入 `skipped`。

## 任务对象

| 字段 | 判读 |
|---|---|
| `status` | `queued` / `running` / `done` / `error` / `canceled` |
| `stage` | `queued` / `loading` / `separate` / `convert` / `mix` / 终态 |
| `stage_text` | 中文阶段说明，直接上屏 |
| `progress` | `0..100`；锚点 3 准备、6→44 分离、45 转换、82 混音、100 完成 |
| `params` | 实际生效参数（已夹取，`voice` 已统一为 ASCII id） |
| `sep` | 实际分离后端：`melband` / `skill` / `skip` |
| `result_url` | 成品相对地址，未完成时为空串 |
| `source_url` | 原曲相对地址 |
| `elapsed` / `duration` | 耗时 / 原曲时长（秒） |
| `saved` | 是否进作品库 |

状态机 `queued → running → done | error | canceled`。取消只置标志，当前阶段收尾时才中断，响应给 `canceling`。

## 错误对照

失败包络 `{"success": false, "ok": false, "error": "<中文原因>"}`，按前缀匹配：

| 原文前缀 | 码 | 处置 |
|---|---|---|
| `没收到音频文件（字段名 file）` | 400 | 字段名必须是 `file` |
| `没有选择音色` | 400 | 补 `voice` |
| `音色不存在：` | 404 | `voices` 取 id 重提 |
| `不支持的格式：` | 415 | 转 wav / mp3 |
| `文件太大（上限 200MB）` | 413 | 压缩或切片 |
| `任务不存在：` / `成果不存在` | 404 | 刷新列表或等终态 |
| `正在转换中，等这一轮结束再卸载` | 409 | 等终态 |
| `正在转换中，等这一轮结束再开训练` | 409 | 等终态 |
| `加载失败：` | 500 | 看 `<项目>/logs/web.log` |

## 直接发请求

```bash
curl -s http://127.0.0.1:8187/health
curl -s http://127.0.0.1:8187/api/voices
curl -s -X POST http://127.0.0.1:8187/api/convert -F "file=@<音频>" -F "voice=<音色id>" -F "pitch=0"

# 引用素材库里已上传过的原曲：只给 asset_id，请求体无文件字段
curl -s http://127.0.0.1:8187/api/assets
curl -s -X POST http://127.0.0.1:8187/api/convert -F "asset_id=<素材id>" -F "voice=<音色id>"

curl -s http://127.0.0.1:8187/api/job/<job_id>
curl -s -o <成品>.wav "http://127.0.0.1:8187/api/jobs/<job_id>/file/<成品名>?dl=1"
```

库调用直接 import `scripts/rvc_client.py`：`health()` / `voices()` / `convert()` / `job()` /
`jobs()` / `download()` / `train()` / `wait_job()`，地址解析、multipart、超时都由它处理。
