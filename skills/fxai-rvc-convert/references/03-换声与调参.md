# 03 · 换声与调参

> **何时读**：选参数、调听感、判断该不该跳过分离、决定成品加不加伴奏时。

## 链路

```
原曲 ──①分离──▶ 人声干声 ──②换声──▶ 新音色人声
        └──伴奏原轨──────────────────▶ ③等响混音 ──▶ 成品 WAV
```

②逐帧沿用原唱的 F0 与时长，只换音色；③回贴①分离出的伴奏原轨，不做时间伸缩，时间轴天然对齐。
成品规格固定 48kHz 立体声。

## 参数判据

| 参数 | 默认 | 调它解决什么 | 调法 |
|---|---|---|---|
| `pitch` | `0` | 音高不匹配（男声模型唱女声原曲或反之） | 跨性别 ±12；±5~7 更自然；范围 `-24..24` |
| `index_rate` | `1` | 听感「不像」目标音色 | 默认 `1`＝音色最像（首要目标）；音色发闷或机械感上来时回退到 `0.7~0.9`，仍嫌闷再往 `0.5` 走。无 `.index` 时引擎按 0 处理 |
| `protect` | `0.33` | 咬字糊、辅音被吃掉 | 上调到 `0.4~0.5`；齿音过重则回到 `0.25` |
| `volume_envelope` | `0.25` | 强弱起伏跟着原唱跑太死 | 往上到 `0.4~0.5` 保留更多动态；`0` 完全贴原唱强弱 |
| `f0_method` | `rmvpe` | 音高线抖、跑调感 | 人声干净时换 `fcpe` 更稳；`rmvpe` 在混响重的素材上更耐用 |
| `inst_gain` | `0` | 伴奏压过人声或太小 | 人声偏小时 `+1~+3`；伴奏抢戏时负值 |
| `sep_backend` | `melband` | 分离质量 / 是否依赖外部服务 | 默认内置 `melband`，离线可跑；`skill` 需外部 ComfyUI 在线 |
| `vocal_only` | `0` | 传的已是干声，再分离会削掉气息 | 干声素材置 `1`，跳过①，整条链路快一半 |

## 常见场景取值

| 场景 | 关键取值 |
|---|---|
| 同性别翻唱 | `pitch=0`、`index_rate=1`（默认）、`protect=0.33` |
| 跨性别 | `pitch=±12`，先试 `±12` 再微调 `±5~7` |
| 说话 / 口播素材 | `index_rate=1`（保持最像），`volume_envelope` 降到 `0.1`；若发闷降到 `0.7` |
| 说唱 / 快节奏 | `protect=0.4`，`f0_method=fcpe` |
| 已有干净干声 | `vocal_only=1`，`index_rate` 按需，成品只有人声 |
| 成品不满意，一键调一版 | 页面「更清晰」= `index_rate=0.8` + `protect=0.45`；「更像本人」= `index_rate=1` + `protect=0.33`。两版都留在列表里，A/B 听完再挑一版存 |
| 怎么判断像不像 | 工作台和作品库的成品卡都有「成品 / 原曲」A/B：共用一个播放器，切换时从同一秒接着放。逐句对比是唯一靠谱的验收方式，别靠回忆 |
| 只要人声轨 | `vocal_only=1` + `--vocal-only`；成品即干声 |
| 素材是视频 | 直接上传，服务端抽音轨；`file` 支持 `.mp4 .mov .mkv .avi .webm` |
| 想给 MV 用分离好的伴奏 | `sep_backend=melband` 跑一次，取 `source` 与成品两条轨 |

## 分离后端

| 值 | 判据 |
|---|---|
| `melband`（默认） | 内置 Mel-Band RoFormer，进程内推理、离线、质量最好。部署与交付一律用它 |
| `skill` | 走 `fxai-vocal-separate` 的外部 ComfyUI；`comfy.up=false` 时该后端直接失败 |

`health` 的 `separator.ready=false` 表示分离模型未就绪：查 `models/separator/` 下的
`.safetensors` 是否存在、文件名是否与 `rvc.sep_model` 一致、结构参数是否与 `MODEL_CONFIG` 匹配。

## 混音规则

- 转换人声先按 RMS 拉到原唱电平（限幅 ±12dB），再叠伴奏，最后 `alimiter` 防爆音。
- 伴奏不重建、不重采样、不时间伸缩，直接用①的伴奏原轨。
- 想改伴奏比例就调 `inst_gain`，不重跑①②：成品已在作品库时重新提交一次全流程更快。

## 耗时参考（RTX 5060 Ti，3 分 08 秒歌曲）

| 环节 | 耗时 |
|---|---|
| 模型装载（进程内首次） | 约 2s |
| 分离 | 约 40s |
| 分离 + 换声 + 混音 | 约 46s |

等待上限按 `rvc.timeout`（900s）给；首次跑要加上装载时间。

## 音色命名

| 位置 | 规则 |
|---|---|
| 磁盘文件名 | 必须 ASCII（`voice_MMDD_HHMM.pth`）。faiss 在 Windows 下打不开中文索引路径 |
| 显示名 | 存 `models/voices/_meta.json` 的 `name` 字段，可为中文 |
| 提交任务 | 用 `id` 或显示名都行，服务端统一解析成 ASCII id |

外部音色直接放 `.pth`（同名 `.index` 一起放）进 `models/voices/`，再在 `_meta.json` 里登记中文名。
