# 常用内联 SVG 图标库（feather 风格，24×24）

用法：复制 `<svg>` 片段，颜色由父元素 CSS `color` 控制（`stroke="currentColor"`）。
卡片图标建议尺寸 26px，汇总条图标 24px，中央大图标 70~80px。

公共属性（每个 svg 标签都带）：
`viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"`
