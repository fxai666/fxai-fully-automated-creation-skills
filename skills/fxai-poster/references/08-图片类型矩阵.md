# 08 · 图片类型矩阵（全场景）

一张图先归到某个类型，类型定了尺寸、必备要素和质检重点，后面每一步都按类型走。
机器校验的尺寸与字数上限以 `qc.py` 的 `TYPES` 为准，本册给**人读的要素清单**。

## 主表

| key | 用途 | 尺寸 | 默认模式 | 必备要素 | 质检重点 |
|---|---|---|---|---|---|
| `record_cover` | 录屏 / 教程视频封面 | 1680×1054 | hybrid | 主标两层 · 教程徽章 · 吸睛元素 ≥2 · 主体 | 缩略图可读、字不压脸 |
| `video_cover` | 抖音 / 视频号 / 快手封面 | 768×1280 | hybrid | 主标两层 · 角标 · 主体 · 上下安全区 | 缩略图可读、安全区 |
| `video_cover_h` | B 站 / YouTube 封面 | 1280×768 | hybrid | 主标两层 · 角标 · 主体 | 与标题一致、缩略图可读 |
| `poster` | 活动 / 课程 / 品牌 / 招聘海报 | 1080×1440 | hybrid | 主标 · 副标 · 时间地点或行动指令 · 主体 | 信息完整、层级清楚 |

`ecom_detail` / `infographic` 这类长图，高度按内容实测，出图后先 `qc.py fit` 裁白再质检。

`video_overlay` 尺寸随成片走，其他类型换平台时按平台规格改，画幅比例不变就不用重排。

### 类型决定「用哪把尺子」，分辨率不影响

质检锐度分三档挂在类型上（`qc.py` 的 `SHARP_TIER`）：
`infographic` / `ecom_detail` / `channel_banner` 走 high，`article_inline` / `video_overlay` / `scene` 走 low，其余默认 mid。

**768 和 4K 用同一档**——实测同一张图导出 768~3072 八档，缩到 640 采样后强边缘 79.7~80.9、95 分位 125~127，
几乎不动。真正拉开差距的是「字多字少、字多大、对比多高」，那是类型和风格的事。

纯画面类（`scene`）出图时记得加 `--no-text`：它天然没有文字硬边，用带字封面的阈值会误判成发虚。
判据细节见 `09-质检门禁.md`。

## 各类型的段位侧重

六段骨架（`10-千问2.1提示词规范.md`）所有类型通用，但各段轻重不同。写提示词前先看这张表，把力气花对段。

| 类型 | 重点段 | 可以少写 |
|---|---|---|
| 封面 | 三 文字区 + 四 主体 + 六 光影 | 五 场景 |
| 海报 | 三 文字区 + 信息块 + 一 质感 | 四 主体（可无人） |
| 信息图 | 区块结构 + 三 文字区 | 四 主体 / 六 光影 |
| 电商主图 | 四 产品细节 + 三 卖点 | 五 场景 |
| 文章内插图 | 二 构图 + 五 场景 + 六 光影 | 三 文字区（不落字） |
| 视频内嵌图 | 三 文字区 + 容器 | 四 五 六（透明或纯色底） |
| 界面类图 | 三 UI 五区 | 四 主体可弱化 |

判据：**段位顺序不变，笔墨分配按类型调。** 每段都写满会让提示词失焦，模型抓不住主次。

## 封面类（媒体运营主战场）

封面决定点击，其余一切排第二。

- 🔴 **停手率优先于信息完整**：划过去那一下没让人慢下来，后面全白做。
- 🔴 每张至少命中 2 项吸睛元素（热点词 / 数字前置 / 反差反转 / 身份标签 / 结果承诺 / 紧迫感），
  判据见 `02-网页模式版式.md`。
- 🔴 主标走「正面 → 反转」两层，每行 ≤ 7 字（横版 ≤ 9 字）。
- 🔴 同一条视频出 **2 版**：一版有人（`photo_big` / `closeup`），一版无人或弱人（`magazine` / `bold_block`）。
- 封面同时用于首帧时，铺法见 `04-接入视频首帧.md`。

## 海报类

比封面多一层「完整信息」义务，但信息完整不等于能读。

- 主标仍是主张，不是活动名；副标补场景；第三层才是时间地点。
- 行动指令只留一个（扫码 / 报名 / 到店），两个指令等于没有指令。
- 信息块 ≥ 3 个时按 `06-图文信息图版式.md` 排版，别堆成一段。

## 文章配图类

- 头图与标题承诺一致；标题改了图要跟着改，不一致就是毁约。
- 内插图只承载一个信息点，画面给正文留呼吸，不与正文抢字号。
- 图注位置在设计中预留，不事后压字。

## 电商类

- 主图产品主体占画面 60% 以上，卖点一行写完；平台角标区（左上 / 右下）保持干净。
- 详情长图按「钩子 → 卖点 → 证据 → 收口」分屏，每屏一个卖点，不用长段文字。

## 视频内嵌类

- 安全区：避开底部字幕带（竖屏预留底部 130~150px）与平台右侧按钮区。
- 停留时长按信息量给：一行标题 ≥ 3 秒，三行信息 ≥ 6 秒。
- 与口播同步出现，不同步的字幕式贴片等于干扰。

## 信息图类

- 结构先于版式：先定信息关系（时间线 / 对比 / 层级 / 构成 / 关系 / 地理），再选骨架。
- 三级层级：0~3 秒扫读、3~20 秒理解、20 秒以上细节，字号必须分出三档。
- 走 `web` 模式：大段中文只有网页层能保证字形与对齐。

## 画幅与安全区

| 平台 | 画幅 | 安全区 |
|---|---|---|
| 抖音 / 视频号 / 快手 | 9:16 | 上下各 10~14%，右侧 12% 留给按钮 |
| B 站 / YouTube | 16:9 | 四边各 5%，右下角留给时长角标 |
| 小红书 | 3:4 | 上下各 8% |
| 公众号 | 2.35:1 | 左右各 5% |
| 电商主图 | 1:1 | 左上角标、右下角标各 12% |
| 频道横幅 | 16:9 | 中央 60% 宽为各端通用安全区 |

## 硬规则

1. 🔴 先归类型再动手：类型定尺寸、要素与质检项，不按手感定。
2. 🔴 同一张图只服务一个用途；多平台发布按平台重新构图，不裁切母版。
3. 🔴 必备要素缺一项即不合格，不靠"看起来还行"放行。
4. 🔴 出图前过 `qc.py pre`、出图后过 `qc.py post`，判据见 `09-质检门禁.md`。
