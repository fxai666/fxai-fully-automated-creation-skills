# 06 · 图文信息图版式（叠加层 / 一图读懂）

叠加层是叠在底图之上的那一层。底图默认来自 AI 生图（`01` 册的 `hybrid`），也可以是纯色或渐变画布。
信息块 ≥ 3 个时按信息图处理，走**信息图版式**：靠结构让人 3 秒扫懂、20 秒读全。

大字封面的判据见 `02-网页模式版式.md`；本册管**信息块怎么摆、卡片怎么组、图标怎么给**。
版式实例见 `infographic-template.html`，图标见 `svg-icons.md`。

## 叠在生图底图之上时

- 🔴 **底图先给低细节区**：生图提示词里要声明留白方位与干净空间（`03` 册），底图细节最密的地方落字必糊。
- 🔴 **叠加前先压暗**：底图亮度高于 0.55 时，先叠一层暗蒙版或渐变再排版，靠字色硬顶必失败。
- 🔴 **底图只做 `object-fit:cover`**，不改构图；要换画幅重新生图，不裁切。
- **底图带字与叠加层二选一**：千问2.1 能直接写准中文（`10` 册），底图带字就不叠字；叠字就让底图留出低细节区。

## 先定结构，再定版式

信息关系决定骨架，版式不得先于结构定。

| 信息关系 | 结构 | 版式骨架 | 首选图形 |
|---|---|---|---|
| 先后 / 步骤 / 演化 | 时间线 | 横向或纵向轴线 + 节点 | 步骤条、里程碑 |
| 两案差异 | 对比 | 左右或上下二分 | 双列清单、对比条 |
| 包含 / 优先级 | 层级 | 金字塔或树状 | 分层矩形、树图 |
| 部分与整体 | 构成 | 中心放射或分区块 | 环形（≤5 项）、堆叠条 |
| 关联 / 流向 | 关系网络 | 网络图或流带 | 桑基图、矩阵 |
| 区域差异 | 地理分布 | 地图 + 分级色块 | 分级色块、气泡 |

## 按信息块数量选版式

| 信息块 | 版式 |
|---|---|
| 3~5 个，无分组 | 单栏纵向卡片流，或横向一排卡片 |
| 4~8 个，无分组 | 两列网格 `grid-template-columns:1fr 1fr`，不设中央区 |
| 有天然分组 | 按分组分栏，每组一个栏目标签胶囊；左右数量不必对称 |
| 9~12 个以上 | 双栏 + 中央视觉区，或 3~4 列纯网格 |
| 有层级 / 递进 | 卡片间加箭头（▲ ▼ →）或流程链，编号体现顺序 |

中央视觉区、汇总条、一览表都是**可选组件**，内容不需要就删。为凑版式填内容，等于把可读性换成了整齐。

## 展示方式库（跨类型复用）

整屏分区这套拆法可以直接搬到封面与海报：一块只装一类信息，块与块之间靠字号和留白分层。

| 区块 | 装什么 | 封面 | 海报 | 信息图 | 电商图 |
|---|---|---|---|---|---|
| 顶部条 | 分类 / 期号 / 品牌 | 教程徽章 | 主办方 | 栏目胶囊 | 品牌角标 |
| 主区 | 主体画面 | 人物 / 产品 | 主视觉 | 中央视觉 | 产品本体 |
| 文案区 | 主标 / 副标 | 两行主标 + 副标 | 主标 + 副标 | 标题层 | 卖点一行 |
| 信息卡 | 条目 / 数据 | 关键词 chips | 卖点三条 | 编号卡片 | 参数条 |
| 侧栏 | 标签 / 互动 | 竖排标签 | 咨询入口 | — | 促销贴 |
| 底栏 | 署名 / 频道 / CTA | 频道名 | 报名方式 | 来源 | 保障承诺 |

承载容器（可叠用，一张图选 2~3 种，不叠满）：胶囊、徽章、色块底、描边、发光、卡片、分屏、斜切。

判据：**每个区块都能被一句话说清装什么**。说不清的区块就是装饰，删掉。

## 页面骨架（从上到下）

渐变主标题（✦ 装饰）→ 副标题深色胶囊 → 栏目标签胶囊 → 编号卡片主区 → 中央视觉区（可选）→ 核心价值汇总条（可选）→ 表格 / 说明面板 → 页脚横幅。

## 编号卡片（核心组件）

```html
<div class="card" style="--c:#7C5CFC">
  <div class="badge">1</div>
  <div class="body">
    <div class="en">Prompt Engineering</div>
    <div class="cn">提示词工程<span class="tag">让模型听懂</span></div>
    <ul><li>要点一</li><li>要点二</li></ul>
  </div>
  <div class="iconbox"><svg …/></div>
</div>
```

四个字段固定，缺一项卡片就塌：**编号（badge）· 英文小标（en，主题色）· 中文标题（cn）+ 标签（tag）· 要点列表（ul，主题色圆点）**，右侧 iconbox 放内联 SVG。

卡片样式：白底、圆角 12px、`border-left:4px solid var(--c)`、阴影 `0 2px 8px rgba(31,68,131,.10)`；iconbox 底色 `color-mix(in srgb, var(--c) 12%, #fff)`。

## 数据块怎么画（图表选型）

信息块里出现趋势、构成、排名、分布，就画图，别用长句描述数字。

| 数据关系 | 首选 | 备选 | 避开 |
|---|---|---|---|
| 随时间变化 | 折线 | 面积（累计量） | 饼图 |
| 部分与整体（≤5 项） | 环形 | 堆叠条形 | 3D 饼图 |
| 部分与整体（>5 项） | 横向条形 | 树图 | 饼图 |
| 排名对比 | 横向条形 | 棒棒糖点图 | 3D 柱图 |
| 两个变量相关 | 散点 | 气泡 | 双 Y 轴折线 |
| 分布情况 | 直方图 | 箱线图 | 只给一个平均值 |
| 流程与步骤 | 线性流程 | 泳道图 | 放射状装饰图 |
| 地理分布 | 分级统计地图 | 气泡地图 | 无图例的色块地图 |

四条硬规矩：

1. 条形图坐标轴从 0 起（截断会把差异放大成假象）。
2. 数据点少于 8 个，直接标数字，图例省掉。
3. 标拐点，平均值把故事藏起来了。
4. 每张图角落标样本量与时间范围；没有口径的数字只是装饰。

图注三级：主注给结论（「三个月翻了三倍」）、轴名给口径、来源用最小字号放图下。
数字叙事按「结论 → 参照 → 变化原因 → 可行动拆分 → 下一步动作」走，一屏一个结论。

## 字号（缩略图判据，非面板尺寸）

字号按**缩略图里能否读出**定，不按画布比例定。

| 元素 | 竖版 768×1280 | 横版 1280×768 |
|---|---|---|
| 主标题 | 64~76px / 900 | 72~88px / 900 |
| 版块标题（cn） | 34~38px / 800 | 34px / 800 |
| 英文小标（en） | 26~28px / 800 | 26px / 800 |
| 条目（li） | 22~24px / 500 | 24px / 500 |
| 编号（badge） | 40px / 900 | 40px / 900 |

信息块 ≥ 8 个时整体下移一档（主标题不低于 56px），靠减字数保住字号，不靠缩字号塞内容。

## 图标

一律内联 SVG，feather 线性风格，公共属性固定：

`viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"`

**现成图标取 `svg-icons.md`**（23 组：对话、搜索、工具箱、机器人、图表、循环、数据库、网络、剪贴板等），
直接复制 `<svg>` 片段，颜色由父元素 `color` 带，不在 svg 内写死。

尺寸：卡片图标 26px、汇总条 24px、中央大图标 70~80px。
**禁用 emoji**：无头 Chromium 对 emoji 渲染不一致，会掉成黑白线条或方框。

完整版式实例见 `infographic-template.html`（11 模块：渐变标题 / 副标胶囊 / 栏目标签 / 编号卡片 / 中央视觉区 /
汇总条 / 表格面板 / 页脚），**只作版式参考，模块数量按内容定**，不是必须照抄。

## 配色

- 页面底：浅色渐变 `linear-gradient(180deg,#DCEAFC,#F4F9FF 30%,#EAF2FC)`
- 标题渐变文字：`#0B3D91 → #3B82F6`（`-webkit-background-clip:text`）
- 卡片主题色板：`#7C5CFC` `#2E7CF6` `#FF8A3D` `#22B07D` `#2C5BA9` `#8B5CF6` `#16A34A` `#2563EB` `#F59E0B` `#7C3AED` `#0D9488`
- 页脚 / 汇总条头：`linear-gradient(90deg,#0B3D91,#1E63D0)`

## 复用版式实例（`infographic-template.html`）

这是一份 892px 宽的竖版信息图成品，能直接渲染（`poster.screenshot`），**当成品看，当组件库用**：

- 文案分散在 20 多处（标题、副标、11 张卡片的中英文名与要点、两组栏目头、汇总条 11 个小项、两张表格、底栏），改一处不够，要逐处换。
- 原始版本的底栏带 emoji，换成 `svg-icons.md` 的片段（本机 Chromium 对 emoji 渲染不稳定，会掉成黑白或方框）。
- 高度按内容实测，别猜：先给足高度渲染，再用 `python qc.py fit --img 出图.png --out 裁好.png` 裁白并报精确尺寸（实测 3600 高裁到 1574，正常封面不会被动）。
- 真正省事的是它的 CSS：编号大徽章、`.card` 左色条 + `.iconbox`、顶部胶囊副标、`.footer` 结论条、双列表格。直接抄这几段比重写快。

## 渲染安全

- 🔴 **色值写死十六进制**。截图端不解析未定义的 CSS 变量，会整体回退成黑色；只有同文档内定义过的 `--c` 可用于卡片主题色。
- 🔴 **宽度定死、高度自适应**，截图走全页 `full_page=True`，倍数 ≥ 3 保证印刷级清晰。
- 🔴 **模板占位替换用 `.replace("{{X}}", v)`**，不用 `%` 格式化：CSS 里 `%` 满地都是，错一个整段样式失效。
- 🔴 **占位后必须带分号**，否则与下一条声明粘连成无效属性，元素会跑到画布外。

## 自查清单（出图后逐项核对）

- [ ] 文字无截断，胶囊与标签不意外换行（换行加 `white-space:nowrap`）
- [ ] 图标全部彩色渲染、风格统一
- [ ] 各列底部高度差可接受（差太多调 padding 或合并内容）
- [ ] 无意外深色块压住正文
- [ ] 中央视觉区不压卡片（走 flex 流式，少用绝对定位）
- [ ] 缩略图尺寸下能读出主标题与版块标题

## 硬规则

1. 🔴 结构先于版式：信息关系没定，不选骨架。
2. 🔴 二级信息块最多 5 个；到 6 个就拆两张图，或降级为条目。
3. 🔴 一张图只用一个视觉隐喻（库见 `07-叙事与信息层级.md`）。
4. 🔴 色彩不单独表意：状态必须配图标或文字。
5. 🔴 字号以缩略图可读为准，内容超载改文案，不改字号。
