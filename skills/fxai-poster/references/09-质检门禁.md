# 09 · 质检门禁（交付前必过）

三道门，按顺序走。**任何一道判 FAIL 就不许往下走**，按报告给出的修法改完重跑。
脚本 `qc.py`，退出码 `0`=可交付、`2`=不许交付，可直接卡流水线。

```
定类型 → 写规格 → ①预检 → 写提示词 → ②提示词门 → 生图 → ③成图门 → 交付
              ↑                                    │
              └──────────── 按 fix 改 ←─────────────┘
```

## ① 规格预检（出图前）

查这张图的**设计规格**有没有硬伤：画幅对不对、模式对不对、必备要素齐不齐、文案超不超宽、吸睛够不够。

```bash
python qc.py pre --kind record_cover --w 1680 --h 1054 --mode hybrid \
  --title "一个人|顶一支团队" --sub "写稿·配音·出镜·剪辑 全是 AI" \
  --tag "完整实操教程" --keys "智能体,技能,提示词" --hooks "数字前置,反差反转" \
  --contrast-plan "底部压暗渐变" --subject-pos center
```

| 检查项 | 判据 |
|---|---|
| 画幅 | 与类型规格偏差 ≤2% |
| 出图模式 | 落在该类型允许的模式内 |
| 必备字段 | 该类型必填项（标题 / 信息块 / 时间…）齐全 |
| 单一主张 | 一张图一个主张 |
| 主标行数 / 字宽 | 行数 ≤ 上限，每行字数 ≤ 上限 |
| 副标 / 角标 / 关键词 | 各自字数与数量上限 |
| 吸睛元素 | 封面海报类 ≥2 项，按标准命名 |
| 视觉隐喻 | ≤1 个 |
| 文字对比方案 | 已声明蒙版 / 压暗 / 描边之一 |
| 主体位置 | 已声明落位（中间 60%） |

字段口径以 `qc.py` 的 `TYPES` 为准，人读要素清单见 `08-图片类型矩阵.md`。

## ② 提示词门（生图前）

AI 出图的质量八成由提示词决定。缺哪类补哪类，不是评文笔。

```bash
python qc.py prompt --text "<提示词全文>" --role     # --role：挂了角色参考图
```

| 段 | 要素 | 为什么必须有 |
|---|---|---|
| 一 | 画布与质感 | 不锁质感总纲，画面出成设计稿 |
| 二 | 构图落位 | 不写占比，主体撑满画面 |
| 三 | 文字区：引号文案 / 位置 / 字号层级 / 字色字体 | 千问2.1 能写准中文，但文案不进引号就不上画面；不写位置与层级，字会挤、会一样大 |
| 四 | 主体 | 不写主体，模型自由发挥 |
| 五 | 场景 | 没有环境，主体悬空 |
| 六 | 光线 | 光比是画面强度的来源，不写就是平光 |
| — | 文案条数 ≤4、单条 ≤14 字 | 超四条模型丢条，长句漏字折行 |
| — | 人物着装（挂参考图时） | 参考图本身无上衣，漏写直接出问题 |
| — | 标签堆 / 负向描述 | 千问2.1 不认 `8k, masterpiece` 标签堆，也没有负向字段 |

报告里出现「文字风险词」时按提示删掉：要文字就走叠加层。

## ③ 成图门（出图后）

```bash
python qc.py post --img 封面.png --kind record_cover
python qc.py post --img 概念图.png --no-text          # 纯画面图跳过文字量下限
python qc.py post --img 图.png --target 1080x1920     # 不在类型表里时直接给尺寸
```

判据分两级：**硬门**不通过必须重做；**提示**只提醒，人眼确认后可放行。

| 指标 | 判据 | 级别 | 说明 |
|---|---|---|---|
| 画幅比例 | 与目标偏差 ≤3% | 硬门 | 换画幅重构图，不裁切 |
| 有效分辨率 | 短边 ≥ 目标短边 85% | 硬门 | 小于目标尺寸必是拉伸出来的 |
| 整图亮度 | 20~228 | 硬门 | 压死或发白都无法落字 |
| 画面层次 RMS | ≥28 | 硬门 | 发平就是没光比 |
| 高频真实性 | 重采样 PSNR ≤44 | 硬门 | **主力判据**：抓模糊与小图拉伸 |
| 缩略图可读 | 200px 宽梯度 ≥档位值 | 提示 | 缩到信息流还认不认得出主标 |
| 画面锐度 | 强边缘梯度 ≥档位值 | 提示 | 边缘是否发虚 |
| 细节峰值 | 梯度 95 分位 ≥档位值 | 提示 | 边缘是否够利 |
| 色彩强度 | 饱和度 ≥0.14 | 提示 | 极简白 / 高级灰是刻意设计 |
| 文字 / 细节量 | 12%~45%（纯画面只查上限） | 提示 | 极简封面 4% 属正常 |
| 边缘安全区 | ≤1.8× 全图密度 | 提示 | 满版构图属正常 |
| 无死区 | 最平 1/16 格 ≥6 | 提示 | 深色底角落属正常 |

### 为什么不用按 768 / 1080 / 4K 分档

**实测过：同一张图导出 768、864、1080、1280、1536、1664、2048、3072 八档，指标几乎不动。**

| 导出宽度 | 缩放比 | 强边缘 | 95 分位 |
|---|---|---|---|
| 3072 | 21% | 80.5 | 126.6 |
| 2048 | 31% | 80.5 | 126.7 |
| 1664 | 38% | 80.9 | 127.6 |
| 1080 | 59% | 79.8 | 125.0 |
| 768 | 83% | 79.7 | 125.0 |

原因：所有指标都在**缩到 640 宽后**计算，采样尺度被归一化了。所以 768 宽的封面和 4K 的封面用同一把尺子，**分辨率本身不影响判定**。

真正影响梯度的是三件与分辨率无关的事：**有没有文字、字有多大、对比度多高**。所以要分档的是**图类型**，不是分辨率。

### 锐度按类型分三档

| 档 | 适用 | 强边缘 | 缩略梯度 | 细节峰值 |
|---|---|---|---|---|
| high | 信息图 / 电商详情 / 频道横幅（字多且密） | ≥35 | ≥18 | ≥70 |
| mid | 各类封面 / 海报 / 头图 / 社交图（默认） | ≥20 | ≥14 | ≥45 |
| low | 纯画面 / 场景图 / 人物图 / 插图（`--no-text`） | ≥10 | ≥10 | ≥20 |

实测跨度极大，一套绝对值量不住：横版深色封面强边缘 81、竖版深色 64、方图浅色 28、竖版浅色 25、纯画面柔光 34。
浅色简约设计的饱和度只有 0.09（深色是 0.80）、文字量 4%（深色 14%）、缩略梯度 7（深色 23）——
**这些指标差十倍是设计风格，不是质量问题**，所以一律降为提示。

### 高频真实性：主力判据怎么算的

把图缩到 1/2 再放大回原尺寸，与原图比 PSNR。**PSNR 越高，说明原图本来就没有高频细节**——模糊或小图拉伸。

这个口径与画幅、主题、字号全都无关，只问一件事：高频细节是真的存在，还是插值编出来的。

| 样本 | PSNR | 判定 |
|---|---|---|
| 清晰（8 个样本：横/竖/方/纯画面/极简） | 27.7~42.6 | PASS |
| 低清拉伸 1/6 | 43.6~51.7 | FAIL |
| 高斯模糊 sigma10 | 54.1~57.3 | FAIL |
| 纯色图 | 99.0 | FAIL |

阈值 44 卡在清晰上限（42.6）与低清下限（43.6）之间。梯度类指标在低清图上会骗人——
横版封面低清版的强边缘是 60.3，比竖版清晰图的 64.1 只低一点；浅色封面清晰图的 95 分位只有 16.0，
低清版反而涨到 24.2（放大插值造出假边缘）。**所以低清和模糊一律看 PSNR，不看梯度。**

面积大于 90% 纯色的极简设计 PSNR 会偏高，被拦时人眼确认后放行（这是设计，不是缺陷）。

## 长图先裁白再判

网页模式出的长图（信息图 / 电商详情）高度靠内容撑，渲染时给的画布往往留大片空白。
交付前先跑 `python qc.py fit --img 出图.png --out 裁好.png`，按背景色裁掉四周空白并报精确尺寸；
裁完再进成图门，否则「无死区」「边缘安全区」会被空白误判。

## 判级与放行

| 结果 | 含义 | 处置 |
|---|---|---|
| 全通过 | 达标 | 直接交付 |
| 只有 WARN | 可交付但有风险项 | 交付说明里登记，人工看一眼 |
| 任一 FAIL | 不达标 | 不许交付，按 fix 改完重跑同一道门 |

分数只用于同一张图多版之间横向比较，**不设分数门槛**：一条 FAIL 就够拦下。

## 返修往哪一步退

| 失败项 | 退到 | 改什么 |
|---|---|---|
| 画幅 / 模式 / 必备要素 / 文案超宽 / 吸睛不足 | ① | 改规格与文案，不动提示词 |
| 提示词缺要素 / 文字风险词 / 着装漏写 | ② | 改提示词，不重出图 |
| 糊 / 灰 / 平 / 构图贴边 / 主体位置错 | ② | **改提示词重出**，不修图 |
| 字太小 / 对比不足 / 文字溢出 / 层级不清 | 叠加层 | 调字号、蒙版、字色，底图不动 |
| 文字量过低（字没出来） | 叠加层或字体 | 先查渲染（字体、截图），再查字号 |

🔴 **底图不合格一律重出，不靠修图救**：糊、灰、构图错都说明提示词或规格有问题，修图是治标。

## 机器测不出的三项（交付前人工过）

1. **主张测试**：一句话 / 静音 / 主角三关（`07-叙事与信息层级.md`）。机器只能测"有没有字"，测不了"这句话值不值得看"。
2. **缩略图实看**：缩到信息流尺寸，人眼扫 3 秒，问自己会不会停。
3. **合规与肖像**：人物肖像授权、地图合规、违禁词与导流信息（媒体平台物料默认裸出，不带网址 / 二维码 / 关注语）。

## 硬规则

1. 🔴 三道门顺序不可跳，任何一道 FAIL 不往下走。
2. 🔴 成图门按实测指标判，不按观感判；指标不达标就是不合格。
3. 🔴 底图问题重出图，叠加层问题改叠加层，两类问题不混着修。
4. 🔴 交付说明里登记 WARN 项与人工复核结论。
5. 🔴 质检脚本的阈值改动必须附实测样板，不凭手感调。
