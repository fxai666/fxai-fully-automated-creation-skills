# 10 · 千问2.1 提示词规范（唯一出处）

本技能的生图模型是**千问2.1（qwen21）**。它原生理解中文，**文字渲染是它的强项**：
海报、封面、招牌、包装、信息图都能直接把中文写准。所以提示词的写法与常见生图模型相反——
**该写文字就大胆写进去**，靠叠加层补字是次优解。

## 五条总原则

| 原则 | 怎么做 | 判据 |
|---|---|---|
| 写句子不写标签 | 用完整自然语言描述画面，含明确空间关系（在…前面 / 后面 / 旁边） | 出现 `8k, masterpiece, best quality, ultra detailed` 这类堆叠标签即不合格 |
| 正向描述 | 只写画面里有什么，靠具体内容挤掉不想要的东西 | 千问2.1 没有负向提示词字段，负向句式不起作用 |
| 具象到可画 | 写 `85mm 浅景深`、`柔光窗光`，不写 `好看`、`高级感` | 形容词要能落到光、材质、构图、镜头 |
| 文案进引号 | 逐字呈现的文案用双引号包住，引号内一字不改 | 引号外的字是描述，引号内的字才上画面 |
| 顺序即权重 | 越靠前的描述越主导画面；需要强调的段落放前面 | 主体与文案位置写在最前 |

## 六段骨架（按序写，不调换）

| 段 | 写什么 | 缺了会怎样 |
|---|---|---|
| 一 画布与质感 | 画幅比例 + 质感总纲（写实摄影 / 3D 渲染 / 扁平插画 / 电影感） | 质感总纲缺，画面出成设计稿 |
| 二 构图落位 | 主体在哪个方位、占画面多少、朝向；前中后三层各由什么填充 | 占比不写，主体撑满画面 |
| 三 文字区块 | 每条文案：引号内容 + 位置 + 字号层级 + 颜色 + 字体风格 | 只写「有标题」，字会漏、会错位 |
| 四 主体 | 人物（年龄感 / 发型 / 着装 / 姿态 / 道具）或产品（材质 / 细节 / 光泽） | 只写「一个女生」，形象随机 |
| 五 场景环境 | 地点、承托物材质、邻位物件、远景 | 只写地点，背景一片空白 |
| 六 光影色调 | 光源方向、受光面、阴影面、色温、氛围 | 缺光源方向，出成平光 |

配额参考：文字区块占提示词三到四成，主体三成，构图场景光影三成。文字段太薄会漏字，太厚会挤小主体。

## 文字区块怎么写

引号内原样渲染，引号外描述样式与位置。**逐条写，一条一句**。

```text
画面中部偏上位置，用白色粗黑体写大字"一个人"，字号占画面宽度的四成；
其下一行用金色粗黑体写"顶一支团队"，字号略小一号；
右上角一枚圆角矩形徽章，深蓝底白色粗体一行写"实操教程"，四个字排成一行；
底部居中一行小字，浅灰白色写"写稿 · 配音 · 出镜 · 剪辑 全是 AI"。
```

| 要写清 | 不写清会怎样 |
|---|---|
| 位置（中部偏上 / 右上角 / 底部居中 / 左上角） | 字挤在一起或跑到画面外 |
| 字号关系（占宽四成 / 大一号 / 小一号） | 主副标一样大，层级消失 |
| 颜色 + 字体风格（白色粗黑体 / 金色描边圆体 / 宋体） | 字色与底图撞，读不清 |
| 排版容器（胶囊 / 徽章 / 色块底 / 描边 / 发光） | 字直接压在杂背景上，糊成一团 |
| 徽章字数与「一行不折行」 | 六字徽章会被挤成两行，读起来断气 |
| 逐字文案（含标点、数字、英文缩写） | 漏字、错字、标点变半角 |

中文可指定字体家族：黑体 / 宋体 / 楷体 / 圆体 / 综艺体。英文与数字单独写清大小写。

需要强调某段文案时用加权语法：`(白色粗体大字"一个人"写在画面中部偏上:1.5)`。权重 1.2~1.8 之间；超过 1.8 常出畸变笔画。

## 文案本身的写法

模型逐字复现，所以文案要先短、要准：

- 🔴 **主标每行 ≤ 7 字**（横版 ≤ 9 字）：长句模型会漏字、拆行、写歪。
- 🔴 **数字、英文缩写、生僻字单独确认**：这些是错字高发区，出图后逐字核对。
- 🔴 **标点走全角**，需要在提示词里写明全角，如「中间一个全角间隔号」。
- 文案条数控制在 4 条以内（主标 / 副标 / 徽章 / 底栏），再多模型会合并或丢弃。

## 人物写法

| 情况 | 怎么写 |
|---|---|
| 挂角色参考图 | 提示词里用 `<image1>` 绑定（多图必须逐个绑定），写明「`<image1>` 是画面中的人物」；**必须写着装**，参考图肩部以上无上衣 |
| 人物弱化为点缀 | 写「远景、仅占画面高度约 1/10、半透明如全息投影、位于画面右下角」 |
| 纯场景无人物 | 写「画面中无人」 |

🔴 着装红线：胸部与私密部位不裸露。透明薄纱、透视演出服、贴身礼服照常写——要「透而不露」。

三条实测口径：

- **配饰要写**：加一句「耳垂一枚细银耳饰」，人物质感明显比不写更精致；只写服装会显得空。
- **手势要写清**：「一只手抬起指向左侧文字区，五指清楚分开」比只写「抬起手」稳定得多，后者常出手指并连或数量不对。
- **参考图绑定漏了会退回默认长相**：不给 `<image1>` 时生图端会告警，人物质感下降；绑定后人物更贴参考图。

## 尺寸

宽高取 **32 的整数倍**，落在 512~4096。传入非 32 倍数会被向下取整，例如 1680→1664、1054→1024。

| 比例 | 像素 | 用途 |
|---|---|---|
| 16:10 | 1664×1024 | 录屏 / 教程封面（对齐 1680×1054 成片） |
| 9:16 | 864×1536 | 竖屏全屏 / 播放页 |
| 3:4 | 1080×1440 | 小红书 / 海报 |
| 1:1 | 1024×1024 | 方图 / 电商主图 |
| 16:9 | 1536×864 | 横版封面 |
| 2:3 | 832×1248 | 竖版略窄 |

成图尺寸与目标画幅允许 ≤2% 偏差，质检按比例判，不按绝对像素判。

## 界面类图（视频信息流 / 播放页 / 详情页）

要的是一整屏 App 界面时，第三段换成 **UI 五区**，段序不变：状态栏、导航栏、右侧互动栏、底部导航、左下文案。

| 区 | 列什么 | 判据 |
|---|---|---|
| 状态栏 | 时间、信号、WiFi、电量 | 电量写颜色 + 内嵌数值 |
| 导航栏 | 左端图标与角标、中段页签文案逐个、选中态、右端搜索 | 选中态写「某文案下方一条白色短横线」 |
| 右侧互动栏 | 头像、点赞、评论、收藏、转发 | 每项 = 图标形状 + 附注文字与数值 |
| 底部导航 | 各入口文案 + 数字角标 | 角标写位置 + 颜色 + 数值；末尾补「入口全部带白色文字标签」 |
| 左下文案 | 作者名、正文、话题标签、按钮 | 话题标签逐个列出 |

图标判据：位置 + 图形 + 附注文字，三者齐。只写「点赞图标」，模型自造数值。
结构化拼装见 `fxai-comfyui-image-gen` 的 `feed_screen.py`（spec → 六段骨架提示词）。

## 图改图（编辑已有图）

参考图与文本走同一个编码器，所以把指令写成**关于这张图的句子**，不写成对工具的命令。

```text
保持人物的面貌、服装、姿态与构图不变，把背景换成午夜工作室，
保留人物与桌面的接触阴影，光线方向与原图一致。
```

只改一件事，改完对比原图看脸、手、文字、产品细节有没有被连带改动。

## 常见错误

| 错误 | 后果 | 改法 |
|---|---|---|
| 文案不写引号 | 模型把文案当描述，画面里没有这行字 | 逐字文案全部进双引号 |
| 写「标题放在左边」 | 位置模糊，字乱跑 | 写「画面左上角，距边缘约一成」 |
| 堆 `8k, best quality` | 千问2.1 不认标签堆，细节反而变差 | 换成具体的镜头、光线、材质描述 |
| 写负向句式 | 无负向字段，等于没说 | 直接略过不写；**只有叠加层路线**才写「画面无任何文字」 |
| 主标写成长句 | 漏字、折行、错位 | 拆成两行，每行 ≤7 字 |
| 文案超过四条 | 模型合并或丢条 | 主标 + 副标 + 徽章 + 底栏，四条封顶 |

## 跨技能调用

本册是图片设计的唯一规范出处。其他技能要出封面 / 海报 / 配图 / 内嵌图时，按三步走，不另写一套。

1. **取类型规格**：`python ~/.workbuddy/skills/fxai-poster/qc.py types --json`，
   拿尺寸、允许模式、字数上限、必备项。
2. **写提示词**：按六段骨架写，文案进双引号。写完过 `qc.py prompt --text "…" --role`。
   封面版式的排版说明由 `fxai-poster/cover_prompt.py` 按 `cover_styles.py` 的样式自动拼，不得手写「加个标题」。
3. **出图后过门**：`qc.py post --img 图.png --kind <类型>`，退出码 `2` 表示不许交付。

调用方只需知道 `qc.py` 的路径，不复制规范、不改阈值——规范只有一处，改了全体生效。

## 硬规则

1. 🔴 提示词用自然语言句子，不堆标签。
2. 🔴 逐字文案必须进双引号，并写明位置、字号关系、颜色与字体风格。
3. 🔴 主标每行 ≤7 字（横版 ≤9 字），文案总数 ≤4 条。
4. 🔴 只做正向描述，靠具体内容挤掉不需要的元素。
5. 🔴 出图后逐字核对文案，错字漏字直接重出，不修补。
