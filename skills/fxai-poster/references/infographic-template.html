十一大工程一览表
序号工程类型核心问题企业落地作用
1Prompt Engineering纵向如何把任务说清楚？让模型稳定理解任务与输出要求
2Context Engineering纵向给模型什么信息？让模型基于企业知识、用户状态和业务规则工作
3Skill Engineering纵向如何把能力标准化、复用化？将 Prompt、上下文、本体、工具规则封装为技能
4Agent Engineering纵向如何让模型行动？让模型规划任务、调用技能和工具、执行流程
5Harness Engineering纵向如何让系统协同运行？把模型、工具、本体、技能、数据整合成系统
6Loop Engineering纵向如何让系统持续变好？用反馈和评估持续优化系统
7Data Engineering横切数据是否可用、可信、合规？支撑知识库、上下文、本体、技能、评估和决策
8Ontology Engineering横切业务知识如何结构化表达？定义业务概念、对象、关系、规则和语义边界
9Evaluation Engineering横切怎么知道 Agent 做得好不好？建立质量标准、测试集、评测体系和上线门槛
10Safety / Governance横切系统是否安全、合规、可控？保障权限、隐私、审计、风险和责任边界
11Product / UX Engineering横切用户是否会用、愿用、信任？设计人机协作体验，提高采纳率和业务价值
为什么是"六大纵向工程 + 五大横切工程"？
能力递进链条（解决"如何变强"）
Prompt→ Context→ Skill→ Agent→ Harness→ Loop
回答：Agent 能力如何从简单回答，逐步走向任务执行、生产上线和持续进化？
横切支撑体系（解决"如何可信可用"）
Data→ Ontology→ Evaluation→ Safety→ Product / UX
回答：整个 Agent 系统如何做到可信、可懂、可测、可控、可用？
🏆  纵向构建能力，横向保障体系，打造可落地、可复制、可进化的企业级 Agent 系统！  🚀
