# 01 · 模式选择（开工必读）

## 主线：AI 生图打底，再叠加

图片设计的主路径是**先让生图模型出画面，再在成图上叠加文案与图形层**。不靠纯手绘排版硬凑画面，
也不指望生图直接写出准确中文。

| 这次要什么 | 模式 | 为什么 |
|---|---|---|
| 要画面 + 要中文文案（绝大多数情况） | **`hybrid`（默认）** | 生图出底图与质感，叠加层落文案，两边各干最擅长的 |
| 只要画面，不落文字（概念图 / 背景 / 纯摄影感） | `image` | 网页画不出照片级画面 |
| 无画面需求，纯文字排版 / 文字密集信息图 | `web` | 中文必须精确、字数多、要结构对齐时，只有网页层做得到 |

## 决策顺序

1. **这张图要落中文吗？** 不需要 → `image`，直接按提示词出图，结束。
2. **画面撑得起主张吗？** 撑得起 → `hybrid`（默认）：按 `08-图片类型矩阵.md` 定类型与要素，按 `10-千问2.1提示词规范.md`
   写提示词生图——**文案可以直接生在图上**，需要精修或多版本再叠叠加层。
3. **画面撑不起**（信息图、纯文字、大段文案、要对齐的表格清单）→ `web`：直接 HTML 排版，
   版式见 `06-图文信息图版式.md`。

判据：**一张有质感的画面能让人停下，就让生图打底；一张画面讲不清的，才走纯排版。**

## 按用途的默认选择

| 用途 | 默认模式 | 默认尺寸 |
|---|---|---|
| 录屏 / 教程视频封面 | `hybrid` | 1680×1054 |
| 竖版视频封面（抖音 / 视频号） | `hybrid` | 768×1280 |
| 横版视频封面（B 站 / YouTube） | `hybrid` | 1280×768 |
| 海报（活动 / 课程 / 品牌） | `hybrid` | 1080×1440 |
| 文章头图 / 公众号封面 | `hybrid` | 900×383 |
| 小红书笔记封面 | `hybrid` | 1080×1440 |
| 电商主图 | `hybrid` | 800×800 |
| 信息图 / 一图读懂 | `web` | 1080×1440 |
| 视频内嵌图（标题卡 / 贴片） | `web` | 随成片分辨率 |
| 概念图 / 背景图 | `image` | 按用途 |

全类型规格（含字数上限、必备要素、质检判据）见 `08-图片类型矩阵.md`。
主推样式按主题自动选（`photo_big` / `closeup` / `magazine` / `bold_block` / `split` / `list`）见 `05-封面模板库.md`。

## 排除项

- ❌ 用 `image` 出带大段中文的图：生图中文必糊、错字、位置失控
- ❌ 用 `web` 硬凑需要真实人物 / 场景的画面：网页只能排版，画不出照片
- ❌ 按习惯统一走一个模式：模式按目标选，不按熟练度选
