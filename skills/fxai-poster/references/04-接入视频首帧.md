# 04 · 接入视频首帧（铺到 MP4 前）

## 什么时候用

平台抓首帧当封面缩略图 → 把海报铺到视频最前面，第一帧就是设计好的封面。
`--attach-video <mp4>` 一键完成。

## 🔴 两个致命点（视频号「咔嚓跳、口型全错」的根因）

### 1. 开头须是真实采样

`anullsrc` 生成的是**采样全 0** 的音频，不是低音量。平台转码器读到开头一段采样为 0，
判成无效数据，**从第一个有声采样点开始输出流**，画面却还从第 0 帧开始 →
音画基准错位，前面跳一下、后面整条口型全跑。

🔴 **垫什么、垫多少、AAC 电平映射表，全部见
`05-封面模板库.md`「音轨：垫次声正弦」。本册不重复，也不许在这里写第二套数。**

### 1b. 更稳的做法：别拼静音段

若源片**本身开头就有人声**（多数幻灯/口播片如此，旁白从第 0 帧起），静音段完全是拼接
引入的。此时首选不是调填充音，而是**不给它静音的机会**：

- 用封面 PNG 顶掉源片开头封面段那几帧的**画面**，音频沿用源片原轨。
- 结果：整片零静音段、零填充音、零拼接接缝，平台无感。
- 代价：源片开头烧进去的字幕会跟着画面一起被盖掉（会「有声音没字幕」）。
- ⚠️ 这一步**改的是原片画面**，用户明确定过禁用（「盖上去不就把我们完整视频
  给破坏了吗」）。除源片开头确实是黑屏/空镜外，一律不得主动用。

### 1c. 先量「封面段那几帧」到底有没有人声

决定拼不拼之前，先量源片**前 10 帧那一段**的音量：

```bash
# -t 取值 = 封面段帧数 ÷ 源片帧率（10 帧 @24fps ≈ 0.42s，@25fps = 0.40s）
ffmpeg -hide_banner -t 0.42 -i 源片.mp4 -af volumedetect -f null -
```

- `max_volume` **低于 −40dB**（静音起手）→ 这段本来就是静音，拼封面段**零损失**，
  直接走 `--attach-video` 正常流程。
- 高于 −30dB → 这段真有人声在说，拼上去会把那几帧的画面/烧录字幕盖掉，才需要考虑 1b。

🔴 **检测窗口不得取得比封面段长。** 取 1 秒去量，会把封面段之后**已经开口的人声**
一起卷进窗口，读数直接跳到 −7dB，于是误判成「第 0 帧就有人声」→ 白白放弃铺封面，
甚至去动原片画面。实测教训：某片实际前 0.457s 是纯静音（`max −64.3dB`），
用 `-t 1.2` 一量却是 `−7.7dB`，结论完全反了。

判据优先级：**先按封面段时长量，量出来是静音就不用管 1b**。
更精确的起点定位用 `silencedetect=noise=-40dB:d=0.08` 看第一个 `silence_end`。

### 1d. 🔴 与 BGM 的先后：铺封面在前，混配乐在后

封面段自带的是**垫音**（25Hz 正弦，−73dB 级），**不是配乐**。垫音照旧、不改。
但封面段若只有垫音，整条音轨的第 0 帧就是准静音，平台可能把开头当空白裁掉。

**规则：BGM 是最后一道工序，排在铺封面之后。**

```
拼接 → 字幕烧录 → 铺首帧封面 → 混 BGM → 出片
```

- 铺完封面，再对**这条已成片**混 BGM：`mix_bgm` 会 `atrim` 到整片时长、`-c:v copy`
  只重编码音频，于是**配乐从封面第一帧起铺满到片尾**，封面这一截自然有音乐。
- 反过来「先混 BGM 再铺封面」会把封面段替换成垫音，第 0 帧缺一截配乐 —— 不许这么排。
- 幻灯侧已在管线里固定该顺序：`sv_pipeline.py --cover <png> --bgm auto`，
  或后补 `sv_media.py --cover <png> --bgm auto`。口径见
  `fxai-slide-video/references/04-字幕与合成.md`「BGM 环节」0 节。

验收：`ffmpeg -t 0.42 -i 成片.mp4 -af volumedetect -f null -`，封面段
`max_volume` 应在 −26dB 上下（有配乐），不是垫音那档的 −76dB。

### 2. 必须 faststart + 单次编码

`concat` demuxer 的 `-c copy` 拼出来的文件：moov 在 mdat 后面（无 faststart）、
两段 time_base 不一致，网页端上传/转码解析容易异常。

现版改成**一次 `filter_complex` 编码**（视频、音频各自 concat）：时间戳天然连续、
帧率锁成 CFR、moov 前置。

判据：`ftyp → moov → mdat`（moov 在 mdat 前），不是 `ftyp → mdat → moov`。

## 输出参数（平台安全档）

| 项 | 值 | 说明 |
|---|---|---|
| 封面段帧数 | 见 `05-封面模板库.md` | 按帧定义，本册不写 |
| 视频编码 | libx264 High@4.1，yuv420p | 不用 HEVC / ProRes / MKV |
| 帧率 | **CFR，跟源片**（`fps=` 必传） | 不传会触发重编码；手机片多是 30，**幻灯成片是 24** |
| 码率 | crf 18 + `-maxrate 8M` | 按需给码率，静态画面实测 2~3M 足够 |
| 音频 | AAC-LC，**48000Hz**，16bit，声道跟源片 | 44.1k 在部分链路会出问题 |
| 封装 | 标准 MP4，`+faststart` | 碎片化 mp4 / `moov` 在尾一律不合格 |

## 出片后必须校验三行

```bash
# ① 封面段内不是 -91dB（有真实采样）
ffmpeg -hide_banner -i out.mp4 -t <封面段秒数> -af volumedetect -f null - 2>&1 | grep max_volume

# ② 音画起点都是 0，帧率是 CFR
ffprobe -v error -show_entries stream=codec_name,r_frame_rate,avg_frame_rate,start_time \
        -of default=nw=1 out.mp4

# ③ moov 在 mdat 前
#    原子顺序应为 ftyp → moov → mdat
```

三项都过才算能上传。任一不过，重导。

## 已经跳了怎么办（Plan B）

按上面重导后仍跳，说明平台认的是「起始静止画面」，不是音频——那就**勿拼接**：
把封面直接做成正片第一段（渲染阶段就把封面画面当首段，`anim:false` 静态段 +
正常旁白/底噪），整片一个文件、零拼接点。代价是要重跑渲染，好处是没有接缝。

## 字幕时间轴保持不动

字幕烧在视频**内部**，前拼封面后整条字幕自动从封面段之后起显示，无错位。
（若字幕是外挂轨道再拼，才需要整体平移封面段时长。）

## 交付清单

海报 PNG 一律进交付清单，标注：
- 样式（`cover_styles` 的 key）/ 模式（web / image / hybrid）
- 尺寸
- 主题
- **字体名与授权协议**（走 `fxai-standard/references/06-字体与素材授权.md`）

## 硬规则

- 🔴 临时文件一律落系统临时目录下的 `fxai_burn/poster/`（ASCII 路径）：中文路径会让 `file://` 与 ffmpeg 滤镜解析失败
- 🔴 ffmpeg 走 `fxai-audio-video` 的 `av.ffmpeg_libass()`（conda 自带的没编 libass）；路径由那个技能决定，本技能不写死
- 🔴 **不许再用 `anullsrc` 拼首帧**，也不许 `concat -c copy` 拼（见上面两个致命点）
- 🔴 `fps` 参数必须等于源片帧率，否则整片重编码

## 片头信息贴片（封面铺首帧叠字，蒙版可选项）

铺封面进成片首帧时，若要在封面上叠「出品/剧名/集名/卖点/署名」信息，用 `intro_card.py`：

```bash
python intro_card.py --cover <封面.png> --title "我是主角，请给我外挂" \
  --ep "第1集 · 如来神掌" --hook "捡到一本神功，一掌拍倒老槐树" \
  --made "fxai-short-drama 智能短剧管线 · 呈现" --top "凤希AI · 智能短剧出品" \
  --mask 0.16 --out <项目>/片头信息贴片_ep1.png
```

- 排版固定：出品小字在上，剧名居中，集名紧贴剧名正下方，卖点+署名在底部；不做上下渐变。
- 🟠 **蒙版是可选项**：`--mask 0`（默认）不加深色蒙版；背景太亮/太锐利、叠字不清晰时传
  `--mask 0.1~0.2` 加**整块均匀淡蒙版**轻微压暗背景让文字清晰（不是上下渐变暗角）。
- `--crop-ratio 0.55` 默认从封面中下部裁背景，避开封面自带文字区；背景干净可调小。
- 字体只走 06 白名单（得意黑标题 / 微软雅黑正文），交付记录字体名与协议。
