# 02 · 网页模式版式（web / hybrid 的排版层）

> 主张怎么定、情绪取哪一拍、画幅与对比度门禁 → `07-叙事与信息层级.md`；信息块 ≥ 3 个的版式 → `06-图文信息图版式.md`。

## 封面设计统一规格（所有海报通用，写文案前必读）

### 第一要求：吸睛

封面在信息流里被划过的窗口极短，时长口径按 `05-封面模板库.md`「封面段时长」定。
判据：**划过去时能否让人停一下。**

### 吸睛元素清单（每张封面至少命中 2 项）

| 元素 | 怎么写 | 例 |
|---|---|---|
| **热点词点名** | 当下热门技术词/工具名直接写上封面 | 智能体、AI 全自动创作、ComfyUI |
| **数字前置** | 具体数字，不用"很多/一些" | 一年多、9 段、3 个技能 |
| **反差/反转** | 正面 → 代价两层（见下一节） | 活，它全干完了 / 人，反而没用了 |
| **身份标签** | 让对的人自动对号入座 | 创作者、剪辑师、想做副业的人 |
| **结果承诺** | 看完能得到什么 | 一句话、一条能看的片子 |
| **紧迫感** | 为什么是现在 | 跑通那天、到今天、2026 |

### 取舍

- 🔴 **吸睛 > 信息完整**：钩住人，后面的正文才有机会。
- 🔴 未命中吸睛元素的元素一律删。
- 🔴 主题词 ≠ 吸睛词：「AI 创作」是主题，「人反而没用了」是钩子。

## 封面文案结构（正面 + 反转）

规范与 `fxai-slide-video`（首帧即封面）+ `fxai-voiceover-script/references/03、04`
（共同经历式叙事 → 当时都这么干 → 翻转）同源，两者共用一套封面文案纪律。

| 层 | 写法 | 判据 |
|---|---|---|
| **胶囊 `--tag`** | 内容属性词 + 热点词，如「痛点 · 智能体」「干货 · ComfyUI」 | 属性词从 `观点/问题/痛点/结论/干货/避坑` 选；**点名当下热点技术词或工具名** |
| **kicker** | 共同经历式场景（述事），如「全自动创作跑通那天」 | ≤ 12 字；含中文数字更好；**不用疑问句、不抛结论** |
| **主标第一行（正面）** | 陈述"我们好不容易做到的那面"，白色 | ≤ 7 字（含标点） |
| **主标第二行（反转）** | 翻转，"但代价/真相是这一面"，强调色 | ≤ 7 字（含标点）；与第一行等宽，保证两行整齐不折行 |
| **chips `--keys`** | 抛出接下来要学 / 要做的具体事物 | 3 个为宜 |
| **副标 `--sub`** | 收一句，承上启下 | ≤ 14 字 |

🔴 **主标必须存在"正面 → 反转"两层**：单句陈述没有停留价值。
反面：标题只写「AI 全自动创作」这种主题词——那是文档名，不是钩子。
正面：第一行"活，它全干完了"（做到的面）+ 第二行"人，反而没用了"（代价的面）。

🔴 **标题行宽**：`|` 分行后每行 ≤ 7 字（含全角标点）。写文案时按 7 字配平；
超宽靠改字号补救会破坏整套视觉统一。

## 三段结构（固定）

1. **顶部胶囊**：内容属性词，不是标题复述（如「痛点 · 智能体」「古风短剧 · 第 3 集」）
2. **中部大标题**：`--title` 用 `|` 分行，**第一行主色、第二行起强调色（金色）**
3. **底部品牌条**：**默认不显示**（媒体平台不允许导流信息）；只有做品牌物料时
   显式传 `--brand` / `--site` 才渲染

可选层：`--kicker`（标题上方小字）、`--sub`（副标题）、`--keys`（关键词 chips）。

## 字号（768 宽基准，1280 高）

| 元素 | 字号 | 说明 |
|---|---|---|
| 主标题 | 88px / 800 | **≤ 8 字一行**，超过会折行破坏节奏 |
| 副标题 | 33px / 600 | 一行放得下 |
| kicker | 31px / 700 | 字距 5px |
| 胶囊 | 27px / 700 | 字距 3px |
| 关键词 chip | 28px / 700 | 3 个为宜 |
| 品牌 | 31px / 24px | 底部左右分列 |

横版（1280 宽）时主标题可到 96px，其余等比。

## 主题

主题 = `themes/*.css` 的 CSS 变量，**改配色只改变量**，不在 HTML 里硬写颜色：

| 变量 | 含义 |
|---|---|
| `--bg1/2/3` | 三段渐变背景 |
| `--ink / --ink2 / --ink3` | 主文字 / 次级 / 弱化 |
| `--ac / --acsoft` | 强调色（胶囊边框、圆点） |
| `--hl` | 标题强调行颜色 |
| `--rule1 / --rule2` | 分隔线渐变两端 |
| `--grid` | 网格纹理透明度 |
| `--font` | 字体栈 |

现有主题：`深色科技`（深色底 + 青蓝 + 金色，AI/科技/方法论）、`简约浅`（浅色底 + 深蓝 + 橙色，知识/职场/财经）。

## 硬规则

- 🔴 标题**不超三行**；`|` 分行后每行 ≤ 8 字
- 🔴 关键词 chips 不超过 4 个
- 🔴 品牌条默认不渲染；缺位由排版本身平衡
- 🔴 禁显清单：网址 / 微信 / QQ / 电话 / 邮箱 / 二维码 / 引导关注语 / logo 位
- 🔴 改样式改 CSS 变量，不内联硬编码颜色
