# 05 · 封面模板库（视频首帧）

封面不是一种解法。同一个主题，**生图人物 + 立体大字**和**纯文字卡片**在信息流里的
停手率差得很远，所以这里做成样式库：一条视频可以出多版挑，也可以按主题自动选。

代码 `cover_styles.py`，入口 `render(style, out_dir, name, bg=..., w=, h=, **kw)`。

## 六种样式一览

| key | 中文 | 长什么样 | 适合的主题 | 最吃哪一项 |
|---|---|---|---|---|
| `photo_big` | 写真大字 | 生图/剧照人物铺满，顶部两行立体大字（金+白），底部胶囊副标 | 人物出镜、故事、情感、人设口播 | 底图质量 |
| `closeup` | 人物特写 | 脸放到占半屏，两行大字压在下三分之一，顶部小胶囊 | 强人设、情绪、口播、站队表态 | 底图的脸 |
| `magazine` | 杂志白卡 | 底图虚化，底部米白卡片 + 黑字无描边 + 细金线 | 观点、认知、方法论、书单 | 文案的锐度 |
| `bold_block` | 撞色色块 | 黄/红/白三块错位拼贴，倾斜 2.4°，底图压暗成纹理 | 反差、结论、硬核干货、数据 | 三行字数要对齐 |
| `split` | 上下分屏 | 上半冷灰「旧貌」/ 下半暖亮「新颜」，斜切 + 橙金分割线 | 改造、前后、转折、升级 | 两张底图要不同 |
| `list` | 清单三条 | 主标一行 + 三条编号条目 + 底部小字 | 干货、教程、步骤、盘点 | 三条必须同构 |

`still`（剧照压底）不在这里：它要成片剧照，走 `poster.py --mode hybrid`。

## 两段式流程（**仅叠加层路线**，必须分开做）

🔴 本节是「无字底图 → HTML 文字层」的路线 B。**默认首选是生图直接把字画在画面上**（路线 A）：
版式排版说明由 `cover_prompt.py` 翻译进提示词第三段，命令见 `11` 册第八节。
只有「一次出多尺寸 / 后续要改字」才走下面这套两段式。

```
底图  →  文字层  →  铺首帧
```

1. **底图**：`fxai-scene-gen.gen_scene_image(prompt, role="<角色参考图相对路径>", w=1080, h=1920)`
   - 有人物才有「实拍感」，`role` 传角色库里的形象照（服务端相对路径，如 `modern_autumn/002.png`）
   - 🔴 提示词必须写明**人物在画面下方三分之二、上方留大面积干净空间**——不留白，字只能压脸
     （⚠️ 这是**叠加层路线**的留白要求；路线 A 让生图直接带字时，留白侧由
     `cover_prompt.py` 按 `text_side` 写成「文字区在某一侧、人物在反侧」，见 `11` 册第七/八节）
   - 底图一次生 2 张（工作台 / 窗边站立各一），分屏样式要两张不同的图
2. **文字层**：`cover_styles.render()`，底图只做 `object-fit:cover`，不动构图
3. **铺首帧**：`poster.attach_to_video(png, mp4, frames=10, fps=<源片帧率>)`

## 用法

```python
import sys
sys.path.insert(0, r"<skills>/fxai-poster")
import cover_styles as CS

# 指定样式
CS.render("photo_big", out_dir, "封面_写真大字", bg="底图.png", w=1080, h=1920,
          t1="一个人", t2="顶一支团队", sub="写稿 · 配音 · 出镜 · 剪辑 <em>全是 AI</em>")

# 自动选
key, score = CS.auto_style("一个人怎么用 AI 把整条片做完")
```

`auto_style()` 按 `STYLES[*]["keys"]` 关键词打分，最高的那项当选，全 0 分回退
`photo_big`（覆盖面最广）。**自动选只是起点**：给出分数表让用户一眼看出为什么选它，
用户改口就 `--style` 强制。

## 每种样式的关键参数

### photo_big
| 参数 | 默认 | 怎么调 |
|---|---|---|
| `s1` / `s2` | 282 / 196 | 两行**视觉等宽**优先：字数少的行给大字号 |
| `top` | 110 | 字顶到画面顶的留白 |
| `subtop` | 自动 | 副标位置，默认紧跟第二行往下 46px |
| 行1/行2 配色 | 金 / 白 | 金 = 做到的事，白 = 代价或反问，别反过来 |

### closeup
`btm`（字距底边，默认 176）决定字压到人物哪里——压到胸口以上会盖脸，往下调。
`s1/s2` 默认 214，超过画面宽会自动缩。

### magazine
`pos="bottom"` 贴底（默认，人脸留在上半）/ `"center"` 居中（会盖脸，只在底图没人时用）。
`hs=132` 是卡内主标字号，两行合计不超过卡片高 55%。底图 `blur(5px)`——再高人就糊成鬼影。

### bold_block
`fs` 不传则按最长一行**自适应**（`(画布宽 − 2·lx) / (字数 + 2·0.20)`），三行统一字号。
三行总字数差超过 2 个就会长短腿，写文案时按 3/6/3 或 4/6/4 配。

### split
`bg`（上半）/ `bg2`（下半）**必须给两张不同的图**，同图会变成同一个人上下叠两遍。
`s1/s2` 按字数自适应，一行最多 9 个字。`sh_ratio=.47` 是分界位置。

### list
`items` 正好三条，每条写成「**动作：结果**」，长度差不超过 4 字。`hs=96` 左右主标一行。

## 五个坑（都踩过）

1. 🔴 **CSS 里 `{X}` 占位用 `.replace("{{X}}", v)`，不用 `%` 格式化**：CSS 里 `%` 满地都是，
   `%(x)s` 要写成 `%%(x)s` 或 `%%`，错一个就整段样式失效。
2. 🔴 **模板占位后面必须带分号**：`bottom:{{vpos}}` 后面紧跟 `background:` 会把两条声明粘成
   一条无效属性，卡片直接跑到画面上方（排查半小时的那种）。
3. 🔴 **两层字必须 grid `grid-area:1/1` 叠**，用 `position:absolute` 会因行高/基线差出重影。
4. 🔴 **粗描边会吃字芯**：`-webkit-text-stroke` 居中描边，0.155em 在 282px 字上等于 44px，
   一半压进笔画内部，金色芯变窄、透出黑边显脏。上限 **0.135em**。
5. 🔴 **字号自适应要算 `_ew()` 视觉宽度**（全角 1.0 / 半角空格 0.45），直接按 `len()` 算，
   带空格的九字行会溢出画面。

## 硬规则

- 🔴 成图按 `09-质检门禁.md` 过三道门，必备要素按 `08-图片类型矩阵.md` 查。
- 🔴 **一张封面至少出 2 版**：主推 `photo_big` 或 `closeup`（有人），备选 `magazine` 或
  `bold_block`（无人/弱人）。只出一版等于没选。
- 🔴 **字压人不压脸**：脸是封面的一半资产。字必须落在地面以上、下巴以下，或天空留白里。
- 🔴 **主标两行，行字数差 ≤ 2**，靠字号配平视觉宽度，不靠加字凑。
- 🔴 **底图与文字层二选一**：走本库叠加时底图不落字（两层字会打架）；直接生图成封面时，文案按 `10` 册写进提示词，底图就不叠字。排版说明由 `cover_prompt.py` 按本节 8 种版式自动拼，别手写。
- 🔴 字体只用**得意黑 + 微软雅黑**；不许换第三款。要更厚靠描边/挤出层，不靠换字。
- 🔴 铺首帧 **10 帧**（**按帧定义，不按秒**；25fps 下 0.4s、24fps 下 0.4167s、
  30fps 下 0.333s——**帧数不变，秒数跟着源片帧率变**）、
  **`fps` 必须传源片帧率**（24 就传 24、25 就传 25；幻灯成片多为 24，手机片多为 30），
  否则触发整片重编码。`attach_to_video(fps=None)` 会自动探源片，别手填死值。
  🔴 出片段用 `-frames:v 10` 卡帧数，**别用 `-t 0.4`**：浮点取整会出 9 帧或 11 帧，
  而接缝位置正是这条规矩的关键（见下节「封面段时长」）。
  🔴 **首帧段音轨垫 25Hz 正弦（输入 -56dB，编码后约 -73dB），禁用 `anullsrc`**：
  全零采样会被平台判成空音频块切掉，表现就是「咔嚓跳一下、后面口型全错」。
  🔴 **别用粉噪，也别停在 -50dB**：粉噪是宽带噪声会「呼呼」；40Hz@-50dB 手机听不见但
  **带低音单元的音箱推得出来**，实测被用户连否两次。诊断、映射表与 Plan B（源片开头
  本来有人声时就别拼静音段）见 `04-接入视频首帧.md`。

## 封面段时长：定 10 帧（2026-10-26 抖音实测定案）

🔴 **定案：封面段 = 10 帧。** 25fps 下 0.4 秒。这是实测出来的落点，不是估的。

实测过程：抖音上传 10 帧封面版，主页动态封面**没有跳变**（观察到封面循环、没有切进
正片壳页）。这说明平台截取的长度**不超过 0.4 秒**，10 帧已能盖住。上限往下还能测
（5 帧 / 2 帧），但没必要——帧数越少，点进去那一刻封面越看不见，10 帧是「不闪」与
「还看得见一眼」之间的平衡点。

抖音**没有公布**动态封面的截取长度，也不用再查了：实践上 10 帧就是安全值。

### 机制

抖音有「动态封面」开关（**观众端** 设置 → 通用设置 → 动态封面，默认开）：开启后主页
作品封面会自己播视频开头一小段并循环。截取窗口比封面段长，就会把正片第一个镜头卷进来：
播到那儿 → 跳回封面 → 又播到那儿，一秒跳一次 = 闪。
**不是单帧本身闪，是循环接缝跨段。**

### 做法（精确 10 帧）

```bash
ffmpeg -loop 1 -framerate 25 -i 封面.png \
       -f lavfi -t 0.4 -i "sine=frequency=25:sample_rate=48000" \
       -filter_complex "[0:v]fps=25,scale=1080:1920,setsar=1,format=yuv420p[v];\
[1:a]volume=-56dB,afade=t=out:st=0.34:d=0.06,\
aformat=sample_fmts=fltp:sample_rates=48000:channel_layouts=mono[a]" \
       -map "[v]" -map "[a]" -frames:v 10 \
       -c:v libx264 -crf 18 -profile:v high -pix_fmt yuv420p -r 25 \
       -c:a aac -b:a 192k -ar 48000 -ac 1 片头封面_10帧.mp4
```

`-frames:v 10` 卡死帧数；音轨必须是垫音，见下节。

接正片走一次 `filter_complex`（不 concat copy），`+faststart`。
接完必查三项：`nb_frames` 应为 `10 + 原片帧数`；
封面段内 `max_volume` 在 -73dB 一档；第 11 帧起 `max_volume` 回到 -3dB 左右（人声）。

### 🔴 与 BGM 的先后：配乐铺在封面之后

封面段的垫音只是**防静音**，不是配乐。要让整条音轨从封面第一帧就响着 BGM，
顺序必须是 **铺封面 → 混 BGM**（BGM 是最后一道，作用于已成片；`mix_bgm` 是 `-c:v copy`，
只重编码音频）。反过来先混 BGM 再铺封面，这一截会被替换成垫音，第 0 帧就缺配乐。
规则全文见 `04-接入视频首帧.md` 1d 节。

因此上面那三项校验分**两个时点**看，两档都是对的：

- **刚铺完封面**：封面段 `max_volume` 在 −73dB 一档（垫音）。
- **混过 BGM 之后**：同一段应变成 **−26dB 上下**（有音乐）；仍是 −76dB 就说明顺序错了。

### 音轨：垫次声正弦，不留空

`anullsrc` 是**采样全 0**，不是低音量。平台转码器读到开头一段采样为 0，判成无效数据，
**从第一个有声采样点开始输出流**，画面却还从第 0 帧开始 → 音画基准错位，前面跳一下、
后面整条口型全跑（视频号最常见）。判据不是音量，是**有没有非零采样**。

但填充音必须同时满足「有采样」和「真听不见」，这两件事互相拉扯：

| 做法 | 封面段 `max_volume` | 结果 |
|---|---|---|
| `anullsrc` | -91.0 dB（全零） | ❌ 被切掉开头 → 音画错位 |
| 粉噪 -40dB | -42 dB | ❌ 全频段填满，**听得出「呼呼」风声** |
| 40Hz 正弦，输出 -50dB | -50 dB | ❌ **音箱推得出来，一片隆隆**（手机外放听不见） |
| **25Hz 正弦，输出 -72dB** | **-73 dB** | ✅ 95% 非零采样，且低于可闻阈 |

现版：`sine=frequency=25` + `volume=-56dB` → 编码后实测峰值 **-73.4dB**、均值 **-77.3dB**，
60Hz 以上全是 -90.3dB，能量全压在 25Hz 附近。末尾 60ms `afade` 淡出，接人声不「啪」。

🔴 **别按手机外放估听感**：40Hz 手机上确实没响应，但**带低音单元的音箱推得出**。
-50dBFS 折算约 55dB SPL，明显高于室内底噪（30~35dB），一开音箱就听出来。
表里 -50dB 那一版被用户连否两次（「呼呼呼」「我音箱放出来很大」）。

⚠️ **AAC 对低频有约 18dB 编码损失**，频率越低损失越大，改电平必须按映射重测：

| 输入电平 | 25Hz 编码后 max | 40Hz 编码后 max |
|---|---|---|
| -26 dB | — | -44 dB |
| -32 dB | — | -50 dB |
| -40 dB | -58 dB | -58 dB |
| -50 dB | -68 dB | -68 dB |
| -56 dB | **-73 dB** | — |
| -60 dB | -78 dB | — |
| -70 dB | -90 dB（量化归零） | — |

压到 -70dB 以下会被 AAC 直接量化成 0，等于回到 `anullsrc`，别踩。

### 发布时手动传封面图（可选，但建议）

手动传了封面图，主页缩略图就跟视频帧彻底解耦，多一层保险：

| 平台 | 入口 |
|---|---|
| 抖音 | 发布页「选封面」→「上传图片」 |
| 视频号 | 发布页点封面区域 →「上传封面」 |
| B站 | 稿件编辑页「更换封面」 |
| 小红书 | 发布页「封面」→ 本地图片 |

⚠️ **做测试时必须注意**：一旦手动传过封面图，主页那张缩略图就是你传的 PNG，
「闪不闪」由视频帧决定，手动选过封面的结论直接作废。测机制时一律不手动选封面。
