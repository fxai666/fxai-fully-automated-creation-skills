# 03 · 生图与叠加

## 生图

委托 `fxai-scene-gen` 的 `gen_scene_image(prompt, role=None, w, h)`。模型是千问2.1（qwen21），
原生吃中文提示词，**能直接把中文文案写进画面**。

🔴 提示词写法**只在 `10-千问2.1提示词规范.md` 定**（六段骨架、文字引号规则、人物绑定、尺寸），
本册不重复。写完先过 `qc.py prompt`。

🔴 **ComfyUI 走本机还是线上容器，本技能不管**：服务寻址（探活 / 切换 / 开机等待）
由 `fxai-workflow` 全权负责，本技能只按接口调用，不写任何服务地址。

## 文字放哪：生成在图上，还是叠加层

| 情况 | 走法 | 理由 |
|---|---|---|
| 文案固定、要一次成图（封面、海报、招牌、包装） | **写进提示词，让千问2.1 直接渲染** | 文字与画面同一次生成，光影质感自然融合，是主路径 |
| 文案要精确控制、后续要改字、要出多版本 | 底图留白 + 叠加层 | 改一个字不必重出图 |
| 信息图 / 大段文字 / 要对齐的表格清单 | 叠加层（HTML） | 层级与对齐靠语言描述控制不住 |

判据：**文案短（≤4 条）、一次成型 → 生在图上；文案要复用或精确调版 → 叠加层。**
两条路可混用：主标生在图上，副标与角标用叠加层补。

🔴 **封面走「生在图上」时，版式排版说明由 `cover_prompt.py` 写进提示词第三段**
（六段骨架 + 引号文案 + 位置/字号层级/字色字体/容器），不得手写、不得凭感觉写「加个标题」。
`cover_styles.py` 的 8 种版式与生图共用同一套语义，改版式两处一起改。命令见 `11` 册第八节。

🔴 **「画面无任何文字」只适用于叠加层路线**（底图要留白给后期落字，两层字会打架）。
把它写成通用生图口径是错的：那等于放弃了千问2.1 最擅长的文字渲染。

## 人物

| 情况 | 怎么写 |
|---|---|
| 人物出镜（封面主力） | 挂角色参考图（`role`），提示词里用 `<image1>` 绑定；**必须写着装**，参考图肩部以上无上衣 |
| 人物弱化为点缀 | 写「远景 / 仅占画面高度约 1/10 / 半透明如全息投影 / 位于画面右下角」 |
| 纯场景无人物 | 写「画面中无人」 |

🔴 多参考图必须逐个写 `<imageN>` 并绑定到具体人物，缺标签参考图会被直接忽略（判据见 `fxai-comfyui-image-gen` 05 册）。
🔴 着装红线：胸部与私密部位不裸露；透明薄纱、透视演出服、贴身礼服照常写，要「透而不露」。

## 混合模式（hybrid）

流程：生图（`bg.png`）→ 网页以 `body::after` 铺满 → 叠暗色蒙板 → 文字排版 → 截图。

| 参数 | 默认 | 怎么调 |
|---|---|---|
| `--overlay` | 0.55 | 底图太抢眼调低（0.4），文字看不清调高（0.7） |
| 底图尺寸 | 与海报同尺寸 | 生图按海报尺寸出，不做二次裁切 |

## 底图改用成片剧照（仅「贴剧」类例外）

🔴 **通用优先级见 `11` 册：底图优先由自家生图技能生成**（`fxai-scene-gen` /
`fxai-comfyui-image-gen`；本地 GPU 与云端容器都走 `fxai-workflow` 的同一个 HTTP 接口，
本技能不写服务地址、不自行拉起服务）。下面这条剧照路线是**例外**，不是默认：

仅当作品**已有成片且封面要贴剧**（短剧 / MV / 数字人）时，才按
**成片剧照 > 剧的组合图（角色四视图 / 场景图）> 重新生图** 取——成片已拍出人物表情和光，
抽一帧最贴剧。两条路线可以并用：生图技能出主视觉，剧照只作补充帧。

四步，缺一步就废：

1. **选帧按戏不按脸**：取表情最凶 / 动作最有指向性的那一帧（指着人、拍桌、翻本子），
   不取最好看的那一帧。选帧前先按秒抽 10 帧左右横向看，别只看一张就定。
2. 🔴 **裁掉烧录字幕带**：成片底部那条字幕是烧进画面的，`crop` 把它切掉再缩放——
   竖屏 768×1280 裁底部 **130~150px**（`crop=768:1150:0:0`），然后
   `scale=-1:1280` 放大、`crop=768:1280:(iw-768)/2:0` 居中取宽。漏裁的字幕会以残影留在封面底部。
3. **压暗 + 暗渐变蒙版**：`--overlay` 开到 **0.95**（剧照不压暗，白字在亮墙上立不住）；
   再叠一层 `linear-gradient(180deg, .34 → .06 → .28 → .82 → .95)`，
   顶部留人、底部压黑给字。
4. **文字压到底部暗区**：`.wrap` 用 `justify-content:flex-end`，标题块贴底——人物脸留在上半，
   标题落在下半暗区，两者不打架。

判据：缩略图大小下**一眼读出三行标题**，且能看清人物在瞪谁 / 指谁。两者缺一就是没做对。

- 三行主标时按**视觉等宽**配平，不是三行同字号：数字行 76 / 陈述行 68 / 反问行 88
  （6 字 / 7 字 / 6 字约等于同宽），靠 `.h1 em:first-of-type` / `.h1 em:last-of-type` 分别设。

## 硬规则

- 🔴 底图出图后先过 `qc.py post`，再人眼抽帧；底图不合格重出，不靠修图救。
- 🔴 挂角色参考图时写着装与 `<imageN>` 绑定。
- 🔴 文字层压在底图上时必须保证对比度：深色主题配高 overlay，浅色主题配低 overlay。
- 🔴 生在图上或叠在图层上的文案，出图后逐字核对，错字漏字重出，不修补。
