# 07 · 叙事与信息层级（跨模式通用）

封面和海报不是"放几个字"，是把一句话讲成有起伏的画面。本册管**说什么、按什么顺序说、怎样算说清楚**；
文案字段怎么写见 `02-网页模式版式.md`，信息块怎么摆见 `06-图文信息图版式.md`。

## 三幕结构（每张图都要有）

| 幕 | 功能 | 占比 | 视觉任务 |
|---|---|---|---|
| 设定 | 建立主角与常态，抛出问题 | 25% | 交代场景、建立代入感 |
| 冲突 | 放大代价，制造张力 | 40% | 对比、特写、节奏加速 |
| 解决 | 给出转折点 | 35% | 释放画面、单一出口 |

单张封面承载的是**一句话主张**，不是三幕全片。三幕决定的是：这张图落在哪一幕、情绪该是多少。
静态封面优先取**转折（强度 70）或高潮（100）**那一拍——平静的"设定拍"放进信息流没有停手率。

## 情绪节拍曲线

| 节拍 | 时间占比 | 强度 | 画面手段 |
|---|---|---|---|
| 常态 | 10% | 20 | 稳定构图、常规光 |
| 触发 | 15% | 35 | 近景、节奏起变 |
| 困境加深 | 25% | 15（谷） | 冷色、留白、慢下来 |
| 转折 | 15% | 70 | 光比反转、镜头推进 |
| 高潮 | 10% | 100（峰） | 最饱和画面、最强对比 |
| 新常态 | 15% | 65 | 回稳构图、主色收尾 |
| 行动号召 | 10% | 55 | 明确入口，单一动作 |

画面强度靠**三件事**拉开，不靠加元素：光比、饱和度、景别。三者同向调才成拍；只加字不加光比，强度上不去。

## 观众是主角，产品是引路人

| 不成立 | 成立 |
|---|---|
| 我方成立于 2010 年，拥有 300 项专利 | 你花了三小时对账，而它本该三分钟 |
| 品牌当主角，观众当看客 | 观众当主角，产品当引路人 |
| 罗列功能 | 呈现功能带来的状态改变 |
| 用形容词形容自己 | 用画面和数字证明改变 |
| 受众写"所有人" | 锁定一个能叫出名字的人 |

## 核心信息三测试

| 测试 | 通过判据 |
|---|---|
| 一句话 | 看完只能复述一句，且就是主标那句 |
| 静音 | 关掉声音，画面自己把这句说清楚 |
| 主角 | 句子主语是观众，不是我们 |

三条里有一条不过，说明主张还没想清楚，排版前先补主张。

## 三级信息层级

| 层级 | 停留 | 承载 | 字号关系 |
|---|---|---|---|
| 一级 扫读 | 0~3 秒 | 主标题、核心数字、主视觉 | 最大 |
| 二级 理解 | 3~20 秒 | 3~5 个版块标题 + 关键结论 | 中等 |
| 三级 细节 | 20 秒以上 | 数据块、图注、来源、方法 | 最小 |

- 一级必须在不读二级的情况下回答「这是什么」和「关我什么事」。
- 三级细节不得提到一级；标题承载观点，不承载数据集。
- 屏幕文字单行 ≤ 20 字，一次 ≤ 2 行。

## 视觉隐喻库

| 信息关系 | 隐喻 | 慎用 |
|---|---|---|
| 增长 | 阶梯、上升曲线、生长的树 | 火箭（过载） |
| 加速 | 齿轮、传送带、流线 | 闪电（暗示不稳定） |
| 连接 | 桥、节点网络、拼图 | 链条（暗示束缚） |
| 保护 | 盾、伞、容器 | 锁（暗示封闭） |
| 简化 | 收纳、筛、折叠 | 剪刀（暗示砍掉价值） |
| 洞察 | 灯、放大镜、透视 | 眼睛（过载） |

一张图只用一个隐喻；隐喻不得与数据冲突（3% 增长配火箭，是视觉上的说谎）。隐喻要过缩略图测试：200px 宽看不懂就换掉。

## 可读性门禁（出图前必过）

| 项 | 判据 |
|---|---|
| 正文对比度 | ≥ 4.5:1（实测取色，不靠目测） |
| 大字对比度 | ≥ 3:1（≥ 24px，或 ≥ 18.66px 且粗体） |
| 字压底图 | 必须有蒙版、描边或压暗层保证上述对比度 |
| 缩略图 | 200px 宽下主标可读；平台列表更小时靠主标字数控制 |
| 主体位置 | 人脸 / 核心物落在画面中间 60% 区域，边缘留给平台 UI 压盖 |
| 竖版安全区 | 上下各留 10~14% 不放关键信息 |
| 色彩表意 | 状态不只靠颜色，配图标或文字 |
| 静音可懂 | 不依赖声音与动效，静帧即可读懂主线 |

## 合规与包容复核（投前过一遍）

### 无障碍（WCAG AA 硬线）

- 图中文字与背景 ≥4.5:1，大字（≥24px 或 ≥18.66px 粗体）≥3:1；底图花就加遮罩。与「可读性门禁」同一把尺。
- 颜色单独表意会丢信息：涨跌、状态同时给箭头或文字，灰度化后照读。
- 关键信息静态可读，动画只做补充。
- 信息图配一段整体描述 + 每块一句，纯文本能线性读完。

### 文化复核十项

符号图形 / 色彩含义 / 人物服饰 / 语言称呼 / 数字与日期 / 场景环境 / 度量与币种 / 幽默双关 / 群体呈现 / 法律合规（肖像权、字体授权、行业宣称）。

### 色彩含义（国内为主，跨境按目标市场改）

| 色 | 中文语境 | 处理 |
|---|---|---|
| 红 | 喜庆、警示、上涨 | 金融数据按国内习惯表示上涨 |
| 白 | 素净、丧事 | 喜庆场景大面积白先用浅暖色替 |
| 金 | 财富、品质 | 与红搭配先对品牌调性 |
| 绿 | 安全、环保、通行 | 涨跌信息同时给箭头，单靠颜色会误读 |

### 人物呈现

- 选真正属于这个场景的人出镜，多元要落在真实身份上。
- 角色分工按真实情况给：照护者可以是任何性别，工程师同样。
- 讲日常生活时纳入不同年龄与身体能力的人物。
- 文化是背景，按真实环境还原，别当服装道具用。

## 画幅矩阵

| 用途 | 画幅 | 尺寸 | 关键约束 |
|---|---|---|---|
| 抖音 / 视频号 / 快手 | 9:16 | 768×1280 | 上下各 10~14% 安全区 |
| 录屏教程封面 | 16:10 | 1680×1054 | 与录屏成片分辨率对齐 |
| B 站 / YouTube 横版 | 16:9 | 1280×768 | 缩略图与标题一致 |
| 小红书竖图 | 3:4 | 1080×1440 | 首屏文字可读 |
| 方图 / IG Feed | 1:1 | 1080×1080 | 静音首帧即海报 |
| Pinterest | 2:3 | 1000×1500 | 首屏文字可读 |

🔴 **换画幅要重新构图，不得裁切母版**：竖版切横版会把人脸和主标一起切掉。

## 自检表

| 项 | 出现即判不合格 | 处置 |
|---|---|---|
| 主张数量 | 一屏两个以上主张 | 留一个，其余拆图或降为条目 |
| 信息层级 | 三级细节出现在主标题位置 | 降到二级或挪进图注 |
| 强度 | 全程一个强度，光比与饱和度同值 | 定一个峰值一个谷值，拉开光比 |
| 文案主语 | 主语是我方 | 改成观众视角 |
| 缩略图 | 200px 宽读不出主标 | 减字数或提字号，不靠加粗补救 |
| 对比度 | 取色低于门禁值 | 加蒙版或换字色，不靠描边硬顶 |
| 隐喻 | 一张图两个隐喻 | 删掉不承载主张的那个 |

## 硬规则

1. 🔴 主张没通过三测试，不得进入排版。
2. 🔴 一屏一个主张。
3. 🔴 封面优先落在转折或高潮拍，画面强度必须与所落节拍一致。
4. 🔴 对比度按取色实测判定，不按观感判定。
5. 🔴 换画幅重新构图，不得裁切母版。
6. 🔴 隐喻、图表、装饰只服务主张；不承载主张的元素删除。
