# 多参考：Ref2VA（全参考）+ 音频参考【重点，按规范写】

多参考工作流的 `1039` 节点 `lines_data` 里 `row[1]` 就是 H3 **六段式**提示词。规则：

- **小标题用英文**（**MV / 数字人口播分支**的管线口径）：`subject_definitions` / `summary` / `retention_analysis` / `detailed_description` / `overall_soundscape` / `non_diegetic_music`。
  > ⚠️ **短剧分支不是这一套**——`fxai-short-drama` 的六段小标题是**中文**（`主体定义 / 摘要 / 延续分析 / 详细描述 / 整体音效 / 非叙事音乐`，见 03 册）。
  > 两套各自是所在管线的原生口径（`build_ref2va_prompt` 走英文、`build_lines_data` 走中文），**各按各的走**；H3 本身两种都收，但本地工具按各自管线的名字切段，串了会切不出段。
- **内容用中文**（我们惯例；也可全中文，H3 支持）。只有画面可见文字、被要求复述的歌词保留原样。
- `row[2]` = `"<Picture 1 人物图>,<Picture 2 场景图>"`（相对 `fxai/image/` 的字符串，人物图在前、场景图在后）。
- ⚠️ `detailed_description` **第一行固定是触发词行**（见 `07-触发词挂载规范.md`）：有运镜诉求写 `camera motion`；打斗镜加 `prfight1`（终结镜再加 `prfin1`）；**文戏镜整行不写**。触发词行独占一行、全小写、逗号分隔。

## 3.1 四种标签

| 标签 | 含义 |
|---|---|
| `<Subject N>` | 从参考素材抽象出的**可复用可见内容**（人物/服装/场景/风格） |
| `<Picture N>` | 参考图**作为具体帧/构图锚点** |
| `<Video N>` | 参考视频（我们基本不用） |
| `<Audio N>` | 被复制或引用的音频信号（我们的原音频） |

> ⚠️ **头号失败原因**：上传了参考图却从没在提示词里定义/引用它 → 模型不知道保留什么 → 人物/场景遵循度低。人物图必须写进 `<Subject 1>` 且注明 `in <Picture 1>`；场景图写进 `<Subject 2>` 且注明 `in <Picture 2>`。

## 3.2 六段写法（以我们的中文歌词 MV 为例）

```text
subject_definitions:
<Subject 1> 是 <Picture 1> 中的人物。
<Subject 2> 是 <Picture 2> 中的场景。
<Audio 1> 是音乐视频中的原声演唱音轨，作为 <Subject 1> (S1) 的音色参考和目标视频的完整最终音轨。

summary:
[reference generation + audio reuse] 目标视频展示 <Subject 1> 在 <Subject 2> 中演唱。<Picture 1> 作为人物外观参考，<Picture 2> 作为场景背景参考，<Audio 1> 作为原声音频。

retention_analysis:
<Subject 1> (appears in [Shot 1]): fully_preserved - 保留人物身份、发型发色、服装样式与颜色、裤装、鞋履。
<Subject 2> (appears in [Shot 1]): fully_preserved - 保留场景的建筑、陈设与物品。
<Audio 1>: fully_copy - <Audio 1> 作为目标视频的完整最终音轨直接复用。

detailed_description:
camera motion
目标视频采用电影感、自然主义的音乐视频风格。
[Shot 1] 中景镜头建立 <Subject 2> 作为场景背景。<Subject 1> (S1) 站在画面略偏中心位置，面向镜头，表情温柔专注。镜头以缓慢的轻微推近（slow push-in）跟随人物，幅度小、速度慢。她轻轻吸气，仿佛在回忆旋律；At 00:02.000, 她开始演唱，嘴唇与 <Audio 1> 中的歌声精准同步开合，身体随节拍轻轻摇摆，右手随乐句做出柔和而富有表现力的手势；结尾随最后一个音符自然放松，定格为柔和宁静的微笑。

overall_soundscape:
来自 <Audio 1> 的复制环境声音与歌声贯穿全程。

non_diegetic_music:
无
```

### 3.2.1 🔴 主体定义只指认，类目归延续分析（铁律 17，全局统一）

上文那句主体定义**只有一句身份词**，这是硬要求不是风格偏好：

- 主体定义：`<Subject N> 是 <Picture M> 中的<身份词>。` —— 到句号为止，**句号后不追加任何内容**。
  身份词可以具体（古装年轻女子 / 临水木构戏台），但止于「是什么」。
- 保留类目**全部写进延续分析**：人物 `保留人物身份、发型发色、服装样式与颜色、裤装、鞋履。`；
  场景 `保留场景的建筑、陈设与物品。`；道具 `保留道具的形制、材质与颜色。`
- **两段都不写**具体颜色（月白、鸦青、浅杏色）、款式（窄袖、束腰短甲、半扎低丸子头）、材质（棉质、烟罗纱）、
  具名物件细节（断纹素银簪、扇骨九节第三节旧裂纹）。
- **详细描述里不复述外观**，只写 `<Subject 1> (S1)` 编号 + 动作。

原因与完整禁用词表见 04 册「铁律 17 展开」。一句话：新底座服从文字，字里写什么就以为什么，
参考图的服装会被文字覆盖（实测同一参考图，写细节版深色像素 44.8%、只留身份词版 25.2%）。

> 场景定义的极简 ≠ 不写场景里发生的事。**场景外观**交给参考图（不描写）；
> **这一段文案该有的动作与道具交互**仍要写进 `detailed_description`（「指着柱状图」「端起马克杯」），
> 那是动作不是外观——写动作是对的，写「暖黄台灯、米色瓷砖」是错的。

## 3.3 🔴 主体归属：台词与音频只挂人物，场景不挂

Ref2VA 送进去的参考图一定有「人物在前、场景在后」两组，主体编号因此固定：
`<Subject 1>~<Subject K>` = 人物，`<Subject K+1>` = 场景（再往后是道具）。

| 内容 | 挂谁 | 说明 |
|---|---|---|
| **音频音色** | 说话/演唱的那个人物 | `<Audio 1> …作为 <Subject N> 的音色参考`。多人就各挂各的 |
| **台词 / 唱词** | 正在讲的那个人的**定义句** | `<Subject 1> …她是画面里正在讲话的人，讲的内容是：<台词>` |
| **环境** | 场景主体 | 只有空间、光、陈设、机位；**不出现任何台词、唱词、音频字样** |

🔴 **场景主体不许挂台词，也不许挂音频**——场景是环境，不是发声体。

> ⚠️ **本册只服务一条工作流：MV 与口播（数字人）共用**——两者都是
> **原始音频 `fully_copy`**（整条复用作成片音轨），提示词格式与挂载规矩完全一致。
> 短剧走 `fxai-short-drama` 的另一套（中文六段小标题、音频多为音色参考），**不与本册混用**。
>
> ⚠️ **送进去的永远是原始音频，不是逐句合成的短句音频**。上面「台词挂人物」
> 指的是**告诉模型这一段画面配的是什么内容**——音频仍然只有一条，
> 由 H3 自己按 9.41667 秒切成 N 段（段数用 `av.h3_segment_count(时长)` 算）。
> 别把「每段有台词」误解成「每段各有一条音频」。

**为什么这条是硬规矩**：把台词拼进 `scene_desc` 后，它落进 `<Subject 2>`（场景背景图）的定义句，
模型读到的是「人物没内容、场景在讲一整段话」，与 `detailed_description` 里的
「口型逐字跟随 `<Audio 1>`」正面打架。实测后果：**15 段每一段人物嘴都是闭的**。
修法是把台词从场景描述里拿出来、挂回人物主体，一句不用改动作链就恢复了。

⛔ 反例（场景挂台词）：
`<Subject 2> 是 <Picture 2> 中的场景背景图，办公工位……；她正在讲：今天下午我对着空白文档坐了很久`

✅ 正例（台词归人）：
`<Subject 1> 是 <Picture 1> 中的人物，年轻女子……。她是画面里正在讲话的人，讲的内容是：今天下午我对着空白文档坐了很久。`
`<Subject 2> 是 <Picture 2> 中的场景背景图，办公工位……，画面中不出现任何人物。`

程序侧：`fxai-audio-video.build_ref2va_prompt(..., lines=…)` 只往人物主体写台词；
`fxai-audio-video.audit_subject_binding()` 逐段校验，门禁见
`fxai-digital-human-video/scripts/preflight.py` ★12。

## 3.4 retention 标记（固定英文值，别写错）

可见内容：

| 标记 | 含义 |
|---|---|
| `fully_preserved` | 角色/场景被完整保留 |
| `partially_preserved` | 仍用，但部分特征被改 |
| `attribute_transfer` | 特征转移到另一主体（如只借服装不借人） |
| `weak_reference` | 只保留风格/类别/氛围的宽泛相似 |

音频：

| 标记 | 含义 |
|---|---|
| `fully_copy` | 完整源音频作成片最终音轨（我们用这个） |
| `partially_copy` | 只复制部分时间线/层 |
| `reference` | 不复制，只参考音色/节奏/风格 |
| `weak_reference` | 只保留类别/氛围相似 |

> ⚠️ `retention_analysis` 里只写 `<Audio 1>: fully_copy`，带上 `(Sx)` 会让 H3 重新解释音频用途。

## 3.4 代码落地

公共件 `fxai-audio-video` 已封装好，无需手写六段：

```python
import audio_video as av
# 多参考：人物图 char_rel + 场景图 scene_ref，提示词由 char_desc/scene_desc 驱动
# ★ char_desc / scene_desc 只传「身份词」（铁律 17），类目清单由函数写进延续分析
p = av.build_ref2va_prompt(char_descs=["古装年轻女子"],
                          scene_desc="临水木构戏台",
                          kind="sing")     # MV 演唱
p = av.build_ref2va_prompt(char_descs=["人物"],
                          scene_desc="室内场景",
                          kind="speak")    # 数字人口播
```

`kind` 决定音频身份与动作措辞（`sing` 演唱 / `speak` 讲话），六段结构与图片顺序完全一致。
函数输出：

```text
subject_definitions:
<Subject 1> 是 <Picture 1> 中的古装年轻女子。
<Subject 2> 是 <Picture 2> 中的临水木构戏台。

retention_analysis:
<Subject 1> (appears in [Shot 1]): fully_preserved - 保留人物身份、发型发色、服装样式与颜色、裤装、鞋履。
<Subject 2> (appears in [Shot 1]): fully_preserved - 保留场景的建筑、陈设与物品。
```

不传时走默认身份词（`人物` / `场景`）。传成旧写法「身份词，脸、发型…」也能用——函数只取第一个逗号前的身份词。

> 🔴 **`kind="speak"` 的说话写法照 01 册 2.3「入画即开口，全程不停嘴」**——
> 入画第一帧就在说、入场/位移句自带「讲」、位移句排在说话句之后。**本册不复写第二遍。**
`mv_pipeline.build_ref2va_prompt` 是同一函数的 `kind="sing"` 转发，MV 侧照旧用即可。

## 模式映射（管线全景）

| 模式 | 工作流内走的模式 | 提示词格式 | 参考素材 | 音频 |
|---|---|---|---|---|
| **单场景** | **FL2VA（首尾帧）+ 音频参考** | **FL2VA 三段式** | 1 张「人物已在场景里」的图 | 原音频 |
| **多场景** | **FL2VA（首尾帧）+ 音频参考** | **FL2VA 三段式** | 多张不同背景图（同人物） | 原音频 |
| **多参考** | **Ref2VA（全参考）+ 音频参考** | **Ref2VA 六段式** | 人物四视图 + 独立场景图 | 原音频 |

> ⚠️ **三条铁律（用户规定）**
> 1. **三个工作流全部带音频参考**，所以 H3 的独立纯文/纯图分支我们都不用。
> 2. **音频 = 原音频**：提示词里不另行设计音轨。`<Audio 1>` 标为 `fully_copy`，`overall_soundscape` 只写「沿用原音频」，`non_diegetic_music` 写「无」。
> 3. **单场景/多场景按 FL2VA 首尾帧格式写，多参考按 Ref2VA 六段式写**——两种格式各自成篇、一篇只用一种。无论哪种格式，**提示词都必须契合这一段文案在讲什么**（见下）。

> ⚠️ **写几条提示词 = 音频被切成几段**。H3 只接受「17k+5 帧」的时长，
> 传「平均分段时长 = 10」时每段实际 **9.41667 秒**，尾段不足 3 秒并回上一段。
> **段数必须用公式算（`av.h3_segment_count(时长)`），`ceil(时长/10)` 只是估值**——估错会让后面几段复用第一条提示词。

## 音频处理铁律：原音频，不描述（逐字段写法）

- `subject_definitions` 里：`<Audio 1> 是音乐视频中的原声演唱音轨，作为 <Subject 1> (S1) 的音色参考和目标视频的完整最终音轨。`
- `retention_analysis` 里：`<Audio 1>: fully_copy - <Audio 1> 作为目标视频的完整最终音轨直接复用。`
- `overall_soundscape`：`来自 <Audio 1> 的复制环境声音与歌声贯穿全程。`
- `non_diegetic_music`：`无`
- ⚠️ **绝不自创音色形容词**（别写"温柔女声""清澈嗓音"）——音色完全复刻原音频，只在后面补**表演方式**（如「克制的演绎」）。
