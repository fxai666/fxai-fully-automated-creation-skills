# 门禁模块维护口径（源码 + 兜底编译件）

> 适用：`fxai-h3-video-prompt/h3_format_gate.py`。MV（`sing`）、数字人口播（`speak`）、短剧三条线在提交前共用这一份校验。

## 1. 形态与入口

门禁以**可读源码**随目录同行，编译件只做兜底。

- 唯一事实源：技能根目录 `h3_format_gate.py`。`import h3_format_gate` 优先命中它。
- 兜底编译件：同目录 `h3_format_gate.pyc`（与源码同名、同处根目录）。源码缺失时解释器按 legacy
  sourceless 规则加载它——**这是唯一可用的兜底位置**；`__pycache__/` 内的 `.pyc` 只作源码的加速缓存，
  单独存在时不可导入。
- 两者须同步：改完源码即重编根目录 `h3_format_gate.pyc`，兜底件与源码版本落差会造成行为不一致。
- 导出两个入口：

| 入口 | 用途 |
|---|---|
| `audit_ref2va_six_segment(prompts)` | 多参考 Ref2VA 六段式校验，MV / 口播 / 短剧共用 |
| `audit_short_drama_six_segment(shots, allow_chinese=True)` | 短剧分镜校验（旧分支） |

返回值：违规描述字符串列表，空列表即通过。调用方按「非空即拦截」处理。

## 2. 解释器绑定

- 源码 `.py` 与兜底 `.pyc` 须用**同一解释器版本**，跨版本加载即 bad magic，属预期行为。
- 当前环境：CPython **3.13.14**，`importlib.util.MAGIC_NUMBER == b"\xf3\r\r\n"`。
- 历史环境曾用 3.12.3（magic `b"\xcb\x0d\x0d\x0a"`）；`_backup/` 里的旧兜底件是 3.12 版，用 3.13 直接加载会报 bad magic。
- 重编命令（用当前解释器）：`python -c "import py_compile; py_compile.compile('h3_format_gate.py', cfile='h3_format_gate.pyc', doraise=True)"`。

## 3. 改动与校验流程

1. 改完源码先冒烟：`import h3_format_gate` 并调用
   `audit_ref2va_six_segment([<一段真实提示词>])`，确认可加载且返回列表。
2. 提交前用真实项目提示词做回归：正例返回空列表，反例逐条命中预期违规。
3. 重编兜底编译件：`python -c "import py_compile; py_compile.compile('h3_format_gate.py', cfile='h3_format_gate.pyc', doraise=True)"`，
   产物落技能根目录，与源码同一解释器版本。
4. 语义改动后与 `_backup/h3_format_gate.pyc.good-*` 做差分：同一批提示词喂新旧两件，违规集合须一致。

## 4. 损坏后的恢复

- 源码损坏：从 `_backup/` 同名 `.good-*` 派生件或项目版本库取回；改动量大时按
  `_backup/h3_format_gate.pyc.good-<时间>` 的行为做等价重建。
- 源码临时不可用：把 `_backup/h3_format_gate.pyc.good-<时间>` 拷回根目录并更名 `h3_format_gate.pyc`，
  即可继续跑通门禁；随后补回源码并重编该件，让两者回到同一版本。
- 兜底编译件损坏：按第 3 节第 3 步重编，再跑冒烟。
- `_backup/*.bak-20261123-*` 只含短剧旧版校验（无 Ref2VA 能力），仅供追溯，勿用于恢复。
- 2026-11-24 的等价性基线：`_backup/h3_format_gate.pyc.good-20261124-100518`（45,001 B），
  以 `林间信` 20 段真实提示词校验，与现行源码的违规集合一致（均为 0）。
  当日的重建件经五入口 820 次调用差分 + 13,500 次模糊差分，零差异。

## 4.1 音色定义行白名单（2026-11-27 新增）
- 🔴 整行必须与模板精确匹配：只查行首会放过同义重复句（标准句后另加一遍「作为…参考」）。白名单判据：
  - **主体定义**：`_AUDIO_DEF_STD` 整行精确匹配 `<Audio N> 是 <Subject M> (Sx) 的参考音色。`，多写同义重复句或没挂 `(Sx)` 都拦。
  - **延续分析**：`_PRESERVED_AUDIO` 从只认 `fully_copy` 扩到四种官方标记（含 `reference`）；音频行带 `(Sx)` 单独提示拦。
- 标准写法唯一事实源：`fxai-short-drama/references/01-提示词规范.md` §音频绑定。
- 冒烟基线（正例 0 违规、三个反例各命中一条、fully_copy 兼容放行）已验证源码与根目录 `.pyc` 行为一致。

## 4.2 元描述 / 否定式与台词行内动作（2026-11-28 新增）

- **⑬ 元描述 / 否定式强调**：`_META_NEG_RE` 命中否定式定格强调（否定词 + 定格 / 静止 / 不动 / 木头人）或全称量词 + 「都在动」结构即拦。只查叙述正文（`_strip_d_tags` 去掉 `<d>` 台词），台词里的否定词放行。
  - 根因：H3 没有负向字段，这类元描述会被当画面内容执行、还会被念进对白（《带问题来》第 1/6/7/9/10 镜结尾胡言乱语实证）。
  - 正解：背景动作只写正向、逐类给具体动作，不写全称量词 + 否定式。唯一事实源 `fxai-short-drama/references/01-提示词规范.md` §背景里的角色（该节不含可照抄文案）。
- **⑩b 台词行内同行动作**：`_D_TAIL_ACTION_RE` 命中 `</d>。` 后同一行还有文字即拦。
  - 正解：另起 `At MM:SS.mmm, 紧接着，<Subject N> ……` 行并给新时刻；`</d>。` 是台词硬边界。
  - 🔴 调用方若自行做 `refit_timing_runtime` 之类时间轴重算，**必须保留纯动作行**：只留含 `<d>` 的台词行、把动作行整条删掉，拆行改动等于白做（`run_zbyl1_ep1.py` 已按此保留动作行）。
- 冒烟基线：旧版 10 镜命中 21 条（10×2 元描述 + 镜2 同行动作）；修正后 0 条；台词对齐仍为 21/21。
- 本次是**语义新增**（不是等价重建），与 `_backup/*.good-*` 的违规集合差分预期不同，改用上述正负例冒烟。
