# MiniMax H3 单发声者音频驱动唇形同步规范【模型级唯一事实源】

> **适用范围**：MiniMax Hailuo H3 **多参考 Ref2VA**（六段式）+ 提供原音频（audio reuse / `<Audio 1>` 标 `fully_copy`）的生成分支。
> **模型边界**：本册规则归属 H3 底座；其他视频模型的唇形/配音语义各自成册，不与本册混用。
> **默认模型**：当前管线默认 H3，凡 MV（`sing`）、数字人口播（`speak`）走 H3 多参考音频复用时，一律以本册为准。
> **职责边界**：本册只管多参考分支里「画面里谁开口、唇形怎么跟音频」这一层语义。
> 六段结构格式见 02 册，触发词见 07 册，分段数与字段写法见 `fxai-audio-video`；
> 业务特化（MV 的双人同框与封面首帧、口播的手势与入场机位）见 `fxai-mv-pipeline/references/10`、`fxai-digital-human-video/references/03`。
> 景别不在本册约束范围：按镜头叙事需要选，需目视验唇形时让唇形可辨即可，详见 `fxai-mv-pipeline/references/10` §3.4.1。

---

## 0. 一句话内核

画面里可以有单人、双人或多人，但**唇形驱动只绑定一个指定的人**：
该人编号固定为 `<Subject 1>`、标 `(S1)`、绑 `<Audio 1>`，从第一帧到音频人声结束全程开口，
唇形逐字跟随音频波形；画面里的其余人双唇自然闭合，只做表情与肢体回应，不做口型。

人数是场景自由度，发声者唯一是硬约束——「指定一个人开口」指的就是这套绑法。

## 1. 四条铁律（缺一条唇形就对不上）

| # | 铁律 | 判据 |
|---|---|---|
| 1 | **提供原音频 = 没有台词**，`详细描述` 里不得出现 `<d>` 块 | 音频 1:1 复用成成片音轨，H3 把波形唇形贴到指定人脸上；写 `<d>` 会让模型二次生成人声，与 `fully_copy` 冲突 |
| 2 | **首帧与末帧只要在响，就都在唱/说状态**；第一个事件不得带时间戳 | 官方 `full-reference-en.txt` §5.1：`[Shot 1]` 无时间戳；音频整段已存在，首帧声音就在响，末帧声音未停就得继续唱/说——两端都以音频为准，不以参考图的静态表情为准（见 §3.3） |
| 3 | **整段唱/讲写一句全程同步**；时间戳只在段内静音/间奏时用 | 只有一个覆盖 0→段尾的人声窗口 = 一句写死；有断档才按 `At MM:SS.mmm` 切唱与不唱 |
| 4 | **唇形只挂唯一发声者 `(S1)`**，其余在场者闭唇 | `<Audio 1>` 音色参考与 `(S1)` 只挂 `<Subject 1>`；给旁人写任何「开口/唱/讲」都会抢走唇形驱动 |

## 2. 唯一发声者的绑定写法

- 发声者固定排在人物编号第一位：`<Subject 1>` 标 `(S1)`，`<Audio 1>` 的身份句挂在它身上。
- 场景/道具/其余人物照常建 `<Subject 2>..K`，只参与构图与表演，不参与唇形驱动。
- 演唱/讲话句写清「只有 `<Subject 1>` 一人开口」，其余人写「双唇自然闭合、有表情与肢体回应」。
- 无人声段（前奏/间奏/尾奏）：整段不写开口与对口型，`<Audio 1>` 写成纯器乐、**不挂 `(Sx)`**。

指定谁开口 = 把谁放成 `<Subject 1>`；画面人数不影响这套绑法。

## 3. 时间轴按人声窗口写

### 3.1 整段有人声（绝大多数段）→ 一句全程同步

`vocal_windows` 只有一个、从 0 覆盖到段尾时，起手句之后直接跟一句：
`<Subject 1> (S1)` 面向镜头持续开口，唇形从第一帧到最后一个音全程逐字跟随 `<Audio 1>` 波形开合，
只有这一人开口；表演动作句接在后面。

此类段不写起唱时刻、收束时刻、起承合时间轴。H3 拿到 `fully_copy` 音频自行把唇形贴满整段，
额外时间锚点等于喂给模型「这段时间才开口」的暗示。

### 3.3 末帧状态：只要在响就以音频为准，不以参考图为准

首帧与末帧谁决定唇形，取决于那一刻音频在不在响：

- **首帧有声音** → 第一帧就在唱/说，不写吸气、闭唇过渡、起唱时间戳。
- **末帧有声音** → 最后一帧仍在唱/说，唇形继续跟随音频，收尾句写「末帧仍在演唱状态，与声音同步自然收尾」。
  参考图常是闭嘴的静态照，FL2VA 首尾帧机制会把末帧往参考图状态回拉；只靠参考图，末帧就会闭嘴定格。

分段生成时，每段尾帧是下一段的首帧锚点（FL2VA 段间传递）。尾帧写成闭嘴静态表情，
下一段就从闭嘴重新开口，衔接断裂。因此**每段的末帧都要保持「仍在唱/说」的自然神情**——
「自然」指演唱中的放松神情，允许微笑，重点是嘴随音频开合、不提前停。

判据：抽末段末尾几帧（如 52/54/55/末帧），嘴应保持开合变化，不得收成闭嘴定格。

### 3.2 段内有静音/间奏 → 才用时间戳分段

判据：`vocal_windows` 有断档、起点不为 0、或终点不到段尾。

- 段首静音：写「随伴奏轻轻呼吸、双唇自然闭合」，到真实起点 `At MM:SS.mmm` 开口——这是唯一允许的时间锚点类型。
- 句中静音：写「音频静音，双唇自然闭合换气、随伴奏轻轻呼吸」。
- 唱/讲到该窗口终点自然停，下一个 `At MM:SS.mmm` 再开口。
- 全段无人声：只写肢体表演 + 双唇闭合，不写演唱/讲话/对口型。

## 4. 硬约束（提交前必过）

- `<d>` 台词块：与 `fully_copy` 打架。
- 段首「闭唇过渡」「1 秒安静站定」、段尾「提前收束闭唇」：让人声在响的区间出现闭嘴。
- 首尾安全区常量人为拉起（如把 head/tail guard 设为非零）：同上。
- 第一个事件带 `At 00:00.000`：等同给模型「此前可不唱」的许可。
- 给非发声者写「开口/唱/讲」：抢唇形驱动。
- `摘要` 段写 `<Picture N>`：H3 当作具体帧锚点，把白底参考图顶成首帧。图与人的绑定只在 `主体定义` 段。

## 5. 六段格式里的落点（与 02 册对齐）

| 段 | 本册相关的写法 |
|---|---|
| 主体定义 | 发声者排第一位、标 `(S1)`；`<Audio 1>` 身份句挂它；其余人只写身份词 |
| 摘要 | `[reference generation + audio reuse]` 开头；不得含 `<Picture N>`、`(Sx)`、`fully_copy` 字样 |
| 延续分析 | 每个标签一行通用型白名单模板（完整沿用 `<Picture N>` + 不新增不替换）；音频 `fully_copy`；模板源 `fxai-audio-video/audio_video.py` 的 `KEEP_*_TPL` |
| 详细描述 | 触发词行 → 首帧钉死句 → `[Shot 1]` 时间轴（铁律 1~4）→ 运镜句 |
| 整体音效 | 写「来自 `<Audio 1>` 的复制…贯穿全程」；音色形容词留空 |
| 非叙事音乐 | `无` |

六段小标题一律中文（`主体定义 / 摘要 / 延续分析 / 详细描述 / 整体音效 / 非叙事音乐`），内容全部中文；
官方固定标记（标签、`fully_copy`、触发词、摘要前缀）保留原样。

---

## 6. 自检清单（门禁口径）

① 唯一发声者标 `(S1)`、其余在场者闭唇；② 无 `<d>` 块；③ `[Shot 1]` 第一事件无时间戳、首帧开口；
④ 全段人声 = 一句全程同步；有静音才按 `vocal_windows` 用 `At MM:SS.mmm`；⑤ 无段首闭唇过渡、无提前收束；
⑥ 摘要段无 `<Picture N>`；⑦ 延续分析整行通用型白名单模板；⑧ `<Audio 1>: fully_copy`、音色词留空、`非叙事音乐: 无`；
⑨ 首末帧只要音频在响就都在唱/说状态，末帧不以参考图静态闭嘴表情收尾（§3.3），分段时每段尾帧保持「仍在唱/说」以衔接下一段。
任一条不过 → 不提交渲染。
