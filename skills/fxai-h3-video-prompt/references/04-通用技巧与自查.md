# 通用技巧、对接与自查

## 4. 通用技巧（单/多/多参都适用）

1. **运镜只写一条主线**：一个短镜头一个主运镜足矣。类型 + 幅度 + 速度 + 跟拍对象写全：
 `镜头以缓慢的轻微推近（slow push-in）跟随人物，幅度小、速度慢。`
 ❌ 空话：`dynamic camera` / `cinematic camera`（没写运动类型/方向/速度=没写）。
 常用：locked（固定）/ slow push-in（慢推）/ tracking（跟拍）/ orbit（环绕）/ handheld（手持）/ aerial reveal（航拍展开）。

2. **动作写成轨迹，不是动词标签**：别写"她招手"，展开成「抬手→手腕翻转→停顿→随乐句落下」。远处人物务必写明「全程持续移动」，否则会卡住。

3. **给每个参考分配角色，并说明「要保留什么、忽略什么」**：
 多参考时明确：`<Picture 1>` 只提供人物外观、`<Picture 2>` 只提供场景氛围；若两个图都含光线，指明以谁为准。最稳的写法是「分离不变项与可变项」——保留面部身份/发型/服装，允许姿态/构图变化。

4. **分离身份与动作**：写「保留同一面部身份、利落短发、白色长风衣贯穿全片」，而不是笼统的"保持人物一致"。面部占画面小的时候，先用全景建场、再用中/近景让身份读清。

5. **一次只改一个变量**：先定 5 秒版，动作→运镜→光线/声音逐次调，保留可用片段再延长时长。

6. **声音是可观测时间线的一部分**：环境声、物理声（衣料/脚步/风）、台词/演唱都按可见事件同步写；音乐只写观众能听到的配乐（我们没有，写「无」）。

7. **一个镜头只做一件事**：一个镜头塞过多同时发生的动作、互相冲突的运镜组合（orbit+zoom+handheld 同句）、靠生成排版出文字（易错，字幕后期加），这三种都算超载。

## 6. 与 fxai-mv-pipeline 的对接

| fxai-mv-pipeline 产物 | 这里当什么 |
|---|---|
| 单场景/多场景的「人物+场景」图 | FL2VA 首尾帧锚点 + 原音频（**保持工作流默认**） |
| 多参考：人物四视图 + 独立场景图 + 音频 | Ref2VA：`<Subject 1>`(in `<Picture 1>`) / `<Subject 2>`(in `<Picture 2>`) / `<Audio 1>`（原音频，`fully_copy`） |
| Yue2 生成的音乐 | `<Audio 1>` 原音频；唱词逐字来自原歌词、嘴型同步 |

> ⚠️ **画风归属**：本技能里「六段小标题」（**短剧中文 / MV·口播英文**，见 02 / 03 册）只适用于 H3 视频提示词本身。**给 AI 生图的中文提示词仍用中文**（三/四视图只写穿搭，图片处理写完整描述）。

## 7. 写好后的自查

① 每个重要参考图都在提示词里被分配了用途（人物图→Subject1/Picture1，场景图→Subject2/Picture2）？② 人物身份/服装是否稳定？③ 每个主要动作是否有起因—推进—反应—终态？④ 运镜是否具体且与动作绑定？⑤ 音频是否只标 `fully_copy` 原音频、未自创音色词？⑥ 声音是否与可见事件同步？⑦ 跨镜头连续性是否保持？⑧ 是否把笼统形容词换成了具体可见信息？

**中文对白镜头（03 册）额外逐条过**：

1. 摘要首句写死了每个在场 `<Subject N>` 的画面坐标？有"两侧/身后/旁边/一前一后"这类没方位的？
2. 有没有虚距离（`隔着满堂` `隔着一段距离` `一高一低` `只差半张脸`）？要对话的是不是写了实际距离（一步/一臂之外/中间隔一张矮几）？
3. 视线是不是只写落点？有没有"扫过…最后落在…"的过程句？
4. 每句台词是不是「说话人 + 对着/看着 <Subject M> + 台词」三件齐全？

## 0.5. 段数决定提示词条数（先算再写）

「一条音频」≠「一条视频」：H3 会把每条音频内部再切成 9.41667 秒一段。
要写几条逐段提示词、备几张场景图，**先算段数**（公式在公共件 `fxai-audio-video`，MV / 口播 / 短剧共用）：

```python
import audio_video as av
n     = av.h3_segment_count(时长)     # → 段数（最常用）
secs, bounds = av.h3_segments(时长)  # → 每段秒数 + 每段 (start, end)
```

| 时长 | 精确公式 | `ceil(时长/10)` | 差 |
|---|---|---|---|
| 37.667 s | 4 段 | 4 | — |
| 120 s | **13 段** | 12 | **差 1** |
| 226 s | **24 段** | 23 | **差 1** |

段数与提示词条数**一一对应**（`lines_data` 行索引按段取值），对不上时靠取模循环，
后面几段就会重复用第一条 —— 场景重复、动作重复，非常明显。

## 1.5 铁律：提示词必须契合这一段文案在讲什么

视频提示词**不是场景的通用描述**，是这一段文案的画面化。写之前先读懂这段在讲什么，再决定场景、动作、道具。

- **场景按内容定**：讲职场沟通就在办公区，讲育儿就落在家里客厅，讲代码就对着屏幕。
  同一个数字人，讲不同主题就该换不同场景——一个书房只对应一种主题。
- **道具跟着内容走**（H3 需要明确写出，别指望它自己加）：讲到咖啡就写「桌上放着马克杯」，
  讲到数据就写「指着柱状图」，讲到纸质笔记就写「摊开的笔记本与笔」。
  道具写「有名字的实物 + 它的状态」，抽象概念写不出画面。
- **动作/情绪跟着语气走**：口播文案每段带的情感标签（`用…的语气说`）就是这段的表演方向，
  提示词里的表情与手势要与之对应（轻松段落可带笑、严肃段落收住笑意）。
- **画面与文案必须对得上**：提示词里出现的场景、道具、人物状态，要能在这一段文案里找到依据；
  找不到依据的道具就剔掉。
- **道具/场景在 single/multi 靠场景图落地**（图片里就有），在 multiref 靠 `detailed_description`
  明确写出——**两种模式都要写，「图里已经有了」不算省略描述的理由**。

## 铁律速查（常驻，完整 14 条）

1. **音频 = 原音频**：`fully_copy`，音轨沿用原音频，**音色形容词一律留空**。
2. **两种格式各自成篇**：单/多场景 → FL2VA 三段式；多参考 → Ref2VA 六段式。
3. **段数必须用 `h3_segment_count(时长)` 算**，`ceil(时长/10)` 只当估值参考。
4. **上传了参考图就必须在提示词里定义并引用它**（人物图→`<Subject 1>` in `<Picture 1>`，场景图→`<Subject 2>` in `<Picture 2>`）——没写 = 头号失败原因。
5. **六段小标题按管线分支走**：短剧管线（`fxai-short-drama`）→ 中文（`主体定义` / `摘要` / `延续分析` / `详细描述` / `整体音效` / `非叙事音乐`，见 03 册）；MV / 数字人口播（`fxai-audio-video`）→ 英文（`subject_definitions:` / `summary:` / `retention_analysis:` / `detailed_description:` / `overall_soundscape:` / `non_diegetic_music:`，见 02 册）。**内容一律中文**；只有画面可见文字、被要求复述的歌词保留原样。触发词行落点两套相同：都在「详细描述 / `detailed_description`」的**下一行**、独占一行（见铁律 13）。
6. **运镜只写一条主线**，写全「类型 + 幅度 + 速度 + 跟拍对象」；空话式运镜（`dynamic camera` / `cinematic camera`）不写。
7. **动作写成轨迹不写动词标签**（写「抬手→手腕翻转→停顿→放下」这类轨迹）。
8. **视线只写落点**（负向禁令式视线一律不写：不看镜头 / 谁都不看镜头）。**MV / 口播分支相反：头部与眼神一个字都不写**（01 册 2.3），动作只写肢体轨迹与表情；动作库里不许出现点头、仰头、低头、转头、回眸、目光、眼神。
9. **画风归属**：本技能「六段小标题」只适用于 H3 视频提示词本身；**给 AI 生图的中文提示词仍用中文**。
10. 单镜 3–10 秒（H3 上限），**单集 ≥60 秒**（短剧硬下限，规划期就要达标）。
11. **打斗镜先取词、再落笔**：含武术动作 / 兵器交手的镜头，写动作描述**之前**先跑 `fxai-combat-design` 检索（`combat_route.py moves --query …` / `--terms <类别> [--tier high]`），术语落地、**一段 2–4 个词**、不加引号。核对 `avoid_when`（落在里面按无命中处理，改走 `--terms`）；无强命中是**正常结果**，如实说「无命中」、招式名只写库里查到的。纯文戏镜跳过。完整流程见 05 册。
12. **打斗镜的物体反馈与运镜按 05 / 06 册写**：物体反馈句走 05 册公式 `[物体与数量] + [行为与因果] + [空间一致性短语（至少 2 条）]`；运镜词只从 06 册词表里挑**一条**。
13. **触发词必挂（07 册）**：按镜型在 `detailed_description` **第一行**挂——**打斗镜** `camera motion, prfight1`；**打斗终结镜** `camera motion, prfight1, prfin1`（慢镜终结再加 `prslow1`）；**只运镜不打斗** `camera motion`；**文戏镜整行不写**。`camera motion` 永远排最前；`prfin1` / `prslow1` 必须与 `prfight1` 同时出现。**漏挂 = 对应 LoRA 完全不起作用，且提示词文本看不出异常**——最隐蔽的一类失败。
    **短剧管线已自动挂载**：`build_lines_data()`（`auto_triggers=True` 默认开）按镜型自动注入第一行，写 shots 时**不必手抄**（手写也不冲突，就地合并去重）。要显式控制就在 shot 上加 `trigger_words`（`""` = 明确不挂）/ `is_fight` / `finisher` / `slow`。MV / 口播走 `fxai-audio-video.build_ref2va_prompt(..., trigger_words=…)`。
14. 🔴 **口播镜入画即开口，全程不停嘴**：说话写成全程状态（`从第一个字到最后一个字持续讲话，嘴部全程保持明显开合`），**不写 `At …开始讲述`**；入场 / 走位 / 后退句必须自带「讲」（`边走边讲` / `边退边讲`），**位移句排在说话句之后**；起手句钉死首帧嘴部已开合。完整写法与反例见 01 册 2.3。
15. 🔴 **同一件事只写一次（不写重复指令）**：一镜的入场 / 位移 / 手势拼成同一条动作链，按「先…后…再…」分工，**同一件事不在两个字段里各写一遍**。重复=权重摊薄+模型当成第二个动作，出来是动作折返或语义打架。要强调就**换说法**（`讲` / `开口` / `嘴部开合` / `口型跟随` 任选其一），不是抄一遍。判据见 01 册「同一件事只写一次」。
16. 🔴 **台词与音频只挂人物主体，场景主体一个字都不得沾**（02 册 3.3）：`<Audio 1> …作为 <Subject N> 的音色参考` 的 N 必须是人物；这段在讲什么写进**人物**的定义句。MV 与口播共用一条工作流、**都传原始音频 `fully_copy`**，送进去的不是逐句合成的短句。程序侧 `av.build_ref2va_prompt(..., lines=…)` + `av.audit_subject_binding()`，门禁见数字人 `preflight.py` ★12。

## 自查速览（写完必过，完整版）

① 每个重要参考图都被分配了用途？② 人物身份/服装稳定？③ 每个主要动作有起因—推进—反应—终态？④ 运镜具体且与动作绑定？⑤ 音频只标 `fully_copy` 原音频、音色词留空？⑥ 声音与可见事件同步？⑦ 跨镜头连续性保持？⑧ 笼统形容词换成了具体可见信息？
⑨ **口播镜：入画第一帧就在说话？入场/位移句带「讲」？位移排在说话之后？**（见 01 册 2.3）
⑩ **同一件事有没有写两遍？**（入场/位移/手势两两比对，≥5 字相同片段＝重复，见 01 册「同一件事只写一次」）
⑪ **台词与音频挂在人物身上了吗？场景主体的定义句里有没有混进「她正在讲 / <Audio」？**（见 02 册 3.3）

中文对白镜头还要逐条过：摘要首句写死画面坐标？无虚距离？视线只写落点？每句台词「说话人 + 对着 <Subject M> + 台词」三件齐全？——完整清单见 04 册。
