# 单场景 / 多场景：FL2VA（首尾帧）+ 音频参考

这两支工作流走 H3 的 **FL2VA**：给一张（或多张）「人物已在场景里」的图当首尾帧锚点，H3 在首尾帧之间
生成连续路径，并让人物对口型。**提示词按下面的 FL2VA 格式写**（三段式逐段填满，格式口径就是 FL2VA，与 Ref2VA 六段式分属两支）。

## 2.1 格式硬约束（三段式）

```text
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot 1) aligns with the S.SS-second mark of the target video.

integrated_multimodal_description: [Shot 1] ...

overall_soundscape: ...

non_diegetic_music: 无
```

- 首行**对齐指令必须是提示词第一行**，空一行再进三段核心字段。`S.SS` = 有效时长，**两位小数**。
- `integrated_multimodal_description` 写画面与时间线上的动作、口型、音轨；`overall_soundscape` 写环境声与物理声；`non_diegetic_music` 写「无」。
- FL2VA **通常只用一镜**（`[Shot 1]`）让模型连续插值；确有多镜才用 `[Shot 2]`，且每镜首句带**递增的切点时间**（`[Shot 2] At 00:03.500, the camera cuts to...`），**`[Shot 1]` 不写时间戳**。
- 描述顺序：**首帧状态 → 可观察的中间变化 → 差异逐步收窄 → 末帧状态**，末帧必须由最后一个 `[Shot N]` 到达。

## 2.2 首尾帧之间写什么（不是重画一遍画面）

首帧和末帧图已经给了构图，**提示词的重点是两者之间发生了什么**：
- 主体怎么移动、姿态怎么变、**道具怎么被拿取/摆弄**、构图怎么演化、光线怎么过渡。
- 动作写成**轨迹**不写动词标签（别写"她抬手"，写「抬手→手腕翻转→停顿→放下」）。
- 运镜只写**一条主线**：`镜头以缓慢的轻微推近（slow push-in）跟随人物，幅度小、速度慢。`
  幅度必须贴合参考图的静态构图（只做小幅缓推 / 缓拉 / 轻横移 / 极轻手持）。

## 2.3 口播（speak）的动作链写法

口播的可见动作就是**讲话**：`嘴唇与 <Audio 1> 中的说话内容精准同步开合`、伴随**小幅手势**、
句间自然停顿换气。`overall_soundscape` 写
`来自 <Audio 1> 的清晰人声与说话内容原样贯穿全程，不加背景音乐与混响。`

### 🔴 铁律：入画即开口，全程不停嘴

音频是**整段已经存在**的（`fully_copy`），画面出现的第一帧声音就已经在响，所以人从第一帧起就得在说话。
实测翻车（2026-10-21）：入场镜前两三秒嘴是闭的、走位镜整段几乎不动嘴、后退镜退着退着就不说了——
原因不是模型不会唇形同步，是**提示词把说话写成了"某个时点开始的动作"**，而入场 / 位移 / 后退
这些句子把时间轴占满了，模型按"先走到位、再开口"演。

三条硬写法：

1. **说话写成全程状态，不写成起点事件**
   ✅ `从第一个字到最后一个字持续讲话，嘴部全程保持明显开合，口型逐字跟随 <Audio 1> 中的说话内容变化`
   ❌ `嘴唇与 <Audio 1> 精准同步开合`（只是"对齐一下"，强度不够，配上「面带微笑」就被做成闭嘴微笑）
   ❌ `At 00:02.000, 她开始讲述`（等于告诉模型前两秒可以不说）
2. **入场 / 位移句自带「讲」**：入场、走位、横移、后退**都不中断说话**，句子里必须带讲/说/开口。
   ✅ `她一边开口讲，一边从画面外侧缓步走入，走到画面中略偏中心的位置停住，边走边讲`
   ✅ `向画面深处缓缓后退，全程持续移动，边退边讲`
   ❌ `从画面外侧走入，走到桌前站定`（纯位移，模型就演成走进来、站好、再开口）
3. **首帧必须是张着嘴的**：图生视频的首帧 = 参考图（嘴闭合），不写就会从闭嘴开始插值。
   起手句写 `画面出现的那一刻她就已经在说话，嘴部正在开合`，把首帧状态钉死。

### 🔴 铁律：同一件事只写一次（动作链按时间顺序，不重复指令）

一镜的入场（`entry`）、位移（`motion`）、手势（`action`）会被拼成**同一条动作链**。
同一件事在两个字段里各写一遍，不是"强调"，是**重复指令（duplicate instruction）**：
权重被摊薄到两句上，且第二句会被模型当成"还有一个独立动作要做"，
出来是动作折返、语义打架，或者干脆只演一遍、另一句被忽略。

**写法：按「先…后…再…」的时间顺序把一件事拆给不同字段，每个字段只说自己那一段。**

| 写法 | 对比 | 判定 |
|---|---|---|
| ✅ 顺序分工 | entry「她一边开口讲，一边从画面右侧缓缓走入」<br>motion「走到桌前站定，双脚踩稳，重心落在左脚，嘴部不停开合」 | 入场与站定各写一次，「讲」与「嘴」分散在两个字段，不重复 |
| ❌ 重复指令 | entry「从画面右侧缓缓走入，走到桌前站定，全程边走边讲，嘴部不停开合」<br>motion「从画面右侧缓缓走入……走到桌前站定，全程边走边讲，嘴部不停开合」 | 同一件事写两遍；「边走边讲」「嘴部不停开合」完全雷同 |

判据（门禁自动拦，**不靠肉眼**）：同一镜任意两个动作字段之间，出现 **≥5 个字的相同片段**
（去掉「全程 / 画面 / 镜头 / 缓缓 / 持续」这类通用词后仍 ≥3 字）即为重复。
同一件事要强调的是**换说法**，不是抄一遍：`讲` / `开口` / `说` / `嘴部开合` / `口型跟随` 任选其一。

**位移句永远排在说话句之后**：说话先写、位移后写。反过来模型会把位移当主任务，说话被挤掉。

🔴 **头部与眼神一个字都不写**：不写点头节拍、不写仰头低头、不写「眼神看向镜头 / 目光与镜头交流」。
写了模型就照着演，出来是边说边点头、眼球来回扫（实测）。只留一句朝向「面向镜头」。

（MV 演唱版把上句替换成：嘴唇与歌声同步开合、身形随乐句轻步移动、双手随乐句做柔和手势。
**头部与眼神同样一个字都不写**——动作库里不出现点头、仰头、低头、转头、回眸、目光、眼神，
只给肢体动作、表情与环境互动。）
