# 中文对白镜头（短剧分镜）写法硬规范

叙事短剧 / 有对白的正片镜头用这套（MV 的 Ref2VA 六段仍照旧，但**用英文**小标题，见 02 册）。六段固定为：
`主体定义 → 摘要 → 延续分析 → 详细描述 → 整体音效 → 非叙事音乐`——**中文小标题是短剧分支的原生口径**（`drama_pipeline` / `export_shot_prompts` 都按中文名匹配），每镜的 `<Subject N>` / `<Picture M>` 都从 1 起独立编号。

## 5.1 站位与距离（决定"两个人是否对得上话"）

- **摘要首句**（`[reference generation] ` 之后）必须把本镜每个在场 `<Subject N>` 的画面坐标一次写死，后面详细描述不得改坐标。
  ✅ 画面正中 / 画面正中偏左 / 画面右上方 / 画面左下方 / 左前方 / 右后方 / 半头 / 一步外 / 一臂之外 / 中间只隔一张矮几
  ❌ 两侧 / 左右两翼 / 身后 / 旁边 / 一前一后 / 错开 / 更后面偏右 / 一高一低（不带方位、不带距离量的一律重写）
- **要对话就必须近**：写数量（一步、半步、一臂之外、中间只隔一张矮几）。
  ❌ 虚距离一律禁写：`隔着满堂`、`隔着一段距离`、`一高一低`、`只差半张脸`、`隔着老远`。
- **隔空喊话**（不在画的人 / 画外声音）：必须写"画外""冲着画外"，且不得要求在画的人回视。

## 5.2 视线只写落点，不写过程

- ✅ `两眼落在 <Subject 2> 的脸上` / `视线钉在 <Subject 2> 脸上，一瞬也不挪`
- ❌ 过程句禁写：`两眼扫过满堂、最后落在 <Subject 2> 脸上`（等于让模型先把眼甩开再拉回来，结果回不来）、`横扫过`、`斜着扫出去`、`视线在两人之间来回收`。
- 要强调强度只用副词（死死 / 一瞬不挪 / 从头到尾不挪一格），一次视线转移写一次就够。

## 5.3 谁对谁说话 —— 正向写死

台词行 = 时间轴 + 说话人 + 表演句 + 台词，缺一样就写不出"对着谁说"：

```text
<Subject 1> (S1) 低头对着 <Subject 2> 尖着嗓子道：<d>[Chinese] 侯爷的面子，你给得起吗？</d>。
At 00:03.500, <Subject 1> (S1) 抬眼对着 <Subject 2> 冷声道：<d>[Chinese] 你今天必须给个说法。</d>。
```

- 首个事件**不写时刻**（`[Shot 1]` 不带时间戳），第二个事件起才写 `At`。

- 表演句里**必须带「对着 / 看着 / 仰着脸对着」+ 对方 `<Subject N>`**。
- ❌ 只写 `两眼钉着 <Subject 2> 道` / `张着嘴道` / `冷声道` —— 没写"对谁"就会自由发挥。
- 说话人一律写 `<Subject N> (Sx)`；旁白/动作行不写说话人。

## 5.4 台词归属与称谓

- 台词只能挂**本镜在画（有参考图、场上）**的角色；只在暗处/后脑勺/画外的人说话，必须标「画外」。
- 台词里的称谓（王爷 / 侯爷 / 奴家）必须指向**本镜的对话对象**；称谓只落在画内、正在对话的那个人身上。
- 台词内的人称用称谓或 `<Subject N>`，不留「他 / 她」代词、不留中文角色名（会被画进画面或被认错人）；`<d>…</d>` 里保留烧字幕的自然中文。

🔴 **`道：` 前面的表演句只写动作，不写可朗读的短语**：H3 会把引导句里的口语短语当成台词念出来，
成片凭空多出半句（实测「抬眼看着…点了点头道」「一步跨上来，眼睛瞪着…道」都被念了）。
- ✅ `At 00:04.000, <Subject 1> (S1) 抬眼对着 <Subject 2> 道：<d>[Chinese]…</d>。`
- ❌ 引导句里塞形容、比喻、口语短句：`把行情摆出来，一句一句往底牌上压，道：<d>…</d>`。
- **摘要段同理**：用第三人称客观陈述（谁在哪、做什么），不写「摆出来 / 压下去 / 顶回去」这类
  带引号感的说法，否则同样被念进口型。


## 5.5 禁负向禁令（只写干什么、怎么写）

一律不写的说法：`绝不看镜头`、`绝不直视镜头`、`绝不看向观众`、`绝不低头看地面`、`谁都不看镜头`、`谁也不看镜头`、`没有一个人的眼睛对着镜头`。 # std:allow
视线落点写死即天然排除看镜头，写禁令反而把"镜头"这个概念喂给模型。

## 5.6 外貌与位置特征

- 外貌句逐字照抄 `project_def.json` 里该角色的生图 `prompt`，不得自造限定、不得抄参考图里没有的特征。
- 位置型特征（疤 / 痣 / 朱砂）**写死左右上下**：`右颊一道旧刀疤` `左手腕一道旧疤` `左眼下一点朱砂`；❌ `眼尾一颗泪痣` `脸颊一颗痣`（相对位逐镜左右漂）。
- 道具文字：只写 `朱红描金卷草纹` / `线条涂鸦` / `空白纸面`；❌ `写着…` `屏幕上显示…` `弹幕`。要传达数据就写"角色指着柱状图/折线图/百分比数字"。

## 5.7 运镜与镜头顺序

- 一镜一条主运镜，写全「类型 + 幅度 + 速度 + 跟拍对象」，写在 `[Shot 1]` 那句里；H3 是图生视频，运镜幅度必须贴合参考图的静态构图（只做小幅缓推 / 缓拉 / 轻横移 / 极轻手持）。
- 镜头顺序按 `建场 → 入场/反应 → 冲突/对峙 → 收尾定格` 编排；每镜单段正文写成一整行，不留段内折行。
- 时间轴按**切点制**：`[Shot 1]` 第一个事件**不写时刻**，之后每档 `At 00:03.500,` 起头（`MM:SS.mmm` + 英文 `At` + 逗号），**只给起点、不写终点**；切点严格递增、不得超出本镜时长，末条到镜尾。说话行带 `<d>[Chinese]…</d>`，旁白行不带。时长：单镜 3–10s（H3 上限），**单集 ≥60s（短剧硬下限，规划期就要达标）**。

## 5.8 触发词（文戏镜不挂）

- 中文对白镜头默认是**文戏镜**：`detailed_description` 第一行**不写任何触发词**——`camera motion` / `prfight1` 都要删干净。
- 一旦本镜出现武术动作 / 兵器交手，就按 `07-触发词挂载规范.md` 挂 `camera motion, prfight1`（本镜走完终结技再加 `prfin1`）。
