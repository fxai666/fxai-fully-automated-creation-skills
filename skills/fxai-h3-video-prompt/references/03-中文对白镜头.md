# 中文对白镜头（短剧分镜）写法硬规范

> 🔴 **先读通用范式**：`SKILL.md` 的「镜头描述通用范式（v1）」给了 5 个槽位的骨架
> （① 取景 ② 建场 ③ 动作拍 ④ 台词拍 ⑤ 收尾拍）。本册是按槽位展开的填法说明，
> 5.1–5.6 讲槽位②③怎么填，5.7 讲槽位①④⑤怎么填。

叙事短剧 / 有对白的正片镜头用这套（MV 的 Ref2VA 六段仍照旧，但**用英文**小标题，见 02 册）。六段固定为：
`主体定义 → 摘要 → 延续分析 → 详细描述 → 整体音效 → 非叙事音乐`——**中文小标题是短剧分支的原生口径**（`drama_pipeline` / `export_shot_prompts` 都按中文名匹配），每镜的 `<Subject N>` / `<Picture M>` 都从 1 起独立编号。

## 5.1 站位与距离（决定"两个人是否对得上话"）

- **摘要首句**（`[reference generation] ` 之后）必须把本镜每个在场 `<Subject N>` 的画面坐标一次写死，后面详细描述不得改坐标。
  ✅ 画面正中 / 画面正中偏左 / 画面右上方 / 画面左下方 / 左前方 / 右后方 / 半头 / 一步外 / 一臂之外 / 中间只隔一张矮几
  ❌ 两侧 / 左右两翼 / 身后 / 旁边 / 一前一后 / 错开 / 更后面偏右 / 一高一低（不带方位、不带距离量的一律重写）
- **要对话就必须近**：写数量（一步、半步、一臂之外、中间只隔一张矮几）。
  ❌ 虚距离一律禁写：`隔着满堂`、`隔着一段距离`、`一高一低`、`只差半张脸`、`隔着老远`。
- **隔空喊话**（不在画的人 / 画外声音）：必须写"画外""冲着画外"，且不得要求在画的人回视。
  - **画外声音两类，自己的心声用「画外主体 + 独立参考图槽」（2026-11-26 定稿）**：
    - ① 别人不在场景里说话 → `<Subject N> (Sx) 画外说：<d>[Chinese]…</d>。`（挂主体无妨——人不在画内、无画内嘴可贴；旧词「画外道」废弃）
    - ② 自己的心声 / 内心独白（脸在画面里时）：
      1. `images` 里把说话人那张图**再传一份**，成为新的 `<Picture M>`（如第 4 槽）；
      2. `<Subject N> 是 <Picture M> 中的男孩。`；
      3. 延续分析写 `…沿用 <Picture M>`；
      4. 动作行写「嘴唇始终闭着、双唇抿成一条白线、下颌不动」；
      5. 说话行独立一行：`At MM:SS.mmm, <Subject N> (Sx) 画外说：<d>[Chinese]…</d>。`；
      6. 画面里不出现该主体。
      🔴 不能复用画内主体的图（`<Subject N> 是 <Picture 1> 中的…`）——等于告诉模型「说话的就是画内那个人」，
      口型照样驱动。门禁硬拦「同一 `<Picture M>` 被两个主体共用」。
      🔴 台词窗按 3.3 字/秒 + 0.3s 气口算。
    - **备选**（仅当上面不成立、且脸不在画面焦点）：官方 voiceover
      `<Subject N> (Sx) says in an off-screen voiceover: <d>…</d> while his lips remain completely closed.`；
      早点铺版 `At MM:SS.mmm, 画外 <Subject N> (Sx) 的心声，他嘴唇始终不动：<d>…</d>`。
    - 🔴 **实测结论**：纯文字闭唇描述压不住口型驱动（官方 voiceover / 早点铺双锁 / 加时间区间三种都试过）。
      之前以为「锁住了」是俯拍低头、嘴不在画面里的错觉。唯一可靠的是「画外主体 + 独立图槽」。
    - ❌ 心声只写「紧闭着嘴默默的说」就挂主体——会被念出来；❌ 心声写「看着 <Subject M> 说」——会张嘴、看向别人。

## 5.2 视线只写落点，不写过程

- ✅ `两眼落在 <Subject 2> 的脸上` / `视线钉在 <Subject 2> 脸上，一瞬也不挪`
- ❌ 过程句禁写：`两眼扫过满堂、最后落在 <Subject 2> 脸上`（等于让模型先把眼甩开再拉回来，结果回不来）、`横扫过`、`斜着扫出去`、`视线在两人之间来回收`。
- 要强调强度只用副词（死死 / 一瞬不挪 / 从头到尾不挪一格），一次视线转移写一次就够。

🔴 **落点用词分两种（2026-11-25 用户定）**：
- 落点是**人**（`<Subject N>` 的脸 / 身上）→ 用「落在 / 钉在」是规范写法，放行。
- 落点是**物件 / 手心 / 地面 / 灵台**等非人物目标 → 必须写「两眼**看着** X / **盯着** X」，
  不要写「落在 X」——「落在」在物件上容易被 H3 理解偏、把目光绑到画面里另一个人身上
  （第5集镜17「两眼落在自己空空的手心上」，成片却看向了旁边的娘）。
- ✅ `两眼看着自己空空的手心` / `盯着掌心那颗丹` / `两眼看着灵台`
- ❌ `两眼落在自己空空的手心上` / `落在掌心那颗丹上`（物件落点用「落在」）

## 5.3 谁对谁说话 —— 正向写死

台词行 = 时间轴 + 说话人 + 表演句 + 台词，缺一样就写不出"对着谁说"：

```text
<Subject 1> (S1) 低头对着 <Subject 2> 尖着嗓子说：<d>[Chinese] 侯爷的面子，你给得起吗？</d>。
At 00:03.500, <Subject 1> (S1) 抬眼对着 <Subject 2> 冷声说：<d>[Chinese] 你今天必须给个说法。</d>。
```

- 首个事件**不写时刻**（`[Shot 1]` 不带时间戳），第二个事件起才写 `At`。

🔴 **说话引导词只有两种范式（2026-11-25 用户定，照抄其一、不得自造）**：
- **范式 A · 直接说**（无修饰）：`<Subject N> (Sx) [表演动作，]说：<d>[Chinese]台词</d>。`
- **范式 B · 表情/动词 + 说**（需要表情/语气/动作修饰）：`<Subject N> (Sx) [表演动作，][表情/语气副词]说：<d>[Chinese]台词</d>。`
  - 修饰词贴在「说」前、仍以「说」字收尾：`笑着说` / `低声说` / `尖着嗓子说` / `冷声说`。
- 共同硬约束：① 引导词以「说」字结尾 + 冒号 + `<d>`；② 修饰词只在「说」前，不在「说」后；③ 表演句正向写死对谁；④ `</d>` 后紧跟句号。
- ❌ **绝不用「道」**：笑道 / 低声道 / 冷声道 / 说道 / 道 全部禁止，一律换「说」。门禁硬拦。

- 表演句里**必须带「对着 / 看着 / 仰着脸对着」+ 对方 `<Subject N>`**。
- ❌ 只写 `两眼钉着 <Subject 2> 说` / `张着嘴说` / `冷声说` —— 没写"对谁"就会自由发挥。
- 说话人一律写 `<Subject N> (Sx)`；旁白/动作行不写说话人。

## 5.4 台词归属与称谓

- 台词只能挂**本镜在画（有参考图、场上）**的角色；只在暗处/后脑勺/画外的人说话，必须标「画外」。
- 台词里的称谓（王爷 / 侯爷 / 奴家）必须指向**本镜的对话对象**；称谓只落在画内、正在对话的那个人身上。
- 台词内的人称用称谓或 `<Subject N>`，不留「他 / 她」代词、不留中文角色名（会被画进画面或被认错人）；`<d>…</d>` 里保留烧字幕的自然中文。

🔴 **`说：` 前面的表演句只写动作，不写可朗读的短语**：H3 会把引导句里的口语短语当成台词念出来，
成片凭空多出半句（实测「抬眼看着…点了点头道」「一步跨上来，眼睛瞪着…道」都被念了）。
- ✅ `At 00:04.000, <Subject 1> (S1) 抬眼对着 <Subject 2> 说：<d>[Chinese]…</d>。`
- ❌ 引导句里塞形容、比喻、口语短句：`把行情摆出来，一句一句往底牌上压，说：<d>…</d>`。
- **摘要段同理**：用第三人称客观陈述（谁在哪、做什么），不写「摆出来 / 压下去 / 顶回去」这类
  带引号感的说法，否则同样被念进口型。


## 5.5 禁负向禁令（只写干什么、怎么写）

一律不写的说法：`绝不看镜头`、`绝不直视镜头`、`绝不看向观众`、`绝不低头看地面`、`谁都不看镜头`、`谁也不看镜头`、`没有一个人的眼睛对着镜头`。 # std:allow
视线落点写死即天然排除看镜头，写禁令反而把"镜头"这个概念喂给模型。

## 5.6 外貌与位置特征

- 🔴 **外貌不写**（铁律 17）：主体定义只写 `<Subject N> 是 <Picture M> 中的<身份词>。`，
  保留类目写进延续分析（`fully_preserved - 保留人物身份、发型发色、服装样式与颜色、裤装、鞋履。`）。
  旧写法「外貌句逐字照抄生图 prompt」与「类目清单进主体定义」**均已作废**（2026-11-12）——
  写进文字就等于让模型按文字重建，参考图被覆盖。
- 🔴 **身份词不加修饰**（2026-11-14 用户定）：只写 `图片中的男子` / `图片中的女子` / `图片中的场景` / `图片中的道具`。
  不加国籍（`中国年轻`）、年龄（`年轻` / `中年`）、民族、身材、相貌、衣着，也不带姓名括号与描述性定语。
- 位置型特征（疤 / 痣 / 朱砂）**默认不写**，全靠参考图；剧情必须时才写，且**写死左右上下**：
  `右颊一道旧刀疤` `左手腕一道旧疤` `左眼下一点朱砂`；❌ `眼尾一颗泪痣` `脸颊一颗痣`（相对位逐镜左右漂）。
- 道具文字：只写 `朱红描金卷草纹` / `线条涂鸦` / `空白纸面`；❌ `写着…` `屏幕上显示…` `弹幕`。要传达数据就写"角色指着柱状图/折线图/百分比数字"。

## 5.7 运镜与镜头顺序

- 一镜一条主运镜，写全「类型 + 幅度 + 速度 + 跟拍对象」，写在 `[Shot 1]` 那句里；H3 是图生视频，运镜幅度必须贴合参考图的静态构图（只做小幅缓推 / 缓拉 / 轻横移 / 极轻手持）。
- 镜头顺序按 `建场 → 入场/反应 → 冲突/对峙 → 收尾定格` 编排；每镜单段正文写成一整行，不留段内折行。
- 时间轴按**切点制**：`[Shot 1]` 第一个事件**不写时刻**，之后每档 `At 00:03.500,` 起头（`MM:SS.mmm` + 英文 `At` + 逗号），**只给起点、不写终点**；切点严格递增、不得超出本镜时长，末条到镜尾。说话行带 `<d>[Chinese]…</d>`，旁白行不带。时长：单镜 3–10s（H3 上限），**单集 ≥60s（短剧硬下限，规划期就要达标）**。
- **描述一律大白话（2026-11-26 用户定）**：每个事件都写成「谁 + 做了什么 + 落在哪个主体身上」，尤其「谁把什么东西给了谁」必须显式写出来。文学化压缩只给结果、不给过程，H3 读不出意图，会自己猜或者干脆把描述当台词念。❌ `少年给白眉老头磕头求得长生丹`（丹哪来的？）→ ✅ `<Subject 2> 从袖子里摸出那颗丹、放进 <Subject 1> 手心`。连续动作之间用「紧接着 / 这时 / 然后」连起来。
- **动作拍只写「主体 + 动词 + 对象」，修饰只许写方式 / 部位 / 方向（2026-11-26 用户定，门禁硬拦）**：程度与情态只传递情绪、不传递动作，模型读不到就不做。**判据是语法形态，不是词表**——① 形容词叠词作修饰（死死 / 轻轻 / 渐渐 / 结结实实 / 干干净净 / 空落落）② 「得」字补语接程度词（捧得死紧）③ 程度·情态副词直接修饰（很静 / 猛地 / 用力）。数量反复（一截一截、一颗一颗、一圈圈）和动词重叠（说说笑笑、讲着讲着）放行，那是看得见的反复。❌ `结结实实磕了三个头` → ✅ `俯下身、额头碰地、抬起来、再碰地`；❌ `把丹捧得死紧` → ✅ `把两只手合在一起、把丹捧在掌心`。心法：**能拍出来的才是描述**。
- **景别必须框住动作（2026-11-26 第5集镜11 实测）**：写进描述的动作，取景框里就必须看得见。镜11 写「近景」，画面切在胸口，两个人的手都在框外——递丹这个动作写多少遍都不会出现，跪着和站着也分不出来（腿在框外）。凡是动作落在手、膝、脚上（递 / 接 / 攥 / 捧 / 跪 / 磕头），景别就得带到那个部位，并在 `[Shot 1]` 里明写「画面从…带到…、把两只手都框在画面里」。写动作之前先问一句：**这个部位在框里吗？**
- **台词行后面不许紧跟以 `<Subject N>` 起头的裸动作行**：H3 会把这条动作接着当台词念（第5集镜11 收尾「结结实实磕了三个头、把丹捧得死紧」被念成旁白，whisper 词级时间轴实证 `节节时时磕了三个头把丹捧得死紧`）。收尾动作要么并进台词行的引导句，要么写成 `At 00:07.200, 紧接着，<Subject 1> ……`。

## 5.8 触发词（文戏镜不挂）

- 中文对白镜头默认是**文戏镜**：`detailed_description` 第一行**不写任何触发词**——`camera motion` / `prfight1` 都要删干净。
- 一旦本镜出现武术动作 / 兵器交手，就按 `07-触发词挂载规范.md` 挂 `camera motion, prfight1`（本镜走完终结技再加 `prfin1`）。

## 5.9 非台词段一律写英文（2026-11-13 实测）

🔴 **只要「摘要 / 详细描述 / 整体音效 / 非叙事音乐」里出现中文动作短语，H3 就可能把它当台词念出来。**
5.4 的「引导句只写动作」不够用——第三人称客观陈述照样会被念。

实测一集 14 镜全中文提示词，音轨比台词多出 5 处旁白：

| 被念出来的内容 | 出自 |
|---|---|
| 「眼皮慢慢抬起、喉线轻轻动一下、唇松开一条缝」 | 详细描述的动作句 |
| 「跟着三步走：蹬地一记、格挡一记、推掌一记」 | 非叙事音乐 |
| 「腿背贴着地面切过…扫堂腿…」 | 详细描述 |
| 「把身子侧过去小半寸，视线挪到画面右后方，没说话」 | 详细描述 |
| 「这气氛卷成轻盈的…」 | 详细描述 |

**定法**：

- **四段正文（摘要 / 详细描述 / 整体音效 / 非叙事音乐）全部英文**；中文只留在 `<d>[Chinese]…</d>` 台词里。
- **段名保持中文**（`主体定义 / 摘要 / 延续分析 / 详细描述 / 整体音效 / 非叙事音乐`）——`drama_pipeline` 按中文段名做匹配与切分，段名必须是这六个字。
- **`主体定义` 与 `延续分析` 可以留中文**（只有身份词与 `fully_preserved - 保留…` 类目清单，无动作短语）。实测这两段留中文不会产生旁白。
- 英文句里的坐标、距离、时刻、`<Subject N>`、触发词写法照 5.1~5.8 的规则搬过去即可，信息量不减。
- 反向描述（`没说话` / `说话` 本身就是词）尤其要删——**写清发生了什么就停笔**，不写没发生什么，见 04 册「白名单模式」。

## 🔴 镜头描述通用范式（v1 · 2026-11-26 定 · 所有镜头一律按此骨架填）

> 这是**写所有镜头**的骨架，不是某一集的写法。任何一镜的「详细描述」都按这 5 个槽位填，
> 顺序固定、不合并、不省略。填不进去，就说明这一镜还没想清楚。

```
<风格句：写实电影感的 X，光线>，<景别>，<机位>。
[Shot 1] <景别>镜头，<机位>，画面<取景范围：从哪带到哪 / 关键部位在不在框里>，建立 <Subject A> 作为场景：<Subject B> 在<位置>、<Subject C> 在<位置>，<首个动作：主体 + 动词 + 对象>。
At 00:0X.XXX, <Subject N> <动词 + 对象>，<动词 + 对象>。
At 00:0X.XXX, <Subject N> (Sx) <对着谁>，说：<d>[Chinese]<台词></d>。
At 00:0X.XXX, <场景副词：紧接着 / 这时 / 然后>，<Subject N> <动词链：动作一、动作二、动作三>。
```

| 槽 | 写什么 | 硬要求 | 门禁 |
|---|---|---|---|
| ① 取景 | 景别 + 机位 + **取景范围** | 动作落在手/膝/脚上，框就必须带到那个部位 | 景别框动作 |
| ② 建场 | `建立 <Subject A> 作为场景` + 每个主体站位 | 站位写死、距离写死 | 主体定义 / 摘要站位 |
| ③ 动作拍 | 主体 + 动词 + 对象，**一拍一行** | 只写动词不写形容词；每拍带 `At`；主体写 `<Subject N>` | 语法形态检查 / At / 裸代词 |
| ④ 台词拍 | 主体 `(Sx)` + 对着谁 + `说：<d>` | 独立成行、一行只一句、`At` 起头、`</d>。` | 台词行 At / 一行一句 / 台词闭合 |
| ⑤ 收尾拍 | 场景副词起头 + 动词链 | **不许**以 `<Subject N>` 裸起头 | 台词后裸动作行 |

**三原则**：① **一拍一行**（一个时间点只做一件事）；② **一拍一主体**（全篇不写「他/她」）；
③ **能拍出来才算**（动词具体、部位在框内、过程完整：谁→给谁→怎么给→结果）。

**自检一句话**：把这段描述当成拍摄指令交给摄影师，他能不能照着拍出来？拍不出来就是没写清。

下面的十二条铁律，就是这套范式在具体环节上的展开；`03-中文对白镜头.md` 是按槽位排的填法说明。

## 🔴 台词与表演十二条铁律（2026-11-25/26 用户定，短剧 / 多参考 / MV / 数字人通用）

1. **台词闭合**：`</d>` 后必须紧跟句号 `</d>。`，再写动作或下一句。漏句号 H3 会把后续文字继续当台词念出来。
2. **拟声词归位**：吱呀 / 磨牙 / 咯吱 / 窸窣等声音词只写「整体音效 / overall_soundscape」段，正文里会被当对白念。
3. **言语意图要落地**：摘要写「默念 / 开口 / 画外」，详细描述必须有对应 `<d>` 台词，或明确标注「无声口型 / 不出声」，否则模型自己编台词乱念。
4. **每镜必写表情 + 肢体**：至少一处情绪表情 + 一处肢体动作，缺一就是纸片人。此前只对 MV / 数字人强制，现对短剧同样强制。
5. **画外声音：画外主体 + 独立参考图槽（2026-11-26 定稿，首选）**：
   - ① 别人不在场景里说话 → `<Subject N> (Sx) 画外说：<d>[Chinese]…</d>。`（挂主体无妨，人不在画内）。
   - ② **自己的心声 / 内心独白（正脸可见时）→ 画外主体独立图槽**。第5集镜17 十五轮对照后的唯一有效写法：
     1. **参考图多传一份**：`images` 里把说话人那张图再放一次，成为新的 `<Picture M>`
        （例：`[016, 007, 013, 016]` → 少年图占第 4 槽）
     2. 主体定义：`<Subject N> 是 <Picture M> 中的男孩。`（N 顺排，M 是新增槽位）
     3. 延续分析：`<Subject N> (appears in [Shot 1]): fully_preserved - …沿用 <Picture M>…`
     4. 动作行照常写「嘴唇始终闭着、双唇抿成一条白线、下颌不动」
     5. 说话行**独立一行**：`At MM:SS.mmm, <Subject N> (Sx) 画外说：<d>[Chinese]…</d>。`
     6. 画面里不出现 `<Subject N>`——他只是声源
     ```
     主体定义
     <Subject 1> 是 <Picture 1> 中的男孩。
     <Subject 2> 是 <Picture 2> 中的女人。
     <Subject 3> 是 <Picture 3> 中的场景。
     <Subject 4> 是 <Picture 4> 中的男孩。      ← 同一张图另占一槽
     详细描述
     [Shot 1] …画面内只有 <Subject 1> 和 <Subject 2> 两个人：…
     <Subject 1> 眼皮猛地掀开、…、嘴唇始终闭着、双唇抿成一条白线、下颌不动；<Subject 2> 低着头、一动不动。
     At 00:01.800, <Subject 4> (S1) 画外说：<d>[Chinese]爷，我回来了。我回来晚了。</d>。
     At 00:05.300, <Subject 1> 膝盖先砸在地上、…、嘴唇始终闭着；<Subject 2> 眼睛肿着、双唇紧闭不出声。
     ```
     🔴 **绝不能复用画内主体的图**：`<Subject 4> 是 <Picture 1> 中的男孩` 等于告诉 H3「说话的就是画内那个人」，
     口型照样被驱动（第八轮实测失败）。门禁已硬拦「同一 `<Picture M>` 被两个主体共用」。
     🔴 台词窗按 3.3 字/秒 + 0.3s 气口算，10 字至少 3.3s，否则提交会被时长校验拒绝。
   - 备选（仅当上面不成立、且脸不在画面焦点时）：官方 voiceover `says in an off-screen voiceover: <d>…</d> while his lips remain completely closed.`（`base-modes-en.txt` §4.4，闭唇句紧跟 `</d>`）；早点铺版 `At MM:SS.mmm, 画外 <Subject N> (Sx) 的心声，他嘴唇始终不动：<d>…</d>`。
   - 🔴 实测结论：**纯文字闭唇描述压不住 H3 的口型驱动**（官方 voiceover / 早点铺双锁 / 加时间区间，三种都试过）。
     之前几次以为「锁住了」，其实是俯拍低头、嘴不在画面里造成的错觉。唯一可靠的是**让说话人成为画外主体 + 独立图槽**。
   - 旧词「画外道」废弃。
   ✅ `<Subject 3> (S1) 画外说：<d>[Chinese]这颗糖，是你爷早就给你留的。</d>。`
   ✅ `<Subject 4> (S1) 画外说：<d>[Chinese]爷，我回来了。我回来晚了。</d>。`（Subject 4 独立占 Picture 4）
6. **视线落点看对象**：落点是人（`<Subject N>`）用「落在 / 钉在」；落点是物件 / 手心 / 灵台等非人物用「看着 / 盯着」，不用「落在」——「落在物件」容易被 H3 把目光绑到画内别人身上。
7. **说话引导词两种范式、一律用「说」不用「道」**：
   - 范式 A 直接说：`<Subject N> (Sx) [表演动作，]说：<d>[Chinese]…</d>。`
   - 范式 B 表情/动词 + 说：`<Subject N> (Sx) [表演动作，][表情/语气副词]说：<d>[Chinese]…</d>。`（笑着说 / 低声说 / 尖着嗓子说，修饰词贴在「说」前、以「说」字收尾）
   - 硬约束：引导词以「说」结尾 + 冒号 + `<d>`；修饰词只在「说」前；`</d>` 后紧跟句号。笑道 / 低声道 / 冷声道 / 说道 / 道 全部禁止。
8. **主体引用格式：正文里每次指代人物都必须写 `<Subject N>` 全称，不许用「他 / 她」**（2026-11-25 用户定）。
   - ❌ `他跪下去、额头碰地磕了三个头` —— 前面没有主体，H3 分不清动作落到谁身上
   - ✅ `<Subject 1> 跪下去、<Subject 1> 额头碰地磕了三个头`
   - 判定按句切（`。` `；` 换行）：句内有他/她、却没有任何 `<Subject N>` 即违规。台词 `<d>` 里的「他」不算。
   - 「其他 / 他人 / 他乡 / 他日 / 他年 / 他处」不算代词，放行。
9. **镜头描述一律写大白话，把「谁把什么东西给了谁」这类关键动作写明白**（2026-11-26 用户定）。
   - 病根：文学化压缩写法只交代结果、不交代过程，H3 读不出意图，只能自己猜或干脆把描述当台词念。
     只写「少年给白眉老头磕头求得长生丹」、没写「老头把丹放到少年手心」时，
     模型就不知道丹是哪来的，收尾动作还被当旁白念了出来。
   - ❌ `收在把丹捧得死紧` / `求得长生丹` —— 只有结果，没有谁给谁
   - ✅ `<Subject 2> 从袖子里摸出那颗丹、放进 <Subject 1> 手心` + `紧接着，<Subject 1> 对着 <Subject 2> 俯下身、额头碰地、抬起来、再碰地`
   - 具体做法：① 动词用日常口语（摸出 / 放进 / 攥住 / 合上手指），不用四字压缩；
     ② 每一步都落到 `<Subject N>` 身上；③ 连续动作之间用「紧接着 / 这时 / 然后」显式连起来。
10. **台词行后面不许紧跟以 `<Subject N>` 起头的裸动作行**（2026-11-26 第5集镜11 实测）。
   - 即使动作单独一行、`</d>。` 收得干干净净，H3 仍会把它接着当台词念：
     镜11 收尾的动作被 whisper 词级时间轴抓到，在 65.28–67.50s 被念成了旁白。
   - 两种合法写法：① 把这个动作并进台词行的引导句（`…看着 <Subject 2>，说：<d>…</d>。`）；
     ② 让这一行以场景副词起头：`At 00:07.200, 紧接着，<Subject 1> ……`。
   - 门禁 `_audit_detail` 已硬拦（台词行下一条以 `At …, <Subject N>` 开头且无 `<d>` 即报错）。
11. **动作拍只写「主体 + 动词 + 对象」，修饰只许写方式 / 部位 / 方向**（2026-11-26 用户定）。
   - 程度与情态（结结实实、死死、捧得死紧、猛地、很静）只传递情绪、不传递动作，
     模型读不到就不做，还会把「过程」整段压没。
   - ❌ `结结实实磕了三个头` → ✅ `俯下身、额头碰地、抬起来、再碰地、再抬起来、再碰地`
   - ❌ `把丹捧得死紧` → ✅ `把两只手合在一起、把丹捧在掌心`
   - ❌ `眼皮猛地掀开` → ✅ `眼皮掀开、眼白先露出来`
   - ❌ `眼神很远很静` → ✅ `眼眶红着、两眼看着糖纸不眨`
   - **判据是语法形态，不是词表**——所以没见过的「渐渐地」「恶狠狠地」「清清楚楚」一样拦得住。
     三种句式：
     | 句式 | 例子 | 说明 |
     |---|---|---|
     | ① 形容词叠词作修饰 | 死死 / 紧紧 / 轻轻 / 渐渐 / 结结实实 / 干干净净 / 空落落 | **数量反复**（一截一截、一颗一颗、一圈圈）和**动词重叠**（说说笑笑、讲着讲着）放行——那是看得见的反复 |
     | ② 「得」字补语接程度词 | 捧得死紧、哭得厉害 | 结果补语写可见结果（吃得精光）不算，写程度才算 |
     | ③ 程度副词 / 情态副词直接修饰 | 很静、非常白、猛地、猛然、用力、使劲 | 副词是封闭类，语言学上可枚举，不是经验清单 |
   - 心法：**能拍出来的才是描述**。写不出来怎么拍，就说明写的不是动作。
12. **景别必须框住动作**（2026-11-26 第5集镜11 实测）。
   - 镜11 写的是「近景」，画面切在胸口，两个人的手都在框外——递丹这个动作写多少遍都不会出现；
     同理「跪着」和「站着」也分不出来，因为腿在框外。
   - 凡是动作落在手 / 膝 / 脚上（递、接、攥、捧、跪、磕头），景别就要带到那个部位，
     并在 `[Shot 1]` 里明写「画面从…带到…、把两只手都框在画面里」。
   - 写动作之前先问一句：**这个部位在框里吗？**
