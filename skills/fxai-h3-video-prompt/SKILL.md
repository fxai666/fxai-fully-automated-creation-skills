# MiniMax H3 视频提示词写作规范（我们管线专用）

把「一句创意」变成「H3 能稳定复现的结构化提示词」。

**核心结论**：H3 提示词不是氛围形容词的堆砌，而是**可观测的因果链**——`镜头 = 当前构图 + 主体状态 + 动作链 + 运镜 + 环境/物理反馈 + 光线 + 声音`。

覆盖我们用到的分支（T2VA / I2VA / L2VA 独立使用不展开）。**通用性**：MV（`sing`）与数字人口播（`speak`）共用这套规范，只有音频身份与「人在干什么」的措辞不同（演唱 vs 讲话）。格式由模式决定：单/多场景 = FL2VA，多参考 = Ref2VA。

## 0. 我们管线的模式映射（决定写哪套）

**单/多场景 → FL2VA（首尾帧）+ 音频参考 → FL2VA 三段式**，参考素材是「人物已在场景里」的图；**多参考 → Ref2VA（全参考）+ 音频参考 → Ref2VA 六段式**，参考素材是人物四视图 + 场景图。音频都是原音频。全表见 02。

> ⚠️ **三条铁律（用户规定）**：三个工作流全部带音频参考，纯文/纯图分支都用不上；提示词里不另行设计音轨；单/多场景按 FL2VA 写、多参考按 Ref2VA 写，各自成篇、一篇只用一种；**提示词都必须契合这段文案**（见 1.5）。

> ⚠️ **写几条提示词 = 音频被切成几段**。H3 只接受「17k+5 帧」时长；传「平均分段时长 = 10」时每段实际 **9.41667 秒**，尾段不足 3 秒并回上一段。

## 0.5. 段数决定提示词条数（先算再写）

「一条音频」≠「一条视频」：**先算段数**再写逐段提示词——`n = av.h3_segment_count(时长)`、`secs, bounds = av.h3_segments(时长)`（公式在 `fxai-audio-video`）。段数与提示词条数**一一对应**（`lines_data` 行索引按段取值），对不上时靠取模循环、后面几段重复用第一条。对照表见 04。

## 1. 音频处理铁律：原音频，不描述

`<Audio 1>` 标 `fully_copy`；`overall_soundscape` 只写「沿用原音频」；`non_diegetic_music` 写「无」。**音色完全复刻原音频，音色形容词一律留空**，后面只补**表演方式**（如「克制的演绎」）。逐字段写法见 02。

### 1.5 铁律：提示词必须契合这一段文案在讲什么

视频提示词**是这一段文案的画面化**：场景按内容定、道具跟着内容走（写「有名字的实物 + 它的状态」）、动作情绪跟着每段的情感标签走、每个元素都要能在这段文案里找到依据。single/multi 靠场景图落地、multiref 靠 `detailed_description` 写。判据见 04。

## 铁律速查（常驻）

必过的 17 条：**主体定义只写身份词一句（类目清单归延续分析）**｜音频原音频 + 音色词留空｜两种格式各自成篇｜段数用 `h3_segment_count(时长)` 算｜参考图必定义并引用｜六段小标题按管线走中/英文、内容一律中文｜运镜一条主线、动作写轨迹、视线写落点｜画风与时长档｜打斗镜先取词｜触发词必挂｜台词只挂人物。逐条见 04。

## 🔴 主体定义只指认（全局铁律，2026-11-12，任何分支适用）

主体定义**一句话到底**，只回答「这是谁 / 这是什么」；「要保住哪几类东西」写进延续分析：

```text
subject_definitions:
<Subject 1> 是 <Picture 1> 中的人物。
<Subject 2> 是 <Picture 2> 中的场景。

retention_analysis:
<Subject 1> (appears in [Shot 1]): fully_preserved - 保留人物身份、发型发色、服装样式与颜色、裤装、鞋履。
<Subject 2> (appears in [Shot 1]): fully_preserved - 保留场景的建筑、陈设与物品。
```

**两段都不写**具体颜色（月白/鸦青/浅杏色）、款式（窄袖/束腰/半扎丸子头）、材质（棉质/烟罗纱）、
具名物件细节（断纹素银簪/扇骨第三节旧裂纹）。`详细描述` 里也不复述外观，只写编号与动作。
短剧 / MV / 数字人口播 / 角色替换 / 主体替换**同一口径**。完整禁用词表与原因见 04 册「铁律 17 展开」。

## 自查速览（写完必过）

① 参考图都被分配了用途？② 人物身份/服装稳定？③ 主要动作有起因—推进—反应—终态？④ 运镜具体且绑定动作？⑤ 音频只标 `fully_copy`、音色词留空？⑥ 声音与事件同步？⑦ 跨镜头连续性保持？⑧ 形容词换成具体信息？

中文对白镜头还要逐条过：摘要首句写死坐标？无虚距离？视线只写落点？每句台词「说话人 + 对着 <Subject M> + 台词」齐全？见 04。
