# MiniMax H3 视频提示词写作规范（我们管线专用）

把「一句创意」变成「H3 能稳定复现的结构化提示词」。

**核心结论**：H3 提示词不是氛围形容词的堆砌，而是**可观测的因果链**——`镜头 = 当前构图 + 主体状态 + 动作链 + 运镜 + 环境/物理反馈 + 光线 + 声音`。

覆盖我们用到的分支（T2VA / I2VA / L2VA 独立使用不展开）。**通用性**：MV（`sing`）与数字人口播（`speak`）共用这套规范，只有音频身份与「人在干什么」的措辞不同（演唱 vs 讲话）。格式由模式决定：单/多场景 = FL2VA，多参考 = Ref2VA。

## 0. 我们管线的模式映射（决定写哪套）

**单/多场景 → FL2VA（首尾帧）+ 音频参考 → FL2VA 三段式**，参考素材是「人物已在场景里」的图；**多参考 → Ref2VA（全参考）+ 音频参考 → Ref2VA 六段式**，参考素材是人物四视图 + 场景图。音频都是原音频。全表见 02。

> ⚠️ **三条铁律（用户规定）**：三个工作流全部带音频参考，纯文/纯图分支都用不上；提示词里不另行设计音轨；单/多场景按 FL2VA 写、多参考按 Ref2VA 写，各自成篇、一篇只用一种；**提示词都必须契合这段文案**（见 1.5）。

> ⚠️ **写几条提示词 = 音频被切成几段**。H3 只接受「17k+5 帧」时长；传「平均分段时长 = 10」时每段实际 **9.41667 秒**，尾段不足 3 秒并回上一段。

## 0.5. 段数决定提示词条数（先算再写）

「一条音频」≠「一条视频」：**先算段数**再写逐段提示词——`n = av.h3_segment_count(时长)`、`secs, bounds = av.h3_segments(时长)`（公式在 `fxai-audio-video`）。段数与提示词条数**一一对应**（`lines_data` 行索引按段取值），对不上时靠取模循环、后面几段重复用第一条。对照表见 04。

## 1. 音频处理铁律：原音频，不描述

`<Audio 1>` 标 `fully_copy`；`overall_soundscape` 只写「沿用原音频」；`non_diegetic_music` 写「无」。**音色完全复刻原音频，音色形容词一律留空**，后面只补**表演方式**（如「克制的演绎」）。逐字段写法见 02。

> 🔴 **谁开口、唇形怎么跟音频 → 见 08 册**（模型级唯一事实源）：画面可多人，唇形只绑 `<Subject 1>` `(S1)`；无台词不写 `<d>`、第一帧开口、整段人声写一句全程同步、有静音才用时间锚点。`sing`（MV）与 `speak`（口播）同套。

### 1.5 铁律：提示词必须契合这一段文案在讲什么

视频提示词**是这一段文案的画面化**：场景按内容定、道具跟着内容走（写「有名字的实物 + 它的状态」）、动作情绪跟着每段的情感标签走、每个元素都要能在这段文案里找到依据。single/multi 靠场景图落地、multiref 靠 `detailed_description` 写。判据见 04。

## 铁律速查（常驻）

必过的 17 条：**主体定义只写身份词一句（类目清单归延续分析）**｜音频原音频 + 音色词留空｜两种格式各自成篇｜段数用 `h3_segment_count(时长)` 算｜参考图必定义并引用｜六段小标题按管线走中/英文、内容一律中文｜运镜一条主线、动作写轨迹、视线写落点｜画风与时长档｜打斗镜先取词｜触发词必挂｜台词只挂人物。逐条见 04。

## 🔴 主体定义只指认（全局铁律，2026-11-12，任何分支适用）

主体定义**一句话到底**，只回答「这是谁 / 这是什么」；「要保住哪几类东西」写进延续分析：

```text
subject_definitions:
<Subject 1> 是 <Picture 1> 中的人物。
<Subject 2> 是 <Picture 2> 中的场景。

retention_analysis:
<Subject 1> (appears in [Shot 1]): fully_preserved - 保留人物身份、发型发色、服装样式与颜色、裤装、鞋履。
<Subject 2> (appears in [Shot 1]): fully_preserved - 保留场景的建筑、陈设与物品。
```

**两段都不写**具体颜色（月白/鸦青/浅杏色）、款式（窄袖/束腰/半扎丸子头）、材质（棉质/烟罗纱）、
具名物件细节（断纹素银簪/扇骨第三节旧裂纹）。`详细描述` 里也不复述外观，只写编号与动作。
短剧 / MV / 数字人口播 / 角色替换 / 主体替换**同一口径**。完整禁用词表与原因见 04 册「铁律 17 展开」。

## 自查速览（写完必过）

## 🔴 镜头描述通用范式（v1 · 2026-11-26 定 · 所有镜头一律按此骨架填）

> 这是**写所有镜头**的骨架，不是某一集的写法。任何一镜的「详细描述」都按这 5 个槽位填，
> 顺序固定、不合并、不省略。填不进去，就说明这一镜还没想清楚。

```
<风格句：写实电影感的 X，光线>，<景别>，<机位>。
[Shot 1] <景别>镜头，<机位>，画面<取景范围：从哪带到哪 / 关键部位在不在框里>，建立 <Subject A> 作为场景：<Subject B> 在<位置>、<Subject C> 在<位置>，<首个动作：主体 + 动词 + 对象>。
At 00:0X.XXX, <Subject N> <动词 + 对象>，<动词 + 对象>。
At 00:0X.XXX, <Subject N> (Sx) <对着谁>，说：<d>[Chinese]<台词></d>。
At 00:0X.XXX, <场景副词：紧接着 / 这时 / 然后>，<Subject N> <动词链：动作一、动作二、动作三>。
```

| 槽 | 写什么 | 硬要求 | 门禁 |
|---|---|---|---|
| ① 取景 | 景别 + 机位 + **取景范围** | 动作落在手/膝/脚上，框就必须带到那个部位 | 景别框动作 |
| ② 建场 | `建立 <Subject A> 作为场景` + 每个主体站位 | 站位写死、距离写死 | 主体定义 / 摘要站位 |
| ③ 动作拍 | 主体 + 动词 + 对象，**一拍一行** | 只写动词不写形容词；每拍带 `At`；主体写 `<Subject N>` | 语法形态检查 / At / 裸代词 |
| ④ 台词拍 | 主体 `(Sx)` + 对着谁 + `说：<d>` | 独立成行、一行只一句、`At` 起头、`</d>。` | 台词行 At / 一行一句 / 台词闭合 |
| ⑤ 收尾拍 | 场景副词起头 + 动词链 | **不许**以 `<Subject N>` 裸起头 | 台词后裸动作行 |

**三原则**：① **一拍一行**（一个时间点只做一件事）；② **一拍一主体**（全篇不写「他/她」）；
③ **能拍出来才算**（动词具体、部位在框内、过程完整：谁→给谁→怎么给→结果）。

**自检一句话**：把这段描述当成拍摄指令交给摄影师，他能不能照着拍出来？拍不出来就是没写清。

下面的十二条铁律，就是这套范式在具体环节上的展开；`03-中文对白镜头.md` 是按槽位排的填法说明。

## 🔴 台词与表演十二条铁律（2026-11-25/26 用户定，短剧 / 多参考 / MV / 数字人通用）

1. **台词闭合**：`</d>` 后必须紧跟句号 `</d>。`，再写动作或下一句。漏句号 H3 会把后续文字继续当台词念出来。
2. **拟声词归位**：吱呀 / 磨牙 / 咯吱 / 窸窣等声音词只写「整体音效 / overall_soundscape」段，正文里会被当对白念。
3. **言语意图要落地**：摘要写「默念 / 开口 / 画外」，详细描述必须有对应 `<d>` 台词，或明确标注「无声口型 / 不出声」，否则模型自己编台词乱念。
4. **每镜必写表情 + 肢体**：至少一处情绪表情 + 一处肢体动作，缺一就是纸片人。此前只对 MV / 数字人强制，现对短剧同样强制。
5. **画外声音：画外主体 + 独立参考图槽（2026-11-26 定稿，首选）**：
   - ① 别人不在场景里说话 → `<Subject N> (Sx) 画外说：<d>[Chinese]…</d>。`（挂主体无妨，人不在画内）。
   - ② **自己的心声 / 内心独白（正脸可见时）→ 画外主体独立图槽**。第5集镜17 十五轮对照后的唯一有效写法：
     1. **参考图多传一份**：`images` 里把说话人那张图再放一次，成为新的 `<Picture M>`
        （例：`[016, 007, 013, 016]` → 少年图占第 4 槽）
     2. 主体定义：`<Subject N> 是 <Picture M> 中的男孩。`（N 顺排，M 是新增槽位）
     3. 延续分析：`<Subject N> (appears in [Shot 1]): fully_preserved - …沿用 <Picture M>…`
     4. 动作行照常写「嘴唇始终闭着、双唇抿成一条白线、下颌不动」
     5. 说话行**独立一行**：`At MM:SS.mmm, <Subject N> (Sx) 画外说：<d>[Chinese]…</d>。`
     6. 画面里不出现 `<Subject N>`——他只是声源
     ```
     主体定义
     <Subject 1> 是 <Picture 1> 中的男孩。
     <Subject 2> 是 <Picture 2> 中的女人。
     <Subject 3> 是 <Picture 3> 中的场景。
     <Subject 4> 是 <Picture 4> 中的男孩。      ← 同一张图另占一槽
     详细描述
     [Shot 1] …画面内只有 <Subject 1> 和 <Subject 2> 两个人：…
     <Subject 1> 眼皮猛地掀开、…、嘴唇始终闭着、双唇抿成一条白线、下颌不动；<Subject 2> 低着头、一动不动。
     At 00:01.800, <Subject 4> (S1) 画外说：<d>[Chinese]爷，我回来了。我回来晚了。</d>。
     At 00:05.300, <Subject 1> 膝盖先砸在地上、…、嘴唇始终闭着；<Subject 2> 眼睛肿着、双唇紧闭不出声。
     ```
     🔴 **绝不能复用画内主体的图**：`<Subject 4> 是 <Picture 1> 中的男孩` 等于告诉 H3「说话的就是画内那个人」，
     口型照样被驱动（第八轮实测失败）。门禁已硬拦「同一 `<Picture M>` 被两个主体共用」。
     🔴 台词窗按 3.3 字/秒 + 0.3s 气口算，10 字至少 3.3s，否则提交会被时长校验拒绝。
   - 备选（仅当上面不成立、且脸不在画面焦点时）：官方 voiceover `says in an off-screen voiceover: <d>…</d> while his lips remain completely closed.`（`base-modes-en.txt` §4.4，闭唇句紧跟 `</d>`）；早点铺版 `At MM:SS.mmm, 画外 <Subject N> (Sx) 的心声，他嘴唇始终不动：<d>…</d>`。
   - 🔴 实测结论：**纯文字闭唇描述压不住 H3 的口型驱动**（官方 voiceover / 早点铺双锁 / 加时间区间，三种都试过）。
     之前几次以为「锁住了」，其实是俯拍低头、嘴不在画面里造成的错觉。唯一可靠的是**让说话人成为画外主体 + 独立图槽**。
   - 旧词「画外道」废弃。
   ✅ `<Subject 3> (S1) 画外说：<d>[Chinese]这颗糖，是你爷早就给你留的。</d>。`
   ✅ `<Subject 4> (S1) 画外说：<d>[Chinese]爷，我回来了。我回来晚了。</d>。`（Subject 4 独立占 Picture 4）
6. **视线落点看对象**：落点是人（`<Subject N>`）用「落在 / 钉在」；落点是物件 / 手心 / 灵台等非人物用「看着 / 盯着」，不用「落在」——「落在物件」容易被 H3 把目光绑到画内别人身上。
7. **说话引导词两种范式、一律用「说」不用「道」**：
   - 范式 A 直接说：`<Subject N> (Sx) [表演动作，]说：<d>[Chinese]…</d>。`
   - 范式 B 表情/动词 + 说：`<Subject N> (Sx) [表演动作，][表情/语气副词]说：<d>[Chinese]…</d>。`（笑着说 / 低声说 / 尖着嗓子说，修饰词贴在「说」前、以「说」字收尾）
   - 硬约束：引导词以「说」结尾 + 冒号 + `<d>`；修饰词只在「说」前；`</d>` 后紧跟句号。笑道 / 低声道 / 冷声道 / 说道 / 道 全部禁止。
8. **主体引用格式：正文里每次指代人物都必须写 `<Subject N>` 全称，不许用「他 / 她」**（2026-11-25 用户定）。
   - ❌ `他跪下去、额头碰地磕了三个头` —— 前面没有主体，H3 分不清动作落到谁身上
   - ✅ `<Subject 1> 跪下去、<Subject 1> 额头碰地磕了三个头`
   - 判定按句切（`。` `；` 换行）：句内有他/她、却没有任何 `<Subject N>` 即违规。台词 `<d>` 里的「他」不算。
   - 「其他 / 他人 / 他乡 / 他日 / 他年 / 他处」不算代词，放行。
9. **镜头描述一律写大白话，把「谁把什么东西给了谁」这类关键动作写明白**（2026-11-26 用户定）。
   - 病根：文学化压缩写法只交代结果、不交代过程，H3 读不出意图，只能自己猜或干脆把描述当台词念。
     原来只写「少年给白眉老头磕头求得长生丹」，没写「老头把丹放到少年手心」，
     模型就不知道丹是哪来的，收尾动作还被当旁白念了出来。
   - ❌ `收在把丹捧得死紧` / `求得长生丹` —— 只有结果，没有谁给谁
   - ✅ `<Subject 2> 从袖子里摸出那颗丹、放进 <Subject 1> 手心` + `紧接着，<Subject 1> 对着 <Subject 2> 俯下身、额头碰地、抬起来、再碰地`
   - 具体做法：① 动词用日常口语（摸出 / 放进 / 攥住 / 合上手指），不用四字压缩；
     ② 每一步都落到 `<Subject N>` 身上；③ 连续动作之间用「紧接着 / 这时 / 然后」显式连起来。
10. **台词行后面不许紧跟以 `<Subject N>` 起头的裸动作行**（2026-11-26 第5集镜11 实测）。
   - 即使动作单独一行、`</d>。` 收得干干净净，H3 仍会把它接着当台词念：
     镜11 收尾的动作被 whisper 词级时间轴抓到，在 65.28–67.50s 被念成了旁白。
   - 两种合法写法：① 把这个动作并进台词行的引导句（`…看着 <Subject 2>，说：<d>…</d>。`）；
     ② 让这一行以场景副词起头：`At 00:07.200, 紧接着，<Subject 1> ……`。
   - 门禁 `_audit_detail` 已硬拦（台词行下一条以 `At …, <Subject N>` 开头且无 `<d>` 即报错）。
11. **动作拍只写「主体 + 动词 + 对象」，修饰只许写方式 / 部位 / 方向**（2026-11-26 用户定）。
   - 程度与情态（结结实实、死死、捧得死紧、猛地、很静）只传递情绪、不传递动作，
     模型读不到就不做，还会把「过程」整段压没。
   - ❌ `结结实实磕了三个头` → ✅ `俯下身、额头碰地、抬起来、再碰地、再抬起来、再碰地`
   - ❌ `把丹捧得死紧` → ✅ `把两只手合在一起、把丹捧在掌心`
   - ❌ `眼皮猛地掀开` → ✅ `眼皮掀开、眼白先露出来`
   - ❌ `眼神很远很静` → ✅ `眼眶红着、两眼看着糖纸不眨`
   - **判据是语法形态，不是词表**——所以没见过的「渐渐地」「恶狠狠地」「清清楚楚」一样拦得住。
     三种句式：
     | 句式 | 例子 | 说明 |
     |---|---|---|
     | ① 形容词叠词作修饰 | 死死 / 紧紧 / 轻轻 / 渐渐 / 结结实实 / 干干净净 / 空落落 | **数量反复**（一截一截、一颗一颗、一圈圈）和**动词重叠**（说说笑笑、讲着讲着）放行——那是看得见的反复 |
     | ② 「得」字补语接程度词 | 捧得死紧、哭得厉害 | 结果补语写可见结果（吃得精光）不算，写程度才算 |
     | ③ 程度副词 / 情态副词直接修饰 | 很静、非常白、猛地、猛然、用力、使劲 | 副词是封闭类，语言学上可枚举，不是经验清单 |
   - 心法：**能拍出来的才是描述**。写不出来怎么拍，就说明写的不是动作。
12. **景别必须框住动作**（2026-11-26 第5集镜11 实测）。
   - 镜11 写的是「近景」，画面切在胸口，两个人的手都在框外——递丹这个动作写多少遍都不会出现；
     同理「跪着」和「站着」也分不出来，因为腿在框外。
   - 凡是动作落在手 / 膝 / 脚上（递、接、攥、捧、跪、磕头），景别就要带到那个部位，
     并在 `[Shot 1]` 里明写「画面从…带到…、把两只手都框在画面里」。
   - 写动作之前先问一句：**这个部位在框里吗？**
