# 仙宫云速查（摘自官方教程，用于排障与手动兜底）

> 官方源：<https://www.xiangongyun.com> ｜本文档只保留与本技能包部署/使用相关的部分。

## 一、HuggingFace 下载：镜像加速

核心一句话：**把下载链接里的 `https://huggingface.co` 替换为 `http://hf.x-gpu.com`**。

```
官方： https://huggingface.co/Wan-AI/Wan2.2-Animate-14B/resolve/main/xxx.safetensors
镜像： http://hf.x-gpu.com/Wan-AI/Wan2.2-Animate-14B/resolve/main/xxx.safetensors
```
- 单文件（Jupyter → Terminal）：
  ```
  wget -nc -P /root/cloud/ "下载链接"
  ```
  空格必须保留，目录结尾的 `/` 必须保留。
- 整仓库：
  ```
  pip install "huggingface_hub[cli]"
  export HF_ENDPOINT=http://hf.x-gpu.com
  export HF_HUB_DOWNLOAD_TIMEOUT=180
  hf download 仓库ID --local-dir /root/文件路径
  ```
- 速度：某模型在平台**首次**下载是正常速度，之后所有用户 100–500 MB/s。
- 401 = 平台未收录该模型，**只能找客服收录**，换源解决不了收录问题。
- HF 仓库文件多且大，很容易把系统盘拉满，**下载前一定看剩余空间**。

## 二、传文件的 5 种方法（按适用场景）
| 方法 | 适用 | 要点 |
|---|---|---|
| 资源中心 / 网页直传 | 传少量小文件 | 受本机上行带宽限制，家庭宽带通常 1–5 MB/S |
| 仙宫云OS 本地上传 | 自己的机器 → 云 | 移动/联通限得比电信狠；文件多先压 zip；**压缩包名和包内文件名用纯 ASCII**，含中文和特殊符号会解压乱码 |
| VNC | 交互式操作、浏览器下载 | 谷歌浏览器打不开时删三个锁：`rm -rf ~/.config/google-chrome/Singleton{Cookie,Lock,Socket}` |
| Jupyter / 终端 | 跑命令 | `wget -nc -P <目录> "<链接>"` |
| SSH | **自动化首选** | 本技能包走的就是这条；API 文档 <https://www.xiangongyun.com/a/API> |

**云储存中转**（`/root/cloud`）：容器之间互传文件非常方便，也可以当下载落点。
注意云储存不支持传文件夹，只支持传文件；多选按住 Alt。

## 三、系统盘与数据盘
- 免费系统盘 = **镜像大小 + 100 GB × GPU 数量**（选镜像时界面直接显示）。
- 容器实例列表里能看到系统盘实时用量，鼠标悬停有具体数字。
- ⚠️ 盘留出余量，撑到 100% 满时系统起不来。
- 只剩几个 G 还要加数据时：**关机（释放 GPU）再开机，系统盘自动免费扩容**。
- 想放更多大数据，就挂数据盘，然后用本技能包的 `--set-dir <模型id>=<子目录>` 指过去。

## 四、其它排障
- 401：镜像未收录 → 找客服。
- 实例里没有 ComfyUI：本技能包脚本会自动 `git clone https://github.com/comfyanonymous/ComfyUI.git /root/ComfyUI`。
- H3 相关节点需要 ComfyUI **≥ 0.30.0**，更老版本会报节点不存在。
- 容器里跑 ComfyUI：装完节点/模型要**重启容器**才会加载。
- 端口：`8188` 是 ComfyUI 默认端口，平台控制台可能没放行公网，必要时用 SSH 端口转发
  （`ssh -L 8188:127.0.0.1:8188 -p <端口> -N root@<ip>`），本机再连 `http://127.0.0.1:8188`。
