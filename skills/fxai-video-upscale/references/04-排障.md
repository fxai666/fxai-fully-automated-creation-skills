# 04 · 排障

> **何时读**：提交了没反应、报错、成片不对（时长/尺寸/帧数/颜色/接缝）、显存炸了时。

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `找不到视频文件：xxx` | 传了相对路径 | 传服务端可读的绝对路径；本机存在的相对路径脚本会自动转绝对 |
| **成片只有第一段（时长 ≈ 一段）** | 111 的 `结束索引` 传成了 `0`，循环只跑一段 | 传 `-1`（＝跑完全部段）；脚本已按成片时长 < 源片 95% 抛错拦住 |
| `custom_validation_failed`（节点 108） | `fxai_duration` 被包成字符串，节点要 FLOAT | 确认 `fxai_duration` 在 `nodeconfig.json` 的 `non_string_placeholders` 里 |
| `custom_validation_failed`（节点 125） | `fxai_scale` 没包成字符串，节点要 STRING | 确认 `fxai_scale` **不在** `non_string_placeholders` 里 |
| 放大倍数没生效 / 精修门槛换算不对 | 124 与 123 的 `放大倍数` 没接同一个 125 输出 | 两处都接 `["125", 1]`，倍数值只填在 125 的 `value` |
| `required_input_missing`（节点 127） | `FxAiCleanGpu` 的 `anything` 没接 | 接 110 的第 1 个输出（循环结束） |
| 提交返回 `queued` 但很快失败 | 视频路径服务端读不到 | 确认传的是 ComfyUI 那台机器上的路径 |
| 成片没声音 | 114 的 `音频` 没接上 108 的音频输出，或源片本身无声 | 114 的 `音频` 接 `["108", 5]`；源片无声就正常 |
| 画面被拉横 / 变形 | 宽高占位符吃了默认 960×544 | 让脚本 ffprobe 源尺寸，或显式 `--width/--height` |
| **非整数倍画面纵向被拉伸** | 目标尺寸对齐到 128 倍数后裁切回目标 | 节点侧 `align_size` 取整 + bicubic 缩回；重跑该任务，验尺寸是否等于源 × 倍数 |
| 输出比输入少几帧 | 流式管线帧数对齐没开 | 124 的 `帧数对齐` 置「对齐」（默认开） |
| 画面边缘有黑带 / 暗边 | 分块外框在无邻居的一侧也做了羽化 | 节点侧 `create_feather_mask` 按 `edges=` 只在真有邻居的一侧渐变；重跑 |
| CUDA out of memory | 单段帧数 > 400，或目标 > 0.98 Mpx 却没分块 | 缩短分段（脚本按 `400 / fps` 自动算）、`分块边长` 置 0 让它自动 384、`批大小` 调小 |
| 分块接缝看得出来 | 重叠不足 | `分块重叠` 64 → 96（更慢）；或降倍数减少块数 |
| 整体偏色 / 提亮 | 色彩校正关了 | 124 的 `色彩校正` 置「开」（几乎不耗时） |
| 脸修完发白 / 发假 | 纹理保留太低、肤色回拉不足 | 调高 `纹理保留`、`肤色回拉`；只修脸不换脸时把参考图留空 |
| 报「必须给参考图」 | `--ref` 没传或传了空串 | `--ref` 是必填项，填服务端相对路径（如 `avatar/000.png`） |
| 参考图报不存在 | `--ref` 写成了本机路径 | 填服务端相对路径，脚本对盘符 / 反斜杠 / 多层子目录直接拒跑 |
| 8188 探不通 | 本机 ComfyUI 没启动 | 由「凤希本地AI控制台」启动，不由 AI 自己起 |
| 下载回来体积过小 / 打不开 | 半片 | 脚本按 `ftyp` 校验并抛错；重跑该任务 |

## 中断与续跑

中断任务按顺序调三个接口：`POST /interrupt`（断 running）→ `POST /queue` body `{"clear":true}`（清排队）→ `POST /free`（放显存）。本地那条提交命令保持不动，任务被接口中断后自行返回。

断了要接着跑：`fxai-workflow/shot_query.py resume <prompt_id>` —— 取回原工作流、把 `开始索引` 挪到下一段、`结束索引` 置 `-1` 重投，已生成的段命中服务端缓存直接复用。
