# 03 · 画质判据与取舍

> **何时读**：判断这条素材适不适合超分、倍数选多少、是否开人脸精修、交片前怎么验时。

## 一、这是生成式重绘，不是锐化

- 低清条件只在上游第一个 block 注入一次，条件很弱 → 细节是**生成**出来的，不是还原出来的。
- 真实纹理（木纹、发丝、织物、砖缝）还原得好，能根根分明。
- **金属高光、磨砂条纹、反光面会无中生有**：凭空长出一道高光、把磨砂玻璃长出横向条纹。这类材质占比大的镜头，倍数往上加反而更容易穿帮。
- 人脸会轻度「美颜化」：皮肤变干净、五官略往标准脸偏。人物特写交片前抽帧看脸。
- 喂进去的低清细节多少几乎不影响结果：源再糊 41%，输出锐度只掉 4% —— 它按自己的理解重建，不跟着源走。

## 二、背景虚化会被破坏

浅景深、电影感镜头（背景树叶/楼房虚化）会被「强行对焦」，整帧变清楚，画面失去层次。
判据：主体背后的虚化区域是否承担叙事（浅景深特写、光斑背景）。承担就降倍数（1.2× 破坏最轻），或只对前景做局部处理。

## 三、精修在链路里恒开，管的是「换谁」和「修不修」

顺序固定：**超分 → 精修**，精修不是可选项。两者都是整帧重绘、无身份约束，反过来会把修好的脸再重画一遍。

精修这一步干两件事，各有一条判据：

| 做什么 | 判据 | 怎么控制 |
|---|---|---|
| 换脸 | 接了参考图 + 认出角色（身份相似度 ≥ 0.10）+ 脸宽 < 换脸脸宽上限 | `--ref` 给参考图（默认自有角色 000/001），`--ref ""` 不换脸 |
| 修脸 | 脸宽 < 处理脸宽上限 | 门槛 120 × 倍数；脸更大的原样输出，省算力 |

- 精修**不增加分辨率**：128px 裁切框放大 4× 喂 VOSR2 重画，再缩回 128 贴回 —— **输出脸宽 == 输入脸宽**。它救的是「脸本身糊」（压缩块、老片、监控素材）和「换人」，不是「让已经清楚的脸更清楚」。
- 1.2× 下脸部锐度 149.6 → 149.8；2× 下 485.6 → 485.6（一位不差），逐像素差均值 0.001 —— 超分已经把脸重画清楚时，精修的输出与输入几乎一致，但时间照付 35~40%。
- 门槛从 96 提到 120 的代价：121px 以上的脸写回反而更软（锐度掉 27%），换脸不受影响（换的是身份，不是锐度）。所以 `换脸脸宽上限` 放宽到 120 是对的，`处理脸宽上限` 若发现大脸越修越软，退回 96。
- 两个脸宽门槛（`处理脸宽上限` / `换脸脸宽上限`）按原图像素标定，默认 120，接了 `放大倍数` 后实际门槛 = 120 × 倍数（1.5× 时 180px）。只在脸宽落在 120~144px 的中景脸，这个换算才改变结果。

## 四、交片前验三样

| 验什么 | 判据 |
|---|---|
| 几何没变形 | 输出尺寸 == 源尺寸 × 倍数；网格/门框类画面横竖线距一致，四角标记都在画面里 |
| 帧数没丢 | 成片帧数 == 源片帧数（节点补帧再裁回，输出帧数恒等于输入帧数） |
| 分块没接缝 | 放大后整帧看接缝：1920×1152 分 24 块（stride 320、重叠 64）接缝列梯度低于全图均值即正常 |

- 非整数倍（1.2×、1.3×）会对齐到 128 倍数再 bicubic 缩回目标尺寸；1.0× / 1.5× / 2.0× 本来就对齐，不进插值分支。
- 交片给用户时说清「这是重绘出来的细节」，别当「原片修复」承诺。
