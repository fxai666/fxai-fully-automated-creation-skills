# 03 · 画质判据与取舍

> **何时读**：判断这条素材适不适合超分、交片前怎么验时。

## 一、这是生成式重绘，不是锐化

- 低清条件只在 132 的 conditioning 里给一次，关键帧之间靠 VSRDecode 补——细节是**生成**出来的，不是还原出来的。
- 真实纹理（木纹、发丝、织物、砖缝）还原得好，能根根分明；11-12 实测梯度能量 2.149 → 3.072（1.43×），五官结构未变、无明显色偏，肤色略提亮。
- **金属高光、磨砂条纹、反光面会无中生有**：凭空长出一道高光、把磨砂玻璃长出横向条纹。这类材质占比大的镜头，倍率上不去（只有 2×），穿帮概率比旧自研链低。
- 人脸会轻度「美颜化」：皮肤变干净、五官略往标准脸偏。人物特写交片前抽帧看脸。

## 二、背景虚化会被破坏

浅景深、电影感镜头（背景树叶/楼房虚化）会被「强行对焦」，整帧变清楚，画面失去层次。
判据：主体背后的虚化区域是否承担叙事（浅景深特写、光斑背景）。承担就先别超分，或只对前景做局部处理。
2× 固定、没有小倍率可退，所以这类素材要事先跟用户说清楚「跑完景深会变浅」。

## 三、精修 / 换脸不在本链（2026-11-28 摘掉）

超分链路止于合并成片，不含人脸精修。要修脸 / 换脸**另外跑一条 `fxai-face-edit`**，
顺序仍是「先超分、后精修」（两者都是整帧重绘，反过来会把修好的脸再重画一遍）。

顺带一句历史结论：旧自研链在 1.2× / 2× 下精修的输出与输入几乎一致（逐像素差均值 0.001）却要多付 35~40% 时长——
这也是把精修从超分链里摘掉的原因之一。

## 四、交片前验三样

| 验什么 | 判据 |
|---|---|
| 几何没变形 | 成片尺寸 == 源尺寸 × 2；网格/门框类画面横竖线距一致，四角标记都在画面里 |
| 帧数没丢 | 成片帧数 == 源片帧数（VSRDecode 补回所有中间帧，输出帧数恒等于输入帧数） |
| 分段没接缝 | 放大后整帧看段边界：11-12 实测边界帧间差 4.26 vs 段内 3.57（1.19×），肉眼无拼接闪烁或亮度跳变 |

- 交片给用户时说清「这是重绘出来的细节」，别当「原片修复」承诺。
