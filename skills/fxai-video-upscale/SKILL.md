# 视频超分与精修

一条命令跑完：**源视频 → 分段 → 自研超分（任意倍数）→ 逐段修脸 / 换脸 → 合并成片**。
跑本机 ComfyUI（不计费），提交与下载全走公共层 `comfy_client`，工作流 `fxai-workflow/upscale-fvsr.json`，任务名 `upscale`。
超分与精修是同一条链上固定的两步，精修恒在链路里，没有开关。

## 直接开跑（最常用）

```bash
U=~/.workbuddy/skills/fxai-video-upscale/scripts/video_upscale.py

python "$U" 源视频.mp4 --ref avatar/000.png --out-dir .   # 1.5× + 修脸换脸，返回成片路径
python "$U" 源视频.mp4 --ref avatar/000.png --scale 2      # 人脸主体 / 要出特写
python "$U" 源视频.mp4 --ref avatar/000.png,avatar/001.png # 多人各换各的
python "$U" 源视频.mp4 --ref avatar/000.png --dry-run      # 只打印注入参数，不提交
```

脚本自己 ffprobe 源尺寸与帧率，按「单段帧数 ≤ 400」算分段，打印输出尺寸、段数与整片预估分钟数，
跑完校验 MP4 完整性与成片时长，返回本机成片绝对路径。
成片默认命名 `<源文件名>_up<倍数>x.mp4`，落在 `--out-dir`。

## 铁律速查（常驻）

1. 🔴 **交付物只认合并后的整片**（合并节点产出）；分段保存节点写的是过程文件，多段任务下只是其中一段。
2. 🔴 **顺序固定「超分 → 精修」**，精修恒在链路里，不得反序；两者都是整帧重绘，反序会把修好的脸再重画一遍。
3. 🔴 **参考图必填**：`--ref` 是必填项（服务端相对路径，逗号分隔，如 `avatar/000.png`），脚本先校验非空 / 单层子目录 / 图片扩展名 / 不是本机路径，缺了直接拒跑 —— 超分后要按参考图换脸，没参考图就换不了。每张脸自动跟所有参考图比一次，最像谁就归谁，各换各的；认不出只修不换。
4. 🔴 **脸宽门槛 120**（`处理脸宽上限` / `换脸脸宽上限` 都是 120，按原图像素标定）：实际门槛 = 120 × 倍数。超分把脸放大并重画过，门槛跟着倍数走，不必手算；脸宽超过实际门槛的原样输出。
5. 🔴 **倍数按素材定**：通用交付 1.5×；人脸主体 2×；只想提一提 1.2×（硬边会略软）；只去块降噪 1.0×。倍数范围 1.0~4.0。
6. 🔴 **源视频传服务端可读的绝对路径**，宽高必须跟源视频一致（占位符默认 960×544 会把竖屏拉横）。
7. 🔴 **单段帧数封顶 400 帧**（显存按帧数线性涨）；高帧率素材缩短分段，超过这条线必 OOM。
8. 🔴 **开工先报时间**：耗时 ≈ 帧数 ×（0.31 × 输出百万像素 + 0.06）秒，精修再占其中 35~40%；随片长线性增长，整片十几分钟到几十分钟是常态，把预估分钟数说清楚再提交。
9. 🔴 **只按地址发 HTTP，启停权在人**：8188 探不通就提示用「凤希本地AI控制台」启动，不由 AI 自己起服务。
10. 🔴 **产物只落当前工作区**，交付前抽帧验几何（尺寸 = 源 × 倍数）、帧数（等于源片）、接缝（放大后整帧看）。
11. 🔴 **这是生成式重绘，不是锐化**：真实纹理能补出来，金属高光 / 磨砂条纹 / 浅景深背景会被改写；交片时说明是重绘细节，不承诺「原片修复」。
