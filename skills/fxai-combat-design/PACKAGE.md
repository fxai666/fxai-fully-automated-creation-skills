# fxai-combat-design · 战斗设计与动作分镜（安装 / 使用说明）

> 纯设计技能：不碰 ComfyUI、不碰 GPU、不写任何提交脚本、不生成任何提示词。
> 只把「一句打斗构想」变成**战斗剧情 + 动作设计 + 空间调度 + 动作分镜**。

## 二、装到哪

- **用户级（推荐，对所有项目生效）**：把 `fxai-combat-design/` 整个文件夹复制到 `<用户名>/.workbuddy/skills/`
- **项目级（仅当前项目生效）**：复制到 `<项目>/.workbuddy/skills/`

装完无需配置、无需依赖、无需起服务。

## 三、怎么用

直接用大白话提需求：

> 帮我设计一段双刀对长枪的打戏。雨夜屋顶，30 秒竖屏，女方最后赢。

**说得越具体，结果越贴合**。讲清这几项效果最好：

| 要素 | 举例 |
|---|---|
| 人物与关系 | 师姐对师弟、主将对刺客、三人围攻 |
| 武器与能力 | 双刀、长枪、水系法术 |
| 场地环境 | 雨夜窄巷、云海浮岛、废弃船坞 |
| 想要的结果 | 谁赢、怎么赢、最想突出的一刻 |
| 时长与画幅 | 15 秒竖屏、60 秒横屏 |
| 结尾画面 | 收刀、雨停、镜头拉远 |

它会先补细节，再一项项和你确认；每步讲清设计取舍，你点头之后才继续。

## 四、资料库维护（明文）

资料全部是 `data/*.json`，可直接打开编辑：

```bash
PY="python -X utf8"
$PY scripts/combat_route.py --validate          # 改完必跑：编号唯一 / 正文非空 / 无占位符 / 类别已登记
$PY scripts/combat_route.py --list scenes       # 列出某域条目
$PY scripts/combat_route.py scenes --query "雨夜 窄巷"   # 抽查检索排序
$PY scripts/combat_route.py --terms             # 列出术语字典的 14 个类别
$PY scripts/combat_route.py --terms sword       # 按类别取词
$PY scripts/combat_route.py --read moves/01     # 读招式，末尾自动带出推荐术语
$PY scripts/combat_route.py --about             # 技能信息
```

- 加条目：往对应 `entries` 数组里追加对象，字段照现有条目抄。
- 改检索词：改 `keywords`（强词，有区分度）/ `weak_keywords`（单字与高频词，只作回退）。
- 单字词与高频通用词**必须**放 `weak_keywords`，放进 `keywords` 会污染召回。
- 术语字典（`glossary`）：新增术语要挂到 `categories` 里已登记的类别；`freq` 越高响应越强。

## 五、依赖边界

- **零外部依赖**：`combat_route.py` 只用 argparse/json/sys/pathlib，任何 Python 3.8+ 都能跑。
- **不连网、不写盘、不调用任何模型**。
- **不带效果样本**：本技能只交付文字资料，不引用任何图片/动图。

## 六、三条硬规则（开工先看）

1. **用户锁定的事实最高优先**：人物、武器、顺序、胜负、时长、媒介一旦给定，不得为套资料而改。
2. **先路由、后读正文**：先检索拿候选，再按需读；零命中要明说「原创设计」，匹配状态按实际结果如实报。
3. **一次只推进一个方案**：展示推荐 + 备选后必须等确认，确认前不读方案正文。
