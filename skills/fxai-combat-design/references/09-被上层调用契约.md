# 09 · 被上层技能调用契约

> 何时读：**上层技能自动来取词时**——即 `fxai-h3-video-prompt` / `fxai-short-drama` / `fxai-short-drama-script`
> 在写含打斗的镜头时，按各自 SKILL.md 的「打斗镜取词前置」条款来调本技能。
> 与并列各册的分工：01–06 册讲**本技能自己怎么走创作流程**；07 册讲**与短剧管线的分工**；
> **本册只讲「被调用」这一种用法**——上层不想要整套战斗设计，只想要**术语和动作链**。

---

## 一、为什么会有这份契约

技能之间**不会互相调用**。技能文件是给智能体读的说明书，智能体只会读**当前被触发的那个技能**的文件。
所以「打斗镜自动取词」这件事，**只能靠在调用方技能里写死一条前置步骤**来实现——
那一条写进了三处：

| 调用方 | 写在哪 |
|---|---|
| `fxai-h3-video-prompt` | `SKILL.md` 铁律 11 / 12 |
| `fxai-short-drama` | `references/01-提示词规范.md` §4.5 + `SKILL.md` 铁律 16 |
| `fxai-short-drama-script` | `SKILL.md` §四之二 |

**本册是那条前置步骤指向的落地说明。** 上层读到「去打 `combat_route.py`」之后，怎么调、调完怎么用，看这里。

---

## 二、什么时候调、什么时候不调

**调**：该镜头含**武术动作 / 兵器交手 / 打斗**——对招、劈砍、格挡、闪避、腾挪、摔擒、终结一击、
一打多清场、兵器脱手、剑气外放等。

**不调**：
- 纯文戏镜（对话、走路、抬眼、递东西）；
- 只需要氛围与运镜、没有身体动作的镜头；
- 只是想写物体物理（碎石飞溅、水花）——那是 `fxai-h3-video-prompt` 05 册的活，本技能不管提示词。

**一句话判据**：**镜头里有没有「谁对谁做了什么身体动作」。** 有 → 调。

---

## 三、三条命令（只跑命令，不通读源码）

```bash
PY="python -X utf8"                                    # Windows 中文环境建议加 -X utf8
S="<技能目录>/fxai-combat-design/scripts/combat_route.py"
```

### 1）检索招式条目 —— 拿动作链

```bash
$PY "$S" moves --query "<本镜动作关键词 3-6 个>"
```

- 关键词从**本镜的实际动作**里提，用具体词而非泛词：`单手长剑 劈砍 格挡` 优于 `打斗`。
- 返回 JSON，含 `primary / eligible / available / weak_fallback` 四个键。
- 取 `primary` 或 `eligible` 里的 `id`（形如 `moves/01`）。

### 2）读正文 —— 拿身体路径 + 推荐术语

```bash
$PY "$S" --read moves/<id>
```

- 返回该条目的**共通动作链**（重心与握剑姿态 → 肩肘腕带动剑刃 → … → 下一次挥剑条件）
  与**硬性规则 / 限制**。
- **末尾自动追加「推荐术语（取自 glossary，可直接取用）」**——这一段就是上层要的东西，
  形如：

  ```
  ## 推荐术语（取自 glossary，可直接取用）
  - 缠头裹脑（54，剑术起手）
  - 劈剑（9）
  - 撩剑（8）
  - 剑气（3，需蓄力前置）
  - 拧腰（32，发力）
  - 格挡卸力（74，衔接）
  ```

### 3）按类别 / 档位取词 —— 补充术语

```bash
$PY "$S" --terms                       # 列全部 16 类
$PY "$S" --terms sword                 # 列某类全部术语
$PY "$S" --terms guard_footwork --tier high    # 只看高频
$PY "$S" --terms "缠头"                # 按关键词模糊查
```

**16 类**：`leg` 腿法 / `fist` 拳法 / `palm_elbow` 掌肘膝靠 / `throw` 摔擒 /
`guard_footwork` 格挡身法衔接 / `sword` 剑术 / `spear_staff` 枪棍 / `saber` 刀术 /
`stance` 步法桩功 / `aerial` 腾空身法 / `power` 发力 / `weight_shift` 重心过渡 /
`shot_scene` 镜头场景词（辅助）/ `sfx` 音效（下游取用）/ `environment` 环境反馈 / `reaction` 细节状态与受击反馈。

**档位**：`high` 频次 ≥10 / `mid` 3–9 / `low` 1–2 / `ref` 词表。**默认优先 `high`。**

## 四、拿到之后怎么用

### 4.1 动作描述：术语当动词，不当标签

组合公式（见 08 册）：

```
[动作段] = 发力词（拧腰 / 蹬地）+ 招式词（缠头裹脑 / 扎枪）+ 衔接词（格挡卸力 / 顺势）
```

- ✅ 一段里落 **2–4 个词**，融进句子里：
  `<Subject 1> (S1) 后脚蹬地、拧腰送胯，长剑以缠头裹脑起手绕头侧一转，顺势劈剑自右上斜劈而下`
- ❌ 堆砌或当标签：
  `<Subject 1> (S1) 使用【缠头裹脑】接【劈剑】再接【格挡卸力】`
- ❌ 一段塞 6 个以上术语 → 动作互相打架（08 册「常见误用」）。

### 4.2 动作链：照招式条目的「共通动作链」走

招式条目的 `body` 里有一条**因果链模板**（起手 → 发力 → 接触 → 反馈 → 残留 → 下一次条件）。
上层的动作描述按这条链展开，天然就有「起因—推进—反应—终态」，不用自己编。

### 4.3 物体反馈与运镜：**不在本技能**

- 物体物理（火星散射、碎木弹开、泥浆回落）→ `fxai-h3-video-prompt/references/05-物理动作提示词示例.md` <!-- std:allow -->
- 运镜（`camera motion` 触发词、9 类词表、强度）→ `fxai-h3-video-prompt/references/06-运镜LoRA与运镜写法.md`

本技能**只给词汇与动作路径**，给不了提示词写法。

### 4.4 触发词：上层自动挂，本技能不管

打斗镜的 LoRA 触发词（`camera motion, prfight1`；终结镜加 `prfin1`，慢镜终结加 `prslow1`）由**上层管线自动挂载**——短剧管线 `drama_pipeline.build_lines_data(auto_triggers=True)`（默认开）按镜型注入到「详细描述 / `detailed_description`」第一行；规则唯一权威来源是 `fxai-h3-video-prompt/references/07-触发词挂载规范.md`。

**本技能不产出、也不判定触发词**（铁律 10：不写提示词）；取词只影响**动作描述怎么写**。

## 五、边界（越界就是违规）

| 边界 | 说明 |
|---|---|
| **不产出提示词** | 铁律 10：任何模型/平台的提示词、生成参数、负面词、字幕声音指令都不写。术语只提供**词汇与响应强度**，不是提示词模板 |
| **不改用户锁定的事实** | 人物、武器、顺序、胜负一旦上层给定，取词只为「怎么说」，不为「说什么」 |
| **零命中如实回报** | 无强命中时如实回「无命中」（`weak_fallback=true` 要一并说明），上层按常规写法走；招式名只来自库里真实存在的条目 |
| **不做资料吸收** | 把外部资料整理入库是另一条独立流程 |
| **不带效果样本** | 不引用、不推送任何图片/动图 |

## 六、完整时序（一条打斗镜走完）

```
上层技能读到「打斗镜取词前置」
   ↓
combat_route.py moves --query "<本镜动作关键词>"
   ↓  primary / eligible 里挑一个 id
combat_route.py --read moves/<id>
   ↓  拿到：共通动作链 + 推荐术语（glossary）
（可选）combat_route.py --terms <类别> --tier high   补词
   ↓
动作描述 = 发力词 + 招式词 + 衔接词（2–4 个/段，当动词用）
物体反馈句 → h3 技能 05 册公式
运镜 → h3 技能 06 册词表挑一条
   ↓
触发词（camera motion / prfight1…）→ 上层管线自动挂（本技能不管）
   ↓
上层自己出提示词（本技能不参与）
```

## 七、自查（上层用完可对一遍）

- [ ] 本镜确实含身体动作，不是纯文戏？
- [ ] 关键词是从本镜实际动作提的，不是泛词？
- [ ] 术语是**取到的**，不是自己编的？
- [ ] 一段 2–4 个词、当动词用、没堆砌？
- [ ] 动作描述有「起因—推进—反应—终态」，不是一串招式名？
- [ ] 零命中时写明了「无命中」，没有编招式名？
