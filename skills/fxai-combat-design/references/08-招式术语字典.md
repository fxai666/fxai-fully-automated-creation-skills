# 08 · 招式术语字典（glossary）

> 何时读：招式命中后要取词、要写专业动作描述、要确认某个术语的响应强度时。

## 一、这是什么

`data/glossary.json` 是**动作术语字典**：把武打训练集里高频出现的招式词、身法词、步法词、发力词、重心过渡词整理成可查的词表，每条带**频次**与**档位**。

- **是什么**：动作词汇表 + 使用强度参考（138 条 / 16 类）。
- **不是什么**：**不是提示词模板**，不含平台语法、生成参数、负面词；本技能不把它拼成任何提示词（见铁律 10）。
- **为什么有用**：动作描述写得越贴近这套词，专业感与动作稳定度越高；下游需要取词时也从这里拿。

## 二、档位规则（频次 = 响应强度）

| 档位 | 频次 | 用法 | 条数 |
|---|---|---|---|
| 高频 `high` | ≥10 | 响应最强，**优先使用** | 43 |
| 中频 `mid` | 3–9 | 有效，建议配一句完整上下文 | 35 |
| 低频 `low` | 1–2 | 响应弱，**必须**配完整上下文 | 4 |
| 参考 `ref` | — | 镜头/场景/音效/环境/细节状态词表，辅助用 | 56 |

**组合公式**：

```
[动作段] = 发力词（拧腰 / 蹬地 / 腰胯发力）
         + 招式词（主体：缠头裹脑 / 扎枪 / 扫堂腿）
         + 衔接词（格挡卸力 / 顺势 / 攻防转换）
```

**优先级**：具体招式 > 发力描述 > 攻防衔接 > 泛动作词。「踢击」「拳法连击」这类泛用兜底词排在最后，具体招式写得出时就用具体招式。

## 三、怎么取词

```bash
PY="python -X utf8"

$PY "<技能目录>/scripts/combat_route.py" --terms                              # 列全部 16 类
$PY "<技能目录>/scripts/combat_route.py" --terms sword                        # 列某类全部术语
$PY "<技能目录>/scripts/combat_route.py" --terms guard_footwork --tier high   # 只看高频
$PY "<技能目录>/scripts/combat_route.py" --terms "缠头"                        # 按关键词模糊查
$PY "<技能目录>/scripts/combat_route.py" glossary --query "腿法"               # 走通用检索
```

**招式命中后自动取词**：`--read moves/<id>` 会在正文末尾**自动带出该招式的推荐术语**（`moves.json` 的 `terms` 字段），无需另外查。

## 五、与 LoRA 触发词的关系（别搞混）

这是**两层**东西，不冲突：

| | 管什么 | 谁负责 |
|---|---|---|
| **触发词**（`prfight1` / `prfin1` / `prslow1`） | 动作**怎么表现**（是否启用打斗增强） | **下游**提示词层 |
| **术语**（本字典） | **打什么动作**（身体路径与招式名） | 本技能 |

- 本技能**只保证动作描述用词准确、专业**，不写触发词、不写任何提示词（铁律 10）。
- 下游（如短剧层）要写提示词时，可从本字典取词、并自行决定触发词挂载。
- ⚠️ 触发词是生造词，正常中文里不会自然出现，所以**术语字典里的词不会误触发 LoRA**。

## 六、与招式库的关系

- **招式库（`moves`）** = 一条完整技法的**结构化绑定 + 身体路径 + 接触反馈**（13 条，颗粒度大）。
- **术语字典（`glossary`）** = 拆到**单个动作词**的词汇表（138 条，颗粒度小）。
- 关系：一条招式 → 对应若干术语（已写进该招式的 `terms` 字段）。
- **顺序**：先用 `moves` 定「用什么技法」，再用 `glossary` / `terms` 把描述**落到专业词汇**上。

## 七、常见误用

- ❌ 把低频词（大背摔、贯耳捶、拍掌）当主力用而不配上下文 → 响应弱、动作糊。
- ❌ 有具体腿法可写，却只用「踢击」兜底 → 丢掉专业感。
- ❌ 一段里堆七八个术语，动作互相打架 → **一段 2–4 个足矣**，且要能串成因果链。
- ❌ 把本字典当提示词模板整段贴出去 → 它不是提示词，本技能也不产出提示词。
- ❌ 术语与招式 `binding` 冲突（如徒手角色用「扎枪」）→ 先过招式合理性门禁。
