# 05 · 剧情与分镜

> 何时读：要仿写案例结构、写分镜表时。

## 一、剧情设计（scripts 案例库）

1. 用**用户原文 + 创作卡 + 已确认动作方案**检索 `scripts`。
2. 有命中时读排名第一的案例；只有宽泛题材且前两名确实互补时才读第二个。
3. **设计前先告知用户**：「将参考《案例名》的结构进行仿写/改编，不复用其专有角色与无关情节。」
4. **只借用可迁移的剧情机制**：冲突升级、攻防转折、空间阶段、高潮接口、结尾结构、时长组织。
5. **不复制**案例的专有角色、连续句子、独特设定或与用户输入冲突的胜负。
6. 零命中时明确写「**案例库无关键词命中，剧情将全新设计**」。

## 二、分镜表（默认格式）

```
时间段 | 叙事目的 | 景别与机位 | 人物位置 | 动作与攻防 | 主运镜及终点 | 接力状态 | 环境反馈
```

写分镜时，每一格都要能读出「这一段画面在干什么」，而不是形容词堆叠。

### 分镜的四条硬要求

1. **一个时间段只留一个主运镜**：先定景别与机位，再选最少且最有效的运动。
2. **人物位置写方位与朝向**：谁在左/右、前/后、正/侧/背，谁挡谁，间隔多远。
3. **攻防成对**：每个攻击都要对应闪避、格挡、卸力或反击，并显示受力。
4. **接力状态**：上一镜末态必须写成下一镜的起点（位置、姿态、武器状态）。

## 三、镜头运动的取舍

- 复杂连击期间优先**稳定侧向跟拍**，读清攻防；不用 360° 环绕。
- 环绕只用于动作密度较低、地理关系已建立的短阶段。
- 运动模糊只用于边缘与轨迹，**人物轮廓与兵器接触点必须可读**。
- 不越轴：默认 A 在左、B 在右；只有正俯拍、中性正面或明确遮挡转场才能重建方向。

## 四、成稿必须满足

- 开场**快速进入有效动作**，不热身、不对视、不摆胜利姿势。
- 重要动作**有因果与结果**。
- 上一段末态成为下一段起点。
- **一打多不排队**（敌群要补位、变向、绕行）。
- **终结来自前文破绽**，不靠突然变强。
- 最后一帧**仍有主体、摄影机或环境余波运动**，不以 pose 结束。

## 五、常见误用

- ❌ 用案例的名字/角色/句子直接改头换面（换名字的复制品）。
- ❌ 分镜只写「快节奏高燃」这类形容词，不写具体画面。
- ❌ 十镜全是一个平视固定机位。
- ❌ 攻击没有防守与受力，动作不闭环。
