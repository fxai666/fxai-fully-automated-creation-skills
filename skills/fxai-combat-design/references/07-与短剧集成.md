# 07 · 与短剧管线集成

> 何时读：把本技能当作 `fxai-short-drama` 的「打斗镜头」模块来用时。**只做打斗镜头时才读。**

## 一、一句话结论

**格式沿用短剧那一套（渲染级），本技能只当上游「设计层」。**
不是二选一，而是分层：短剧负责「写提示词、出片」，本技能负责「打斗怎么打、怎么走位、镜头怎么排」。

## 二、两层分工

```
fxai-combat-design（设计层，本技能）
   战斗剧情 / 动作设计 / 空间路线 / 分镜表
        │  （只出「料」，不写提示词）
        ▼
fxai-short-drama-script（剧本层）
   把打斗内容填进「镜头六要素」→ 完整分镜脚本.md
        │
        ▼
fxai-short-drama（渲染层）
   H3 六段式提示词 → shots → 提交渲染 → 合并烧录
```

- **本技能不写提示词**（这是硬边界，和原版一致）：提示词包装、H3 六段式、生成参数、负面词、字幕声音指令都归短剧层。
- **短剧层不设计打斗**：没有本技能时，短剧的打斗镜靠自由发挥；接上本技能后，打斗镜的动作由本技能供料。

## 三、调用时机（关键）

**只有当短剧分镜里出现「打斗镜」时，才调用本技能。**
非打斗镜（对话、情绪、过场、空镜）一律不调；文戏按短剧自己的流程走，资料只服务于打斗镜。

判定：该镜的核心是**身体对抗**（攻防、兵器、招式、走位）→ 是打斗镜；核心是**信息与情绪**（说台词、看表情）→ 不是。

## 四、格式对照：本技能 → 短剧镜头六要素

本技能出的分镜表字段，逐项翻译成短剧的镜头六要素（短剧层照此填写）：

| 短剧镜头六要素 | 从本技能的哪个字段来 |
|---|---|
| **站位** | 人物位置 + 空间路线的锚点（写死画面方位与距离） |
| **运镜** | 景别与机位 + 主运镜及终点 |
| **表演动作** | 动作与攻防（动作设计链：目的→起势→响应→接触→反馈→位移→下一条件） |
| **视线** | 动作与攻防里的攻防指向（只写落点，不写禁令） |
| **表情** | 发力/受击/破招时的神态（按播放顺序写变化） |
| **背景** | 环境反馈 + 空间路线的环境机制 |
| **台词** | 剧情设计里的对白（挂在本镜在画的角色上） |

> 短剧层再把这六要素翻成 H3 六段式（主体定义/摘要/延续分析/详细描述/整体音效/非叙事音乐）——这一步**完全由短剧层完成，本技能不参与**。

## 五、打斗镜要补进短剧「详细描述」的动作规则

短剧的镜头格式管得住视线、表情、背景，但**管不住打斗的动作逻辑**。打斗镜必须叠加以下规则（写进该镜的详细描述与时间轴）：

1. **开场即交战**：打斗镜不热身、不对视、不摆胜利姿势。
2. **攻防成对**：每个攻击都要对应闪避、格挡、卸力或反击，并显示受力。
3. **接触点可读**：兵器/肢体的相交点不被火花、光效遮挡。
4. **接力状态**：上一镜末态（位置、姿态、武器状态）必须是下一镜的起点。
5. **一打多不排队**：敌群要有补位、变向、绕行，始终保持自己在动。
6. **终结来自破绽**：胜负来自前文已埋的破绽，不靠突然变强。
7. **最后一帧有余波**：以滑停、震颤、碎屑或衣袍回落收束，不以 pose 结束。

> 这几条就是本技能相对短剧格式「更规范」的地方——补在**动作维度**，不动短剧原有的视线/表情/背景规范。

以上是**单镜级**规则。**一场完整打戏的宏观节奏**（8 拍、情绪曲线、缺口机制、绝招谱系、状态锁定）见 `references/10-打斗节奏与大招谱系.md`——重头打戏必读。

## 六、兵器词转译（设计层 → 提示层）

> 本技能资料用专业兵器名（如「长枪」）是**正确的**——设计层描述的是动作本身。
> 但同一个词**直接写进 H3 提示词会被画成另一样东西**，短剧层照抄就会出穿帮镜头。

### 为什么需要这一层转译

H3 对「枪」的默认视觉是现代枪械。古装戏里写「长枪」「枪尖」「枪杆」，出片会出现带枪托的火铳 / 步枪轮廓。

**这不是本技能的问题**（设计层就该写长枪）——而是渲染层的词义默认不同。所以转译发生在**短剧层写提示词的那一步**，本技能仍然只管出设计。

### 已知转译表

| 设计层用词（本技能资料） | 提示层安全词（写进 H3） | 依据 |
|---|---|---|
| 枪 / 长枪 / 枪尖 / 枪杆 / 枪身 / 枪法 | 矛 / 长矛 / 矛尖 / 矛杆 / 矛身 / 矛法 | 古装题材：「长枪」被画成火铳；全镜改「矛」后重渲正常 |

### 执行规则

1. **资料库不用改**：`data/moves.json` 等照旧写「长枪」，保持设计层用词准确。
2. **短剧层拿到动作链后逐词转译**，再翻成 H3 六段式。
3. **全文清零，不只改出问题的那一镜**：整集重渲会让其余镜一并重新生成，同一批词会重复出问题。改完 grep 确认「枪」为 0。
4. **只在古装 / 冷兵器题材转译**：现代、科幻题材里「枪」就是枪，不改。
5. **遇到新的歧义词，回补这张表**：按同样格式加一行并写清依据，**只写验证过的**。

### 附：打斗镜常碰到的道具文字

H3 画不出可读中文，承载文字的道具一律写死「只有潦草线条涂鸦 / 色块与数字 / 空白纸」——不给参考图它也会自己写汉字。屏幕、界面、控制台类镜头判不可靠，解法是换构图。

## 七、交付接口（本技能交给短剧层什么）

打斗镜交付给短剧层的最小充分内容：

```
① 该镜在整场打斗里的位置（起手 / 升级 / 转折 / 终结）
② 人物位置与空间锚点（画面方位 + 距离）
③ 动作链（目的 → 起势 → 对手响应 → 接触 → 反馈 → 位移 → 下一条件）
④ 主运镜与终点（一个时间段只留一个主运镜）
⑤ 接力状态（上一镜末态）
⑥ 环境反馈（这一镜环境怎么响应）
```

短剧层拿到后，按六要素填进 `完整分镜脚本.md`，再翻成 shots。**本技能不产出 shots，也不产出提示词。**

## 八、资料复用（重要边界）

- **只复用架构与规则，不复用他人的资料正文**：本技能的 `data/*.json` 全部是原创，不导入任何第三方资料库的数据。
- 需要更多题材时，**在我们自己的库里新增原创条目**（编辑 `data/<域>.json`，跑 `--validate`），而不是搬运别家的数据。
- 跨技能不互相 import：本技能零依赖；短剧层按本节规则**读本技能的输出文本**即可，不需要跑本技能的脚本（脚本只服务本技能自己的检索）。

## 九、常见误用

- ❌ 把本技能的分镜表**直接**当提示词提交（它只是设计层，缺渲染所需的六要素与六段式）。
- ❌ 在短剧里把文戏也套本技能流程（只有打斗镜才调）。
- ❌ 用本技能写 H3 提示词 / 生成参数 / 负面词（越界）。
- ❌ 把第三方资料库的数据导入本技能（版权与一致性双重问题）。
