# 判据表（做两层诊断时对照）

## 内容层五维度（零外部数据，现在就能做）

每条诊断都要能指到具体哪一句。

| 维度 | 看什么 |
|---|---|
| 开头钩子 | 第 1 句靠悬念/冲突/利益/反差/共鸣留人，够不够利 |
| 中间结构 | 推进顺不顺、哪里讲糊涂 |
| 卖点呈现 | 卖点用哪几句说的、击不击中人 |
| 结尾引导 | 引导什么、自然不自然 |
| 口播可读性 | 句子长短、顺口吗 |

## 数据层

给了播放/完播/互动/转化才分析；没给就列出要导的字段。

## 复盘六步

1. **对齐内容**：确认领域（哪个岗位）/ 标题/主题/类型（人设型·信任型·变现型）/ 文案原文；领域问出来才入库（落错污染该岗位计数）。
2. **两层诊断**：内容层按上表五维度逐条走；数据层按上节处理。
3. **一条一入库**：每问题单独成条，带全分类、关键词、结论、证据、下次动作；分类从受控表选（选错被拒）。命中已有条目按指纹计数 +1，不新增条目；满 2 次即顽疾。
4. **登记素材缺口**：发现"这类内容缺素材"就记进缺口表，积累后按表补。
5. **导出**：跑 `exp export`，按领域生成经验库文件。
6. **沉淀（可选）**：命中 ≥2 且已确认的经验升规则写进技能。
