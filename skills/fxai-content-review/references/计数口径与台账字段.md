# 计数口径与台账字段（入库前照查）

## 指纹与计数口径

- **领域内计数**：`指纹 = 领域|分类|关键词`，只在本领域内计数（文章与口播的"开头没给利益"各算各的）。
- **经验条目去重**：`指纹 = 分类|关键词`，命中已有条目**计数 +1**，不新增条目。
- **顽疾线**：命中 ≥2 即顽疾。
- **待沉淀线**：命中 ≥2 + 已确认 + 未晋升，进 `exp pending`。

## 受控词表

| 参数 | 取值 | 默认 |
|---|---|---|
| `--领域` | 通用/文章/口播/视频/素材/复盘 | 通用 |
| 经验 `--分类` | 钩子/结构/卖点/结尾/画面/节奏/呈现/话题/发布时间/变现/承接/其他 | — |
| 经验 `--状态` | 待观察/已确认/已作废 | 待观察 |
| 素材 `--分类` | 人设型/信任型/变现型 | — |
| 素材 `--状态` | 可用/待补拍/作废 | 可用 |
| 缺口 `--优先级` | 高/中/低 | 中 |
| 素材 `--领域` | 素材（查素材自动带「通用」） | — |

标签先在受控词表登记（代码强制），写不进未登记标签。

## 台账硬约束

1. **只登记本地最终产物**：ComfyUI 服务端的参考图、四视图、中间帧属生产过程，不入库。
2. **只存路径不存文件本体**：本地文件不存在则 `verified=0`，仍可入库但复用前复查；传未登记标签会报错（先 `tag add`）。
3. **经验去重靠指纹不靠语义相似度**：算同类用同一 `领域|分类|关键词`。
4. **库目录解析顺序**：`FXAI_DATA_DIR` > `fxai_global.json.data_dir` > `工作目录/_fxai_data`。
5. `经验库_{领域}.md` 是导出产物**只读**。

## 沉淀通路

`exp add` 记一笔 → 反复命中变顽疾 → `exp promote` 升规则 → 写进对应技能。`exp promote --id N` 把条目（规则/反例/落点技能）追加进 `已沉淀规则.md`（落点看 `SCOPE_SKILL`）。
