# 命令与导出格式（照查照抄）

工作目录 `scripts/`，命令均为 `python db.py <子命令>`：

```
init / scopes → 建库建表(旧库补领域列)返回库路径 / 列出领域
exp add --领域 --分类 --关键词 --状态 --结论 --证据 --动作 --关联 → {id, hits, new}
exp list [--领域 x] [--分类 x] [--状态 已确认] [--min 2] → 条目
exp stat [--领域 x] → 总数/命中/按领域/按分类/顽疾 top10
exp export [--领域 x] → 按领域写 经验库_领域.md（不传各领域一份）
exp pending [--领域 x] → 命中 ≥2+已确认+未晋升条目
exp promote --id 7 → 晋升为规则，追加进 已沉淀规则.md
tag add --名称 --类别 --别名 [--领域 素材] ; tag list [--领域 素材]
material add --path <绝对路径> --分类 --子类 --类型 --画幅 --时长 --标签 --领域 → {id, verified}
material list [--领域 x] [--分类 x] [--标签 y] [--状态 可用] ; material use --id 3 → 次数+1
gap add --缺什么 --优先级 --经验 --领域
gap list [--领域 素材] [--状态 待补] ; gap done --id 2
```

## 导出格式

- `exp export` 按领域拆成 `经验库_文章.md` 等，**岗位技能只读自己领域那份**；SQLite 是唯一真相源，`经验库.md` 是它的只读投影。
- `exp promote` 落点看 `SCOPE_SKILL`，把规则追加进 `已沉淀规则.md`。
