# 产物命名规则（下载 / 交付 / 复用时照查）

## 服务端产物名 → 本地落地名

- 服务端 `FxAiAudioManager` 保存的文件名是 `<目录内已有数量:03d>_audio.wav`（首次即 `000_audio.wav`），不是 `人声.wav`。
- 下载一律用 `/fxai/tasks/result` 返回的 url 令牌（形如 `audio|<歌名>_vocalsep|000_audio.wav`），落地时再改名为 `人声.wav`；令牌由接口返回，按文件名硬拼令牌会取错产物。
- 输出子目录每歌一个独立目录（由 `audio_rel` 派生），编号按歌递增、不跨歌累加。

## 本地落地清单

| 产物 | 落地名 | 说明 |
|---|---|---|
| 人声（分离原始） | `人声.wav` | `out_dir/<vocal_name>` 存在即判定已有分离结果，直接跳上传与分离 |
| 人声（去噪成品） | `人声_去噪.wav` | 默认 `denoise=True` 自动生成，取 `res["denoised"]` |
| 伴奏 | 传 `accomp_name` 时下载 | 默认 `None`（当前工作流只保存人声一路） |
| 服务端子目录 | `out_sub`，默认 `<歌名>_vocalsep` | 令牌第二段 |

## MV 管线内的命名（用户定）

- **`人声.wav` = 去噪后的成品**（即交付物，写进 meta.json 的 outputs）。
- 分离出来未去噪的那版叫 `_人声.wav`（`_` 开头 = 中间件，收尾自动清理）。
- 已存在 `人声.wav` 时自动复用，直接读本地文件、跳过服务端算力。
- 开关：`fxai_global.json` 的 `vocal_separation`（默认 **true**；设 false 则回到「直接用音乐对齐」）。
