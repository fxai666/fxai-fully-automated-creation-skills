# fxai-standard · 技能包通用标准规范

凤希AI 全部 `fxai-*` 技能共用的操作规范。新建或修改技能（SKILL.md / references /
scripts）前先读本册；改完跑 `scripts/check_standard.py` 体检，ERROR/WARN 清零再收工。

## 本技能文件清单（先读这里，再决定读哪册）

|---|---|

| `references/02-文档写作规范.md` | 写或改 SKILL.md / references / 脚本注释时（过程叙述、句式、豁免） |

| `references/04-规范体检.md` | 跑 check_standard.py、查判据与豁免标记时 |
| `references/05-工作区与全局配置.md` | 定工作区口径、全局配置层级、数据目录时 |

## 第零法则（先于六条硬规则）

1. **代码优先**：能脚本化的一律脚本化，检查点前移到写稿/生成阶段，不靠人看文档记得。
2. **跨技能改动先问**：改动落到别的技能（它的 SKILL.md / references / scripts）先问用户，不问不动。
3. **规范只写归属技能，别处只留指针**：一条规则归哪个技能就在哪个技能写全；其他技能引用处只留一行指针（如「通用法则见 fxai-standard 硬规则 6」）。

## 铁律速查（常驻）

1. 🔴 **文档只写最终执行规则与判据**：过程叙述（已修 / 踩坑 / 实测数据…）不进文档与注释；规则条目不附现成句子，要说明写判据。<!-- std:allow -->判定词禁的是「记录我方操作过程」——平台用词、违禁词表、判据词表、功能名、对观众的话术，撞词正常保留（豁免机制见 02 册）。
2. 🔴 **只写「怎么做」，不写禁令清单**：禁令清单不落盘；表禁用一律用「不得 / 禁用」，不用弱化措辞（见 02 册词表）。<!-- std:allow -->
3. 🔴 **SKILL.md ≤9KB**（文件体积，右键属性即得），路由三要素齐全：文件清单表 + 什么时候读 + 只读对应册其余不读；细节进 references，只留指针与铁律速查。
4. 🔴 **产物只落当前工作区** `<工作区>/<项目名>/`：无 projects_root 层；用户个人目录只作素材来源；运行时临时覆盖改内存、只在上屏生效，用户明说「改配置」才写 config.json。
5. 🔴 **目录整洁**：垃圾文件零残留；孤儿脚本（现役入口零引用且文档未提及）删除，不留归档。项目目录同此：过程文件进 `_tmp/`，交付前跑 `check_project_clean.py` 返回 0。
6. 🔴 **本地服务只走接口，启停权在人**：技能只按地址发 HTTP，不拉起、不管理服务；探不通报错让人启动。
7. 🔴 **能力只从技能包取，不探本地环境**：模型清单、节点清单、配置文件、安装目录、权重文件一律不读、不列举、不扫描；存在性判定走服务端接口（被 `queued` 即存在）。用户明说「去看一下 XX」才动，且只动他点名的那一样。见 07 册。
8. 🔴 **路径不写死本机盘符**：字体 / 浏览器 / node / 私钥按 `FXAI_FONT_DIR`、`PATH`、`FXAI_CRYPT_KEY` 解析，产物走工作区。判据见 03 册。
9. 🔴 **客户端为前置的技能开工先自检**：要读安装目录 / 数据目录 / 登录身份 / 账号库的技能，按 08 册四步判定；缺配置、未登录就停在该步，提示装软件 → 登录 → 复制安装口令，补完重跑（见 08 册）。
10. 🔴 **项目清单与记忆只由脚本写**：产物目录建好即 `fxai_project.py init` 建档，每完成一段用 `episode`/`stage`/`deliver` 登记；加工作业开工先用 `context` 定位项目；产出技能登记在 `check_standard.py` 的 `PRODUCERS`，缺指针体检报 ERROR、`--fix` 补齐。判据见 01 册。
11. 🔴 **记忆先判层再写**：项目口径归 `B/_fxai_memory.md`（`fxai_project.py memory --add`，开工先读）；技能模板与判据归该技能 `references/`；跨技能规范归本技能。五层判据见 01 册「记忆分层与归属」，口径写回被操作对象，操作方只留通用判据。
12. 🔴 **视频渲染中问进度一律查，不等终态**：问「第几镜 / 还剩几镜 / 还要多久」直接用 `shot_query`，判据＝保存目录里非 `merged/` 的分镜文件数，共用目录按任务窗口过滤。见 01 册。
13. 🔴 **会话记忆只留现行口径**：口径进 `MEMORY.md`，日期日志只做变更台账；旧结论被推翻就地改写为现行口径，同一关键词全文只命中一处；标题写口径不写时间；日志不记过程叙述与操作流水。判据见 09 册。
14. 🔴 **资源引用只填服务端相对路径**：`<子目录>/<文件名>`（三类基准不进串、子目录单层、正斜杠、多图逗号串）；rel 只从上传 / 生图 / 产物令牌、常量、接口列表取，本机路径只作上传源与 ffmpeg 入参。判据见 10 册。
15. 🔴 **出图规范只在 `fxai-poster`**：封面 / 海报 / 配图的设计规范与质检门禁归它（08 册定要素、09 册三道门、10 册提示词、`qc.py` 出判据）；其他技能引用处留指针，出图后跑 `qc.py pre|prompt|post`，退出码 2 即重做。
16. 🔴 **对比片按源片画幅拼**：横屏上下、竖屏左右（判据见 01 册）。
17. 🔴 **浏览器运行时走公共件**：Chrome 检测与缺失补装统一调 `scripts/ensure_chrome.py`，其他技能只留指针；判据见 11 册。

## 规范体检

```bash
python scripts/check_standard.py <技能目录> [--junk] [--fix]        # 自身
python scripts/check_standard.py --skills-root <技能根> [--fix]      # 全包批量
python scripts/check_project_clean.py <项目目录> [--strict] # 交付目录
python scripts/fxai_project.py check <项目目录>            # 清单结构
python scripts/sync_categories.py --site <站点根> [--write] # 类别表 → 客户端页面
python -B scripts/ensure_chrome.py --check-only --json  # 浏览器就绪自检（零下载零安装）
```

清单与记忆的读写一律走 `scripts/fxai_project.py`（init / episode / deliver / stage / memory），
调用见 `references/01-产出铁律.md`；契约受检范围 = `check_standard.py` 顶部 `PRODUCERS`
字典（技能名 → category），新技能接入时在字典加一行。判据与豁免见 `04-规范体检.md`。

项目类别只在 `categories.json` 定义一处：`init` 的合法取值、体检的类别校验、客户端项目页的
类型栏与默认阶段都由它推导。加类别改这份 JSON + 跑 `sync_categories.py --write`，三步见 01 册「类别表」。
