# 11 · 浏览器运行时与自动安装

> **何时读**：能力需要本机浏览器、检测 Chrome 是否就绪、浏览器缺失要自动下载安装时。

## 一、适用范围与边界

本册管的是**运行时依赖的可用性**，与 07 册「能力只从技能包取、不得勘察本地环境」分属两件事：浏览器可执行文件属于运行前提，检测它按 03 册「路径可移植」的取值顺序走；模型清单、节点清单、权重文件、服务端配置仍归 07 册约束，不得借本册顺带勘察。

跨技能共用，只有一份实现：`scripts/ensure_chrome.py`。各技能在引用处留一行指针，不得自造探测与安装逻辑。

## 二、解析顺序

| 序 | 来源 | 取值 |
|---|---|---|
| 1 | 全局配置 `chrome_path` | `~/.workbuddy/fxai_global.json` 里用户显式指定的可执行文件；只取该字段 |
| 2 | `PATH` | 常见可执行名按序查 |
| 3 | 平台默认位置 | 由系统环境变量与固定相对子路径拼接，零盘符字面量 |
| 4 | 自动化库自带浏览器 | 仅在调用方带 `--allow-bundled` 时兜底 |

命中判据：文件存在且版本可读。POSIX 跑 `--version` 子进程返回 0；Windows 读 PE 版本资源，零窗口零启动。仅看文件存在会命中残留旧版本或失效快捷方式。返回 `source` 标明命中层级，便于排查优先级串位。

## 三、缺失时的自动安装

| 平台 | 取包形态 | 安装方式 |
|---|---|---|
| Windows | 官方在线安装器 | 静默参数装到系统默认位置 |
| macOS | 官方磁盘映像 | 挂载后把应用包复制进系统应用目录 |
| Linux | 官方 deb / rpm 包 | 交系统包管理器安装 |

- 下载协议限定 HTTPS，主机名须过官方域名白名单 `dl.google.com`；主机名不匹配即拒收，装完重新按第二节解析一次。
- 下载落在临时目录，体积上限 300 MB，失败即清理；临时目录由上下文管理器回收。
- 安装属系统级修改：调用方在任务开始前告知用户，日志打清将执行的动作与取包来源。
- 权限不足或包管理器返回非零时，返回明确原因与手动安装指引，不做提权重试。
- 平台不在支持表内，或取包地址未过白名单，退出码 2。

## 四、调用契约

```bash
python -B scripts/ensure_chrome.py --check-only       # 只检测，零下载零安装
python -B scripts/ensure_chrome.py --json             # 检测 + 缺失则自动装，输出 JSON
python -B scripts/ensure_chrome.py --check-only --json
python -B scripts/ensure_chrome.py --allow-bundled --json
```

返回字段：`ok`（布尔）、`path`（可执行文件，缺失为空）、`source`（命中来源）、`action`（`none / installed / failed`）、`reason`（失败原因）、`version`。退出码：0 就绪、1 未就绪且安装失败、2 参数或平台不受支持。只读模式未就绪时 `action=none`、`reason` 写明零下载零安装。

## 五、接入方式

技能需要浏览器时，先跑 `--check-only --json`；未就绪则调用一次默认模式，拿到 `path` 后交给自动化库作 `executable_path`。技能文档里只留一行指针，不复写取值顺序、下载源与安装命令。

`--allow-bundled` 由调用方决定：自带浏览器与 `channel="chrome"` 语义不同，命中该项时按 `executable_path` 使用。

## 六、视口与截图固定规格

页面自动化按固定视口运行，截图尺寸恒定，跨机器可比对；视口漂移即视为页面记录失效。

| 项 | 取值 | 判据 |
|---|---|---|
| 视口 | `1440 × 900` | 主流后台在 1366 以上布局稳定；1440 覆盖笔记本与外接屏，避开响应式折叠；高度 900 让首屏覆盖上传区 |
| 设备像素比 | `1` | 高分屏不放大，截图恒为 1440×900 |
| 截图 | 视口截图、PNG、非整页 | 整页截图高度随内容变化，无法复用比对 |
| 锁定 | 运行时不改写视口 | 站点记录按视口指纹校验，不一致即判失效 |

指纹格式 `宽x高@像素比`，由 `viewport_fingerprint()` 生成，写进站点记录后每次复用前比对。

## 七、验收判据

| 项 | 判据 |
|---|---|
| 唯一实现 | 全包内只有一个探测安装脚本，其余技能只留指针；`check_standard.py` 命中重复的 `*chrome*.py` 即 ERROR |
| 零盘符 | 脚本内不出现盘符绝对路径，平台默认位置由环境变量拼接 |
| 命中判据 | 以版本信息可读为准，POSIX 子进程返回 0，Windows 读 PE 版本资源 |
| 只读模式 | `--check-only` 全程零下载、零安装、零系统改动 |
| 来源可信 | 下载地址协议与主机名均过白名单 |
| 幂等 | 已就绪时重复调用返回 `action=none`，不重复安装 |
| 字段收敛 | 全局配置只读 `chrome_path` 一个字段，其余字段零读取零输出 |
| 视口恒定 | 连续两次截图尺寸一致，均为 1440×900，像素比为 1 |
| 记录对位 | 站点记录带视口指纹，不一致时判失效而非直接点击 |
