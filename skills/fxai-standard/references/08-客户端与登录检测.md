# 08 · 客户端软件与登录检测

> **何时读**：技能要读本机客户端（软件安装目录 / 数据目录 / 登录身份 / 用户数据）时，
> 开工第一步。与 07 册同时适用：本册只按配置项取值，不枚举磁盘。

## 适用面

技能脚本出现下列任一依赖，本册生效：

| 依赖 | 典型用法 |
|---|---|
| `<software_install_dir>`（固定目录名 `fxai`） | ffmpeg / libass / whisper / 随软件带的第三方工具 |
| `<software_data_dir>`（固定目录名 `fxaitool`） | conda 环境、缓存、项目素材 |
| `<software_install_dir>/userinfo.json` | 当前登录人 `myid` / `usertoken` / 昵称 |
| `<software_data_dir>/sqlite/user_<myid>.db` | 该账号的角色、素材、台账等用户数据 |

## 检测时机

- 每轮对话开工一次；用户换机器、换账号、改过配置后重跑。
- 只读 `~/.workbuddy/fxai_global.json` 及其字段指向的两个路径；不列目录内容、
  不按固定目录名扫盘找替代（07 册边界）。

## 四步判定（顺序固定，第一个不通过即停）

| 步 | 判据 | 不通过的结论 | 用户动作 |
|---|---|---|---|
| 1 配置 | `~/.workbuddy/fxai_global.json` 存在且为合法 JSON | 客户端未安装，或装完没生成全局配置 | 装客户端 → 登录 → 该页复制智能体安装口令 |
| 2 路径 | `software_install_dir`、`software_data_dir` 都有值，且两个目录都存在 | 配置不完整；盘符变了（换盘、移动盘未挂载） | 回配置页重新复制口令 |
| 3 登录 | `<software_install_dir>/userinfo.json` 有非空 `myid` | 客户端未登录，或登录的不是这个账号 | 打开客户端登录一次 |
| 4 账号库 | `<software_data_dir>/sqlite/user_<myid>.db` 存在 | 该账号还没在客户端建库 | 登录后打开一次用到该库的页面，让客户端建表 |

四步全过即为**就绪**：安装目录、数据目录、登录身份、账号库都有来源，后续按技能
自己的路径解析取用，文档与脚本里不写死盘符。

## 提示要素（判据）

命中缺失时，一次说清五件事，不分多轮挤：

1. **缺哪一项**：按上表「不通过的结论」定性——安装、配置、登录、还是建库。
2. **下载入口**：凤希AI伴侣客户端与整合包，渠道以安装说明第一节为准
   （GitHub 仓库 `fxai666/fxai-toolkit` 与夸克 / 迅雷 / 百度网盘）。
3. **教程入口**：站点「软件配置（全面使用凤AI必看）」与「视频教程」两个区块，
   按视频装、按视频配。
4. **配置入口**：客户端 → 本机配置 → 技能运行环境 → 复制智能体安装口令 →
   粘贴回对话，由智能体写入 `~/.workbuddy/fxai_global.json`。
5. **回执**：请用户补完回一句，随即重跑本册检测；重跑不过继续停在该步。

## 与 07 册的分界

| 事项 | 07 册边界 | 本册做法 |
|---|---|---|
| 路径来源 | 遍历各盘找 `fxai` / `fxaitool` | 只取全局配置里写好的两个字段值 |
| 目录 | 列安装目录、看装了什么 | `os.path.isdir` 判存在，不列内容 |
| 身份 | 拿本机账号信息反推能力 | 读 `userinfo.json` 的 `myid` 定位账号库 |
| 缺口 | 现场勘察补齐 | 停在该步，由用户安装 / 登录 / 复制配置 |

## 统一实现

`scripts/check_client.py` 是唯一执行点，各技能直接调用，不各写一份：

```bash
python <fxai-standard>/scripts/check_client.py          # 文本
python <fxai-standard>/scripts/check_client.py --json   # 机器读
```

退出码：`0` 就绪 / `2` 未安装或配置不全 / `3` 未登录 / `4` 账号库缺失。

技能包里不带 fxai-standard 时，按本册四步判据自行实现，判据、结论措辞、退出码
与本册保持一致。
