# 06 · 字体与素材授权

> **何时读**：任何文字上屏/上图（图片 / 视频 / 封面 / 字幕 / 图表 / 标题卡）选字体时；
> 交付记录字体与素材授权时。

## 总规则

- 🔴 **任何文字，字体只从白名单选取**：图片、视频、封面、字幕、图表、标题卡、
  网页模板——只要是交付物上看得见的文字，全覆盖。
- 🔴 **交付时随产物记录字体名与协议**（写进交付清单）：字体名 + 授权协议，可追溯。
- 素材（图片 / 音频 / 视频片段）同口径：只用授权明确的素材，交付记录来源与协议。

## 白名单 A（开源协议，不可撤销，首选）

| 字体 | 协议 | 典型用途 |
|---|---|---|
| 思源黑体 / Noto Sans SC | SIL OFL | 正文、字幕、UI 首选 |
| 思源宋体 | SIL OFL | 正文衬线、文艺向标题 |
| 得意黑 Smiley Sans | SIL OFL | 标题大字、封面主标、章节页（斜体设计，不用于正文） |
| 霞鹜文楷 / 霞鹜新晰黑 | SIL OFL | 国风向、细笔画场景 |
| 更纱黑体 | SIL OFL | 等宽、代码、数据 |
| 寒蝉系列 | SIL OFL | 标题点缀 |
| 悠哉字体 | SIL OFL | 手写感标题 |
| Mona Sans | SIL OFL | 西文/混排 |

## 白名单 B（厂商免费商用声明，可调整）

阿里巴巴普惠体、HarmonyOS Sans、OPPO Sans、Honor Sans、MiSans、抖音美好体。

- B 类凭厂商公开免费商用声明可用；厂商政策可能调整，交付记录里注明声明来源与日期。

## 预装与取用

- 本机开源中文字体现状：Noto Sans SC（3 字重）、思源宋体 Heavy；得意黑按需下载到
  项目字体目录（OFL）。网络下载加 `--ssl-no-revoke`。
- 代码里字体栈写白名单字体名；引用具体文件时用绝对/相对路径指向白名单字体文件。

## 微软雅黑边界（查证定稿）

- Windows 授权覆盖：屏幕渲染、编辑、输出到设备（打印）——这些场景可用。
- 重新分发 / 嵌入交付物（随包发字体文件、嵌入式字段）按微软官方字体 FAQ 谨慎处理，
  默认不走这条路；交付物上的文字用白名单 A 出图/烧录，不发字体文件。
- 前一版把微软雅黑整体判为商业禁用的说法偏重，已按官方 FAQ 纠正；跨技能引用以本册为准。
