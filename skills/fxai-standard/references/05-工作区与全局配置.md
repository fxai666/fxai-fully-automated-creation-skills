# 05 · 工作区与全局配置

> **何时读**：定产物落点口径、全局配置层级、技能数据目录时。产物落点的执行规则
> 在 01 册；本册是配置侧口径。

## 工作区口径

- 🔴 **项目空间 = `<projects.root>/<分类>/`**：根目录记在全局配置 `projects.root`
  （换机 / 换盘只改这一处），实际内容（成片、教程、文章、作品）一律建在项目空间对应
  分类下（`<分类>/<项目名>/`）。规则正文见 01 册「产物落点」。
- **工作区 ≠ 项目空间**：本地 ComfyUI 安装目录这类代码仓库只是干活的地方，脚本、录制、
  `_tmp/` 可以留在那儿，**项目目录不建在工作区根下**。
- 🔴 **本机物理路径一律进全局配置**：项目空间根（`projects.root`）、素材库根
  （`asset_library.root`）、ComfyUI 安装目录（`comfyui.root`）、解释器、字体目录、品牌资源
  统一记在 `~/.workbuddy/fxai_global.json`，读取只走 `fxai-common/global_config.py`
  （`projects_root()` / `asset_library_root()` / `comfy_root()`）；技能源码与文档都不写盘符。
  环境变量 `FXAI_PROJECTS_ROOT` / `FXAI_COMFY_ROOT` 可临时覆盖，优先级高于配置文件。
- **全局配置只管本机数据，不定项目落点**：项目根仍按下方解析链算，不往上跳
  `.workbuddy` 目录找配置。

## 落点解析优先级（代码实现口径）

脚本自动解析（`fxai-workflow/output_layout.py` 等）仍按下列顺序，落到的工作目录若属
代码仓库类工作区，**交付前要按 01 册把项目移到项目空间对应分类下**：

```
FXAI_PROJECTS_ROOT 环境变量
  > 工作区级 <工作区>/_fxai_global.json 的 projects_root
  > 当前工作目录
```

- `fxai-workflow/output_layout.py` 的 `root()` 是唯一执行点；其他技能不各自解析。
- 技能数据目录（台账、缓存、索引）落 `工作目录/_fxai_data`，不带 projects_root 前缀。

## 配置读写

- 🔴 **运行时临时覆盖不落盘**：对话里临时改默认值 / 换人物 / 换尺寸，改脚本顶部内存区
  （如 `RUN_OVERRIDES`）或传参生效；只有用户明说「改配置」才写 `config.json`。
- **三级读取顺序**：内存覆盖 > 脚本 SPEC 默认 > `config.json`；meta 类信息（时长等）
  按技能约定读，不进全局配置。
- **配置只存相对路径**（如 `avatar/005.png`），按本机 `fxai_root` 解析；角色参考图
  只锁面貌，穿搭归当次作品（`--char-desc` / SPEC）。
