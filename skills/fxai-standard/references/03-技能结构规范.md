# 03 · 技能结构规范

> **何时读**：新建技能、拆 references 分册、压 SKILL.md 体积、清理技能目录时。

## SKILL.md（每个技能的入口）

- 🔴 **≤9KB**（文件体积，右键属性即得）：超了把细节降级到 references，不靠压表述过关——判据压成一行会丢判据本身。
  口径：按字节判；中英混排实测字节/字符比 1.68~1.70，9KB ≈ 5400 字符，纯中文 9KB 约 3070 汉字。行数不论，内容多少以体积为准。
- 🔴 **路由三要素**（缺一即 ERROR）：
  1. **文件清单表**：一张表列全 `references/*.md`（列头含「文件 | 什么时候读」）。
  2. **什么时候读**：每册一句话说清触发场景。
  3. **只读对应册**：明确写「确定本次要做什么之后，只读对应的那一册，其余一律不读」。
- **frontmatter 三件套**：`name`（= 目录名）、`description`（一句话定位 + 触发词 +
  不做什么）、`agent_created: true`。
- **结构**：定位一段 → 文件清单表 → 直接开跑（最常用命令）→ 铁律速查（常驻，编号）→
  指针（跨技能依赖、公共件）。细节一律进 references，SKILL.md 只留指针。
- **铁律速查常驻**：硬约束编号列成速查表，读 SKILL.md 就能看到全部红线，不必翻分册。

## references 分册

- 按「什么时候读」拆册，不按技术层拆；一个触发场景只对一个册。
- 命名 `NN-名称.md`（两位编号 + 中文名）；册内写细节与完整规则，SKILL.md 留指针。
- 册与册不重复：一条规则只在一个册写全，别处指针（第零法则 3）。
- 跨技能共用规则归 `fxai-standard`；技能自己的规则归自己，引用处只留一行指针。

## scripts/ 与数据分离

- 🔴 **固定程序实现放技能 `scripts/`，项目只放数据与产物**：场景 prompt 清单、
  标题卡 JSON、节拍时间码、文案、音频留项目；`_*.py` 不落项目目录。
- 脚本注释与 docstring 同受 02 册写作规范约束（过程叙述禁入）。

## 路径可移植

- 🔴 **技能包内不出现本机绝对路径**：盘符路径（`<盘符>:/…`、`<盘符>:\…`）不得写进
  SKILL.md / references / scripts / json / 注释。
- 按归属解析，取值顺序固定：
  | 对象 | 解析顺序 |
  |---|---|
  | 字体目录 | `FXAI_FONT_DIR` → `%WINDIR%/Fonts` |
  | 浏览器 / node | 全局配置字段 → `PATH` → `%ProgramFiles%` 下探测 |
  | 构建机私钥 | `FXAI_CRYPT_KEY` → `~/.fxai-crypt/…` |
  | 产物 | `<工作区>/<项目名>/`（铁律 4） |
- 文档举目录写占位形式（`<交付目录>/<项目名>`），不落真实盘符。
- 服务端实例路径（`/root/…`、`/workspace/…`）是部署目标，不属本条规定范围。
- 判据：`check_standard.py` 命中盘符绝对路径即 ERROR；`C:\Windows` / `C:/Windows`
  作系统目录缺省值放行。
- 🔴 **浏览器运行时唯一实现归 `fxai-standard/scripts/ensure_chrome.py`**：检测、取值顺序与缺失补装全在 11 册写全；其他技能引用处只留一行指针，`scripts/` 里出现独立的 `*chrome*.py` 即 ERROR。

## 目录整洁

- 垃圾文件零残留：`__pycache__/`、`.pyc`、`.DS_Store`、`Thumbs.db`、备份副本。
- **孤儿脚本判定**：现役入口（SKILL.md / references / 被引用脚本）零引用、零提及 →
  彻底删除，不留归档副本。
- 删除后跑 `py_compile` 全量通过 + `check_standard.py --junk` 复检 0 项。
