# fxai-novel-writing（小说创作）

## 硬规则（不看分册也要守）

1. 每本小说一个独立文件夹 `<工作区>/<书名>/`，全部产物落该文件夹内；立项先定**作品分类**（主 / 子分类、频道、平台分类），见 `references/05-作品分类.md`。
2. 短篇小说正文写进**一个文件**，正文 ≥ 8000 汉字，章节标题独立成行分隔。
3. 长篇小说先立**档案**（人物画像 / 创作思路 / 章节梗概 / 目录），再写正文；正文**每章一个文件**，**每章 ≥1000 汉字**、单章 ≤5 万字（番茄发布门槛）。
4. 短篇与长篇**都写人物画像**，落 `<书名>/02-人物画像.md`。
5. 封面图先出**封面提示词**（写明目标平台与尺寸），出图调 `fxai-comfyui-image-gen` 的 `generate_image`，成品按平台尺寸裁切为 JPG。
6. 出封面图前先读 `fxai-comfyui-image-gen/SKILL.md` 的「开工前置」与「长期约定」。
7. 封面提示词按 `fxai-poster/references/10` 的六段骨架写（文案进引号 + 位置 + 字号层级），平台尺寸与必备要素按 `08` 册，出图后跑 `qc.py post` 过门。
7. 写完跑 `python scripts/check_novel.py <书名目录>`，全绿才往下走。
8. 交付前由**大模型通读终检**（错别字 / 语病 / 逻辑 / 设定一致性），见 `references/06-模型终检.md`。
9. 写正文前先读 `references/07-创作方法论.md`：开篇钩子型、章末钩子级、爽点节奏逐项达标才往下写。
10. 投稿番茄前跑 `python scripts/check_signing.py <书名目录>`，再按 `references/08-签约验收.md` 做内容验收，结论落 `<书名>/签约验收报告.md`。
11. **第一人称题材禁区**：主角以「我」自称时，不写主角父母的生病与死亡（全书内保持健在）；要「失去感」就写衰老与力不从心、分离与远行、代际隔膜。详见 `07-创作方法论.md` 第九节。
12. **正文体例**：章标题独立成行不带标记；不插场景分隔符；不出现中英混排间距；引号只用中文弯引号。投稿前跑 `normalize_punct.py --apply` 统一（`08-签约验收.md` 第六节）。

## 产出物结构

- 短篇：`<书名>/01-作品档案.md` + `<书名>/正文.md` + `<书名>/02-人物画像.md` + `<书名>/封面/`。
- 长篇：`<书名>/00-目录.md`、`01-创作思路.md`、`02-人物画像.md`、`03-章节梗概.md`、`正文/第001章 章名.md`、`封面/`。

- 番茄投稿：`<书名>/签约验收报告.md`（见 `references/08-签约验收.md`）。

## 八步流程

1. **立项**：定书名、体裁（短篇 / 长篇）、目标平台、作品分类。
2. **人物画像** → `02-人物画像.md`（短篇、长篇都写）。
3. **长篇立档**：写 `01-创作思路.md`、`03-章节梗概.md`、`00-目录.md`。
4. **写正文**：短篇单文件；长篇按章分文件。下笔前按 `07-创作方法论.md` 定开篇钩子型与章末钩子级。
5. **封面**：出提示词 → 调 `fxai-comfyui-image-gen` 出图 → 按平台尺寸裁切。
6. **脚本验收**：`python scripts/check_novel.py <书名目录>`。
7. **模型终检**：大模型通读全文与档案，见 `06-模型终检.md`。
8. **签约验收**（番茄平台做）：`python scripts/check_signing.py <书名目录>` → 过 A 类否决项、给 B 类五项打分 → 写 `签约验收报告.md`；格式缺陷按 `references/08-签约验收.md` 第六节跑 `reflow_paragraphs.py` / `normalize_punct.py` 整改后复验。
