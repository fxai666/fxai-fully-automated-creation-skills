# 03 人物画像规范

## 一、产出

落 `<书名>/02-人物画像.md`，短篇与长篇共用。

## 二、字段模板

每个人物一个块：

```markdown
## 姓名（角色定位）

- 性别 / 年龄：
- 身份 / 职业：
- 外貌：身高、体形、脸型、发型、标志性特征
- 性格：3–5 个关键词 + 一句话行为逻辑
- 背景：出身、成长经历、当前处境
- 目标：想要什么、害怕什么
- 关系：与其他主要人物的关系
- 口头禅 / 标志动作：
- 人物弧光：起点 → 终点
```

## 三、角色配额

| 体裁 | 主角 | 配角 |
|---|---|---|
| 短篇 | 1–2 | 3–5 |
| 长篇 | 2–4 | 8–15 |

## 四、配角两要素

每个配角写清两项：与主角的**关系**、推动主线的**功能**（对照 / 助力 / 阻碍）。

## 五、外貌字段复用

外貌字段供 `references/04` 的封面提示词直接取用：身高体形、发型、标志性服装各写一句。
