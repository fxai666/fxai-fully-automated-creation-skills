# 06 模型终检

## 一、何时做

正文与档案全部写完、`check_novel.py` 通过后，交付前由**大模型通读一遍**。

## 二、检测项

| 项 | 查什么 |
|---|---|
| 错别字 | 同音字 / 形近字误用（的得地 / 在再 / 做作 / 即既 / 其他其它 / 账帐 / 需须） |
| 标点 | 中英文标点混用、成对标点缺失（引号 / 括号 / 书名号）、省略号与破折号用法 |
| 语病 | 成分残缺、搭配不当、语序混乱、重复啰嗦 |
| 逻辑 | 时间线、因果关系、前后矛盾 |
| 设定一致性 | 人名 / 地名 / 称谓 / 年龄 / 能力设定全书统一，且与人物画像一致 |
| 章节结构 | 章号连续、章名与目录及梗概一致 |
| AI 味 | 模板化句式、过度排比、口号式结尾 |

## 三、做法

- 通读范围：正文全文 + 全部档案。
- 问题逐条列出：位置 + 原文 + 建议改法。
- 改完复读改动处，确认无新增问题。
- 终检通过才交付。

## 四、与脚本的分工

- `check_novel.py` 查硬指标：字数、章节标签、档案齐备。
- 本册查软指标：语言、逻辑、一致性，由大模型完成。
