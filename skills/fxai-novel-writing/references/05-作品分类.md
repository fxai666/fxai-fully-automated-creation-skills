## 二、定分类三步

1. 看主线定主分类：升级打怪 → 玄幻 / 仙侠；情感 → 言情；探案 → 悬疑；权谋 → 历史；职场 → 都市。
2. 看视角定频道：男主视角 → 男频；女主视角 → 女频；不限 → 通用。
3. 选一个子分类，查目标平台的分类名，填入档案。

## 三、档案字段

短篇 `01-作品档案.md` 与长篇 `01-创作思路.md` 都写这四个字段：

| 字段 | 取值 |
|---|---|
| 主分类 | 上表主分类之一 |
| 子分类 | 该主分类下的子分类 |
| 频道 | 男频 / 女频 / 通用 |
| 平台分类 | 目标平台后台的实际分类名 |
