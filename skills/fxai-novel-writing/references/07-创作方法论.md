# 07 创作方法论

写正文前读本册。短篇与长篇共用；与 `01`、`02` 册的格式规则并行，本册只管「怎么写得抓人」。

开工前先读 `{data_dir}/经验库_小说.md`（若有），把里面每条的「下次动作」带进本轮。该文件由 `fxai-content-review` 从番茄驳回原因、章节完读、签约评估不通过的理由累积导出；同类问题满 2 次即为顽疾，可晋升为本册或 `08` 的硬规则。

## 一、开篇钩子六型（第一章必用一型，全书只用一型）

| 型 | 开法 | 适用 |
|---|---|---|
| ① 危机当成型 | 冲突已在进行，读者被直接扔进现场 | 都市 / 悬疑 / 玄幻 |
| ② 损失砸落型 | 一个具体的坏结果已经发生（丢了什么 / 死了谁 / 被退婚） | 逆袭 / 复仇 |
| ③ 秘密目击型 | 主角看见不该看见的事 | 悬疑 / 权谋 |
| ④ 身份错位型 | 主角被当成另一个人，或顶替了谁 | 言情 / 古言 |
| ⑤ 倒计时型 | 一个期限压下来（三天 / 最后一场 / 再败一次就……） | 竞技 / 职场 / 系统文 |
| ⑥ 认知推翻型 | 先给一个读者认定的事实，第一句就推翻 | 反转向短篇 |

三条硬规则：

1. 第一章第一句写动作或对话，不写身世、不写世界观、不写景。
2. 第一章内出现一次具体冲突：有人挡路 / 有东西被夺 / 有话被当众撂下。
3. 第三章末尾抛出全书主问题，让读者带着一个明确疑问往下走。

前 1000 字禁令：不写主角生平、不写设定说明、不用「话说」「自古以来」起手。

## 二、章末钩子四级（每章必带，连续两章换级）

| 级 | 内容 | 用法 |
|---|---|---|
| 1 悬念 | 抛出一个未答的问题 | 常规章 |
| 2 危机 | 新威胁已到门口 | 长篇每 3 章一次 |
| 3 反转 | 刚确立的认知被推翻 | 长篇每 10 章一次 |
| 4 情感 | 关系出现不可逆的裂痕或靠近 | 感情线章 |

- 钩子落在最后一两句，写完后不补解释。
- 短篇 6–8 章：全篇至少 1 个 3 级钩子。

## 三、爽点与节奏

- 忍耐期上限：主角连续受压不超过 3 章，第 4 章给一次小胜或补偿。
- 小爽点（每章 ≥1）：占到便宜 / 赢下一句 / 拿到一点信息 / 被认可一次。
- 大爽点：打脸、升级、逆转、真相落地。

| 体裁 | 小爽点 | 大爽点 |
|---|---|---|
| 短篇 6–8 章 | 每章 1 个 | 第 3、6 章各 1 个 |
| 长篇 | 每章 1 个 | 每 5 章 1 个 |

## 四、章内五拍

接住上章钩子 → 推进一件事 → 出现阻碍 → 付出代价或拿到小胜 → 落本章钩子。

- 一章只推进一条线，副线留到下一章。
- 一章视角不超过 1 人。

## 五、反转与埋线

- 反转三层：① 推翻读者认知 ② 动机翻转（谁才是布局的人）③ 善恶对调。
- 反转必须在上一章埋一颗钉：一个眼神 / 一句软话 / 一个动作 / 一件没解释的物件。
- 长篇反转间隔 ≤10 章；短篇全篇 ≥1 次。

## 六、断章位置

断在四处之一：真相将露未露 / 危机降临瞬间 / 新人物现身未报名 / 抉择未决。

不断在：一段解释的中间 / 一个场景完整收束之后 / 大段回忆末尾。

## 七、叙述与对话

- 情绪用动作与生理反应写（攥紧、后退半步、喉咙发紧），不直接写「他很愤怒」。
- 对话一句 ≤30 字，带潜台词（说的和想的不一致）。
- 每人一套说话方式：句式长短、用词层级、是否带敬语；与 `03-人物画像规范.md` 的口头禅字段一致。
- 内心独白用自由间接引语，不加引号、不加「他想」。

## 八、意象与对照

- 选一个贯穿物件（信物 / 一棵树 / 一首歌），全书出现 ≥3 次，最后一次落在结尾章。
- 主角配 2–3 个对照角色，各自代表不同的外挂来源（资源 / 武力 / 情感）。

## 九、第一人称题材禁区

- 主角以「我」自称、形象与作者本人重合时，**父母的生病与死亡一律不写**；父母在全书内保持健在。
- 要「失去感 / 无力感」的同等重量，改用四类素材：
  - **衰老与力不从心**：母亲穿不上针、父亲拧不动螺丝、上两层楼要歇一歇。
  - **分离与远行**：父母搬走、老屋要拆、摊子收了、铺子关门。
  - **代际隔膜**：说不出口的话、两代人各自的沉默、各自把难处咽下去。
  - **隐忍的付出**：把好东西留给子女、把疼说成不疼。
- 祖辈（爷爷奶奶）的离世、非亲属角色的死亡，不受此限。
- 旧稿已写父母病故的，改造时**保留幻想段与章末钩子，只换现实困境**。
