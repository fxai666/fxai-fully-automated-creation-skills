# 01 短篇小说规范

## 一、产出与目录结构

```
<书名>/
├── 01-作品档案.md           # 书名 / 体裁 / 分类 / 目标平台 / 一句话简介
├── 正文.md                 # 唯一正文文件
├── 02-人物画像.md           # 人物设定（必产）
└── 封面/                    # 封面独立成目录，内部结构见 references/04-封面图与平台尺寸.md
```

- 作品档案文件名固定 `01-作品档案.md`，字段见本册第七节。
- 正文文件名固定 `正文.md`（HTML 版为 `正文.html`）。
- 人物画像文件名固定 `02-人物画像.md`，模板见 `references/03-人物画像规范.md`。
- 封面独立成目录 `封面/`，成品为 JPG，母版为 PNG。

## 二、字数

- 正文汉字数 ≥ 8000（`check_novel.py` 硬校验）。
- 计数口径：中文字符（正则 `[\u4e00-\u9fff]`），标点与英文单词不计入。
- 篇幅上限按目标平台定：知乎盐选短篇理想 1–3 万字。

## 三、章节标签

每章一个标题，**独立成行、不带任何标记**：

```markdown
第一章 章名
```

- 首尾按需加 `楔子` / `尾声`。
- 章序号全篇统一：中文数字（第一章）或阿拉伯数字（第1章）二选一。
- 章名 2–8 字。
- 正文内不出现中英混排间距（空格一侧是汉字、另一侧不是）；引号只用中文弯引号 `“”`；不插场景分隔符。

### HTML 版章节标签

章节用 `<h2>` 承接，段落用 `<p>`：

```html
<h2>第一章 章名</h2>
<p>正文段落……</p>
```

- 首行写 `<!DOCTYPE html>`，`<head>` 内写 `<meta charset="utf-8">`。
- 需要统一样式时用 `<h2 class="chapter-title">`。

## 四、结构骨架

| 段 | 作用 | 篇幅占比 |
|---|---|---|
| 楔子 | 一个当下场景，定调或抛悬念 | 5% |
| 主体 N 章 | 起承转合，主角推进 | 85% |
| 尾声 | 收束主题，落定 | 10% |

- 章节数按「8000 字 ÷ 每章 1200–1500 字」估算，落在 6–8 章。

## 五、写作要点

开篇钩子、章末钩子、爽点节奏、反转埋线、断章位置、叙述与对话、意象与对照，见 `references/07-创作方法论.md`。

短篇专属：全篇至少 1 个 3 级（反转级）章末钩子。

## 六、人物画像

短篇同样写人物画像：主角 1–2 人、配角 3–5 人。字段模板见 `references/03-人物画像规范.md`。

## 七、作品档案字段

`01-作品档案.md` 写以下字段：

| 字段 | 取值 |
|---|---|
| 书名 | 作品名 |
| 体裁 | 短篇 |
| 主分类 / 子分类 | 见 `references/05-作品分类.md` |
| 频道 | 男频 / 女频 / 通用 |
| 平台归属 | 起点写分类（如 都市）；番茄写「目标读者 + 分类标签」（如 男频·都市）；晋江写频道（如 言情） |
| 目标平台 | 番茄 / 起点 / 七猫 / 晋江 / 知乎盐选 … |
| 一句话简介 | 30 字内，含主角 + 核心冲突 |
| 作品简介 | 100–300 字（平台上限 500），前 100 字必须勾人 |
| 主题句 | 全书要落的那一句话 |

简介写法：前 100 字给主角处境 + 核心冲突 + 悬念钩子，结局留白；标题与标签另行列出。
