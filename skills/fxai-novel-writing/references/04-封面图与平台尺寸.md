# 04 封面图与平台尺寸

## 一、封面目录结构

封面独立成目录 `<书名>/封面/`，**扁平存放**：

```
封面/
├── 封面提示词.md
├── 母版_<风格>.png         # 3:4 源图 1200×1600
└── 封面_<风格>_<平台>.jpg   # 各平台成品
```

- `<风格>` 取风格名（科幻 / 超现实 / 怀旧 / 写实 / 极简）。
- `<平台>` 取平台名（番茄 / 起点 / 七猫 / 微信读书 / 晋江）。
- 母版一律 PNG，平台成品一律 JPG。
- 测试期一次出齐各风格；定稿后按选定风格只保留一套 `封面_<风格>_<平台>.jpg`。

## 三、出图母版

- 主母版出 **3:4（1200×1600）**，供番茄 / 起点系 / 七猫等 600×800 平台。
- 需要 2:3 的平台（微信读书）与横版平台（知乎盐选）另出。
- 由母版下采样到目标平台尺寸，按平台比例裁切。

## 四、封面提示词

落 `<书名>/封面/封面提示词.md`，字段固定：

```markdown
# 封面提示词

- 目标平台：
- 尺寸 / 比例：
- 画面主体：
- 氛围 / 色调：
- 构图（留白区）：书名区位于上 1/3 或下 1/3
- 提示词（中文，直接喂生图）：
- 参考图 role：（woman / man / 空）
```

提示词写作要点：

- 竖版竖构图，主体居中或偏下，顶部或底部留出书名区。
- 色调贴合题材（现实题材 → 暖灰 / 胶片感；玄幻 → 高对比冷色）。
- 画面里有人时，写明【穿搭 / 服装】与【头型 / 发型】。

## 五、调用生图

封面文字**一律由生图模型渲染在画面里**，与画面同一光源、同一质感，不经字体后加。

开工前先读 `fxai-comfyui-image-gen/SKILL.md` 的「开工前置」与「长期约定」。

调用 `fxai-comfyui-image-gen/image_gen.py` 的 `generate_image(prompt, role=None, tag="")`：

- `role="woman"` / `"man"` 唤起自有形象 000 / 001；纯氛围封面用 `role=None`。
- 书名、笔名、标语一并写进提示词，交代字体风格、颜色、位置。
- 返回本地 PNG 路径。
- 出图后**逐字核对**书名与笔名；有错字改提示词重出。

## 六、出图后处理

- 按目标平台尺寸裁切 / 缩放走 `scripts/crop_cover.py <源图> <平台>`，输出平台尺寸 JPG。
- 封面成品一律 JPG；母版与其他图片转 JPG 走 `fxai-image-to-jpeg`（quality=95）。
- 各平台成品命名 `封面_<风格>_<平台>.jpg`，母版命名 `母版_<风格>.png`，与 `封面提示词.md` 同放 `封面/` 下。
