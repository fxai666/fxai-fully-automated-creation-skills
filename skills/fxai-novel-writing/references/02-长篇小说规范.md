# 02 长篇小说规范

## 一、产出与目录结构

```
<书名>/
├── 00-目录.md              # 章节列表（章号 + 章名 + 一句话看点）
├── 01-创作思路.md          # 主题 / 主线 / 冲突 / 节奏 / 伏笔 / 目标平台
├── 02-人物画像.md          # 人物设定（必产）
├── 03-章节梗概.md          # 逐章梗概（每章一段）
├── 正文/
│   ├── 第001章 章名.md
│   ├── 第002章 章名.md
│   └── ...
└── 封面/                    # 封面独立成目录，内部结构见 references/04-封面图与平台尺寸.md
```

## 二、先立档案，再写正文

顺序固定：`02-人物画像.md` → `01-创作思路.md` → `03-章节梗概.md` → `00-目录.md` → `正文/`。

档案三件（创作思路 / 章节梗概 / 目录）与人物画像齐备后，才动笔写正文。

## 三、01-创作思路.md 字段

| 字段 | 内容 |
|---|---|
| 主分类 / 子分类 | 见 `references/05-作品分类.md` |
| 频道 | 男频 / 女频 / 通用 |
| 平台归属 | 起点写分类；番茄写「目标读者 + 分类标签」；晋江写频道 |
| 一句话简介 | 30 字内，含主角 + 核心冲突 |
| 作品简介 | 100–300 字（平台上限 500），前 100 字必须勾人 |
| 主题句 | 全书要落的那一句话 |
| 主线 | 主角从起点到终点的转变 |
| 核心冲突 | 外部冲突 + 内心冲突各一 |
| 结构 | 卷 / 幕划分与节奏安排 |
| 伏笔表 | 埋点 → 回收章 |
| 目标平台 | 番茄 / 起点 / 七猫 … |

## 四、03-章节梗概.md 格式

每章一个块，字段固定：

```markdown
### 第001章 章名
- 场景：
- 人物：
- 事件：
- 转折：
- 收尾钩子：
```

## 五、00-目录.md 格式

```markdown
# 目录

| 章号 | 章名 | 看点 |
|---|---|---|
| 第001章 | 章名 | 一句话看点 |
```

## 六、分章正文

- 文件名：`第001章 章名.md`，章号补零到三位，便于排序。
- 单章汉字数 ≥ 2000。
- 章内首行标题 `第001章 章名`（**不带 `#` 等标记**），与文件名一致。
- 正文内不出现中英混排间距（空格一侧是汉字、另一侧不是）；引号只用中文弯引号 `“”`；不插场景分隔符。
- 章末钩子级、章内五拍、爽点节奏、反转埋线与断章位置见 `references/07-创作方法论.md`。

## 七、卷册（超长篇）

章节超过 100 章时，正文按卷建子目录：`正文/第一卷 卷名/第001章 章名.md`，目录与梗概按卷分段。
