# fxai-voiceover-script · 口播文案生成

出一份能直接念的口播稿：**一行一段，每段 = 语气标签 + 分隔句号 + 正文**。

```
用[语言][情感][情绪][语气](说|喊)<|endofprompt|>。<正文>
```

- `<|endofprompt|>` 左边是语气指令，右边是要念的正文。
- 🔴 **分隔句号 `。` 必带**（紧跟分隔符后）。**这个句号占一个字**。
- 🔴 标签以 `用` 开头；`You are a helpful assistant.` 由后端自动补。
- 🔴 **默认标签 = `用[语言]自然口语的语气说`**：各槽位直接连写、不加顿号，连成一句通顺的指令。
  语言默认普通话不写（只有方言才写）；不指定情感/情绪/语气时就用 `自然口语` 这一档，
  要情绪才显式给、顶掉默认值。

喂给合成：`python voice_gen.py --project <项目名> --script <项目名>/口播文案_标签.md`（逐段各用各的语气）。

## 口播链路四段（本技能管第 1 段）

| 段 | 做什么 | 归属 | 是否公共 |
|---|---|---|---|
| 1 写稿 | 内容生成范式：叙事、用词、选题 | **本技能**（03/04 两册） | 公共 |
| 2 文本转语音 | 配音、音色、语速 | `fxai-voiceover` | 公共 |
| 3 展示形态 | 二选一：人物出镜 / 幻灯片展示 | `fxai-digital-human-video` / `fxai-slide-video` | 各自私有 |
| 4 收口 | 音频对齐 + 烧字幕 | 由第 3 段那个技能执行 | 两种形态同样处理 |

> 展示形态只影响画面怎么来；写稿、配音、对齐烧字幕三步两边一致。

## 🚨 铁律（每次开工都守）

1. 🔴 **标签格式** `用[语言][情感][情绪][语气](说|喊)<|endofprompt|>。<正文>`，槽位连写不加顿号，
   默认档 `自然口语`。→ `01-贴标签规则.md`
2. 🔴 **单段正文 < 80 字**（含标点，只算正文；分隔句号占 1 字 → 正文最多 79 字）。
3. 🔴 **分隔句号 `。` 必带**：`<|endofprompt|>。` 后接正文。
4. 🔴 **带问题的稿子停在质检这一步**：质检不过自动修最多 3 轮，修好才写文件、才送合成。
   → `02-流程与参数.md`
5. 🔴 **写稿按 `03-叙事范式.md`**：开篇一律共同经历式叙事（述事 → 当时都这么干 → 翻转），
   每个观点凑齐「现象 + 代价 + 因果」。
   🔴 **开篇不套模板句式**：夜半熬夜式、反问逼问式、灾难夸张式一律不用（判据见 `03-叙事范式.md` 开篇三不）。
   🔴 **首段字数不限**——22 字上限只管发布标题，正文开篇讲完为止。
6. 🔴 **产品/品牌/能力介绍用「迭代历程式叙事」**（见 `03-叙事范式.md` 同名节）：
   不许写成"某天突然升级成某产品/镜像"的瞬间切换；必须按
   "早就想解决 → 不断打磨迭代 → 现在达到目标 → 减少用户门槛 → 还会继续升级"的自洽弧来写。
   镜像/产品只是当前载体，叙事落点是"我们一直在努力、现已做到、还会更好"。
   费用要写当前真实值且分笔写清（我们收的 vs 平台另收的）。
7. 🔴 **第一人称感受是过审硬指标**（平台会判「缺少第一人称感受」）：带第一人称的段 **≥ 半数**、
   **最长连续无第一人称 ≤3 段**，且感受词（我用下来 / 我们试了 / 我自己那回）与第一人称同段。
8. 🔴 **互动引导**（平台会判「缺少互动引导」）：全篇**真实问句 ≥2 段**（中后段一处 + 结尾一处）；
   结尾写「**真实问句 + 关注动作**」，关注动作取关注 / 收藏 / 点赞。→ `05-结尾与引导.md`
9. 🔴 **标签格式走引擎白名单**：只有 `cosyvoice` 用 `用…的语气说<|endofprompt|>。<正文>`；
   `qwen3tts` 输出纯正文（`--engine` 指定，缺省取全局 `tts.default_engine`）。
10. 🔴 **用词与选题按 `04-用词与选题.md`**：口播里的数字写中文读法（两点 / 四小时 / 百分之三十），
   选题锚定一个当下热门的技术词或工具名，首帧（或开场第一句）直接点名它。

## 直接开跑

```bash
# 默认：现成文案贴标签，原文一字不改
python script_gen.py --project <项目名> --text-file 文案.txt \
       --emotion 亲切 --mood 温暖 --tone 说

# 只要标签里带方言（平常语气，不额外加情感情绪）
python script_gen.py --project <项目名> --text-file 文案.txt --lang 四川话
```

完整参数与流程见 `references/02-流程与参数.md`。
