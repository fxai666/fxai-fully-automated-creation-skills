# 08 · 用词与选题（写 `segments.json` 前必读）

> **何时读**：动笔之前，与 `03-叙事范式.md` 一起读。数字人口播与幻灯片口播共用。
> 本册管两件事：**念出来的字怎么写**、**这条片子选什么题、封面亮什么**。

## 一、🔴 口播文案里的数字写中文读法

口播正文是要念出来的，**按"念出来的样子"写中文**（数字人口播同样遵循）。
幻灯片的配图 `fields` 是给人看的，照常写阿拉伯数字（`4 小时`、`20 分钟` 在屏幕上更醒目）。

| 想表达 | `text` 里这么写 |
|---|---|
| 2 点 | 两点 |
| 4 小时 | 四小时 |
| 20 分钟 | 二十分钟 |
| 30% | 百分之三十 |
| 3.0 | 三点零 |
| 2026 年 | 二零二六年 |
| 99 元 | 九十九元 |
| 6 万 | 六万 |
| 10 倍 | 十倍 |
| 1/3 | 三分之一 |

- 时刻读「两点」「两点半」；时段读「四个小时」；小数读「三点五」；比例读「百分之三十」「三成」。
- 百分比、金额、倍数展开写全：写「百分之三十」。
- 型号与版本号在 `text` 里写成中文读法或换说法：GPT-4 读「GPT四」、Qwen3 读「千问三」；
  读法拿不准就改成中文描述（「那个连节点的绘图工具」）。
- 合规预检扫 `text` 里的阿拉伯数字并告警；屏幕上的数字不查。

## 二、🔴 选题只挑行业里正在热的技术词与工具名

- 一条片子**锚定一个当下正在被搜、被讨论的热点技术词或工具名**：
  ComfyUI、Stable Diffusion、n8n、Dify、Cursor、MCP、智能体、工作流、LoRA……
  **优先挑当下卡住最多人的那个**。
- 选题判据：这个词放进标题，目标观众会不会立刻想点？会 → 留下；不会 → 换题。
- 泛话题一律换成带热点的具体题：
  「AI 提效」→「ComfyUI 工作流还得手工连？」；
  「自动化很重要」→「n8n 跑通一条，量产十条就崩」。
- 热点词在全篇反复出现（首帧、痛点、解法、结尾各带一次）。
- 术语第一次出现顺手翻译：节点图 = 连线管道；智能体 = 帮你做决定的大脑。

## 三、🔴 首帧一眼看懂：封面上直接点名热点词

- 首帧 = 封面（幻灯片第 1 段 `"anim": false`），**主标题含「热点词 + 具体动作」**，
  扫一眼就知道这条讲什么；数字人口播则由开场第一句点名热点词。
- 封面主标题写法：`我折腾了几年 ComfyUI 工作流，最近终于整个扔了`（前半「折腾几年」、后半「整个扔了」，反差即钩子）。
- 🔴 **封面文案必须吸睛，且做前后对比（反差）**：主标题用「旧做法受罪 / 耗时 ↔ 新做法轻松 / 已甩掉」的强反差抓眼球，
  让人一眼看到「我干了什么、现在怎样了」；抽象观点、纯情绪、行业黑话做主标题一律重写，观众看不懂就滑走。
- 🔴 **热点词必须做成最大视觉元素**：封面要把锚定的热点词（如 ComfyUI）做成整页最大的字，
  宁可缩小其它字也要让它一眼被看到——观众扫一眼就知道这条讲什么工具 / 工作流。
- 封面 `chapter` 胶囊只写内容属性（观点 / 问题 / 见解 / 痛点）；`tag` ≤4 个汉字。

## 四、🔴 开篇一律用共同经历式叙事（不提问）

钩子**只用叙事式**：一句话陈述一件"我前不久还在这么做"的具体事，
听众听着像在讲自己，共鸣比提问强。

**前三段固定节奏：**

| 段 | 作用 | 写法要求 |
|---|---|---|
| 1 场景陈述 | 把人拉进画面 | 接触时长 + 一直在跟什么打交道 + 热点词；字数不限，不出现问号 |
| 2 共同经历 | 让听众对号入座 | 一句"大家当时都这么做"，写常态化、不写抱怨 |
| 3 翻转 | 点出代价 / 已被替代 | 点明现在已有别的做法替掉它，代价落到时间或次数 |

- 三要素：**具体场景（带热点词）→ 一句"大家当时都这么做" → 翻转点出现在的做法已经替掉它**。
- 首段**不出现问号**（22 字上限只管发布标题，首段正文不限字数）。留人靠中文数字与具体画面。
- 🔴 **开篇禁用套路化**：夜半熬夜式 / 反问逼问式 / 灾难夸张式一律不用，
  从真实接触经历起手，时间只写真量级——规则见 `03-叙事范式.md` 开篇三不。
- 提问留给中后段的互动锚与结尾 CTA；开篇提问削弱共鸣，合规预检会告警。
- 相邻段首重复同一关键词仍属开篇三不（见 `03-叙事范式.md`）。

## 五、🔴 没人出镜，画面就是证据

数字人靠一张脸建立信任；幻灯片不出镜，**信任全由画面承担**。

- 画面按段分工：**痛点段放真实界面 / 报错 / 操作路径，解法段放成品与对比数据，家底段放清单与流程图**。
- 每张配图至少含一个**可核验的具体物**：文件名、报错码、按钮名、数字、时间。
- 抽象概念配示意图 + 一句人话标注（节点图 = 连线管道）。
- 空白装饰页、纯情绪大字页一律换成带具体物的画面页。

## 六、🔴 第一人称表述与互动问句的用词

平台审核会直接判「缺少第一人称感受 / 缺少互动引导」，用词照下面这张表选。

**第一人称表述（念出来要像"我自己用过"）：**

| 用在哪 | 用这些词 |
|---|---|
| 说做法 | `我用` / `我自己` / `我这边` / `我平时` |
| 给感受 | `我用下来` / `我试了` / `我自己那回` / `说实话我懵了` / `我踩过的坑` |
| 下结论 | `我比过` / `我量过` / `我自己试过三遍` |

### 🔴 讲自己的经历，一律用「我」，不用「我们」

这条是硬规则，不是风格偏好。**凡是讲我自己的经历——踩坑、操作、翻车、试错、
感受、结论——主语只能是「我」。「我们」一律改「我」。**

为什么：「我们」是集体口吻，念出来像公司通稿、像旁观者替别人转述，
第一人称的现场感当场就没了。数字人口播是一张脸在讲自己的事，
一开口"我们"，观众听到的是"一个机构在念稿"。

| ❌ 勿写 | ✅ 要写成 |
|---|---|
| `我们试了好多遍才明白，得先把人物视图固定下来` | `我试了好多遍才明白，得先把人物视图固定下来` |
| `我们自己跑过这条链路，最清楚一件事` | `我自己跑过这条链路，最清楚一件事` |
| `这些年我们一直在想办法，一遍遍试、一遍遍改` | `这些年我一直在想办法，一遍遍试、一遍遍改` |
| `我们数了两遍才敢信` | `我数了两遍才敢信` |
| `我们收的镜像费，平台另收算力费` | `我收的镜像费，平台另收算力费` |

**唯一保留「我们」的场合**（除此之外一律改「我」）：

- 指代**我和观众一起**：`咱们`（口语更近）或 `我们一起做`，且是**邀约/共做**语义，不是叙述自己的经历。
- **引用他人原话**、平台/官方口径的转述。

**自检**：稿子写完，把每一处「我们」圈出来问一句——这句讲的是我自己的事吗？
是 → 改「我」；不是（邀约共做 / 引述）→ 才留。**经历类段落里出现「我们」= 不合格，重写。**

- 🔴 痛点段别只写故障，要写**"我碰上这个故障时的反应"**。
- 🔴 第一人称落在动作或感受上；`我认为 / 我觉得` 这类空话不算。
- 🔴 一段里出现一次即可，堆多了像念稿。

**互动问句与结尾引导：** 🔴 规则与写法全在 **`05-结尾与引导.md`**（结尾写法 / 关注动作白名单 /
问句三种可答写法 / 数量与位置），本册不另抄。

- 🔴 结尾写「问号 + 关注动作」；引导取关注 / 收藏 / 点赞。
- 🔴 中后段再埋一处面向群体的开放提问（大家 / 各位 / 你们）。
