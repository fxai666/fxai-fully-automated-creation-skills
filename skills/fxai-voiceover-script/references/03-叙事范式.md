# 03 · 叙事范式（口播文案怎么写：数字人与幻灯片共用）

> **何时读**：动笔之前，与 `04-用词与选题.md` 一起读。
> 本册是**写稿公共层**，数字人口播与幻灯片口播共用：决定"一段话怎么写、全篇怎么排"。
> 硬指标（字数、亲历、互动）由各视频技能的预检脚本卡（幻灯片侧 `sv_compliance.py`）。

## 总原则：文案不限时长，厚度来自段数

> 🔴 **文案多长就多长，讲完为止**——任何"控制在 X 分钟""压到 X 段"的要求都与本节冲突，一律作废。
🔴 **不按时长砍内容。** 一段 = 一张图 = 一条音频，段数没有上限；
想讲透就多写几段，把细节写足。

- 一段写多长都行、拆多少段都行。
- "说细一点"靠**多拆段**实现，不是靠把长句塞进一段：
  把一件事拆成「场景 → 动作 → 后果 → 感受」几句话，连续播放就成了细述。
- 时长由内容自然决定；觉得"单薄"就补段，不靠压缩。

## 🔴 绝不杜撰：只写真实经历，不编造场景 / 数字 / 代价

> 全局硬要求：**口播文案必须真实，绝不杜撰。** 观众信的是「你真踩过这坑」，不是编出来的惨案。

- 🔴 **只写自己真实经历过的事**：痛点来自真实操作——繁琐、升级频繁、这错那错、要调、要查资料；
  不为了「有冲击力」去编造灾难题面（如「全崩」「白折腾几个钟头」「一晚上没了」「连一整天」这类夸张场景）。
- 🔴 **数字与代价落到真实可核**：时间 / 钱 / 次数只写自己真遇到的量级；拿不准就写定性描述
  （「反复打磨、查资料」），别拍脑袋给个具体数字充惨。
- 🔴 **对比可以强，但不得假**：前后对比（旧做法 ↔ 新做法）鼓励做，但两边都得是事实——
  旧路是我真走过的难，新路是我真用上的轻松，不夸大任一边。
- 真实感靠「记得有一次 / 我自己那回」式亲历 vignette 制造，不靠灾难修辞。

## 开篇三不（专治"开头重复、像机器念稿"）

1. 🔴 **相邻段首不重复同一关键词。** 首段用**场景/情绪**起手，规模数字放到第 2~3 段再给。
2. 🔴 **不用抽象结论开头。** 判断句一律改成画面句：写"谁在什么场景做了什么、结果怎样"，
   不写"XX 很难用"这类定性结论。
3. 🔴 **首段一句钩子，写共同经历式叙事（字数不限）。**
   陈述一件"我前不久还在这么做"的具体事（含热点词），第 2、3 段接"当时都这么干"再翻转
   ——写法见 `04-用词与选题.md`。
   🔴 **22 字上限只管发布标题，不卡首段正文**：首段该讲完就讲完，不为压字数砍信息。
   预检会查首段：出现问号告警，无数字告警（中文数字算数字），套路化开篇告警；字数不查。
   钩子负责"让人停下"，细节在后面第 2、3 段立刻展开。
4. 🔴 **禁用套路化开篇**（同一套句式反复出现在每条稿子上，观众一听就出戏；预检会拦）：
   - **不写夜半熬夜式**：不以深夜 / 凌晨的具体时刻配熬夜动作起手。
   - **不写反问逼问式**：不以反问句开场（"还在…吗""是不是又…"式逼问）。
   - **不写灾难夸张式**：不夸大损失（"全没了""白折腾""彻底崩"式定性）。
   - 开篇从**真实的接触经历**起手：什么时候开始用、一直在跟什么打交道、现在是什么状态。
   - 时间只写真实量级，不编造具体时刻与惨状。

## 推荐叙事弧（13 拍，可按题材裁剪）

| 拍 | 作用 | 写法要点 |
|---|---|---|
| 1 钩子 | 让人停下 | 一句话场景/提问，不堆关键词、不抛结论 |
| 2~5 痛点具象 | 把痛点讲成画面 | 每个痛点**一段一个画面**（装环境/找东西/调参/报错），用"记得有一次…"式 vignette |
| 6 共鸣放大 | 让听众对号入座 | "但凡 X 过的人都懂" + 自己那次的具体狼狈（带感受） |
| 7 数据佐证 | 立信 | 第三方数字/对比，强与难都摆出来 |
| 8~9 瓶颈 | 旧路走到头 | 指出"它天生干不了什么"，最好给一个具体代价场景 |
| 10 转折 | 抛新解法 | "2026 的解法是…"三层分工一句话讲清 |
| 11 原理一句话 | 让人信得过 | 用大白话说清为什么省/为什么稳 |
| 12~14 亲历 | 真人背书（带感受，至少一段在中后段） | 同一件事两种活法的对比 + "那 X 小时怎么没的"细节 + 技能包这边多轻松 |
| 15~16 家底/生产线 | 展示能力 | 数量清单 + "可拼装、可替换" |
| 17~18 全流程 | 降低门槛 | 一句话到成片 + 每一步谁在干（人只提需求） |
| 19~20 部署/成本 | 消除顾虑 | 一条命令/不操心 + 验收清单 |
| 21~22 资产化 | 升维价值 | 经验第一次能当资产送出去 + 共鸣 |
| 23 对号入座 | 分人群 | "这三类人现在就该换" |
| 24 互动 CTA | 收尾引导 | 面向群体的提问 + 关注动作，提问在前；**话术不写在本册**，唯一事实源 → `05-结尾与引导.md` |

> 不必死守 24 段；核心是**每一拍都能独立成一张有信息量的图**，且全程口语。

## 🔴 迭代历程式叙事（产品 / 品牌 / 能力介绍专用）

> 适用：介绍"我做了个什么东西/服务"时——不是讲一次性功能，而是讲"我怎么一步步走到今天"。
> 凡是带"这是我提供的 XX 能力/镜像/服务"性质的口播，一律走本范式，不得用"突然升级成某产品"的瞬间切换。

🔴 **核心铁律：不许写成「某天我把它升级成了某产品/镜像」的瞬间切换。**
要写成一条**自洽的历程弧**，逻辑落点是"我一直在努力、现在已经做到、还会更好"，不是"我搞出了个镜像"：

1. **起点**：我早就认到这个痛点/问题，一直在想办法解决（不是今天才想起来）。
2. **过程**：一遍遍试、一遍遍改、不断升级更新、摸索迭代；带真实翻车佐证"不是拍脑袋定的"。
3. **现在**：通过持续迭代，终于达到当前目标（如"全量自动化创作"）。
4. **价值**：这一路直接减少了普通用户 / 个人 / 团队的痛点与门槛（让创作门槛越来越低）。
5. **未来**：这还不是终点，我还会继续升级迭代，走向更高目标。

- 🔴 **产品/镜像只是"当前历程的载体"，不是叙事的终点或惊喜点。** 叙事落点是"历程"，不是"产品揭晓"。
- 与 13 拍弧兼容：把"转折/新解法"那一拍，从"抛出一个产品"改成"讲清我走到这一步的来路"——
  例如把"2026 的解法是把它做成镜像"改成"这些年我一直在想办法，一遍遍试、一遍遍攒，到今天终于整合成能直接上手的东西"。
- 🔴 **价格/费用要写当前真实值，且分笔写清**：我收的（镜像费）与平台另收的（GPU 算力费）分开陈述，不混为一笔、不隐瞒。

## 口语化细则

- 🔴 **大白话，像跟朋友讲自己踩的坑**，不写稿腔、不堆术语。
  术语第一次出现用"人话"翻译：节点图 = 连线管道；智能体 = 帮你做决定的大脑。
- **每句说一件事**，一个主语一条信息，别一句里塞三个结论。
- 用 **"你 / 咱们 / 大家"** 拉近距离；把"用户"改成"你"，把"该系统"改成"它"。
- **每个痛点给一个具体画面**，不写抽象结论：
  错 → "ComfyUI 很难用"；对 → "动一个节点，后面一串全崩，像推倒的多米诺骨牌"。
- 用 **"记得有一次 / 我自己那回"** 式亲历 vignette 制造真实感，比陈述句可信十倍。

## 厚度四件套（把文案写深，每个观点都凑齐）

> "单薄"的根因是只写了现象。**写完一段问自己：代价呢？为什么？听众怎么自测？**

| 件 | 作用 | 写法 |
|---|---|---|
| 现象 | 让人认出自己 | 一个具体画面：谁、在什么场景、做什么 |
| 代价 | 让它变疼 | 量化到"时间 / 钱 / 次数 / 比例"四选一，听众能换算成自己的成本 |
| 因果 | 让人服气 | 一句"因为…"，讲清为什么必然这样，而不是只感叹 |
| 判据 | 让人记住 | 一句"你现在就能试…"，给一个当场可验证的动作 |

- 🔴 每个核心观点至少凑齐 **现象 + 代价 + 因果**；全篇至少一处给 **判据**。
- 🔴 **判断句一律降级为画面句**：「ComfyUI 很难用」→「动一个节点，后面一串全崩，像推倒的多米诺」。
- 🔴 **数字落到四选一**：写「四个小时」「一晚上」「百分之三十的返工」「跑了八遍」，
  写「效率很低」这类不可换算的词等于没写。
- 🔴 **因果只挖一层**：讲清"它天生只能干什么 / 干不了什么"即可，往下追术语会失焦。
- 🔴 **结尾升维一层**：从工具升到能力、资产、时间——「省下的四个小时，才是你真正能攒下来的东西」。

## 🔴 第一人称在场：痛点段也必须带「我」

> 平台审核原话：**「缺少第一人称感受，可以多加些『我用下来』这类表述。」**
> 只写"ComfyUI 很难用"是旁观者口吻，痛点再真实也过不了。

- 🔴 **全篇带第一人称的段 ≥ 半数**，且**最长连续无第一人称的段数 ≤ 3**。
  痛点段一段不落"我"，审核直接判"没有真人感受"。
- 🔴 **第一人称落在动作或感受上**，不落在"我认为"这类空话上：
  | 弱（旁观） | 强（在场） |
  |---|---|
  | `装个依赖能卡在版本冲突上，一晚上就这么没了。` | `装个依赖卡在版本冲突上，我一晚上就这么没了。` |
  | `模型缺一个，整张图红一片。` | `模型缺一个，整张图红一片，我当时真看懵了。` |
- 🔴 **感受词必须跟第一人称同段出现**：`我用下来 / 我试了 / 我自己那回 / 说实话我懵了`。
  只写故障不写感受 = 没写第一人称感受。
- 🔴 **中后段必再落一次**亲历（别全堆在前半段）。
- 一段里第一人称出现一次就够，堆多了像念稿。
- 🔴 **讲自己的经历只用「我」，不用「我们」**：翻车、操作、返工、感受、结论，
  主语一律「我」。`我们` 是集体口吻，念出来像公司通稿、像旁观者转述，现场感当场没了。
  完整词表与自检见 `04-用词与选题.md` 第六节。**经历类段落里出现「我们」= 不合格，重写。**

## 🔴 互动引导：中段埋一个、结尾必须问

> 平台审核原话：**「结尾加个互动提问就更好啦。」**
> 🔴 **完整规则见 `05-结尾与引导.md`**：结尾写法、关注动作白名单、问句三种可答写法、数量与位置。
> 本册只留与叙事弧衔接的一句。

- 🔴 **结尾段 = 真实问句 + 关注动作**，问句在前、引导在后。
  话术**只认 `05-结尾与引导.md` 一处**，本册不复写——复写即分叉，改一处漏一处。
- 🔴 全篇真实问句 `≥2 段`：中后段一处面向群体的开放式提问 + 结尾一处。
- 🔴 提问只出现在中后段与结尾；开篇提问削弱共鸣（见 `04-用词与选题.md`）。

## 与合规规则的衔接（硬指标仍由 `sv_compliance.py` 卡）

- 亲历段 `≥2 段`，其中 `≥1 段带主观感受`（抓狂/解脱/白折腾…），且至少一段落在中后段。
- 带第一人称的段 `≥ 半数`，最长连续无第一人称 `≤3 段`。
- 互动锚 `≥2 处`，其中 `≥1 处面向群体`（大家/各位/你们）。
- **全篇真实问句（带问号）`≥2 段`**；结尾段「真实问句 + 关注动作」，缺问号即告警。
- 首段钩子（字数不限）含中文数字、不出现问号、不套模板句式（夜半熬夜 / 反问逼问 / 灾难夸张）。
- 以上写完 `segments.json` 由管线自动查；本册管的是"查之前怎么写才不单薄"。
