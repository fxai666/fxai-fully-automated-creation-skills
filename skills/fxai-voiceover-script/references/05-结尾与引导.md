# 05 · 结尾与引导（口播收尾怎么写）

> **何时读**：写结尾段、定互动引导时。
> 本册是**收尾公共层**：数字人口播与幻灯片口播共用，两个视频技能只留一行指针。

## 一、结尾段 = 真实问句 + 关注动作

- 🔴 结尾一段只放两样：**真实问句在前，关注动作在后**。
- 🔴 关注动作取**当页就能完成的三个**：关注 / 收藏 / 点赞。
- 🔴 关注话术取三要素：**关注 + 一起做 + 后续性**。标准写法：
  **`关注我，我会持续分享这类实操，跟着我一起做`**。
- 🔴 后续性只用「**持续分享 / 后面还会讲 / 一块儿做**」这类持续性动词表达，
  **不写「还在更 / 接着更」**——那是连载追更口吻，把受众降成看客，也把账号说成更新机器。

## 二、问句写法三选一

| 写法 | 判定 |
|---|---|
| 二选一 | 给两个互斥的现状，让听众挑一个 |
| 聊经历 | 邀请听众讲自己被卡最久的那次经历 |
| 对号入座 | 列出前文人群体，问「这几种里有你吗」 |

措辞取**能一句话接上话**的邀请：说经历 / 说是否需要 / 写心得 / 说身边有没有同样情况。

## 三、数量与位置

- 🔴 全篇真实问句 `≥2 段`：中后段一处面向群体的开放式提问（大家 / 各位 / 你们）+ 结尾一处。
- 🔴 互动锚 `≥2 处`，其中 `≥1 处` 面向群体。
- 🔴 提问落在中后段与结尾；开篇写共同经历式叙事（见 `04-用词与选题.md`）。

## 四、用词

| 取 | 替 | 判定 |
|---|---|---|
| 实操 / 踩坑 / 干货 | 学习视频 | 「学习」是收费课程预期 <!-- std:allow --> |
| 持续分享 / 后面还会讲 | 还在更 / 接着更 | 连载追更口吻，受众变看客 |
| 持续分享 | 分享 | 「分享」单用不交代后续，必须带「持续 / 后面」 |

## 五、预检对位

`sv_compliance.py` 查：结尾段含问号 + 含关注动作（关注 / 收藏 / 点赞）；全篇真实问句 `≥2 段`、互动锚 `≥2 处`。
