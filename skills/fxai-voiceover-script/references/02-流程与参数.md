# 02 · 流程与参数

> **何时读**：开工前、查 CLI 参数、看质检与产出时。

## 开工前：先读「口播」领域的经验库

写之前先读一遍 `{data_dir}/经验库_口播.md`（由 `fxai-content-review` 导出）；文件不存在说明还没复过盘，直接开工。

- 每条都带「第几次出现」和「下次该怎么改」，把「下次」带进本轮的断句与语气标签。
- 标「顽疾」「已确认」的优先遵守；标「待观察」的按判断取舍。
- 目录解析：环境变量 `FXAI_DATA_DIR` > `fxai_global.json.data_dir` > `工作目录/_fxai_data`。

## 两种模式

| 给了什么 | 做什么 |
|---|---|
| `--text-file <现成文案>` | **默认**：只贴标签，原文一字不改 |
| `--source-file <原文>` | 忠实原文抽要点成篇：开头 `为啥…？` → 中间核心句 → 结尾固定句 |

用户已经给好文案时一律走 `--text-file`；只有明确要求「按这个内容写一篇口播稿」才走 `--source-file`。

## 流程（顺序别换）

1. 分段 + 逐句打标签（贴标签模式或提炼模式）
2. **质检（硬门槛）**：每段必须带 `<|endofprompt|>`、情感标签和说话内容都非空、正文 <80 字
3. 不过就**自动修一轮再复检**（超长的再切、空段丢掉、缺标签补上），最多 3 轮；
   修不好才报错退出。**带问题的稿子一律停在质检这一步。**
4. 全过才写 `口播文案_标签.md` + `口播文案_标签_段落.json`（项目根目录）
5. 送合成：`python voice_gen.py --project <项目名> --script <项目名>/口播文案_标签.md`

自动修正打印的问题清单长这样，照着判断该怎么改：

```
[script] 质检发现问题，自动修一轮：
  第 1 段：正文 119 字 > 80（这一行内容特别长，这一行内容特别长，这一…）
  第 3 段：缺说话内容（用亲切的语气说…）
```

## 硬约束

- 🔴 **单段正文 < 80 字**（官方 `split_paragraph` 的 `token_max_n=80`，中文按字符数算）。
  分隔句号 `。` 占 1 个字，即**正文最多 79 字**；标签不计入。
- 🔴 **分隔句号 `。` 必带**：`<|endofprompt|>。` 后接正文。
- 结尾固定句（原文照抄，不改）：
  `对此您有什么看法请在评论区告诉我，关注我，后面我接着更，咱们下次见。`
- 阿拉伯数字转中文（`3 秒` → `三秒`），第二人称改敬称（`你` → `您`）。
- 空行是硬边界：一行 = 一段 = 一条音频；段内再按 79 字以内切。

## 参数

| 参数 | 作用 |
|---|---|
| `--text-file` / `--source-file` | 现成文案（只贴标签）/ 原文素材（提炼成篇） |
| `--tag-file` | 标签文件，一行一个标签，按句顺序套用；相邻同标签自动并块 |
| `--tag` | 整篇一个标签（确实通篇统一时才用；不给就按下面四个槽位拼，再没有取全局 `tts.default_instruct_text`） |
| `--lang` / `--emotion` / `--mood` / `--tone` | 语言（默认不写）/ 情感 / 情绪 / 语气动作 |
| `--end-emotion` / `--end-mood` / `--end-tone` / `--end-tag` | 结尾段单独指定，不给就沿用上面的 |
| `--lines` | 提炼模式的段数（默认 6） |
| `--max-chars` | 每段正文上限（默认 80） |
| `--out` | 不建项目目录时的输出路径 |
| `--project` | 落 `<项目根>/<项目名>/口播文案_标签.md` |

## 开跑

```bash
# 默认：现成文案贴标签，原文一字不改
python script_gen.py --project <项目名> --text-file 文案.txt \
       --emotion 亲切 --mood 温暖 --tone 说

# 逐句分情感语气：标签文件一行一个，按句顺序套用，相邻同标签自动并块
python script_gen.py --project <项目名> --text-file 文案.txt --tag-file 标签.txt

# 明确要求按内容写一篇：忠实原文提炼成篇
python script_gen.py --project <项目名> --source-file 原文.txt --lines 6

# 只要标签里带方言（平常语气，不额外加情感情绪）
python script_gen.py --project <项目名> --text-file 文案.txt --lang 四川话
```

## 产出

```
<项目名>/doc/
├─ 口播文案_标签.md    一行一段，标签 + 正文，空行分段
└─ 口播文案_段落.json  {index, instruct_text, text}，给下游按段取用
```
