# 01 · 贴标签规则

> **何时读**：给文案贴语气标签、写 `--tag-file`、判断每段用什么情绪时。

## 槽位

槽位顺序固定：`用[语言][情感][情绪][语气](说|喊)`，**槽位间不加顿号**，连成一句通顺的指令。

- 🔴 **默认一档 = `自然口语`**：不指定情感/情绪/语气就用它，照写不省。
- `[语言]` 默认普通话 → **不写**；只有方言才写。
- 要情绪才显式给，顶掉 `自然口语`；语气动作默认 `说`，要喊写 `喊`。
- 例：`用自然口语的语气说` / `用四川话自然口语的语气说` / `用四川话兴奋激昂的语气说`。

## 逐段怎么定

1. **先给整篇定基调**：这内容属于哪一类（教程 / 避坑 / 情感共鸣 / 观点 / 故事）→ 定一个主导情感。
2. **再逐段判断**：这段在说什么、想让听的人有什么反应 → 定这一段的情感+情绪+语气。
   **每段按内容各定各的**，情绪有转折就换标签。
3. **相同的归一块**：情绪连贯的相邻句子用同一个标签，工具会自动并成一条；
   情绪一转就换标签，一段只承载一种情绪。
4. **一段之内也能换**：一句话一个语气完全支持（`--tag-file` 按句顺序套用）。

## 标签文件（`--tag-file`）

一行一个标签，按句子顺序往下套，相邻同标签自动并成一块：

```
用亲切温暖的语气说          ← 打招呼
用兴奋激昂的语气说          ← 抛出看点
用四川话自然口语的语气说    ← 方言 + 默认档
```
