# 01 · 采集执行

> **何时读**：跑单条 / 批量采集、定素材落点、选参数、验收下载结果时。

## 输入形态

| 形态 | 入口处理 |
|------|----------|
| 完整页面链接 | 直接解析 |
| 短链 | 跟随重定向，以最终落地页为准 |
| 整段分享文案 | 取第一个 http(s) 串，去尾部标点；中文文案、话题标签、口令类尾串一并清洗 |
| 多个链接 | 位置参数并列 |
| 每行一条的 txt | `--file`，`#` 开头行跳过 |

## 命令与参数

统一入口 `python -B scripts/collect.py`，参数取下表。

| 参数 | 取值 | 默认 |
|------|------|------|
| `links` | 链接或分享文案 | 无 |
| `--file` | 链接清单路径 | 无 |
| `--out` | 素材落点 | 当前工作目录下 `素材采集/` |
| `--info` | 只解析地址，不下载 | 关 |
| `--engine` | `auto` / `parse` / `ytdlp` | `auto` |
| `--cookie` | cookie 头字符串 | 无 |
| `--cookies` | Netscape cookies.txt 路径 | 无 |
| `--browser` | `chrome` / `edge` / `firefox` | 无 |
| `--proxy` | 代理地址 | 无 |
| `--ascii-name` | 文件名收敛为 ASCII | 关 |
| `--list-profiles` | 列出已有站点分册与复用状态 | 关 |
| `--refresh` | 忽略旧经验重新分析，成功后覆盖分册 | 关 |
| `--no-profile` | 本次不读不写经验档 | 关 |
| `--list-sites` | 列出已注册解析器 | 关 |
| `--selftest` | 离线自检 | 关 |

- `--engine auto`：页面解析优先，取不到地址或地址全不可用时转外部下载器。
- `--engine parse`：只走页面解析，关闭外部兜底。
- `--engine ytdlp`：只走外部下载器。
- 解析器按 `PRIORITY` 升序匹配，数值大的通用解析器兜底；同一域名只预热一轮会话。
- 固定先查用户级站点分册；命中日志出现 `[经验] 命中`，按档内链路首轮直取，跑通日志出现 `[经验] 写入分册`。字段与流程见 02 册。
- 日志出现 `[完成]` 且退出码 0 才算跑通；分册只在下载成功（或图集至少一张）后回写。

## 素材落点

- 落点取当前工作目录，`--out` 给相对路径时按当前工作目录解析。
- 视频文件名 `<素材ID>_<标题前 40 字>.mp4`；`--ascii-name` 收敛为 `<素材ID>.mp4`。
- 图集文件名 `<素材ID>_<NN>.jpg`，`NN` 从 01 起。
- 素材 ID 取落地页路径中的长数字段；无数字段时取链接摘要前 12 位。
- 标题里的路径分隔符、控制字符、首位空格与点由 `core.safe_name` 收敛。
- 技能目录内禁写入素材、临时分片与字节码；下载分片写落点目录，成功后原子改名。

## 验收判据

| 项 | 判据 |
|----|------|
| 退出码 | 0，日志出现 `[完成]` 与完成计数 `N/M` |
| 文件格式 | 文件头含 `ftyp` |
| 媒体信息 | ffprobe 读出 `width` / `height` / `codec_name` / `duration` 并上屏 |
| 解析模式 | `--info` 输出候选地址列表 |
| 离线自检 | `python -B scripts/collect.py --selftest` 全绿 |
| 经验档 | 跑通后 `--list-profiles` 出现对应分册；再次运行日志出现 `[经验] 命中` |

- ffprobe 缺失时媒体信息行省略，其余判据照常生效。
- 单条失败不计入完成数，批量任务继续跑下一条。
- 下游走 ffmpeg 滤镜链路时加 `--ascii-name`，文件名不带中文与空格。
