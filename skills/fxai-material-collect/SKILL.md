# fxai-material-collect · 素材采集

按链接自动解析页面内嵌数据与媒体地址，把视频或图集取回本地。整段分享文案可直接喂入，尾部干扰串由入口清洗。通用解析覆盖任意链接，个别页面形态需要专门处理时追加解析器，入口不改。

## 本技能文件清单（先读这里，再决定读哪册）

| 文件 | 什么时候读 |
|------|-----------|
| `references/01-采集执行.md` | 跑单条 / 批量采集、定素材落点、选参数、验收下载结果时 |
| `references/02-扩展解析.md` | 理解通用解析路径、查/写使用层全局配置、追加专用解析器时 |
| `references/03-风控与故障.md` | 拿不到地址、需要登录态 cookie、换出口、外部下载器兜底时 |
| `scripts/collect.py` | 统一入口；改命令行行为才读 |
| `scripts/core.py` | 公共底座；改 HTTP / 下载 / 文件名规则才读 |
| `scripts/sources/*.py` | 页面解析器；改取数逻辑才读 |

**确定本次要做什么之后，只读对应的那一册，其余一律不读。**

## 直接开跑

```bash
python -B scripts/collect.py "<链接或整段分享文案>"
python -B scripts/collect.py --file links.txt --out ./素材
python -B scripts/collect.py "<链接>" --info
python -B scripts/collect.py --list-sites
python -B scripts/collect.py --list-profiles
python -B scripts/collect.py --selftest
```

默认素材落点 = 当前工作目录下的 `素材采集/`，由 `--out` 改。下载完成后自动探测时长 / 尺寸 / 编码并上屏。

## 铁律速查

1. 🔴 整段分享文案直接喂入，链接提取与尾部噪声清洗由入口完成。
2. 🔴 取数前按目标链接与落地页根各预热一次会话；部分页面缺会话凭据只返回校验壳页。
3. 🔴 候选地址由水印标记与清晰度参数派生，按可用性排序，无标记直连优先。
4. 🔴 解析器由 `sources/` 自动发现并按 `PRIORITY` 排序，通用解析兜底；追加解析器勿改 `collect.py`。
5. 🔴 素材落当前工作区；技能目录内禁写入素材、缓存或字节码。
6. 🔴 运行一律带 `-B`，脚本内设 `sys.dont_write_bytecode = True`。
7. 🔴 下游接 ffmpeg 链路时加 `--ascii-name`，文件名收敛为 ASCII。
8. 🔴 职责边界止于取回文件，后续加工交下游技能。
9. 🔴 技能包内禁写入具体平台名称、域名与专属接口路径；页面特征一律由调用时传入的链接提供。
10. 🔴 站点经验只由运行时写入技能包外的用户级配置 `~/.workbuddy/<技能名>/sites/`，命中即复用、跑通即回写；技能包与发布包内均零站点记录。`sites/`／域名式分册／`CONFIG.md` 由打包器默认排除，分册参数块命中即拒绝出包；格式与流程见 02 册。
11. 🔴 采集对象须自有或获授权，遵守目标站 robots 协议、用户协议与访问频次约定；不得绕过登录校验、验证码、身份认证、访问控制与频率限制，不得用代理池或换出口规避风控，不得去水印或绕开权利管理电子信息。边界全文见分享包包根《合规使用边界.md》。
