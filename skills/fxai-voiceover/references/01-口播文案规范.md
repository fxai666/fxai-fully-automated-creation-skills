# 01 · 口播文案规范

> **何时读**：写口播文案、贴语气标签、提交 `--script` 前自检时。

## 引擎白名单：标签格式只服务 CosyVoice

| 引擎 | 送进 `text` 的东西 |
|---|---|
| `cosyvoice` | 带语气标签：`用…的语气说<|endofprompt|>。<正文>` |
| `qwen3tts` | **正常写稿文案，纯正文**，不带标签、不带分隔符 |

- 🔴 千问 Qwen3-TTS **没有 instruct 入口**，给它套标签会把「用自然口语的语气说」也念出来，并造成吞字漏读。
- 🔴 引擎取 `tts.default_engine`（`voice_gen.py --engine` 可顶掉）；贴标签由 `fxai-voiceover-script` 按引擎判定。

## 格式（CosyVoice 专用，只此一种）

一行一段。**需要语气/方言时才加标签**：

```
用[语言][情感][情绪][语气](说|喊)<|endofprompt|>。<正文>
```

- `<|endofprompt|>` 是硬分隔符：左边是语气指令，右边是要念的正文。
- 🔴 **分隔句号 `。` 必带**（紧跟分隔符后、正文前），**占一个字**，算进长度预算。
- 🔴 标签以 `用` 开头；客户端只送纯文本。
- 🔴 **默认标签 = `用[语言]自然口语的语气说`**，槽位顺序：语言 → 情感 → 情绪 → 语气动作，
  **直接连写、不加顿号**。
  - 不指定情感/情绪/语气时就用这一档，`自然口语` 照写；要情绪才显式给，顶掉 `自然口语`。
  - `[语言]` 默认普通话，**不写**；只有方言才写。
  - 语气动作默认 `说`，要喊写 `喊`（`笑着说` 这类也认）。

## 例子（照抄这个尺度）

- 普通话 + 默认 → `用自然口语的语气说<|endofprompt|>。各位老铁，大家好。`
- 方言 + 默认 → `用四川话自然口语的语气说<|endofprompt|>。各位老铁`
- 方言 + 情绪 → `用四川话兴奋激昂的语气说<|endofprompt|>。…`
- 普通话 + 情绪 → `用无奈心疼的语气说<|endofprompt|>。…`

## 长度

🔴 **单段正文 < 80 字**（含标点，**只算正文**，标签不计入）。分隔句号占 1 字，即正文最多 79 字。

## 送参

🔴 **整段（标签 + 分隔符 + 句号 + 正文）一起送进 `text`**。语气只走 `text`。

## 配套文案生成器

文案由 `fxai-voiceover-script` 出，直接当多段脚本喂进来：

```bash
python voice_gen.py --project <项目名> --script <项目名>/口播文案_标签.md --name 口播
```

`--script` 提交前自动质检：标签+正文非空、正文 <80 字（`--max-chars` 为 0 时不查长度）；
整段没标签的按普通分镜放行。**质检不过直接拒绝，一条都不合成。**
