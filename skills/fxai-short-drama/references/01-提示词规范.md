# 镜头提示词规范（写 shots 提示词前必读）

## 数据规范

### lines_data 行结构（4 元素）
`[时长秒, 六段式提示词, 图片列表(逗号分隔相对服务端 fxai/image/ 的路径，如 shortdrama_xjz/000.png), 场景续接(bool)]`

- 第 4 项 = **本段要不要给下一段留接点**（True = 勾「场景续接」）。老数据只有 3 项 = 断开。
  - 用在**同场景的双人对峙 / 对话**：要保住上一镜末的人物位置、朝向、视线接点才勾；下一镜换场景就断开，不要勾。
- 🔴 **同场景跨分镜自动勾，换场景自动断**（2026-11-28 定）：`drama_pipeline.build_lines_data`
  用 `fxai-common/relay_plan.py` 判定——相邻两镜取同一张场景图（图片列表最后一张，人物在前场景在后）
  → 前一段自动 True；换场景自动 False；单图镜判不出场景不自动勾。
- 要强制某几镜：shot 里写 `relay: true/false`（语义同第 4 项 = 本镜续下一镜），
  或整条管线传 `relay_flags=[True/False/None, …]`（None = 按自动规则）。**最后一镜恒不续**。
- 续接一旦生效，下一镜的第 0 帧被上一镜末帧硬钉（K 帧）——写法见下节「续接镜提示词」。

### 镜头提示词（H3 六段式精简版，无 Audio 段）
主体定义 / 摘要 / 延续分析 / 详细描述(`<d>[Chinese]台词</d>`) / 整体音效 / 非叙事音乐

**排版硬要求（每镜都要守）**：
- **世界观念句单独一行打头**（`world_constraint` 由 `_fix` 注入并补换行结尾）。
- **每条 `<Subject N> 是 <Picture N> 中的…` 各起一行**，上一句句号后换行再写下一条。
- 时间轴里的台词句（`<Subject 1> (S1) …说：<d>…</d>`，`(S1)` = 说话人编号）紧跟动作写，不另起一行。
- **详细描述按段写，段内不折行**：一段 = 一个语义单元（风格开头 / 整镜句+细节 / 一档时间轴），从句首写到句末一整行，不在逗号、顿号、分号处断行。
- 🔴 **详细描述 = 两行**（2026-11-23 按官方规范校准）：**首行风格 / 影调句** + **次行 `[Shot 1]` 正文一整段**。
  `[Shot 1] ` 起头 → 建立场景 / 景别 + 机位 + 运镜 → 在场人物全点名 → 动作因果链 → 表情与视线落点
  → 台词（说话人 + 表演 + `：<d>[Chinese]…</d>`），一路写到段末，**正文段内部不折行**。
  旧「风格 / 整镜句 / 细节 / 时间轴各占一行」的四行写法已作废（正文再拆行会被当成多个独立小节）。
- 🔴 **影调句必须在详细描述首行，不放摘要**（官方 `examples/episode_template.py` 即「风格行 + `[Shot 1]` 段」）。
- **时间轴嵌在句中，不换行、不单独成行**：`[Shot 1]` 的**第一个事件不写时刻**，从第二个事件起才把
  `At MM:SS.mmm, ` 前置在该句句首；`At` 只给起点、**不写终点**（窗口由下一条 `At` 决定，末条到镜尾）；`MM:SS.mmm` 三位毫秒 + 英文 `At` + 半角逗号。

### 主体引用格式
- **引用一个主体，永远写 `<Subject N>` 全称**（`N` = 本镜主体定义里那条自己的序号）。
  **同一个标签在后续镜头、后续句子里继续沿用，官方明确要求反复写标签、不缩写**
  （`full-reference-en.txt` §5.3：“Continue using the same label in later shots without redefining what the label represents.”）。
- **`(Sx)` 是说话人编号，不是主体简写**（官方 §5.4：“`<Subject N>` identifies the referenced subject,
  while `(Sx)` identifies the actual speaker. When the subject speaks, write `<Subject N> (Sx)`.”）：
  - **只有会开口说话的主体才配号**：这一镜从头到尾不开口的人、场景、道具**一律不带** `(Sx)`；
  - **声明位置可以提前**（官方 §7 的做法就是提前声明）：`<Subject 3> (S1), the young woman … sits on the sofa…` 写在她出场句里，
    台词还在后面几句才出现；也可以等第一次开口时再写。**两种都合规，同一镜内同一主体始终用同一个号**；
    官方反例可对照 `<Subject 4>`：他在 Shot 1 出场时只写标签，到 Shot 2 开口才写 `<Subject 4> (S2)`；
  - **号由「谁会开口 + 开口先后」决定，与音频参考无关**：同例中 `<Subject 4> (S2)` 没有任何 `<Audio N>` 绑他，
    一样拿到 S2；`<Audio 1>` 那行的 `(S1)` 是**向说话人编号借号**，方向是「音频引用已有编号」，不是音频产生编号
    （官方 §2.4：“The ID comes from the target video's global speaker order and is not independently assigned or renumbered in the audio definition.”）；
  - 🔴 **号一旦定下就固定，整条目标视频内保持不变**：同一主体后续每次开口（含画外音，写 `off-screen` 但号不变）都写同一对
    `<Subject N> (Sx)`，**不换号、也不把这个号让给别的说话人**；音频定义行同样照抄这一对
    （官方 §5.4：“Assign `(Sx)` once according to the order of actual vocal events in the target video.
    Reuse the corresponding ID at every actual vocal event in `detailed_description`; an `<Audio N>` definition
    bound to a target speaker … also reuses the same `(Sx)` but never assigns a new one independently.”）；
  - 🔴 **有没有音频，都不影响发号**：音频绑定只是「借号」。第二个开口的人即使没有任何 `<Audio N>` 绑他，
    也照样按开口顺序拿 `(S2)`；反过来，一条音频也不会凭空给谁多一个号。
    号从 S1 起按开口先后**连续**排，中间不许空号（官方 §5.1：“Give vocal sources stable `(S1)`, `(S2)`, and subsequent IDs.”）；
  - 说话人**不对应任何已定义主体**（纯画外旁白、没有对应人物参考图）时，用一句稳定的音色描述 + `(Sx)`，
    不硬套 `<Subject N>`（官方 §5.4：“When the speaker does not correspond to a defined subject,
    use a stable voice description followed by `(Sx)`.”）；
  - 🔴 **画外声音分两类，自己的心声用「画外主体 + 独立参考图槽」（2026-11-26 定稿，首选）**：
    - **① 别人不在场景里说话**（画外的娘 / 捎信人 / 爹）：写
      `<Subject N> (Sx) 画外说：<d>[Chinese]…</d>。` ——这类说话人有参考图、只是人在画外，
      挂 `<Subject N>` 无妨（说话人不在画内、没有画内嘴可贴）。旧词「画外道」废弃。
    - **② 画面里的人自己的心声 / 内心独白**（如少年默念那句话、心里对爷爷说话）：
      **画外主体独立图槽**——第5集镜17 十五轮对照后的唯一有效写法：
      1. **参考图多传一份**：`images` 里把说话人那张图再放一次，成为新的 `<Picture M>`
         （例：`[016, 007, 013, 016]`，少年图占第 4 槽）；
      2. 主体定义：`<Subject N> 是 <Picture M> 中的男孩。`（N 顺排，M 是新增槽位）；
      3. 延续分析：`<Subject N> (appears in [Shot 1]): fully_preserved - …沿用 <Picture M>…`；
      4. 动作行照常写「嘴唇始终闭着、双唇抿成一条白线、下颌不动」；
      5. 说话行**独立一行**：`At MM:SS.mmm, <Subject N> (Sx) 画外说：<d>[Chinese]…</d>。`；
      6. 画面里不出现 `<Subject N>`——他只是声源。
      ```
      <Subject 4> 是 <Picture 4> 中的男孩。      ← 同一张图另占一槽
      [Shot 1] …画面内只有 <Subject 1> 和 <Subject 2> 两个人：…
      <Subject 1> 眼皮猛地掀开、…、嘴唇始终闭着、双唇抿成一条白线、下颌不动；<Subject 2> 低着头、一动不动。
      At 00:01.800, <Subject 4> (S1) 画外说：<d>[Chinese]爷，我回来了。我回来晚了。</d>。
      At 00:05.300, <Subject 1> 膝盖先砸在地上、…、嘴唇始终闭着；<Subject 2> 眼睛肿着、双唇紧闭不出声。
      ```
      🔴 **绝不能复用画内主体的图**：`<Subject 4> 是 <Picture 1> 中的男孩` 等于告诉 H3
      「说话的就是画内那个人」，口型照样被驱动（第八轮实测失败）。门禁硬拦「同一 `<Picture M>`
      被两个主体共用」。
      🔴 台词窗按 3.3 字/秒 + 0.3s 气口算，10 字至少 3.3s，否则提交会被时长校验拒绝。
      - **备选（仅当上面不成立、且脸不在画面焦点时）**：
        官方 voiceover `<Subject N> (Sx) says in an off-screen voiceover: <d>…</d> while his lips remain completely closed.`
        （`base-modes-en.txt` §4.4，闭唇句紧跟 `</d>`）；早点铺版
        `At MM:SS.mmm, 画外 <Subject N> (Sx) 的心声，他嘴唇始终不动：<d>…</d>`。
      - ❌ `<Subject 1> (S1) 紧闭着嘴默默的说：…`（只写这句不够，实测仍被 H3 贴回画内人物嘴上、念出来）
      - 🔴 **关键教训（十五轮实测）**：**纯文字闭唇描述压不住 H3 的口型驱动**——官方 voiceover、
        早点铺双锁、再加「从 X 到 Y 嘴唇始终闭着」的时间区间，三种都试过，脸正对镜头时嘴照样张。
        之前几次以为「锁住了」，其实是俯拍低头、嘴根本不在画面里造成的错觉。
        唯一可靠的是**让说话人成为画外主体 + 独立图槽**。
        `(Sx)` 所有写法都保留，保证声音仍会生成。
    - 关键：① 说话人必须在画外，② 画外主体单独占一个参考图槽，③ 两类都保留 `(Sx)`。
  - `(Sx)` 按目标视频里**实际开口的先后**编号（第一个开口的是 S1），**与主体编号无关**——`<Subject 3> (S1)` 完全合法；
  - 编号范围是**一个目标视频（一次生成）**：本项目按镜生成、每镜是一个独立片段，所以**每镜从 S1 起各自排**——
    镜 1 里先开口的那位写 `(S1)`，镜 2 换成另一位先说，那位也写 `(S1)`，不需要跨镜沿用同一套号；
  - **不开口的主体、场景、道具一律不带 `(Sx)`**；
  - **裸 `(Sx)`（前面没有 `<Subject N>`）没有官方依据，门禁直接拦**；
  - `(Sx)` 只出现在详细描述：摘要 / 延续分析 / 整体音效 / 非叙事音乐一律不写
    （官方 §5.4 明确 “Do not write `(Sx)` in `retention_analysis`”）。
  - 🔴 旧写法「首次写全称、同段第二次起只写 `(SN)`」**已作废**（2026-11-23 查证官方，属误读 `(Sx)` 为别名）。
- **场景也是主体**，同样写 `<Subject N>` 全称，但**不带 `(Sx)`**（场景不发声）。全片不出现 `<Environment>`、`<Picture N>` 当主语这类标签。
- 🔴 **有音频参考时，必须在主体定义里完成绑定**（官方 §2.4）：**整行只有一种标准写法**
  `<Audio N> 是 <Subject M> (Sx) 的参考音色。`
  （官方英文原句：`<Audio 1> is the voice-timbre reference for <Subject 1> (S1).`）。
  🔴 **不要写「是…的参考音色，作为…说话时的音色参考」这类同义重复句**——一句就够，门禁按整行白名单硬拦。
  绑定有三个硬要求：
  - 号必须**挂在主体上**写成 `<Subject M> (Sx)`，不能只写裸 `(Sx)`；
  - 这个 `Sx` 必须与该主体在**详细描述里的号完全一致**——音频只借号、不重新编号
    （官方 §2.4：“…is not independently assigned or renumbered in the audio definition”），门禁会查两边是否同号。
  - 音色绑定只在**主体定义写一次**；`延续分析` 里用 `<Audio N>: reference - …` 声明关系（不是再定义一次音色）。
  - 纯配乐 / 观众笑声这类**不挂具体说话人**的音频，**不写 `(Sx)`**，直接用 `<Audio N>` 当可听源（官方 §5.4）。
  - 本项目（系统生成音色）没有音频参考，这一段用不上；一旦换成引用音频，就得按上面写。
- 🔴 **延续分析的音频行**（`延续分析` 段）：音色参考写 `<Audio N>: reference - <Subject M> 的说话音色参照 <Audio N>，不复制原始信号。`
  （官方原句：`<Audio 2>: reference - the target speaker follows <Audio 2>'s voice timbre ... without copying the original signal.`）。
  **音频行不带 `(Sx)`**——`(Sx)` 只在主体定义绑定行和详细描述台词行出现，门禁硬拦延续分析音频行的 `(Sx)`。
  整条原音频复用作音轨才写 `fully_copy`。
- **一张图 = 一个主体**：本镜每张上传参考图对应一条 `<Subject N>` 定义，一条定义只引一张图；人物、场景都走这条。
- **中文角色名（凤希、清鸢、侯爷、老鸨、摄政王）、「她 / 他 / 这个人 / 那位姑娘」一律不准当主语。**
- 场景若在机位句里没被提到，详细描述开头补一句「建立 `<Subject N>` 作为场景」把场景建立出来（**不带 `(Sx)`**）。

### 六段白名单模板（2026-11-23 定稿：门禁逐段按此白名单校验，逐字照抄结构，只换内容）

```
主体定义
<Subject 1> 是 <Picture 1> 中的女子。
<Subject 2> 是 <Picture 2> 中的男子。
<Subject 3> 是 <Picture 3> 中的场景。

摘要
[reference generation] <Subject 1> 在画面正中偏左、离桌面一步之外，<Subject 2> 在画面右侧前景、与她相隔一步。目标视频是 <Subject 1> 开口问话、<Subject 2> 点头回应，收在两人一起转向 <Subject 3>。

延续分析
<Subject 1> (appears in [Shot 1]): fully_preserved - 人物身份、五官发型、以及参考图中的全部穿着与配件完全沿用 <Picture 1>；不新增、不替换图里没有的任何服饰细节。
<Subject 2> (appears in [Shot 1]): fully_preserved - 人物身份、五官发型、以及参考图中的全部穿着与配件完全沿用 <Picture 2>；不新增、不替换图里没有的任何服饰细节。
<Subject 3> (appears in [Shot 1]): fully_preserved - 场景环境、背景与画面中已有元素完全沿用 <Picture 3>；不新增参考图里没有的任何内容。

详细描述
写实办公室内景，冷白屏幕光作主光、暖黄台灯作辅光。
[Shot 1] 中景镜头建立 <Subject 3> 作为场景，<Subject 1> 与 <Subject 2> 在场景中相对而立，镜头缓慢小幅横移。<Subject 1> (S1) 眉眼带笑、手指轻轻点了点桌面，对着 <Subject 2> 说：<d>[Chinese]最近我用上了凤希AI自动化创作，你听过没有？</d>。 At 00:03.500, <Subject 2> (S2) 挑眉点头、上身微微前倾，对着 <Subject 1> 说：<d>[Chinese]用起来还真好，做短剧省了不少事。</d>。

整体音效
室内安静，只有衣料摩擦声与远处风声。

非叙事音乐
无
```

**白名单判据（门禁只认这套结构；不在白名单里的写法一律拦下）**

| 段 | 白名单结构（照抄，只换内容） | 拦下的情形 |
|---|---|---|
| 主体定义 | `<Subject N> 是 <Picture M> 中的<身份词>。`；身份词只取白名单：男子 / 女子 / 老人 / 小孩 / 男孩 / 女孩 / 男人 / 女人 / 人物 / 场景 / 道具 / 动物；编号从 1 连续。有音频参考时另允许一行 `<Audio N> … <Subject M> (Sx)`（须与详细描述同号） | 任何修饰（年轻 / 古装 / 黑发 / 戴眼镜）、外观、衣着；没句号；编号跳号或重复；音频行写成裸 `(Sx)` 或与详细描述不同号 |
| 摘要 | `[reference generation]` + 站位句（≥8 字）+ `目标视频是…，收在…`。**图与人的对应由主体定义 `<Subject N> 是 <Picture M> 中的…` 承担，摘要不重复挂 `<Picture N>`**（官方 §2.2 + §7 写法） | 缺任务类型前缀 / 缺站位句 / 缺目标视频句；带 `(Sx)` |
| 延续分析 | 整行照抄两类模板之一（人物句 / 场景句），见上方模板 | 改字增删、写面部衣着颜色、带 `(Sx)`、缺「不新增」 |
| 详细描述 | 恰好两行：风格句 + `[Shot 1]` 正文段；**主体每次引用都写 `<Subject N>` 全称**（不缩写），会开口的主体写成 `<Subject N> (Sx)`（可提前声明）；**`(Sx)` 按开口先后从 S1 连续发号，号一旦定下整条目标视频内固定**：同一主体每次开口同一号、一号只归一个主体、不跳号；音频绑定行照抄同一号，没绑音频的说话人照样顺排拿下一个号；台词 `<d>[Chinese]…</d>` 后紧跟句号；每镜至少一处情绪表情 + 一处肢体动作；正文不写拟声词 | 拆成三行以上；首行夹台词 / 时刻；**裸 `(Sx)`**（前面没有 `<Subject N>`）；同一主体换号 / 两个主体同号 / 跳号；音频行与正文不同号；正文引 `<Picture N>`；`</d>` 后无句号；缺表情 / 缺肢体；正文出现吱呀 / 磨牙 / 咯吱等拟声词 |
| 整体音效 | 非空、落到具体声音（声 / 响 / 鸣 / 嗡 / 滴答 / 摩擦…）；所有拟声 / 环境声只写这里 | 只写动作没声音；夹台词；带 `(Sx)`；拟声词写进正文 |
| 跨段（言语意图） | 摘要写「默念 / 开口 / 画外」等言语意图，详细描述必须有对应 `<d>` 台词，或明确标注「无声口型 / 不出声」 | 摘要有意图、正文既无台词也无无声标注（模型会自己编台词乱念） |
| 非叙事音乐 | `无` / `N/A`，或写出乐器 / 节奏 / 力度（旋律 / 电子 / 单音 / 铺底 / 鼓 / 渐弱…） | 空话（「一段很好听的音乐」）；夹台词；带 `(Sx)` |

## 六段式各段职责（每段只答一件事）
| 段 | 只回答这个问题 | 只写这些（白名单，没列的一律不写） |
| --- | --- | --- |
| `主体定义` | 这些东西**分别是什么**（谁 / 哪） | 身份句（年龄性别 / 场景名）+ 指向 `<Picture M>`。**到句号为止**：不写外观、不写保留类目清单（那是延续分析的活）。有音频参考时另加一行 `<Audio N> … <Subject M> (Sx)` 把音色绑定到说话人 |
| `摘要` | 这一整段里谁在哪、干什么、收在哪 | 任务类型前缀 `[reference generation]` + 本镜站位关系第一句 + **「目标视频是…，收在…」**。**不放影调 / 风格 / 布光 / 画质**（那些归详细描述首行），**不带 `(Sx)`**；图与人的绑定由主体定义承担，摘要**不重复挂 `<Picture N>`**（写「`<Picture N>` 作为…参考」属可选） |
| `延续分析` | 每个主体从参考图里保住了什么、出现在哪些镜头 | **整行照抄模板句**：`<Subject N> (appears in [Shot 1]): fully_preserved - 人物身份、五官发型、以及参考图中的全部穿着与配件完全沿用 <Picture N>；不新增、不替换图里没有的任何服饰细节。`（场景换成场景句）；**具体外观一个字不写**，不带 `(Sx)` |
| `详细描述` | 按播放顺序一帧一帧怎么动 | **首行风格/影调句 + 次行 `[Shot 1]` 正文一整段**：运镜 + 动作因果链 + 物理反馈 + 台词（主体一律写 `<Subject N>` 全称，开口处带 `(Sx)` 说话人编号）+ 时间轴嵌在句中 |
| `整体音效` | 全片铺底的环境氛围与实体声音 | 环境底噪 + 贯穿全片的实体声，一条概括 |
| `非叙事音乐` | 画外的配乐 | 风格、强度、走向，与场景音分开写 |

**规则**：每段只写这一列里的东西，表里没列的一律不写进该段。
- 跨段唯一性只有两条：站位/方位/距离/相对关系写在摘要首句且全提示词只出现一次；动态（动作、表情、视线落点、运镜、时间轴）按播放顺序写在详细描述。

## 逐段写作标准

六段顺序与字段名固定死，六段齐全且顺序一致：`主体定义` / `摘要` / `延续分析` / `详细描述` / `整体音效` / `非叙事音乐`。

**1. 主体定义 `主体定义`**
- **一张图 = 一个 `<Subject N>`，一条一行**，人物、场景都用这个标签。
- **按 `主体 1 / 主体 2 / 主体 3` 依次往下写**：第一条是 `<Subject 1>`、第二条 `<Subject 2>`；场景行排在这一段最后。
- 人物：`<Subject N> 是 <Picture M> 中的女子。`
- 🔴 **身份词不加修饰**（2026-11-14 用户定，2026-11-23 收紧为白名单）：身份词**只能取这 12 个之一**——
  `男子` / `女子` / `老人` / `小孩` / `男孩` / `女孩` / `男人` / `女人` / `人物` / `场景` / `道具` / `动物`，
  不加国籍（`中国年轻`）、年龄（`年轻` / `中年`）、民族、身材、相貌、衣着。`古装年轻女子` 这类写法一律不采用；
  白名单之外一个字都写不进去，修饰和外观从结构上就进不来。
- 🔴 **提示词里不写括号角色名**：`中的女子（清鸢）。` 这种写法**提交前必须剥掉括号**，最终提示词只留 `<Picture M> 中的女子。`。
  角色名是分镜档案里给人看的标注，写进提示词等于又给模型下一遍文字约束；本项目脚本直接输出身份词，不带括号名。
- 场景：`<Subject N> 是 <Picture M> 中的场景。`（同样只写「场景」这个身份词，不写场景名、不写「（办公室）」）
- 一条一行不折行；同一主体由多张图共同定义时来源合并写（`是 <Picture 1>、<Picture 2> 中的…`）。
- 🔴 **主体定义只写身份，到句号为止**（全局铁律 17，见 `fxai-h3-video-prompt/references/04` 展开）。
  「要保住哪几类东西」写进**延续分析**：人物 `fully_preserved - 保留人物身份、发型发色、服装样式与颜色、裤装、鞋履。`；
  场景 `fully_preserved - 保留场景的建筑、陈设与物品。`；道具 `fully_preserved - 保留道具的形制、材质与颜色。`
- **两段都禁写**：具体颜色（月白、鸦青、玄色、浅杏色）、款式细节（窄袖、束腰短甲、黑发高挽、半扎低丸子头）、
  材质工艺（棉质、烟罗纱、银线暗纹）、具名物件细节（断纹素银簪、扇骨九节第三节旧裂纹）、光调氛围（夜色偏冷）。
  也**不要**在主体定义里再写「全部来自 <Picture M>」「不另行描写」这类补充或元指令——只写身份词就够。
  写了就等于让 H3 按文字重建，参考图被文字覆盖 → 服装换色、款式改样、道具有无逐镜漂。
- **不照抄生图描述**：`project_def.characters[].prompt` 只用于生图，**不进提示词**。
  旧版「外貌句逐字照抄生图 prompt、且必须是其子序列」的写法**已作废**（2026-11-12），
  `_audit` 第 2 轮由校验子序列改为校验「主体定义只有身份词一句、延续分析有对应类目句、且两段都不含颜色款式词」。
- **主体定义只写身份词，到句号为止**：本镜的状态与环境（脸上有酒渍、身形被门光勾出一道边、雨气未干、只露侧后脑勺）不进主体定义，挪到 `[Shot 1]` 里去写。
- **详细描述里不复述外观**：只写 `<Subject N>` 标签（**开口说话时才写成 `<Subject N> (Sx)`**）+ 动作，不写「穿月白纱裙的她抬手」这类带颜色款式的复述——复述一次等于又下一遍文字指令。
- **痣 / 疤 / 朱砂这类位置特征不写进主体定义**：极简口径下这些只靠参考图，图上没有就不写；
  真要写（剧情关键）必须写死左右上下，并先确认四视图上真的画出来了。

**2. 摘要 `摘要`**：固定两句，顺序不能换
`[reference generation] <① 站位句。><② 目标视频是 <本镜唯一动作>，收在 <终点态>。>`

- 🔴 **② 必须有「目标视频是 / 展示」引导句**（2026-11-23 按官方标准校准）。官方两种写法都认：
  - `目标视频是 <本镜唯一动作，动词 + 物体 + 方向>，收在 <终点态>。`（`fxai-ad-video/templates/分镜表.md:26`）
  - `目标视频展示 <Subject 1> 在 <Subject 2> 中<动作>。`（`fxai-h3-video-prompt/references/02-Ref2VA多参考.md:32`、`fxai-audio-video/audio_video.py:423`）
  只写站位、不写「目标视频是…」= 摘要不成句，门禁直接拦。
- ⚪ **③ Picture 分工句（可选，非官方固定句式）**：`<Picture 1>、<Picture 2> 作为人物外观参考，<Picture 3> 作为场景背景参考。`
  **官方依据（2026-11-23 查证）**：`full-reference-en.txt` §2.2 写明「图片只用于定义人物 / 场景 / 服装 / 风格时，
  **不要单独建 picture 条目**，把图源引用写进对应的 `<Subject N>` 定义句」；§7 完整版的 `summary` 里**没有任何 Picture**。
  所以这句**不是必写项**：写了不拦（格式须为「`<Picture N>` 作为…参考」），**不写更贴官方**——图与人的绑定靠主体定义那一句就够了。
  若写：多个人物图可合并成一组，**不加「两个」这类量词**；场景统一写「**场景背景参考**」，不写「场景参考」。
- 🔴 **摘要不放影调 / 光线 / 风格**：影调句属详细描述段首（官方 `examples/episode_template.py` 就是「风格行 + [Shot 1] 段」两行）。
- 🔴 **摘要用 `<Subject N>` 全称，不带 `(Sx)`**（`(Sx)` 是说话人编号，只在详细描述里主体开口处写）。
- **第一句是本镜站位关系**，取本镜既定的站位句原句。
- **站位方位一律写死画面坐标**：每个在场 `<Subject N>` 都要带明确方位（在画面正中 / 在画面正中偏左 / 在画面右后方 / 在画面左下方 / 从画面右上方）；「两侧 / 左右两翼 / 身后 / 旁边 / 一前一后 / 更后面偏右 / 从右上方」这类不带「画面」或只给相对方向的说法要换成坐标写法——模型每镜独立理解，同一个「偏右」上一镜在左下一镜在右。
- **位置型特征（痣 / 疤 / 朱砂 / 伤口）必须写死左右、上下**：「右颊一道明显旧刀疤」「左手腕一道旧疤」「左眼下一点朱砂」；要写成「眼尾一颗泪痣」「脸颊一颗痣」这种相对位时，H3 每镜自己定左右，成片里痣会一会儿在左一会儿在右，改写成带左右上下的绝对位。这一条从生图提示词（project_def prompt）起就写死，分镜照抄即可。
- **距离必须写数量**：要对话的两个人写「相隔不到两步 / 一步之外 / 一臂之外 / 中间只隔一张矮几」这类可量距离；「隔着满堂」「隔着一段距离」「一高一低」「只差半张脸」「隔着老远」这类虚距离要换成可量值——写了虚距离，模型会把两人摆到画面对角（一个右上、一个左下），隔着一整个大堂就没法对视、也没法「对着对方说话」，成片里必然一个看别处。
- **每个在场 `<Subject N>` 的站位要带距离**：光有方位（「在右上方」）不说明两人多近，方位 + 距离量一起写（「在右上方三步外的楼梯口，俯着身子对着 <Subject 2> 说话」）。
- **提示词里的特征要与生图对齐**：极简口径下**默认一律不写**痣、疤、朱砂这类细节，全靠参考图；参考图里没有的，写进文字 H3 就会自补并漂。只有剧情必须（如「右颊一道旧刀疤」是关键线索）才写，且要先确认四视图上真的画出来了。

**3. 延续分析 `延续分析`**：逐条 `<Subject 1> (appears in [Shot 1]): fully_preserved - <要保住的特征>`。
- 分级只用官方 §4.1 的四个关系标记：`fully_preserved / partially_preserved / attribute_transfer / weak_reference`。系统生成音频模式下写 `fully_preserved`；有音频参考时换 `fully_copy / partially_copy / reference / weak_reference` 并补 `<Audio N>: reference - …`。

**4. 详细描述 `详细描述`**（逐镜按播放顺序写）：
- 骨架：`[Shot 1] <景别>镜头，<机位角度>，<运动方式>，<主体动作与初始静态状态>` → 动作链（准备 → 触发 → 加速 → 主体动作 → 接触/反应 → 收尾）→ 物理反馈（衣摆 / 发丝 / 酒珠 / 火光 / 尘土）→ 镜头运动绑定动作 → 时间轴 → 画面结尾收敛。
- **起点状态、表情变化、视线落点按播放顺序排在这里**。
- 一条动作写成连续因果链，展开成眉、眼、唇、下颌的动作过程。
- 镜头写死五要素：机位 / 景别 + 运动类型 + 方向 + 速度幅度 + 跟随对象；运动类型从 推近 / 拉远 / 横移 / 摇 / 环绕 / 跟拍 / 手持 / 固定机位 里选。
- 最后 1 秒收敛：幅度收小，或干净定格交给下一镜。
- 背景参与者各给一个不同的动作；配角只留后脑勺 / 侧脸 / 暗色剪影。

**打斗镜取词前置（含武术动作的镜头必做）**

本镜只要出现**武术动作 / 兵器交手 / 打斗**（对招、劈砍、格挡、闪避、腾挪、摔擒、终结一击…），

```bash
$PY "$S" moves --query "<本镜动作关键词 3-6 个，如 单手长剑 劈砍 格挡>"

$PY "$S" --terms guard_footwork --tier high    # 或按类别 / 档位取词
```

- 取到的术语写进动作描述里，**一段 2–4 个词**，当动词用、不加引号、不当标签堆砌
  （✅「弓步沉身、上架格挡举刀硬接」；❌「使用【上架格挡】招式」）。

**5. 整体音效 `整体音效`**：环境底噪 + 与画面同步的具体音效（布料、靴底、杯响、水声）。全片铺底的那一条概括写这里，跟某一镜对位的瞬时声音事件写在详细描述对应那一行。

**6. 非叙事音乐 `非叙事音乐`**：配乐风格 / 强度 / 走向，与场景音分开写，不混。无画外配乐时写 `N/A`，不编。

**7. 参考图编号**：`<Subject N>` 的 N = 该图在 `images` 数组里的下标，每镜独立从 1 起排（3 张图就用 `Subject 1/2/3`）；场景图同样占一个号。

**9. 格式标准（其余硬性格式）**：
- **正文用编号，不用人名也不用人称代词**：四段一律写 `<Subject 1>` / `<Subject 2>` 标签（**不写「凤希」「她」「他」「那位姑娘」**）；
  `(Sx)` 只是说话人编号、**只加在会开口说话的主体上**（`<Subject 1> (S1) …说：<d>…</d>`；也可在主体出场句里提前声明），
  主体定义 / 摘要 / 延续分析 / 整体音效 / 非叙事音乐**都不带 `(Sx)`**。`<d>` 对白原文保留自然中文。群演复数写名词短语（`一圈客人里头每一个都在动`、`一圈客人的影子在纱帐上一晃一晃`）。
- 视觉描述用直白句，连接关系写出来：禁箭头 `→ ↑ ↓`、禁 `+ /` 连接符（写 `特写镜头缓慢拉远为中景镜头`、`Logo 和 Slogan`）。
- 同一时间戳内同一主体的姿态 / 动作 / 视线合并成一句。
- 台词用「说」，且**说话人 + 对谁说 + 台词三件齐全**（`At 00:03.500, <Subject 1> (S1) 低头对着 <Subject 2> 尖着嗓子说：<d>[Chinese] 台词</d>。`），动作写在「说」前面，同一台词时间窗内写对应的身体动作。首个事件不写 `At`。
- 🔴 **说话引导词只有两种范式（2026-11-25 用户定，必须照抄其一，不得自造）**：所有发声说话处一律用「说」字，**绝不用「道」**（笑道 / 低声道 / 冷声道 / 说道 / 道 全部禁止）。
  - **范式 A · 直接说**（无表情 / 副动词修饰时）：
    `<Subject N> (Sx) [表演动作]说：<d>[Chinese]台词</d>。`
    - 例：`<Subject 1> (S2) 看着 <Subject 2>说：<d>[Chinese]爷，你吃。</d>。`
  - **范式 B · 表情 / 动词 + 说**（需要表情、语气、动作修饰时，修饰词贴在「说」前、仍以「说」字收尾）：
    `<Subject N> (Sx) [表演动作][表情/语气/副词]说：<d>[Chinese]台词</d>。`
    - 例：`<Subject 2> (S1) 看着 <Subject 1>笑着说：<d>[Chinese]想儿回来啦。</d>。`
    - 例：`<Subject 1> (S2) 看着 <Subject 2>低声说：<d>[Chinese]我要是再快一点。</d>。`
    - 例：`At 00:03.500, <Subject 1> (S1) 低头对着 <Subject 2> 尖着嗓子说：<d>[Chinese]台词</d>。`
  - 两种范式的共同硬约束：① 引导词以「说」字结尾、后紧跟冒号 + `<d>`；② 修饰词只在「说」之前（笑着说 / 低声说 / 尖着嗓子说），不在「说」之后；③ 「对谁说」在表演句里正向写死；④ `</d>` 后紧跟句号；⑤ 🔴 **`<Subject N>` 后标点白名单（2026-11-28 用户定）**：标签后只允许接 ` (Sx)` 说话人编号，或直接接正文（汉字 / 字母 / 数字），**逗号、顿号等任何标点都不许直接贴在标签后**——写 `看着 <Subject 2>说：`，不写 `看着 <Subject 2>，说：`。门禁 `_audit_detail` 按白名单硬查，不在白名单里即拦。
  - 🔴 **台词闭合边界：`<d>…</d>` 后必须紧跟句号 `</d>。`（2026-11-25 用户定，短剧 / 多参考 / MV 通用）**：`</d>` 后面直接接文字（空格、分号、`<Subject`、动作句）都没有台词结束信号，H3 会把后面的文字**继续当台词念出来**——第5集镜11「结结实实磕了三个头」、镜15「讲着讲着睡着了」、镜18「你站着」之后的动作都被配音，就是漏了句号。
    - 正确：`…说：<d>[Chinese]我给你磕头。</d>。 <Subject 1> 结结实实磕了三个头、把丹捧得死紧。`
    - 错误：`…说：<d>[Chinese]我给你磕头。</d> <Subject 1> 结结实实磕了三个头…`
    - 一句台词说完就 `</d>。`，句号之后才写动作 / 下一句；多句台词逐句各自闭合。门禁 `h3_format_gate._audit_detail` 硬查，缺句号即拦。
  - 🔴 **拟声词 / 环境声只写「整体音效」段，正文禁止（2026-11-25 用户定）**：吱呀、磨牙、咯吱、窸窣、噼啪、呜咽这些声音词写进详细描述正文，会被 H3 当成对白念出来（第5集镜2「床板吱呀一响」「有人磨牙」变成胡言乱语）。正文只写画面可见的动作，所有声音落到「整体音效」。门禁硬查。
  - 🔴 **摘要言语意图必须与台词落地一致（2026-11-25 用户定）**：摘要写了「默念那句话 / 开口说话 / 画外」等言语意图，详细描述就必须写出对应 `<d>` 台词，或明确标注「嘴唇无声开合、不出声」。只写意图不给文本，H3 会自己编出台词乱念（第5集镜7）。门禁 `_audit_cross_section` 跨段核对。
  - 「对谁说」必须正向写死：表演句里带「对着 / 看着 / 仰着脸对着」+ 对方的 `<Subject N>`。只写「两眼钉着 <Subject 2> 说」「张着嘴说」「冷声说」等于没写对谁，模型自由发挥成看别处。
  - **台词只能挂本镜在画（有参考图、场上）的角色**；只在暗处 / 后脑勺 / 画外的人开口，必须标「画外」。
  - **称谓必须指向本镜的对话对象**（王爷 / 侯爷 / 奴家这类词指的就是对面那个 `<Subject N>`）；称谓只给场上在画的人。
  - **视线只写落点**：正向落点句本身就排除了看镜头，写禁令反而把"镜头"这个概念喂给模型。
- 空形容词（cinematic / dynamic / 高清）换成可观测的具体信息。

## 无引用模式提示词规则
- `subject_definitions` 只写 `<Subject N> 是 <Picture N> 中的...(角色外观/场景)`，不写 `<Audio>`
- `retention_analysis` 只写 Subject 的 `fully_preserved`
- `overall_soundscape` 写环境音设计（系统生成），不写歌声/原音频
- `detailed_description` 里的 `<d>[Chinese]台词</d>` 必须保留（语音生成依据）

## 人物剧镜头六要素：站位 / 动作 / 视线 / 表情 / 运镜 / 背景

与「分镜技能」里的 `四之一、每镜必写的镜头设计六要素` 一一对应——**分镜脚本写什么，shots 提示词就翻成什么**：
| 要素 | 在 shots 里落在哪一段 |
|------|----------------------|
| 站位 | 摘要首句（谁在谁的环境里 / 谁前谁后 / 谁左谁右 / 隔多远） |
| 表演动作 | 详细描述 + 时间轴 |
| 视线 | 详细描述（只写落点） |
| 表情 | 详细描述（按播放顺序写变化过程） |
| 运镜 | 详细描述里单独一句「[Shot 1] 近景镜头，固定机位，缓推，……」 |
| 背景角色 | 详细描述开头（一句统一约束 + 逐类人群的具体动作） |

**0. 站位 + 距离**
- 双人同框错开成三分之四侧身或一前一后，**且必须写两人之间的实际距离**（一步 / 半步 / 一臂之外 / 中间只隔一张矮几）。
- 站位 + 距离写进摘要首句：`A 在画面右后方三分之四侧身朝左，B 在画面左前方一步外仰着脸，两人中间只隔一张矮几，正对着说话`。
- 遮挡关系要写：`A 是背对镜头的，只露一个侧后脑勺与肩线，B 从 A 的肩膀边上探出一条眼缝看过去`。
- 站位与 `images` 顺序、`[Shot 1]` 景别描述保持一致。

**1. 视线（只写落点）**
- ✅ 落点句：`两眼落在 <Subject 2> 的脸上，一瞬也不挪` / `视线钉在 <Subject 2> 的脸上，从头到尾不往旁处移一格` / `两眼往画面左上方、楼上的那扇窗看过去`
- 落点写成单一确定的目标：`两眼扫过满堂、最后落在 <Subject 2> 脸上`、`横扫过满堂`、`斜着扫出去`、`视线在两人之间来回收` 这类过程跨度会让模型先把眼甩开再拉回来、结果回不来，落点直接写终态。
- 要强调强度只用副词（死死 / 一瞬不挪 / 从头到尾不挪一格）；写成 `绝不看镜头`、`绝不看向观众`、`绝不低头看地面`、`谁都不看镜头`、`没有一个人的眼睛对着镜头` 属负向禁令，会把"镜头"这个概念喂给模型。 （# std:allow）
- 多人同框写清**一条视线链**（谁看谁）：
  `三个人一条视线：<Subject 1> 从背后锁住 <Subject 3> 的后心，<Subject 2> 从 <Subject 1> 腋下看出去，<Subject 3> 盯着 <Subject 1> 的后脑勺。`
- 视线落点要与「对谁说话」一致：说话的人落点是对手，听话的人落点是说话人。

**1.5 谁对谁说话（台词行三件齐全）**
`时间轴 + <Subject N> (Sx) + （表演句里带「对着/看着 <Subject M>」）+ <d>[Chinese]…</d>`
- 每句台词都要能答出「谁、对谁、说什么」，缺「对谁」就补。
- 台词挂在本镜在画的角色上；画外的人开口写「画外」。
- 称谓指向本镜对话对象；不留「他/她」、不留中文角色名（`镜头六段式提示词.md` 与 `完整分镜脚本.md` 给人读，shots 提示词里一律编号）。

**2. 表情 + 肢体语言（每镜必写，短剧 / 多参考 / MV 通用硬要求）**
- 🔴 **每镜至少一处情绪表情 + 一处肢体动作，缺一即为纸片人**（2026-11-25 用户定）：门禁 `h3_format_gate._audit_detail` 对短剧 / MV / 数字人三条线一律强制，缺表情或缺肢体都拦下。
- 表情拆到**眉/眼/睫毛/瞳孔/唇/下颌/脸色/喉结/牙关**逐件写，且写**变化过程**（这些都是门禁认可的表情词，写「牙关咬紧」「瞳孔骤缩」同样算数）：
  例：`两条柳叶眉先是拧在一起、然后一寸一寸松开，丹凤眼细长地裂开一条缝、眼皮往上推、睫毛颤了两下，唇先抿成一条细白线、再松开一点点，下颌轻轻往里收住，脸色白得没有血色`
- 同一个角色在同集里每镜表情改一点（同一个「抬眼」，镜 2 是冷、镜 9 是「认出来的瞳孔骤缩」）。
- 肢体语言写清身体在做什么：伸手 / 攥紧 / 跪下 / 转身 / 扶起 / 侧身 / 重心前倾 / 肩膀绷住等，和台词时间窗对位；只写「站在那里」不算肢体动作。
- 双人同框要有眼神 / 表情互动（对视、相视、她抬眼看他），别各看各的。

**2.5 运镜（写在「[Shot 1]」那句里，一句话带全）**
- 格式：`[Shot 1] <景别>镜头，<机位角度>，<运动方式>，<主体动作>。`，例：
  `近景镜头，固定机位，缓缓推近到下颌，<Subject 2> 扬碗泼酒`
  `中景镜头，机位略低，缓慢横移，<Subject 1> 抬手一压，满堂杯子与团扇一齐炸响`
  （这两句只是动作、不开口，所以**不带 `(Sx)`**；同一句里如果开口说话，才写成 `<Subject 1> (S1) …说：<d>…</d>`）
- **幅度贴合参考图构图**：只做**小幅缓推、缓拉、轻横移、极轻的手持晃动**。
- 同一集里景别与运动方式要有节奏（特写钩子 → 中景对话 → 全景群戏 → 缓推特写收）。
- 时间轴里的每一句都要跟运镜对得上：写了"缓缓推近"，动作就得是连续慢的，"猛地抬手"这类突变与缓推不匹配。

**3. 背景里的角色**
- 场景参考图里定了有几类人（客人/家丁/管家/楼上的脑袋），每一类给一个具体动作。
- 写法：先一句**统一约束**（每镜都带，口径一致），再**逐类给动作**。可做成常量在 `_fix()` 里统一替换：
  ```python
  CROWD = ("背景里所有配角一律只留后脑勺、侧脸轮廓与暗色剪影，不转到正面五官、不露出正脸；"
           "他们里头每一个都在动（缩杯子、耸肩、探头、挪凳子、把身子往暗处退），根本不是定格的木头人。")
  ```
- 逐类动作按人群给（非群演角色同理）：
  `左边一桌四个人同时把杯子往桌上一顿、有三个瑟缩着往后退、其中一个撞到椅子腿、另一个把手里的筷子撒了一地；`
  `楼梯口探出两个脑袋、一个往这边看、另一个缩了回去、只留后脑勺；`
  `身后两个家丁鞋底在地砖上蹭了半步、两只手往后收、其中一个手按在腰刀上又松开。`
- 背景两条一起写：配角只留后脑勺 / 侧脸 / 暗色剪影；每类人群各给一个动作。

**提交前自检**（对 `shots` 逐镜跑一遍）：
- 动作拍写「主体 + 动词 + 对象」：**修饰只许写方式 / 部位 / 方向，程度与情态不写**。判据是语法形态不是词表——① 形容词叠词作修饰（死死 / 轻轻 / 渐渐 / 结结实实 / 干干净净 / 空落落）② 「得」字补语接程度词（捧得死紧）③ 程度·情态副词直接修饰（很静 / 猛地 / 用力）。数量反复（一截一截、一颗一颗）和动词重叠（说说笑笑、讲着讲着）放行，那是看得见的反复。❌ `结结实实磕了三个头` → ✅ `俯下身、额头碰地、抬起来、再碰地`；❌ `把丹捧得死紧` → ✅ `把两只手合在一起、把丹捧在掌心`；❌ `眼神很远很静` → ✅ `眼眶红着、两眼看着糖纸不眨`；
- 大白话：镜头描述一律用日常口语把过程写明白，**尤其「谁把什么东西给了谁」必须落到 `<Subject N>` 身上**。❌ `少年给白眉老头磕头求得长生丹`（只有结果，模型不知道丹哪来的）→ ✅ `<Subject 2> 从袖子里摸出那颗丹、放进 <Subject 1> 手心`，收尾再写 `紧接着，<Subject 1> 对着 <Subject 2> 磕头`；
- 主体引用：详细描述里**每次指代人物都写 `<Subject N>` 全称，不许用「他 / 她」**——按 `。；` 换行切句，句内有他/她却没有任何 `<Subject N>` 就是漏写（台词 `<d>` 里的「他」不算；「其他/他人/他乡」豁免）。❌ `他跪下去、额头碰地磕了三个头` → ✅ `<Subject 1> 跪下去、<Subject 1> 额头碰地磕了三个头`；
- 站位：摘要首句钉了站位 + 距离量，双人镜错开（侧身或一前一后），两人不对视时确实在一臂/一步内；
- 视线：每镜每个出镜人物都只有落点句，落点单一确定（不带「扫过…最后落在…」的过程跨度）；
- 台词：每句台词「说话人 + 对着 <Subject M> + 台词」三件齐全，称谓指向本镜对话对象；他人在画外写 `<Subject N> (Sx) 画外说`；自己心声（脸在画面里）写「画外主体 + 独立参考图槽」——`images` 多传一份说话人的图成为 `<Picture M>`，`<Subject N> 是 <Picture M> 中的…`，说话行独立一行 `At MM:SS.mmm, <Subject N> (Sx) 画外说：<d>…</d>。`，**不得复用画内主体的图**；`</d>` 后紧跟句号；
- 台词后不许留裸动作行：台词行紧接着的下一行若以 `<Subject N>` 起头、又没有 `<d>`，H3 会把这条动作当台词念出来（第5集镜11「结结实实磕了三个头、把丹捧得死紧」被念成旁白，whisper 词级时间轴实证）。要么并进台词行的引导句，要么写成 `At MM:SS.mmm, 紧接着，<Subject N> ……`；
- 视线：落点是人物用「落在 / 钉在」，落点是物件 / 手心 / 灵台等非人物用「看着 / 盯着」，不用「落在」；
- 表情：详细描述里有 ≥3 个表情细部词（眉/眼皮/睫毛/唇/下颌/脸色/喉结/瞳孔），写的是变化过程；
- 运镜：每镜都有以 `[Shot 1]` 开头的景别+机位+运动句，运动幅度是小幅（缓推/缓拉/轻横移/极轻手持）；
- 背景：每镜都含群演约束句，且背景描述里有 ≥2 类人群的具体动作；
- 主体定义：每条 `<Subject N> 是 <Picture M> 中的…` 各起一行、按 1/2/3 顺序向下（见「排版硬要求」）。

## 续接镜提示词（同场景跨分镜 · 2026-11-28 定）

同一场景连着两三个分镜、下一镜人物必须留在原位时，工作流会自动勾「场景续接」（见开头「lines_data 行结构」）。
续接镜的提示词有 4 条硬规矩：

1. 🔴 **不写跨段延续词**：「仍是刚才那一带」「保持在原位置」「不要互换」「接上一镜」——
   各镜**独立生成**，模型看不到上一镜写了什么，这些话只会让它凭空编一个上一步。站位靠**写同一套构图描述**。
2. **构图措辞与上一镜对齐**：机位、景别、人物在画面里的相对位置，两镜写同一套
   （「中近景，人物站画面右侧三分之一，面向镜头」），不靠「还是老位置」表达。
3. 🔴 **首帧写「已经在位」，不写进场**：续接时第 0 帧已被上一镜末帧硬钉，
   再写「从画面左侧走进来」「推门而入」会和钉子打架、多演一遍进场。
   `[Shot 1]` 第一句直接写当前姿态：「`<Subject 1>` 已站在书桌右侧，右手扶着桌沿」。
4. **主体定义 / 延续分析照常写全套**，图片顺序不变（人物图在前、场景图在后），
   `<Subject>` 编号也不要因为「接着上一镜」而重排。

**该关的时候必须关**：换场景、换机位（正打↔反打）、景别跨档（中景→特写）。
K 帧钉的是整帧，换场景还开着续接，新场景图会输给续帧里的旧场景（11-27 实测：换新办公室仍出旧书房）。
换镜就写 `relay: false`，或让场景图不同（自动断开）。

## 镜头描述通用范式（v1 · 2026-11-26 定 · 所有镜头一律按此骨架填）

> 这不是某一集的写法，是**所有镜头**的写法。任何一镜的「详细描述」，都按下面这个骨架填：
> 5 个槽位、顺序固定、槽位之间不合并也不省略。填不进去，就说明这一镜还没想清楚。

```
<风格句：写实电影感的 X，光线>，<景别>，<机位>。
[Shot 1] <景别>镜头，<机位>，画面<取景范围：从哪带到哪 / 关键部位在不在框里>，建立 <Subject A> 作为场景：<Subject B> 在<位置>、<Subject C> 在<位置>，<首个动作：主体 + 动词 + 对象>。
At 00:0X.XXX, <Subject N> <动词 + 对象>，<动词 + 对象>。
At 00:0X.XXX, <Subject N> (Sx) <对着谁>，说：<d>[Chinese]<台词></d>。
At 00:0X.XXX, <场景副词：紧接着 / 这时 / 然后>，<Subject N> <动词链：动作一、动作二、动作三>。
```

**五个槽位**

| 槽 | 写什么 | 硬要求 | 门禁 |
|---|---|---|---|
| ① 取景 | 景别 + 机位 + **取景范围** | 动作落在手/膝/脚上，框就必须带到那个部位 | 景别框动作 |
| ② 建场 | `建立 <Subject A> 作为场景` + 每个主体的站位 | 站位写死、距离写死；主体各占一行定义 | 主体定义 / 摘要站位 |
| ③ 动作拍 | 主体 + 动词 + 对象，**一拍一行** | 修饰只许写方式/部位/方向；每拍带 `At` | 语法形态检查 / At 检查 / 裸代词 |
| ④ 台词拍 | 主体 `(Sx)` + 对着谁 + `说：<d>` | 独立成行、**一行只一句**、`At` 起头、`</d>。` | 台词行 At / 一行一句 / 台词闭合 |
| ⑤ 收尾拍 | 场景副词起头 + 动词链 | **不许**以 `<Subject N>` 裸起头（会被当台词念） | 台词后裸动作行 |

**范式三原则**

1. **一拍一行**：一个时间点只做一件事。两件事挤一行，H3 只会做其中一件。
2. **一拍一主体**：每拍开头写 `<Subject N>`，全篇不写「他 / 她」——模型不知道「他」是谁。
   - 🔴 **主体打头、修饰后置（2026-11-28 用户定，门禁硬查）**：句式是「主体 + 做什么 + 对谁」，表情 / 语气 / 姿态这些修饰语一律放在主体之后。✅ `<Subject 1> 手指点了点桌面，眉眼带笑的看着 <Subject 2>`；❌ `眉眼带笑的 <Subject 1> 看着 <Subject 2> 时手指点了点桌面`。修饰语贴到标签前面，门禁 `_audit_detail` 直接拦。
3. **能拍出来才算**：动词要具体（`放进` 不是 `给`）、部位要在框内（写手就先把手框进来）、过程要完整（谁→给谁→怎么给→结果）。

**自检一句话**：把这段描述当成拍摄指令交给摄影师，他能不能照着拍出来？拍不出来就是没写清。

> 写的时候照左边，交之前跑门禁照右边。**表里没有一条是建议，全部是硬拦。**

## 人物长相锁参考图

H3 对人物参考图的身份锁定弱，多张参考图同框时容易互相污染、长成网红脸。两板斧：
1. **`images` 顺序把该角色排第一**（排前面的参考图决定长相），群像镜头把女主排第一位。
2. **长相一个字都不写**，主体定义只到身份词，保留类目写进延续分析——极简口径下长相全靠参考图，
   文字写得越细越会被覆盖。多图同框已实测出现脸崩 / 网红脸时，才在人物行末加固定后缀：
   `保持参考图中的本人身份，不做美化、不换成网红脸。`（不改写、不加形容词）

**提交前自检**：每镜女主那条 `<Subject N> 是 <Picture M> 中的…` 存在、**止于身份词**、**不含类目清单与颜色款式词**，
延续分析有对应类目句，`images[0]` 是女主那张。
- 阿拉伯数字（5.09 / 1900 这类）H3 画得准，可以正常使用；汉字、字母的准确率低，信息靠台词与后期字幕承载。
