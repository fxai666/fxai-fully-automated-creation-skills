# 镜头提示词规范（写 shots 提示词前必读）

## 数据规范

### lines_data 行结构（3 元素）
`[时长秒, 六段式提示词, 图片列表(逗号分隔相对服务端 fxai/image/ 的路径，如 shortdrama_xjz/000.png)]`

### 镜头提示词（H3 六段式精简版，无 Audio 段）
主体定义 / 摘要 / 延续分析 / 详细描述(`<d>[Chinese]台词</d>`) / 整体音效 / 非叙事音乐

**排版硬要求（每镜都要守）**：
- **世界观念句单独一行打头**（`world_constraint` 由 `_fix` 注入并补换行结尾）。
- **每条 `<Subject N> 是 <Picture N> 中的…` 各起一行**，上一句句号后换行再写下一条。
- 时间轴里的 `<Subject 1> (S1)` 紧跟动作句写，不另起一行。
- **详细描述按段写，段内不折行**：一段 = 一个语义单元（风格开头 / 整镜句+细节 / 一档时间轴），从句首写到句末一整行，不在逗号、顿号、分号处断行。
- **详细描述的四行结构**（对标参考写法）：
  1. **风格开头**（`[Shot 1]` 之前）：一两句定调体裁、叙事方式、镜头语言；质感和色调由主体定义里的世界观念句承担，这里不重复。
  2. **整镜句**：`[Shot N] <景别>镜头，<机位角度>，<运动方式>，整镜在场的是谁、每个人整体什么状态`。**第一个句号之前要把在场的人物主体全部点名**，场景主体走参考图绑定、不点名。
  3. **细节展开**：接在整镜句同一行往后写——起点状态 → 动作因果链 → 表情变化 → 视线落点 → 背景各类人群 → 声音，一路写到句号。
  4. **时间轴**：切点制，每档一行 `At 00:03.500, …`（`MM:SS.mmm` + 英文 `At` + 逗号）。**`[Shot 1]` 的第一个事件不写时刻**，从第二个事件起才写；`At` 只给起点、**不写终点**，窗口由下一条 `At` 决定、末条到镜尾。

### 主体引用格式
- **引用一个主体的唯一写法：`<Subject N> (SN)`**（`N` = 本镜主体定义里那条自己的序号，`SN` = 本镜说话/延续编号，如 `<Subject 1> (S1)`）。N 与 SN 一一对应，同号同人。
- **场景也是主体**，同样用 `<Subject N> (SN)` 引用（如「`<Subject 1> (S1) 在 <Subject 2> (S2) 里」——`S1` = 场景、`S2` = 人物）。全片不出现 `<Environment>`、`<Picture N>` 当主语这类标签。
- **一张图 = 一个主体**：本镜每张上传参考图对应一条 `<Subject N>` 定义，一条定义只引一张图；人物、场景都走这条。
- **中文角色名（凤希、清鸢、侯爷、老鸨、摄政王）、「她 / 他 / 这个人 / 那位姑娘」一律不准当主语。**
- 延续分析行写 `<Subject N> (出现在 [Shot 1]、[Shot 2]): <标记> - …`，不带 `(SN)`；其余各段（摘要、详细描述、时间轴）一律带 `(SN)`。

## 六段式各段职责（每段只答一件事）
| 段 | 只回答这个问题 | 只写这些（白名单，没列的一律不写） |
| --- | --- | --- |
| `主体定义` | 这些东西**分别是什么**（谁 / 哪） | 身份句（年龄性别 / 场景名）+ 指向 `<Picture M>`。**到句号为止**：不写外观、不写保留类目清单（那是延续分析的活） |
| `摘要` | 这一整段里谁在哪、干什么、收在哪 | 任务类型前缀 + 本镜站位关系第一句 + 发生什么、怎么发展、收在什么状态 |
| `延续分析` | 每个主体从参考图里保住了什么、出现在哪些镜头 | `<Subject N> (出现在 [Shot 1]、[Shot 2]): <标记> - 要保住的特征` |
| `详细描述` | 按播放顺序一帧一帧怎么动 | 每镜骨架 `[Shot N]` + 动作因果链 + 物理反馈 + 运镜 + 时间轴 + 与镜头对位的对白和声音 |
| `整体音效` | 全片铺底的环境氛围与实体声音 | 环境底噪 + 贯穿全片的实体声，一条概括 |
| `非叙事音乐` | 画外的配乐 | 风格、强度、走向，与场景音分开写 |

**规则**：每段只写这一列里的东西，表里没列的一律不写进该段。
- 跨段唯一性只有两条：站位/方位/距离/相对关系写在摘要首句且全提示词只出现一次；动态（动作、表情、视线落点、运镜、时间轴）按播放顺序写在详细描述。

## 逐段写作标准

六段顺序与字段名固定死，六段齐全且顺序一致：`主体定义` / `摘要` / `延续分析` / `详细描述` / `整体音效` / `非叙事音乐`。

**1. 主体定义 `主体定义`**
- **一张图 = 一个 `<Subject N>`，一条一行**，人物、场景都用这个标签。
- **按 `主体 1 / 主体 2 / 主体 3` 依次往下写**：第一条是 `<Subject 1>`、第二条 `<Subject 2>`；场景行排在这一段最后。
- 人物：`<Subject N> 是 <Picture M> 中的古装年轻女子（清鸢）。`
- **人物行带括号角色名锚**，锚紧接年龄性别词（中间隔「，」匹配不上）；脚本按锚把本行 `<Picture N>` 重刷成 images 真实下标，并删掉括号名。
- 场景：`<Subject N> 是 <Picture M> 中的（场景名）。`
- 一条一行不折行；同一主体由多张图共同定义时来源合并写（`是 <Picture 1>、<Picture 2> 中的…`）。
- 🔴 **主体定义只写身份，到句号为止**（全局铁律 17，见 `fxai-h3-video-prompt/references/04` 展开）。
  「要保住哪几类东西」写进**延续分析**：人物 `fully_preserved - 保留人物身份、发型发色、服装样式与颜色、裤装、鞋履。`；
  场景 `fully_preserved - 保留场景的建筑、陈设与物品。`；道具 `fully_preserved - 保留道具的形制、材质与颜色。`
- **两段都禁写**：具体颜色（月白、鸦青、玄色、浅杏色）、款式细节（窄袖、束腰短甲、黑发高挽、半扎低丸子头）、
  材质工艺（棉质、烟罗纱、银线暗纹）、具名物件细节（断纹素银簪、扇骨九节第三节旧裂纹）、光调氛围（夜色偏冷）。
  也**不要**在主体定义里再写「全部来自 <Picture M>」「不另行描写」这类补充或元指令——只写身份词就够。
  写了就等于让 H3 按文字重建，参考图被文字覆盖 → 服装换色、款式改样、道具有无逐镜漂。
- **不照抄生图描述**：`project_def.characters[].prompt` 只用于生图，**不进提示词**。
  旧版「外貌句逐字照抄生图 prompt、且必须是其子序列」的写法**已作废**（2026-11-12），
  `_audit` 第 2 轮由校验子序列改为校验「主体定义只有身份词一句、延续分析有对应类目句、且两段都不含颜色款式词」。
- **主体定义只写身份词，到句号为止**：本镜的状态与环境（脸上有酒渍、身形被门光勾出一道边、雨气未干、只露侧后脑勺）不进主体定义，挪到 `[Shot 1]` 里去写。
- **详细描述里不复述外观**：只写 `<Subject N> (S1)` 编号 + 动作，不写「穿月白纱裙的她抬手」这类带颜色款式的复述——复述一次等于又下一遍文字指令。
- **痣 / 疤 / 朱砂这类位置特征不写进主体定义**：极简口径下这些只靠参考图，图上没有就不写；
  真要写（剧情关键）必须写死左右上下，并先确认四视图上真的画出来了。

**2. 摘要 `摘要`**：写法固定为
`[reference generation] <两人/几人的站位关系一句。><目标视频是…，主体简写引用，动作与视线落点。>`
- **第一句是本镜站位关系**，取本镜既定的站位句原句。
- **站位方位一律写死画面坐标**：每个在场 `<Subject N>` 都要带明确方位（在画面正中 / 在画面正中偏左 / 在画面右后方 / 在画面左下方 / 从画面右上方）；「两侧 / 左右两翼 / 身后 / 旁边 / 一前一后 / 更后面偏右 / 从右上方」这类不带「画面」或只给相对方向的说法要换成坐标写法——模型每镜独立理解，同一个「偏右」上一镜在左下一镜在右。
- **位置型特征（痣 / 疤 / 朱砂 / 伤口）必须写死左右、上下**：「右颊一道明显旧刀疤」「左手腕一道旧疤」「左眼下一点朱砂」；要写成「眼尾一颗泪痣」「脸颊一颗痣」这种相对位时，H3 每镜自己定左右，成片里痣会一会儿在左一会儿在右，改写成带左右上下的绝对位。这一条从生图提示词（project_def prompt）起就写死，分镜照抄即可。
- **距离必须写数量**：要对话的两个人写「相隔不到两步 / 一步之外 / 一臂之外 / 中间只隔一张矮几」这类可量距离；「隔着满堂」「隔着一段距离」「一高一低」「只差半张脸」「隔着老远」这类虚距离要换成可量值——写了虚距离，模型会把两人摆到画面对角（一个右上、一个左下），隔着一整个大堂就没法对视、也没法「对着对方说话」，成片里必然一个看别处。
- **每个在场 `<Subject N>` 的站位要带距离**：光有方位（「在右上方」）不说明两人多近，方位 + 距离量一起写（「在右上方三步外的楼梯口，俯着身子对着 <Subject 2> 说话」）。
- **提示词里的特征要与生图对齐**：极简口径下**默认一律不写**痣、疤、朱砂这类细节，全靠参考图；参考图里没有的，写进文字 H3 就会自补并漂。只有剧情必须（如「右颊一道旧刀疤」是关键线索）才写，且要先确认四视图上真的画出来了。

**3. 延续分析 `延续分析`**：逐条 `<Subject 1> (出现在 [Shot 1]): fully_preserved - <要保住的特征>`。
- 分级只用五个：`fully_preserved / partially_preserved / attribute_transfer / weak_reference / newly_generated`。系统生成音频模式下写 `fully_preserved`；有音频参考时换 `fully_copy / partially_copy / reference / weak_reference` 并补 `<Audio N>: reference - …`。

**4. 详细描述 `详细描述`**（逐镜按播放顺序写）：
- 骨架：`[Shot 1] <景别>镜头，<机位角度>，<运动方式>，<主体动作与初始静态状态>` → 动作链（准备 → 触发 → 加速 → 主体动作 → 接触/反应 → 收尾）→ 物理反馈（衣摆 / 发丝 / 酒珠 / 火光 / 尘土）→ 镜头运动绑定动作 → 时间轴 → 画面结尾收敛。
- **起点状态、表情变化、视线落点按播放顺序排在这里**。
- 一条动作写成连续因果链，展开成眉、眼、唇、下颌的动作过程。
- 镜头写死五要素：机位 / 景别 + 运动类型 + 方向 + 速度幅度 + 跟随对象；运动类型从 推近 / 拉远 / 横移 / 摇 / 环绕 / 跟拍 / 手持 / 固定机位 里选。
- 最后 1 秒收敛：幅度收小，或干净定格交给下一镜。
- 背景参与者各给一个不同的动作；配角只留后脑勺 / 侧脸 / 暗色剪影。

**打斗镜取词前置（含武术动作的镜头必做）**

本镜只要出现**武术动作 / 兵器交手 / 打斗**（对招、劈砍、格挡、闪避、腾挪、摔擒、终结一击…），
在写动作描述**之前必须先向 `fxai-combat-design` 取词**，取到再落笔：

```bash
PY="python -X utf8"
S="<技能目录>/fxai-combat-design/scripts/combat_route.py"
$PY "$S" moves --query "<本镜动作关键词 3-6 个，如 单手长剑 劈砍 格挡>"
$PY "$S" --read moves/<命中的 id>              # 自动带出该条推荐术语
$PY "$S" --terms guard_footwork --tier high    # 或按类别 / 档位取词
```

- 取到的术语写进动作描述里，**一段 2–4 个词**，当动词用、不加引号、不当标签堆砌
  （✅「弓步沉身、上架格挡举刀硬接」；❌「使用【上架格挡】招式」）。
- **命中后必须核对**：读命中条目的 `summary` 与 `avoid_when`——若本镜动作落在它的 `avoid_when` 里，
  说明**命中了但用不上**，按「无强命中」处理；只有命中词是**通用词**（格挡 / 压制 / 连击…）而条目本身对不上时，同理。
- **提词要用招式库的词形**：招式库按「兵器 + 特色机制」组织，`单手长剑` 能命中、`长剑` 不一定。
  先用 `--list moves` 看一遍全库条目名，再按本镜动作提词，比盲试快。
- **无强命中是正常结果**：改从 `--terms <类别>` 按类别取词（`guard_footwork` 格挡衔接 / `sword` 剑术 /
  `saber` 刀术 / `stance` 步法 / `power` 发力…），术语照用，招式名一律取命中 id 里的原词，条目与本镜动作对不上时就只取类别词。
- **物体反馈句**（火星 / 碎屑 / 泥浆 / 水花 / 尘土）按
  `fxai-h3-video-prompt/references/05-物理动作提示词示例.md` 的公式写：<!-- std:allow -->
  `[物体与数量] + [行为与因果] + [空间一致性短语（至少 2 条）]`。
- **运镜**只从 `fxai-h3-video-prompt/references/06-运镜LoRA与运镜写法.md` 的 9 类词表里挑**一条**，仍守「一镜一条」。
- **触发词必挂（代码层已自动挂，不用手抄）**：本镜的 `详细描述` **第一行**写触发词——打斗镜 `camera motion, prfight1`；本镜走完终结技再加 `prfin1`（慢镜终结加 `prslow1`）；只运镜不打斗写 `camera motion`；**纯文戏镜整行不写**。对照表见 `fxai-h3-video-prompt/references/07-触发词挂载规范.md`。
  **`build_workflow` / `build_lines_data`（`auto_triggers=True` 默认开）按镜型自动注入**，写 shots 时**不必手抄**；手写了也不冲突（就地合并去重）。要显式控制就在 shot 上加 `trigger_words`（`""` = 明确不挂）、`is_fight` / `finisher` / `slow`；关掉自动挂载传 `auto_triggers=False`。`export_shot_prompts.py` 导出的六段式 md 会按同一规则补出这一行。
- **零命中就写「无命中」**，按常规写法走；招式名一律取命中 id 里的原词。
- 纯文戏镜（本镜无交手）跳过本节。
- 详见 `fxai-combat-design/references/07-与短剧集成.md` 与 `09-被上层调用契约.md`。
- **重头打戏**（本场高潮、有绝招与终结技）另读 `fxai-combat-design/references/10-打斗节奏与大招谱系.md`——8 拍节奏、缺口机制、绝招谱系、状态锁定；一场打戏 = **1–4 个分镜**走一轮 8 拍，**单镜仍守 3–10 秒**（与本节时长规范一致）。

**5. 整体音效 `整体音效`**：环境底噪 + 与画面同步的具体音效（布料、靴底、杯响、水声）。全片铺底的那一条概括写这里，跟某一镜对位的瞬时声音事件写在详细描述对应那一行。

**6. 非叙事音乐 `非叙事音乐`**：配乐风格 / 强度 / 走向，与场景音分开写，不混。无画外配乐时写 `N/A`，不编。

**7. 参考图编号**：`<Subject N>` 的 N = 该图在 `images` 数组里的下标，每镜独立从 1 起排（3 张图就用 `Subject 1/2/3`）；场景图同样占一个号。

**9. 格式标准（其余硬性格式）**：
- **正文用编号，不用人名也不用人称代词**：`主体定义 / 摘要 / 延续分析 / 详细描述` 一律 `<Subject 1> (S1)` / `<Subject 2> (S2)`；`<d>` 对白原文保留自然中文。群演复数写名词短语（`一圈客人里头每一个都在动`、`一圈客人的影子在纱帐上一晃一晃`）。
- 视觉描述用直白句，连接关系写出来：禁箭头 `→ ↑ ↓`、禁 `+ /` 连接符（写 `特写镜头缓慢拉远为中景镜头`、`Logo 和 Slogan`）。
- 同一时间戳内同一主体的姿态 / 动作 / 视线合并成一句。
- 台词用「说」，且**说话人 + 对谁说 + 台词三件齐全**（`At 00:03.500, <Subject 1> (S1) 低头对着 <Subject 2> 尖着嗓子道：<d>[Chinese] 台词</d>。`），动作写在「说」前面，台词结束用分号接下一段；同一台词时间窗内写对应的身体动作。首个事件不写 `At`。
  - **「对谁说」必须正向写死**：表演句里带「对着 / 看着 / 仰着脸对着」+ 对方的 `<Subject N>`。只写「两眼钉着 <Subject 2> 道」「张着嘴道」「冷声道」等于没写对谁，模型自由发挥成看别处。
  - **台词只能挂本镜在画（有参考图、场上）的角色**；只在暗处 / 后脑勺 / 画外的人开口，必须标「画外」。
  - **称谓必须指向本镜的对话对象**（王爷 / 侯爷 / 奴家这类词指的就是对面那个 `<Subject N>`）；称谓只给场上在画的人。
  - **视线只写落点**：正向落点句本身就排除了看镜头，写禁令反而把"镜头"这个概念喂给模型。
- 空形容词（cinematic / dynamic / 高清）换成可观测的具体信息。

## 无引用模式提示词规则
- `subject_definitions` 只写 `<Subject N> 是 <Picture N> 中的...(角色外观/场景)`，不写 `<Audio>`
- `retention_analysis` 只写 Subject 的 `fully_preserved`
- `overall_soundscape` 写环境音设计（系统生成），不写歌声/原音频
- `detailed_description` 里的 `<d>[Chinese]台词</d>` 必须保留（语音生成依据）

## 人物剧镜头六要素：站位 / 动作 / 视线 / 表情 / 运镜 / 背景

与「分镜技能」里的 `四之一、每镜必写的镜头设计六要素` 一一对应——**分镜脚本写什么，shots 提示词就翻成什么**：
| 要素 | 在 shots 里落在哪一段 |
|------|----------------------|
| 站位 | 摘要首句（谁在谁的环境里 / 谁前谁后 / 谁左谁右 / 隔多远） |
| 表演动作 | 详细描述 + 时间轴 |
| 视线 | 详细描述（只写落点） |
| 表情 | 详细描述（按播放顺序写变化过程） |
| 运镜 | 详细描述里单独一句「[Shot 1] 近景镜头，固定机位，缓推，……」 |
| 背景角色 | 详细描述开头（一句统一约束 + 逐类人群的具体动作） |

**0. 站位 + 距离**
- 双人同框错开成三分之四侧身或一前一后，**且必须写两人之间的实际距离**（一步 / 半步 / 一臂之外 / 中间只隔一张矮几）。
- 站位 + 距离写进摘要首句：`A 在画面右后方三分之四侧身朝左，B 在画面左前方一步外仰着脸，两人中间只隔一张矮几，正对着说话`。
- 遮挡关系要写：`A 是背对镜头的，只露一个侧后脑勺与肩线，B 从 A 的肩膀边上探出一条眼缝看过去`。
- 站位与 `images` 顺序、`[Shot 1]` 景别描述保持一致。

**1. 视线（只写落点）**
- ✅ 落点句：`两眼落在 <Subject 2> 的脸上，一瞬也不挪` / `视线钉在 <Subject 2> 的脸上，从头到尾不往旁处移一格` / `两眼往画面左上方、楼上的那扇窗看过去`
- 落点写成单一确定的目标：`两眼扫过满堂、最后落在 <Subject 2> 脸上`、`横扫过满堂`、`斜着扫出去`、`视线在两人之间来回收` 这类过程跨度会让模型先把眼甩开再拉回来、结果回不来，落点直接写终态。
- 要强调强度只用副词（死死 / 一瞬不挪 / 从头到尾不挪一格）；写成 `绝不看镜头`、`绝不看向观众`、`绝不低头看地面`、`谁都不看镜头`、`没有一个人的眼睛对着镜头` 属负向禁令，会把"镜头"这个概念喂给模型。 （# std:allow）
- 多人同框写清**一条视线链**（谁看谁）：
  `三个人一条视线：<Subject 1> 背后锁住 <Subject 3>，<Subject 2> 从 <Subject 1> 腋下看出去，<Subject 3> 盯着 <Subject 1> 的后脑勺。`
- 视线落点要与「对谁说话」一致：说话的人落点是对手，听话的人落点是说话人。

**1.5 谁对谁说话（台词行三件齐全）**
`时间轴 + <Subject N> (Sx) + （表演句里带「对着/看着 <Subject M>」）+ <d>[Chinese]…</d>`
- 每句台词都要能答出「谁、对谁、说什么」，缺「对谁」就补。
- 台词挂在本镜在画的角色上；画外的人开口写「画外」。
- 称谓指向本镜对话对象；不留「他/她」、不留中文角色名（`镜头六段式提示词.md` 与 `完整分镜脚本.md` 给人读，shots 提示词里一律编号）。

**2. 表情**
- 拆到**眉/眼/睫毛/唇/下颌/脸色/喉部**逐件写，且写**变化过程**：
  例：`两条柳叶眉先是拧在一起、然后一寸一寸松开，丹凤眼细长地裂开一条缝、眼皮往上推、睫毛颤了两下，唇先抿成一条细白线、再松开一点点，下颌轻轻往里收住，脸色白得没有血色`
- 同一个角色在同集里每镜表情改一点（同一个「抬眼」，镜 2 是冷、镜 9 是「认出来的瞳孔骤缩」）。

**2.5 运镜（写在「[Shot 1]」那句里，一句话带全）**
- 格式：`[Shot 1] <景别>镜头，<机位角度>，<运动方式>，<主体动作>。`，例：
  `近景镜头，固定机位，缓缓推近到下颌，<Subject 2> (S2) 扬碗泼酒`
  `中景镜头，机位略低，缓慢横移，<Subject 1> (S1) 抬手一压，满堂杯子与团扇一齐炸响`
- **幅度贴合参考图构图**：只做**小幅缓推、缓拉、轻横移、极轻的手持晃动**。
- 同一集里景别与运动方式要有节奏（特写钩子 → 中景对话 → 全景群戏 → 缓推特写收）。
- 时间轴里的每一句都要跟运镜对得上：写了"缓缓推近"，动作就得是连续慢的，"猛地抬手"这类突变与缓推不匹配。

**3. 背景里的角色**
- 场景参考图里定了有几类人（客人/家丁/管家/楼上的脑袋），每一类给一个具体动作。
- 写法：先一句**统一约束**（每镜都带，口径一致），再**逐类给动作**。可做成常量在 `_fix()` 里统一替换：
  ```python
  CROWD = ("背景里所有配角一律只留后脑勺、侧脸轮廓与暗色剪影，不转到正面五官、不露出正脸；"
           "他们里头每一个都在动（缩杯子、耸肩、探头、挪凳子、把身子往暗处退），根本不是定格的木头人。")
  ```
- 逐类动作按人群给（非群演角色同理）：
  `左边一桌四个人同时把杯子往桌上一顿、有三个瑟缩着往后退、其中一个撞到椅子腿、另一个把手里的筷子撒了一地；`
  `楼梯口探出两个脑袋、一个往这边看、另一个缩了回去、只留后脑勺；`
  `身后两个家丁鞋底在地砖上蹭了半步、两只手往后收、其中一个手按在腰刀上又松开。`
- 背景两条一起写：配角只留后脑勺 / 侧脸 / 暗色剪影；每类人群各给一个动作。

**提交前自检**（对 `shots` 逐镜跑一遍）：
- 站位：摘要首句钉了站位 + 距离量，双人镜错开（侧身或一前一后），两人不对视时确实在一臂/一步内；
- 视线：每镜每个出镜人物都只有落点句，落点单一确定（不带「扫过…最后落在…」的过程跨度）；
- 台词：每句台词「说话人 + 对着 <Subject M> + 台词」三件齐全，称谓指向本镜对话对象，画外的人标了「画外」；
- 表情：详细描述里有 ≥3 个表情细部词（眉/眼皮/睫毛/唇/下颌/脸色/喉结/瞳孔），写的是变化过程；
- 运镜：每镜都有以 `[Shot 1]` 开头的景别+机位+运动句，运动幅度是小幅（缓推/缓拉/轻横移/极轻手持）；
- 背景：每镜都含群演约束句，且背景描述里有 ≥2 类人群的具体动作；
- 主体定义：每条 `<Subject N> 是 <Picture M> 中的…` 各起一行、按 1/2/3 顺序向下（见「排版硬要求」）。

## 人物长相锁参考图

H3 对人物参考图的身份锁定弱，多张参考图同框时容易互相污染、长成网红脸。两板斧：
1. **`images` 顺序把该角色排第一**（排前面的参考图决定长相），群像镜头把女主排第一位。
2. **长相一个字都不写**，主体定义只到身份词，保留类目写进延续分析——极简口径下长相全靠参考图，
   文字写得越细越会被覆盖。多图同框已实测出现脸崩 / 网红脸时，才在人物行末加固定后缀：
   `保持参考图中的本人身份，不做美化、不换成网红脸。`（不改写、不加形容词）

**提交前自检**：每镜女主那条 `<Subject N> 是 <Picture M> 中的…` 存在、**止于身份词**、**不含类目清单与颜色款式词**，
延续分析有对应类目句，`images[0]` 是女主那张。
- 阿拉伯数字（5.09 / 1900 这类）H3 画得准，可以正常使用；汉字、字母的准确率低，信息靠台词与后期字幕承载。
