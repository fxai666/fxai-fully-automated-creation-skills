# 镜头提示词自查三遍（提交前硬门禁）

**写完所有镜头提示词，必须跑 `python _audit.py` 过三轮自查；三轮全绿才提交。**
- 自检器放在每集目录下（`_audit.py`），从 run 模块读真实 `shots`，不读 md、不读手抄稿；`镜头六段式提示词.md` 只给人读，验收一律看自检器。
- 三轮各管**一个方面**，同一个问题只在这一轮出现一次（新增一条检查前先问它属于哪一轮，别两边都挂——重复挂载会让某一轮的红灯失去意义）：

  1. **结构可解析**（这句写得成不成立，机器读不读得动）：六段齐全且顺序固定、无空段、`<Subject N>` 从 1 连续并按序向下、`<Picture N>` 与本镜 `images` 对应且人物性别对得上、场景也用 `<Subject N>` 定义（标签统一走 `<Subject N>`）、延续分析关系标记合法、摘要有 `[reference generation]` 前缀、`[Shot N]` 从 1 连续、时间轴骨架（从 0.00 起 / 首尾相接 / 无反区间 / 止值不超本镜）、说话行格式完整（冒号 + `<d>[Chinese]` 非空 + 说话人 `<Subject N> (Sx)` + 写明对谁说）、正文用编号与人称代词清零、无残留锁脸句。
  2. **内容要素齐全**（缺了哪一项，H3 就按自己的理解补，位置和细节逐镜漂）：主体定义有身份句**且带可辨识特征**、外貌句是 `project_def` 生图 prompt 的子序列、位置特征（痣/疤/朱砂/伤口）带左/右/上/下、站位写死「画面×」方位、距离写数量而非虚距离、主体定义与站位视线各归其段、详细描述四件套（风格开头 / 整镜句点名全员 / 段内不折行 / 有运镜）、有视线落点句、有表情描写、有背景层且背景各人有各自动作、空形容词与箭头 `/` 清零、视线只写落点、落点不带过程跨度。
  3. **整集可提交**（活交不交得出去）：整集 ≥60s、单镜 3–10s（10s 是 H3 上限）、每镜用到的参考图都能在 `assets_map.json` 里查到（服务端素材不齐全会整集白跑）、最后一帧时间戳不超本镜时长、全片视线都有确定落点。
- 三轮全过才打印「自查三遍全绿：结构可解析 ✓ ／ 内容要素齐全 ✓ ／ 整集可提交 ✓（N 镜 / M 秒）」，任一不过 exit 1，走不到提交。
- **改完自检器必须做负向验证**：故意把某一项的写法改坏（如删掉整句外貌特征只留身份句），确认它只在应属的那一轮报、**且只报一项**报不出＝判据被架空，等于没有门禁。
- **接成硬门禁**：run 脚本提交前调 `audit_gate()`，`import _audit` 放在 `__main__` 里 lazy 引（`_audit` 反过来要 import run 模块，模块级互相 import 会绕成死结）；自检器自身报错也算没过。

## 提交前时长校验（写在 run 脚本里）

用户硬约束：**单集 ≥60 秒、单镜 3–10 秒**。两道都在提交前，不在成片后。

```python
from drama_pipeline import check_episode_duration, episode_seconds
print(episode_seconds(shots))     # 只算总时长
check_episode_duration(shots)     # 不达标直接 ValueError（附还差几秒/至少加几镜）
def check_shot_durations(shots, max_seconds=10):
    bad = [(i+1, int(s["duration"])) for i, s in enumerate(shots)
           if not 3 <= int(s["duration"]) <= max_seconds]
    if bad:
        raise ValueError("镜头时长越界（3~%ds）：%s" % (max_seconds, bad))
```
- **镜数不预设**：先把全部台词排完、按 `speech_seconds()` 逐句算出需用秒数，镜数是排完之后的结果（常见 10–14 镜）。不得先定「N 镜 × M 秒」的包数再回头压台词。
- `build_workflow` 是通用入口，默认不做时长校验；短剧入口 `render_episode` 才卡（内部默认 `min_episode_seconds=60`）。`min_episode_seconds=0`/`None` 可关。
- 成片验收用 ffprobe 核对时长（成片比请求略长，是刻意的向上取整）。

## 每镜时长怎么定

**镜头时长 = 该镜头提示词「详细描述」里的时间轴总长度**，且 3–10 秒。时间轴按切点制写：第一个事件不写时刻（= 0 起点），之后每档 `At 00:03.500, …`，末条到镜尾。例：`At 00:03.000` 起两句、末句顶到 6 秒 → 镜长 6 秒。

- 🔴 **10 秒是上限，不是目标**。镜长由这一镜的台词需用秒数决定，不按固定档位凑。
- 🔴 **台词一字不删**：一句装不下就**拆成独立一镜**（或顺延到下一镜开头），不缩写、不删语气词、不改短句、不并句。镜数是结果不是预算，一集从 10 镜扩到 14 镜属于正常。
- **每句台词需用 = 字数 ÷ 3.3 字每秒 + 0.3 秒气口**（`drama_pipeline.speech_seconds()`）。
- **镜长 = 该镜全部台词需用秒数之和 + 余量（≥0.35 秒）**，向上取整到 0.5 秒，封顶 10 秒。合计超 10 秒 → 把其中一句拆到独立一镜，不压台词。
- **句窗口按各句需用秒数累加分配**：第一句从 0 起，每个 `At` = 之前各句需用累计 + 余量平摊；末句顶到镜尾。两句同镜时长短句按需用比例分，不对半分（对半分会让长句被拦、短句留空）。
- `audit_shot_speech(shots)` 对「台词装不进窗口」硬拦，同时卡「切点必须递增」「切点不得超出镜时长」。窗口由相邻 `At` 之差推出（首句 = 0 到第一个 `At`，末句到镜尾），不需要写终点。
- 无台词的动作镜 / 空镜：按动作走完所需时间给 3–10 秒。
- **先算完全部台词的秒数再写提示词**，不写完 10 镜再回头改。
- **说话行之后紧跟的静场段必须显式写成「静场，」行**（补「只有……的一声，一句台词也不出／任何一个人都不出声」）。只写动作描述（「抬了抬下颚，退到门口…」）不行：H3 会顺着上一句台词把这段当还在说话，自己编一句人声念出来（ep2 集尾 4 秒胡言「老奸们你向溜达秀」就是这么来的，成片里是**真有人声**，不是 whisper 误识别）。隔了几段才到的收尾静场风险低，不强制。第 4 轮 `audit_shot_speech` 对这条硬拦：说话行之后紧跟的静场段不含「静场」二字 = 报错。
- **判定成片里有没有 H3 自吐人声**：走 **40ms 窗 RMS 包络**判（人声 = 多组独立音节峰，起落间歇；乐器 = 单调衰减 / 连续拨弦）。whisper 出怪词分不出人声与误识别（它俩都认不出），别据此下结论。确证后改该段为显式静场 + `single_shot=<镜号>` 只重渲染该镜，其余镜命中缓存，再重跑 `acceptance_burn`。
