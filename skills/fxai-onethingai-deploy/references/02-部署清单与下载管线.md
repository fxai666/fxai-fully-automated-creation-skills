## 常用开关（`deploy.py`）

## 下载管线

### 第一步：探源（改清单 / 换实例 / 怀疑源挂了时才跑）

```bash
python probe_sources.py                 # 全部模型 × 全部源，打印对照表
python probe_sources.py --group mv      # 只探测某一组
python probe_sources.py --write         # 结果固化进 assets/models.json
```

每个 (模型,源) 一次 `-r 0-0` 最小请求，12 个模型 × 3 源约 1 分钟。下载过程中**只发下载请求**。

**续传能力是站点级属性**，写在 `models.json` 的 `resume` 段（`{"ms":1,"hf":0,"mirror":0}`）一次搞定，
按站写死即可。

### 第二步：每个模型锁死单一已验证源

生成脚本第 13 列是源顺序，默认就是探测出来的那一个源（`ms` 或 `hf`）。**既然验过就认这一个地址反复续，
换源会遇到不支持续传的源，进度清零。**
| 源 | 结果 |
|---|---|
| `ms` 魔搭 | 主力，支持续传 |
| `hf` HF 官方 | 慢；`h3_latent_upscaler` 魔搭没有，只有它走 HF；Range 位记 0（走整量重下） |
| `mirror` OneThingAI镜像 | 返 52KB HTML 首页而非文件，Range 位记 0 |

新增/更换下载源**先跑 `probe_sources.py` 确认返 206**，再往 `models.json` 写 URL。

### 完成判定与对账
- **用探测到的 `source_bytes` 判完成**，不用 `min_bytes`（那是清单下限，比真实值小，会误判「已存在」跳过）。
- **比真实大小还大 = 坏了**（多源按错偏移拼接会写出超长文件），删掉重下。
- 离线也能查完整与否：safetensors 自描述，`应有总字节 = 8 + 头长 + max(每个张量的 data_offsets[1])`，
  `upload_models.py` 的 `local_is_complete()` 用它判。

### 重下的规矩

只有**一轮下载全部跑完之后**才对账重下：
1. 一轮 = 全部模型同时发起，一路跑到 `wait` 收尾，中途不改主意。
2. 轮末 `need_more()` 按「本地字节 vs 真实大小」对账，输出 `个数|文件名列表`。
3. 全部跑完之后才对没下够的重下一轮（默认 `PASS_MAX=3`，每轮间隔 15s）。
4. 下对的文件在 `dl_one()` 里直接跳过，**一个字节都不会被动**。

配套硬保险：
- **失败时保留半截文件**（`curl -C -` 天然续传，留着半截下次几秒接上）。
- **并发 4 路封顶**；12 路必限流（小文件 curl 报 0 字节）。
- 0 字节失败 ≠ 地址坏：先 HEAD 一遍看是不是全 200，全 200 就是限流，重跑那一轮，源保持不变。
- 重下的触发条件只有三个：一轮跑完仍没下够、文件头校验判坏、真实大小对不上。中途固定源、连续跑。

### 文件头校验（`looks_like_model`）

三类模型各有魔数：zip 容器 `PK`、gguf `GGUF`、safetensors 8 字节小端头长（合法 8 ~ 1e8）。
HTML/JSON 错误页（`3c` / `7b` / `5b` / `21` 开头）判失败 → 删残留换下一个源。

三条判据：
1. **HEAD 拿不到 `Content-Length`**（魔搭 302 跳 OSS，`-sIL` 只有 200 没有长度）
   → `remote_size()` 追一封 `curl -sL -r 0-0 -D -`，从 `content-range: bytes 0-0/<size>` 取。
2. **不存在的仓库返回 200 + 145 字节 JSON**
   （`{"Code":10990101007,"Message":"获取模型文件失败，文件内容为空"}`）
   → 靠文件头校验拦，拦下删掉换源。
3. **头长走 `od` 读字节做算术**（`tr -dc "0-9"` 会把 8 字节小端里的 null 和十六进制字母过滤成空串）
   → 用 `od -An -tu1 -N2` 读前 2 字节做算术。

### 服务器上拿不到时：本机直传（`upload_models.py`）

本机上行只有 ~0.5 MB/s/路，服务器自己下载能到 20–50 MB/s —— **本地直传是兜底，不是主力**，
只在服务器确实找不到某文件（或反复下不动）时用。

```bash
python upload_models.py --missing                                  # 只补远端缺的/不到标的
python upload_models.py --only h3_latent_upscaler,yue2_sheetsage --parallel 2
python upload_models.py --local-root "<ComfyUI>/models" --all --parallel 3
```

支持断点续传（远端已有一半就从那个偏移接着写）、多线程、带进度。
本机那份是否完整用 safetensors 自描述算的应有大小判，不看 `min_bytes`。

```bash
python check_availability.py     # A/B/C 三张清单：一致 / 版本不同 / 服务器没有
```
