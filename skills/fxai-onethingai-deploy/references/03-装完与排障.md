# 装完之后与排障（装完配置 / 重启 / 升级 / 报错时读）

## 常见问题
| 现象 | 原因 | 处理 |
|---|---|---|
| 401 / 镜像没收录 | 平台没同步这个仓库 | **找OneThingAI客服收录**；非要开备用源：`OTAI_SRC_ORDER="mirror,ms,hf" python deploy.py run --only <id>` |
| 速度只有 ~11 MB/s | 魔搭单连接速度 | 加 `--parallel 3`；或挂数据盘 |
| 下下来 145 字节、开头是 `{"Code":10990101007...}` | 不存在的仓库也返 200 | 脚本已自动识别；若出现，检查 `repo` / `ms_repo` 配的仓库名 |
| 文件体积越下越小 | 源不支持 Range，`curl -C -` 把目标文件从 0 截断重写 | 所有 URL 都由 `probe_sources.py` 提前验过返 206；换源前必须重跑探测 |
| 磁盘不够 | 全量 79.5 GB | `--group img`（21 GB）；或「关机释放GPU → 开机」免费扩容；或挂数据盘后 `--set-dir <id>=<子目录>` |
| 节点报错「找不到模型」 | 凤希自研节点读盘目录和常规约定不同 | 脚本末尾自动 grep `fxai_minimax_upscaler*.py` 打出真实目录名，按那个改 `--set-dir` |
| 装完节点不生效 | ComfyUI 没重启 | 重启 ComfyUI 进程/容器；`python deploy.py verify -H ...` 复查 |
| pip 装依赖失败 | 镜像源慢 | 不致命，重启看日志再补；或手动 `$PY -m pip install -r <节点>/requirements.txt`（`$PY` 是脚本日志里的解释器） |
| GitHub 克隆 `gnutls_handshake() failed` | OneThingAI到 GitHub 的 TLS 常被掐 | 已加 3 次重试（间隔 3 秒）。仍失败手动 `git clone --depth 1 <repo> <目标>` |
| 装完仍报缺节点 | ComfyUI 版本 < 0.30.0 | `--upgrade-comfy` 升级 |

## 工作流改了要同步清单

改了工作流（新增/换模型）之后**必须**跑一次对账，否则装完才发现少东西：

```bash
python scan_workflows.py
```

它扫工作流目录里所有 `*.json`，正则捞出模型文件名、汇总所有 `class_type`，
跟 `assets/models.json` / `assets/nodes.json` 对账，报告哪些模型没被清单覆盖、哪些节点类型没有对应节点包。

## 装完之后
1. 重启云端 ComfyUI（装在 screen `sd` 会话里，见下）。
2. 本机 `~/.workbuddy/fxai_global.json` 把 `comfy_url` 指向 ComfyUI 公网地址：
   **`http://<实例ID>-7860.container.OneThingAI.com`**（端口写在**主机名里**，不是 `:7860` 后缀）。
   地址用 `python xgy_api.py comfy-url <id>` 拿，别自己拼。
   本机跑客户端前要 `export NO_PROXY=".OneThingAI.com,127.0.0.1,localhost"`（本机有代理会拦）。
3. 角色参考图传到 **`<comfy_root>/fxai/image/avatar/`**（不是 `input/avatar/`），
   否则运行时报 `没有图片，请选择图片文件`。参考图从本机 ComfyUI 输入目录（`<你的ComfyUI目录>\input\`）取 `0NN_*.png`。
4. 按 `fxai-workflow` 铁律：确认资源只走接口（提交任务返回 `queued` 即证明服务端读到了），
   本机侧以接口返回为准。

## 重启云端 ComfyUI

装在 screen 会话 `sd` 里（`/tmp/sd.log` 为日志），conda env `comfyui`：

```bash
bash /root/xgyscripts/xgy_restart_comfy.sh
```

脚本内容（现成，别手敲）：`screen -S sd -X quit` → kill 残留 → `rm -f /tmp/sd.log` → 重新拉起 → sleep 45 后打日志尾部。
启动参数：`python main.py --enable-cors-header --enable-manager --listen 0.0.0.0 --mmap-torch-files --disable-pinned-memory`
（`--enable-manager` 别改，不然前端 focusMode 之外还会少 Manager 入口）。

脚本只 sleep 45 秒，脚本内不一定打完「All startup tasks have been completed」，要额外 sleep 20–25 再查。

## fxai-toolkit 报「节点不存在 / IMPORT FAILED」

**通常不是没装节点**，而是缺 Python 依赖，整个包 import 失败（comfyui.log 留痕
`fxai_audio_utils.py line N → ModuleNotFoundError: No module named 'soundfile'`）。
必须先装依赖再重启，否则所有 `FxAi*` 节点都不会注册。

```bash
PY=$(readlink -f /proc/$(pgrep -f "main.py --enable-cors-header" | head -1)/exe)
$PY -m pip install soundfile        # 目前唯一缺的依赖；toolkit 无 requirements.txt
# 装完必须重启 ComfyUI，日志出现「凤希AI - 角色资源管理器」横幅即成功
```

**别在 ComfyUI 进程外用裸 import 验证 fxai-toolkit**：会误报
`PromptServer has no attribute 'instance'`。只能在重启后看 `/object_info` 里有没有 `FxAi*` 节点。

连哪台机 **以 profile 实例 ID 现取凭据** —— 老母版机 `q4k1jqb0x0n5k4nw.ssh.OneThingAI.com:52346`
（密码 eem3…）**已经连不上了**（SSH banner 直接 Reset）。凭据一律从
`secrets/OneThingAI.json` 的 profile 读，key 就是实例 ID：

```bash
python xgy_ssh.py --profile 9xtjztkxzajn9vp5 "<远程命令>"   # 本机工作区 <工作目录>\OneThingAI\xgy_ssh.py
```

### 步骤
1. **先看落后多少**（非 shallow 仓库才能算出来）：
   `git rev-list --left-right --count HEAD...@{u}`，或用 `git fetch origin --quiet` +
   `git log --oneline HEAD...origin/HEAD`。
2. **确认依赖变没变**：`git log --name-only --pretty=format: HEAD..origin/master | grep -E "requirements|pyproject"`。
   没输出就**一个包都不用装**；有输出才 `python -m pip install -U -r requirements.txt`
   （注意别顺手升 requirements 里的 `comfyui-frontend-package` 等钉死版本，
    `system_stats` 里 installed 必须等于 required）。
3. **升本体**：`git pull --ff-only origin master`。工作区有已跟踪文件被删也能拉，
   前提是要拉的那批 commit 没碰它们（`git log --name-only` 先核一遍）。
4. **升自定义节点**：git 装的 `git pull --ff-only`；**zip 装的目录没有 .git，
   只能删了重拉**（`git clone --depth 1` 覆盖前把旧目录 `mv` 成 `.bak.<ts>` 可回滚）。
   解压前先 `rm -rf` 旧 `__pycache__`（残留 pyc 会让节点看起来加载了其实没换代码）。
5. **重启**：`bash /root/xgyscripts/xgy_restart_comfy.sh`（sleep 55 后日志才打完）。
6. **验收**：`/fxai/health` + `/system_stats` 必须 200；`object_info` 节点数
   **不该比升级前少**（升级前先记一次基线）。当前基线：`object_info` **1549** 个，
   其中 `FxAi*` **102** 个、`*KJ` **37** 个。日志里 `Import times` 段要能看见每个节点的加载秒数。

### 本机到云端的下载/网络现状
| 目标 | 结果 |
|---|---|
| `codeload.github.com/.../zip/refs/heads/master` | ❌ 返回 `404: Not Found`（只有 14 字节） |
| `git clone --depth 1 https://github.com/...` | ✅ 通，但**会随机 `gnutls_handshake() failed`**，`for i in 1 2 3 4; do git clone … && break; sleep 4; done` 重试即可 |
| `raw.githubusercontent.com`（Manager 拉清单） | ❌ 现在连不上（日志报 `Failed to perform initial fetching extension-node-map.json`），Manager 退到 local mode，**不影响装/升级节点** |
| `comfyregistry.org` | ❌ 仍不通 |

⚠️ **Jupyter 通道走不通**，别在这上面绕：`POST /api/kernels` → 405（禁建 kernel）、
`GET /api/contents/Work/` → 403、terminal websocket 的
`/api/kernels/terminals/websocket/<n>` 和 `/api/terminals/websocket/<n>` **全 404**。
SSH 是唯一能执行命令的通道。
