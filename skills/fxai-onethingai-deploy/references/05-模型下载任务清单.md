> 用途：在 OneThingAI 控制台 → 模型下载 → **外部模型下载** 页，按本清单逐条提交。
> 表单说明：一个任务 = 一个链接；单实例最多 30 条任务；实例须运行中。

---

## ⚠️ 先看这三条

1. **URL 必须是单文件直链**，仓库页面（`.../Qwen3-TTS-12Hz-1.7B-Base`）不得用 —— 要带`/resolve/main/` 和具体文件名。
2. **下载路径必须一字不差** —— 千问 TTS 服务端代码里目录名是写死的：`Qwen3-TTS-12Hz-1.7B-CustomVoice` / `Qwen3-TTS-12Hz-1.7B-Base`，差一个字符就加载不到（判定依据是目录下有 `config.json`）。
3. **`speech_tokenizer/` 是子目录** —— 4 个 json + 1 个 650M 权重，别漏。
4. 建议加前缀目录（下面统一用 `fxai/`），跟系统自带模型隔开，将来清理/重做镜像时好分辨。
   → 千问 TTS 启动时用 `--cv-dir` / `--base-dir` 指到带前缀的路径即可。

## 提交后：怎么验收

下载完成后在云端执行：

```bash
# 看三个目录的文件数与体积
du -sh /root/qwen3tts/models/* /root/whisper/models 2>/dev/null
ls /root/qwen3tts/models/Qwen3-TTS-12Hz-1.7B-CustomVoice/ | wc -l   # 期望 ≥ 7（11个文件里有4个在子目录）

# 判据：每个模型目录下必须有 config.json，缺了就说明有任务没成功
for d in /root/qwen3tts/models/*/ /root/whisper/models/; do
  [ -f "$d/config.json" ] && echo "OK   $d" || echo "缺配置 $d"
done
```

### 启动参数（下载到默认路径时）

```bash
# 千问 TTS 8086 —— 代码已上传，直接起
setsid /root/miniconda3/bin/python -u /root/qwen3tts/qwen3tts_server.py \
  --host 0.0.0.0 --port 8086 </dev/null >/tmp/tts.log 2>&1 &

# Whisper 8185 —— 已起；若手动预置了模型，加 --model /root/whisper/models
```

## 一个必须先验证的问题

你说「下载后会不会进入公共模型池」——**目前的证据是不进**：

- 平台那1PB「公共库」实测是 **MinIO 对象存储 + 内容寻址**：目录形如 `models/<hash前2>/<hash后2>/<完整sha256>`，共 3191 个**叶子文件**，文件名就是 SHA256。
- **没有任何索引/清单文件**，`find -iname '*qwen3*tts*'`、`'-iname '*whisper*'` 全是空 —— 连一个带名字的文件都没有。
- 所以「下载完自动进池、以后按名字映射」这条路走不通：**没名字就没法定位**。

**建议的实践方式**：先只提交 **第23–27 条（Whisper，5 条任务、1.6G）** 试水，验两件事——
1. 控制台下载完成后，容器内文件是否真出现在指定路径（会不会其实落在别处/需要重启才可见）；
2. 磁盘占用是否真计入实例配额（截图里显示实例总用量 `3833/71680 MB`，如果下载后这个数涨了，就是**占我们自己空间**，不进公共池）。

Whisper 验证通过后再决定千问 TTS 那 22 条怎么走。
