# 06 · 安装与分发（打包给最终用户 · 必守）

> 何时读：把技能包打包分发给别人、在新机器上装机、核对包根内容。**日常生产不用读。**

技能包**不写死任何机器路径**，靠「用户解压包 + UI 生成全局配置 JSON 粘贴给 WorkBuddy」完成安装。

## 两级配置（职责不混）
- **全局部署配置 `fxai_global.json`**（机器级，安装时生成，用户态）：ComfyUI 地址、ffmpeg、whisper 路径+模型目录、软件安装/数据目录等。所有脚本运行期都读它（`FXAI_GLOBAL_CONFIG` 环境变量 → `~/.workbuddy/fxai_global.json` → 代码默认值兜底）。**不随包发真实路径**。
- **工作区配置 `config.json`**（每首歌/MV 空间一份，纯项目数据）：人物参考图、尺寸约定。不进机器路径。

字段与 schema 详见 `04-配置与归档.md`「全局部署配置 schema」。

## 包结构（解压后）

包根是文档 + 各技能目录平铺，装的时候把 `fxai-*` 目录整体拷进技能根。

```
<包>/
├── README.md  SKILL.md  安装说明.md  环境配置.md  更新日志.md
├── 凤希AI技能操作手册.html
├── 合规使用边界.md  已知合规缺口清单.md  字体与素材授权台账.md
├── 智能体安装规程.md
├── fxai_global.example.json     # 全局配置空模板（路径全空，装完按本机填）
├── 专家包/                       # 专家包整目录
└── fxai-*/                      # 各技能目录平铺，含 references/ 与 config.example.json
```

> ⚠️ **打包/复制必须整个技能目录一起拷（含 `references/`）**——只拷 SKILL.md 会让技能看着能跑、实际缺细节。
> 市场版是两级结构（`install.py` + 内包 `fxai-skills.zip`），跑 `python install.py` 效果相同，见《安装说明.md》。

## 安装流程（用户视角的指令）
1. 用户解压包到某文件夹，记下路径。
2. 把各 `fxai-*` 技能目录整体复制到 `~/.workbuddy/skills/`（市场版执行 `python install.py`，同效）。
3. 装完跑一次 `python ~/.workbuddy/skills/fxai-common/global_config.py --init`：探测本机数据写进 `~/.workbuddy/fxai_global.json`，已填的键不覆盖，探不到的留空、用到时再补。字段口径见 `04-配置与归档.md`。
4. 用户建 MV 工作区时，把技能目录里的 `config.example.json` 复制为工作区 `config.json`，填人物参考图。

## 校验
- 必填非空：`comfy_url`（ComfyUI 服务地址）。其余 `whisper_dir` / `python_exe` 等可选：代码按「软件安装目录 / 数据目录」自动定位 ffmpeg 与 whisper 环境，无需手工配置；`comfy_root`/`fxai_root` 已彻底移除，产物全部经 HTTP 接口下载。
- 自检：`python ~/.workbuddy/skills/fxai-common/global_config.py --show` 打印采集结果，与包内 `fxai_global.example.json` 逐键对照，缺项按需补。
