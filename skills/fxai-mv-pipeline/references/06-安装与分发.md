# 06 · 安装与分发（打包给最终用户 · 必守）

> 何时读：把技能包打包分发给别人、在新机器上装机、写安装器 / UI 对接配置。**日常生产不用读。**

技能包**不写死任何机器路径**，靠「用户解压包 + UI 生成全局配置 JSON 粘贴给 WorkBuddy」完成安装。

## 两级配置（职责不混）
- **全局部署配置 `fxai_global.json`**（机器级，安装时生成，用户态）：ComfyUI 地址、ffmpeg、whisper 路径+模型目录、软件安装/数据目录等。所有脚本运行期都读它（`FXAI_GLOBAL_CONFIG` 环境变量 → `~/.workbuddy/fxai_global.json` → 代码默认值兜底）。**不随包发真实路径**。
- **工作区配置 `config.json`**（每首歌/MV 空间一份，纯项目数据）：人物参考图、尺寸约定。不进机器路径。

字段与 schema 详见 `04-配置与归档.md`「全局部署配置 schema」。

## 包结构（解压后）

```
<包>/
├── install.json                 # 安装清单（manifest）—— UI 与安装器共同遵守的契约
├── install_skill.py             # 安装器
├── README.txt                   # 用户安装说明
├── fxai_global.example.json     # 全局配置模板（安装器合并默认值用）
├── fxai_global.字段说明.md       # 全局配置逐字段中文说明（UI 自动生成时照此对接）
├── config.example.json          # 工作区配置模板（用户建 MV 工作区时复制为 config.json）
└── skills/
    ├── fxai-mv-pipeline/        # 仅源码，不含 output/__pycache__/参考图/_package
    └── fxai-lyric-subtitle/
```

> 源文件在 `fxai-mv-pipeline/_package/` 下维护；正式打包时把 `_package/*` 放到包根、`fxai-mv-pipeline/*`（排除本地产物与 `_package`）放到 `skills/fxai-mv-pipeline/`。
> ⚠️ **打包/复制必须整个技能目录一起拷（含 `references/`）**——只拷 SKILL.md 会让技能看着能跑、实际缺细节。

## 安装流程（用户视角的指令）
1. 用户解压包到某文件夹，记下路径。
2. 用户在「凤希AI伴侣」UI 生成全局配置 JSON（字段见 `fxai_global.字段说明.md`），复制下来。
3. 在 WorkBuddy 对话说「安装技能 <包路径>」并把 JSON 粘贴给 WorkBuddy。
4. WorkBuddy 跑 `install_skill.py --pkg <包> --config-file <配置>`：按 `install.json` 复制技能到 `~/.workbuddy/skills/`、写出 `~/.workbuddy/fxai_global.json`（与模板合并，缺省项用模板默认补全）。
5. 用户建 MV 工作区时，把包内 `config.example.json` 复制为 `config.json` 填人物参考图。

## 校验
- 必填非空：`comfy_url`（见 `install.json` 的 `global_config.required`，ComfyUI 服务地址）。其余 `ffmpeg`/`whisper_py`/`whisper_script` 等均可选：代码按「软件安装目录 / 数据目录」自动定位 ffmpeg 与 whisper 环境，无需手工配置；`comfy_root`/`fxai_root` 已彻底移除，产物全部经 HTTP 接口下载。
- 装完用 `_package/_selftest.py` 自检完整安装链路。
