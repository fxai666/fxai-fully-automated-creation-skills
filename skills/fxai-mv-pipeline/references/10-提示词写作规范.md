### 🔴 和短剧的关系：格式共用，音频语义是两套（2026-11-24 用户定）

**无台词**）是**两套规则**。两者**六段小标题都用中文**（2026-11-24 用户定：  
本册一律中文，不写英文段名）。我们**只参考短剧的格式**，不照搬它的音频语义：

| 维度               | 短剧（另一套，只作参考）          | 本册 MV 音频驱动                       |
| ---------------- | --------------------- | -------------------------------- |
| 六段小标题            | 中文（`主体定义 / 摘要 / …`）   | **中文（同左）**                       |
| 主体定义 / 延续分析 / 绑定 | ✅ **格式一致，照用**         | ✅ 同一套白名单                         |
| 音频               | 音色参考 / `<d>` 台词，按句生成  | `fully_copy` 原音频 1:1，**无 `<d>`** |
| 唇形驱动             | 按 `<d>` 台词句生成         | 唇部直接跟随音频波形，**不写开始时间**（除段内有间奏）    |
| 门禁               | 公共门禁校验**格式**，短剧另有中文规则 | 公共门禁校验格式 + 本册 §3 语义校验，**各自一套**   |

一句话：**格式（六段结构、中文小标题、主体绑定、白名单）共用；音频/唇形语义各走各的。**  
短剧的音频写法不得套用到 MV 段。

## 0. 写之前先定三件事（不靠猜）

1. **模式**：多参考（人物图 + 独立场景图）→ **Ref2VA 六段式**。单/多场景 → FL2VA 三段式，  
   不在本册范围（见 h3 技能 01 册）。混用会切不出段。
2. **段数**：`n = av.h3_segment_count(时长)`，每条提示词对应一段，**一一对应**。  
   每段实际 9.41667 秒（H3 的 17k+5 帧约束），尾段不足 3 秒并回上一段。  
   用 `ceil(时长/10)` 估会错 1 段 → 后面几段重复第一条。
3. **该段的人声状态**：从 `歌词时间轴.json` ∩ 分段边界算出  
   `vocal`（有无演唱）和 `vocal_windows`（段内真实起止秒）。  
   **时间轴只按这段真实人声写，不是整段都唱，也不是整段都静音。**

## 1. 六段结构总表（顺序固定，缺一不可）

| 段（中文小标题） | 写什么                                               | 禁写                                           |
| -------- | ------------------------------------------------- | -------------------------------------------- |
| `主体定义`   | 每个人物/场景/道具一句身份词 + `<Audio 1>` 身份                  | 外观细节、颜色、款式、`<Picture>` 独立条目                  |
| `摘要`     | `[reference generation + audio reuse]` 开头，一段话说清表演 | **`<Picture N>`（首帧污染源）**、`(Sx)`、`fully_copy` |
| `延续分析`   | 每个标签一行**通用型白名单模板**（完全沿用 `<Picture N>` + 不新增不替换，见 §2.3）；音频 `fully_copy` | 类目枚举（发型发色/裤装/鞋履）、具体颜色/款式/材质/具名物件、`(Sx)` |
| `详细描述`   | 触发词行 → 风格句 → `[Shot 1]` 时间轴 → 运镜句                 | 时间戳出现在第一事件、`<d>` 块、`At 00:01.000 开始唱`        |
| `整体音效`   | `来自 <Audio 1> 的复制…贯穿全程`                           | 新增音轨、混响、音色形容词                                |
| `非叙事音乐`  | `无`                                               | 任何配乐                                         |

🔴 **六段小标题一律中文**（`主体定义 / 摘要 / 延续分析 / 详细描述 / 整体音效 / 非叙事音乐`），  
内容也全部中文——只有画面可见文字、官方固定标记（标签、`fully_copy`、`camera motion` 等）保留原样。  
门禁已支持中文段名归一化（实测 PASS），不写英文段名。

## 2. 逐段写法

### 2.1 `主体定义` —— 只指认，不描写

```text
主体定义:
<Subject 1> 是 <Picture 1> 中的女子。
<Subject 2> 是 <Picture 2> 中的男子。
<Subject 3> 是 <Picture 3> 中的场景。
<Audio 1> 是本段对应的原声音轨（含清晰人声演唱与伴奏），作为 <Subject 1> (S1) 的音色参考和目标视频的完整最终音轨。
```

- 人物图在前、场景图在后 → `<Subject 1>..<Subject K>` = 人物，`<Subject K+1>` = 场景。
- **一句话到底**：`<Subject N> 是 <Picture M> 中的<身份词>。` 句号后不追加。  
  身份词只到「女子 / 男子 / 场景 / 道具」这一层，不加年龄、国籍、相貌、衣着修饰。
- 音频音色**只挂演唱者人物**（这里是女主 `<Subject 1> (S1)`），不挂场景。
- 无人声段把 `<Audio 1>` 写成「纯器乐、**没有人声演唱**」，**不挂 `(Sx)`**。

> 为什么：新底座高度服从文字。主体定义里写了颜色款式，成片就按文字重建、  
> 参考图被覆盖（实测同图：写细节版深色像素 44.8%，只留身份词版 25.2%）。  
> 外观的决定权必须留在图里，不得写进字里。

### 2.2 `摘要` —— 不得出现 `<Picture>`

```text
摘要:
[reference generation + audio reuse] 本段画面中是 <Subject 1>、<Subject 2> 站在 <Subject 3> 的实景里。目标视频展示 <Subject 1> 在 <Subject 3> 中演唱，收在最后一个音符落下后的安静神情。本段为「主歌1」，音频中有人声演唱。<Audio 1> 作为原声音频。
```

🔴 **`<Picture N>` 是「具体帧 / 构图锚点」，不是「外观参考」**。  
写「`<Picture 1>` 作为人物外观参考」→ 模型真把白底参考图渲染成第一帧，  
写这句会让每段开头 1~1.5 秒是棚拍人像，之后才切实景；删掉这句即可，图与人的绑定只靠 `主体定义` 那一句。

### 2.3 `延续分析` —— 通用型白名单模板（逐字照抄，与短剧同一套）

延续分析**不枚举**「发型发色 / 裤装 / 鞋履 / 建筑陈设」这类类目清单——那是早期写法，
会和短剧分叉、还诱导写死细节。全技能包（短剧 / MV / 口播）统一用下面**三句通用型模板**，
门禁 `h3_format_gate._audit_retention` 逐字校验，改一个字都过不了：

```text
延续分析:
<Subject 1> (appears in [Shot 1]): fully_preserved - 人物身份、五官发型、以及参考图中的全部穿着与配件完全沿用 <Picture 1>；不新增、不替换图里没有的任何服饰细节。
<Subject 2> (appears in [Shot 1]): fully_preserved - 人物身份、五官发型、以及参考图中的全部穿着与配件完全沿用 <Picture 2>；不新增、不替换图里没有的任何服饰细节。
<Subject 3> (appears in [Shot 1]): fully_preserved - 场景环境、背景与画面中已有元素完全沿用 <Picture 3>；不新增参考图里没有的任何内容。
<Audio 1>: fully_copy - <Audio 1> 作为目标视频的完整最终音轨直接复用。
```

三句模板（只换 `<Picture N>` 号，其余逐字不动）：

| 类型 | 模板（`%d` = 对应 `<Picture N>` 号） |
|---|---|
| 人物 | `人物身份、五官发型、以及参考图中的全部穿着与配件完全沿用 <Picture %d>；不新增、不替换图里没有的任何服饰细节。` |
| 场景 | `场景环境、背景与画面中已有元素完全沿用 <Picture %d>；不新增参考图里没有的任何内容。` |
| 道具 | `道具形制、材质与颜色完全沿用 <Picture %d>；不新增参考图里没有的任何部件。` |

一句话逻辑：**外观决定权全交回参考图**——「完全沿用 + 不新增不替换」一句兜住所有类目，
既不写月白 / 鸦青 / 窄袖这类具体词，也不枚举「发型发色、裤装、鞋履」这类类目。
模板唯一事实源：`fxai-audio-video/audio_video.py` 的 `KEEP_PERSON_TPL / KEEP_SCENE_TPL / KEEP_PROP_TPL`；
短剧同款见 `fxai-short-drama/references/01-提示词规范.md`。

### 2.4 `详细描述` —— 触发词 + 首帧钉死 + 时间轴

```text
详细描述:
camera motion
目标视频采用电影感、自然主义的音乐视频风格。
本片为多参考实景成片：<Subject 1>、<Subject 2> 与 <Subject 3> 同时出现在同一个真实拍摄的森林画面里，人物身份与衣着来自人物参考图，环境来自场景参考图，画面从头到尾都是双人同框的森林实景。
[Shot 1] 本段共 9.42 秒，严格按以下时间轴表演：
画面第一帧就是 <Subject 3> 的森林实景：<Subject 1> 与 <Subject 2> 身处林间，并肩站在雾中的小径上……（首帧钉死实景，景别按本镜需要写法见 §3.4.1）
<Subject 1> (S1) 面向镜头持续开口演唱，唇形逐字跟随 <Audio 1> 的歌声波形开合……（第一事件不带时间戳）
At 00:04.200, ……（后续事件才用 `At MM:SS.mmm`）
镜头自雾中树影缓缓下摇……（运镜句按本镜需要写，不写死景别）。
```

- **触发词行固定第一行**：有运镜诉求写 `camera motion`（全小写、独占一行）；  
  文戏镜整行不写；打斗镜按 07 册加 `prfight1` 等。漏挂 = LoRA 完全不生效。
- **首帧钉死句**：起手写「画面第一帧就是 `<Subject K+1>` 的实景：…」，把首帧钉在实景上，  
  不写这句会从参考图的白底构图起手。**钉的是「实景」，不是某个景别**——景别按本镜需要决定（§3.4.1）。
- **`<Audio 1>` 按实际状态写**：有人声段的唇形句见第 3 节；  
  无人声段只写「全段无人声，不演唱、不开口、双唇始终自然闭合」+ 肢体表演。

### 2.5 声音两段

```text
整体音效:
来自 <Audio 1> 的复制人声演唱与伴奏贯穿全程。     ← 有人声段

非叙事音乐:
无
```

无人声段写「来自 `<Audio 1>` 的复制纯器乐伴奏与环境声音贯穿全程，没有人声。」  
音色形容词一律留空（音色完全复刻原音频），不新增音轨。

## 3. 🔴 原音频驱动对口型（本册核心，不可改）

> 这是 `伴读` 等既往 MV 一直用对、本次写跑偏的部分。  
> 三条铁律 + 一条边界，缺一条就唇形对不上。

### 3.1 边界：提供原音频 = 没有台词，不写 `<d>`

官方 `full-reference-en.txt` 的 `<d>[语言]…</d>` 是给**要生成台词/歌词**的分支用的  
（audio reference / T2VA）。我们三条工作流都是**原音频 `fully_copy`**：  
整条音频 1:1 复用成成片音轨，H3 直接把波形唇形贴到人物脸上，  
**不存在"让模型说/唱这段话"这件事**。

- ✅ `<Subject 1> (S1) 面向镜头持续开口演唱，唇形逐字跟随 <Audio 1> 的歌声波形开合`
- ❌ `<d>[Chinese] 雾还没散 我先到了林边</d>` —— 凭空造台词，等于让模型二次生成人声，  
  与 `fully_copy` 打架，唇形必崩。**任何提原音频的 MV 段都不写 `<d>`。**

### 3.2 第一帧 0.000 就开口，第一个事件**不写时间戳**

官方 §5.1：`[Shot 1] marks the opening shot and **has no timestamp**;
later shots use `[Shot N] At MM:SS.mmm, ...\`。  
音频是整段已经存在的，画面第一帧声音就在响，所以人从第一帧起就得在唱。

- ✅ 第一事件：`画面第一帧就是…（首帧钉死）；<Subject 1> (S1) 面向镜头持续开口演唱，唇形逐字跟随 <Audio 1> 的歌声波形开合，……`
- ❌ `0.00s–1.00s（段首过渡）：双唇自然闭合，不做口型；At 00:01.000, 她开始演唱`  
  —— 明确告诉模型前 1 秒可以不唱。**这就是本次唇形对不上的第一根因。**
- ❌ `HEAD_GUARD=1.0` / `TAIL_GUARD=1.0` 人为首尾安全区 —— 沿用会重现该问题，禁用。

### 3.3 时间戳只在"段内有间奏/静音"时用；整段唱就写一句全程同步（关键）

这是用户 2026-11-24 专门澄清的一点，别再搞反：

**情况 A：整段从头唱到尾（绝大多数主歌/副歌段）**  
→ **一句写死全程同步，不写任何时间锚点**，写法：

```text
<Subject 1> (S1) 面向镜头持续开口演唱，唇形从第一帧到最后一个音符全程逐字跟随 <Audio 1> 的歌声波形自然开合，只有她一人开口；身形随乐句轻步移动，双手做柔和手势（表演句接在后面）。
```

不需要"起唱时间""收束时间""起承合时间轴"——H3 拿到 `fully_copy` 原音频自己把唇形贴满整段。  
写时间锚点反而把"这段时间才唱"的暗示喂给模型，是本次翻车的根源。

**情况 B：段内确实有静音/间奏**（`vocal_windows` 是分开的多段，或段首/段尾是静音）  
→ 才用时间戳把"唱 / 不唱"分段写清：

- 段首静音：写「随伴奏轻轻呼吸、双唇自然闭合」，到真实起点  
  `At MM:SS.mmm, <Subject 1> (S1) 开口演唱…`（这是**唯一允许**的时间锚点类型）。
- 句中间奏：写「乐句间音频静音，双唇自然闭合换气、随伴奏轻轻呼吸」。
- 唱到该窗口终点自然停，下一个 `At MM:SS.mmm` 再开口。
- **全段无人声**（前奏/间奏/尾奏）：整段不写演唱/歌声/对口型，只写肢体表演 + 双唇闭合。

判据：看 `vocal_windows` —— 只有一个从 0 覆盖到段尾的窗口 = 情况 A；  
有断档 / 起点不为 0 / 终点不到段尾 = 情况 B。**别凭感觉加时间轴。**

### 3.4 唇形只挂**唯一歌手**；双人同框时另一人不开口

- `<Audio 1>` 音色参考与 `(S1)` 只挂**演唱的女主 `<Subject 1>`**。
- 演唱行明确写「**只有她一人开口演唱**」，使唇形只贴女主脸上。
- 男主同框但不开口：写他「双唇自然闭合、安静陪伴，随她的乐句有表情与肢体回应」——  
  这是**互动表演**，不是第二发声源。给他写任何"开口/唱/讲"都会抢唇形驱动。
### 3.4.1 景别按镜头需要选（2026-11-24 用户定：景别是创作判断，不是铁律）

**景别由这一镜的叙事需要决定**——中景可以半身入画，也可以特写、近景、全景、远景，按情况来：
交代环境用全景 / 远景，看情绪用近景 / 特写，表演与对白用中景 / 中近景。规范**不预设、不强制任何景别**，门禁也不查景别。

真正与景别有关的是一条**创作权衡**（不是禁令、不是门禁项）：

- 需要**目视验收唇形同步**的演唱段，选景时让发声者的唇形在该景别下**清晰可辨**——
  近景 / 中近景 / 特写能满足；若这一镜的叙事需要是全景 / 远景，唇形自然看不清，
  那就靠听音频验收唇形，属于正常创作取舍，不得因景别拦下提交。
- `林间信` 第 3、4 镜当初从全身改中近景，是**该项目的创作选择**（那两镜要验唇形），
  不构成全片、更不构成所有 MV 的默认景别。

`frame_rule` 是项目级**可选项**：写什么景别由该项目镜头需要决定；不写时代码用缺省中景构图。
门禁**不校验**景别措辞，只有「缺首帧钉死实景句」才拦（那防的是白底首帧，与景别无关）。

### 3.5 表情与互动（别做成念稿）

每段一句**专属**表情，相邻段不重复；双人段要写眼神/对视/笑意等互动，  
不得写"头部动作"（点头、仰头、低头、转头、回眸）和"眼神来回扫"——  
写了模型会照演。只留：面向镜头、眉眼/嘴角/笑意、肢体手势、与环境的互动。

### 3.5.1 🔴 同框锁：两人全程同一画面内（2026-11-24 整片重渲实测定，门禁⑧）

画面 ≥2 人时，模型会在「面向镜头开口演唱 + 唇形逐字跟随」重复出现的位置把镜头**推成单人特写**。
仅在场景句里写一句「双人同框的森林实景」压不住（`林间信` 段 6 / 7 / 10 实测：段 7 整段 9.4 秒变成女主单人特写）。

做法是两层同框约束，缺一不可：

- **首帧句之后紧跟一条可执行的构图锁定**（代码 `pair_lock` 在 `k ≥ 2` 时缺省开启，自动生成）：
  「（构图锁定）镜头始终保持在能同时容纳 `<Subject 1>`、`<Subject 2>` 的距离，两人全程同时出现在同一画面内，
  不得推进到只框住其中一人、不得切到单人特写；」
- **文末构图句再重复一次**同框约束，与首帧处前后呼应。
- 该镜刻意要单人特写时，项目设 `prompt_rules.pair_lock: false` 关掉（该段不生成同框锁，门禁⑧亦放行）。
- 门禁⑧：主体定义里 ≥3 个 `<Subject>`（≥2 人 + 1 场景）却缺「始终同时出现在同一画面内」→ 不得提交。

### 3.6 🔴 跨镜头延续：每段首帧承接上一段收尾（2026-11-24 用户定）

全片是连贯的一条线，相邻镜头之间动作 / 姿态 / 神情要接得上，**不得每镜都静止站定、重新起手**。

- 实现落点：项目 `制作.json` 的 `prompt_rules.head_by_seg = {"段号": 首帧句}`（段号 1 起）。
  `build_segment_prompt()` 优先取该段句，缺失时回退 `head_text`。
- 每段首帧句写法：**首帧钉死实景（§2.4）+ 承接上一段收尾状态**（景别按本镜需要写，见 §3.4.1），
  例如「两人仍一前一后走着、他刚收回虚扶的手」「她刚从溪边直起身、指尖还带着水光」。
  承接的是**上一段 act 的收尾**，不得写成当前段的动作（会与本段时间轴动作重复演两遍）。
- 承接句的**姿态须与本段 act 的起点一致**：上一段收尾是「他蹲在旁看她」，本段 act 写「他在前头走」，
  两个状态打架会让模型抓不住人物关系、更容易把镜头推成单人特写（`林间信` 段 6 / 7 / 10 实测）。
  首帧句按本段 act 的**起始姿态**写，上一段的收尾作为「刚做完」的痕迹带一句
  （如「她刚把信盖好松针、指尖离开苔窝，两人已一前一后走进松林深处」）。
- 多段项目（`n ≥ 2`）必须配齐 `head_by_seg`（覆盖全部段号），缺失或段数不足 → 门禁不得提交。
- 仅单段项目允许只用 `head_text`。

### 3.7 🔴 项目配置三项（写提示词前先核准，2026-11-24 定）

这三项从项目 `制作.json.prompt_rules` 读入，直接改变提示词生成路径，写错就翻车：

| 配置 | 正确值 | 写错的后果 |
|---|---|---|
| `full_sing` | 整段演唱段设 `true` | 走双人默认路径、不读 `vocal_windows`、段内静音不做处理 |
| `head_text` | 只保留「画面第一帧就是…实景」首帧钉死句 | 写闭唇 / 站定 / 不做口型 → 门禁 §3.2 拦截；清空 → 器乐段丢首帧句 |
| `frame_rule` | 按本片镜头需要写，留空用缺省 | 景别是创作选择，门禁不校验（§3.4.1） |

- 器乐段（前奏 / 间奏 / 尾奏）时间轴第一事件不写 `At 00:00.000`，首帧钉死句靠 `head_text`/`head_by_seg`；
  清空首帧句会让器乐段同时丢首帧钉死 → 门禁报「没钉死首帧」。

## 4. 镜头语言（H3 规范，别写空话）

- **一条主线**：`镜头自雾中树影缓缓下摇，落到挂着露珠的松针，竖幅低位仰拍，雾占上三分…`  
  写全「类型 + 幅度 + 速度 + 跟拍对象」；`dynamic camera` / `cinematic camera` 空话不写。
- 运镜词只从 06 册词表挑**一条**，与动作绑定（跟拍她的移动 / 落在道具上）。
- 动作写**轨迹**不写动词标签：「抬手→手腕翻转→停顿→随乐句落下」。
- 一段一个镜头只做一件事；多事件靠时间轴顺序串，不堆并行动作。

## 5. 写完必过（自检清单 = 门禁口径）

① 六段小标题齐全、顺序对，内容中文；  
② 主体定义只有身份词一句，延续分析整行照抄通用型白名单模板（§2.3，非类目枚举）；  
③ **`摘要` 无 `<Picture>`**，`详细描述` 首帧钉死句在；  
④ 触发词行在 `详细描述` 第一行；  
⑤ **无任何 `<d>` 块**（原音频驱动）；  
⑥ **`[Shot 1]` 第一事件无时间戳**，开口从第一帧起；  
⑦ **无 `HEAD_GUARD/TAIL_GUARD` 式「段首闭唇过渡 / 段尾提前收唇」**；  
⑧ 起止时刻与 `vocal_windows` 一致；静音段不写演唱；  
⑨ 唇形只挂唯一歌手 `(S1)`，另一人不开口；**首帧钉死实景**（§2.4），景别按镜头需要选、门禁不查（§3.4.1）；  
⑩ `<Audio 1>: fully_copy`，音色词留空，`非叙事音乐: 无`；  
⑪ 相邻段表情不重复，无"点头/眼神扫"类头部动作；  
⑫ **多段项目配齐 `head_by_seg`（覆盖全部段号），每段承接上一段收尾，不静止重来**（§3.6）；  
⑬ **项目配置三项核准：`full_sing` / `head_text`（无闭唇）/ `frame_rule`（按需，可留空）**（§3.7）；  
⑭ **画面 ≥2 人段含同框锁**（`pair_lock` 缺省开启，门禁⑧）（§3.5.1）；  
⑮ 抽帧验收：第 0 帧是实景不是白底人像；**每段头/中/尾各抽一帧确认两人全程未推成单人特写**；每个有歌声窗口抽一帧看唇形开合。

任一条不过 → **不提交渲染**，整段重写。
