# 08 · 音乐生成 · Yue2（**独唱默认**）

> 何时读：用 Yue2 出歌时。**默认用于独唱（单人）**；对唱（多人）默认走 MiniMax Music 3，见 `09-音乐生成-MiniMaxMusic3.md`。
> 本册只讲 Yue2 自己的格式与规则。

## 一、定位

| | |
|---|---|
| 模型 | `yue2_3b_bf16.safetensors`（3B，本地 ComfyUI） |
| 工作流 | `fxai-workflow/music-yue2.json` |
| 默认场景 | **独唱**（单人歌）；也用于「对唱但暂时不想用 M3」的降级 |
| 输出 | wav |

## 二、两个输入：`style` + `lyrics`

### 2.1 Style（一句话风格串）

按「语言 + 流派 + 人声特征 + 速度 + 乐器 + 音乐特征」写，**音乐性指令全部放这里**。

```
中文，内敛女声（温柔略带沧桑），当代流行融合民谣，约 80 BPM，
木吉他与钢琴铺底、低调贝斯、轻电子氛围垫底，咬字清晰，氛围安静疏离。
```

- 人声特征**只能写在 style**——Yue2 **没有男女声标签**。
- `**加粗**` 这类 markdown 标记会被当成风格文本，风格只写纯文本。

### 2.2 Lyrics（歌词 + 结构标签）

标签**独占一行**，中英文均可（本管线统一用中文）：

```
[前奏]
[主歌1]
窗外的晨光洒落
城市在脚下慢慢苏醒
[副歌]
跟我一起奔向阳光里
[桥段]
…
[尾奏]
```

- 可用标签：`[前奏] [主歌] [副歌] [桥段] [尾奏]`（对应 `[Intro] [Verse] [Chorus] [Bridge] [Outro]`）。
- **歌词里只放要被唱出来的词**；音乐说明归 style。
- **歌词只放唱词**——「（男）」「（女）」会被**当歌词唱出来**。

## 三、时长与模式（**锁在工作流里**）

`music-yue2.json` 内置：`mode="full"`、`max_duration=360s`，node 50 的 `seconds` 保持对 node 45 输出的链接。
→ 因此 `gen_music(..., duration=…)` 对 Yue2 **不生效**，歌曲时长由模型按歌词自行决定（360s 是上限）。
**要改时长/模式必须改工作流 JSON 本身。**

## 四、工作流与占位符（维护用）

节点构成（API 格式，`节点id -> {class_type, inputs}`）：

| 节点 | class_type | 关键参数 |
|---|---|---|
| 41 | `CheckpointLoaderSimple` | `yue2_3b_bf16.safetensors` |
| 42 | `YuE2GenerateABC` | mode `full`、`max_abc_tokens` 8192 |
| 45 | `YuE2GenerateMusic` | mode `full`、`max_duration` 360 |
| 50 | `EmptyYuE2LatentAudio` | `seconds` **链到 45 输出 1**（写死会断链） |
| 47 | `ConditioningZeroOut` | 接 45 作 negative |
| 49 | `KSampler` | steps 32 / cfg 1 / `dpm_2` / `sgm_uniform` |
| 51 | `VAEDecodeAudio` | — |
| 53 / 54 | `PrimitiveStringMultiline` | Text(Style) / Text(Lyrics) |
| 55 | `FxAiAudioManager` | `目录` 固定 `音乐生成` |

占位符（提交前由 `submit_workflow` 文本替换）：

| 占位符 | 落在哪 | 类型 |
|---|---|---|
| `fxai_prompt` | 53 `value`（Style） | string |
| `fxai_lyrics` | 54 `value`（Lyrics） | string |
| `fxai_seed` | 52 `seed` | 数字（<1 自动随机） |

注册：`WORKFLOWS["music"]["yue2"] = "music-yue2.json"`；校验走 `WF_SPECS["music"]["any_of"]` 的第 1 个分支。

## 五、调用

```python
from mv_pipeline import gen_music
dst, rel = gen_music(style, lyrics, model="yue2", tag="…", timeout=3600)
```

`model=None` 时按人数默认：单人 → yue2；多人 → minimax3。

## 六、常见故障

| 现象 | 处置 |
|---|---|
| `缺失必填节点 42` | 用了 M3 工作流却按 Yue2 分支校验；检查 `WF_SPECS["music"]` 的 `any_of` 是否完整 |
| 时长不是想要的 | 正常——Yue2 时长锁在工作流（360s 上限），模型按歌词自行收尾 |
| 想要男女对唱 | Yue2 **做不到可控对唱**，换 M3（见 `09-音乐生成-MiniMaxMusic3.md`） |
| 歌词被唱出「（男）」 | 歌词里掺了演唱说明——挪到 `歌曲.md` 的 `## 对唱分工` 与 `分镜剧本.md` 的 `- sing:` |
