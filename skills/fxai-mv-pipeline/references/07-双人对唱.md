# 06 · 双人对唱（对唱模板 · `- sing:` 字段 · 谁在唱）

> 何时读：做**双人 / 多人对唱**的歌时。单人的歌**不用读**本册（走【独唱模板】，与旧版完全一致）。

## 一、两套模板：独唱 vs 对唱

MV 的分镜模板按**角色数**自动切换，互不干扰：

| | 【独唱模板】（单人） | 【对唱模板】（双人 / 多人） |
|---|---|---|
| 触发 | 角色数 = 1 | 角色数 > 1 |
| 分镜字段 | `img / sdesc / cam / camf / act` | 同上 **+ `- sing:`** |
| 谁开口 | 默认该角色整段唱（提示词里是 `<Subject 1>`） | 由 `- sing:` 指定 `<Subject N>`，**可段内秒级切换** |
| 音频 | 单声部（如「温暖女声」） | 男女对唱（Style 里写「男女对唱 / 逐句交替」） |
| 实现 | `render_storyboard_md(n_chars=1)` | `render_storyboard_md(n_chars=2)` |
| 规范 | 本册不用读 | 本册全部 |

**互不干扰**：独唱模板与旧版**逐字一致**；对唱模板只在多人时**追加** `- sing:` 与说明。脚本按 `len(char_defs)` 自动切换，**不需要手动选**。
（`produce_song.py` 的 `render_storyboard_md(..., n_chars=N)`；调用点传 `n_chars=len(char_defs)`。）

## 二、`- sing:` 字段规范（对唱模板专有）

写在 `分镜剧本.md` 每条分镜的字段区（`- act:` 之后一行）。值用**角色名**（与 `制作.json` 的 `characters` 一致，如 `女主` / `男主`）。

| 写法 | 含义 |
|---|---|
| `女主` | 整段由女主开口唱 |
| `男主` | 整段由男主开口唱 |
| `男主(0.00-4.50) 女主(4.50-9.42)` | **段内切换**：0–4.5s 男主唱、4.5–9.42s 女主唱 |
| `女主 男主`（都不带时间） | 演唱区内两人**依次均分** |
| （留空） | 默认第一个角色整段唱（等同独唱行为） |

- 时间为**段内相对秒**（从该段开头算起），可精确到 `0.01s`。
- 段首 1s / 段尾 1s 是过渡安全区，脚本会自动收进「闭唇」区间，`sing` 里的时间**不必避开**它。
- **器乐段**（前奏 / 间奏 / 尾奏）**不写** `sing`（本来就没人开口）。

## 三、提示词层：谁唱 → 谁的唇形动

`build_segment_prompt` 按 `- sing:` 生成明确时间轴（`_parse_sing_plan` 解析）：

- 单段单人：`1.00s–8.42s（演唱）：<Subject 2> (S2) 开口演唱，唇形与 <Audio 1> 中的人声精准同步开合…`
- 段内切换：`1.00s–4.50s（演唱）：<Subject 2> (S2) 开口演唱…` + `4.50s–8.42s（演唱）：<Subject 1> (S1) 开口演唱…`

`<Subject N>` 与多参考图顺序一一对应：第 1 个角色 = `<Subject 1>`（= `<Picture 1>`）、第 2 个 = `<Subject 2>`…（场景排在人物之后）。**角色名 → 序号的换算由脚本在调用点自动完成，分镜里只写角色名即可。**

## 四、音频层：对唱默认走 MiniMax Music 3

★ **对唱（多人）默认音乐模型 = MiniMax Music 3**（独唱才用 Yue2）；这条按人物数**自动生效**，不用手配。M3 的 caption / lyrics 写法与对唱分工规范见 **`09-音乐生成-MiniMaxMusic3.md`**；Yue2 那套见 `08-音乐生成-Yue2.md`。下面第 4 点仍是对唱通用的**验证铁律**。

（Yue2 作为备选：它的 `lyrics` **只认结构标签**（`[前奏] / [主歌1] / [副歌] / [桥段] / [尾奏]`），**没有男 / 女声标签**；人声特征**只能写在 `style`**。若因故仍用 Yue2 出对唱：

1. **Style 里写清对唱**：`中文男女对唱（duet），男声低沉温润、女声清亮柔和，主歌男女声逐句交替应答、一人一句，副歌两人合唱`。
2. **歌词只写唱词**——「（男）」「（女）」会被**当歌词唱出来**。演唱者分工写在两处：
   - `歌曲.md` 的 `## 对唱分工`（人类可读的设计）
   - `分镜剧本.md` 的 `- sing:`（机器用）
3. **Yue2 对唱是「引导式」，常偏单声部**，不保证严格交替。）

4. **无论用哪个模型，生成后都必须验证实际人声**：用基频（f0）分析逐句判定男 / 女（男声 f0 中位数 ≈ 110–150Hz，女声 ≈ 200–260Hz，阈值 ≈ 180Hz），**以实际音频为准**回填 `- sing:`。
   ⚠️ **别用裸自相关**：容易八度误判（把女声判成男声或反之）。用**次谐波求和（SHS）**并拿**频谱最低强峰抽查**做裁判。参考实现：`丹青/_gender_final.py`、`_shs_check.py`。

## 五、验收标准（对唱专属）

- [ ] 分镜每段的 `- sing:` 与该段**实际人声**一致（谁唱谁开口）。
- [ ] 抽帧逐段核对：**唱的那一方唇形开合，另一方闭唇 / 微笑 / 注视**（不抢唱）。
- [ ] 段内切换的段：切换点两侧，画面里开口的人要**跟着换**。
- [ ] 合唱段：两人都可开口，但不必强求同步。

## 六、边界

- 独唱的歌：`- sing:` 留空（脚本也不输出该字段）。
- 对唱的歌：`act` 只写**非演唱**的肢体与互动；演唱由 `sing` 统一驱动（两处都写会打架）。
