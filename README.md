# 凤希AI · 全自动化创作技能包

**FXAI Fully-Automated Creation Skills** · `V1.8`

**说一句话，就出片** · 不绑定任何一家智能体 · 装进你的智能体，从创意 → 剧本 → 出图 → 出片 → 配音 → 字幕 → 发布，全链路它自己跑

## 这是什么

把一整套内容生产流水线装进你的智能体。你不用记命令、不用拼参数、不用打开 ComfyUI 拖节点——说一句「做一条 30 秒的仙侠 MV」「把这段口播做成数字人视频」「这条片换个人」，智能体自己判断该调用哪条链路、该等多久、产物落在哪。

覆盖的成品形态：**短剧 / MV / 数字人口播 / 广告片 / 幻灯片口播 / 图文海报 / 小说与剧本 / 视频号与公众号发布**。

技能不是脚本合集，而是**带护栏的作业规范**：每条链路都写清了判据、失败处置、交付清单与验收口径，所以智能体不会跑一半卡住、也不会静默出一个不能用的片子。

---

## 装在哪：通用，不绑定某一家智能体

这套技能按**通用技能规范**组织，不是某个产品的插件：一个技能 = 一个目录 + `SKILL.md`（触发描述 + 铁律 + 命令速查）+ 按需加载的 `references/`。**任何能读技能目录、能执行本机命令、能读写文件的智能体都能装**，不依赖某家平台的专有接口。

| 宿主需要具备 | 为什么 |
|---|---|
| 能读技能目录 | 它把 `SKILL.md` 顶部的描述当作触发条件，决定这次该不该用这个技能 |
| 能执行本机命令 | Python / ffmpeg / curl 是真正干活的手脚，技能只负责指挥 |
| 能读写文件 | 产物落盘、写交付清单、记项目记忆 |

凤希AI 自己开发与验证时用的是 WorkBuddy，所以下文示例里会出现它的路径与叫法——**那只是其中一个宿主，不是限定**。换到别的智能体，只需把「技能根」换成对方文档里写的那个目录，其余流程完全一样。

## 为什么用这套，而不是自己搭

| 自己搭 | 用这套 |
|---|---|
| 装 ComfyUI、对模型版本、拖节点、写脚本，换个需求又重来一遍 | 说一句话，智能体自己选链路、自己拼参数、自己等任务 |
| 脚本跑完不报错，成片却糊、脸忽大忽小、段与段之间跳 | 每条链路带判据与返修口径，出片前先自检，不合格不交付 |
| 换脸 / 换人 / 换场景按次付费，素材还得上传第三方 | 跑在你自己的机器或你自己的云实例上，素材不出门 |
| 写稿在一个工具、出图在另一个、配音在第三个、发布在第四个 | 创意 → 剧本 → 出图 → 出片 → 配音 → 字幕 → 发布，一条线走完 |

**适合谁**：做号的内容团队、接代运营的小工作室、短剧与 MV 工作室、电商与品牌内容岗、一个人干一整个组活的人。

**不适合谁**：只想批量搬运、盗用他人形象与音色的人——这套的合规边界写得很清楚，越界的活儿它不接。

## 先分清两件东西

| 你拿到的东西 | 跑在哪 | 负责什么 |
|---|---|---|
| **仙宫云镜像** | 云端 GPU 实例 | ComfyUI 本体 + 凤希自研节点 + 全套模型（生图 / 出视频 / 超分 / 换脸换人 / 人声分离） |
| **本仓库（技能包）** | 你自己的智能体 | 42 个通用技能：听懂需求、编排流程、调度云端算力、校验产物、落盘交付 |

- **只开镜像、不装技能**：云端有算力，但没人指挥。
- **只装技能、不开镜像**：能指挥，但本机没算力；纯 CPU 的部分（幻灯片口播、字幕、剪辑、发布）照样能跑。

两件配齐，才是「全自动化」。

> 省钱要点：出片完就**关机**（释放 GPU 才停计费）。技能会读这个地址自动帮你开关机，不需要你手动盯着。

### 3. 下载并解压技能包

到 [Releases](../../releases) 或官网 <https://www.fxai.site> 下载最新技能包 zip，解压到任意目录。

### 4. 把技能装进你的智能体

解压后看到一堆 `fxai-*` 目录，把它们**平铺复制**到你这个智能体的技能根目录：

| 宿主 | 技能根 |
|---|---|
| WorkBuddy（Windows） | `C:\Users\<你的用户名>\.workbuddy\skills\` |
| WorkBuddy（macOS / Linux） | `~/.workbuddy/skills/` |
| 其它智能体 | 该宿主文档里指定的技能目录；不确定就直接问它「你的技能目录在哪」 |

> 注意：是复制 `fxai-*` 这些**目录本身**，不要再套一层父目录。

**还没有智能体？** 先装一个就能用：👉 **[下载 WorkBuddy](https://www.workbuddy.cn/events/invite?inviteCode=q8j94equzsvuskb)**（链接已含推广码；凤希AI 就是在这个宿主上开发和验证的）。它只是**其中一个**可选宿主——任何支持 `SKILL.md` 技能目录的智能体都能装这套技能，装法完全一样。

### 5. 把这段话发给你的智能体（复制即用）

```text
你现在的任务：把这套凤希AI技能包装到这台机器上，并接上我的云端算力。

4. 我的算力环境：仙宫云镜像已经部署好。
   ComfyUI 地址：<填上你在第 2 步拿到的 abc123-8188.container.x-gpu.com>
```

## 方式二：本地安装（下载技能包）

不想用云端 GPU，就把重算力搬回自己机器：

1. 到 <https://www.fxai.site> 下载「凤希AI伴侣」整合包（内含 ComfyUI + ffmpeg + whisper 环境 + 模型与工作流），按安装视频装好：<https://www.bilibili.com/video/BV1EfHL6eEPQ/>
2. 把技能包 `fxai-*` 目录复制进你的智能体技能根（以 WorkBuddy 为例：`~/.workbuddy/skills/`）
3. 把上面第 5 步那段话发给智能体，但第 4 点改成：`我的算力在本机，ComfyUI 地址是 http://127.0.0.1:8188`

装完的效果与方式一一致，区别只是出片速度取决于你自己的显卡。
